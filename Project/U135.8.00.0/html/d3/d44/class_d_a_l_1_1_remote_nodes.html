Description

Singleton holding the input and output images of the remote nodes, each with an activity flag.

The XBee server task writes the inputs and the activity flags, the RS232 task writes the outputs. The 64-bit images are not atomic; a torn read is tolerated, because the next transaction rewrites every image.

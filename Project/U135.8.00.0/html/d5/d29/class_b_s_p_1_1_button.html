Description

Singleton for the XCTU push button, polled by the shared Lib::BSP::DeviceManager tick, reporting press, release and hold events.

The events run in the context of the timer task that dispatches the tick, so a handler must not block. The button is active high. A hold is reported once, when the button has been pressed for HOLD_PERIOD without being released. The first call of instance() registers the device.

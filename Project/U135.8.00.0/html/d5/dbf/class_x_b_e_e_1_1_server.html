Description

Singleton XBee server that sends the node outputs and receives the node inputs, one transaction after another.

Every transaction carries the outputs of all active nodes to the field and returns their inputs. A node becomes active when it reports its inputs for the first time. The images live in DAL::RemoteNodes. The server runs on its own task once start() succeeded.

Description

Singleton for the receive, transmit, association and state LEDs, refreshed every 10 ms from the shared Lib::BSP::DeviceManager tick.

Every LED is active low. An LED with a bound update callback follows the value the callback returns; an LED without one keeps the state last written with set(). The callbacks run in the timer task context and must not block. The first call of instance() registers the device. Its set-up blocks the calling task for 400 ms with an LED start-up sequence.

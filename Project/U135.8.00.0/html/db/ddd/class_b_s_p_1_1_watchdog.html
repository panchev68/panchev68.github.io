Description

Singleton that refreshes the independent watchdog on every tick of the shared Lib::BSP::DeviceManager.

The watchdog is as healthy as the timer task that dispatches the tick: if the timer task starves, the controller resets. The first call of instance() registers the device, so it decides the order in which the devices run their set-up.

Important
The watchdog is started by CubeMX (MX_IWDG_Init()) before the scheduler runs, so it must be refreshed before its timeout elapses. Call instance() before the other devices are created, so that the set-up of this device refreshes the counter before the slower devices run theirs.

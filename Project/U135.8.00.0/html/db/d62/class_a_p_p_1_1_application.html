Description

Singleton application of the U135 board: a radio gateway between the XBee field nodes and the RS232 host controller, or, when the controller is powered from USB, a USB serial port repeater to the XBee module for XCTU.

The start-up mode is chosen once, on the first use. A mode requested with the button before the last reset wins; after a power-on reset the mode follows the USB power detection. Holding the button for BSP::Button::HOLD_PERIOD and releasing it requests the other mode and resets the controller. A short press in the USB mode pulses the XBee reset pin, so XCTU can find the module.

In the normal mode the LEDs show the radio activity: receive and transmit pulse for 10 ms, the association LED follows the XBee association pin and the state LED is lit while the radio link is up. In the USB mode the state LED blinks.

Important
Call run() once, in task context after the scheduler started: the device manager, the button and LED callbacks and the tasks keep the address of the application state.

Starts the devices and the services of the chosen start-up mode.

Blocks for the duration of the LED start-up sequence and, in the normal mode, for the reset of the XBee module. Returns when the services run on their own tasks. If the XBee module does not answer, the transmit LED blinks forever.

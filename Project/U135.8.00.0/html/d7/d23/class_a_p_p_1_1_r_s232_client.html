Description

Singleton for the RS232 link: receives framed commands from the host controller and answers them from DAL::RemoteNodes.

A task assembles the incoming bytes into messages. A message that stays incomplete for 5 ms after its last byte is dropped. Responses are written only while the radio link of XBEE::Server is up, so the host never reads stale node images.

Lib::BSP::EncoderTimer Class Reference

Description

Hardware timer-based rotary encoder and button management.

Uses an STM32 timer in encoder mode for position tracking and a GPIO external interrupt for button events. Button hold detection uses a timeout, and events are passed through FreeRTOS queues and a queue set. The timer and interrupt must be configured before instantiating the class. Verify the timer clock sources and interrupt priorities to ensure reliable encoder operation.

Lib::BSP::EEPROM::I2C::DriverBase Class Referenceabstract

Description

Base class for I2C EEPROM drivers.

Provides initialization, read/write operations and device management for I2C EEPROM devices. Derived classes ('M24C16', 'M24C64W') implement the device-specific 'read()' and 'write()' methods.

The driver supports 8-bit and 16-bit memory addressing and writes page by page with boundary checks and a delay after each page. 'open()', 'close()', 'read()', 'write()' and 'getChipSize()' stay virtual because 'M24C16' and 'M24C64W' override them without a 'noexcept' specification; keeping them virtual with the same signature keeps those overrides compatible. The I2C handle and the EEPROM must be configured before use.

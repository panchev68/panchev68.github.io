Description

Core model aggregator for UI and system modules.

Aggregates individual subsystem models and provides convenience helpers for common operations such as triggering a beep or dispatching periodic tick events to submodels.

◆ tick()

void ModelBase::tick ( Listener * modelListener)
inlinenoexcept

Dispatches periodic tick events to submodels and refreshes the watchdog.

Invokes each submodel's 'handleTickEvent()' to allow polling or periodic processing. 'modelListener' is forwarded so submodels can notify the UI layer about events that occurred during the tick.

Parameters
modelListenerListener to notify about submodel events; 'nullptr' is accepted and simply skips notification for the submodels that require one.

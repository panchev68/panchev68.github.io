System::StartupMode Class Reference

Singleton that manages the device startup behaviour across resets. More...

Description

Singleton that manages the device startup behaviour across resets.

The startup mode is selected by writing a persistent magic word and performing a system reset, so the selected mode takes effect on the next boot. On construction the class reads the magic word to determine the active mode and resets it to the normal-mode sentinel to avoid repeated special boots.

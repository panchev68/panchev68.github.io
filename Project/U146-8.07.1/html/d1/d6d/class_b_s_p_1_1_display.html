BSP::Display Class Reference

Display singleton that extends the ILI9341 driver with project hooks. More...

Description

Display singleton that extends the ILI9341 driver with project hooks.

Backlight level is forwarded to the centralized BSP::Backlight controller. The inherited 'init()' and 'tick()' let the singleton bind into Lib::BSP::DeviceDriverManager as a Lib::BSP::Device handle. Use this instance as the global display.

void BSP::Display::setBacklight ( uint8_t value)
inlineoverridevirtual

Sets the display backlight level.

The value is forwarded as-is to BSP::Backlight, which takes 0-255. The driver's 'init()' itself passes 0 while resetting the chip and 100 once the display is on.

Parameters
valueBrightness level (0-255).

BSP::Display Class Reference

Description

Display singleton that extends the ILI9341 driver with project hooks.

Backlight level is forwarded to the centralized 'Backlight' controller. The inherited 'init()' and 'tick()' let the singleton bind into 'DeviceDriverManager' as a 'Device' handle. Use this instance as the global display.

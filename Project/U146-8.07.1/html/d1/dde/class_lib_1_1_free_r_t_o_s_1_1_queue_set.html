Lib::FreeRTOS::QueueSet Class Reference

Description

Wrapper around a FreeRTOS 'QueueSetHandle_t'.

Allows grouping of queue and semaphore handles into a set so that a single select operation can determine which member is ready. The class validates usage with assertions and requires explicit creation and release.

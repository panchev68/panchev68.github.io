Description

CAN server implementation for the project.

Inherits from 'Lib::Canbus::ServerBase<Server>' (CRTP) and keeps per-client runtime state in 'clientNodes'. There is exactly one concrete server, so no virtual dispatch is needed for its own API. 'start()', 'stop()' and 'getDiagnostic()' are inherited unchanged; only the CRTP hook 'postScanCallback()' and the virtual 'taskEntry()' are implemented here. Client state is synchronized into 'Data::CanbusNodes'.

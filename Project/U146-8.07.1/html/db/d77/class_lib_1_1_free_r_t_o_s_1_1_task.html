Lib::FreeRTOS::Task Class Reference

Description

Wraps FreeRTOS tasks, providing a C++ interface for task creation, management, and control.

Supports task creation with custom functions, priority management, suspension/resumption, and automatic resource cleanup. The class uses RAII principles for task lifetime management.

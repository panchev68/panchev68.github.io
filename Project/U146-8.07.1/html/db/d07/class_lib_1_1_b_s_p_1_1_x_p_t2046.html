Lib::BSP::XPT2046 Class Reference

Description

XPT2046 resistive touch-screen controller driver.

Runs a dedicated RTOS task that bit-bangs the SPI protocol to sample the touch ADC, debounces the press state, integrates/averages raw samples, and maps them to display coordinates according to the configured rotation.

void Lib::BSP::XPT2046::taskEntry ( )

RTOS task entry point.

Continuously polls the debounced press state, samples and integrates the raw X/Y ADC values while pressed, and maps the averaged position to display coordinates once the integrator is full, according to the configured rotation.

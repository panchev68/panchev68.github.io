Lib::BSP::Voltmeter::Base Class Reference

Description

Voltmeter base class for ADC voltage measurement.

Provides an interface for ADC-based voltage measurement, value integration, and change notification, driven periodically by 'DeviceDriverManager' through 'init()' and 'tick()'.

void Lib::BSP::Voltmeter::Base::tick ( )
inlinenoexcept

Periodic driver tick, called by 'DeviceDriverManager'.

Updates the measured voltage once the update-period timeout elapses, and notifies 'valueChangedCallback()' on change.

Precondition
The update-period timeout must have been armed by a previous call to this method.

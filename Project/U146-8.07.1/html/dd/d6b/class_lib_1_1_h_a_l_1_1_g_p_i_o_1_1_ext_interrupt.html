Lib::HAL::GPIO::ExtInterrupt Class Reference

Description

Interrupt-capable GPIO input pin with callback binding.

Combines pin state reading (via 'PinInput') with device registration (via 'Lib::HAL::Handle') so the 'DeviceManager' can look up the instance bound to a given pin number and forward its EXTI callback. Callbacks run in ISR context, so they must stay short and non-blocking, and must be bound or unbound outside interrupt handling.

◆ bind()

bool Lib::HAL::GPIO::ExtInterrupt::bind ( FunctionRef< void(const ExtInterrupt *) noexcept > callback)
inlinenoexcept

Binds a callback to be invoked from ISR context when this pin's interrupt fires.

Binds by reference, like 'Lib::Core::FunctionRef': a free function or a capture-less lambda is stored by value, but any other callable (e.g. a lambda capturing 'this') must be an lvalue that outlives this 'ExtInterrupt'. Prefer 'FunctionRef::fromMethod()' to bind an owning object's method without that lifetime risk.

Parameters
callbackCallback to invoke on interrupt; must not throw.
Returns
'true' if the device was registered successfully, 'false' otherwise.

Lib::HAL::LastResetState Class Reference

Description

MCU last reset state detector.

This class determines and stores the cause of the last MCU reset using RCC flags. It allows applications to identify reset reasons and respond appropriately for improved reliability and diagnostics in STM32-based embedded systems.

Lib::Xbee::API::ClientBase< Derived > Class Template Reference

Description

template<typename Derived>
class Lib::Xbee::API::ClientBase< Derived >

Request/response cycle and connection supervision of an XBee client.

'Derived' must provide 'handleIncomingMessage(const std::vector<uint8_t> &)' returning 'bool', 'handleOutgoingMessage(std::vector<uint8_t> &)' and 'handleTaskTickEvent()'; if they are private it must befriend 'ApplicationBase<Derived>' and 'ClientBase<Derived>'.

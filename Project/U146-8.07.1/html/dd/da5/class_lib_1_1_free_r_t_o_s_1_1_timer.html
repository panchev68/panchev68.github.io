Lib::FreeRTOS::Timer Class Reference

Description

C++ wrapper around FreeRTOS software timers with RAII management.

Provides automatic resource cleanup and a simplified, type-safe API for creating, managing, and controlling software timers in embedded systems. Offers thread-safe operations, with ISR variants for use from interrupt context.

◆ pendFunctionCall()

bool Lib::FreeRTOS::Timer::pendFunctionCall ( FunctionRef< void() noexcept > function,
uint32_t delay )
inlinenoexcept

Pends a function call for execution.

Schedules a function to be executed after a specified delay, via the timer daemon task. The timer must be created.

'function' is stored non-owning ('Lib::Core::FunctionRef') and is only invoked later, from the daemon task, so it must stay valid until then: a free function, a capture-less lambda, or an lvalue callable/method binding (e.g. 'FunctionRef::fromMethod()') that outlives the pended call. A lambda capturing state, passed as a temporary, is rejected at compile time because it would dangle.

Parameters
functionThe function to execute; must outlive the pended call and not throw.
delayThe delay in ticks before execution.
Returns
'true' if the function call was pended successfully, 'false' otherwise.

Pends a function call from an ISR context.

Schedules a function to be executed immediately from within an interrupt service routine, via the timer daemon task. The timer must be created.

Same non-owning lifetime contract as 'pendFunctionCall()': 'function' must remain valid until the daemon task actually invokes it.

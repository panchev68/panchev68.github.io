ModelXbee::Listener Class Reference

Listener interface to receive XBee model change events. More...

Description

Listener interface to receive XBee model change events.

Implementations receive granular callbacks when submodel values change. Every callback has an empty default body, so an implementation overrides only the ones it needs.

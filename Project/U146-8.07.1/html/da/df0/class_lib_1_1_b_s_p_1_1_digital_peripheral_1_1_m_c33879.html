Lib::BSP::DigitalPeripheral::MC33879 Class Reference

Description

MC33879 motor driver control class.

The MC33879 class encapsulates the register constants of the MC33879 motor driver IC for status reads and control writes. It performs no hardware access itself. The class assumes proper SPI communication setup and hardware initialization before use. Verify the hardware connections and power supply before use to avoid damage to the MC33879 IC or the connected motors.

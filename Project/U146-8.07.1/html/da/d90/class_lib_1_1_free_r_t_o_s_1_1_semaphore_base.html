Lib::FreeRTOS::SemaphoreBase Class Reference

Description

Base class for FreeRTOS semaphores.

Encapsulates the handle lifecycle and the take/give operations common to every semaphore flavor. Each derived class provides its own 'create()' with the parameters appropriate to that semaphore type (binary, counting, mutex).

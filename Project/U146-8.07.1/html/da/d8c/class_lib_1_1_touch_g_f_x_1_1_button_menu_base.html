Lib::TouchGFX::ButtonMenuBase< ButtonCount > Class Template Reference

Description

template<size_t ButtonCount>
requires (ButtonCount > 0U && ButtonCount <= static_cast<size_t>(INT16_MAX))
class Lib::TouchGFX::ButtonMenuBase< ButtonCount >

Toggle-button menu logic for a screen or container.

The derived screen forwards its lifecycle and key events to setupScreen(), up(), down(), select() and deselect(). Selecting the last button (by convention "Back") stores position 0, so the menu reopens on the first entry.

Template Parameters
ButtonCountNumber of menu buttons.

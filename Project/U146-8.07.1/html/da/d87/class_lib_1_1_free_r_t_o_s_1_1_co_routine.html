Lib::FreeRTOS::CoRoutine Class Reference

Description

Wrapper that encapsulates FreeRTOS co-routine creation and related helpers.

The constructor invokes the FreeRTOS co-routine creation API and asserts on failure. Static helpers are provided for scheduling and performing queue operations from an ISR context; these helpers assert if an unexpected error occurs.

This class does not retain or expose co-routine handles beyond creating the underlying co-routine.

Creates a FreeRTOS co-routine by calling 'xCoRoutineCreate' with the provided entry function, priority and index. The call asserts if creation fails.

Lib::BSP::Ethercat::PDI::LAN9252::Base Class Reference

Description

Base class for the LAN9252 EtherCAT PDI driver.

Implements the SPI interface, register/PRAM access, chip reset, and state management for the LAN9252 EtherCAT PDI.

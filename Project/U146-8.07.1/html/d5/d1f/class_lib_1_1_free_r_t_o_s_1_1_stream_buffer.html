Lib::FreeRTOS::StreamBuffer Class Reference

Description

Wraps FreeRTOS stream buffers, providing a C++ interface for streaming data between tasks.

Supports sending and receiving data with timeouts, querying buffer status, and ISR-safe operations. The class manages the stream buffer handle with RAII principles.

Description

Selects and exposes the 'HardwareProfile' for the hardware revision of the board.

The revision is the packed 4-bit identifier from 'System::HardwareVersion::readVersionId()'. A revision without its own profile data selects the default profile and sets 'isFallback()', so the caller can signal it.

The class is non-instantiable and offers a static API. Profile data stays in 'ProfilesData.hpp', which is included only from the implementation so the CubeMX HAL headers do not leak into consumers of this header.

Lib::Helper::SunMoonCalculator Class Reference

Description

Calculates sunrise, sunset, and moon phase for a fixed position, time zone, and date.

Call 'setPosition()' (or the constructor) and 'setDate()' before reading any sunrise/sunset or moon phase value.

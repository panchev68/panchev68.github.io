System::Parameters Class Reference

Singleton that manages persistent parameters stored in EEPROM. More...

Description

Singleton that manages persistent parameters stored in EEPROM.

Use 'instance()' to obtain the global object. The EEPROM driver is hidden behind the implementation, so logical const accessors can still check the storage state.

bool Lib::Xbee::Core::ComDriver::send ( const Frame::Data & frameData,
uint32_t timeoutMs )
inline

Builds a Digi API1 frame from the frame data and sends it.

The frame is built while mutexSend is held, into a driver-owned buffer, so tasks sending in parallel (application, channel scanner, GUI services) cannot overwrite each other's frame.

Parameters
frameDataFrame data to serialize.
timeoutMsTimeout in milliseconds.
Returns
'true' if the frame was sent successfully; 'false' otherwise.

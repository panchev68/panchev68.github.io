Lib::BSP::Device Class Reference

Description

Non-owning handle binding a concrete driver's 'init()'/'tick()' to a uniform call interface.

Stores the driver address plus one statically generated thunk per operation, so each call is a single indirect jump into a thunk where the driver's own method is resolved (and usually inlined) at compile time. Drivers need no base class, no vtable, and no virtual destructor. The referenced driver must outlive the handle — in practice every driver is a static singleton.

BSP::Outputs Class Reference

Drives the 24 digital outputs over SPI from a 64-bit output bitmap. More...

Description

Drives the 24 digital outputs over SPI from a 64-bit output bitmap.

Two hardware variants are supported. BSP::Outputs::Type::DaisyChain is the MC33879 chain: the transmit buffer is built from BSP::Outputs::PRECODE_ARRAY and the returned daisy-chain identifiers are checked. BSP::Outputs::Type::ShiftRegister is three 74HCT595 in series (3 bytes, no feedback), latched by NSS.

◆ setup()

void BSP::Outputs::setup ( )
noexcept

Configures the NSS and OE pins and opens the SPI port.

Sets NSS and OE to push-pull outputs and drives NSS inactive. OE is inactive for BSP::Outputs::Type::DaisyChain and active (low, outputs enabled) for BSP::Outputs::Type::ShiftRegister.

◆ update()

void BSP::Outputs::update ( )
noexcept

Sends the current output bitmap to the output devices.

Dispatches on the output variant. BSP::Outputs::Type::DaisyChain sets BSP::Outputs::isError when the returned identifiers are wrong. BSP::Outputs::Type::ShiftRegister has no feedback, so BSP::Outputs::isError is always cleared.

Precondition
BSP::Outputs::setup() must have been called to open the SPI port.

BSP::Outputs Class Reference

Description

Drives the 24 digital outputs over SPI from a 64-bit output bitmap.

Two hardware variants are supported. 'DaisyChain' is the MC33879 chain: the transmit buffer is built from 'PRECODE_ARRAY' and the returned daisy-chain identifiers are checked. 'ShiftRegister' is three 74HCT595 in series (3 bytes, no feedback), latched by NSS.

◆ update()

void BSP::Outputs::update ( )
noexcept

Update the outputs according to the current output bitmap.

Dispatches on the output variant. 'DaisyChain' sets 'isError' when the returned identifiers are wrong. 'ShiftRegister' has no feedback, so 'isError' is always cleared.

Precondition
spiPort must point to a valid opened SPI port (call setup() before update()).

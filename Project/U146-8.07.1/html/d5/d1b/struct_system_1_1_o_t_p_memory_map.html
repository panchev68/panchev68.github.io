Description

Packed structure reflecting the OTP memory map for production and sale dates.

Each field maps to a 32-bit word in the device OTP region and holds an encoded date value; the encoding is defined elsewhere. The struct mirrors the physical layout and must remain packed. Only productionDate2 and saleDate2 are used, through System::ProduceDate and System::SaleDate.

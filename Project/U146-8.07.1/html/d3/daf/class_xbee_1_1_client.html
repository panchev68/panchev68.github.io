Description

Singleton XBee client with the project-specific message handling and lifecycle hooks.

Header-only, built on the CRTP bases 'Lib::Xbee::API::ClientBase' and 'Lib::Xbee::API::UserProtocol'. It answers every received OUTPUTS message with an INPUTS message and mirrors the client state on the ready LED. The first 64-bit value of each exchanged payload belongs to the local peripheral, every following one to a CAN bus node, in 'Data::CanbusNodes' order.

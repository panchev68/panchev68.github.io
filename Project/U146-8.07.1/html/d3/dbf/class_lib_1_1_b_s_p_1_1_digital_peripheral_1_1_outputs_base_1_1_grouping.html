Lib::BSP::DigitalPeripheral::OutputsBase< T_PIN_NUM >::Grouping Class Reference

Description

template<size_t T_PIN_NUM>
class Lib::BSP::DigitalPeripheral::OutputsBase< T_PIN_NUM >::Grouping

Grouping nested class for output management.

The 'Grouping' class manages output value changes asynchronously using FreeRTOS. It implements logic to prevent excessive simultaneous output switching by grouping changes and applying them in controlled batches, which protects power supplies and reduces electromagnetic interference.

Requires a FreeRTOS environment for task execution.

Template Parameters
T_PIN_NUMThe number of output pins, inherited from the parent class.

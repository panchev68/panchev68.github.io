Lib::HAL::GPIO::ExtInterrupt::DeviceManager Class Reference

Description

Singleton registry of bound 'ExtInterrupt' instances, keyed by pin number.

'getDevice()' overrides the base's pointer-identity lookup with a by-value pin-number comparison, since each device's handle pointer is a distinct address into its own instance.

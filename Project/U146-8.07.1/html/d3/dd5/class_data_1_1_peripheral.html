Data::Peripheral Class Reference

Singleton class that holds peripheral input and output states. More...

Description

Singleton class that holds peripheral input and output states.

Stores input and output bitmasks and provides events that subscribers use to react to changes. No internal thread-synchronization is provided; callers must ensure thread-safety when accessing the singleton from multiple threads.

[8.07.1] - 2026-10-26

Added

  • Split class implementations out of headers into .cpp files, keeping the public interface unchanged:
    • TouchGFX/Model: ModelCanbus, ModelDiagnostic, ModelDisplay, ModelPeripheral, ModelSystem, ModelUsb, ModelXbee.
    • System: Parameters, StartupMode, StartupSync, Watchdog, HardwareVersion, DisplayRotation, SerialNumber, SaleDate, ProduceDate, BuildVersion, LastResetState.
    • BSP: Leds, M24C64W, Backlight, Beep, Display, TouchScreen, W25Q128JVSIQ, DigitalPeripheral, DigitalPeripheral/Inputs, DigitalPeripheral/Outputs.
    • Canbus/Server, Xbee/Client, USB/SerialPortRepeater, HAL/RTClock, Data/Peripheral.
  • Project/EWARM/U146.ewp: registered the new .cpp files next to their headers and added a HAL group with RTClock.hpp/RTClock.cpp.
  • @version/@date block in 76 library files that had none (Lib/Lib/XBEE, HAL, BSP, std).
  • Project/.vscode/c_cpp_properties.json: manual IntelliSense configuration (U146) with IAR libc++ and C include paths, forcedInclude of Lib/common.h, and the project defines. Editor only, not part of the firmware build.

Changed

  • TouchGFX updated from 4.26.1 to 4.27.0: TouchGFX/U146.touchgfx (Version), generated code regenerated with TouchGFX Generator 4.27.0 (fonts, images, texts, gui_generated), and the environment path in TouchGFX/config/gcc/app.mk and TouchGFX/config/msvs/Application.props set to C:\TouchGFX\4.27.0.
  • @version of every project and library source set to 8.07.1 (from version.h: FW_VERSION 8.07 and FW_SUB_VERSION 1); @date set to 2026-10-26.
  • version.h: FW_SUB_VERSION set to 1; @version set to 8.07.1. version.txt set to 8.07.1.
  • Project/.vscode/settings.json: removed C_Cpp.default.configurationProvider.
  • Pimpl applied to CanbusNodes, Peripheral, DisplayRotation, StartupSync, StartupMode, Parameters and TestPeripheralOutputs (struct changed to class).
  • Comment pass over project sources (Doxygen layout, single-quoted identifiers, #endif conditions, #pragma region grouping) and over Lib/Lib (209 files). No code changes.
  • Line endings of project .cpp/.hpp files normalized to CRLF.
  • EWARM/U146.ewp, EWARM/U146.ipcf, EWARM/U146.ewt: TouchGFX linker input changed to Middlewares/.../cortex_m4f/IAR9.x/touchgfx_core_libcpp.a (the libc++ variant used with --libc++; IAR8.x has no _libcpp build). Previously it pointed to IAR8.x/touchgfx_core_libcpp.a, which does not exist.
  • EWARM/U146.ewp: include paths X:\Projects\Mechatronika\U146-Firmware\Lib (misspelled absolute path) replaced with $PROJ_DIR$/../../Lib, $PROJ_DIR$/../../Lib/Lib, and $PROJ_DIR$/../../Lib/Lib/std.

Fixed

  • Removed a stale HardwareProfiles/Profiles.hpp entry from the IDE project.
  • HardwareProfiles/Manager.hpp brought to 8.05.2 to match Manager.cpp (version drift).
  • RTClock documentation no longer claims it inherits from Lib::HAL::RTClock.
  • CanbusNodes.cpp: removed a stale @note that said the file was no longer used.
  • ModelXbee: removed a stale FIX comment (raw RSSI is no longer stored).
  • M24C64W::write() documentation no longer claims callers must avoid page crossings; writePages() splits transfers at page boundaries.
  • ModuleParameters::getChannelIndex assert now has a message.

Removed

  • Stale Profiles.hpp IDE entry (see Fixed).

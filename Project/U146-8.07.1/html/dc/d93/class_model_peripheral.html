Description

Peripheral I/O model.

Caches the inputs/outputs/activity of whichever node is currently selected (index 0 == local peripheral, 1..'NUM_OF_CANBUS_CLIENT_NODES' == CAN bus nodes) and notifies a 'Listener' only for the fields that actually changed since the last 'handleTickEvent()' call.

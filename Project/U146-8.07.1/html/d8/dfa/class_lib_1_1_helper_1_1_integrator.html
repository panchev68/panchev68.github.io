Description

template<typename T, size_t SIZE>
class Lib::Helper::Integrator< T, SIZE >

Moving-average integrator over a fixed-size sample window.

Template Parameters
TSample type; must support addition, subtraction and division by 'size_t'.
SIZEWindow size (number of samples); must be at least 1.

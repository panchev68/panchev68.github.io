Lib::FreeRTOS::EventGroup Class Reference

Description

RAII-style wrapper around FreeRTOS 'EventGroupHandle_t'.

Provides creation, deletion and convenience operations such as waiting, setting and clearing bits, including ISR-safe variants. Methods assert that the underlying handle is valid where appropriate.

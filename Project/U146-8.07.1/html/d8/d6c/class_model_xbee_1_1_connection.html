Connection status submodel. More...

Description

Connection status submodel.

Mirrors the connection state, the retry and reconnection counters and the link quality of the XBee client, and notifies ModelXbee::Listener when they change.

void ModelXbee::Connection::tick ( Listener * listener)
noexcept

Periodic update: detects connection state, retry and quality changes.

Notifies the listener when they occur. State, retry and reconnection changes are checked on every call; quality changes are checked once per ModelXbee::Connection::QUALITY_UPDATE_PERIOD_DURATION.

Parameters
listenerListener to notify.
Precondition

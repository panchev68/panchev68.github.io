Lib::HAL::CAN::PortBase Class Reference

Description

Base class for CAN port operations.

Manages the FreeRTOS resources (queues, semaphores, task) created on 'open()' and released on 'close()', and dispatches HAL events to the virtual 'messageReceivedCallback()', 'errorCallback()', 'preSendCallback()' and 'postSendCallback()' hooks. The hooks are virtual because 'Lib::HAL::CAN::DeviceManager' (see 'DeviceManager.hpp') holds registered ports behind a plain 'PortBase *' and routes HAL interrupt callbacks to them polymorphically. Callbacks are invoked from interrupt context, so they must stay short and non-blocking.

Lib::Helper::JaggedArray< T > Class Template Reference

Description

template<class T>
class Lib::Helper::JaggedArray< T >

Compact container of unique, non-owning pointers.

Stores non-owning pointers to existing 'T' objects, rejecting null and duplicate entries, with fast add/remove and bounds-checked indexed access.

Template Parameters
TType of the elements referenced by the jagged array.

Lib::FreeRTOS::MemoryManager::Diagnostic Struct Reference

Description

Diagnostic counters for memory operations.

Tracks cumulative allocations, deallocations and currently active allocations. The counters may overflow in long-running systems, so use them for debugging and profiling only.

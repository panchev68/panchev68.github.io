System::BuildVersion Class Reference

Description

Firmware build version manager.

Inherits from 'Lib::System::Version::Firmware' and exposes the firmware version and sub-version taken from 'version.h'. The singleton is created on first use and lives for the whole program; construction is private and copy/move are disabled.

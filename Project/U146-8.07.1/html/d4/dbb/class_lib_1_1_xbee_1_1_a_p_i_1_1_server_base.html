Lib::Xbee::API::ServerBase< Derived > Class Template Reference

Description

template<typename Derived>
class Lib::Xbee::API::ServerBase< Derived >

Transaction state machine and connection supervision of an XBee server.

'Derived' must provide 'handleIncomingMessage(const std::vector<uint8_t> &)' returning 'bool', 'handleOutgoingMessage(std::vector<uint8_t> &)', 'outputsUpdatedSuccessfulCallback()' and 'handleTaskTickEvent()'; if they are private it must befriend 'ApplicationBase<Derived>' and 'ServerBase<Derived>'.

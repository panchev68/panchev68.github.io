Lib::FreeRTOS::Timer

Using the FreeRTOS Timer Wrapper for Periodic Tasks

This example demonstrates how to use the Timer class to create and manage a periodic software timer in a FreeRTOS-based embedded system. The timer executes a callback function every 1000 ticks (approximately 1 second at 1000 Hz tick rate) to toggle an LED or perform a periodic task.

Example usage:
#include "Lib/FreeRTOS/Timer.hpp"
#include <iostream> // For demonstration, replace with actual output
void ledToggleCallback() {
// Code to toggle LED
std::cout << "LED toggled!" << std::endl;
}
int main() {
// Create timer configuration
Lib::FreeRTOS::Timer::Config config{
.name = "LED Timer",
.callback = ledToggleCallback,
.period = 1000, // 1000 ticks
.autoReload = true
};
// Create and start the timer
Lib::FreeRTOS::Timer timer(config);
timer.start();
// Timer will now call ledToggleCallback every 1000 ticks
// In a real application, the main loop would handle other tasks
vTaskDelay(portMAX_DELAY); // Wait indefinitely
return 0;
}

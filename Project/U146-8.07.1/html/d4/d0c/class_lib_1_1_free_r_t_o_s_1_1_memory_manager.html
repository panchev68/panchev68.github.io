Lib::FreeRTOS::MemoryManager Class Reference

Description

FreeRTOS memory allocation and deallocation manager.

Provides static wrapper methods around FreeRTOS heap functions with basic diagnostic tracking to monitor allocations, deallocations and currently active allocations.

void Lib::FreeRTOS::MemoryManager::free ( void * memory)
inlinestaticnoexcept

Deallocate memory previously allocated with 'malloc()'.

Decrements diagnostic counters and returns memory to the FreeRTOS heap. Assumes the pointer is valid and was previously allocated by this manager.

Parameters
memoryPointer to memory allocated by 'malloc()'. Must not be null.

Passing null is undefined; this is a programmer error.

◆ malloc()

void * Lib::FreeRTOS::MemoryManager::malloc ( size_t size)
inlinestaticnoexcept

Allocate memory from the FreeRTOS heap.

Allocates the requested size and increments diagnostic counters if successful. Memory is not zero-initialized.

Parameters
sizeNumber of bytes to allocate (must be > 0).
Returns
Pointer to allocated memory, or null if allocation failed.

The caller is responsible for lifetime management and must eventually call 'free()' on the returned pointer.

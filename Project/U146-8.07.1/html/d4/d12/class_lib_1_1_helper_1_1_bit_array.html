Lib::Helper::BitArray< T, T_SIZE > Class Template Reference

Description

template<typename T, size_t T_SIZE = (sizeof(T) * 8U)>
class Lib::Helper::BitArray< T, T_SIZE >

Fixed-width bit array with compile-time size checking.

Wraps 'std::bitset' to provide safe, convenient bit-level operations on an integral type, including conversion to/from 'T' and bounds-checked per-bit access.

Template Parameters
TThe underlying integral type represented by the bit array.
T_SIZENumber of bits in the array; defaults to the bit width of 'T'.

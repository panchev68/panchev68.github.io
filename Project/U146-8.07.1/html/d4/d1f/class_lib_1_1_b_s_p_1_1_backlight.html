Lib::BSP::Backlight Class Reference

Description

PWM backlight controller implementing gradual fading and sleep.

The controller is constructed with a 'Config' that describes the hardware timer channel and timing parameters. Satisfies 'DeviceDriver': 'DeviceDriverManager' calls 'init()' once to start PWM and then 'tick()' periodically to perform fading and sleep handling.

Lib::HAL::GPIO::Pin< Type::OUTPUT > Class Reference

Description

GPIO output pin specialization.

Reuses 'Pin<Type::INPUT>' handle, mode configuration and read support through ordinary (non-virtual) inheritance, and adds write and toggle operations for driving the pin.

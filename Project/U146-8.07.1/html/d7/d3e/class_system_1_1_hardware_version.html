◆ readVersionId()

uint8_t System::HardwareVersion::readVersionId ( ) const
nodiscardnoexcept

Read hardware revision pins and compute a packed revision identifier.

Samples 'HW_REV0..HW_REV3' (active low) and packs the four bits into a 4-bit value where bit 0 corresponds to 'HW_REV0'.

Returns
4-bit revision identifier in the range 0..15.

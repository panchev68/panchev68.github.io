Lib::BSP::DigitalPeripheral::Input Class Reference

Description

Input class for debounced digital input handling.

Manages digital input signals with debouncing to filter out transient noise and produce a stable boolean output.

bool Lib::BSP::DigitalPeripheral::Input::update ( bool value)

Update input with debouncing logic.

Processes the provided raw input value and applies debouncing. If the input value remains stable for the configured debounce period, the processed output is updated.

Description

Singleton adapter for the W25Q128JV external SPI flash.

Public inheritance from Lib::BSP::W25Q128JVSIQ exposes its read, write, erase and status interface unchanged. The flash sits on hspi3 with chip select 'FMEM_NSS'.

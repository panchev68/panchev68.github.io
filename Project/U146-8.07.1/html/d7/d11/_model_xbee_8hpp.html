ModelXbee.hpp File Reference

Description

Declares 'ModelXbee', the top-level model for XBee-related UI state.

Aggregates submodels for signal strength, connection status, transmit timing, activity LEDs, module parameters and the spectrum analyzer, and dispatches periodic tick events to all of them.

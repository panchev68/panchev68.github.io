Lib::FreeRTOS::Timeout Class Reference

Description

Manages timeouts based on FreeRTOS tick counts.

Provides methods to set, reset, and check timeouts, as well as operators for convenient timeout manipulation. The class automatically handles tick count retrieval and comparison. Timeouts are based on FreeRTOS tick counts, so the tick configuration must be correct.

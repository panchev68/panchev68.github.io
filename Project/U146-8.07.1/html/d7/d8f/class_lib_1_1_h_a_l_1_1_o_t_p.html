Lib::HAL::OTP Class Reference

Description

Accessor for the MCU OTP flash user region.

Provides utilities to read and program the OTP area used for user data and exposes a singleton instance for global access.

The OTP region used on target devices starts at FLASH_OTP_BASE and ends at FLASH_OTP_END; platform documentation describes layout and locking behavior.

See also
FLASH_OTP_BASE, FLASH_OTP_END

Description

Driver for the M24C64W I2C EEPROM with bounds-checked reads and page-aware writes.

Wraps an Lib::HAL::I2C::Master::Port in interrupt mode and addresses memory with 16-bit addresses. Copy and move are disabled: an instance owns exclusive state (BSP::M24C64W::isReady, BSP::M24C64W::presenceState) mirroring one physical device on the bus, and a duplicate would drift out of sync with that hardware.

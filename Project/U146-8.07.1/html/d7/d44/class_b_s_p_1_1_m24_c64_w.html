BSP::M24C64W Class Reference

Description

Driver for the M24C64W I2C EEPROM.

Copy and move are disabled: an instance owns exclusive state ('isReady', presence cache) mirroring one physical device on the bus, and a duplicate would drift out of sync with that hardware.

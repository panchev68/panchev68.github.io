Lib::Xbee::Core::RemoteAtCommand Class Reference

Description

Sends the remote AT commands of an XBee module and queues their responses, through FreeRTOS queues.

◆ close()

void Lib::Xbee::Core::RemoteAtCommand::close ( )
inline

Closes the remote AT command handler: stops accepting responses and releases the message queue.

The handler stays bound; close() waits for a running handler to leave before the queue is deleted, because the receiver task could be writing to it while another task releases it.

◆ open()

bool Lib::Xbee::Core::RemoteAtCommand::open ( )
inline

Opens the remote AT command handler: creates the message queue and registers the response callback.

The handler is shared by several services; a second open is reported as busy instead of asserted.

Returns
'true' if this call opened the handler, 'false' if it is already open (another owner).

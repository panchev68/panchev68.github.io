Lib::Helper::ContainerBase< T > Class Template Reference

Description

template<typename T>
class Lib::Helper::ContainerBase< T >

Non-virtual collection of values of type 'T'.

Provides fast addition, removal, clearing, indexed access, and iteration, with duplicate/null rejection and no virtual dispatch overhead.

Template Parameters
TValue type managed by the container (typically a pointer or lightweight handle).

Lib::FreeRTOS::Queue Class Reference

Description

Lightweight C++ wrapper for a FreeRTOS 'QueueHandle_t'.

Provides methods for creating, deleting and interacting with a FreeRTOS queue from both task and ISR contexts. Methods validate the handle via assertions where appropriate.

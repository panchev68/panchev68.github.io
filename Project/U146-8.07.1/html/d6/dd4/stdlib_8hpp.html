Description

Minimal freestanding replacements for atol(), strtod(), and itoa().

Provides small, self-contained implementations of these conversions for use when the platform's C library is unavailable or considered too resource-intensive. Not a full-fidelity implementation: whitespace skipping is limited to space/tab, and no exponent notation is supported. Do not include this header in a translation unit that also links the real C library's atol(), strtod() and itoa() (via '<cstdlib>'), because both define the same 'extern "C"' symbols and collide at link time.

Lib::Canbus::ServiceBase Class Referenceabstract

Description

Base class for CAN bus service abstraction.

Core functionality for CAN message transmission, reception, diagnostics, and task management, built on top of 'HAL::CAN::Port'. Public inheritance from 'Port' is required so 'messageReceivedCallback()'/ 'errorCallback()' can override the own virtuals of 'Port', which the HAL layer invokes polymorphically from interrupt context — the one genuine reason this class keeps any virtual dispatch at all.

'taskEntry()' is a pure virtual hook invoked by 'start()' itself (through a plain 'ServiceBase*'), so every mode specialization must keep it virtual too; see 'ServerBase.hpp'/'ClientBase.hpp' for why their other hooks use CRTP instead.

◆ taskEntry()

virtual void Lib::Canbus::ServiceBase::taskEntry ( )
protectedpure virtualnoexcept

Main task loop for the CAN service; runs in its own FreeRTOS task started by 'start()'.

'start()' invokes this hook through a plain 'ServiceBase*', so it must stay a genuine virtual override all the way down to the concrete service type — CRTP dispatch cannot reach across that call site. Must be implemented by every derived service.

Implemented in Lib::Canbus::Service< Mode::CLIENT, T_DERIVED >, and Lib::Canbus::Service< Mode::SERVER, T_DERIVED >.

Lib::BSP::DigitalPeripheral::Base< T_MODE, T_DERIVED > Class Template Reference

Description

template<UpdateMode T_MODE, typename T_DERIVED>
class Lib::BSP::DigitalPeripheral::Base< T_MODE, T_DERIVED >

CRTP base template class for digital peripheral management.

This template class provides a foundational abstraction for managing digital peripherals in the board support package. It supports two update modes: 'SEQUENTIAL' for step-by-step processing with delays, and 'PARALLEL' for concurrent input/output operations with timing measurements. The class integrates with FreeRTOS to run peripheral tasks in real-time, ensuring deterministic behavior under embedded constraints.

'T_DERIVED' must implement 'enableOutputs(bool)', 'preProcessingCallback()' and 'postProcessingCallback()'; it may optionally implement 'handleTickEvent()', which is called only if present. Dispatch to 'T_DERIVED' happens at compile time through CRTP, avoiding a vtable since no code in this project stores peripherals in a heterogeneous 'Base' pointer collection - the only polymorphic pointers involved are the injected 'PortBase' input/output ports, which remain virtual.

The template is header-only. The mode is selected at compile time through 'T_MODE' and the task is specialized per mode. Assertions report critical errors and are active only in builds where 'NDEBUG' is not defined.

Template Parameters
T_MODEThe update mode for the peripheral (SEQUENTIAL or PARALLEL).
T_DERIVEDThe concrete peripheral implementation providing the CRTP hook methods.

template<UpdateMode T_MODE, typename T_DERIVED>
bool Lib::BSP::DigitalPeripheral::Base< T_MODE, T_DERIVED >::init ( )
inlinenodiscardnoexcept

Initializes the digital peripheral and starts the FreeRTOS task.

This method performs initialization of input and output ports, then creates and starts a FreeRTOS task for handling peripheral updates according to the selected update mode. The task runs the template-specialized task() method in a loop, managing real-time peripheral operations.

The task is created with a stack depth of 128 words; adjust it when a derived class needs more.

Returns
'true' if initialization and task creation succeeded, 'false' otherwise.
Precondition
Constructor must have been called with valid port pointers.
Postcondition
FreeRTOS task is running; ports are initialized.

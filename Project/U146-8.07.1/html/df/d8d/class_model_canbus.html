CAN bus model. More...

Description

CAN bus model.

Caches the activity/inputs/outputs of every 'NUM_OF_CANBUS_CLIENT_NODES' CAN node and notifies a 'Listener' only for the fields that actually changed since the last 'handleTickEvent()' call.

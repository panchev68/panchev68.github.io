BSP::Inputs Class Reference

Controller for reading inputs from daisy-chained SPI input devices. More...

Description

Controller for reading inputs from daisy-chained SPI input devices.

Performs SPI reads of chained CD4021 input registers, converts the bytes into a 64-bit bitmap and updates Data::Peripheral only when the state changes.

Reads the chained input devices over SPI and publishes any detected change to the peripheral data store.

Bits above BSP::Inputs::NUM_OF_INPUTS are masked off, since the chain always returns whole bytes and the last chip may carry unused, floating stages.

Precondition
BSP::Inputs::setup() must have been called to open the SPI port.

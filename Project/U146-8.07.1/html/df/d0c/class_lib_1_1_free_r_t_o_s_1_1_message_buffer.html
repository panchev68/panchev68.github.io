Lib::FreeRTOS::MessageBuffer Class Reference

Description

C++ wrapper for a FreeRTOS 'MessageBufferHandle_t'.

Provides methods to create and delete the underlying buffer and to send/receive data from task and ISR contexts. Methods assert that the handle is valid when required.

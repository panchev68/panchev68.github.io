System::StartupSync Class Reference

Description

Singleton that manages a readiness event for system startup synchronization.

Wraps a 'FreeRTOS::EventGroup' to signal and wait for the 'SYSTEM_IS_READY' flag. It is non-copyable and non-movable; the event group is released before the singleton is destroyed.

bool System::StartupSync::waitForSystemReady ( uint32_t timeout)
nodiscardnoexcept

Wait for the system ready event.

Blocks until the 'SYSTEM_IS_READY' bit is set or the timeout elapses. The timeout is forwarded to 'FreeRTOS::EventGroup::wait()', so its units are those of that API.

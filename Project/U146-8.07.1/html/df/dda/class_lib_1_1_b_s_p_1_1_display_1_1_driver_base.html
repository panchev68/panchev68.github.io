Lib::BSP::Display::DriverBase Class Referenceabstract

Description

Abstract base class for display driver operations.

Defines the interface for initializing the display, transmitting blocks, handling transfer completion and managing transfer state. Concrete drivers ('ILI9341', 'ST7789') implement 'Lib::BSP::DeviceDriver' and bind into 'DeviceDriverManager' as a 'Device' handle. The virtual hooks serve only the controller specializations and the TouchGFX bridge below.

The static 'instance' pointer and the C-linkage 'DisplayDriver_TransferCompleteCallback()' bridge this polymorphic driver to the TouchGFX C HAL callbacks. Both are used directly by 'Project/TouchGFX/startTouchGFX.cpp' and must keep their exact names.

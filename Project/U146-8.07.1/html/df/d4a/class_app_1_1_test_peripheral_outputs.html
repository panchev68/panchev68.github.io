App::TestPeripheralOutputs Class Reference

Description

Singleton class that controls peripheral output test execution.

Provides lifecycle control (start/stop), index manipulation and timing configuration for the sequence that exercises peripheral outputs. Instances are not copyable or movable; use the single globally-accessible instance via instance().

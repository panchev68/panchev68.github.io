StaticBuffer< BUFFER_SIZE > Class Template Reference

Description

template<size_t BUFFER_SIZE>
class StaticBuffer< BUFFER_SIZE >

Fixed-size, stack-allocated buffer with no heap usage.

< Type alias for 'Lib::Helper::Buffer'.

Derives from 'Buffer' to reuse its interface while storing bytes in a compile-time-sized 'std::array', avoiding dynamic allocation entirely. The buffer is zero-initialized on construction and does not report itself as owning (the storage lifetime is tied to the object, not to 'holder').

Template Parameters
BUFFER_SIZESize of the static buffer, in bytes.

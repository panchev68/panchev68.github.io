Lib::BSP::DigitalPeripheral::PortBase Class Referenceabstract

Description

Abstract base class for digital peripheral ports.

PortBase defines the operations every digital peripheral port must support: initialization, pre-initialization, state update, and waiting for completion with a timeout. Derived classes must implement all pure virtual methods. The class is abstract and cannot be instantiated directly.

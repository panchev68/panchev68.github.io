HardwareProfiles::Manager Class Reference

Facade over 'HardwareProfileManager' that keeps the existing call sites working. More...

Description

Facade over 'HardwareProfileManager' that keeps the existing call sites working.

The class is non-instantiable and offers a static API. It is kept split from 'ProfilesData.hpp' on purpose: that file pulls in the CubeMX HAL headers ('spi.h', 'tim.h', 'stm32f407xx.h'), which must not leak into every consumer of this widely included header.

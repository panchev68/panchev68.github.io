Lib::USB::SerialPortRepeater Class Reference

Description

Bridges a USB CDC virtual COM port to a 'SerialPort'.

Registers itself with the USB CDC interface ('USBD_Interface_fops_FS') to receive host data and forward it to the serial port, and forwards serial port data back to the host. Plain (non-virtual): the project embeds exactly one instance behind a facade singleton (see 'USB::SerialPortRepeater'), not a heterogeneous collection.

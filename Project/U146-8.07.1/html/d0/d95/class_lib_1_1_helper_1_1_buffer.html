Lib::Helper::Buffer Class Reference

Description

Owning or non-owning byte buffer with copy/move semantics.

Manages either heap-allocated memory it owns, or a reference to external memory it does not own. Owned memory is zero-initialized on allocation and released automatically (RAII); external memory is left untouched by destruction.

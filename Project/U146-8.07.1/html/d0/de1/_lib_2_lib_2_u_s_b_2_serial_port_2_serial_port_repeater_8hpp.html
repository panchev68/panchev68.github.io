Description

USB CDC-to-serial repeater for STM32.

Bridges a USB CDC virtual COM port to a 'SerialPort', with USB detect/disable pin control and connection-state notification via 'onConnected'. Requires the project's USB CDC glue ('usbd_cdc_if.h') and 'MX_USB_DEVICE_Init()'.

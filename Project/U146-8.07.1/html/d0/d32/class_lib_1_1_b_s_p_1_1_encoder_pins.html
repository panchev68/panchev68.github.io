Lib::BSP::EncoderPins Class Reference

Description

Rotary encoder pin and button event handling.

Encapsulates channel pins for quadrature rotation detection and a button pin for press/release events. Rotation direction is decoded from interrupt-driven pin changes and buffered as 'EventState' values in a FreeRTOS queue, with configurable pulse division and direction reversal.

Encoder event states.

Type-safe representation of the events produced by the encoder, used for queue-based communication between the interrupt handler and application code.

Button press detected.

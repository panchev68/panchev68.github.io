Lib::HAL::GPIO::Pin< Type::INPUT > Class Reference

Description

GPIO input pin specialization.

Provides state reading and mode/pull/speed configuration for an STM32 GPIO input pin. Every consumer in this project holds a 'Pin' by value (never behind a common base pointer), so its operations are plain, non-virtual methods; 'Pin<Type::OUTPUT>' reuses them through ordinary (non-polymorphic) inheritance.

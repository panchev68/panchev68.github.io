U146 Firmware

U146 Firmware is the embedded application for the U146 controller, an STM32F407 board with a TouchGFX display, CAN bus, XBee and USB interfaces.

The application is written in C++20 and runs on FreeRTOS. 'startup.cpp' selects the hardware profile with HardwareProfiles, initializes the drivers in Board Supported Peripheral and Hardware Abstraction Layer, loads the persistent settings from System Layer and then starts the services for the configured mode, either the CAN bus server in Canbus, the radio client in Xbee or the serial port repeater in USB. The user interface is handed over to TouchGFX at the end of the start sequence, and the runtime data shared between the layers is kept in Data.

To start reading, open 'startup.cpp' and follow the initialization sequence into the namespaces above. Each namespace page lists its classes, and every class carries its own description.

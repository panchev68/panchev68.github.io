Lib::Helper::TimeZone Class Reference

Description

Represents a named time zone with a fixed UTC offset.

Holds a display name and a UTC offset in minutes, and converts a local calendar date/time to minutes since the Unix epoch in UTC using its own calendar arithmetic (no C library time zone database or 'mktime()' dependency).

This class does not model daylight saving time transitions; the offset is fixed.

Converts a local calendar date/time in this time zone to minutes since the Unix epoch (UTC).

Uses Howard Hinnant's days-from-civil calendar algorithm rather than 'mktime()', so the result depends only on this object's stored offset, never on the C library's configured local time zone.

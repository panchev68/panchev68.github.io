Lib::Helper::DateTime Class Reference

Description

Combines a calendar date and a time of day for embedded systems.

Wraps the nested 'Date' and 'Time' classes, adding comparison, binary packing/unpacking, and conversion to the standard 'tm' structure. All operations are exception-free.

constexpr uint32_t Lib::Helper::DateTime::pack ( const DateTime & dt)
inlinestaticnodiscardconstexprnoexcept

Packs a DateTime into a 32-bit integer for storage or transmission.

Only years 'Date::FIRST_YEAR' to 'Date::FIRST_YEAR' + 63 survive the round trip, because the year field is 6 bits wide. Asserts in debug builds when 'dt' exceeds that range.

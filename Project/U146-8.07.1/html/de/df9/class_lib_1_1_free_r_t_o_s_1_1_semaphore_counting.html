Lib::FreeRTOS::SemaphoreCounting Class Reference

Description

Counting semaphore wrapper.

Allows multiple resources to be managed via a FreeRTOS counting semaphore. Inherits from 'SemaphoreBase' to reuse common take/give functionality.

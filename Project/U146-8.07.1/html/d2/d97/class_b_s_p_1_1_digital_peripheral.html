BSP::DigitalPeripheral Class Reference

Manager that instantiates and runs the digital input/output devices. More...

Description

Manager that instantiates and runs the digital input/output devices.

The singleton configures the board SPI ports for the input and output chains, binds the output-command callback to Data::Peripheral and runs a polling task that calls BSP::Inputs::update() and BSP::Outputs::update() every 10 ms.

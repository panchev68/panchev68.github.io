Lib::FreeRTOS::TickCounter Class Reference

Description

Static utility class providing access to the FreeRTOS tick counter.

Offers methods for retrieving the current tick count from both task and ISR contexts. This is a static utility and cannot be instantiated.

Tick counts wrap around after reaching the maximum value; handle overflow appropriately.

BSP::Backlight Class Reference

Description

Singleton wrapper around the library backlight implementation.

Builds the library 'Lib::BSP::Backlight::Config' from the active hardware profile and inherits the full library interface, so the singleton binds into 'DeviceDriverManager' as a 'Device' handle.

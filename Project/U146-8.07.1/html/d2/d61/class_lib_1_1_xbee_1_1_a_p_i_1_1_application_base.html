Lib::Xbee::API::ApplicationBase< Derived > Class Template Reference

Description

template<typename Derived>
class Lib::Xbee::API::ApplicationBase< Derived >

Module, connection and service owner plus application task for an XBee client or server.

'Derived' must provide 'initialize()', 'update()' and 'handleTaskTickEvent()' (all 'void', no parameters); if they are private it must befriend 'ApplicationBase<Derived>'. The public API is 'Pausable'.

DerivedClass deriving (directly or through 'ClientBase' / 'ServerBase') from this base.

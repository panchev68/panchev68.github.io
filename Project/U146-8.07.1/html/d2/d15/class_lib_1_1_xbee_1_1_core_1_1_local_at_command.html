Description

◆ close()

void Lib::Xbee::Core::LocalAtCommand::close ( )
inline

Closes the local AT command interface: stops accepting responses and releases the response queue.

The handler stays bound (this object outlives the module); close() waits until a running handler has left, because the receiver task could be writing to the queue while another task deletes it.

◆ open()

bool Lib::Xbee::Core::LocalAtCommand::open ( )
inline

Opens the local AT command interface: sets up the response handler and the response queue.

The channel is shared by several services opened from different tasks; a busy channel is reported, not asserted.

Returns
'true' if this call opened the channel, 'false' if another owner has it open.

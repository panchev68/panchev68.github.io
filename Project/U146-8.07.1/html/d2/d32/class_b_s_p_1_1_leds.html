BSP::Leds Class Reference

Singleton driver for the ready and error status LEDs. More...

Description

Singleton driver for the ready and error status LEDs.

Drives each LED from its logical BSP::Leds::State. Blink timing is advanced by BSP::Leds::tick() in RTOS tick units. Satisfies Lib::BSP::DeviceDriver, so the singleton binds into Lib::BSP::DeviceDriverManager as a Lib::BSP::Device handle without a common base class.

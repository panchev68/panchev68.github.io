BSP::Leds Class Reference

Description

Driver providing control over board LEDs.

Drives the ready and error LEDs from their logical OFF/ON/BLINKING state. Blink timing is advanced by 'tick()' in RTOS tick units. Satisfies 'Lib::BSP::DeviceDriver', so the singleton binds into 'DeviceDriverManager' as a 'Device' handle without a common base class.

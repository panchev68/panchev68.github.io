Lib::Xbee::API::Connection::Quality Class Reference

Description

Computes link quality from the packet delivery ratio (PDR) and the RSSI link margin.

Every request/response cycle is recorded as one bit in a sliding window of the last WINDOW_SIZE cycles; the PDR over that window is the primary score. The filtered RSSI is mapped linearly from RSSI_STRONG (100 %) to RSSI_SENSITIVITY (0 %) and scales the PDR score down by up to RSSI_WEIGHT percent, so a weakening signal lowers the result before packets actually start getting lost, while lost packets alone can still drive it to 0. The qualitative state follows the percent with hysteresis (down immediately, up only after the better grade has held for STATE_UPGRADE_DELAY).

In scanner mode the statistics are reset on every mode request or clear(), the first SCANNER_SETTLE_TIME after the reset is ignored, and onUpdate is fired once, when the window is completely filled with fresh samples.

Thread safety: onExchange() and update() run in the application task; onRssi() is called from the receiver task; clear(), the mode setters and the getters may be called from any task (GUI, scanner, parameters). Cross-task data goes only through atomics and is applied inside update().

Lib::Helper::RingBuffer< T, SIZE > Class Template Reference

Description

template<typename T, size_t SIZE>
class Lib::Helper::RingBuffer< T, SIZE >

Fixed-capacity circular buffer supporting FIFO push/pop.

One slot is always kept empty to distinguish the full and empty states, so the usable capacity is 'SIZE' - 1 elements.

Template Parameters
TType of elements stored.
SIZEBuffer capacity; must be greater than 1.

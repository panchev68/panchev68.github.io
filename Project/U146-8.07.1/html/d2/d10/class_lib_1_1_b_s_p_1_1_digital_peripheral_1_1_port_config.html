Lib::BSP::DigitalPeripheral::PortConfig Class Reference

Description

Configuration of a digital peripheral port.

PortConfig gathers the SPI handle, NSS pin and mapping fields that a port implementation receives at initialization. All members are public for easy access and initialization. The class is used together with PortBase and its derived classes. Ensure that all pointers are initialized before use to avoid null pointer dereferences.

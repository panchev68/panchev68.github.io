Lib::Helper::DataHandle< T > Class Template Reference

Description

template<typename T = uint8_t *>
class Lib::Helper::DataHandle< T >

Non-owning handle for a pointer and its size.

Wraps a pointer/size pair, supporting explicit move transfer and clearing, without taking ownership or managing the pointee's lifetime.

Template Parameters
TPointer type managed by the handle.

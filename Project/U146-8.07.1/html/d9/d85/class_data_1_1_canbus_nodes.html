Description

Manages the collection of CAN-bus client nodes.

Singleton providing indexed access to the 'Node' entries, the collection size and the raw storage. The number of nodes is defined by 'NUM_OF_CANBUS_CLIENT_NODES'. No internal synchronization is provided; callers must ensure thread-safety when accessing from multiple threads.

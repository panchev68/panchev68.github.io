◆ trigger()

template<typename... T_ARGS>
template<typename... CallArgs>
void Lib::Helper::Event< T_ARGS >::trigger ( CallArgs &&... args) const
inline

Invokes every bound listener with the given arguments, in bind order.

Arguments are passed as lvalues to each listener, since a single call must broadcast to every listener — forwarding them as rvalues would let the first listener move from an argument that later listeners still need.

◆ unbind()

template<typename... T_ARGS>
void Lib::Helper::Event< T_ARGS >::unbind ( const ListenerType & listener)
inlinenoexcept

Unbinds every instance of a listener function previously bound with 'bind()'.

Matching relies on 'std::function::target()' and reliably identifies only listeners created from a plain function pointer; two separately-constructed capturing lambdas or 'std::bind' expressions never compare equal even when functionally identical, since each has its own unique closure type.

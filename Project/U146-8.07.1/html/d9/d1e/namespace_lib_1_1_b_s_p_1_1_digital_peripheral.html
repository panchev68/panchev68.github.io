Description

Digital peripheral components namespace.

This namespace includes classes and interfaces for managing digital peripherals, such as ports and digital I/O components, ensuring consistent and safe interaction with hardware. It defines abstract base classes and concrete implementations for digital peripheral operations.

enum class Lib::BSP::DigitalPeripheral::UpdateMode
strong

Update strategy of digital peripheral outputs.

Use 'SEQUENTIAL' for systems requiring strict timing control, 'PARALLEL' for bulk updates. Callers using the mode from several threads must ensure thread-safety. Changes to this enum may affect real-time performance, so test thoroughly.

Enumerator
SEQUENTIAL 

Outputs are updated one after another.

PARALLEL 

Outputs are updated simultaneously.

Lib::TouchGFX::MenuScroller Class Reference

Description

Slider-driven vertical menu scroller for a scrollable container of buttons.

The slider top (maximum value) shows the first button; moving it down scrolls towards the last one. The slider is hidden when all buttons fit in the container.

Description

Top-level XBee model.

Owns the ModelXbee::SignalStrength, ModelXbee::Connection, ModelXbee::TransmitTime, ModelXbee::Leds, ModelXbee::ModuleParameters and ModelXbee::SpectrumAnalyzer submodels and ticks each of them from ModelXbee::handleTickEvent().

ModelXbee Class Reference

Description

Top-level XBee model.

Owns the 'SignalStrength', 'Connection', 'TransmitTime', 'Leds', 'ModuleParameters' and 'SpectrumAnalyzer' submodels and forwards 'handleTickEvent()' to each of them.

Lib::Xbee::API::Service::Parameters Class Reference

Description

Manages the XBee device parameters with local and remote AT command operations.

Provides the automatic parameter acquisition, change tracking and synchronized updates of both the local and the remote device. A state machine coordinates the multi-step parameter changes.

◆ writeChanges()

void Lib::Xbee::API::Service::Parameters::writeChanges ( )
inline

Initiates the parameter write, local or remote as needed.

The state machine applies the pending parameter changes either remotely or locally, depending on the connection status. Callers run in other tasks; the write is started by process() in the application task, and a request made while a write is running is queued instead of asserting.

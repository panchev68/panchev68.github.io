Lib::Helper::Container< T > Class Template Reference

Description

template<typename T>
class Lib::Helper::Container< T >

Polymorphic collection of pointers to objects of type 'T'.

Provides efficient storage, duplicate/null-checked addition and removal, and batch processing, with 'add()'/'remove()' left virtual so a derived container can enforce additional invariants.

Template Parameters
TType of the objects pointed to by the container elements.

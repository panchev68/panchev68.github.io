Description

WCC issuer key policy for 'Lib::BSP::RFID::NTAG21x::CardRecord'.

Supplies only the per-product constants: the record magic 'WCC', and the key id and public key from IssuerPublicKey.hpp, generated by 'tools/card_tool.py keygen'. The verification itself (format, key id, ECDSA P-256 over SHA-256(header || UID)) is the library template.

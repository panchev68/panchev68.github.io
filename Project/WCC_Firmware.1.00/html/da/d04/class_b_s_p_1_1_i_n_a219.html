Description

Project-level facade exposing the two board INA219 monitors as singletons bound to I2C1.

The implementation lives in the shared library as Lib::BSP::INA219; this class only supplies the board wiring: both monitors share I2C1, carry a 20 mOhm shunt and use the calibrated current corrections below.

Description

Live distance readout singleton.

Measures the distance every 'PERIOD' in its own task, the same way APP::DistanceMeter does: 12 V booster, start-up wait, first reading discarded, UART and booster released. Nothing is asserted: move a hand or a target in front of the transducer and read the values with the IAR Live Watch or a debugger.

The values are the members of one global structure, 'APP::distanceLiveWatch' ('DistanceLiveTest.cpp'): add that one expression to the Live Watch and expand it; it fits on one screen. Less needed values (resets, memory, small counters, the register override slots) are in a second structure, 'APP::distanceLiveWatchMore'. Most of the switches default off and are meant to be flipped from the Live Watch, not in code; each field's own trailing comment in 'DistanceLiveTest.cpp' documents what it does. It also checks the transducer (frequency, decay period, echo dump) and tunes the PGA460 (burst pulse count, gain range, threshold map, register overrides) without a rebuild; needs 'ENABLE_DISTANCE_METER' off since both share the same UART.

Description

RTC synchronization from the modem.

The RTC (HAL::RTCPort) keeps UTC and runs through STOP1 and resets. syncFromModem() reads the modem clock, which follows the network time (NITZ), and writes it to the RTC. A time before MIN_VALID_UNIX_TIME is treated as "not synchronized": the modem keeps its own default until the network sends the time, and a fresh RTC starts at 2000-01-01.

Stateless: everything it needs is in the RTC.

Warning
syncFromModem() is task context only and must run in the task that owns the modem.

RiverSense firmware

Firmware of an autonomous river-level monitoring node on an STM32U575VGT6 (Cortex-M33, FreeRTOS).

The node measures the distance to the water surface with an A02YYUW ultrasonic sensor and the water temperature with a DS18B20, and reports to the cloud over HTTPS through an A7670E 4G modem. A solar panel with a charger and an accumulator power it. Every external device is powered only while it is used, and the processor sleeps in STOP1 between measurements. The measurement period shortens after a rapid level change and lengthens when the accumulator is low; the modem is powered off after each report.

The application is layered. APP holds the measurement cycle, the solar charger, the diagnostics, the clock, the site position, the cloud link and the cloud command interpreter. Board Supported Peripheral holds the supply switches and the drivers of the external devices. Hardware Abstraction Layer holds one port singleton per CubeMX peripheral handle. Below them lie the CubeMX-generated code, the FreeRTOS support and the shared library in 'X:/Lib/IAR/inc/Lib'.

Start with APP::Monitor, the measurement cycle, and APP::PowerSupply, the solar charger. The entry point is 'startup()' in 'startup.cpp', run from the default FreeRTOS task after the scheduler starts.

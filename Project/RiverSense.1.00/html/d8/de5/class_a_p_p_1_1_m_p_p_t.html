Description

Cascaded MPPT controller of the solar accumulator charger, driving the LMR14030 buck charger.

The outer loop (library MPPT, every OUTER_LOOP_DIVIDER steps) computes the panel voltage setpoint; the inner loop (every step() call) moves the DAC_OUT voltage injected into the buck feedback node until the measured panel voltage reaches that setpoint.

The DAC current is summed into the FB node through R13 + R14, so a higher DAC voltage lowers the buck output voltage, unloads the panel and lets its voltage rise. Panel irradiance is not measured; it is estimated from the panel current relative to the MPP reference current. Divider of the WCC board hw2.00 (R15 from the output after the R9 shunt, R11 + R12 to GND through Q4, R13 + R14 from DAC_OUT):

Vout = Vfb * (1 + R15 / (R11 + R12) + R15 / (R13 + R14)) - Vdac * R15 / (R13 + R14) ~ 7.82 V - 1.32 * Vdac

Singleton: the charger has one buck, one DAC and one enable pin. The state, the hardware constants and the private helpers live in an Impl defined in the '.cpp', reached through impl() (function-local static, no heap).

Warning
Not thread-safe: init(), step() and disable() must all run in the power supply task.

◆ getChargerCurrent()

float APP::MPPT::getChargerCurrent ( ) const
nodiscardnoexcept

Returns the charger output current measured by the last step() call.

The 0x41 monitor's shunt R9 sits between the charger diode D2 and the 6 V rail, so this is the current the charger feeds into the loads plus the accumulator; the accumulator's own discharge does not pass it.

Returns
Charger output current, in amperes; never positive (calibration sign), 0 until the first update.

◆ step()

bool APP::MPPT::step ( )
nodiscardnoexcept

Runs one inner-loop iteration and, every OUTER_LOOP_DIVIDER calls, one MPPT update.

Call every STEP_PERIOD_MS milliseconds. The accumulator charge voltage and charge current limits override the MPPT setpoint.

Returns
false if a sensor read or the DAC write failed; the charger then keeps its last DAC value.

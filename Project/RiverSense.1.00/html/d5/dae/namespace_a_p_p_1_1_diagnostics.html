APP::Diagnostics Namespace Reference

Description

Hardware diagnostics, split into the boot check and the runtime fault mask.

APP::Diagnostics::Boot checks every device once before the other modules start and shows the result on the LEDs; APP::Diagnostics::Runtime keeps the fault mask that the modules update and APP::Monitor sends to the cloud. The shared APP::Diagnostics::Device bits and 'applyResult()' sit in the namespace itself.

Description

Singleton driver of the A02YYUW ultrasonic distance sensor on USART1.

With its RX line idle high (the USART1 TX line) the sensor sends a processed reading on its own about every 100 ms as a four-byte frame: '0xFF', distance high byte, distance low byte, checksum = low byte of the sum of the first three. The distance is in millimetres. The driver resynchronizes on '0xFF' and drops frames with a bad checksum or a distance outside the sensor range.

The sensor is powered from BSP::PowerSwitches channel BSP::PowerSwitches::Channel::SENSORS; the caller powers it, then calls open(), and calls close() before cutting the rail so USART1 does not back-feed it.

Holds no state between calls, so no Pimpl.

Warning
Task context only, one task at a time: it reads the single-reader stream of HAL::Usart1Port.

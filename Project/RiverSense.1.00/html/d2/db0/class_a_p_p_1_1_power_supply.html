APP::PowerSupply Class Referencefinal

Solar MPPT charger of the OT12-GEL accumulator. More...

Description

Solar MPPT charger of the OT12-GEL accumulator.

Owns the charger task: it brings up both INA219 monitors, the TMP102 and the MPPT controller, then steps the MPPT loop every MPPT::STEP_PERIOD_MS. A failed bring-up is retried; repeated step failures restart it.

Night and dark: with a synced RTC, before sunrise or after sunset at the APP::Site position, or while the panel voltage is below BSP::SolarPanel::MIN_CHARGING_VOLTAGE, the charger is disabled and both INA219 are put into power-down. The task then polls (every minute at night, every 5 min in the dark) until charging is possible again, measuring the accumulator at every poll so BSP::Accumulator::getVoltage() stays current. An unsynced clock never counts as night.

The state, the task and the private helpers live in an Impl in 'PowerSupply.cpp'; each getter's own comment documents what it publishes.

bool APP::PowerSupply::getIsSensorsOk ( ) const
nodiscardnoexcept

Reports whether both INA219 monitors and the TMP102 are considered healthy.

Does not touch I2C1: the MPPT loop already uses the bus, so a diagnostic in another task reads this instead of starting a second, racing transaction.

Returns
true while the charger steps or idles for the night or the dark; false only while it retries a failed bring-up.

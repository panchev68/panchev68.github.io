Description

Dispatches a command text to the handler registered for its name.

The commands are not defined yet, so the interpreter knows none itself: each module registers its own commands with registerCommand() at start-up, and execute() splits the text and calls the matching handler.

Format: 'name' or 'name<separator>arguments', the separator being the first space, ':' or '=' ("name = value" works too). Leading and trailing spaces are ignored and names are case-sensitive: "reboot", "interval:15", "site 42.87,25.31". The arguments reach the handler as raw text; parsing them is the handler's job.

Threads: register every command before the task that receives the cloud answers calls execute(); the table is not guarded, so registration after that point is not allowed.

Description

Published flag telling whether the accumulator is currently not being charged.

Set while the charger idles for the night or for insufficient panel light, so other modules (e.g. the measurement cycle) can scale back their activity. Only APP::PowerSupply writes it.

The flag lives in an Impl in "PowerSupply.cpp".

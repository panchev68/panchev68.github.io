Description

Sends JSON to the cloud with an HTTPS POST and returns its answer.

TLS runs in the modem against the server certificate (APP::CloudCertificate::PEM), which is uploaded once to the modem file system. The request is 'POST /insertData/' with 'Content-Type: application/json'; the server answers '{"message":"...","command":"..."}'.

TLS is the only encryption: the JSON itself is sent in plain text inside the TLS session. The payload format is not defined yet: an empty object '{}' is a valid request and the server answers that the device is not registered.

The modem has to be powered, awake and registered (Lib::BSP::GSM::A7670E). Stateless except for remembering that the certificate is in the modem.

Warning
Task context only, in the task that owns the modem.

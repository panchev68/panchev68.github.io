Description

Singleton holding the two fault masks that go to the cloud with every report: the current one and the latched one.

Unlike WCC there is no diagnostic task: the node sleeps between measurements, and the sensor rail, the modem and the single-reader UART streams belong to APP::Monitor, so a second task probing them would collide with it. The runtime pass is the measurement cycle itself. The modules that own the devices report every result they get with update(): Boot once at start-up, APP::Monitor after each measurement (both sensors, plus the I2C mirror, once per measurement period) and each modem session. The I2C sensors are mirrored from APP::PowerSupply::getIsSensorsOk() by refreshPowerSensors().

Thread-safe: both masks are atomic bytes in an Impl in the '.cpp'.

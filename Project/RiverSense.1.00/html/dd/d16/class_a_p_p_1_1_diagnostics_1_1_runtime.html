Description

Singleton holding the fault mask that goes to the cloud with every report.

Unlike WCC there is no diagnostic task: the node sleeps between measurements, and the sensor rail, the modem and the single-reader UART streams belong to APP::Monitor, so a second task probing them would collide with it. The runtime pass is the measurement cycle itself. The modules that own the devices report every result they get with update(): Boot once at start-up, APP::Monitor after each measurement (both sensors, plus the I2C mirror, once per measurement period) and each modem session. The I2C sensors are mirrored from 'PowerSupply::getIsSensorsOk()' by refreshPowerSensors(), which does not touch the bus the MPPT loop uses.

Thread-safe: the mask is a single atomic word in an 'Impl' in the '.cpp'.

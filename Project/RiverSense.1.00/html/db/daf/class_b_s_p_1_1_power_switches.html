BSP::PowerSwitches Class Referencefinal

Description

Singleton mapping each switched supply rail to its enable pin.

Every external consumer is powered only while it is used, to save the battery. The order of powering a device and opening its port stays with the device driver. Every switch is active-high and off after reset (the pins are initialized low by CubeMX).

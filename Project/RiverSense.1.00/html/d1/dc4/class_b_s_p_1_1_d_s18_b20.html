Description

Singleton facade binding the shared DS18B20 driver to the 'DS18B20_DATA' pin.

The driver is Lib::BSP::Thermometer::OneWire::DS18B20 in the shared library; this class only binds it to the board's DQ pin 'DS18B20_DATA' (PB5).

Important
The sensor is powered through BSP::PowerSwitches::Channel::SENSORS; it answers only while that channel is on.

APP Namespace Reference

Description

Application layer, one singleton module per functional area.

APP::LowPower enables tickless idle with STOP1 and is started first. APP::Diagnostics::Boot checks the hardware at start-up and shows the result on the LEDs. APP::PowerSupply runs the solar charger (APP::MPPT over INA219/TMP102 and DAC1), taken over from the WCC project.

APP::Monitor is the measurement cycle: it measures level and temperature, reports through APP::Cloud (JSON over HTTPS through the modem) and runs the returned command with APP::CommandInterpreter. After the modem registers, APP::Clock synchronizes the RTC from the network time and APP::Site fetches the installation position for the night window.

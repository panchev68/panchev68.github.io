Description

Solar panel singleton: the INA219 at 0x40 on the panel input and what the charger asks about the panel.

The monitor is driven by the task of APP::PowerSupply only; I2C1 is shared, so no other task reads it. The MPPT controller takes the monitor itself through monitor().

◆ isLightSufficient()

bool BSP::SolarPanel::isLightSufficient ( )
nodiscardnoexcept

Tells whether the panel gives enough voltage to charge, waking the sleeping monitor for one reading.

Wakes the monitor, waits WAKE_CONVERSION_TIME (a reading right after waking returns the stale value from before the sleep), reads the voltage and puts the monitor back to sleep. A failed wake or read counts as sufficient, so a real sensor fault falls through to the bring-up retry of the charger instead of idling.

Returns
false only if the panel voltage was read below MIN_CHARGING_VOLTAGE.

float BSP::SolarPanel::MIN_CHARGING_VOLTAGE = 9.0F
staticconstexpr

Panel voltage below which the LMR14030 buck cannot regulate down to the accumulator charge limit.

Charge limit (6.9..7.5 V, BSP::Accumulator) plus an assumed ~1.5 V of buck headroom; pending confirmation against the LMR14030 dropout and the actual open-circuit voltage of the panel.

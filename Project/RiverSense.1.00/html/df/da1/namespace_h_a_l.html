HAL Namespace Reference

Description

Concrete peripheral port instances, one function-local-static singleton per CubeMX handle.

HAL::I2CPort1, HAL::DAC1Port and HAL::RTCPort wrap the matching 'Lib::HAL' classes. USART1 and USART3 (HAL::Usart1Port, HAL::Usart3Port) use the shared Lib::HAL::StreamSerialPort instead, which receives continuously into a stream buffer for devices that send without being asked.

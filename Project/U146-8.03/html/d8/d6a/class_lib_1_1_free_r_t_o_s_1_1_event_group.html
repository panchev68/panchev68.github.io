Lib::FreeRTOS::EventGroup Class Reference

Description

EventGroup class for managing FreeRTOS event groups.

This class provides a C++ wrapper around FreeRTOS event groups, offering safe and convenient methods for creating, managing, and interacting with event groups in a real-time operating system environment. It encapsulates the EventGroupHandle_t and provides RAII-compliant resource management.

Role of the type within the module or system: Serves as the primary interface for event group operations in the FreeRTOS namespace, ensuring type safety and ease of use.

Important design decisions: Uses RAII for handle management, asserts for precondition checks, and provides both blocking and ISR-safe methods.

Note
The class is not copyable or movable to prevent handle duplication.

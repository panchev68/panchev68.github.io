Description

Base driver class for SPI flash memory devices.

This file defines the base class and supporting structures for SPI flash memory drivers. It provides a common interface for reading, writing, and erasing SPI flash memory devices, along with configuration and status management.

Important dependencies: HAL/SPI for SPI communication, HAL/GPIO for chip select pin control.

Note
This is an abstract base class; concrete implementations must override pure virtual methods.

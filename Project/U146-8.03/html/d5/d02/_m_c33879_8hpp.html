MC33879 Motor Driver Component Header.

This header file defines the MC33879 class, which provides an interface for controlling the MC33879 configurable octal serial switch with open load detect. It includes port configurations for receive and transmit operations, along with basic initialization.

Important dependencies or interactions with other modules: Relies on standard integer types from <cstdint> for type safety and portability.

Any special instructions or notes for users of the file: Ensure proper hardware initialization and SPI communication setup before instantiating the class.

Note
This is a header-only implementation for simplicity and performance in embedded systems.
Attention
Verify hardware connections and power supply before using this component to avoid damage to the MC33879 IC or connected motors.

Canbus Nodes Data Management Header.

This header file defines the CanbusNodes class within the Data namespace, providing a singleton interface for managing the state of CAN bus nodes in the U146 firmware project. It includes access operators and size information for the collection of nodes.

Important dependencies or interactions with other modules: Depends on standard library array for node storage.

Note
This class uses the singleton pattern to ensure a single instance for CAN bus nodes management.
Attention
Ensure thread-safety when accessing the singleton instance from multiple contexts.

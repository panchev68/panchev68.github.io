Lib::Canbus::ServiceBase Class Referenceabstract

Description

Base class for CAN bus service abstraction.

Core functionality for CAN message transmission, reception, diagnostics, and task management. The ServiceBase class provides a standardized interface for CAN bus communication in embedded systems, handling message queuing, error diagnostics, and integration with FreeRTOS tasks.

Role of the type within the module or system: Acts as the base for all CAN services in the Lib::Canbus namespace, ensuring consistent behavior and resource management across different CAN implementations.

Important design decisions: Uses composition with HAL::CAN::Port, employs FreeRTOS queues for thread-safe message handling, and provides virtual callbacks for extensibility.

Note
Derived classes must implement the pure virtual taskFn method to define service-specific behavior.

virtual void Lib::Canbus::ServiceBase::taskFn ( )
protectedpure virtual

CAN service task function.

Pure virtual method that defines the main task loop for the CAN service. Derived classes must implement this method to provide service-specific functionality, such as periodic message sending, response handling, or state management.

This method runs in its own FreeRTOS task and should contain the main service logic.

Note
This method is called in a separate task context and should handle blocking operations appropriately.

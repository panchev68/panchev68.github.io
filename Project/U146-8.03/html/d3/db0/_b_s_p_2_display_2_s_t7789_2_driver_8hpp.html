Description

ST7789 Display Driver Header File.

This header file defines the ST7789 display driver class, which provides an interface for initializing and controlling ST7789-based LCD displays. It includes configuration structures, initialization sequences, and methods for transmitting pixel data to the display.

The driver inherits from DriverBase and implements display-specific functionality using SPI communication, GPIO pins for control signals, and DMA for efficient data transfer.

Note
This driver is designed for embedded systems using FreeRTOS and HAL libraries.
Attention
Ensure proper SPI and GPIO configurations before using this driver.

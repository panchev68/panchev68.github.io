Description

EncoderTimer header file for timer-based encoder management.

This file defines the EncoderTimer class which provides an interface for handling rotary encoder inputs using hardware timers and interrupt-driven button detection in the Board Support Package (BSP). It includes configuration structures, event codes, and methods for initialization and event reading.

The EncoderTimer class utilizes STM32 timer peripherals in encoder mode for precise position tracking and external interrupts for button events. It uses FreeRTOS queues for thread-safe event communication.

Important dependencies include FreeRTOS for synchronization, HAL/GPIO for interrupts, HAL/TIM for timer operations, and standard library components.

Ensure proper timer and interrupt configuration before instantiating EncoderTimer objects. The class supports configurable button hold times and provides virtual methods for extensibility.

This header file contains the complete implementation.

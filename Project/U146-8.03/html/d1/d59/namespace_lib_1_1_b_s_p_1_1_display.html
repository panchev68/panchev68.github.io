using Lib::BSP::Display::ILI9341 = Driver<Controller::ILI9341>

Defines a type alias for the ILI9341 display driver using the generic Driver template.

This alias provides a concise type name for the ILI9341 driver throughout the codebase.

Note
The implementation uses Driver<Controller::ILI9341>, which encapsulates hardware-specific functionality for the ILI9341 display controller.

◆ Registers

enum Lib::BSP::Display::Registers : uint8_t

ST7789 register addresses.

Provides register address constants for the ST7789 display controller. Use these constants to send commands and read status or data from the controller for initialization, power management, display modes, and diagnostics.

Note
Communicate with the ST7789 controller via SPI or parallel interface using these constants.

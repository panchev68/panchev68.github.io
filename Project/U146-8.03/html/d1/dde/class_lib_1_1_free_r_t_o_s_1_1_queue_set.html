Lib::FreeRTOS::QueueSet Class Reference

Description

QueueSet class for managing FreeRTOS queue sets.

This class provides a C++ wrapper around FreeRTOS queue set functionality, allowing multiple queues and semaphores to be grouped together for efficient selection operations. It ensures RAII for resource management and provides type-safe interfaces for embedded systems.

The class supports adding multiple queue set members and selecting from them with timeout support.

Note
All methods assume the queue set is properly created before use.
Attention
Queue sets must be enabled in FreeRTOS configuration.

Lib::BSP::EncoderPins Class Reference

Description

EncoderPins class for managing rotary encoder pins and events.

The EncoderPins class encapsulates the functionality for handling rotary encoder inputs, including channel pins for rotation detection and a button pin for press events. It provides methods for initialization, event reading, and state management, utilizing FreeRTOS queues for event buffering and interrupt-driven callbacks for efficient operation.

This class serves as the primary interface for encoder hardware in the BSP module, enabling reliable detection of clockwise/counterclockwise rotations and button presses with configurable sensitivity and direction mapping.

Important design decisions include interrupt-based pin change detection for low-latency response, pulse division for adjustable sensitivity, and support for reverse direction interpretation. The class ensures thread-safe operation through FreeRTOS queue mechanisms.

Note
Requires proper FreeRTOS task context for queue operations and interrupt service routines.

The EventState enum defines the possible events that can be detected by the encoder, including rotation directions and button press/release states.

This enumeration provides a type-safe way to represent encoder events and is used for queue-based communication between interrupt handlers and application code.

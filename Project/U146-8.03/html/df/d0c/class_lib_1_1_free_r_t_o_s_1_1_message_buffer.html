Lib::FreeRTOS::MessageBuffer Class Reference

Description

Message Buffer class for FreeRTOS.

Provides a C++ wrapper around FreeRTOS message buffers for safe message passing. Handles creation, destruction, and operations like send, receive, with both blocking and ISR-safe variants. Ensures proper resource management and diagnostic assertions.

Note
Destructor asserts that the buffer is released to prevent resource leaks.

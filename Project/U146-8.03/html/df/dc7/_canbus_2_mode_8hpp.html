Mode header file for CAN bus operation modes.

This file defines the Mode enum class, which specifies the operation modes for CAN bus communication, including client and server roles. It provides a type-safe way to represent and handle different CAN bus service modes within the Lib::Canbus namespace.

Important dependencies include the standard library <cstdint> for the underlying type of the enum.

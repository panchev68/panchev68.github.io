Description

Display Driver Template Header.

This header file defines template structures and enumerations for display drivers in the BSP module. It provides a common interface for different display controllers such as ILI9341 and ST7789. The templates allow for compile-time selection of the appropriate driver implementation.

Note
This file is part of the BSP (Board Support Package) for display peripherals.
Attention
Ensure that the template parameter matches the actual hardware controller.

Lib::Canbus::Service< Mode::CLIENT > Class Referenceabstract

Description

Service template specialization for client mode.

This class provides the base implementation for CAN bus client services, inheriting from ServiceBase and adding client-specific functionality such as starting with an ID, sending messages, and handling received messages.

Template Parameters
ModeTemplate parameter specifying the service mode, set to Mode::CLIENT.

Lib::Canbus::Service< Mode::SERVER > Class Referenceabstract

Description

Server-side CAN bus service implementation.

This class provides the server mode specialization of the CAN bus service, inheriting from ServiceBase. It handles server-specific operations such as scanning for client nodes, sending messages, and managing diagnostics.

Template Parameters
Mode::SERVERThe mode template parameter set to SERVER.

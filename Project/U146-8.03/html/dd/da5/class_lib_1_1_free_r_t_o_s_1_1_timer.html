Lib::FreeRTOS::Timer Class Reference

Description

Timer Class.

This class wraps FreeRTOS software timers, providing a C++ interface for timer creation, management, and control. It supports periodic and one-shot timers with callback functions, and includes methods for starting, stopping, and modifying timer parameters. The class uses RAII principles for automatic resource cleanup.

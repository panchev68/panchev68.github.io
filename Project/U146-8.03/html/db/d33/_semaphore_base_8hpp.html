Description

Base class for FreeRTOS semaphore wrappers.

This file defines the SemaphoreBase class, which provides a common base for various FreeRTOS semaphore types, offering virtual methods for creation, taking, giving, and management of semaphores in a C++ context.

Depends on FreeRTOS semaphore API (semphr.h) and standard C++ libraries for assertions and types.

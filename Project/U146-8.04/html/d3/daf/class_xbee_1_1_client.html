Xbee::Client Class Reference

Description

Xbee::Client class for XBee wireless communication client.

Inherits from ClientBase and UserProtocol to provide message handling, output updates, and state management. Integrates with Data for peripheral control and supports FreeRTOS task events. All methods are implemented inline for embedded performance. Implements Singleton pattern for global access.

Serves as the main interface for XBee communication in the system.

Uses inline implementations to avoid function call overhead in real-time contexts.

Role of the type within the module or system: Manages XBee wireless communication and data exchange with peripherals and CAN bus nodes.

Important design decisions or considerations: Singleton ensures single XBee client instance; inline methods for performance; integrates with BSP LEDs for status indication.

Note
State management includes LED control based on client state.

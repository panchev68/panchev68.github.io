Data::Peripheral Class Reference

Description

Peripheral Data Manager Class.

The Peripheral class provides a singleton interface for managing peripheral input and output data. It supports event-driven notifications when data changes, enabling reactive programming patterns throughout the application.

Key features:

  • Singleton access pattern for centralized data management
  • Event notifications for input and output changes
  • Thread-safe data access in embedded environments
Note
This class uses events for change notifications and follows the singleton pattern.
  • Events are triggered only when data actually changes.
  • Data is stored as 64-bit integers for efficient peripheral representation.

Description

UART Port HAL Wrapper Header.

This header file defines the UartPort class, which provides a comprehensive HAL-specific wrapper for UART (Universal Asynchronous Receiver-Transmitter) port management on STM32 devices. The class encapsulates initialization, configuration, asynchronous send/receive operations, error handling, and event-driven communication using the STM32 HAL and FreeRTOS.

Key functionalities include:

  • Singleton-like instance tracking for callback routing.
  • Asynchronous data transmission and reception with timeout support.
  • Event group-based signaling for operation completion and errors.
  • Baudrate configuration and port state management.
  • Integration with HAL callbacks for interrupt-driven operations.

The UartPort class ensures thread-safe and efficient UART communication, suitable for embedded systems requiring reliable serial data exchange. It manages resource allocation, prevents copying and moving to maintain integrity, and provides a high-level interface for UART peripherals.

Dependencies include STM32 HAL UART driver, FreeRTOS for event groups and timeouts, and standard C++ libraries for containers and assertions.

Note
This class is designed for use in real-time embedded applications and assumes proper configuration of UART peripherals in the STM32CubeMX project.
Attention
Ensure that UART interrupts are enabled and HAL UART is initialized before using instances of this class. Improper use may lead to undefined behavior or resource leaks.

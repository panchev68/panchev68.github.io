BSP::DigitalPeripheral Class Reference

Description

DigitalPeripheral class for managing digital inputs and outputs.

This class provides a unified interface for digital peripheral management, including initialization based on hardware version, error state tracking, and coordination between input and output subsystems. It dynamically instantiates appropriate output versions and manages their lifecycles. Implements Singleton pattern for global access.

Role within the module: Central controller for digital I/O operations, abstracting hardware version differences and providing error handling.

Important design decisions or considerations: Singleton ensures single instance for consistent peripheral management; uses dynamic allocation based on hardware version.

Note
Call init() after obtaining instance to initialize peripherals.

Initializes the digital peripheral based on hardware version.

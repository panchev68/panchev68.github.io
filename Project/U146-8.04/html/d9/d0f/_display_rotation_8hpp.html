Description

Display Rotation Management Header.

This header file defines the DisplayRotation class, which manages the display orientation state for the system. It provides a singleton interface for getting, setting, and resetting the display rotation, ensuring consistent orientation handling across user interface components and rendering modules. The class integrates with TouchGFX for display rendering and supports thread-safe access to the global rotation state.

Key functionalities include:

  • Singleton pattern for global, thread-safe access to rotation state.
  • Methods to query, update, and reset the rotation flag.
  • Prevention of copying and moving to maintain singleton integrity.
  • Default initialization to non-rotated state.

The DisplayRotation class is crucial for applications requiring dynamic display orientation, such as touch-based interfaces where rotation affects touch coordinate mapping and UI layout. It ensures that all system components reference the same rotation state, preventing inconsistencies.

Dependencies include TouchGFX for display rendering integration and potential interactions with touch input processing modules.

Note
Access the rotation state via DisplayRotation::instance().get() or set() methods. The state persists until explicitly changed or reset.
Attention
Ensure thread-safety when accessing from multiple contexts, as the singleton instance is shared globally. Use appropriate synchronization if modifications occur concurrently.

Data::CanbusNodes Class Reference

Description

Singleton class for managing CAN bus nodes data.

This class provides a centralized way to access and modify the state of CAN bus nodes, using a singleton pattern to ensure only one instance exists. It manages an array of Node objects, allowing indexed access and providing methods for data manipulation. The singleton ensures thread-safe access in multi-threaded embedded environments, preventing race conditions.

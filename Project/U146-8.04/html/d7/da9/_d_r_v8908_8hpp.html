Description

DRV8908 motor driver header file.

Provides abstraction and interface for controlling DRV8908 motor driver chips in embedded systems. Includes register definitions, output control methods, error handling, and status monitoring for robust motor control applications. Designed for use with SPI communication and FreeRTOS for real-time operation.

Depends on OutputsListener for SPI messaging, OutputsPrecodeItem for data mapping, and FreeRTOS for timing. Integrates with BSP namespace for hardware abstraction layer.

Note
Ensure SPI bus is properly initialized before using this class.

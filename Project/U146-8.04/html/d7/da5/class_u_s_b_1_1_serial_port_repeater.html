USB::SerialPortRepeater Class Reference

Description

SerialPortRepeater class for USB serial port repeating in embedded systems.

Extends SerialPortRepeaterBase for port open/close, USB power detection, USB port enable/disable, and module reset pin. Implements Singleton pattern for global access to USB serial functionality.

Role of the type within the module or system: Manages USB serial communication and peripheral control in embedded systems.

Important design decisions or considerations: Singleton prevents multiple instances, ensuring consistent USB serial state management.

Note
Uses UART3 and UART2 for communication, with GPIO pins for control signals.

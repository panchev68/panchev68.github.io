System::HardwareVersion Class Reference

Description

Hardware Version Detector Class.

This class encapsulates hardware version detection logic for STM32 systems. It reads dedicated GPIO pins to determine the hardware revision and provides methods to retrieve the version as an ID or string. The class uses the singleton pattern to provide global access to version information, ensuring consistency across the application.

The hardware version is determined by reading four revision pins (HW_REV0 to HW_REV3), which are active-low and combined into a version ID. Known versions include 4.03, 4.04, and 4.05, with fallback to "UNKNOWN" for unrecognized combinations.

Role within the system: Provides authoritative hardware version information for feature enablement, diagnostics, and compatibility checks.

Design considerations: Singleton prevents multiple detections; GPIO reading is const to ensure no side effects; version mapping is hardcoded for reliability.

Note
Version detection occurs on-demand; cache results if called frequently.
See also
Lib/HAL/GPIO for pin reading details.

◆ readVersionId()

uint8_t System::HardwareVersion::readVersionId ( ) const
inline

Read the hardware version ID from GPIO pins.

Reads the four hardware revision pins (HW_REV0 to HW_REV3), inverts their logic (active-low), and combines them into a single version ID byte. This ID is used for version identification and mapping. The result is cached after first read to avoid repeated GPIO operations.

Returns
The hardware version ID as an unsigned 8-bit integer.
Precondition
GPIO pins HW_REV0-3 must be properly configured and accessible.
Postcondition
Returns a value between 0 and 15 based on pin states.
Note
Active-low pins: true pin state becomes false in version ID.

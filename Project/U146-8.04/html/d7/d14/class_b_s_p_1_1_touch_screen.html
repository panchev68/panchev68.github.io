BSP::TouchScreen Class Referencefinal

Description

TouchScreen class for touchscreen management.

Provides an interface for touchscreen functionality, extending TouchController and utilizing the XPT2046 driver. This class handles touch sampling, initialization, and rotation settings for resistive touchscreens. It implements the Singleton pattern to ensure a single instance manages touchscreen operations across the system.

Role of the type within the module or system: Acts as the abstraction layer for touchscreen hardware in the BSP, enabling TouchGFX integration and user interaction handling.

Important design decisions or considerations: Uses private inheritance from Driver to hide implementation details, employs deleted copy/move operations for Singleton enforcement, and provides override methods for TouchController interface compliance.

Note
Calibration values are hardcoded for specific hardware; adjust if necessary.
See also
Lib::BSP::XPT2046::Driver, touchgfx::TouchController

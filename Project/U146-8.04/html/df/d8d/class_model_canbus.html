ModelCanbus Class Reference

Description

ModelCanbus class for CAN bus node management.

Manages CAN bus client nodes with activity tracking, input/output state monitoring, and listener notifications for TouchGFX UI integration. This class acts as the model component in the MVP pattern, providing data and state management for CAN bus operations while enabling real-time UI updates through event-driven callbacks.

Key features include node state synchronization with the Data layer, change detection for activity/inputs/outputs, and extensible listener interface for UI components. The class maintains an array of Node structures representing the current state of each CAN bus client node.

Note
Designed for embedded systems with real-time constraints, using efficient state change detection to minimize processing overhead.

void ModelCanbus::handleTickEvent ( Listener * listener)

Handles periodic tick event for node state updates.

This method synchronizes the internal node states with the Data CAN bus nodes, checking for changes in activity, inputs, and outputs. If changes are detected, it notifies the provided listener through appropriate callbacks, enabling real-time UI updates and event-driven responses.

Parameters

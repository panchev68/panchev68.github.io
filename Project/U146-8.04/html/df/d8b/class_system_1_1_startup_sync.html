System::StartupSync Class Reference

Description

StartupSync class for system startup synchronization.

The StartupSync class provides a singleton-based synchronization mechanism for coordinating system startup processes. It inherits from FreeRTOS EventGroup to manage event bits that signal when various system components are ready, ensuring proper initialization order.

Role of the type within the module or system: Acts as a central synchronization point in the System namespace for managing startup sequences and ensuring all components are initialized before proceeding.

void System::StartupSync::signalSystemReady ( )
inline

System ready signaling method for StartupSync.

Sets the SYSTEM_IS_READY event bit to indicate that the system initialization is complete and all critical components are operational. This allows waiting tasks to proceed.

Note
This method should be called once all system components are initialized.

bool System::StartupSync::waitForSystemReady ( uint32_t timeout)
inline

System ready waiting method for StartupSync.

Blocks the calling task until the SYSTEM_IS_READY event bit is set, indicating that system initialization is complete, or until the specified timeout expires. This ensures that dependent tasks wait for full system readiness.

Parameters
timeoutMaximum time to wait in FreeRTOS ticks.
Returns
true if the system is ready within the timeout, false if timeout occurred.
Note
Use appropriate timeout values to prevent indefinite blocking.

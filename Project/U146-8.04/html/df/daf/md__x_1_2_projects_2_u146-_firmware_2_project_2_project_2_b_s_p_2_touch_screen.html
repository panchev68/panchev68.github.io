TouchScreen Class Documentation

Overview

The BSP::TouchScreen class provides a concrete implementation of the touchgfx::TouchController interface for STM32 embedded systems. It integrates the XPT2046 touch controller via the Lib::BSP::XPT2046::Driver to enable touch input for graphical user interfaces (GUIs) built with TouchGFX.

This class is responsible for:

  • Initializing the XPT2046 hardware driver
  • Sampling touch coordinates
  • Handling screen rotation for touch input

Architecture

The TouchScreen class inherits publicly from touchgfx::TouchController and privately from Lib::BSP::XPT2046::Driver. This design allows it to expose the required TouchGFX interface while encapsulating the low-level driver details.

Class Responsibilities

Public Interface

  • TouchScreen()
    Constructs the controller, initializing the XPT2046 driver with the required pin configuration and calibration parameters.
  • void init() override
    Initializes the touch controller hardware.
  • bool sampleTouch(int32_t& x, int32_t& y) override
    Samples the touch screen for a touch event and returns the coordinates.
  • void setRotation(bool value) override
    Sets the screen rotation for touch input.

Private Inheritance

  • Inherits from Lib::BSP::XPT2046::Driver to access hardware-level touch functions.

Usage Example

#include <BSP/TouchScreen.hpp>
BSP::TouchScreen touchScreen;
touchScreen.init();
int32_t x = 0;
int32_t y = 0;
if (touchScreen.sampleTouch(x, y)) {
// Handle touch at (x, y)
}

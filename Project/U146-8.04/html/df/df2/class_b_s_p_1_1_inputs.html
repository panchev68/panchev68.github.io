BSP::Inputs Class Reference

Description

Digital Peripheral Inputs Class.

The Inputs class manages digital peripheral inputs in the BSP layer. It inherits from PortBase and provides methods for setting up the input port, handling pre-update and post-update operations, and performing periodic tick updates. The class utilizes SPI communication with DMA support to read input values from the digital peripheral hardware, processing up to 24 inputs packed into 3 bytes.

Note
  • This class is designed for reading digital inputs via SPI with DMA.
  • It manages a fixed number of input items and handles SPI timeouts.
  • Assertions are used for critical errors like SPI initialization failures.

void BSP::Inputs::handleInputDataChanged ( const uint64_t value)
inline

Process input data changes.

Updates the internal state of input items based on a 64-bit value representing the state of all inputs. Each byte of the value corresponds to a group of 8 inputs, and this method extracts and updates the state of each input item accordingly.

Parameters
valueThe new input data value packed as a 64-bit integer.

◆ update()

void BSP::Inputs::update ( )
inline

Execute periodic input update cycle.

Performs a periodic update of the input states by initiating SPI communication, reading raw data bytes from the digital peripheral, and processing the received bytes into a combined 64-bit value. Updates the system peripheral data structure with the new input values. Triggers an assertion if the read operation fails, indicating a potential hardware or communication error.

Precondition
The SPI port and NSS pin must be properly initialized.
Postcondition
The peripheral input data is updated with the latest values from hardware, or an assertion failure occurs if communication fails.

Data::CanbusNodes::Node Struct Reference

Description

CAN bus node state representation.

The Node struct encapsulates the state of a single CAN bus node, including its activity status and data values for inputs and outputs. This structure is used within the CanbusNodes collection to maintain consistent node information.

Role of the type within the module or system: Represents individual CAN bus node data in the collection, providing a standardized interface for node state management.

BSP::Outputs Class Reference

Description

Digital Peripheral Outputs Class.

The Outputs class manages digital peripheral outputs in the BSP layer. It provides methods for setting up output ports, handling data changes, and performing periodic updates via SPI communication with DMA support. The class supports up to 24 outputs organized with daisy-chaining capabilities, utilizing the MC33879APEK driver for robust output control in embedded systems.

Note
  • This class is designed for controlling digital outputs via SPI with DMA.
  • Outputs are organized with precode configuration for flexible bit mapping.
  • Daisy-chaining identifiers define separate output groups for multi-device setups.
  • Error detection is implemented through daisy-chain verification.

Retrieve the error state of the outputs.

Returns the current error state of the outputs based on the last SPI communication cycle. The error state is determined by verifying the daisy-chain identifiers in the received data, indicating whether the communication was successful.

Returns
true if an error is detected in the last update cycle, false otherwise.

void BSP::Outputs::setup ( )
inline

Initialize the output configuration.

Sets up the SPI communication port and GPIO pins for digital peripheral output operations. This method configures the NSS and OE pins as output pins with appropriate modes and speeds, sets their initial states, and opens the SPI port for communication. This ensures proper hardware initialization before output operations can begin.

◆ update()

void BSP::Outputs::update ( )
inlinenoexcept

Execute periodic output update cycle.

Performs a periodic update of output states by preparing the transmit buffer with daisy-chain identifiers and output configuration data, then initiating SPI communication to transfer the data to the hardware. Updates the internal output state based on the current output data using precode configuration. Verifies communication integrity through daisy-chain response checking.

Precondition
The SPI port and GPIO pins must be properly initialized.
Postcondition
The output hardware is updated with the current output configuration, or an assertion failure occurs if communication fails.

API namespace for Xbee application programming interface.

Long detailed description of the API namespace, its purpose, and functionality. The API namespace defines the application layer for Xbee communication, including protocol message structures, command handling, and user-defined protocol extensions. It facilitates the development of custom communication protocols over Xbee modules, with support for inputs, outputs, and parameter management.

Role of the type within the module or system: Organizes API-related classes for Xbee communication, providing a clean interface for protocol implementation and extension.

Important design decisions or considerations: Uses virtual functions for extensibility, employs enum-based command codes for type safety, and implements efficient message building and parsing.

Note
API classes should be extended for specific protocol requirements; ensure command handling is implemented correctly to avoid communication errors.

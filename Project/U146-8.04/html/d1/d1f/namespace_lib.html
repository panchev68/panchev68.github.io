Lib namespace for library components and utilities.

Long detailed description of the Lib namespace, its purpose, and functionality. The Lib namespace encapsulates reusable library components, including hardware abstraction layers, communication protocols, and utility classes. It provides a structured organization for shared code across different modules and projects, ensuring modularity and maintainability. This namespace includes sub-namespaces for specific domains such as Xbee for wireless communication and HAL for hardware abstraction.

BSP::PortBase Class Referenceabstract

Description

Abstract base class for digital peripheral ports.

PortBase defines the interface for all port types in the digital peripheral system. It provides virtual methods for setup, select, deselect, and main update operations, allowing derived classes to implement specific port behaviors while maintaining a uniform API.

Note
  • This class is designed to be inherited by concrete port implementations.
  • All methods are pure virtual and must be implemented by derived classes.

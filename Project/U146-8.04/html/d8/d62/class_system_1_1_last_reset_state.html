System::LastResetState Class Reference

Description

LastResetState class.

Extends the HAL LastResetState functionality for the System namespace to provide access to the last reset state. This class follows the Singleton pattern to ensure a single instance for reset state tracking across the system. It allows retrieval of the reset cause and conversion to a state enumeration for diagnostics and error handling.

Role of the type within the module or system: Serves as a centralized interface for reset state information, enabling the application to determine the cause of system resets and take appropriate actions.

Important design decisions or considerations: Implements Singleton pattern to maintain a single source of truth for reset state, preventing inconsistencies from multiple instances.

Note
This class relies on HAL functionality for actual reset state detection.
Important
The Singleton pattern ensures thread-safe and consistent access to reset state information.

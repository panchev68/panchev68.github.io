System::DisplayRotation Class Referencefinal

Description

Display rotation state manager.

This class encapsulates the display rotation state, providing methods to get, set, and reset the rotation. Implements Singleton pattern for global access to ensure consistent display orientation management.

Role of the type within the module or system: Manages display rotation state for user interface and rendering components.

Important design decisions or considerations: Singleton prevents multiple instances, ensuring single source of truth for rotation state; final class prevents inheritance.

Note
State is initialized to false (not rotated) by default.

System::DisplayRotation Class Referencefinal

Description

Display Rotation State Manager Class.

This class encapsulates the display rotation state, providing a centralized mechanism for managing display orientation. It implements the singleton pattern to ensure a single source of truth for rotation information, which is essential for consistent UI rendering and touch input processing. The class is marked as final to prevent inheritance and maintain design integrity.

The DisplayRotation manages a boolean flag indicating whether the display is rotated (true) or in its default orientation (false). This state affects how coordinates are transformed and how UI elements are positioned on the screen.

Role within the system: Acts as the authoritative source for display orientation, used by rendering engines, touch controllers, and UI layout managers.

Design considerations: Singleton prevents multiple conflicting instances; final prevents extension; default initialization ensures predictable startup behavior.

Note
The rotation state is initialized to false (not rotated) by default on construction.

void System::DisplayRotation::reset ( )

Reset the rotation state to default.

Resets the display rotation state to its default (non-rotated) position. This ensures the display returns to standard orientation, which may be necessary for system resets or error recovery scenarios.

Precondition
The instance must be accessible.
Postcondition
The rotation state is set to false, equivalent to default orientation.
Note
This method provides a convenient way to restore default orientation without explicitly calling set(false).

CanPanelServer.hpp File Reference

Description

CAN server of the controller that the room panels connect to.

Runs Lib::Canbus::ServerBase (node 0) on one CAN peripheral. Frames received from a panel are handed to a callback in the service task; frames to a panel go out through transmit(). The protocol carried on top of it is Display::CanProtocol.

It compiles only when CAN1 is enabled in the CubeMX project: HAL_CAN_MODULE_ENABLED in the HAL configuration, the CAN1 peripheral on the device and USE_HAL_CAN_REGISTER_CALLBACKS set to 1. Otherwise the header is empty.

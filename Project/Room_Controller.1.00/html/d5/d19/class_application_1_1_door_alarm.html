Description

Raises the alarm once the door stayed open for GRACE_PERIOD.

Evaluated once per second like the legacy firmware. A closed door or a disabled alarm resets the countdown at once. A singleton: the node has one door. Not thread-safe; only the control step of RoomController uses it. The yellow indicator LED of the old panel is gone, so there is no blinking state any more.

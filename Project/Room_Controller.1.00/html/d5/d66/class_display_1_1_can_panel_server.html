Description

Controller side of the panel CAN bus: a Lib::Canbus server that forwards panel frames to a callback.

Thread-safe: transmit() may be called from any task; the callback runs in the service task, so it must only hand the frame over, for example through a queue. A singleton on CAN1: configure() binds the frame callback, open() starts the server.

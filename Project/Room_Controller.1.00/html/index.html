Source code

Hardware

Room controller of the Thermo Control 1.00 hotel HVAC system. It regulates the temperature of one room with a water convector (fan coil) with three fan speeds and a floor heater. The chiller feeds the convector with hot or cold water, so the regulator has both a HOT and a COLD mode; the floor heater works only in HOT.

The target is an STM32F407VET6 running FreeRTOS, built with IAR EWARM and C++20. The controller talks to the central unit and the PC program over RS485 on USART1 at 19200 baud, to the room panel (three seven-segment digits, two keys, SMT160 thermometer) over a second RS485 line on USART3, and keeps its settings in an external EEPROM on I²C1.

How the firmware works

The code is header-only and touches no hardware directly: every input and output goes through callbacks on Application::RoomController::Config. Application::RoomController owns the whole controller: the RS485 task (RS485::Communication), the panel task (Display::SerialPanel), a 5 ms control step and a task for the slow work (saving the settings, restart).

The control step reads the panel keys and the room temperature, draws the panel screens (Display::PanelScreen), checks the open-door alarm and runs the regulator (Control::Regulator): fan speed proportional to the demand, a soft landing at the setpoint and a floor heater with hysteresis. The settings are kept in two EEPROM slots with a sequence number and a checksum (Data::SettingsStorage).

Compatibility with the legacy firmware

The RS485 frames, commands and checksum follow the original ATmega8 firmware, so the existing PC application works unchanged. The serial port of that application is fixed at 19200 baud 8N1, which is why USART1 keeps this speed.

Previous versions

The firmware this one replaces, the room panel and the PC program it works with are kept in the same repository:

  • Controller firmware 004-2010.06.02, the original ATmega8 firmware running in the controllers of Hotel "Черневци".
  • Room panel firmware, the AVR firmware of the serial panel with the three digits, two keys and the SMT160 thermometer.
  • Clima Control 2.0.1.37, the PC program that talks to the controllers over RS485.

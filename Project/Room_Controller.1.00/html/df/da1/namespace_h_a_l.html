Description

MCU interfaces of the room controller over the CubeMX handles.

One singleton per used interface (UART1Port, UART3Port, I2C1Port, IWDGPort), UARTBase with the shared serial logic, and System for the restart and reset cause. Not to be confused with Lib::HAL, the shared HAL layer.

Description

Room controller application, the C++20 counterpart of the legacy AVR firmware main loop (004/2010.06.02).

Wires the RS485 node protocol, the serial room panel, the regulator, the door alarm and the persistent settings together. The RS485 master protocol stays compatible with the legacy firmware.

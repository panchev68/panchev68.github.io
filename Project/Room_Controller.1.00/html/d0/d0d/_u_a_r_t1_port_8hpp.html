UART1Port.hpp File Reference

Description

USART1 of the room controller: the RS485 bus to the central unit and the PC application.

Singleton that binds HAL::UARTBase to the CubeMX handle huart1, so the application never names the handle. The line runs at 19200 8N1, the fixed speed of the PC application (RS485v2/Com.cs); the CubeMX project sets it.

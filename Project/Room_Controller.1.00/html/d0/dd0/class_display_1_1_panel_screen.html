Description

What the panel shows and how the keys change the room, without any RTOS object or hardware access.

The main screen shows the setpoint, or the room temperature between key presses when the setup asks for it, and the up and down keys change the setpoint. The LEDs show the mode: red for heating, blue for cooling, and all three while the service menu is still open after the power-up. Holding both keys for PanelKeyboard::REPEAT_DELAY during that window opens the service menu, which the guest can no longer reach later. The parameters are:

0 RS485 node address, 1 to 32
1 Mode: 0 off, 1 heating, 2 cooling
2 Highest fan speed, 0 to 3
3 Floor heater, 0 off, 1 on
4 Main screen: 0 setpoint, 1 room temperature between key presses
5 Temperature calibration in steps of 0.1 degC, shows the room temperature
6 Shows the room temperature
RS485
RS485 node protocol towards the central unit and the PC application.
Definition Communication.hpp:27

Each change goes out through a callback; the callbacks run inside update(). Not thread-safe; the control step of the room controller is the only user.

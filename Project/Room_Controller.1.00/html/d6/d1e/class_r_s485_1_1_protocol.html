Description

Hardware-agnostic RS485 packet protocol engine handling framing, CRC16 validation and command dispatch.

Feed received bytes into onByteReceived(), advance time with onTick(), and call process() once isFrameReady() reports true; RS485::Communication does all three from one task. All methods except setNodeAddress() and getNodeAddress() must be called from that single task. Config::transmit must block until the frame is physically sent, since Config::setDirection switches back to receive right after it returns.

void RS485::Protocol::process ( )
inlinenoexcept

Validates and dispatches the frame captured by onTick(), then transmits the reply.

Frames for another address are ignored silently. A frame for this node always gets a reply: the command result, INVALID_CHECKSUM for a truncated or corrupted frame, or COMMAND_NOT_SUPPORTED.

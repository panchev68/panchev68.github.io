IWDGPort.hpp File Reference

Description

Independent watchdog of the room controller.

Singleton that owns the Lib::HAL::IndependentWatchdog of the CubeMX handle hiwdg. The control step refreshes it; a hang or a stopped timer task resets the MCU, which the next start reads as a warm restart (HAL::System::isWarmRestart()).

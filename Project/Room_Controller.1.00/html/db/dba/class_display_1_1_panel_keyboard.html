Description

Turns the key code that the panel reports into press events.

A new key code gives one event at once. A key held for REPEAT_DELAY then gives an event every REPEAT_PERIOD, and isRepeating() tells that it is held. An event stays until takeKey() reads it. Not thread-safe; the control step of the room controller is the only user.

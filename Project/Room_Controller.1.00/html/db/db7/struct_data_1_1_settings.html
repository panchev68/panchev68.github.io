Description

Persistent parameters of one room controller, in the byte units of the legacy RS485 protocol.

The struct is packed and trivially copyable, so storage code can save and load it as raw bytes. Defaults match the legacy default_value_init(). Mode and setup bytes are kept raw, so bits the firmware does not interpret are returned to the master unchanged, as before.

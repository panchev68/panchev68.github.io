Description

Fixed-capacity command dispatcher that replaces one large switch statement over RS485::Protocol::Command.

Register one handler per command with RS485::Parser::addHandler(), then bind RS485::Parser::dispatch() to RS485::Protocol::Config::onCommand. Commands without a handler make RS485::Protocol reply with RS485::Protocol::Error::COMMAND_NOT_SUPPORTED. Registration is not thread-safe; finish it before the protocol task starts.

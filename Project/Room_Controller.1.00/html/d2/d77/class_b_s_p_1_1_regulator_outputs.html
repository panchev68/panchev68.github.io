Description

Drives the four regulator outputs from the low nibble of the value Control::Regulator produces.

Bit 0 is the floor heater, bit 1 fan speed 3, bit 2 fan speed 2 and bit 3 fan speed 1, as on the legacy PC0 to PC3. Each output is a single atomic pin write, so any task may call set(). A singleton: the node has one set of outputs; configure() binds the pins.

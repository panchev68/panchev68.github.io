Description

Controller side of the CAN panel link: sends the room state and tracks the panel events.

Not thread-safe: call every method from one task. Forward frames from the CAN receive task into that task through a queue, then into onFrameReceived(). Without a frame from the panel for Config::statusTimeout the link counts as lost and the temperature as unavailable. A zero timeout disables the supervision.

PanelProtocol.hpp File Reference

Description

Frames of the serial link to the room panel "Climate Control Display rev.001", the port of suart_fifo2.cpp.

The controller polls the panel over a half-duplex RS485 line at 19200 baud, 8 data bits, no parity, one stop bit. The legacy AVR firmware drove the line from an inverted software UART (idle low, start bit high, inverted data bits), but the panel is a separate Atmel CPU with a hardware UART behind its own transceiver, so on the line the polarity is normal. A normal USART carries the bytes as they are written here; if the panel does not answer, the A and B wires of the cable are swapped.

  • Controller to panel, 5 bytes: segment 1, segment 2, segment 3 (bit 0 to 6 segments a to g, bit 7 decimal point), LED and beep byte, checksum. The LED byte holds the blue (bit 0), yellow (bit 1) and red (bit 2) LEDs and a beep of 100 ms per bit in bits 4 to 7.
  • Panel to controller, 6 bytes: key code, period and low time of the SMT160 thermometer signal (two bytes each, big-endian), checksum.

The checksum is the sum of all bytes before it, modulo 256.

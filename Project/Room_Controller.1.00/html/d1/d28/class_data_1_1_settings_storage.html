Description

template<EepromDevice T_EEPROM>
class Data::SettingsStorage< T_EEPROM >

Keeps the settings record in two alternating EEPROM slots, each with a sequence number and a CRC16.

Data::SettingsStorage::save() always writes the slot that does not hold the newest record, so a power loss during a write leaves the previous record intact and Data::SettingsStorage::load() falls back to it. Saving an unchanged record writes nothing. The EEPROM must be opened by the caller. Not thread-safe; the EEPROM drivers block and need a running scheduler.

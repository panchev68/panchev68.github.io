APP Namespace Reference
Application Layer

Description

Application layer, one singleton module per functional area.

Each module owns its task, brings up its own hardware with retry inside that task, and publishes results through atomic getters: APP::PowerSupply (MPPT, with APP::Supply12V and APP::LowPower), APP::DistanceMeter (PGA460, USART1), APP::ExternalThermometer (DS18B20), APP::RFID (ST25R100/SPI3, NTAG21x card-record verification), APP::UserInterface (front-panel buttons, door locks and sensors), APP::ComModule (ESP32 link over USART3) and APP::StorageManager (W25Q128 flash). APP::Diagnostics checks the hardware, and APP::Application starts every module. The on-target self-tests in 'Project/Tests' are also in this namespace (group Application Tests).

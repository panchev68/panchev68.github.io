Board Support Package

Description

Board I/O singletons and chip drivers.

BSP::Inputs (BUT1_SW/BUT2_SW, SW_INP1/SW_INP2), BSP::Outputs (OUT1..OUT4), BSP::ButtonLeds (BUT1_LED/BUT2_LED) and BSP::Buzzer wrap the board's buttons, door sensors, switched outputs and buzzer. The chip drivers (BSP::INA219, BSP::TMP102, BSP::DS18B20, BSP::PGA460TPWRQ1, BSP::ST25R100, BSP::W25Q128JVSIQ) are thin board-wiring facades over the header-only drivers of the shared library 'X:/Lib/IAR/inc': pins and port instance only, the driver logic lives in the library.

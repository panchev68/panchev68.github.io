Description

External flash storage module singleton.

The flash is opened once by start(); every read, program and erase then takes a mutex so several modules can use it. The data layout belongs to the callers: the blocklist at 0x000000 (Blocklist), the disposal record backup at 0x040000 (RecordStore) and the service list at 0x050000 (ServiceList).

The flash stays powered (standby) between accesses; the driver's deep power-down (enterPowerDown()) is not used.

The state lives in an Impl defined in 'StorageManager.cpp'.

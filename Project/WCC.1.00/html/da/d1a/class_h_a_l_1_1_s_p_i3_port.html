Description

Singleton wrapper for the SPI3 port.

Provides a single, global access point to the driver bound to the external HAL handle hspi3. Chip select is the hardware NSS output ('PA15'), so no GPIO is driven by software.

The transfers are deliberately blocking, although 'SPI3_IRQn' is enabled in STM32U575VGT6.ioc: the ST25R100 traffic is mostly 2-3 byte register accesses (~50 us each at 500 kHz), shorter than the interrupt and task-switch overhead of 'Lib::HAL::DriverMode::IT', and a task waiting for an interrupt-driven transfer could let tickless idle enter STOP1, which stops the SPI3 clock mid-transfer ('Lib::HAL::SPIPort' takes no DeepSleepLock).

Important
Before switching Driver to 'Lib::HAL::DriverMode::IT', make the transfer withhold STOP1 and test it on the board.

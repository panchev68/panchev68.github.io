Description

Published state: whether the accumulator is currently not being charged.

Idle means night or insufficient panel light (see idleUntilChargeable() in 'PowerSupply.cpp'), so other modules can scale back their own activity while solar power is not available. It is a nested class only so a reader (APP::RFID, APP::DistanceMeter) has a narrow, obviously-scoped name to call instead of a loose top-level one; setIsIdle() is called only by APP::PowerSupply itself.

The published flag lives in Impl, defined in 'PowerSupply.cpp'.

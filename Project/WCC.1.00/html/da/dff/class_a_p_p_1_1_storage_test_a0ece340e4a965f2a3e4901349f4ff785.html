enum class APP::StorageTest::Result : uint8_t
strong

Test steps; the result is the first step that failed.

Enumerator
RUNNING 

Not finished yet.

PASSED 

Every cycle passed.

START_FAILED 

The flash did not open or is not present: check the OCTOSPI wiring, the supply and the JEDEC ID.

ERASE_FAILED 

An erase command was not accepted or did not finish.

NOT_ERASED 

A byte of the erased sector is not 0xFF; see "getBadAddress()".

WRITE_FAILED 

The program command was not accepted or did not finish.

READ_FAILED 

A read did not complete.

VERIFY_FAILED 

The data read back differs from the pattern; see "getBadAddress()".

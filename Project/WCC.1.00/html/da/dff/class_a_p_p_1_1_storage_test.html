Description

Flash self-test singleton on the last 4 KiB sector (0xFFF000), which no module uses.

One cycle opens the flash, erases the sector, checks that every byte reads 0xFF, programs a pattern that starts inside a page and crosses page boundaries, reads it back and compares, then erases the sector again and checks it is empty. Five cycles run, so an unreliable link shows up as a changing result; the sector is left erased.

The result, the passed cycles and the address of the first wrong byte are published in the Live Watch structure APP::storageTestWatch. A failed step stops at an assert naming it, a full pass at __BKPT(1) (debug build).

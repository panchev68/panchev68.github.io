◆ setIdleWakeupTiming()

bool BSP::ST25R100::setIdleWakeupTiming ( bool isIdle)
staticnodiscardnoexcept

Switches the wake-up (LPCD) measurement period between the project's normal, faster tuning and a slower, lower-standby-current one, meant for use only while "APP::PowerSupply::ChargeIdle::getIsIdle()" (see "APP::RFID::Impl::taskEntry()", which calls this around a "pause()"/"resume()" pair so the reconfiguration SPI writes never race an in-progress discovery).

Parameters
isIdle"true" selects the slower, lower-power timing; "false" returns to the normal, faster one.
Returns
"true" if the SPI writes succeeded.

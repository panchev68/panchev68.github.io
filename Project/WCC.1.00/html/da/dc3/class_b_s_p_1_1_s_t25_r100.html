Description

Exposes the board ST25R100 and its discovery manager as singletons bound to SPI3.

The implementation lives in the shared library ('Lib::BSP::RFID::ST25R100', 'Lib::BSP::RFID::NfcManager'); this class only supplies the board wiring and the project's wake-up (LPCD) tuning: the reader on HAL::SPI3Port and its nIRQ line ST25R100_NIRQ (PD0, EXTI0 rising edge, 'EXTI0_IRQn' at priority 5, FreeRTOS-safe). The library's 'Lib::HAL::GPIO::ExtInterrupt' owns the HAL EXTI callbacks and runs the bound handler in its worker task, which wakes the reader task.

Stops forwarding nIRQ edges to the reader, without touching the reader or the manager.

Important

◆ enableInterrupt()

void BSP::ST25R100::enableInterrupt ( )
staticnoexcept

Applies the project's wake-up (LPCD) tuning, then lets nIRQ edges reach the reader task.

The threshold and the measurement period are tuned for a longer card-detect range and a faster reaction than the library defaults, at the cost of a higher standby current. A transient caused by the reconfiguration is still dropped, since forwarding starts only afterwards.

Important
Call it once the reader opened successfully: the reader task is created inside 'open()', and notifying it earlier asserts.

◆ setIdleWakeupTiming()

bool BSP::ST25R100::setIdleWakeupTiming ( bool isIdle)
staticnodiscardnoexcept

Switches the wake-up (LPCD) measurement period between the normal, faster tuning and a slower one.

The slower timing lowers the standby current and is meant only for while APP::PowerSupply::ChargeIdle reports no charge.

Important
Call it between 'pause()' and 'resume()' of APP::RFID, so the SPI writes never race an in-progress discovery.
Parameters
isIdle'true' selects the slower, lower-power timing; 'false' returns to the normal, faster one.
Returns
'true' if the SPI writes succeeded.

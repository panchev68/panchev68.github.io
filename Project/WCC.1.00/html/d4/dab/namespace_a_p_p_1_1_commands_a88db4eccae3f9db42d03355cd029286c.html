enum class APP::Commands::CardResult : uint8_t
strong

Outcome of a presented card.

Enumerator
ACCEPTED 

Valid record, number not blocked.

BLOCKED 

Valid record, number blocked (or the blocklist could not be read).

INVALID_RECORD 

Missing or malformed record.

BAD_SIGNATURE 

Record not signed by the issuer, or copied from another card.

UNKNOWN_KEY 

Record signed with an unknown issuer key id.

READ_ERROR 

Card memory could not be read.

UNSUPPORTED_CARD 

Not an NTAG21x (UID is not 7 bytes); the UID is still reported (4, 7 or 10 bytes).

NOT_GENUINE 

The card has no valid NXP originality signature (not a genuine NTAG21x, possibly a clone).

BUSY 

Valid card, but the user interface is still handling a previous selection/open door, or the record buffer is full.

SERVICE_ACCEPTED 

Valid record, number in the service list: all three doors were opened, not a billed disposal.

APP::Commands Namespace Reference
Application Layer

Description

Frame types exchanged with the ESP32 over ComService and their payload sizes.

All multi-byte fields are big-endian; the ESP32 is the master and sends every command, the controller only answers. The full frame catalog and the framing are in the module doc Protocol.md.

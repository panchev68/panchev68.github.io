APP::Commands Namespace Reference
Application Layer

Description

Frame types exchanged with the ESP32 over "ComService" ("FrameType") and their payload layouts.

All multi-byte fields are big-endian; the ESP32 is the master and sends every command, the controller only answers. See the Protocol.md module doc for the full frame catalog and framing.

◆ CardResult

enum class APP::Commands::CardResult : uint8_t
strong

Outcome of a presented card.

Enumerator
ACCEPTED 

Valid record, number not blocked.

BLOCKED 

Valid record, number blocked (or the blocklist could not be read).

INVALID_RECORD 

Missing or malformed record.

BAD_SIGNATURE 

Record not signed by the issuer, or copied from another card.

UNKNOWN_KEY 

Record signed with an unknown issuer key id.

READ_ERROR 

Card memory could not be read.

UNSUPPORTED_CARD 

Not an NTAG21x (UID is not 7 bytes); the UID is still reported (4, 7 or 10 bytes).

NOT_GENUINE 

The card has no valid NXP originality signature (not a genuine NTAG21x, possibly a clone).

BUSY 

Valid card, but the user interface is still handling a previous selection/open door, or the record buffer is full.

SERVICE_ACCEPTED 

Valid record, number in the service list: all three doors were opened, not a billed disposal.

◆ DeviceFault

enum class APP::Commands::DeviceFault : uint8_t
strong

Bits of the device faults byte of STATUS_RESPONSE: a set bit is a device that did not answer the start-up diagnostics.

The byte is 0 when the diagnostics did not run.

Enumerator
EXTERNAL_FLASH 

The W25Q128 flash does not answer.

SOLAR_MONITOR 

INA219 of the solar panel (0x40).

ACCUMULATOR_MONITOR 

INA219 of the accumulator (0x41).

TEMPERATURE_SENSOR 

TMP102 (0x48).

THERMOMETER 

DS18B20 does not answer the presence pulse.

NFC_READER 

ST25R100 does not open or has a wrong IC identity.

DISTANCE_SENSOR 

PGA460 does not answer a register read.

◆ DoorEvent

enum class APP::Commands::DoorEvent : uint8_t
strong

Door state reported by a disposal record.

Enumerator
OPENED 

Lock pulsed and the door was opened.

NOT_OPENED 

Lock pulsed but the door sensor showed no opening within 2 s (error).

LEFT_OPEN 

Door still open 30 s after it opened; the buzzer alarm starts (runs for 15 s).

CLOSED 

Door closed after a "LEFT_OPEN" alarm.

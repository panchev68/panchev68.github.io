Description

Singleton wrapper for the HASH port.

Provides a single, global access point to the interrupt-driven driver bound to the external HAL handle 'hhash' (CubeMX: SHA-256, 'HASH_DATATYPE_8B', 'HASH_IRQn' enabled, register callbacks on).

Important
Call 'open()' before the first 'sha256()'; it is idempotent.

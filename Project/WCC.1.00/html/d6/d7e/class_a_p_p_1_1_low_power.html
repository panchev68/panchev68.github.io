Description

Puts the controller into STOP1 whenever the kernel is idle long enough.

With no task ready the idle task sleeps: a plain WFI for short idle times, STOP1 for more than RTOS::PowerManager::MIN_TICKS_FOR_STOP_MODE ticks. LPTIM1, clocked from the LSE, or any interrupt wakes it. All of it lives in the project, so regenerating the project in CubeMX changes nothing: the strong vPortSuppressTicksAndSleep() and LPTIM1_IRQHandler() are in the implementation file, and the LPTIM1 clock source and interrupt are set in start(). Only 'configUSE_TICKLESS_IDLE' and 'FREERTOS_LOW_POWER_SUPPORT' stay in the USER CODE block of 'FreeRTOSConfig.h'.

Warning
Do not enable the LPTIM1 global interrupt in CubeMX: it would generate a second LPTIM1_IRQHandler().

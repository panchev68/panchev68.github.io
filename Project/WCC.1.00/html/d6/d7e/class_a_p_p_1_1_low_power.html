Description

Low-power singleton.

With no task ready the kernel idle task sleeps: a plain "WFI" for short idle times and STOP1 for more than "RTOS::PowerManager::MIN_TICKS_FOR_STOP_MODE" ticks, woken by LPTIM1 (clocked from the LSE) or by any interrupt.

Everything that makes this work lives in the project, so regenerating the project in CubeMX changes nothing: the strong "vPortSuppressTicksAndSleep()" and the "LPTIM1_IRQHandler()" are in "LowPower.cpp", the LPTIM1 clock source and its interrupt are set in "start()". Only "configUSE_TICKLESS_IDLE" and "FREERTOS_LOW_POWER_SUPPORT" stay in the USER CODE block of "FreeRTOSConfig.h".

Note
Do not enable the LPTIM1 global interrupt in CubeMX: it would generate a second "LPTIM1_IRQHandler()".

The timer, and the state of the setup live in an "Impl" defined in "LowPower.cpp".

◆ countRejectedCard()

void APP::RecordBuffer::countRejectedCard ( )
noexcept

Counts a disposal refused before it could even be attempted (a caller saw isFull() and declined the card, e.g.

UserInterface, instead of opening a door for a "push()" that would only be refused).

Without this, such refusals would not show up in "getLostCount()" at all, since no push() call is ever made for them.

NOT_GENUINE 0x08U 

The card has no valid NXP originality signature (not a genuine NTAG21x, possibly a clone).

BUSY 0x07U 

Valid card, but the user interface is still handling a previous selection/open door, or the record buffer is full.

SERVICE_ACCEPTED 0x09U 

Valid record, number in the service list: all three doors were opened, not a billed disposal.

◆ DeviceFault

enum class APP::Commands::DeviceFault : uint8_t
strong

#include <Commands.hpp>

Bits of the device faults byte of FrameType::STATUS_RESPONSE.

A set bit is a device that did not answer the diagnostics: APP::Diagnostics::run() at start-up, refreshed periodically by APP::Diagnostics::startRuntimeDiagnostics(). The byte is 0 when the diagnostics did not run.

Enumerator
EXTERNAL_FLASH 0x01U 

The W25Q128 flash does not answer.

SOLAR_MONITOR 0x02U 

INA219 of the solar panel (0x40).

ACCUMULATOR_MONITOR 0x04U 

INA219 of the accumulator (0x41).

TEMPERATURE_SENSOR 0x08U 

TMP102 (0x48).

THERMOMETER 0x10U 

DS18B20 does not answer the presence pulse.

NFC_READER 0x20U 

ST25R100 does not open or has a wrong IC identity.

DISTANCE_SENSOR 0x40U 

PGA460 does not answer a register read.

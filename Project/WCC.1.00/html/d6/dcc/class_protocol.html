Description

Lightweight framing protocol utilities for encoding and decoding framed messages.

Supports optional byte-stuffing (API mode 2) and checksum validation. All payloads and encoded frames are held in fixed-capacity Buffer instances backed by 'std::array', so encoding and decoding never touch the heap.

Encodes a frame with optional byte-stuffing (API mode 2).

Format: START_DELIMITER, length MSB, length LSB, frame type, payload..., checksum. The bounded 'payload' guarantees the worst-case escaped output fits in an EncodedFrame, so this cannot fail.

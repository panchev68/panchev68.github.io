Description

RGB LED singleton: three separate pins ('LEDR', 'LEDG', 'LEDB'), plain GPIO outputs.

Every colour channel is either on or off, so the LED shows the eight combinations of Color. The class only switches the channels; what a colour means (card accepted, error, ...) and any blinking stay with the user. The pin level that lights a channel (low) is set in one place, Impl::ACTIVE_LEVEL in 'RgbLed.cpp'.

Calls are thread-safe (the three pins change inside one critical section), so they are for task context only.

The pins and the helpers live in Impl, defined in 'RgbLed.cpp'.

Which modules/tests started, one flag per 'ENABLE_*' switch above plus isDiagnosticsPassed. More...

Description

Which modules/tests started, one flag per 'ENABLE_*' switch above plus isDiagnosticsPassed.

A flag for a switch left false stays false too, since that module was never asked to start.

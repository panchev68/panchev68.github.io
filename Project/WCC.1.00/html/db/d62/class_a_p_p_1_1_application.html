Description

Startup sequencer.

"startup()" ("Project/startup.cpp") only calls "Application::start()". Each "APP/"/"Project/Tests/" module is a singleton with its own "start()"; this class holds no state of its own beyond the compile-time switches below, so it needs no Impl (see "ClassStructure.md": no private state, no private dependencies).

◆ start()

Status APP::Application::start ( )
staticnodiscardnoexcept

Starts the firmware, in the fixed order above.

Beeps/flashes the power-on indication, runs "APP::Diagnostics" if enabled, then starts every other enabled module/test. The order matters in a few places: diagnostics run first so a device that never answers is caught and reported before anything tries to use it; "Blocklist::open()"/"ServiceList::open()" only run once "StorageManager" is up, since they need the flash; a test that only reads another module's published value ("DistanceMeterTest"/"DistanceIndicatorTest") is only started when that module is also enabled.

Returns
Which modules/tests started; a switch left false above leaves its flag false too.

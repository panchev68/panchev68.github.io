Description

Flash-backed card number blocklist singleton.

The list is an append-only log of 8-byte slots in a reserved flash region, so adding and removing a number never needs an erase:

Word Erased Active Removed
0 0xFFFFFFFF card number card number
1 0xFFFFFFFF 0x5A5A5A5A 0x00000000

Removal only clears bits of word 1, which NOR flash allows without erasing. A slot interrupted by a power loss is neither erased nor active and is skipped. Only clear() erases the region; a full region rejects further adds until then. clear() itself can be interrupted (e.g. a brown-out mid-erase, up to several seconds): open() does not assume the first erased slot marks the end of the log, so a later un-erased sector still reporting an active number is never silently dropped from the index; clear() stays callable after a failed attempt so the caller can simply retry it to finish erasing.

open() reads the region once into a sorted RAM index (number and slot), so contains() never touches the flash and add() / remove() each program one slot.

Enumerator

remove() - number was not blocked.

add() - no free slot or MAX_ACTIVE reached; clear() and resend the list.

Flash access failed or the list is not open.

Reported by APP::ComModule for a malformed request; never returned here.

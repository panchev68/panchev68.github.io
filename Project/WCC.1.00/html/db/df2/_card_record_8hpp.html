CardRecord.hpp File Reference

Description

WCC issuer key policy for the signed card record, and the CardRecord alias wired to it.

The verification itself (format, key id, ECDSA P-256 over SHA-256(header || UID)) lives in Lib::BSP::RFID::NTAG21x::CardRecord; this file only supplies the per-product constants it needs: the record magic WCC and the key id and public key from IssuerPublicKey.hpp (generated by tools/card_tool.py keygen).

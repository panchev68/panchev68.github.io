Description

Checks a presented NFC card and publishes the result.

Started by the card-activated callback of the BSP::ST25R100 reader: the card's record and NXP originality signature are verified against the issuer key, then its number against the lists. A card in the APP::ServiceList goes to APP::UserInterface::requestServiceOpen() without a APP::Blocklist check; any other unblocked card goes to APP::UserInterface::requestSelection(), and a APP::Commands::CardResult::BLOCKED one is queued through APP::ComModule::queueBlocklistRemoval(). An accepted card gives one short beep, any other result three. The last 32 cards that passed both signature checks are cached by a digest of their read data, so presenting one again skips the slow ECDSA checks; the lists are still checked every time.

pause() and resume() are reference-counted, so APP::DistanceMeter (around a PGA460 measurement) and the check task itself (switching the wake-up timing with APP::PowerSupply::ChargeIdle) can each hold their own pair.

◆ pause()

void APP::RFID::pause ( )
noexcept

Pauses card discovery; call resume() afterwards.

Waits briefly for an in-progress card check to finish before stopping the reader; a wait that times out stops it anyway. Reference-counted: the reader stops on the first pause() of an overlapping set and restarts on the last matching resume(), and a mutex serializes the stop/start transition, so callers from different tasks cannot cut each other's pause short.

Referenced by pause().

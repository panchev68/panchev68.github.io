Description

Checks a presented NFC card and publishes the result.

Started by the card-activated callback of "BSP::ST25R100"; a verified, unblocked card is handed to "UserInterface::requestSelection()", and a card found "BLOCKED" is also queued for removal via "ComModule::queueBlocklistRemoval()". A verified card whose number is in the "ServiceList" is never checked against the "Blocklist"; it is handed to "UserInterface::requestServiceOpen()" instead of "requestSelection()". The accepting beep (including a service card) is one short beep, any other result three. "pause()"/"resume()" let "APP::DistanceMeter" stop discovery for the duration of a PGA460 measurement.

void APP::RFID::pause ( )
noexcept

Pauses card discovery, e.g.

around a PGA460 distance measurement ("APP::DistanceMeter") that must not run concurrently with the reader. Waits briefly for an in-progress card check to return to idle before stopping the reader, so an activation already under way is not cut off; a wait that times out stops it anyway. Call "resume()" afterwards. Not reentrant: call a "pause()"/"resume()" pair from one task at a time.

Description

Flash-backed disposal record store singleton.

Records normally live only in the RAM "RecordBuffer".

When the accumulator is nearly empty or the ESP32 does not acknowledge, "ComModule" moves them here so they survive a power loss. They are not loaded back into the RAM buffer at start: "ComModule" returns them to the ESP32 oldest first, before the RAM records, when it asks, and they are acknowledged by the ESP32 through GET_DISPOSAL_RECORDS.

The region is a ring of 32-byte slots (23 bytes used, the rest reserved and left erased), written in order and never erased in place:

Bytes Field
0..3 sequence number
4..7 card number
8..11 Unix time, UTC
12 litres
13 door event
14..15 state: 0xFFFF erased, 0xA55A active, 0x0000 acknowledged
16..22 card UID (fixed 7 bytes: only NTAG21x cards reach a record)
23..31 reserved, left erased

Acknowledging only clears the state bits, which NOR flash allows without an erase. A sector is erased when the write position reaches it; if it still holds an active record the ring is full and the new record is refused. A slot interrupted by a power loss is neither erased nor active and is skipped.

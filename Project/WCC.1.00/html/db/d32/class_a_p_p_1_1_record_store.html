Description

Flash-backed disposal record store singleton.

Records normally live only in the RAM APP::RecordBuffer. When the accumulator is nearly empty or the ESP32 does not acknowledge, APP::ComModule moves them here so they survive a power loss. They are not loaded back into the RAM buffer at start: APP::ComModule returns them to the ESP32 oldest first, before the RAM records, and the ESP32 acknowledges them through APP::Commands::FrameType::GET_DISPOSAL_RECORDS.

The region is a ring of 32-byte slots, written in order and never erased in place; the slot layout is in 'doc/RecordStore.md'. Acknowledging only clears the state bits, which NOR flash allows without an erase. A sector is erased when the write position reaches it; if it still holds an active record the ring is full and the new record is refused. A slot interrupted by a power loss is neither erased nor active and is skipped.

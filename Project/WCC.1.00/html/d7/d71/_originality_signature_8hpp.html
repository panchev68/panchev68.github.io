Description

Project wiring for the NXP NTAG21x originality signature check.

The verification itself (fixed NXP public key, secp128r1) lives in Lib::BSP::RFID::NTAG21x::OriginalitySignature; this file only aliases it and holds the project's switch to skip the check (for example while the NXP key is unconfirmed on this board revision).

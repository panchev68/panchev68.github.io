Description

Thread-safe ring buffer of unacknowledged blocklist removal requests.

Holds one request per presented card found APP::Commands::CardResult::BLOCKED, in order of creation. The controller never removes a number from the APP::Blocklist itself; it only queues the request here, and the ESP32 reads it with APP::Commands::FrameType::GET_BLOCKLIST_REMOVE_REQUESTS and acts on it, on its own initiative, with APP::Commands::FrameType::BLOCKLIST_REMOVE. When the buffer is full the oldest request is overwritten and getLostCount() grows. The contents are lost on reset.

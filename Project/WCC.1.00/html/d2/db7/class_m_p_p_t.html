Description

Cascaded MPPT controller of the solar accumulator charger, driving the LMR14030 buck charger.

The outer loop (library MPPT, every "OUTER_LOOP_DIVIDER" steps) computes the panel voltage setpoint; the inner loop (every "step()") moves the DAC_OUT voltage injected into the buck feedback node until the measured panel voltage reaches that setpoint.

The DAC current is summed into the FB node through R30, so a higher DAC voltage lowers the buck output voltage, unloads the panel and lets its voltage rise. Panel irradiance is not measured; it is estimated from the panel current relative to the MPP reference current.

Vout = Vfb * (1 + R28 / R31 + R28 / R30) - Vdac * (R28 / R30)

The state, the hardware constants and the private helpers live in an Impl defined in "MPPT.cpp", owned through a pointer created in the constructor. Not thread-safe by design: "init()", "step()" and "disable()" must all be called from the single power supply task.

◆ getChargerCurrent()

float MPPT::getChargerCurrent ( ) const
nodiscardnoexcept

Returns the charger output current measured by the last "step()".

The 0x41 monitor's shunt R25 sits between the charger diode D4 and the 6 V rail, so this is the current the charger feeds into the loads plus the accumulator; the accumulator's own discharge does not pass it.

Returns
Charger output current, in amperes; never positive (calibration sign), 0 until the first update.

◆ step()

bool MPPT::step ( )
nodiscardnoexcept

Runs one inner-loop iteration and, every "OUTER_LOOP_DIVIDER" calls, one MPPT update.

Call every "STEP_PERIOD_MS". The accumulator charge voltage and charge current limits override the MPPT setpoint.

Returns
false if a sensor read or the DAC write failed; the charger then keeps its last DAC value.

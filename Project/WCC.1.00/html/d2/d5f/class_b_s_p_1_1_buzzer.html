Description

Buzzer singleton.

CubeMX configures TIM1 CH3 as output compare (timing mode). This class switches the channel to toggle mode and sets the period for the tone frequency ("FREQUENCY_HZ" unless "setFrequency()" changed it); CH3 and CH3N toggle in antiphase, so the buzzer sees twice the swing.

Buzzer part: PT-1240PQ (confirmed by schematic, 18.10.2026), 4.1 kHz resonance, rated 20 Vp-p drive, 13.8 mm diameter, driven through TC118S from PE12/PE13.

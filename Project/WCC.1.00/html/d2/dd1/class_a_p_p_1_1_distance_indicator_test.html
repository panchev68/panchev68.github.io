Description

Distance-to-blink-rate indicator singleton.

Runs forever in its own small task, never stopping to switch the LED off.

It never shares the PGA460/UART, so it does not depend on anything that could block it, and reads APP::DistanceLiveTest::getDistance() at every toggle. A fresh valid reading latches into 'APP::distanceIndicatorWatch.lastDistanceMeters' ('DistanceIndicatorTest.cpp'); an invalid or missing one (nothing in range, a failed measurement, or none yet) leaves that latch at its last value instead of jumping to the fastest or slowest rate, so a momentary dropout does not visibly change the blink rate. The latched distance maps onto a blink period: 'Impl::MIN_DISTANCE' (closest, the PGA460's near range limit) blinks every 'Impl::MIN_BLINK_PERIOD', 'Impl::MAX_DISTANCE' (farthest, the sensor's far range limit, also the value the latch starts at) every 'Impl::MAX_BLINK_PERIOD', linearly in between: closer is faster, like a parking-sensor indicator.

The values are the members of one global structure, 'APP::distanceIndicatorWatch' ('DistanceIndicatorTest.cpp'): add that one expression to the IAR Live Watch and expand it. 'lastDistanceMeters' is the latched distance described above; 'blinkPeriodMilliseconds' is the full on/off cycle currently in effect, derived from it.

Does not touch the PGA460/UART itself, only the distance APP::DistanceLiveTest already publishes, so it runs alongside it rather than instead of it: needs 'ENABLE_DISTANCE_LIVE_TEST' on.

Description

Configures the PGA460 after each power-up and measures the distance of the nearest object, ~0.20 .

. 2 m.

The library UART path of the PGA460 driver misses the device's fast answers, so this class exchanges the frames by polling the USART1 registers with interrupts off for the few milliseconds of one exchange. The PGA460 forgets its threshold map at power-down, so the map, the burst length and the gain range are written after each power-up. The values come from tests with the black parking-sensor transducer (about 40 kHz) on APP::DistanceLiveTest. Below ~0.37 m only a strong enough echo is detected (see 'MIN_TIME_OF_FLIGHT').

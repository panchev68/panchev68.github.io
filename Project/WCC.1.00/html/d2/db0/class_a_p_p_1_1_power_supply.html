◆ getChargerCurrent()

float APP::PowerSupply::getChargerCurrent ( ) const
nodiscardnoexcept

Returns the charger output current into the 6 V rail, read by the last MPPT update.

This is both the loads and the accumulator charge; the board has no accumulator or load current measurement, since the 0x41 shunt R25 sees only the charger output.

Returns
Charger output current, in amperes (positive); 0 at night, until the first reading or below ~20 mA.

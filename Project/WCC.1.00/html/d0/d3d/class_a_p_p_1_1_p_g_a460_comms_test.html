Description

PGA460 UART link self-test singleton.

Every "PERIOD" it powers the 12 V rail, opens the UART, sends a "P1BL" burst command (as "DistanceMeter" does), waits the listen window, sends the "UMR" result request and checks that a 6-byte answer comes back with a valid checksum and the fixed 01b marker in the diagnostic byte. The PGA460 answers that request even when no transducer is connected, so this proves the supply, the UART wiring and the framing and does not need an echo. "DistanceMeter" must be disabled while this runs (both use the same UART). The counters and the last raw answer are kept for inspection with a debugger.

The state, the task and the helpers live in an "Impl" defined in "PGA460CommsTest.cpp".

enum class APP::PGA460CommsTest::Result : uint8_t
strong

Outcome of the last attempt.

Enumerator
RUNNING 

No attempt finished yet.

PASSED 

A valid answer was received.

OPEN_FAILED 

The UART did not open.

SEND_FAILED 

The request could not be sent.

NO_RESPONSE 

Not a single byte came back: no power, wrong wiring or wrong port.

SHORT_RESPONSE 

Some bytes came back but fewer than 6; see "getReceivedBytes()".

BAD_CHECKSUM 

An answer came back, but its checksum is wrong: noise, wrong baud rate or framing.

BAD_DIAGNOSTIC 

Checksum is right, but diagnostic bits 7:6 are not 01b.

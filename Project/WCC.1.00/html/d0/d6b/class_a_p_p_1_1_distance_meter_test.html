Description

Distance meter self-test singleton.

Runs once in its own task: waits for the start-up measurement of DistanceMeter, calls notifyDisposal() to trigger a second one AFTER_DISPOSAL_DELAY later, waits for it, and checks that both distances are valid, inside the sensor range and close to each other (the target must not move during the test). The result and both distances are kept for inspection with a debugger.

The state, the task and the helpers live in an Impl defined in DistanceMeterTest.cpp.

enum class APP::DistanceMeterTest::Result : uint8_t

Test steps; the result is the first step that failed.

Enumerator
RUNNING 

Not finished yet.

PASSED 

Every step passed.

NO_FIRST_RESULT 

The start-up measurement did not finish in time or gave no valid distance.

NO_SECOND_RESULT 

The measurement after notifyDisposal() did not finish in time or gave no valid distance.

OUT_OF_RANGE 

A distance is outside the sensor range (0.1..5 m).

UNSTABLE 

The two distances differ by more than 5 cm.

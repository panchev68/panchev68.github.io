Description

Distance meter self-test singleton.

Runs once in its own task: waits for the start-up measurement of APP::DistanceMeter, calls APP::DistanceMeter::notifyDisposal() to trigger a second one 'AFTER_DISPOSAL_DELAY' later, waits for it, and checks that both distances are valid, inside the sensor range and close to each other (the target must not move during the test). The result and both distances are kept for inspection with a debugger.

The state, the task and the helpers live in Impl, defined in 'DistanceMeterTest.cpp'.

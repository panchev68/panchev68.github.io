Description

Board inputs singleton.

Channels: "BUT1_SW", "BUT2_SW" (front-panel buttons); "SW_INP1", "SW_INP2" (magnetic door sensors).

The class only maps a channel to its pin and returns the raw pin level. The active level of a channel (which level means "pressed" or "door open") and the debouncing stay with the user.

The pins live in an "Impl" defined in "Inputs.cpp".

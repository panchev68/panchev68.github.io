HAL Namespace Reference
STM32F4xx_HAL_Driver » Hardware Abstraction Layer

Description

Concrete peripheral port instances, one function-local-static singleton per CubeMX handle.

Each port (HAL::I2CPort1, HAL::Usart1Port, HAL::Usart3Port, HAL::SPI3Port, HAL::DAC1Port, HAL::OSPI1Port, HAL::RTCPort, HAL::HashPort, ...) wraps the matching 'Lib::HAL' template over the 'extern "C"' handle generated into 'Core/'. Board Support Package and Application Layer use these instances instead of touching the CubeMX handles directly.

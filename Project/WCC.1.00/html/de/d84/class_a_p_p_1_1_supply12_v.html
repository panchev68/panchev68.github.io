Description

Reference-counted 12 V supply for the MT3608 booster, shared by the lock outputs and the PGA460.

The booster enable is 'V12_EN' on 'PA5' (active-high with a pull-down); the rail feeds the BTS724G 'Vbb' of the lock outputs and the PGA460 ultrasonic sensor 'VPWR'. The booster runs while at least one user holds it. acquire() waits SETTLE_TIME after switching it on, so the caller may load the rail right away; a user that joins while the booster is still settling waits for the remainder.

The enable pin, the user counter and the settle time stamp live in Impl, defined in 'Supply12V.cpp'.

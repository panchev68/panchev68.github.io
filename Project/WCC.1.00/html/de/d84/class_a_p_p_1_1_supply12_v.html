Description

Reference-counted 12 V supply singleton for the MT3608 booster (enable "V12_EN" on PA5, active-high with a pull-down), shared by the lock outputs (BTS724G Vbb) and the PGA460 ultrasonic sensor (VPWR).

Users are reference-counted: the booster runs while at least one user holds it. "acquire()" waits "SETTLE_TIME" after switching it on, so the caller may load the rail right away; a user that joins while the booster is still settling waits for the remainder.

The enable pin, the user counter and the settle time stamp live in an Impl defined in "Supply12V.cpp".

Description

Communication service that receives and sends framed messages over UART.

A background receiver task decodes frames according to Protocol (API mode 2, escaped) and delivers them to a consumer callback. Transmission is serialized by a mutex so multiple tasks may send concurrently.

bool ComService::sendFrame ( const Frame & frame)
nodiscardnoexcept

Encodes and sends a frame over UART.

Encoding happens outside the lock; only the transfer and the TX counter update are serialized.

Parameters
frameFrame to encode and send.
Returns
'true' on successful transmission, 'false' on lock timeout or UART failure.

◆ setOnErrorCallback()

void ComService::setOnErrorCallback ( ErrorCallback callback)
noexcept

Sets the callback invoked on error conditions.

The reference is non-owning: the bound callable must outlive the service. Set it before frames start arriving, since the receiver task reads it without locking.

Parameters
callbackFunction that receives an ErrorCode describing the fault.

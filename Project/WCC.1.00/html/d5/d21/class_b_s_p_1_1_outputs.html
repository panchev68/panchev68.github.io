Board outputs singleton. More...

Description

Board outputs singleton.

The class only maps a channel to its pin and writes the level. What the level means (a lock pulse) stays with the user of the channel. Every output is active-high.

Note
The 12 V switches need the booster, see APP::Supply12V.

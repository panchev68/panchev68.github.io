Description

Board outputs singleton: maps a Channel to its pin and writes the level.

What the level means (a lock pulse) stays with the user of the channel. Every output is active-high. The front-panel button LEDs are not 12 V switches, see BSP::ButtonLeds.

Note
The 12 V switches need the booster, see APP::Supply12V.

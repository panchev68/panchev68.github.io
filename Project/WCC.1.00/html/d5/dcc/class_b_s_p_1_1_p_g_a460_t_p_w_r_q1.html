Description

Project-level facade exposing the board PGA460 as a singleton bound to USART1.

The implementation and its usage guide live in the shared library as Lib::BSP::Ultrasonic::PGA460TPWRQ1; this class only supplies the board wiring: the sensor on USART1 with the factory UART address.

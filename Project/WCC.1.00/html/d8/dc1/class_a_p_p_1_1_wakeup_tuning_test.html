Description

Polls the ST25R100 wake-up (LPCD) registers into one Live Watch structure, to tune the wake-up threshold.

Every POLL_PERIOD it reads the raw wake-up registers and the lifetime min/max ADC range of BSP::ST25R100::instance() into APP::wakeupTuningWatch, so the threshold (BSP::ST25R100::Impl::WAKEUP_DIFF_THRESHOLD) can be picked from a measured margin between no card and a card at the wanted distance. The min/max fields change only when a wake-up interrupt fires; writing 1 to 'resetRangeRequest' clears them for a fresh run. The procedure is in 'doc/WakeupTuningTest.md'.

Runs in its own task, not an 'RTOS::TickClient' timer: reading the registers takes the reader's SPI mutex, which may block and would stall every software timer on the shared timer daemon task.

Important
Opens no reader and starts no discovery of its own: enable it alongside APP::RFIDCardTest or APP::RFID, and start it after that module in APP::Application::start().

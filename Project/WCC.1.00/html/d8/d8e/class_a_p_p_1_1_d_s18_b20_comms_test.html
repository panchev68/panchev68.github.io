Description

DS18B20 1-Wire link self-test singleton.

Opens the sensor like "ExternalThermometer" does ("BSP::DS18B20::instance().open()"), retrying every 2 s until a device answers a bus reset with a presence pulse. Then every 5 s it checks the presence pulse again and reads the temperature ("readTemperatureCelsius()", reset, Skip ROM, Convert T, scratchpad read with CRC-8 check): the driver itself validates the CRC, so a successful read already proves the 1-Wire timing and the pull-up are correct. The result additionally flags a reading outside the datasheet range (-55..125 C) and the DS18B20's own power-on default of +85.0 C (a read before the conversion finished, or a device that never started converting). "ExternalThermometer" must be disabled while this runs (both use the same pin). The result, the counters and the last temperature are kept for inspection with a debugger.

enum class APP::DS18B20CommsTest::Result : uint8_t
strong

Outcome of the last attempt.

Enumerator
RUNNING 

No attempt finished yet.

PASSED 

Presence pulse seen and a valid, plausible temperature was read.

OPEN_FAILED 

No presence pulse at start-up: check the DQ wiring, the pull-up and the level shifter.

NO_PRESENCE 

No presence pulse on a later attempt: the device stopped answering.

READ_FAILED 

Presence seen, but no scratchpad came back or its CRC-8 did not match.

OUT_OF_RANGE 

A valid, CRC-correct reading outside -55..125 C.

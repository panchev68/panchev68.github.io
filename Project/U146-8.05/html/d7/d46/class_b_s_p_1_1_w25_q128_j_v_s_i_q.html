BSP::W25Q128JVSIQ Class Reference

Description

Project-level adapter for the W25Q128JV SPI flash chip.

Inherits the API from the generic Lib::BSP::W25Q128JVSIQ implementation and configures it with the board-specific SPI handle and chip-select pin. Use instance() to access the global flash object.

USB::SerialPortRepeater Class Reference

Description

SerialPortRepeater class for USB serial port management.

The SerialPortRepeater class manages USB serial port repeater operations in the U146 embedded system. It provides a singleton interface for accessing USB port functionality, including opening/closing connections, power management, and module reset control. This class inherits from Lib::USB::SerialPortRepeaterBase and configures it with specific hardware pins for UART interfaces and control signals.

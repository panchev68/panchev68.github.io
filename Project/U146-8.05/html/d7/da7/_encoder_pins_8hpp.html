Description

EncoderPins header file for rotary encoder pin management.

This file defines the EncoderPins class which provides an interface for handling rotary encoder pins and button events in the Board Support Package (BSP). It includes configuration structures, event states, and methods for initializing, reading, and managing encoder interactions.

The EncoderPins class encapsulates functionality for rotary encoder inputs, supporting channel pins for rotation detection and button press events. It utilizes FreeRTOS queues for event buffering and provides interrupt-driven callbacks for efficient pin change handling.

Important dependencies include FreeRTOS for queue management, HAL/GPIO for pin operations, and Helper/Container for utility functions.

Ensure proper pin configuration and interrupt setup before instantiating EncoderPins objects. The class supports pulse division for sensitivity adjustment and reverse direction mapping.

This header file contains inline implementations for performance-critical embedded operations.

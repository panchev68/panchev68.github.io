Description

CAN Bus Server Base header file with template specialization.

Defines the Lib::Canbus::Service<Mode::SERVER> template specialization for CAN bus server base functionality. Provides virtual methods for starting, stopping, sending messages, diagnostics, and handling received messages. Includes scanning for active nodes and callback mechanisms for post-scan and task entry.

Depends on ServiceBase for core CAN functionality, Template.hpp for mode definitions, and HAL libraries.

Note
This is a template specialization providing the base interface for CAN bus servers.

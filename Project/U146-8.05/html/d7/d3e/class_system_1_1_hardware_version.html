System::HardwareVersion Class Reference

Description

Hardware version helper.

Singleton utility that provides access to the board hardware revision encoded by discrete GPIO pins and a human-readable profile name from the active hardware profile. Typical uses: logging, runtime diagnostics and selecting behavior based on board revision.

◆ readVersionId()

uint8_t System::HardwareVersion::readVersionId ( ) const
inline

Read the hardware revision identifier from the configured pins.

The board revision is encoded on four GPIO inputs HW_REV0..HW_REV3. Each pin is sampled (active low) and combined into a 4-bit value where HW_REV0 is the LSB and HW_REV3 the MSB.

Precondition
HW_REV0..HW_REV3 pins are configured as digital inputs with the expected pull resistors so that an open pin reads high.
Postcondition
Returns a value in the range [0, 15] representing the hardware revision bitfield.
Note
The inputs are read as active-low: a driven-low level maps to a logical 1 in the resulting bitfield.
Returns
4-bit revision identifier as uint8_t.

Obtain a human-readable name for the active hardware profile.

Returns the profile name provided by HardwareProfiles::Manager if available; otherwise returns the literal "UNKNOWN". Intended for use in logs, diagnostics and UI status lines.

Returns
Profile name or "UNKNOWN" when no name is set.

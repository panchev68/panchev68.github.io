Lib::Helper::DateTime::Date Class Referencefinal

Description

Represents a calendar date (day, month, year).

Encapsulates day, month, and year values with validation, comparisons, and formatting. Supports leap year calculation and day-of-week computation. All operations are exception-free for real-time use.

Lib::HAL::GPIO::Pin< Type::OUTPUT > Class Reference

Description

GPIO Output Pin Specialization Class.

This template specialization provides state writing and toggling for STM32 GPIO output pins. It supports flexible initialization and robust abstraction for digital output control, inheriting common functionality from the input pin base.

Note
  • Inherits from Pin<Type::INPUT> to reuse handle and configuration methods.
  • Provides write and toggle operations specific to output pins.
Important
  • Validate port pointer before operations to prevent undefined behavior.
  • Use appropriate GPIO modes for output reliability.
Template Parameters
Type::OUTPUTTemplate parameter indicating output pin type.
See also
Pin<Type::INPUT>, Handle, ModeSetter.

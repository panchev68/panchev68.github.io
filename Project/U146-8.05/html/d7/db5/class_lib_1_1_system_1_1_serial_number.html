Lib::System::SerialNumber Class Reference

Description

Serial number generator for U146 devices.

This class computes a unique 32-bit serial number by hashing the raw 12-byte STM32 unique ID. It exposes the value as a numeric uint32_t and as a formatted string. The computed value is stable for the lifetime of the instance.

Note
  • The serial number is derived directly from the STM32 UID for hardware uniqueness.
  • CityHash is used to generate a compact 32-bit identifier from the UID.
Important
  • The STM32 UID registers must be readable by the firmware for correct operation.

Lib::System::SerialNumber::SerialNumber ( )
inline

Construct and compute the serial number.

Reads the STM32 unique ID registers and computes the 32-bit serial number using the CityHash algorithm. Computation occurs once during construction and the result is stored in the instance.

Precondition
The STM32 UID_BASE registers must be accessible when invoked.
Postcondition
The result member contains the computed serial number.

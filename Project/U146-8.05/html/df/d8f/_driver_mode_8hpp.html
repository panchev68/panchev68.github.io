Description

Driver mode enumeration for HAL drivers.

Defines operational modes for hardware abstraction layer drivers, specifying how data transfer and communication are handled in embedded systems. This enumeration enables configuration of blocking, interrupt-driven, or DMA-based operations for efficient resource management.

Note
  • BLOCK mode provides synchronous operations with blocking behavior.
  • IT mode uses interrupts for asynchronous, non-blocking communication.
  • DMA mode leverages direct memory access for high-performance data transfers.
Important
  • Select mode based on application requirements for latency and throughput.
  • Ensure hardware support for chosen mode before configuration.
Warning
  • DMA mode may require specific memory alignment and buffer management.
  • Interrupt modes can impact real-time performance if not handled properly.
Attention
  • Validate mode compatibility with target hardware during initialization.
  • Monitor resource usage when switching between modes dynamically.

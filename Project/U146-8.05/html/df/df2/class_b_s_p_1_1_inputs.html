BSP::Inputs Class Reference

Description

Controller for reading inputs from daisy-chained SPI input devices.

The class performs SPI reads of chained input registers, converts the received byte sequence into a 64-bit bitmap and updates the global peripheral data store when the state changes.

void BSP::Inputs::handleInputDataChanged ( const uint64_t value)
inline

Preload the receive buffer with a provided bitmap.

This helper converts the provided 64-bit bitmap into the byte sequence expected in the receive buffer. It is useful for testing or for forcing a specific input state prior to calling update().

Parameters
value64-bit bitmap where bit 0 corresponds to the first input.

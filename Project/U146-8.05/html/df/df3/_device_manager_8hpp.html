Description

CAN Port Device Manager.

This file provides a singleton manager for CAN port devices in STM32 embedded systems. It handles device registration, callback management, and device removal for CAN peripherals. The manager ensures all supported HAL CAN callbacks are registered/unregistered for each device. It integrates with DeviceManagerBase for consistent device management across the HAL layer.

Note
  • Requires HAL_CAN_MODULE_ENABLED to be defined for compilation.
  • Uses singleton pattern for global access to CAN device management.
  • Automatically registers/unregisters HAL callbacks on device add/remove.
Important
  • Ensure HAL CAN callbacks are enabled (USE_HAL_CAN_REGISTER_CALLBACKS == 1).
  • Call add() to register devices and remove() to unregister.
  • Singleton instance is created on first access.
Warning
  • Improper callback management may lead to undefined behavior.
  • Ensure devices are properly initialized before adding.
Attention
  • This module is specific to STM32 microcontrollers with CAN support.
  • Requires proper HAL initialization before use.
  • Thread-safe for singleton access in FreeRTOS environment.

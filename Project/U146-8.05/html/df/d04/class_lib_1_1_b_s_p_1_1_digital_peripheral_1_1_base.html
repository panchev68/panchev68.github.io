Description

template<UpdateMode T_MODE>
class Lib::BSP::DigitalPeripheral::Base< T_MODE >

Base template class for digital peripheral management.

This template class provides a foundational abstraction for managing digital peripherals in the board support package. It supports two update modes: SEQUENTIAL for step-by-step processing with delays, and PARALLEL for concurrent input/output operations with timing measurements. The class integrates with FreeRTOS to run peripheral tasks in real-time, ensuring deterministic behavior under embedded constraints.

The class offers virtual methods for initialization, output control, and event handling, allowing derived classes to customize peripheral behavior while maintaining a consistent interface. It manages input and output ports, tracks tick counters, and provides hooks for pre- and post-processing callbacks.

Role within the system: Serves as the base class for all digital peripheral implementations, promoting code reuse and ensuring compliance with real-time requirements.

Important design decisions: Template-based mode selection for compile-time optimization, use of smart pointers avoided for real-time performance, assertions for error detection in debug builds.

Template Parameters
T_MODEThe update mode for the peripheral (SEQUENTIAL or PARALLEL).

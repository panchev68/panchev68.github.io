App::TestPeripheralOutputs Class Reference

Description

TestPeripheralOutputs class for managing peripheral output tests.

This class implements a test suite for peripheral outputs, providing methods to start, stop, and configure tests. It uses a singleton pattern to ensure only one instance exists and employs the PIMPL idiom for implementation hiding. The class handles periodic updates and event processing for testing digital outputs and related peripherals.

Note
  • Designed for use in embedded systems with FreeRTOS.
  • Integrates with peripheral management and event handling systems.
Important
  • Call start() before using test functionality.
  • Ensure stop() is called to clean up resources.
Warning
  • Not thread-safe; use appropriate synchronization in multi-threaded environments.
  • Modifying parameters during active tests may cause undefined behavior.
Attention
  • Monitor system performance during tests as they may impact real-time constraints.
  • Validate input parameters to prevent out-of-bounds access.

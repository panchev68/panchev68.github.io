Description

SPI flash support for board-level firmware.

This file provides the BSP-specific wrapper that constructs and exposes a singleton instance of the W25Q128JVSIQ SPI flash driver configured with the board's HAL SPI handle and chip-select pin. The wrapper is intended for use by higher-level storage subsystems such as file systems or firmware configuration managers and forwards operations to the library implementation while supplying board-specific resources.

Important responsibilities of this wrapper include ensuring the library driver receives the correct SPI_HandleTypeDef pointer and the correct chip-select (NSS) pin for the U146 board so that read, write and erase operations behave predictably on the on-board flash device.

Note
  • The wrapper constructs the driver with &hspi3 and the NSS pin defined by the PIN(FMEM_NSS) macro. Update the wrapper only if the SPI peripheral or board pinout changes.
See also
Lib::BSP::W25Q128JVSIQ for the library-level API and operation details.

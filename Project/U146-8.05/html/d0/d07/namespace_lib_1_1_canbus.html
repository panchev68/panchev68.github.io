Description

CAN bus communication namespace within the library.

This namespace contains components and utilities for CAN bus communication, including client and server service implementations, message handling, and diagnostic interfaces. It provides abstractions for initializing, configuring, and managing CAN bus operations in embedded systems.

enum class Lib::Canbus::Mode : uint8_t
strong

CAN bus operation mode enumeration.

This enum class defines the available operation modes for CAN bus services, allowing differentiation between client and server roles in the communication system. It uses uint8_t as the underlying type for efficient storage and compatibility.

The Mode enum is used to specify the behavior and interface of CAN bus services within the Lib::Canbus namespace, enabling type-safe configuration of client or server operations.

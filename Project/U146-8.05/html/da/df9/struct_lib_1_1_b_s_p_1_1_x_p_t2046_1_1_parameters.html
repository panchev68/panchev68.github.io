Lib::BSP::XPT2046::Parameters Struct Reference

Description

Touch screen parameters.

Holds calibration and display parameters for XPT2046 touch screen. Calibration values (xMin, xMax, yMin, yMax) map raw ADC readings to display coordinates (dispWidth, dispHeight). Rotation settings determine coordinate transformation based on display orientation. Debounce time prevents touch bouncing.

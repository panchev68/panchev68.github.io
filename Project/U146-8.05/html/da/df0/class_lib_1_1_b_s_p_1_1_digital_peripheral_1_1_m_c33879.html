Lib::BSP::DigitalPeripheral::MC33879 Class Reference

Description

MC33879 Motor Driver Control Class.

The MC33879 class encapsulates the functionality for controlling the MC33879 motor driver IC. It provides port definitions for status and control registers, enabling safe and efficient motor control operations in embedded systems.

Role of the type within the module or system: Serves as the primary interface for motor driver operations within the digital peripheral module, abstracting hardware details and providing a clean API for higher-level control logic.

Important design decisions or considerations: Uses constexpr for port definitions to ensure compile-time evaluation, avoiding runtime overhead and enabling optimization. The class is designed as a lightweight, header-only component suitable for resource- constrained environments.

Note
This class assumes proper SPI communication setup and hardware initialization before use. It does not handle low-level communication protocols.

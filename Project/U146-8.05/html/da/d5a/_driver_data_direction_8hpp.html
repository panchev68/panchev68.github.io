Description

Data direction enumeration for HAL drivers.

This file defines the DriverDataDirection enumeration, which specifies data transfer directions for hardware abstraction layer (HAL) drivers. It supports receive, transmit, and bidirectional modes, enabling clear specification of data flow in embedded communication interfaces.

Note
  • Values are bit flags that can be combined for bidirectional operations.
  • Used in driver configurations to specify supported directions.
Important
  • Ensure driver implementations support the specified directions.
  • Validate direction compatibility before operations.
Warning
  • Mismatched directions may cause communication failures.
  • Bidirectional flags should be checked for both RX and TX support.
Attention
  • Use bitwise operations to check or combine directions.
  • Document driver-specific direction limitations.

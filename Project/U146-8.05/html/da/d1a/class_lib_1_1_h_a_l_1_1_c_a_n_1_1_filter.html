Lib::HAL::CAN::Filter Class Reference

Description

CAN filter configuration class.

This class extends CAN_FilterTypeDef to provide type-safe, robust CAN filter setup and management. It encapsulates all filter parameters and provides methods for initialization, validation, and configuration. The class handles hardware-specific register encoding for CAN identifiers and masks.

Note
  • Inherits from CAN_FilterTypeDef for HAL compatibility.
  • Provides type-safe setters with validation.
  • Handles hardware register encoding automatically.
Important
  • Use constructors or setters to initialize filter parameters.
  • Call enable() to activate/deactivate the filter.
  • Use operator CAN_FilterTypeDef*() for HAL API compatibility.
Warning
  • Filter parameters must be set before activation.
  • Hardware encoding may vary between STM32 families.
Attention
  • Default constructor creates disabled filter.
  • Explicit constructor requires ID and optional mask.
  • Destructor is default and does not perform cleanup.

Constructs a default CAN filter (32-bit ID mask mode, all fields zeroed).

Creates a CAN filter with default settings: 32-bit ID mask mode, all identifiers and masks set to zero, assigned to FIFO0, bank 0, enabled, and slave start filter bank 0. This constructor provides a clean starting point for filter configuration.

Constructs a CAN filter with specified ID and mask (32-bit ID mask mode, default settings).

Creates a CAN filter with the specified identifier and mask, using 32-bit ID mask mode. Other settings are set to defaults: FIFO0 assignment, bank 0, enabled, slave start filter bank 0. The ID and mask are automatically encoded for hardware registers.

Parameters
idThe CAN identifier to filter (11-bit or 29-bit depending on CAN mode).
maskThe CAN identifier mask (default 0x1FFF'FFFF for 29-bit extended IDs).
Precondition
id must be a valid CAN identifier for the configured CAN mode.
Postcondition
Filter is configured with specified ID and mask, ready for activation.

Enables or disables the filter.

Sets the filter activation state to enable or disable CAN message filtering. When enabled, the filter will process incoming CAN messages according to its configuration. When disabled, the filter is bypassed and messages are not filtered.

Parameters
valueThe activation value: CAN_FILTER_ENABLE to enable, CAN_FILTER_DISABLE to disable.
Precondition
value must be either CAN_FILTER_ENABLE or CAN_FILTER_DISABLE.
Postcondition
Filter activation state is updated accordingly.

Sets CAN identifier for filter (hardware register encoding).

Sets the CAN identifier to filter and automatically encodes it for the STM32 CAN hardware registers. The encoding handles both standard (11-bit) and extended (29-bit) CAN identifiers. The identifier is split and stored in FilterIdHigh and FilterIdLow registers.

Parameters
idThe CAN identifier to set (11-bit or 29-bit depending on CAN mode).
Precondition

Postcondition
FilterIdHigh and FilterIdLow are updated with hardware-encoded values.

void Lib::HAL::CAN::Filter::setMode ( uint32_t mode)

Sets filter mode.

Sets the filter mode to either ID mask mode or ID list mode. In ID mask mode, the filter accepts messages where (received_id & mask) == (filter_id & mask). In ID list mode, the filter accepts messages that exactly match the filter ID.

Parameters
modeThe filter mode: CAN_FILTERMODE_IDMASK or CAN_FILTERMODE_IDLIST.
Precondition
mode must be either CAN_FILTERMODE_IDMASK or CAN_FILTERMODE_IDLIST.
Postcondition
FilterMode is updated with the specified value.

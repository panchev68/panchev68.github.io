BSP::Display Class Reference

Description

Display hardware abstraction class.

Provides a project-level singleton wrapper around the ILI9341 driver implementation. The class forwards display operations to the driver and integrates with the project Backlight controller for brightness control.

Returns a reference to the singleton instance. The instance is constructed on first use and remains valid for the application lifetime.

Set the display backlight level.

Overrides the base driver method and delegates brightness control to the project Backlight singleton.

Parameters

Precondition

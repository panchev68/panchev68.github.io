Lib::BSP::Display::Driver< Controller::ST7789 > Class Reference

Description

ST7789 Display Driver Class.

This class provides a concrete implementation of the DriverBase for ST7789 display controllers. It handles initialization, configuration, and data transmission to the display using SPI communication and GPIO control pins. The driver supports DMA-based pixel data transfer for efficient rendering.

Transmit a block of pixel data to the display.

Sets the display window to the specified position and size, then transmits the pixel data using DMA for efficient rendering. The data is sent in 16-bit format.

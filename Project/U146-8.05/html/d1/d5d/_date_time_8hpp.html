Description

Date and time management classes for embedded systems.

This file provides efficient, type-safe, allocation-free classes for representing and manipulating dates and times. Includes classes for managing dates, times, and combined DateTime values with comprehensive validation, comparison operations, formatting, and binary packing/unpacking for storage or transmission.

Note
  • All classes are designed for zero dynamic memory allocation.
  • All methods are noexcept for real-time safety.
  • Supports date validation, leap year calculation, and day-of-week computation.
  • Compact binary representation using bit-fields for efficient storage.
Important
  • Year range: 2000-2099 for storage efficiency.
  • All time values are validated at construction time.
  • No heap allocations in hot paths.

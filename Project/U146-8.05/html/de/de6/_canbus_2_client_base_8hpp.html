Description

ClientBase header file for CAN bus client services.

This file defines the ClientBase class, which is a specialization of the Service template for client mode in the CAN bus communication system. It provides the base functionality for CAN bus clients, including starting, stopping, sending messages, and handling diagnostics.

Important dependencies include ServiceBase.hpp for base service functionality, Template.hpp for template definitions, and standard libraries for types.

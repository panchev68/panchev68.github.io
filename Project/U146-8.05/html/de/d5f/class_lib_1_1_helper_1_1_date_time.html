Lib::Helper::DateTime Class Reference

Description

Manages date and time values for embedded systems.

This is the main DateTime class that combines Date and Time components. Provides validation, comparison operations, binary packing/unpacking, and formatting. All operations are exception-free and designed for embedded systems.

Lib::FreeRTOS::Queue Class Reference

Description

Queue class for managing FreeRTOS queues.

This class provides a C++ wrapper around FreeRTOS queue functionality, offering methods for queue creation, message sending and receiving, and queue management. It ensures RAII for resource management and provides type-safe interfaces for embedded systems.

The class supports both dynamic and static queue allocation, depending on FreeRTOS configuration.

Note
All methods assume the queue is properly created before use.
Attention
ISR methods should be used carefully to avoid blocking.

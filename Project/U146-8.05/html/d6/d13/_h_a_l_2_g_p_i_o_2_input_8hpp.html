Description

GPIO Input Pin Abstraction for STM32.

This file specializes the Pin template for input pins, providing type-safe reading and configuration of GPIO input state, mode, pull, and speed in STM32-based embedded systems. It enables efficient and safe GPIO input operations through a high-level interface.

Note
  • This specialization is designed for STM32 HAL and requires HAL_GPIO_MODULE_ENABLED.
  • The class inherits from Handle and ModeSetter for pin identification and configuration.
Important
  • Ensure GPIO ports are initialized before using input pins.
  • Use appropriate pull resistors and modes for reliable input reading.

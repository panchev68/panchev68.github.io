Lib::BSP::Display::Driver< Controller::ILI9341 > Class Referenceabstract

Description

Driver class for ILI9341 LCD controller.

This template specialization provides the implementation for driving the ILI9341 display controller, handling initialization sequences, pixel data transmission, and various display settings such as rotation and backlight.

The driver uses SPI for data communication and GPIO pins for control signals, ensuring efficient and reliable display operations in embedded systems.

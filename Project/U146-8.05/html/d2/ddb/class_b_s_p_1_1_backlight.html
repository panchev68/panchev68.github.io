BSP::Backlight Class Reference

Description

Backlight class for managing display backlight.

The Backlight class provides functionality to control display backlight brightness and fading. It inherits from Lib::BSP::Backlight and implements singleton pattern for global access.

This method provides global access to the single Backlight instance. The instance is created on first access and persists throughout the application lifetime.

Description

LED management for the U146 device.

Provides the BSP::Leds singleton which controls the ready and error LEDs. The class supports three states for each LED (OFF, ON, BLINKING) and implements periodic blinking via the tick() mechanism inherited from the device driver base.

The implementation uses GPIO pins for LED outputs and a simple software tick counter to derive blink timing. Use Leds::instance() to access the global manager and call init() during system startup to ensure LEDs are configured.

Note
  • Blinking timing is derived from FreeRTOS tick events; ensure the tick rate matches system expectations.
  • GPIO pin identifiers for default construction come from the project's board-level macros (e.g. PIN(LED_RDY)).
Important
  • This header only contains lightweight logic and must not assume the HAL peripheral state beyond GPIO availability.

Description

Base template for device managers in embedded systems.

This file defines the DeviceManagerBase template class, which provides a generic foundation for managing collections of device objects. It supports adding, removing, and retrieving devices by their handles, enabling flexible hardware abstraction and resource management in embedded environments.

Note
  • This is a template class requiring device and handle types.
  • Uses Lib::Helper::Container for underlying storage.
Important
  • Ensure device pointers are valid before adding.
  • Handle matching is done by pointer comparison.
Warning
  • Device pointers must remain valid during management.
  • Concurrent access may require external synchronization.
Attention
  • Derived classes should implement specific device logic.
  • Monitor container size for memory constraints.

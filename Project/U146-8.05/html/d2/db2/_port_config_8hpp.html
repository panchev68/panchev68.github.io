Description

PortConfig header file for digital peripheral configuration.

This file defines the PortConfig class, which holds configuration parameters for digital peripheral ports. It encapsulates settings such as SPI handles, NSS pins, and mapping fields required for port initialization and operation within the BSP layer.

The class provides a structured way to pass configuration data to port implementations, ensuring consistent setup across different digital peripherals.

Note
This class is used in conjunction with PortBase and its derived classes.
Attention
Ensure that all pointers are properly initialized before use to avoid null pointer dereferences.

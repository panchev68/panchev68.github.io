Description

GPIO Output Pin Abstraction for STM32.

This file specializes the Pin template for output pins, providing type-safe writing, toggling, and configuration of GPIO output state in STM32-based embedded systems. It enables robust digital output control through a high-level interface.

Note
  • This specialization inherits from Pin<Type::INPUT> for shared functionality.
  • Designed for STM32 HAL and requires HAL_GPIO_MODULE_ENABLED.
Important
  • Ensure GPIO ports are initialized before using output pins.
  • Use appropriate modes and speeds for reliable output operations.

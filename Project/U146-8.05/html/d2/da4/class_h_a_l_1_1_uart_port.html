HAL::UartPort Class Reference

Description

UART port manager.

Provides higher-level operations on top of the HAL UART handle such as blocking send/receive with timeout, baudrate accessors and event-based notifications. The class is intended to be referenced via the HAL handle by interrupt callbacks.

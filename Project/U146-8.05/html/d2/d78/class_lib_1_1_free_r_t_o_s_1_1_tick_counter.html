Lib::FreeRTOS::TickCounter Class Reference

Description

Tick Counter Class.

This utility class provides static methods to access the FreeRTOS tick counter. It offers methods for retrieving the current tick count from both task and ISR contexts. The class is designed as a static utility and cannot be instantiated.

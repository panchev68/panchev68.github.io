BSP::DigitalPeripheral Class Reference

Description

Digital peripheral manager class.

Coordinates the Inputs and Outputs subsystems, maps application data changes to hardware updates and runs a periodic task that performs SPI transfers. This class is the recommended single access point for all digital peripheral operations within the BSP layer.

◆ setup()

void BSP::DigitalPeripheral::setup ( )
inline

Initialize peripherals and start the update task.

Configures inputs and outputs, binds application data change callbacks to the respective handlers and starts a FreeRTOS task that calls taskEntry() periodically.

Precondition
  • The active hardware profile must contain valid pin and SPI handles.
  • The FreeRTOS scheduler must be available so tasks can be created.
Postcondition
  • inputs and outputs subsystems are configured and bound to application data callbacks.
  • A FreeRTOS task named "DigitalPeripheralTask" is started and will execute taskEntry().

Description

HAL wrapper for the Real-Time Clock peripheral.

Provides the hardware-specific integration layer between the CubeMX-generated RTC handle and the project's generic Lib::HAL::RTClock interface. The implementation is inline in this header and the class is exposed via a singleton accessor.

BSP::Beep Class Reference

Description

Audio beep manager.

Provides a project-level, singleton interface for simple beep sequences used for user notifications. The class inherits from Lib::BSP::Beep and supplies the HAL timer handle and channel required to generate PWM output.

Play a beep pattern.

Forward the request to the base class which performs timer-driven PWM to generate audible beeps. This wrapper simpl y exposes the API from the library on the project singleton.

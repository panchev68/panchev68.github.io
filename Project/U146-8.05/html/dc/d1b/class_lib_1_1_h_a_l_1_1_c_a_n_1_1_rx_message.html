Lib::HAL::CAN::RxMessage Class Reference

Description

Structure for CAN received messages.

This class encapsulates a received CAN message, including the header information from CAN_RxHeaderTypeDef and the data payload. It provides convenient access methods for retrieving message details.

Note
  • Inherits from CAN_RxHeaderTypeDef to access standard CAN header fields.
  • Data is stored in a fixed-size array of 8 bytes.
Important
  • Check DLC before accessing data to ensure valid length.
  • Use appropriate access methods for const-correctness.
Warning
  • Direct modification of data may corrupt message integrity.
  • Ensure thread-safety if used in multi-threaded contexts.
Attention
  • Validate message source and content for security.
  • Handle DLC values greater than 8 as per application requirements.
See also
CAN_RxHeaderTypeDef

GPIO pin template and type enumeration.

Defines a strongly typed enumeration for GPIO pin direction and a template class for pin abstraction. Enables type-safe GPIO pin configuration and usage in embedded systems.

Note
  • Type enum defines pin directions.
  • Pin template provides compile-time type safety.
Warning
  • Ensure correct type selection for pin function.
  • Template instantiation requires valid Type value.

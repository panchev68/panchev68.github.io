Description

Structure for CAN received messages.

This file defines the RxMessage class, which represents a received CAN message. It extends the CAN_RxHeaderTypeDef to include the message data payload. The class provides methods to access the message ID, length, and data. It is used in the CAN HAL layer for handling incoming messages from the CAN bus.

Note
  • The data array is fixed to 8 bytes, as per CAN standard.
  • The class inherits from CAN_RxHeaderTypeDef for header information.
Important
  • Ensure the DLC (Data Length Code) is valid before accessing data.
  • Data access methods return pointers; handle with care to avoid buffer overflows.
Warning
  • Modifying the data through non-const access may lead to undefined behavior.
  • Do not assume data beyond DLC is valid.
Attention
  • Use const methods for read-only access to prevent accidental modifications.
  • Validate message integrity before processing.

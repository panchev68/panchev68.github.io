Lib::HAL::GPIO::ModeSetter Class Reference

Description

GPIO Mode Setter Class.

The ModeSetter class is responsible for setting the mode, pull resistor, speed, and alternate function of GPIO pins. It uses the STM32 HAL GPIO initialization structure to configure pins safely and consistently. This class provides a high-level interface for GPIO pin configuration in embedded systems.

Note
  • Encapsulates GPIO initialization logic.
  • Ensures type-safe configuration using enums.
Warning
  • Validate pin availability before use.
  • Monitor for HAL errors during initialization.

Set GPIO Pin Mode.

Configures a GPIO pin with the specified mode, pull resistor, speed, and alternate function. This method initializes the GPIO pin using the STM32 HAL GPIO_Init function with the provided parameters. It ensures proper pin configuration for various GPIO operations in embedded applications.

Parameters
portPointer to the GPIO port (e.g., GPIOA, GPIOB).
pinNumPin number to configure (0-15 for standard GPIO ports).
modeGPIO mode (INPUT, OUTPUT, ALTERNATE, ANALOG).
pullPull resistor configuration (NOPULL, PULLUP, PULLDOWN).
speedGPIO speed (LOW, MEDIUM, HIGH, VERY_HIGH).
alternateAlternate function number (0-15) for alternate mode.
Note
  • Default values provided for optional parameters.
  • Uses HAL_GPIO_Init for hardware configuration.
Warning
  • Ensure port clock is enabled.
  • Invalid parameters may cause HAL errors.

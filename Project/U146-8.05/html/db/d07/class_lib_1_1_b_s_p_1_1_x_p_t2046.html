Lib::BSP::XPT2046 Class Reference

Description

XPT2046 touch screen controller driver.

Provides touch detection, position calculation, debouncing, and rotation handling for XPT2046-based touch screens. Integrates with FreeRTOS for asynchronous touch processing via a dedicated task. Implements SPI communication through GPIO bit-banging and includes calibration for accurate coordinate mapping.

Note
Coordinates are calibrated and may be rotated based on display orientation.
Attention
Ensure proper pin configuration and calibration before use.

Checks if touch is pressed with debounce filtering.

Monitors the interrupt pin (NIRQ) to detect touch pressure while applying debounce filtering. Prevents false touch detection from electrical noise or contact bouncing.

Returns
true if touch is pressed and debounce timer has elapsed, false otherwise.
Note
Debounce time is configured in parameters; zero disables debouncing.

Initializes the driver and starts touch processing task.

Sets up the XPT2046 touch controller hardware and starts a FreeRTOS task for asynchronous touch sampling. The task runs independently and updates touch position continuously.

Precondition
GPIO pins must be configured; sampleTouch() will return false until touch is detected.
Postcondition
Touch processing task is running and monitoring for touch events.
Note
Task creation failure will trigger an assertion; ensure sufficient heap and task memory.

Reads a 12-bit ADC value from the XPT2046 controller.

Sends an SPI command to read ADC data, manages chip select and clock lines, and receives the 16-bit ADC response (with 4-bit shift). Used to sample X and Y position coordinates.

Writes a byte to the XPT2046 controller via SPI bit-banging.

Transmits a single byte using GPIO pins (SI and SCK) for serial communication. Each bit is shifted out starting with MSB, with clock pulses between transitions.

Parameters
dataByte value to transmit to the controller.
Note
Uses GPIO pin manipulation with NOP delays for timing; blocking operation.

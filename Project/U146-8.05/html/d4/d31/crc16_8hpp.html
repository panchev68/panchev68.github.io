Description

CRC16 checksum calculation utility for embedded systems.

This file provides an efficient CRC16-CCITT (0x1021, MSB-first) calculator for data blocks in embedded systems. It supports input from raw pointers and std::vector, designed for minimal overhead and real-time use. The implementation ensures type safety, performance optimization, and compliance with MISRA C++ standards.

Note
  • Optimized for embedded environments with limited resources.
  • Uses fixed-width integer types for portability and safety.
  • Assertions are used for debug builds to validate preconditions.
Important
  • Ensure data buffers are valid and non-null before construction.
  • The CRC calculation is MSB-first with polynomial 0x1021.

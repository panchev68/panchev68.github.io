Lib::Helper::BitArray< T, T_SIZE > Class Template Reference

Description

template<typename T, size_t T_SIZE = (sizeof(T) * 8U)>
class Lib::Helper::BitArray< T, T_SIZE >

Template class for bit array operations.

Provides a wrapper around std::bitset for safe and convenient bit-level operations on integral types with compile-time size checking.

Template Parameters
TThe underlying integral type for bit operations.
T_SIZEThe number of bits in the array, defaults to the size of T in bits.

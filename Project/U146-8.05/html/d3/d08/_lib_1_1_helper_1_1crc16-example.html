Lib::Helper::crc16

Example usage of CRC16 calculator.

This example demonstrates how to use the crc16 class to compute CRC16 checksums for data blocks using both raw pointers and std::vector inputs.

Example usage:
#include <Lib/Helper/crc16.hpp>
#include <vector>
#include <iostream>
int main() {
std::vector<uint8_t> bytes = {1, 2, 3, 4, 5, 6};
Lib::Helper::crc16 calc1(bytes.data(), bytes.size());
uint16_t result1 = calc1;
std::cout << "CRC from pointer: " << result1 << std::endl;
Lib::Helper::crc16 calc2(bytes);
uint16_t result2 = calc2;
std::cout << "CRC from vector: " << result2 << std::endl;
return 0;
}

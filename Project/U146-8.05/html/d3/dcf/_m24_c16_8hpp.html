Description

M24C16 EEPROM Driver Header File.

This header file defines the M24C16 EEPROM driver class, which provides an interface for reading and writing to M24C16 I2C EEPROM devices. It inherits from DriverBase and implements 8-bit addressing mode for the 2KB EEPROM chip with 16-byte page size.

The driver supports standard EEPROM operations including open/close, read/write, and chip size retrieval, optimized for the M24C16 device specifications.

Note
This driver is designed for embedded systems using FreeRTOS and HAL libraries.
Attention
Ensure proper I2C configuration and M24C16 device connections before use.

Description

Buffer and StaticBuffer classes for safe, efficient byte buffer management.

This file provides Buffer for dynamic/external byte buffers and StaticBuffer for fixed-size stack buffers, supporting copy/move semantics and memory clearing for embedded systems. The Buffer class manages memory ownership and provides safe access to byte data, while StaticBuffer offers stack-based fixed-size buffers.

Note
  • Buffer supports both owned (dynamically allocated) and external (non-owned) memory.
  • StaticBuffer uses std::array for stack allocation, avoiding heap usage.
  • All operations include bounds checking and memory safety features.

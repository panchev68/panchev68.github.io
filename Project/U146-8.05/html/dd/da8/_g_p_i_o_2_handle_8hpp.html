Description

GPIO Pin Handle Abstraction for STM32.

This file provides a lightweight, type-safe mechanism for identifying and referencing GPIO pins using a port pointer and pin number. It encapsulates GPIO port and pin information in a simple class structure to ensure safe and efficient GPIO operations in embedded systems.

Note
  • This abstraction is designed for STM32 microcontrollers and relies on STM32 HAL definitions.
  • The Handle class does not own the GPIO port; it only references it for identification purposes.
Important
  • Ensure that the GPIO port pointer is valid and initialized before using the Handle.
  • Pin numbers should be within the valid range for the specific STM32 device (typically 0-15).

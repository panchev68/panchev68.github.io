System::LastResetState Class Reference

Description

Last reset state management class.

Singleton that exposes the device's last reset state at the System level. The class inherits from Lib::HAL::LastResetState and re-uses the HAL implementation while providing a single global access point for consumers.

Note
  • The class uses the Meyers singleton pattern via instance().

◆ ProduceDateBase

using System::ProduceDateBase = Lib::System::ProduceDate

Alias for the library production date type.

Using this alias, code inside the System namespace can refer to the production date type as ProduceDateBase instead of Lib::System::ProduceDate. This improves readability and decouples call sites from the external namespace qualifier.

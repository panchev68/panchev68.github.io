ModelUsb

Using ModelUsb to check USB power status and control module reset.

This example demonstrates how to use the ModelUsb class in a TouchGFX application to query the USB power state and control the module reset pin. The ModelUsb class provides a hardware-agnostic interface for USB-related operations, ensuring safe and maintainable interaction with USB components in embedded STM32 applications.

Example usage:
#include "ModelUsb.hpp"
// In a TouchGFX model or presenter context
ModelUsb usbModel;
// Check if the device is powered by USB
bool isPowered = usbModel.isPoweredByUSB();
if (isPowered) {
// Perform USB-powered specific actions
// For example, update UI to show USB power indicator
} else {
// Handle battery or other power source
}
// Control the module reset pin, e.g., for error recovery
usbModel.setModuleResetPin(true); // Assert reset
// Perform reset-related operations
usbModel.setModuleResetPin(false); // Deassert reset

Lib::HAL::Watchdog Class Reference

Description

Watchdog class for managing Independent Watchdog Timer (IWDG).

This class provides an object-oriented interface to the STM32 IWDG peripheral, allowing for easy setup, refresh, and mode detection of the watchdog timer. It supports both software and hardware triggered watchdog modes.

Note
The watchdog must be refreshed periodically to prevent system reset.
Important
Initialize the watchdog handle before using any methods.
Warning
Do not use in interrupt service routines without careful consideration.
Attention
Ensure HAL_IWDG_MODULE_ENABLED is defined for proper operation.

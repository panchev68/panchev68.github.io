◆ Mode

enum class Lib::HAL::GPIO::Mode
strong

GPIO mode enumeration.

Available STM32 GPIO modes for pin configuration: input, push-pull output, and open-drain output.

Note
  • INPUT: Read digital signals from external sources.
  • OUT_PP: Drive loads with push-pull output.
  • OUT_OD: Open-drain output for bus interfaces.
Warning
  • Open-drain mode requires external pull-up resistor.
  • Incorrect mode may cause short circuits.

enum class Lib::HAL::GPIO::Pull

GPIO pull-up/pull-down enumeration.

STM32 GPIO pull resistor configuration: no pull, pull-up, or pull-down.

Note
  • NOPULL: No internal resistor, floating input.
  • PULLUP: Internal pull-up resistor to VDD.
  • PULLDOWN: Internal pull-down resistor to GND.
Warning
  • External resistors may conflict with internal pull.
  • Incorrect pull may cause unexpected behavior.

enum class Lib::HAL::GPIO::Speed
strong

GPIO speed enumeration.

STM32 GPIO output speed levels: low, medium, high, or very high frequency.

Note
  • LOW: Minimum speed, lowest power consumption.
  • MEDIUM: Balanced speed and power.
  • HIGH: High speed for performance-critical applications.
  • VERY_HIGH: Maximum speed, highest power consumption.
Warning
  • Very high speed may cause signal integrity issues.
  • Ensure adequate decoupling capacitors.

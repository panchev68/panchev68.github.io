Description

Base class for CAN port management in the HAL layer.

This file defines the PortBase class, which provides a foundational interface for managing CAN (Controller Area Network) ports in embedded systems. It encapsulates the initialization, operation, and communication handling for CAN peripherals, integrating with FreeRTOS for real-time task management. The class offers methods for opening and closing the CAN port, sending and receiving messages, configuring filters, and handling callbacks for various CAN events. It serves as a base for derived classes that may implement specific CAN functionalities or extend the basic operations.

Note
  • This class is designed for use in embedded environments with FreeRTOS.
  • Ensure that the CAN peripheral is properly initialized before using instances of this class.
Important
  • The class uses FreeRTOS primitives for synchronization and task management, so it must be used in a FreeRTOS context.
  • Callbacks are invoked from interrupt context, so they should be kept short and avoid blocking operations.
Warning
  • Improper use of CAN filters or message handling can lead to data loss or system instability.
  • Ensure thread-safety when accessing shared resources in derived classes.
Attention
  • Monitor error callbacks for CAN-related faults and handle them appropriately in the application.
  • Validate message data lengths and IDs to prevent buffer overflows or invalid operations.

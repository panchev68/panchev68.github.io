Description

Hardware Abstraction Layer namespace within the library.

This namespace contains hardware abstraction components and utilities for various peripherals, providing a consistent interface for interacting with microcontroller hardware. It includes drivers and abstractions for UART, SPI, I2C, and other communication interfaces.

◆ DriverDataDirection

enum Lib::HAL::DriverDataDirection

Data direction enumeration for drivers.

Represents possible data transfer directions for hardware drivers, enabling clear specification of receive, transmit, or bidirectional data flow in embedded communication interfaces.

Note
  • RX_TX combines RX and TX flags for convenience.
  • Values are designed for bitwise operations.
Important
  • Use these flags to configure driver behavior.
  • Check driver documentation for supported directions.
Warning
  • Ensure hardware supports the selected direction.
  • Invalid directions may result in undefined behavior.
Attention
  • Bidirectional implies both RX and TX capabilities.
  • Validate direction before driver initialization.
Enumerator
RX 0x01 

Receive direction.

TX 0x02 

Transmit direction.

RX_TX 0x03 

Bidirectional (receive and transmit).

◆ DriverMode

enum Lib::HAL::DriverMode

Driver mode enumeration for HAL drivers.

Specifies the operational modes for HAL drivers, controlling data transfer mechanisms and synchronization approaches in embedded communication interfaces.

Note
  • BLOCK: Synchronous blocking operations.
  • IT: Interrupt-driven asynchronous operations.
  • DMA: Direct memory access for high-speed transfers.
Important
  • Choose mode based on performance and resource constraints.
  • Validate hardware capabilities before mode selection.
Warning
  • DMA requires proper buffer alignment and management.
  • Interrupt modes may affect system responsiveness.
Attention
  • Ensure mode is set during driver initialization.
  • Test mode switching in development environments.
Enumerator
BLOCK 

Blocking mode for synchronous operations.

IT 

Interrupt mode for asynchronous operations.

DMA 

DMA mode for high-performance data transfers.

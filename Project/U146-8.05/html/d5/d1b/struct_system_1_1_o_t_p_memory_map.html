System::OTPMemoryMap Struct Reference

Description

Packed structure matching the OTP memory layout for production/sale dates and related fields.

The structure is packed to guarantee a predictable memory layout that corresponds directly to the on-device OTP storage. Field formats (timestamp format, encoding, endianness) are board-specific — consult the platform/HAL documentation for exact encoding details.

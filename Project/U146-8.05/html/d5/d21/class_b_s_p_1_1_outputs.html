BSP::Outputs Class Reference

Description

Driver for a set of digital outputs connected through SPI daisy-chains.

The Outputs class accepts an SPI port reference and control pins for chip-select (NSS) and output-enable (OE). Use setup() to configure GPIO lines and open the SPI interface, then update the outputs by calling handleOutputDataChanged() followed by update() to transmit the new state to the hardware.

Notify the driver that the logical output bitmap has changed.

Store the new 64-bit bitmap; calling update() will transmit the updated state to the hardware. The method does not perform the transmission itself.

Parameters
value64-bit bitmap where bit i corresponds to output index i (LSB = index 0).
Postcondition
  • outputData is updated to contain the provided bitmap value.

◆ setup()

void BSP::Outputs::setup ( )
inline

Configure GPIO pins and open the SPI port.

This prepares the NSS and OE pins and opens the configured SPI master port. It must be called before performing update().

Precondition
  • spiPort must point to a valid SPI master port pointer. The caller must ensure that the pointer and the referenced object are valid before calling this method.
Postcondition
  • The SPI port is opened and configured for transfers. The NSS and OE pins are configured as outputs and driven high (disabled state) after setup completes.

◆ update()

void BSP::Outputs::update ( )
inlinenoexcept

Build the transmit buffer and send it to the daisy-chained devices.

The method translates the current outputData bitmap into the device-specific precode bytes, transmits them over SPI and updates the internal error state based on the received response.

Precondition
  • setup() has been called and the SPI port is open. spiPort and the underlying handle must be valid before invoking this method.
Postcondition
  • isError is updated to reflect whether the device response matched the expected daisy-chain markers. The NSS line is released (driven high) when the transfer completes.

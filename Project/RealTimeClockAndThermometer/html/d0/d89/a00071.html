Detailed Description

Display driver class for ILI9341-based displays.

This class provides a high-level interface for controlling ILI9341 TFT displays, including communication, chipset initialization, backlight control, and data transmission. It inherits from RTOS::TickService::ClientBase to handle periodic tick events.

The driver supports DMA-based data transfer for efficient display updates and integrates with FreeRTOS for real-time operation.

Note
This class is a singleton; use instance() to access the global instance.

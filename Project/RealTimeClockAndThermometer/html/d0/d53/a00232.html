Detailed Description

Clock container class for TouchGFX GUI.

This class represents a clock widget in the TouchGFX user interface, allowing users to view and adjust time settings through scroll wheels for hours and minutes. It provides methods for setting time values, handling touch events, and controlling visibility of UI elements like decimal points.

Note
Inherits from ClockBase, which is auto-generated by TouchGFX Designer.

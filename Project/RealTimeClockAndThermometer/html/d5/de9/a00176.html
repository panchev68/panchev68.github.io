Detailed Description

RealTimeClock class for STM32F407ZET6 RTC HAL operations.

This class provides a singleton wrapper around the Lib::HAL::RealTimeClock for managing real-time clock operations on the STM32F407ZET6 microcontroller. It handles date and time reading/writing, register access, and timestamp event callbacks. The class is designed as a final class to prevent inheritance and ensures thread-safe access through the singleton pattern.

Key responsibilities:

  • Provide global access to RTC via singleton instance.
  • Override base class methods for date/time operations.
  • Manage register read/write for low-level control.
  • Handle timestamp events with user-defined callbacks.
Note
Inherits from Lib::HAL::RealTimeClock and uses FreeRTOS-compatible operations.

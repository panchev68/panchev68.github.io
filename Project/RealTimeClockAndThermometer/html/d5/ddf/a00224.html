Detailed Description

FrontendApplication class.

The FrontendApplication class represents the main application logic for the TouchGFX frontend. It handles tick events, manages the interaction between the model and the UI, and oversees the application's lifecycle. Inherits from FrontendApplicationBase to provide base application functionality.

Role of the type within the module or system: Serves as the central controller for the TouchGFX application, coordinating model updates and UI events.

Important design decisions: Uses references to model and heap for efficient resource management. Overrides handleTickEvent to integrate model ticking with base event handling.

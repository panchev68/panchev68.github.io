Detailed Description

MoonPhase class.

This class represents a moon phase display container in the TouchGFX GUI, used for showing the current moon phase using bitmap images. It supports setting the phase index to display the appropriate moon phase image, from new moon to full moon. The class provides methods for initialization and phase updating, ensuring proper integration with the GUI framework.

Role of the type within the module or system: Acts as a UI component for moon phase visualization in the clock and thermometer application, enhancing user experience with astronomical data.

Important design decisions or considerations: Uses a fixed array of bitmaps for efficiency, assumes phase index validation is handled externally to maintain performance in embedded systems.

Note
Inherits from MoonPhaseBase for base container functionality.

void MoonPhase::setPhase ( uint8_t phase)

Set the moon phase.

Updates the moon phase image displayed in the container by selecting the appropriate bitmap based on the provided phase index. The phase index corresponds to different stages of the moon, from new moon (0) to full moon and back. This method triggers a redraw of the container to reflect the new phase.

Parameters
phaseThe phase index (0-7) corresponding to the desired moon phase image.
Precondition
The phase index must be between 0 and 7 inclusive.
Postcondition
The moon phase image is updated and the container is invalidated for redraw.
Note
Out-of-range indices may cause undefined behavior or crashes.

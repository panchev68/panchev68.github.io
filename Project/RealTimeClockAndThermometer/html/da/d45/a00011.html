Detailed Description

Display Driver Header File

This header file defines the DisplayDriver class and its nested classes for managing ILI9341-based displays. It provides interfaces for communication, chipset control, and backlight management in the STM32F407ZET6-EVB project.

Important dependencies include HAL drivers for DMA and TIM, RTOS for task management, and ILI9341 register definitions.

Note
Ensure proper initialization of HAL handles before using the driver.
Attention
This driver is designed for embedded systems and may not be suitable for other platforms.

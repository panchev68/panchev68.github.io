Detailed Description

Header file for the MoonPhase container class.

This file defines the MoonPhase class, which is a TouchGFX container responsible for displaying the current moon phase in the clock and thermometer application. The class manages moon phase images based on a phase index, providing methods to initialize the container and update the displayed phase. It inherits from MoonPhaseBase and integrates with the TouchGFX framework for GUI rendering and bitmap handling.

Important dependencies include MoonPhaseBase.hpp for base container functionality, and interactions with TouchGFX for image display and GUI updates.

Any special instructions or notes for users of the file: Ensure the phase index passed to setPhase is within the valid range (0-7) to avoid out-of-bounds errors.

Note
This class assumes the moon phase index is validated externally.
Attention
Invalid phase indices may lead to undefined behavior or crashes.

Detailed Description

ModelClock class for managing clock model in TouchGFX.

This class encapsulates the logic for handling time and date updates in the TouchGFX application. It interacts with the real-time clock hardware to read and write time and date, calculates moon phases, and notifies listeners of changes.

Note
Uses a listener pattern for event notifications.

void ModelClock::handleTickEvent ( Listener * listener)
inline

Handles tick events to update time and date.

This method is called periodically to check for updates in time and date. It reads the current date and time from the RTC, updates the moon phase, and notifies the listener if seconds or day have changed.

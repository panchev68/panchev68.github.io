Detailed Description

Thermometer class for temperature and humidity sensing.

This class provides a high-level interface for interacting with a DTH22 temperature and humidity sensor. It implements a singleton pattern to ensure only one instance exists, which is suitable for embedded systems where resource management is critical. The class applies configurable offsets to temperature and humidity readings to allow for calibration. It integrates with FreeRTOS for timing and uses HAL for hardware abstraction.

Role of the type within the module or system: Acts as the BSP layer for thermometer functionality, abstracting sensor-specific details from higher-level application code.

Important design decisions or considerations: Singleton pattern for global access, final class to prevent inheritance, private constructor to enforce singleton, and offset adjustments for sensor calibration.

Note
This class is not thread-safe for multiple concurrent accesses; use from a single task or protect with mutexes.
Attention
Ensure proper initialization before use.
See also
Lib::BSP::Thermometer::DTH::DTH22 for the underlying sensor implementation.

Get the current humidity reading.

Retrieves the latest humidity measurement from the DTH22 sensor, adjusted by the configured humidity offset. The humidity is returned as a percentage (0.0 to 100.0).

Returns
The adjusted humidity value as a percentage.
Note
This method does not trigger a new measurement; it returns the last valid reading.

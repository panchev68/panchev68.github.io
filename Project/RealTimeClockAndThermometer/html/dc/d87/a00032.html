Detailed Description

STM32F407ZET6-EVB-ClockAndThermometer RealTimeClock HAL wrapper header file.

This file provides a hardware abstraction layer (HAL) wrapper for the Real-Time Clock (RTC) functionality on the STM32F407ZET6 evaluation board. It encapsulates the low-level RTC operations, providing a clean interface for reading and writing date and time, managing registers, and handling timestamp events. The implementation ensures thread-safety and integrates with the FreeRTOS environment.

Key features include:

  • Singleton pattern for global access to RTC instance.
  • Override methods for reading/writing date and time.
  • Register-level access for advanced configurations.
  • Callback mechanism for timestamp events.

Dependencies: Relies on STM32 HAL library for RTC operations and Lib::HAL::RealTimeClock for base functionality.

Note
This header is part of the HAL module and should be included only where RTC operations are required.
Attention
Ensure proper initialization of the RTC peripheral before using this class.

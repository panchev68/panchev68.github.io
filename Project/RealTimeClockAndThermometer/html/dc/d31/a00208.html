Detailed Description

ModelThermometer class for managing thermometer model in TouchGFX.

This class encapsulates the logic for handling temperature and humidity readings in the TouchGFX application. It monitors changes and notifies listeners when values update beyond a threshold.

Note
Uses a listener pattern for event notifications and epsilon-based change detection.

void ModelThermometer::handleTickEvent ( Listener * listener)
inline

Handles tick events to update temperature and humidity.

This method is called periodically to check for changes in temperature and humidity. It reads the current values from the thermometer hardware and notifies the listener if changes exceed the epsilon threshold or on first update.

Parameters
listenerPointer to the listener to notify. Must not be nullptr.

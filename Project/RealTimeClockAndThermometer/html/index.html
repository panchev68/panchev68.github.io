STM32F407ZET6 Clock and Thermometer Firmware Project

Overview

Welcome to the STM32F407ZET6 Clock and Thermometer Firmware Project! This embedded software application provides a comprehensive solution for displaying time and environmental data on an STM32F407ZET6 evaluation board.

The project combines real-time clock functionality with temperature and humidity sensing capabilities, presented through an intuitive TouchGFX-based graphical user interface. Built with modern C++17 standards and following MISRA C++ guidelines, this firmware demonstrates best practices for embedded system development.

Key Features

⏰ Real-Time Clock

  • Accurate timekeeping with hardware RTC
  • Multiple time format support
  • Alarm and timer functionality
  • Battery-backed time retention

🌡️ Environmental Monitoring

  • Temperature and humidity sensing using DTH22 sensor
  • Configurable calibration offsets
  • Real-time data display
  • Sensor health monitoring

🎨 User Interface

  • TouchGFX-based graphical interface
  • Intuitive navigation and controls
  • Real-time data visualization
  • Responsive touch interactions

🔧 Technical Architecture

Hardware Platform

  • Microcontroller: STM32F407ZET6 (ARM Cortex-M4)
  • Display: TFT LCD with touch capability
  • Sensors: DTH22 temperature and humidity sensor
  • Real-Time Clock: Hardware RTC with backup battery

Software Stack

  • RTOS: FreeRTOS for task management
  • GUI Framework: TouchGFX for user interface
  • HAL: STM32 HAL for hardware abstraction
  • Language: C++17 with MISRA C++ compliance
  • Build System: IAR Embedded Workbench

Project Structure

📁 Core Modules

BSP (Board Support Package)

The BSP namespace provides hardware abstraction and driver implementations:

  • Thermometer Module (BSP::Thermometer): Singleton class for temperature and humidity sensing
  • Display Module: TouchGFX integration and LCD control
  • RTC Module: Real-time clock management and alarm functionality

  • Clock Application: Time display, setting, and alarm management
  • Thermometer Application: Environmental data acquisition and display
  • UI Components: TouchGFX screens and widgets for user interaction

Getting Started

Prerequisites

  • STM32F407ZET6 evaluation board
  • IAR Embedded Workbench (latest version)
  • TouchGFX (compatible version)
  • DTH22 temperature/humidity sensor
  • USB cable for programming and debugging

Building the Project

  1. Clone the repository:
    git clone https://github.com/panchev68-MyProjects/STM32F407ZET6-EVB-ClockAndThermometer.git
    cd STM32F407ZET6-EVB-ClockAndThermometer
  2. Open in IAR Embedded Workbench:
    • Launch IAR Embedded Workbench
    • Open workspace file: Project/STM32F407ZET6-EVB-ClockAndThermometer.eww
  3. Configure TouchGFX:
    • Open TouchGFX Designer
    • Load project from TouchGFX/
    • Generate code for target platform
  4. Build and Flash:
    • Build the project in IAR
    • Connect STM32 board via USB
    • Flash the generated binary

Hardware Setup

  1. Connect DTH22 Sensor:
    • VCC → 3.3V
    • GND → GND
    • DATA → GPIO pin (configured in BSP)
  2. RTC Battery:
    • Install CR1220 battery for time retention
  3. Display Connection:
    • Ensure TFT display is properly connected to STM32 pins

API Reference

Core Classes

  • BSP::Thermometer: Main interface for temperature and humidity sensing
    • Thermometer::instance() - Get singleton instance
    • getTemperature() - Read temperature in °C
    • getHumidity() - Read humidity in %
    • setTemperatureOffset() - Calibrate temperature readings
    • setHumidityOffset() - Calibrate humidity readings

Key Functions

  • Clock Management: Time setting, alarm configuration, and display formatting
  • Sensor Interface: Data acquisition, calibration, and error handling
  • UI Controls: Screen navigation, touch input processing, and data visualization

Troubleshooting

Common Issues

  1. Sensor Not Responding
    • Check DTH22 wiring connections
    • Verify GPIO pin configuration
    • Ensure proper power supply (3.3V)
  2. Display Not Working
    • Verify TouchGFX project settings
    • Check LCD connections
    • Confirm SPI/I2C configuration
  3. RTC Time Resetting
    • Check backup battery installation
    • Verify RTC crystal oscillator
    • Confirm power management settings

Debug Information

  • Use IAR C-SPY debugger for real-time debugging
  • Monitor FreeRTOS task states
  • Check sensor communication logs

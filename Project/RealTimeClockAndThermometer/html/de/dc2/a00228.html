Detailed Description

FrontendHeap class.

The FrontendHeap class handles the memory allocation for user-defined and generated types in TouchGFX, including views, presenters, and transitions. It uses a singleton pattern for instance management and partitions memory for efficient allocation.

Role of the type within the module or system: Provides centralized memory management for the TouchGFX frontend, ensuring proper allocation and deallocation of UI components.

Important design decisions: Uses meta-programming for type size calculations and partitions for memory pools. Singleton ensures single instance across the application.

Detailed Description

Frontend Application Header File.

This file defines the FrontendApplication class, which manages the application's lifecycle, handles tick events, and interacts with the model and heap in the TouchGFX GUI framework. The application coordinates between the model for data and the UI for presentation.

Important dependencies include FrontendApplicationBase for base functionality and FrontendHeap for memory management. Interactions with the Model for data updates and with TouchGFX framework for event handling.

Note
This class is the entry point for the TouchGFX application logic.
Attention
Ensure that the model and heap are properly initialized before creating this application.

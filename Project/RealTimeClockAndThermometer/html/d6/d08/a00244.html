Detailed Description

Digit2 container class for displaying two-digit values.

The Digit2 class provides functionality for displaying and setting a two-digit numerical value in the TouchGFX GUI. It manages the display of digits and handles value updates accordingly.

Role of the type within the module or system: Serves as a container for two-digit numerical UI elements in the application.

Important design decisions or considerations: Extends Digit2Base and overrides methods for custom behavior to handle digit-specific logic.

Note
This class is designed for embedded systems using TouchGFX and should be initialized properly.

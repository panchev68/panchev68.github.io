Detailed Description

WelcomePresenter class.

This class inherits from touchgfx::Presenter and ModelListener, implementing the presenter role in the Model-View-Presenter (MVP) pattern. It manages the welcome screen's lifecycle, including activation and deactivation, and facilitates communication between the model and the view components.

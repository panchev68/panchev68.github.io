Detailed Description

Date class for managing date display and input elements.

This class represents a container for date-related elements in the TouchGFX GUI, including scroll wheels for day, month, and year selection. It handles initialization, state management, and user interaction for date input, ensuring valid date ranges and proper display updates.

The class extends the generated DateBase and provides methods to get and set individual date components, as well as control touchability and update scroll wheel items.

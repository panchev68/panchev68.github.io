Detailed Description

ClockPoint class for managing clock point display elements.

This class represents a container for clock point elements in the TouchGFX GUI. It handles initialization and state management for visual clock points, such as hour or minute markers.

The class extends the generated ClockPointBase and provides methods to control the appearance and behavior of clock points based on their state.

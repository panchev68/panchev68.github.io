Detailed Description

ModelBase class.

This class represents the base model for the TouchGFX application, aggregating the main components such as clock, thermometer, and data logger. It provides a unified interface for handling periodic tick events and managing the application's model state. The class includes public member instances of the model components and a protected listener pointer.

Role of the type within the module or system: Acts as the central model hub in the MVP architecture, coordinating data flow between hardware interfaces and the GUI.

Important design decisions or considerations: Uses composition to aggregate model components, provides virtual tick() method for extensibility, and includes a nested Listener class for event handling to maintain separation of concerns.

Note
Inherits from no base class but provides a foundation for derived model classes.

virtual void ModelBase::tick ( )
inlinevirtual

Handles tick event.

Virtual method to handle periodic tick events from the application framework. This method delegates the tick handling to the clock and thermometer components, allowing them to update their state and notify the listener if present. The data logger is not ticked here as it may have different update requirements.

Precondition
The modelListener should be set to a valid listener instance.
Postcondition
The clock and thermometer components have processed the tick event.
Note
This method can be overridden in derived classes for additional processing.

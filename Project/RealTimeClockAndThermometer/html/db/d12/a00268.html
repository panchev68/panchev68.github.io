Detailed Description

SetupView class for time and date configuration UI.

This class manages the setup screen UI, allowing users to configure the clock time and date. It provides buttons for setting the clock and date, handles user interactions, and navigates to the clock screen upon completion. The class uses the PIMPL idiom to hide implementation details and ensure clean separation of interface and implementation. It inherits from SetupViewBase to leverage generated UI components.

Role of the type within the module or system: Serves as the view component in the MVP pattern, providing the user interface for setup operations and delegating logic to the presenter.

Important design decisions or considerations: Employs PIMPL to reduce compilation dependencies and improve maintainability in embedded environments.

Note
This class is designed for TouchGFX-based embedded GUIs with limited resources.

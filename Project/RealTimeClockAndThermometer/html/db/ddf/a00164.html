Detailed Description

Singleton class for managing backup RAM data storage.

This class encapsulates the storage and retrieval of temperature and humidity data in the device's backup RAM. It provides methods to access, validate, and manipulate the stored data, ensuring persistence across power resets.

The class uses a nested Simple struct to represent individual data points and a private Storage struct to organize the data in memory.

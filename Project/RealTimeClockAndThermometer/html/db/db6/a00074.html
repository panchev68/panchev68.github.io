Detailed Description

Date container header file.

This file defines the Date class, a custom TouchGFX container for displaying and managing date elements in the GUI. It provides functionality to initialize, get, and set date components such as day, month, and year, enabling user interaction with date selection through scroll wheels.

The class inherits from the generated DateBase class and extends it with custom behavior for date management and validation.

Note
This is part of the TouchGFX GUI framework for STM32F407ZET6-EVB-ClockAndThermometer project.

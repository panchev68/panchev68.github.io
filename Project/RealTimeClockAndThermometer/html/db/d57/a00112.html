Detailed Description

DataLogger class for periodic data logging.

This singleton class manages the logging of temperature and humidity data at regular intervals. It uses backup RAM for persistent storage, integrates with the real-time clock for accurate timing, and employs the RTOS tick service for event-driven operation. The class filters data based on minute intervals to avoid redundant logging and provides callback mechanisms for event notification.

Role of the type within the module or system: Serves as the application layer component for data acquisition and storage, bridging sensor data with persistent memory and user interface updates.

Important design decisions: Singleton pattern for global access and resource management, event-driven architecture to minimize power consumption, and data validation to ensure integrity.

Note
This class assumes the underlying hardware (backup RAM, RTC) is properly initialized.

void App::DataLogger::bindOnDataLogged ( const std::function< void()> & callback)
inline

Bind a callback for data logged events.

Registers a user-defined callback function that will be invoked whenever new data is successfully logged. This allows other components to react to logging events, such as updating the user interface.

Parameters
callbackThe function to call when data is logged. Should be a callable that takes no parameters.
Postcondition
The callback will be invoked on each successful data logging operation.

void App::DataLogger::start ( )
inline

Start the data logging process.

Initiates the periodic data logging by starting the tick service client. This enables the DataLogger to begin monitoring and logging sensor data at the configured intervals.

Precondition
The thermometer, RTC, and backup RAM must be properly initialized.
Postcondition
The tick service client is active and will handle periodic logging events.

Lib::Canbus::ServiceBaseabstract

Description

ServiceBase class for CAN bus communication.

This class serves as the base class for all CAN bus services in the Lib::Canbus namespace. It provides essential functionality for CAN communication, including service initialization and shutdown, message transmission and reception, diagnostic monitoring, error handling, and task execution. Designed for embedded systems using FreeRTOS, it integrates with HAL for hardware abstraction.

Note
Derived classes must implement the pure virtual taskFn() method.

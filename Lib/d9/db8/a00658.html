Description

Lib::Helper namespace.

Namespace for helper utilities in the Lib library.

This namespace contains various helper utilities and classes for common tasks such as data conversion, hashing, containers, timing, exceptions, and signal processing. It provides reusable components to simplify development in embedded systems.

Contains various utility functions for common operations like byte swapping.

void Lib::Helper::swapBytes ( const void * source,
void * dest,
size_t size )
inline

Swaps bytes in a memory buffer.

This function reverses the order of bytes in the source buffer and writes to the destination. If source and dest are the same, it performs in-place reversal.

Parameters
sourcePointer to the source buffer.
destPointer to the destination buffer.
sizeSize of the buffer in bytes.
Precondition
source and dest must not be nullptr.

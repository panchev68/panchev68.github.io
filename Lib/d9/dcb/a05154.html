Lib::Digi::Core::Frame0x80final

Description

RX Packet (0x80): RF data received from a node addressed by its 64-bit address.

Wire layout after the frame type byte: source address (8, big-endian), RSSI (1), options (1), RF data. A frame shorter than the fixed fields leaves every member zero and "rfData" empty.

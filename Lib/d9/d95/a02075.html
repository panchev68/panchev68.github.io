Description

Base class for I2C EEPROM drivers.

This header defines the DriverBase class, providing common functionality for interacting with I2C EEPROM devices over an I2C interface. It includes configuration, open/close, read/write, and address handling for EEPROM chips, supporting both 8-bit and 16-bit memory addressing modes.

Depends on I2CPort interface for I2C communication.

Derive from this class to implement specific EEPROM driver variants.

Note
Supports memory addressing in both 8-bit and 16-bit formats for flexibility with different EEPROM types.

StringHelper.hpp - String manipulation utilities.

This header provides a utility class for common string operations such as case conversion, trimming whitespace, and searching in arrays of strings. The class offers static methods for efficient string processing suitable for embedded and real-time applications.

Important dependencies include standard library headers such as <algorithm>, <cassert>, <cctype>, <cstdint>, <cstring>, <string>, and <string_view> for string handling and utilities.

Note
All methods are static and thread-safe for read-only operations.
Attention

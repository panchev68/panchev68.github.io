Description

ADC Port type aliases for different driver modes.

The Lib::HAL namespace contains all classes, functions, and types related to the Hardware Abstraction Layer.

#

This file defines type aliases for ADC ports operating in blocking, interrupt-driven, and DMA-based modes.

It provides convenient access to ADC port specializations for various use cases in embedded systems.

#

Depends on AdcPortBlock, AdcPortIT, AdcPortDMA, and DriverMode.

#

Select the appropriate mode based on performance and interrupt requirements.

It provides a unified interface for hardware interactions, ensuring portability across different platforms and architectures.

Key components within this namespace include:

  • Hardware drivers for peripherals (e.g., GPIO, UART, SPI)
  • Platform-specific implementations
  • Abstraction classes for common hardware operations
  • Error handling and status reporting mechanisms

All HAL components are designed to be thread-safe where applicable and to minimize dependencies on external libraries.

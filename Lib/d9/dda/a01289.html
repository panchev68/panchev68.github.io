Lib::Errors::Observer

Description

Base class for observing and managing errors.

The Observer class provides an interface for monitoring errors in the system. It can filter errors by group and provides methods to check for active errors, read error lists, and count errors. Supports both external and internally managed groups.

Note
This is a base class intended for inheritance; derived classes can override virtual methods.

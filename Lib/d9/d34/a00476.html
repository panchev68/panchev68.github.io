Description

Delay class for busy-wait delay operations.

This header provides the Delay class for lightweight busy-wait delay helpers using the Cortex-M DWT cycle counter. It exposes static methods for short delays in microseconds and nanoseconds. The implementation uses the device clock (HAL_RCC_GetHCLKFreq) and performs busy-waiting, suitable only for short blocking waits where interrupts can be disabled.

Important dependencies or interactions with other modules: Depends on STM32F4xx HAL library for IWDG operations. Any special instructions or notes for users of the file: Ensure HAL_IWDG_MODULE_ENABLED is defined in the project configuration.

Note
Designed for embedded systems requiring precise short delays.
Attention
Use only for short delays; not suitable for long waits.

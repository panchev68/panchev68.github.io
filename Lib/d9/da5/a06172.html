Lib::HAL::BackupRamDomain

Keeps small values in the backup data registers, which survive a system reset, with Lib::HAL::BackupRamDomain.

Keeps small values in the backup data registers, which survive a system reset, with Lib::HAL::BackupRamDomain. Lib::HAL::BackupRamDomain::open() opens the write gate of the backup domain, enables the PWR clock and, where the device has one, the backup SRAM clock; Lib::HAL::BackupRamDomain::close() reverses them. Reads are always allowed, but writes take effect only between open() and close(), so open the gate before calling Lib::HAL::BackupRamDomain::writeRegister(). The registers keep their content across low-power modes and, with a backup supply, across a power loss.

Important
The module guard is HAL_PWR_MODULE_ENABLED, which the project's 'stm32f4xx_hal_conf.h' enables. On the STM32F407xx target the HAL headers define neither RTC_BKP_NUMBER nor TAMP_BASE, so the register count is not known here and the index is not range-checked at all. The registers are read from the RTC block, because the device has no TAMP block.
Warning
The index is checked only by an assert in debug builds, and on this target there is no check at all. An index beyond the backup registers of the device accesses memory outside the register block, so pass only the indices defined for the target (the STM32F4 has 20 backup registers, 0 to 19, per its reference manual).

Store a value across a reset

#include <Lib/HAL/BackupRamDomain/BackupRamDomain.hpp>
#include <cstdint>
namespace {
constexpr uint32_t BOOT_COUNT_REGISTER = 0U;
}
uint32_t incrementBootCount() {
Lib::HAL::BackupRamDomain backup;
if (!backup.open()) {
return 0U;
}
const uint32_t count = backup.readRegister(BOOT_COUNT_REGISTER) + 1U;
backup.writeRegister(BOOT_COUNT_REGISTER, count);
static_cast<void>(backup.close());
return count;
}

Keep the access window short

Backup-domain write access stays open between open() and close(), so a stray write from another task or an ISR during that window goes through. Open it, do the accesses, and close it in one task.

#include <Lib/HAL/BackupRamDomain/BackupRamDomain.hpp>
#include <cstdint>
void saveFaultCode(uint32_t faultCode) {
constexpr uint32_t FAULT_REGISTER = 1U;
Lib::HAL::BackupRamDomain backup;
if (backup.open()) {
backup.writeRegister(FAULT_REGISTER, faultCode);
static_cast<void>(backup.close());
}
}

Description

XPT2046 touchscreen controller driver with SPI interface and debouncing.

This file contains the XPT2046 class for interfacing with the XPT2046 touchscreen controller.

Overview

Provides a complete driver for the XPT2046 capacitive touch controller, a 4-wire resistive touch panel controller with integrated 12-bit ADC. The driver uses bit-banged SPI for communication via GPIO pins (no hardware SPI required) and runs touch detection on a dedicated FreeRTOS task for non-blocking operation.

Key Features

  • 12-bit ADC resolution for precise touch position detection
  • Configurable calibration ranges for X and Y axes with automatic scaling
  • Moving average integration (10-sample window) for noise reduction and stability
  • Debounce filtering to eliminate transient touch noise
  • Support for multiple display orientations with rotation capability (normal and flipped)
  • Event-driven interrupt handling via active-low NIRQ signal with RTOS queue signaling
  • Non-blocking operation with dedicated FreeRTOS task (IDLE priority)

Hardware Interface

  • NIRQ: Interrupt pin (active-low touch detection signal)
  • MOSI: Serial data output to controller
  • MISO: Serial data input from controller ADC
  • SCK: Serial clock signal
  • NSS: Chip select (active-low)

Notes

  • Touch coordinates are automatically clamped and scaled to display dimensions
  • All SPI communication is performed via GPIO bit-banging (not hardware SPI)
  • Integrator window must fill before reliable coordinates are available
  • RTOS task automatically starts during construction

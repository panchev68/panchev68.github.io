Lib::Helper::DataHandle< T >

Description

template<typename T = uint8_t>
class Lib::Helper::DataHandle< T >

DataHandle template class for managing data buffers.

Provides a flexible way to handle data buffers with type safety. Supports initialization from single elements or raw buffers, and provides access to typed data pointers.

Role within the module: Utility for buffer management in embedded systems.

Important design decisions: Uses void* for buffer storage to allow flexibility; template parameter for type safety in access methods.

Template Parameters
TThe data type for type-safe access (default: uint8_t).

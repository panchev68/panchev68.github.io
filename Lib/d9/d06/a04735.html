Lib::BSP::Voltmeter< T_DERIVED >

Description

template<typename T_DERIVED = void>
class Lib::BSP::Voltmeter< T_DERIVED >

Voltmeter for ADC voltage measurement with integration, interpolation and change notification.

Reads raw ADC values periodically from one regular ADC channel through a single-slot DMA scan. Each value is averaged over a fixed window of five samples, converted to voltage by linear interpolation, and reported through handleValueChanged() when the voltage changes.

Registered with DeviceManager::DeviceBase, which drives handleTickEvent() from the shared tick timer. A derived class passes itself as T_DERIVED and overrides handleValueChanged(); the CRTP static_cast in handleTickEvent() selects that override, so there is no virtual call.

Template Parameters
T_DERIVEDConcrete voltmeter overriding handleValueChanged(), or void to use Voltmeter directly.

void Lib::BSP::Voltmeter< T_DERIVED >::handleValueChanged ( float value)
inlinenoexcept

Handles a change of the measured voltage.

Called from handleTickEvent() when the interpolated voltage differs from the previous measurement.

The default does nothing; T_DERIVED overrides it, for example to update a display or log the change. Not meant to be called directly.

Parameters
valueNew voltage, in volts.

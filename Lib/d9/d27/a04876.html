Lib::Crypto::WolfSSHServer< T_DERIVED >

Description

template<typename T_DERIVED>
class Lib::Crypto::WolfSSHServer< T_DERIVED >

CRTP base for a single server-side SSH session (CubeMX: wolfSSH Core).

A derived class implements the byte transport the session runs over: 'ioReceive(std::span<uint8_t>)' and 'ioSend(std::span<const uint8_t>)', each returning the number of bytes transferred, 0 when none are available yet, or a negative 'WS_CBIO_ERR_*' code. wolfSSH reaches them through a 'void*' context dispatched back to this instance, not through a virtual table, so CRTP replaces the vtable a transport-agnostic design would otherwise need.

One instance is one connection: construct it after accepting a connection on the underlying transport (e.g. a TCP socket or a UART link), destroy it when the connection ends. Not thread-safe: service one session from one task.

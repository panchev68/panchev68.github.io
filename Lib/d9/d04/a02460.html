Lib::Helper::RingBuffer< T, T_SIZE >

Description

template<typename T, size_t T_SIZE>
class Lib::Helper::RingBuffer< T, T_SIZE >

Fixed-size ring (circular) buffer template.

Provides FIFO push/pop semantics with a compile-time capacity. push returns false when the buffer is full; pop returns false when the buffer is empty. front()/back() give access to the next/last element respectively and assert on empty buffer.

Template Parameters
TType of elements stored in the buffer.
T_SIZECompile-time capacity (must be > 0).
Precondition
T_SIZE > 0
Important
  • Ensure T is MoveAssignable or CopyAssignable depending on how it is used.

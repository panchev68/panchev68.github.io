Lib::System::ParametersBaseabstract

Description

Common base for parameter containers that supports loading, validation and persistence using a pluggable storage backend.

The class stores a copy of the parameter blob plus a trailing CRC16. The StorageBase interface abstracts read/write operations to the underlying non-volatile storage.

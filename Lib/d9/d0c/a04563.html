Lib::BSP::IS62WV51216< T_DERIVED >

Description

template<typename T_DERIVED>
class Lib::BSP::IS62WV51216< T_DERIVED >

Mutex-guarded byte access to an IS62WV51216 SRAM mapped into the address space by the FSMC/FMC.

The memory controller is set up outside this class (CubeMX MX_FSMC_Init()); the driver only copies bytes at offsets inside the configured region. After each write the CRTP hook onMemoryChanged() runs under the lock; a derived class may shadow it, keeping it public or befriending the base.

Important
Call open() first: until then every transfer fails rather than touching the region unprotected.

Reacts to a completed write; does nothing by default.

Shadow it in the derived class to mark data dirty, notify a consumer or maintain a cache. Runs inside write() with the mutex held, so keep it short.

Warning
Calling read() or write() from here deadlocks: the mutex is not recursive.

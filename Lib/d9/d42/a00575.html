Description

Doxygen documentation for the Lib::RTOS namespace.

This file provides detailed documentation for the Lib::RTOS namespace, which encapsulates all Real-Time Operating System (RTOS) abstractions, helpers, and types for embedded and real-time applications. The namespace serves as the main entry point for RTOS-related APIs, including task management, synchronization primitives, queues, timers, and timing utilities.

The RTOS library is designed to provide modern C++ interfaces for FreeRTOS operations, enabling safe and efficient real-time scheduling and synchronization in embedded systems. All classes and functions follow RTOS best practices and embedded system constraints.

Components covered by this namespace include:

  • Task management and scheduling
  • Synchronization primitives (mutexes, semaphores, event groups)
  • Message queues and stream buffers
  • Software timers
  • Tick and timing services
Note
All RTOS-related code should reside within the Lib::RTOS namespace to ensure modularity, maintainability, and proper code organization.

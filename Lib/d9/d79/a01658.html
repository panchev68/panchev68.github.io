Description

template<typename T = float>
class Lib::Math::Pid< T >

Templated PID controller.

Template parameter T selects the numeric type used for inputs and outputs (typically float or double). The controller supports proportional, integral and derivative terms, with configurable sample time and output limits. The compute() method calculates the control output based on the current setpoint and input, applying the PID formula and respecting the configured output limits. The controller can be switched between automatic and manual modes, and supports reversing the control direction. Parameters can be updated at runtime, with care taken to manage state consistency when changing sample time or output limits. The class is designed to be simple and efficient for use in embedded systems, with a focus on clarity and correctness.

T input )
inline

Compute controller output for given setpoint and input.

If controller is in manual mode, the last output is returned unchanged. In automatic mode, the error is computed as (setpoint - input) and used to calculate the proportional, integral and derivative terms. The integral term is accumulated over time and clamped to prevent windup. The final output is clamped to the configured output limits before being returned. The state is updated with the current input and output for use in the next iteration.

Switch between automatic and manual mode.

When enabling automatic mode the integral term is reinitialized to the current output to avoid bumps.

When switching from manual to automatic mode, the integral sum is set to the current last output minus the proportional term based on the last input. This helps to ensure a smooth transition without causing a sudden change in output due to the integral term. For example, if the controller was producing an output of 50 in manual mode with a proportional gain of 2 and a last input of 20, when switching to automatic mode, the integral sum would be initialized to 50 - (2 * 20) = 10. This means that the integral term will start contributing from that point onward without causing an immediate jump in output, allowing for a seamless transition between modes. When switching from automatic to manual mode, the integral sum is not modified, so if the controller is switched back to automatic mode later, the integral term will continue from where it left off, which can be useful for maintaining control behaviour across mode changes. The method also updates the autoMode flag to reflect the current mode of the controller.

Set controller sample time and scale integral/derivative terms to preserve behaviour.

When the sample time is changed, the integral gain is scaled by the ratio of the new sample time to the old sample time, and the derivative gain is scaled by the inverse of that ratio. This preserves the intended effect of the integral and derivative terms relative to the proportional term, even as the sample time changes. For example, if the sample time is doubled, the integral gain will be doubled to maintain the same integral response over time, while the derivative gain will be halved to maintain the same derivative response to changes in the input. This allows for flexible adjustment of the sample time without needing to manually retune the gains to achieve the same control behaviour. The method also validates that the new sample time is greater than zero to prevent invalid configurations.

Lib::Digi::Core::Protocol

Description

XBee API protocol frame handler for parsing and building communication frames.

The Protocol class provides a utility interface for handling XBee API protocol frames. It implements frame parsing from binary buffers, frame validation including checksum verification, and frame construction from structured data. The class is designed as a static utility class with no instance creation allowed.

const ApiFrameBuffer & Lib::Digi::Core::Protocol::build ( const Frame::Data & frameData)
inlinestatic

Build binary API frame from structured frame data.

Constructs a complete XBee API frame in binary format from the provided Frame::Data structure. Encapsulates the frame type and payload, adds the API frame header with length information, and computes and appends the checksum. The resulting frame buffer is returned as a static reference and is reused for subsequent calls.

Parameters
frameDataThe source Frame::Data structure containing frame type and payload.
Returns
A constant reference to the static buffer containing the built API frame.
Note
The returned buffer is static and will be overwritten on subsequent calls to build().

Validate API frame structure and checksum from frame buffer.

Verifies that an API frame in the buffer is well-formed according to the XBee API specification. Checks the frame size, start delimiter, length field consistency, and validates the checksum. A valid frame must have the correct structure and valid checksum.

Parameters

Returns
true if the frame is valid and complete, false if the frame is malformed or checksum fails.

Parse binary API frame buffer into structured frame data.

Decodes a binary XBee API frame from an ApiFrameBuffer into a Frame::Data structure. Validates the frame structure, extracts the frame type, and populates the payload vector with the frame data. The frame must be valid before parsing (as verified by isValid()).

Parameters
apiFrameThe input API frame buffer containing binary frame data.
frameDataThe output Frame::Data structure to populate with parsed frame information.
Returns
true if the frame was successfully parsed, false if the frame is invalid.

Process incoming API frame and dispatch to appropriate event handlers.

Parses the API frame and dispatches the parsed data to event handlers based on the frame type. Handles various frame types including receive packets, command responses, transmit status, and modem status frames. Event handlers are invoked through the ResponseEvents singleton interface.

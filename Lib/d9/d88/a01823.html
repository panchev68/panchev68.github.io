Lib::Helper::DataHandle

Managing Data Buffers with DataHandle

This example demonstrates how to use the DataHandle class to manage data buffers and access typed data. It shows initialization with a single element, setting data, and retrieving the data and length.

Example usage:
#include "DataHandle.hpp"
#include <iostream>
int main() {
// Create a DataHandle for a single uint16_t element
uint16_t value = 0x1234;
Lib::Helper::DataHandle<uint16_t> handle(value);
// Access the data
uint16_t * data = handle.getData();
size_t length = handle.getLength();
std::cout << "Data: 0x" << std::hex << *data << ", Length: " << std::dec << length << std::endl;
// Set new data buffer
uint8_t buffer[] = {0x01, 0x02, 0x03, 0x04};
handle.setData(buffer, sizeof(buffer));
// Access the new data (cast to uint8_t*)
uint8_t * newData = handle.getData();
size_t newLength = handle.getLength();
std::cout << "New data length: " << newLength << std::endl;
return 0;
}

Lib::BSP::Thermometer::DTH::Driver< Type::DTH22 >

Description

Driver specialization for the DHT22 sensor type.

Implements sensor-specific timing decoding and provides accessors for temperature and humidity values. The class inherits common hardware and RTOS utilities from Base.

Lib::HAL::Timer< TimerMode::ENCODER >

Description

Timer specialization for encoder mode.

This class specializes the Timer template for TimerMode::ENCODER, inheriting from TimerBase. It provides methods for opening and closing the encoder timer, handling interrupts, and notifying value changes via a callback function.

Role within the module: Handles quadrature encoder input processing in the HAL.

Important design decisions: Uses interrupt-driven callbacks for real-time value updates, sets maximum counter value for full range encoder support.

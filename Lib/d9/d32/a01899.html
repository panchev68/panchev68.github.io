Lib::GSM::A7670Efinal

Description

Driver of the SIMCom A7670E modem: supply and power key, AT command exchange and the file system.

The driver is split into nested groups that share the modem state: Power for the supply and the boot, Network for registration, time and location, Files for whole-file operations and File for handle-based access. The application owns the port and the pins and passes them in Config; the driver never touches the hardware directly.

The serial port is a Lib::HAL::StreamSerialPort: it receives continuously, because the modem sends unsolicited result codes at any time. Only one task may read it.

Warning
Task context only, one task at a time: the driver keeps one response buffer and one file handle.
Important
The driver does not power the modem by itself: Config::setSupply does, and it must cut the supply again after a failed power-on.
Examples
Lib::GSM::A7670E.

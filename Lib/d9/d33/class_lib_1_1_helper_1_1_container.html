Lib::Helper::Container< T > Class Template Reference

Description

template<typename T>
class Lib::Helper::Container< T >

Container - Template class for managing collections of pointers.

This class provides methods for adding, removing, and processing pointers to objects of type T. It uses std::vector to store the pointers and supports operations like adding single items or lists, removing items, clearing the collection, and processing items with callbacks.

Template Parameters
TThe type of objects pointed to in the container.

Lib::Helper::Convert::HexHelper

Shows the lightweight conversion helpers of 'Lib::Helper::Convert::HexHelper': a nibble to its ASCII hex digit, a value from 0 to 99 packed into 8-bit BCD, a decimal value packed into 32-bit BCD, and an ASCII hex digit back to its numeric nibble.

Shows the lightweight conversion helpers of 'Lib::Helper::Convert::HexHelper': a nibble to its ASCII hex digit, a value from 0 to 99 packed into 8-bit BCD, a decimal value packed into 32-bit BCD, and an ASCII hex digit back to its numeric nibble.The helpers are 'static constexpr' and do not touch the RTOS, so they are safe from tasks and ISRs. 'toBcd()' and 'toBcd8()' assert on a value above their capacity in debug builds; 'fromAscii()' returns 'HexHelper::INVALID_NIBBLE' for a non-hex character.

Nibble to ASCII

#include <Lib/Helper/Convert/HexHelper.hpp>
#include <iostream>
void printNibbleAsAscii() {
using Lib::Helper::Convert::HexHelper;
const char c = HexHelper::toAscii(0xAU);
std::cout << "Nibble 0xA -> " << c << '\n'; // A
}

Packing decimal values into BCD

'toBcd8()' packs 0 to 99 into one byte, and 'toBcd()' packs up to 8 decimal digits into 32 bits.

#include <Lib/Helper/Convert/HexHelper.hpp>
#include <cstdint>
#include <iostream>
void printPackedBcd() {
using Lib::Helper::Convert::HexHelper;
const uint8_t bcd8 = HexHelper::toBcd8(42U);
std::cout << "BCD8(42) -> 0x" << std::hex << static_cast<int>(bcd8) << std::dec << '\n'; // 0x42
const uint32_t bcd32 = HexHelper::toBcd(1234U);
std::cout << "BCD32(1234) -> 0x" << std::hex << bcd32 << std::dec << '\n'; // 0x1234
}

ASCII to nibble

#include <Lib/Helper/Convert/HexHelper.hpp>
#include <cstdint>
#include <iostream>
void printAsciiAsNibble() {
using Lib::Helper::Convert::HexHelper;
const uint8_t nibble = HexHelper::fromAscii('F');
if (nibble != HexHelper::INVALID_NIBBLE) {
std::cout << "'F' -> " << static_cast<int>(nibble) << '\n'; // 15
}

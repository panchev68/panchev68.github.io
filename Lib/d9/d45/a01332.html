Lib::Ethercat::Dev::Lan9252Base::SpiPort

Description

SpiPort class for SPI communication.

Manages SPI port operations including chip select and data transfer for the LAN9252.

Role of the type within the module or system: Encapsulates low-level SPI interactions.

Important design decisions or considerations: Handles NSS pin management automatically.

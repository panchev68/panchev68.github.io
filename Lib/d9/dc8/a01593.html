Lib::Helper::TimeZone

Description

TimeZone class.

Encapsulates a time zone name, offset in minutes from UTC and a list of rules that describe time changes (for example daylight saving transitions). The class exposes simple accessors and a conversion helper to obtain UTC minutes from local calendar fields.

Convert local calendar time to UTC minutes since the epoch.

The function fills a local std::tm structure using the provided calendar fields, converts it to a time_t value with mktime (which treats the structure as local time) and adjusts the result by subtracting offsetSeconds to obtain UTC. The returned value is the number of minutes since the epoch in UTC, or -1 if the conversion failed.

Parameters
yearCalendar year (for example 2024).
monthCalendar month in the range [1..12].
dayCalendar day of month in the range [1..31].
hourHour of day in the range [0..23].
minuteMinute in the range [0..59].
offsetSecondsOffset in seconds to subtract from the local time to obtain UTC.
Returns
Number of minutes since the epoch in UTC on success; -1 on error.

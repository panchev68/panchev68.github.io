Description

High-level Module wrapper around the communication driver and protocol.

The Module class composes the ComDriver implementation and provides a convenient API to send protocol queries and subscribe to response events. It exposes a reference to the global ResponseEvents instance and allows clients to attach callbacks for message send/receive lifecycle events.

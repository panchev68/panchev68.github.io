Description

File access over EtherCAT (FoE): the file server of an EtherCAT slave.

Lets the master write a file to the slave (a firmware image, a configuration) and read a file from it, over the mailbox, in packets of the size the mailbox allows. The class runs the protocol (request, data packets with their numbers, acknowledgements, errors, busy) and leaves the files to the application: it asks a handler to open a file by name and password, to take the data of a write, to give the data of a read and to finish a write.

Use it from the mailbox handler of a Slave: pass every message to handle(). FoE is allowed in PRE-OP, SAFE-OP, OP and BOOTSTRAP; the AL state is passed to the open handler, which can refuse a file in a state (a firmware image is usually accepted only in BOOTSTRAP).

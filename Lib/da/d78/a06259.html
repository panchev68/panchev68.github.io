Lib::Math::LinearInterpolation

Converts a measured value to a physical quantity with Lib::Math::LinearInterpolation, a piecewise linear table stored in a fixed-size array without heap allocation.

Converts a measured value to a physical quantity with Lib::Math::LinearInterpolation, a piecewise linear table stored in a fixed-size array without heap allocation. Values outside the table clamp to the first or last point. The table is not thread-safe because a lookup may sort it first, so use it from one context or guard it with a mutex.

Table from an array

Build the table from a std::array of points in any order; the constructor sorts it. The aliases Lib::Math::LinearInterpolationF and Lib::Math::LinearInterpolationD use the same type for input and output.

#include <Lib/Math/Interpolation/LinearInterpolation.hpp>
#include <array>
using Curve = Lib::Math::LinearInterpolationF;
Curve ntcCurve(std::array<Curve::Point, 4U>{{
{-20.0F, 96.3F},
{0.0F, 32.6F},
{25.0F, 10.0F},
{85.0F, 1.2F},
}});
float resistanceAt(float celsius) noexcept {
return ntcCurve.interpolate(celsius);
}

Adding points at run time

Lib::Math::LinearInterpolation::addPoint() appends a point and returns false when the table already holds Lib::Math::LinearInterpolation::MAX_POINTS points. Points may arrive in any order; the next lookup sorts them. At least two points are needed before the first lookup.

#include <Lib/Math/Interpolation/LinearInterpolation.hpp>
Lib::Math::LinearInterpolationF calibration;
bool addCalibrationPoint(float reference, float measured) noexcept {
return calibration.addPoint(measured, reference);
}
void resetCalibration() noexcept {
calibration.clear();
}
float correct(float measured) noexcept {
if (calibration.getPointCount() < 2U) {
return measured;
}
return calibration.interpolate(measured);
}

Raw ADC counts as input

The second template argument sets the type of the input coordinate. With an integral type, such as raw ADC counts, the interpolation still runs in floating point, so there is no integer rounding. Lib::BSP::Voltmeter uses this form to convert counts to volts.

#include <Lib/Math/Interpolation/LinearInterpolation.hpp>
#include <array>
#include <cstdint>
using AdcCurve = Lib::Math::LinearInterpolation<float, uint32_t>;
AdcCurve adcToVolt(std::array<AdcCurve::Point, 3U>{{
{0U, 0.0F},
{2048U, 1.65F},
{4095U, 3.3F},
}});
float voltage(uint32_t counts) noexcept {
return adcToVolt.interpolate(counts);
}

Interpolating between two points

Lib::Math::LinearInterpolation::interpolateBetween() and Lib::Math::LinearInterpolation::interpolateSimple() are static and constexpr and need no table. They do not clamp, so a coordinate outside the two points extrapolates along the line.

#include <Lib/Math/Interpolation/LinearInterpolation.hpp>
#include <cstdint>
using Curve = Lib::Math::LinearInterpolation<float, uint32_t>;
constexpr float QUARTER = Curve::interpolateBetween(Curve::Point(0U, 0.0F), Curve::Point(4096U, 4.0F), 1024U);
constexpr float SIMPLE = Curve::interpolateSimple(0U, 0.0F, 4096U, 4.0F, 3072U);
constexpr float OUTSIDE = Curve::interpolateSimple(0U, 0.0F, 4096U, 4.0F, 8192U);
static_assert(QUARTER == 1.0F);
static_assert(SIMPLE == 3.0F);
static_assert(OUTSIDE == 8.0F);

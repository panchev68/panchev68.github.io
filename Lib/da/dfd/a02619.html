Lib::SolarControl::MPPT

Description

Adaptive-step Perturb-and-Observe MPPT helper gated by an estimated maximum power.

Unlike 'Lib::SolarControl::PerturbAndObserve', which perturbs by a fixed step, this variant scales its perturbation step by the local power/voltage slope and only perturbs while the measured power tracks close to the estimated maximum. Otherwise it falls back to a fraction of the reference voltage.

The type is a literal type: it declares no destructor and owns nothing, so an instance can be built in a constant expression. The optional estimator is a non-owning 'FunctionRef'.

◆ update()

float Lib::SolarControl::MPPT::update ( const Measurement & currentMeas)
inlinenodiscard

Updates the internal state with a new measurement and computes a voltage setpoint.

The perturbation step is scaled by the local power/voltage slope, clamped to ['MIN_STEP', 'MAX_STEP'], and is applied only while the measured power stays within the tolerance of the estimated maximum. Otherwise the setpoint falls back to a fraction of 'ReferenceParameters::mppVoltageRef'. The result is always clamped to [0, 'mppVoltageRef * UPPER_BOUND_MULTIPLIER']. The first call initialises the internal state and returns the restart setpoint.

Parameters
currentMeasLatest sensor measurements: temperature, irradiance, voltage and current.
Returns
Computed voltage setpoint in volts.

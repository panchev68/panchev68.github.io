Lib::Core::FunctionRef

Binds a 'FunctionRef<int(int)>' to a lambda, to a functor and to a free function, then calls it.

Binds a 'FunctionRef<int(int)>' to a lambda, to a functor and to a free function, then calls it.'FunctionRef' owns nothing: it stores a capture-less lambda or a free function by value, and any callable as wide as a pointer and trivially copyable, such as a 4-byte functor on this 32-bit target or a lambda capturing 'this'. Any other callable is referenced, so an lvalue of it must outlive the reference, and a larger temporary is rejected at compile time. The reference is not thread-safe to rebind while another task calls it.

Bind and rebind

#include <Lib/Core/FunctionRef.hpp>
#include <iostream>
struct Adder {
int base;
Adder(int b) :
base(b) {
}
int operator()(int x) const {
return base + x;
}
};
void functionRefExample() {
// A capture-less lambda is stored by value, so the temporary is fine.
FunctionRef<int(int)> callable = [](int x) { return x * 2; };
std::cout << callable(5) << "\n";
// A functor as wide as a pointer is stored by value too.
callable = Adder{3};
std::cout << callable(5) << "\n";
// A free function, or a lambda assigned through its own lvalue.
auto square = [](int v) { return v * v; };
callable = square;
std::cout << callable(4) << "\n";
}

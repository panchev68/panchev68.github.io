Lib::Helper::DataHandle< T > Class Template Reference

Description

template<typename T = uint8_t>
class Lib::Helper::DataHandle< T >

Template class for handling data buffers with type-safe access.

This class provides a wrapper around raw data pointers and sizes, allowing type-safe access to buffers of various types. It supports initialization from references, raw buffers, and setting data dynamically.

Template Parameters
TThe data type for type-safe access (default: uint8_t).

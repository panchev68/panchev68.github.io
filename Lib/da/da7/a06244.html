Lib::Helper::Exception

Shows installing a terminate handler and reading the message of a Lib::Helper::Exception instance.

Shows installing a terminate handler and reading the message of a Lib::Helper::Exception instance.The project builds with '–no_exceptions', so nothing is ever thrown or caught. The class serves as a non-allocating error description and as the access point for the terminate handler (std::terminate_handler), which must never return. The message pointer is stored as is, so pass a string literal.

Usage

Installing a terminate handler

Lib::Helper::Exception::setTerminateHandler() installs the handler for the whole program. The handler must not return.

#include <Lib/Helper/Exception.hpp>
[[noreturn]] void onTerminate() noexcept {
while (true) {
// Log the fault, then halt here or reset the MCU.
}
}
void installTerminateHandler() noexcept {
Lib::Helper::Exception::setTerminateHandler(onTerminate);
}

Reading the message

Lib::Helper::Exception::what() never returns 'nullptr'; a null message passed to the constructor is replaced by 'Null Exception'.

#include <Lib/Helper/Exception.hpp>
const Lib::Helper::Exception flashError{"Flash write failed"};
const char * describe(const Lib::Helper::Exception & error) noexcept {
return error.what();
}

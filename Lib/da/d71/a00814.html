Lib::BSP::EncoderPins

Description

EncoderPins class for handling rotary encoder inputs.

This class provides functionality to manage rotary encoder pins, including two channels for rotation detection and a button for user input. It handles event processing, debouncing, and queuing of events using RTOS mechanisms. The class supports configuration of divider for pulse counting and reverse rotation direction.

Note
Requires RTOS and GPIO initialization.

◆ getButtonState()

bool Lib::BSP::EncoderPins::getButtonState ( uint32_t debounce = 20)
inline

Gets the current button state with debouncing.

Reads the button state with optional software debouncing to filter electrical noise. If debounce is 0, returns the raw button state; otherwise, samples multiple times with delays. The button is considered pressed when the GPIO reads low (active low).

Parameters
debounceNumber of samples for debouncing (default 20; 0 for no debouncing).
Returns
true if button is pressed (after debouncing), false otherwise.
Note
This method may block for debounce * 1ms if debouncing is enabled.

◆ handlePinChangedEvent()

bool Lib::BSP::EncoderPins::handlePinChangedEvent ( uint16_t pinNumber)
inline

Handles pin changed event.

Processes GPIO interrupt events for encoder channels and button pin changes. Detects button press/release by reading the button state. For encoder channels, manages quadrature decoding by tracking pending events on both channels. Generates rotation events (CW/CCW) when both channels have transitioned.

Parameters
pinNumberThe pin number that triggered the interrupt.
Returns
true if the event was handled (pin belongs to this encoder), false otherwise.
Note
This method should be called from GPIO interrupt handlers.

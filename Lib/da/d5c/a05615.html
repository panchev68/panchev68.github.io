Lib::BSP::Beep

Demonstrates a short start-up click followed by a three-beep alarm on a buzzer driven by TIM1 channel 1.

Demonstrates a short start-up click followed by a three-beep alarm on a buzzer driven by TIM1 channel 1.TIM1 is initialized by CubeMX; its prescaler and period set the tone, while the driver switches the channel to output-compare toggle mode on every beep. 'play()' returns at once and the sequence plays in the RTOS timer service task, so the task waits with 'isPlaying()' before queuing the next sequence: a 'play()' call made while one is still running returns 'false' and is dropped.

Important
The RTOS timer service task must be running ('configUSE_TIMERS'), since every beep is timed from it.
See also
Lib::BSP::Beep, Lib::BSP::Beep::play(), Lib::BSP::Beep::isPlaying()
Example usage:
#include <Lib/BSP/Beep/Beep.hpp>
#include <Lib/RTOS/FreeRTOS/Kernel.hpp>
#include <chrono>
extern "C" TIM_HandleTypeDef htim1; // TIM1 output compare, period sets the tone.
using namespace std::chrono_literals;
Lib::BSP::Beep beeper{{.timerHandle = &htim1, .timerChannel = TIM_CHANNEL_1}};
void alarmTask() {
static_cast<void>(beeper.play(50U)); // Short click on start-up.
while (beeper.isPlaying()) {
RTOS::delay(10ms);
}
if (!beeper.play(200U, 3U, 100U)) { // Three 200 ms beeps, 100 ms apart.
// A sequence is still playing: this request is dropped.
}
}

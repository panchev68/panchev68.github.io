Lib::Helper::JaggedArrayBase< T >

Description

template<class T>
class Lib::Helper::JaggedArrayBase< T >

Generic base for a jagged array row or collection.

Manages a sequence of pointers to type 'T' and provides safe access and manipulation helpers. The container does not take ownership of the pointed-to objects; callers are responsible for their lifetime.

Template Parameters
TElement type stored as pointers in the collection.

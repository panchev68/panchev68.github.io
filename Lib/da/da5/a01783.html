Lib::XCOM::Protocol

Description

Protocol helper for building and parsing XCOM frames.

The Protocol class provides static methods to construct and decode framed messages using start delimiter, escaping, length prefix, and CRC16 checksum validation. Frames are built by prepending a header (delimiter, length, command) and appending a two-byte CRC16 checksum, then escaping special bytes. Parsing reverses this process with full validation of frame integrity.

Note
All byte values matching START_DELIMITER or ESC_SUBST outside the initial delimiter are escaped by replacing with ESC_SUBST followed by the byte XORed with PRECODE_MASK.

std::vector< uint8_t > Lib::XCOM::Protocol::build ( const Frame & frame)
inlinestatic

Build a framed and escaped byte vector from a Frame instance.

Constructs a complete frame by prepending the header (start delimiter, payload length, command) and appending a CRC16 checksum, then escaping all special bytes. The resulting frame is ready for transmission over a serial or similar interface.

Parameters
frameSource Frame containing command and payload data.
Returns
Escaped frame bytes ready for transmission, including all delimiters, length, command, payload, and checksum.
Precondition
frame.payload.size() <= MAX_PAYLOAD_SIZE; larger payloads are silently truncated.
Postcondition
Result contains escaped representation of header + payload + CRC16 checksum.

Status Lib::XCOM::Protocol::parse ( const std::vector< uint8_t > & inputFrame,
Frame & outputFrame )
inlinestatic

Parse an incoming frame buffer into a Frame object.

Validates the input buffer structure, un-escapes all special bytes, extracts the command and payload, and verifies the CRC16 checksum. The frame must start with START_DELIMITER and contain properly formatted header and checksum.

Parameters
inputFrameRaw input bytes to parse (must start with START_DELIMITER).
[out]outputFrameDecoded output Frame object on successful parse.
Returns
Status::OK if frame parsed and verified successfully, Status::ERROR if validation fails.
Precondition
inputFrame must not be empty and must start with START_DELIMITER.
Postcondition
outputFrame.command and outputFrame.payload are populated on success.

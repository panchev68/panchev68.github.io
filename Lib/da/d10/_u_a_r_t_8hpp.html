Description

UART base class for handling UART operations.

Provides an abstraction for UART initialization, data transmission, reception, and error handling. Defines the Lib::HAL::UARTBase class which integrates with HAL UART callbacks and RTOS event mechanism for embedded systems.

The class supports asynchronous UART operations with interrupt-driven I/O, error handling, and baud rate configuration. It uses RTOS event groups for synchronization and provides a device manager for handle-to-object mapping.

Important dependencies include STM32 HAL UART library, RTOS event groups, and device manager base class. Interacts with UART peripherals through HAL callbacks and interrupt handlers.

Note
Requires USE_HAL_UART_REGISTER_CALLBACKS to be enabled in HAL config.
Designed for real-time embedded applications with interrupt handling.

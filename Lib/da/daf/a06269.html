RTOS::SemaphoreCounting

Shows limiting concurrent access to a pool of resources with an RTOS::SemaphoreCounting.

Shows limiting concurrent access to a pool of resources with an RTOS::SemaphoreCounting.Covers a pool of three buffers guarded by a counting semaphore: a task takes a slot before using a buffer and gives it back afterwards. RTOS::SemaphoreBase::take() and RTOS::SemaphoreBase::give() are task-context only; FromISR variants exist for interrupt handlers.

Buffer pool

The constructor takes the maximum count and the initial count, so both are 3 here: all slots are free at start.

#include <Lib/RTOS/FreeRTOS/SemaphoreCounting.hpp>
namespace {
RTOS::SemaphoreCounting bufferPool(3U, 3U);
}
bool openPool() noexcept {
return bufferPool.open();
}

Taking and returning a slot

RTOS::SemaphoreBase::take() with an RTOS::Timeout returns false when every slot stays busy for the whole window.

#include <Lib/RTOS/FreeRTOS/SemaphoreCounting.hpp>
#include <chrono>
using namespace std::chrono_literals;
namespace {
RTOS::SemaphoreCounting bufferPool(3U, 3U);
}
void workerTask(void * parameters) {
static_cast<void>(parameters);
if (!bufferPool.open()) {
return; // Creation failed: out of heap.
}
if (bufferPool.take(RTOS::Timeout(20ms))) {
// One of the three buffers is reserved for this task.
static_cast<void>(bufferPool.give());
} else {
// All buffers were busy for 20 ms.
}
}

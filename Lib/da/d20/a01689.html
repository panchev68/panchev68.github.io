RTOS::Queue< T_ELEMENT_TYPE, QUEUE_LENGTH >

Description

template<typename T_ELEMENT_TYPE, size_t QUEUE_LENGTH = 1>
class RTOS::Queue< T_ELEMENT_TYPE, QUEUE_LENGTH >

RAII wrapper for FreeRTOS queues.

Provides type-safe operations for queue management, including creation, destruction, sending, receiving, and querying. Supports both dynamic and static allocation.

The Queue class template provides a modern C++ interface to FreeRTOS queues with:

  • Compile-time type safety and size validation
  • Automatic resource management through RAII
  • Support for both heap-based (dynamic) and user-provided (static) storage
  • Timeout-based operations for flexible blocking behavior
  • ISR-safe variants for interrupt context usage
  • Comprehensive queue state inspection methods

Usage patterns:

  • Use dynamic allocation for simple cases with heap availability
  • Use static allocation for deterministic memory usage or memory-constrained systems
  • Choose appropriate timeouts based on real-time requirements
  • Use ISR variants only from interrupt service routines
Template Parameters
T_ELEMENT_TYPEElement type, must be trivially copyable.
QUEUE_LENGTHMaximum number of elements in the queue.
Note
Element type must satisfy std::is_trivially_copyable for safe memcpy operations.
Queue length is validated at compile-time to be greater than zero.
Attention
Queue operations are not inherently thread-safe; use appropriate synchronization.
ISR operations should complete quickly to avoid blocking other interrupts.

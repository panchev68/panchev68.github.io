Lib::Digi::Core::Checksum

Description

Lightweight helper that computes and stores a frame checksum.

The object computes the checksum on construction and provides an implicit conversion to 'uint8_t' for convenience when appending or validating frames. Preconditions are asserted (non-null pointers and message size within buffer limits).

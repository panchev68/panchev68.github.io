Description

template<typename T, size_t T_SIZE>
requires (std::default_initializable<T> && (T_SIZE > 0U) && (T_SIZE <= std::numeric_limits<size_t>::max() / 2U))
class Lib::Helper::RingBuffer< T, T_SIZE >

Fixed-capacity FIFO container with lock-free single-producer/single-consumer semantics.

Exactly one execution context may act as producer ('push()', bulk write(), the linear write block / advance() pair) and exactly one (possibly different) context may act as consumer ('pop()', front(), bulk read(), peek(), the linear read block / skip() pair). 'overwrite()' runs in the producer context but also advances the read side, so it needs exclusive access to both. clear(), copy and move are not concurrency-safe.

Template Parameters
TElement type stored in the buffer; must be default-constructible.
T_SIZEMaximum number of stored elements; must be greater than 0 and at most half of 'SIZE_MAX'.

template<typename T, size_t T_SIZE>
std::span< const T > Lib::Helper::RingBuffer< T, T_SIZE >::getLinearReadBlock ( ) const
inlinenodiscardnoexcept

Returns the longest contiguous stored span starting at the read position (consumer side).

The caller may read directly from the returned span (e.g. via DMA) and then release the consumed elements with skip(). The span may be shorter than 'available()' when the stored data wraps past the end of the backing storage; call again after skip() to reach the remainder.

Returns
Readable span of stored elements; empty when the buffer is empty.

Lib::Helper::Sunset

Description

Sunset and moon phase calculation utility.

The Sunset class provides methods for calculating sunrise, sunset, and moon phase information for a specified geographic location and date. It supports official, nautical, civil, and astronomical sun event calculations, and computes times using precise astronomical algorithms. The class is suitable for embedded and real-time applications requiring solar and lunar event data, such as calendar utilities, astronomical tools, and environmental monitoring systems.

Calculates the time of astronomical sunrise for the current date and position.

This method computes the time when the sun is 18 degrees below the horizon, marking the start of astronomical twilight. Astronomical sunrise occurs when the sun's upper limb is 18 degrees below the horizon.

Returns
Astronomical sunrise time in minutes from midnight UTC.
Precondition
Geographic position and current date must be set.
Postcondition
Returns the calculated astronomical sunrise time adjusted for the time zone.

Sets the geographic position and time zone offset.

This method configures the location for astronomical calculations by storing the latitude, longitude, and UTC offset. It also precomputes trigonometric values for efficiency in subsequent calculations.

Parameters

longitudeGeographic longitude in degrees.
timeZoneOffsetTime zone offset from UTC in hours.

timeZoneOffset must be between -12 and 14 hours.
Postcondition
The geographic position and time zone are set, and cached trigonometric values are updated.

Lib::Exception

Description

Exception type that stores a diagnostic message.

The message lives in a fixed, NUL-terminated buffer rather than a std::string: an exception object must not need the heap to report why something failed, least of all on a target where the allocator may be the thing that failed. A message longer than MAX_MESSAGE_LENGTH is truncated. The type provides copy and move semantics, integrates with std::exception through what(), and exposes helpers to query and install a terminate handler for process-wide termination behavior.

Lib::GUI::String< T_CAPACITY >final

Description

template<size_t T_CAPACITY>
class Lib::GUI::String< T_CAPACITY >

Single-line text that keeps its own copy of the characters, so it can be changed while the screen is running.

The text is placed at a position. When the widget has a width, the text is aligned inside that width and the whole width is cleared before drawing, so a shorter text leaves no remains of a longer one. Without a width the text starts at the position and nothing is cleared. A text longer than the capacity is cut. Changing the text only stores it; it appears with the next Lib::GUI::String::draw() and a flush.

Template Parameters
T_CAPACITYMaximum number of characters, at least 1.

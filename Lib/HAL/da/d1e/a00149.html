I2CPort.hpp File Reference

Description

I2CPort class definition and I2C HAL abstraction for STM32. This file defines the I2CPort class, which provides a type-safe, RTOS-integrated abstraction for STM32 HAL I2C peripherals. It manages device registration, callback setup, event signaling, and provides high-level methods for I2C memory and master transfers, error/status handling, and device readiness checks. The class is designed for use with FreeRTOS and TouchGFX, and integrates with the DeviceManagerBase for device tracking and resource management.

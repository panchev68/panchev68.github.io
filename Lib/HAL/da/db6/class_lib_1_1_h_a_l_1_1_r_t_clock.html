Lib::HAL::RTClock Class Reference

Description

STM32 RTC peripheral device abstraction.

Provides thread-safe access to the STM32 RTC peripheral, supporting date/time read/write and backup register operations. Integrates with RTOS mutex and backup SRAM domain for safe concurrent access.

Lib::HAL::GPIO::Input Class Reference

Description

Abstraction for a GPIO pin configured as input.

Encapsulates logic for managing a GPIO input pin, including construction from port/pin or handle, reading pin state, and configuring pin mode. Designed for robust and reusable GPIO input handling in embedded systems.

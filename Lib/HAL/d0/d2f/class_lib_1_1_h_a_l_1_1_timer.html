Description

template<TimerMode T_MODE>
class Lib::HAL::Timer< T_MODE >

Template class for timer management.

This class encapsulates timer functionality for a specific mode, providing methods to set and retrieve the timer handle, check validity, and get the operational mode. It is designed as a base class for timer implementations, with deleted copy and move operations to ensure exclusive ownership.

Template Parameters
T_MODEThe timer mode, defining the operational characteristics.

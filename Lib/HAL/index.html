Hardware Abstract Layer Library

The Hardware Abstraction Layer (HAL) Library provides a unified interface for interacting with various hardware components in embedded systems. It abstracts the complexities of hardware management, allowing developers to write code that is portable across different microcontroller platforms.

Key Features

  • Modular Design: The library is organized into modules for different hardware components such as ADC, CAN, TIM, etc.
  • Template-Based Classes: Utilizes C++ templates to create flexible and reusable classes for hardware components.
  • Thread Safety: Ensures safe access to hardware resources in multi-threaded environments.
  • Comprehensive Documentation: Each class and function is well-documented to facilitate ease of use and understanding.
  • Support for DMA and Interrupt-Driven Operations: Provides classes that support both DMA and interrupt-driven data handling for efficient performance.
  • Platform Independence: Designed to work across multiple microcontroller platforms, primarily STM32 series.
  • Error Handling: Robust error handling mechanisms to manage hardware failures and exceptions.
  • Low-Level Optimization: Optimized for performance and memory usage in resource-constrained embedded environments.

Architecture

The HAL is structured around a namespace Lib::HAL and consists of several key components:

  • Core Classes: Base classes and templates that provide the foundation for hardware abstraction.
  • Peripheral Drivers: Specific implementations for each hardware peripheral (ADC, GPIO, UART, etc.).
  • Device Manager: Handles device initialization and resource management.
  • Error Handling: Mechanisms for reporting and handling hardware-related errors.

Modules

The HAL library includes the following modules:

Analog-to-Digital Converter (ADC)

  • Provides interface for analog signal conversion.
  • Supports multiple channels and sampling modes.

Controller Area Network (CAN)

  • Implements CAN bus communication protocols.
  • Supports standard and extended frames.

General Purpose Input/Output (GPIO)

  • Manages digital I/O pins.
  • Supports input, output, and interrupt configurations.

Inter-Integrated Circuit (I2C)

  • Handles I2C communication for peripheral devices.
  • Supports master and slave modes.

Serial Peripheral Interface (SPI)

  • Manages SPI communication.
  • Configurable for different clock speeds and modes.

Universal Asynchronous Receiver/Transmitter (UART)

  • Provides serial communication interface.
  • Supports various baud rates and data formats.

Timer (TIM)

  • Offers timer and counter functionality.
  • Supports PWM generation and input capture.

Real-Time Clock (RTC)

  • Manages real-time clock operations.
  • Provides date and time functions.

Watchdog Timer

  • Implements watchdog functionality for system reliability.

Backup SRAM (BKPSRAM)

  • Provides access to backup SRAM for data retention.

One-Time Programmable (OTP)

  • Manages OTP memory operations.

System Reset

  • Handles system reset operations.

Usage

To use the HAL library in your project:

  1. Include the necessary header files for the peripherals you need.
  2. Initialize the HAL components in your main function.
  3. Use the provided classes and methods to interact with hardware.

Example

#include "Lib/HAL/GPIO.hpp"
#include "Lib/HAL/UART.hpp"
int main() {
// Initialize GPIO
Lib::HAL::GPIO gpio(Lib::HAL::GPIO::Port::A, Lib::HAL::GPIO::Pin::Pin0);
gpio.setMode(Lib::HAL::GPIO::Mode::Output);
// Initialize UART
Lib::HAL::UART uart(Lib::HAL::UART::Instance::UART1);
uart.init(9600);
// Use the peripherals
gpio.setHigh();
uart.write("Hello, World!");
return 0;
}

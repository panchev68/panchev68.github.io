CanRxMessage Class Reference

Description

CAN receive message wrapper class.

The CanRxMessage class encapsulates a CAN receive message, including the CAN header and data buffer. It provides convenient accessors for the message ID, data length, and data buffer, and is designed for use with STM32 HAL CAN drivers in embedded applications.

#include <CanRxMessage.hpp>

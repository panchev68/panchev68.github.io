Description

GPIO pin configuration utilities and abstractions.

This file declares the PinMode class for configuring GPIO pins in embedded systems. It provides strongly-typed enums for mode, speed, and pull-up/pull-down settings, enabling robust and flexible pin setup in embedded applications.

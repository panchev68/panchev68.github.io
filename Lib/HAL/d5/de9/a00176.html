Description

GPIO HAL interface header.

This file provides type aliases and EXTI callback for the GPIO HAL abstraction layer.
It defines convenient aliases for GPIO handle, input, output, and port types, and provides a macro for pin handle
construction. The file also declares the HAL EXTI callback for GPIO, which routes EXTI events to the EXTIBase
device manager. This infrastructure enables unified GPIO handling and event management for STM32 HAL-based projects.

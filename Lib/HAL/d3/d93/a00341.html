Lib::HAL::Reset

Reset State Query and System Reset Example

This example demonstrates how to query the current reset state of the system and trigger a system reset using the Reset class. It shows initialization, state retrieval, and reset invocation in an embedded application context.

Example usage:

The code initializes the Reset instance, retrieves the current reset state, logs it (assuming a logging mechanism), and then triggers a system reset if the state is not unknown. This is useful for handling reset events in STM32-based systems, such as after a watchdog reset or power-on.

#include "Lib/HAL/core/Reset/Reset.hpp"
#include <iostream> // Assuming a logging output for demonstration
int main() {
// Get the singleton instance
auto& resetManager = Lib::HAL::Reset::instance();
// Query the current reset state
Lib::HAL::Reset::State currentState = resetManager.getState();
// Log the reset state (in a real embedded system, use appropriate logging)
switch (currentState) {
case Lib::HAL::Reset::State::SOFTWARE_RESET:
std::cout << "System was reset by software." << std::endl;
break;
case Lib::HAL::Reset::State::POWER_ON_POWER_DOWN_RESET:
std::cout << "System was reset by power-on or power-down." << std::endl;
break;
// Add cases for other states as needed
default:
std::cout << "Reset state is unknown or other." << std::endl;
break;
}
// Optionally trigger a reset (commented out to avoid actual reset in example)
// resetManager.reset();
return 0;
}

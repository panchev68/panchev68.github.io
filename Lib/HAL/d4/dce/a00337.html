Lib::HAL::RTClock

Basic Usage of RTClock

This example demonstrates how to initialize the RTClock, write a date and time, and read it back.

Example usage:

The following code shows the setup, writing, and reading operations for the RTClock class.

#include "Lib/HAL/core/RTC/RTClock.hpp"
int main() {
// Assume RTC_HandleTypeDef is initialized elsewhere
RTC_HandleTypeDef rtcHandle;
Lib::HAL::RTClock rtc(&rtcHandle);
rtc.setup();
// Write a date and time
Lib::Helper::DateTime dt = {{2023, 10, 1}, {12, 30, 0}};
rtc.write(dt);
// Read the date and time
Lib::Helper::DateTime readDt = rtc.read();
rtc.release();
return 0;
}

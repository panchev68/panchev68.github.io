CAN_FilterTypeDef Struct Reference

Description

CAN filter type definition.

Defines the structure for CAN filter configuration, including ID, mask, bank, mode, scale, activation, FIFO assignment, and slave start filter bank. This structure is used by the STM32 HAL for CAN filter setup.

CanFilter Class Referencefinal

Description

CAN filter wrapper class.

Provides a type-safe and convenient interface for configuring CAN hardware filters. The CanFilter class wraps the CAN_FilterTypeDef structure, allowing easy setup of CAN filters for message acceptance in embedded systems. It supports setting filter ID, mask, bank, mode, scale, activation, and FIFO assignment. The class ensures proper initialization and provides conversion operators for use with HAL functions. It is designed for STM32 HAL and integrates with the CAN port management in the Lib::HAL namespace.

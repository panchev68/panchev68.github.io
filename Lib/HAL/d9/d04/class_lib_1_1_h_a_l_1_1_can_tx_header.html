Lib::HAL::CanTxHeader Class Reference

Description

CAN TX Header class.

The CanTxHeader class extends CAN_TxHeaderTypeDef and provides a type-safe, convenient interface for configuring CAN transmit headers, including support for standard and extended IDs, remote frames, and timestamping. It allows initialization and configuration of CAN message headers for transmission.

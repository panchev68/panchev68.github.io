Lib::HAL::Port< Lib::HAL::DriverMode::DMA > Class Reference

Description

ADC DMA Port specialization. Specialization of the Lib::HAL::Port template for DriverMode::DMA. Provides DMA-based ADC port functionality, implementing the required interface for ADC operations using DMA.

RTOS::Kernel::Scheduler::Lockfinal

Description

RAII lock that suspends the scheduler for the lifetime of the guard.

Interrupts stay enabled while the scheduler is suspended; only context switches are deferred. Must not be used from an ISR, and no blocking API may be called while the lock is held.

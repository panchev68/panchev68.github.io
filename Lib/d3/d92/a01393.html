Lib::HAL::Port< DriverMode::DMA >

Description

DMA-based ADC Port specialization.

This class provides DMA-driven ADC functionality, allowing for efficient data transfer from ADC to memory without CPU intervention. It inherits from AdcTransparentPortBase and implements the Port interface for DMA mode.

Key features:

  • DMA-based ADC conversions for reduced CPU load
  • Single-channel DMA buffer management
  • Transparent read operations with timeout support

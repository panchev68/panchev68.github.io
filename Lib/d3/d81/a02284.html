Lib::HAL::CanTxHeader

Description

Helper class for preparing CAN transmit headers.

Provides a simple constructor that sets ID type (standard/extended), RTR flag, timestamping and DLC. Accessor methods return the effective ID, data length and flags in a convenient form.

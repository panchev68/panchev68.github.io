Description

Root namespace for the IAR EWARM library.

Groups every library module: the hardware abstraction layer, board support package, communication-protocol stacks, helpers and the freestanding exception type. FreeRTOS wrappers are the one exception: they live in the top-level RTOS namespace instead of Lib::RTOS.

Note
The library is not a C++ standard library implementation; it is a collection of modules that are useful in embedded applications, and that are not already provided by the compiler's standard library.

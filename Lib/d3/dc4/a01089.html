Description

Centralized error creation, state tracking and observation.

The Lib::Errors::Dispatcher singleton owns every Lib::Errors::Error created through createError() and periodically scans them for state transitions. Lib::Errors::Observer (ready-made: Lib::Errors::GroupObserver) provides the pull-based read side, which can be filtered by Lib::Errors::Group.

Detailed Description

Semaphore class for RTOS synchronization.

The Semaphore class encapsulates FreeRTOS binary semaphore functionality, providing a high-level interface for thread synchronization. It supports operations like taking and giving semaphores with configurable timeouts, ISR-safe operations, and state queries.

Role: Provides synchronization primitives for RTOS tasks and interrupt service routines.

Important design decisions: Inherits from SemaphoreBase for common semaphore operations and uses RAII principles for resource management.

Lib::HAL::ADCPort< DriverMode::DMA >final

Description

DMA specialization: scans one or more regular-group channels into a caller-owned buffer via start().

ADCPortBase::getValue() (inherited) still reads the most recent conversion result. Holds the RTOS event group, the wait wrapper, the HAL callback registration and the DeviceManager wiring, none of which a blocking conversion needs.

Important
Requires USE_HAL_ADC_REGISTER_CALLBACKS set to 1 in the HAL configuration; the header fails to compile otherwise.

bool Lib::HAL::ADCPort< DriverMode::DMA >::start ( std::span< uint32_t > destination)
inlinenodiscardnoexcept

Starts a non-blocking DMA scan of the configured regular group.

Clears the pending Event bits first. The buffer is written by the DMA while the scan runs, so it must stay valid until stop(). Asserts on an unbound handle and on an empty buffer.

Parameters
destinationBuffer receiving one converted sample per configured regular channel and rank; must not be empty.
Returns
true if the HAL accepted the DMA start, false otherwise.

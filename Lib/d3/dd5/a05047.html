Counters of sent, received and rejected Digi API messages, shared by the driver and the application layer. More...

Description

Counters of sent, received and rejected Digi API messages, shared by the driver and the application layer.

Each counter is incremented from a single context (receive path or send path) and only read elsewhere, so plain 32-bit fields are used: reads are never torn on Cortex-M and no read-modify-write races with another writer.

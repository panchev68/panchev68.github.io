Lib::Ethercat::SOES::Slave< T_DERIVED, T_ESC, T_MAILBOX_SIZE >

Description

template<typename T_DERIVED, EscAccess T_ESC, size_t T_MAILBOX_SIZE = 256U>
class Lib::Ethercat::SOES::Slave< T_DERIVED, T_ESC, T_MAILBOX_SIZE >

EtherCAT slave: the application layer state machine, the process data and the mailbox of one slave controller.

Written directly on the ESC registers, so no vendor stack is needed. The class follows the master's AL control requests (INIT, PRE-OP, SAFE-OP, OP), checks the sync manager configuration the master wrote before each step up, reports a refused request or a failure through the AL status and AL status code registers, drops from OP to SAFE-OP when the process data watchdog expires, and exchanges the process data of SM2 (outputs) and SM3 (inputs), which it enables through the PDI control registers on entering OP and SAFE-OP. The mailbox is a "Mailbox"; the messages of a protocol such as CoE are handed to the derived class.

The BOOTSTRAP state is offered when the derived class says so ("isBootstrapSupported()"); the firmware update itself runs over FoE. Distributed clock synchronization is configured by the master in the ESC; the step to SAFE-OP asks the derived class to accept it ("checkDistributedClock()"). Not covered: AoE and SoE on the mailbox. CoE, FoE and EoE are the separate classes "CoE", "FoE" and "EoE" (class/): call their "handle()" from "handleMailboxMessage()". The chip is reached through any type that provides "readReg()" and "writeReg()" (the LAN9252 driver does).

The class is a CRTP base. A derived class may provide "handleMailboxMessage()", "handleMailboxIdle()", "handleStateChange()", "isBootstrapSupported()" and "checkDistributedClock()"; each replaces the default of this class. If it declares them private, it must make "Slave<...>" its friend. One task at a time may use a slave.

template<typename T_DERIVED, EscAccess T_ESC, size_t T_MAILBOX_SIZE = 256U>
Error Lib::Ethercat::SOES::Slave< T_DERIVED, T_ESC, T_MAILBOX_SIZE >::checkDistributedClock ( uint8_t syncActivation)
inlineprotected

Called on the step from PRE-OP to SAFE-OP when the master has activated distributed clock synchronization (SYNC0 / SYNC1 outputs, ESC register 0x0981).

Default: the configuration is refused, because the base class has no distributed clock support.

Parameters
syncActivationValue of the SYNC activation register: bit 0 activates the cyclic operation, bit 1 enables SYNC0, bit 2 enables SYNC1, bit 3 is the automatic activation.
Returns
"Error::NONE" to accept the configuration, otherwise the AL status code to refuse it with.

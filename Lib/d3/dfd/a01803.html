Lib::HAL::GPIO::ExtInterrupt

External Interrupt Usage Example

This example demonstrates how to configure and use external interrupts on GPIO pins in an embedded system using the ExtInterrupt class. The example shows button press detection with debouncing and event handling.

Example usage:
#include "ExtInterrupt.hpp"
#include "GPIO.hpp" // Assuming GPIO handle creation utilities
// Global variables for interrupt handling
static volatile bool buttonPressed = false;
static volatile uint32_t pressCount = 0;
// Interrupt callback function
void onButtonPress(const Lib::HAL::GPIO::ExtInterrupt * interrupt) {
// Simple debouncing - in real application, use timer-based debouncing
static uint32_t lastPressTime = 0;
uint32_t currentTime = HAL_GetTick(); // Assuming HAL tick function
if (currentTime - lastPressTime > 50) { // 50ms debounce
buttonPressed = true;
pressCount++;
lastPressTime = currentTime;
// Optional: Read pin state for additional logic
bool pinState = interrupt->read();
// Process pin state if needed
}
}
int main() {
// Initialize HAL and GPIO peripherals
HAL_Init();
// ... GPIO peripheral initialization ...
// Create GPIO handle for pin 0 on GPIOA
Lib::HAL::GPIO::Handle buttonHandle(GPIOA, 0); // Assuming GPIOA is defined
// Create ExtInterrupt instance
Lib::HAL::GPIO::ExtInterrupt buttonInterrupt(buttonHandle);
// Bind the interrupt callback
bool bindSuccess = buttonInterrupt.bind(onButtonPress);
if (!bindSuccess) {
// Handle binding failure (e.g., pin already bound)
// Error handling code here
}
// Configure HAL EXTI for falling edge (button press)
// This is typically done through HAL_GPIO_Init or similar
// GPIO_EXTI_Config(buttonHandle.getPort(), buttonHandle.getPinNumber(),
// GPIO_MODE_IT_FALLING, GPIO_PULLUP);
// Main application loop
while (true) {
if (buttonPressed) {
buttonPressed = false;
// Process button press in main loop
// This ensures interrupt context is kept minimal
printf("Button pressed! Total presses: %lu\n", pressCount);
// Application logic for button press
// e.g., toggle LED, send message, etc.
}
// Other application tasks
// ...
// Small delay to prevent busy waiting
HAL_Delay(10);
}
// Cleanup (in real application, this might not be reached)
buttonInterrupt.unbind();
return 0;
}
Configuration Notes:
  • Ensure HAL_EXTI_MODULE_ENABLED is defined in project configuration
  • Configure GPIO pin mode as interrupt-capable in HAL initialization
  • Set appropriate interrupt priority and enable NVIC interrupts
  • Consider RTOS task priorities when handling interrupts
Thread Safety:
  • Interrupt callbacks execute in interrupt context - keep them brief
  • Use volatile variables for shared data between ISR and main code
  • Consider using RTOS queues or semaphores for complex inter-task communication
Error Handling:
  • Check return values from bind() and unbind() operations
  • Handle cases where interrupt binding fails (pin already in use)
  • Implement proper cleanup in destructors and error paths

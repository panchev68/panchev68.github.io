Lib::XCOM::ServiceBase::Value64Handle

Description

Helper for tracking and updating a 64-bit value reference.

Value64Handle allows binding to an external uint64_t reference and provides utilities to detect changes, mark progress, and complete the update cycle. It is intended for lightweight change-tracking in communication or synchronization code.

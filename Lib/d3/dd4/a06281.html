RTOS::Semaphore

Shows signalling between a task and an ISR with a binary RTOS::Semaphore.

Shows signalling between a task and an ISR with a binary RTOS::Semaphore.Covers opening the semaphore, a task waiting for an event with a timeout, and an interrupt handler that gives the semaphore from ISR context. The FromISR variant must not be called from a task, and the task variant must not be called from an ISR.

Important
Call RTOS::Semaphore::open() from task context before the interrupt is enabled.

Usage

Creating the semaphore

The semaphore is created empty, so the first RTOS::SemaphoreBase::take() blocks until the ISR gives it.

#include <Lib/RTOS/FreeRTOS/Semaphore.hpp>
namespace {
RTOS::Semaphore dataReady;
}
bool createDataReady() noexcept {
return dataReady.open();
}

Signalling from the interrupt

The handler runs in ISR context, so it uses only the RTOS::SemaphoreBase::giveFromISR() variant.

#include <Lib/RTOS/FreeRTOS/Semaphore.hpp>
namespace {
RTOS::Semaphore dataReady;
}
void EXTI_DataReady_Callback() noexcept {
static_cast<void>(dataReady.giveFromISR());
}

Waiting in a task

RTOS::Semaphore::takeMs() returns false when no event arrives within the timeout.

#include <Lib/RTOS/FreeRTOS/Semaphore.hpp>
namespace {
RTOS::Semaphore dataReady;
}
void consumerTask(void * parameters) {
static_cast<void>(parameters);
if (!dataReady.open()) {
return; // Creation failed: out of heap.
}
while (true) {
if (dataReady.takeMs(100U)) {
// New data available.
} else {
// No event within 100 ms.
}
}
}

1/** FreeRTOS function utilities for task management and timing operations.
2 *
3 * Provides convenient delay and tick helper functions for FreeRTOS-based embedded
4 * applications. Includes utilities for task delays in milliseconds, tick count retrieval,
5 * and processor yielding to facilitate real-time scheduling and task coordination.
6 *
7 * The functions act as thin wrappers around Kernel utility functions, providing a clean
8 * API for common RTOS operations. All functions are inline for minimal overhead and are
9 * safe to use from task context and interrupt context where applicable.
10 *
11 * Important dependencies include the FreeRTOS Kernel for underlying timing and scheduling
12 * operations. Ensure FreeRTOS is initialized before using these functions.
13 *
14 * @note All functions are and designed for real-time embedded systems.
15 * @note Functions are thread-safe when called from task or ISR context.

27 /** Delay execution for a specified number of milliseconds.
28 *
29 * Pauses the current task for the specified duration in milliseconds, allowing
30 * the scheduler to switch to other ready tasks. The actual delay may be slightly
31 * longer due to task scheduling granularity.
32 *
33 * @param duration Number of milliseconds to delay. A value of 0 performs a yield.
34 *
35 * @note Safe to call from task context only, not from ISR.
36 * @note Other tasks with higher priority may prevent exact timing.
37 */
38 inline void delay(uint32_t duration) { Kernel::delay(duration); }

40 /** Get the current tick count in milliseconds.
41 *
42 * Retrieves the current FreeRTOS tick count and converts it to milliseconds.
43 * The tick count represents the number of ticks since FreeRTOS scheduler started.
44 *
45 * @return Current tick count in milliseconds.
46 *
47 * @note Safe to call from task context and ISR context.
48 * @note Useful for measuring elapsed time and scheduling operations.
49 */
50 inline TickType_t getTickCountMs() { return Kernel::getTickCountMs(); }

52 /** Yield the processor to another task.
53 *
54 * Allows the FreeRTOS scheduler to immediately switch to another ready task
55 * with equal or higher priority. The current task enters the ready state and
56 * can be scheduled again when its priority warrants execution.
57 *
58 * @note Useful for cooperative multitasking and load balancing.
59 * @note Safe to call from task context only, not from ISR.
60 */
61 inline void yield() { Kernel::yield(); }

Lib::HAL::I2CPort< DriverMode::IT >final

Description

Interrupt-driven (IT) master specialization.

Handle lifecycle and isReady() come from I2CPortBase; the event group, start-then-wait master transfers, abort(), HAL callback registration and DeviceManager wiring come from I2CPortAsync, shared with the DMA mode. This specialization only supplies the four HAL calls that start an interrupt-driven master transfer.

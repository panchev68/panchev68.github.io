Description

Fixed-size, lock-free single-producer/single-consumer ring buffer (circular FIFO) for elements of type 'T'.

'writePos' is written only by 'push()'/bulk-write/write-side-DMA calls and 'readPos' only by 'pop()'/bulk-read/ read-side-DMA calls, so no shared counter is mutated from both sides. Both indices are std::atomic (lock-free on Cortex-M) with release/acquire ordering, which guarantees that a slot written by the producer is visible to the consumer before the index that publishes it, and that the compiler never caches an index in a register across a polling loop. This makes one producer context (e.g. an ISR) and one consumer context (e.g. a task) safe against each other without a lock. Queries such as 'available()' still return a momentary snapshot when used across contexts. 'overwrite()' is the one exception: it advances 'readPos' from the producer side, so it must not run concurrently with 'pop()'/consumer-side reads.

All 'T_SIZE' slots are usable, no slot is sacrificed to tell full from empty: the indices run over twice the capacity, so the distance between them covers [0, T_SIZE]. When 'T_SIZE' is a power of two the indices are free-running and the slot is found by masking, otherwise they wrap at 2 * T_SIZE.

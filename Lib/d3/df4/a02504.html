Description

template<typename T_VALUE, typename T_INPUT = T_VALUE>
class Lib::Math::CubicInterpolation< T_VALUE, T_INPUT >

Cubic interpolation table and evaluator.

Implements a natural or clamped cubic spline interpolation over a set of (x, y) points. Template parameters define the numeric types used for input (T_INPUT) and output/value (T_VALUE).

Template Parameters
T_VALUEFloating point type used for computed values and coefficients.
T_INPUTFloating point type used for input abscissa values.

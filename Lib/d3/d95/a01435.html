Lib::HAL::UartPort< T_MODE >

Description

template<DriverMode T_MODE>
class Lib::HAL::UartPort< T_MODE >

UART port template for mode-specific operations.

Base class encapsulating UART port functionality with handle management, validity checks, and mode-specific implementations via template specialization. Exclusive ownership enforced through deleted copy and move constructors.

Role within the HAL UART system as a template base for different driver modes, providing type-safe UART port management with resource ownership guarantees.

Note
Exclusive ownership prevents accidental handle sharing between instances.
Template Parameters
T_MODEThe UART driver mode defining operational characteristics.

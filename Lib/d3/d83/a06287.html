RTOS::Task

Shows creating an RTOS::Task, synchronizing it with notification event bits, and stopping it.

Shows creating an RTOS::Task, synchronizing it with notification event bits, and stopping it.A worker task waits for an event bit and a controller fires that bit. The entry callable is stored in place inside the task wrapper, so a capturing lambda such as '[this]' needs no heap allocation. It must be trivially copyable and fit RTOS::Task::ENTRY_CAPACITY bytes. Receiving calls such as RTOS::Task::Notify::waitForBits() must run in the task itself.

Usage

Worker task with event bits

#include <Lib/RTOS/FreeRTOS/Task.hpp>
#include <Lib/RTOS/FreeRTOS/TickCounter.hpp>
#include <chrono>
#include <cstdint>
using namespace std::chrono_literals;
class Worker {
public:
static constexpr uint32_t WORK_BIT = 0x01U; ///< Event bit requesting one unit of work.
bool begin() noexcept {
task.setup({"Worker", 256, RTOS::Task::Priority::NORMAL});
return task.start([this] { taskEntry(); }) != nullptr;
}
void requestWork() noexcept {
static_cast<void>(task.notify.fireEvent(WORK_BIT));
}
bool end() noexcept {
return task.stop();
}
private:
RTOS::Task task;
void taskEntry() noexcept {
while (true) {
if (task.notify.waitForBits(WORK_BIT, RTOS::TickCounter::toTicks(500ms))) {
// Perform the requested work.
}
}
}
};

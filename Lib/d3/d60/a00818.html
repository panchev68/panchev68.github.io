Description

Calendar date and time-of-day value types with compact 32-bit packing and std::chrono interoperability.

All calendar arithmetic (leap years, month lengths, day of week, day of year, epoch conversion) is delegated to the C++20 std::chrono calendar, which is fully constexpr and implements the proleptic Gregorian calendar. Packing into 32 bits is intended for persistent storage such as OTP or backup registers.

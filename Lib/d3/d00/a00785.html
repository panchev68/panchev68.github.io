Lib::BSP::EEPROM::I2C::M24C64W

Description

M24C64W I2C EEPROM driver with 8192-byte capacity.

Implements a concrete I2C EEPROM driver for the M24C64W device. The M24C64W is an 8192-byte (8K) EEPROM with 32-byte page size, suitable for high-capacity configuration and non-volatile data storage in embedded systems. This driver uses 16-bit memory addressing mode required for the larger address space.

Design details. Uses the DriverBase class as a foundation for I2C communication, inheriting timeout handling, page-aligned write optimization, and connection management. The class is marked as final since specialized addressing (16-bit mode) is standardized for M24C64W variant support.

Note
M24C64W addresses range from 0x0000 to 0x1FFF (8192 bytes).
Page operations are aligned to 32-byte boundaries for optimal write performance.
Uses 16-bit addressing mode to support the larger address space.

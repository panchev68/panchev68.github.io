Lib::Ethercat::SOES::CoEfinal

Description

CANopen over EtherCAT (CoE): the SDO server and the SDO information service of an EtherCAT slave.

Serves the object dictionary of the slave to the master over the mailbox. It handles the SDO upload (read) and download (write) of an object, expedited (up to 4 bytes), normal (the whole value in one mailbox message) and segmented (a value split over several messages), checks the access rights of the object against the AL state, lets the application validate and react to a transfer, and answers a failed request with an SDO abort. The SDO information service lists the objects (also over several fragments) and describes an object and its entries, from the names, data types and sizes in the dictionary.

Not covered: complete access (answered with the abort for "complete access not supported") and the object lists other than "all objects".

The dictionary is a table given by the application, ordered by index and then subindex, with the entries of one object next to each other; this class owns no data. Use it from the mailbox handler of a "Slave": pass every message to "handle()", call "service()" in the idle hook of the slave, and "reset()" when the mailbox stops.

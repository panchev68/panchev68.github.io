Description

Device Manager Base Class.

This file defines a base template class for managing devices in the HAL layer. It provides functionality to add, find, and remove devices using handles, serving as a foundation for specific device managers in embedded systems.

Depends on std::unordered_map for storage and Handle.hpp for handle types.

Note
This is a singleton base class; use instance() to access.
Attention
Ensure thread-safety if used in multi-threaded environments.

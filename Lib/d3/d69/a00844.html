Lib::BSP::Ethercat::PDI::LAN9252::Base

Description

Base class for LAN9252 EtherCAT slave controller.

Encapsulates initialization, reset and register access for the LAN9252 device.

bool Lib::BSP::Ethercat::PDI::LAN9252::Base::resetChip ( )
inline

Reset the LAN9252 device and wait until it responds with a valid chip ID.

The method drives the reset pin low for a short period, then polls the device until a valid chip ID is observed or a timeout elapses.

Returns
true when reset and verification succeeded, false on timeout or error.

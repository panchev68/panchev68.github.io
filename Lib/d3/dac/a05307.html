Lib::HAL::ADCPort< DriverMode::DMA >final

Description

DMA specialization: scans one or more regular-group channels into a caller-owned buffer via 'start(destination)'.

getValue() (inherited) still peeks at the most recent conversion. Holds the RTOS event group, the wait wrapper, the HAL callback registration and the DeviceManager wiring, none of which a blocking conversion needs.

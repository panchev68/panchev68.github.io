Lib::Helper::Singleton< T >

Description

template<typename T>
class Lib::Helper::Singleton< T >

Singleton template class.

Provides a base class for implementing the Singleton pattern. Derived classes inherit the Singleton behavior, ensuring only one instance exists. The instance is created on first access and persists for the program's lifetime.

Template Parameters
TThe type that will be made a singleton (usually the derived class).

Lib::BSP::RFID::ST25R100< T_MODE >

Description

template<Lib::HAL::DriverMode T_MODE>
class Lib::BSP::RFID::ST25R100< T_MODE >

Driver for the ST25R100 NFC controller: SPI comms, IRQ handling, ISO14443A protocol ops.

Provides lifecycle control, register access, and protocol orchestration for NFC-A/ISO14443A. The driver owns no peripheral of its own: every bus access is routed through the SPI port bound in Config::spiPort. Each transaction is a single full-duplex transfer, so chip select (driven by the port's transaction hooks) frames the command byte and the data that follows it within one selection window.

Template Parameters
T_MODETransfer mode of the bound Lib::HAL::SPIPort instance.

Waits for Register::FIFO_STATUS_1 to stop growing (unchanged across two consecutive polls) before reading, not just for it to become nonzero, so a reply that is still being clocked in is not read prematurely.

inlinenodiscardnoexcept

Masks or unmasks 'IRQ_MASK_1/2' (tx/rx frame-level sources).

Masking only gates the physical 'nIRQ' pin, not the status latch; a direct 'IRQ_STATUS_1/2' poll is unaffected.

Unmasking first reads 'IRQ_STATUS_1/2' to clear the bits latched while the sources were masked. Otherwise the device sets 'nIRQ' high at the moment of unmasking (DS14139, Interrupt interface) and keeps it high, because nothing else reads those two registers: no further rising edge reaches the host, so a later wake-up event would never wake the processing task.

Parameters
maskedtrue to mask (block the pin), false to unmask.
Returns
true on success.

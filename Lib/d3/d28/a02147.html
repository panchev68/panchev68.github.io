Description

Utility unions for LAN9252 EtherCAT slave controller.

This header provides the Helper class, which encapsulates unions for efficient conversion between integer types and their corresponding byte, word, and dword representations. These utilities are essential for low-level register access and communication with the LAN9252 EtherCAT slave controller, enabling precise manipulation of data formats.

No external dependencies; provides standalone utilities for type conversions.

Unions are designed for performance-critical embedded code; ensure proper byte order handling for the target platform.

Lib::HAL::Timer::TimOnePulsefinal

Description

Controls a hardware timer configured in One-Pulse Mode.

Maps the output channel's compare interrupt through the DeviceManager to a task notification, so a task blocked in waitPulseStart() wakes when a pulse starts.

In OPM, channels 1 and 2 are always used together: one is the output, the other the trigger input. After a trigger the counter runs from 0 to ARR once; with PWM mode 2 (or PWM mode 1 with inverted polarity) the output is inactive while the counter is below CCRx and active from CCRx up to ARR. The compare interrupt therefore fires when the pulse starts, not when it ends.

Description

Static utility class providing kernel-level control and diagnostics.

Covers critical sections, scheduler locking, system time delays, and kernel diagnostic information.

Fills a snapshot of every task in the system; requires "configUSE_TRACE_FACILITY".

Task context only.

Runs with the scheduler suspended and walks every task list, so it is meant for debugging, not for normal operation. Size "tasks" with "getNumberOfTasks()", plus some margin for tasks created meanwhile.

Parameters
[out]tasksDestination for one entry per task.
[out]totalRunTimeTotal run time counter, if non-null and "configGENERATE_RUN_TIME_STATS" is set; otherwise left unchanged or written as 0 by the kernel.
Returns
Number of entries written, or 0 if "tasks" is too small to hold every task.

◆ toTimerCommandBlockTime()

TickType RTOS::Kernel::toTimerCommandBlockTime ( TickType requested)
inlinestaticnodiscardnoexcept

Limits the block time of a software timer command to what is safe in the calling task.

The timer daemon task is the only consumer of the timer command queue, so a command issued from a timer callback that blocked on a full queue would wait forever for itself. Task context only; ISRs use the "FromISR" commands, which never block.

Parameters
requestedBlock time requested by the caller, in ticks.
Returns
"requested", or 0 when called from the timer daemon task while the scheduler runs. Without "xTaskGetCurrentTaskHandle()" the daemon cannot be detected and "requested" is returned unchanged.

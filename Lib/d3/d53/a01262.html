Lib::Digi::Core::RemoteAtCommand

Description

RemoteAtCommand class for Digi XBee modules.

Provides methods to send and receive remote AT commands using Digi XBee modules. The class encapsulates frame construction, transmission, and response handling, ensuring reliable communication and integration with Digi XBee modules.

Description

COP (CoE) helper providing minimal CANopen-over-EtherCAT (CoE) glue for the EtherCAT stack integration.

This header exposes a small, header-only utility type that forwards platform-specific CoE operations (declared in the native SOES header) to the higher-level stack. Implementers should consult the underlying SOES definitions for details about object dictionary layout and lifecycle.

Lib::BSP::EncoderTimer

Demonstrates a timer-mode rotary encoder with a push button, polled from a menu task.

Demonstrates a timer-mode rotary encoder with a push button, polled from a menu task.TIM3 is set to encoder mode in CubeMX and the button pin, named ENC_BTN, is an EXTI on both edges with a pull-up, so the 'PIN()' macro can build its handle. The task polls Lib::BSP::EncoderTimer::read() every 10 ms. Holding the button for 'BUTTON_HOLD_TIME' resets the position.

Important
Poll faster than one detent can be turned: several steps between two calls make only one event.
Warning
Cannot share a program with 'Lib::BSP::EncoderPins', which needs its own 'HAL_GPIO_EXTI_Callback()'.
See also
Lib::BSP::EncoderTimer, Lib::BSP::EncoderTimer::Config, Lib::BSP::EncoderTimer::EventCode
Example usage:
#include <Lib/BSP/Encoder/EncoderTimer.hpp>
#include <Lib/RTOS/FreeRTOS/Kernel.hpp>
#include <chrono>
#include <cstdint>
extern "C" TIM_HandleTypeDef htim3; // TIM3 in encoder mode, generated by CubeMX.
using namespace std::chrono_literals;
Lib::BSP::EncoderTimer encoder{{
.handle = &htim3,
.button = PIN(ENC_BTN),
}};
void menuTask() {
if (!encoder.open()) {
return;
}
using Event = Lib::BSP::EncoderTimer::EventCode;
int32_t position = 0;
while (true) {
switch (encoder.read()) {
case Event::ENCODER_CW:
++position;
break;
case Event::ENCODER_CCW:
--position;
break;
case Event::BUTTON_HOLD:
position = 0; // Held for BUTTON_HOLD_TIME: reset.
break;
default:
break; // Nothing, push or release.
}
RTOS::delay(10ms);
}
}

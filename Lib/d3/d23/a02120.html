Description

Register definitions for ILI9341 display controller.

This header defines all command and control register addresses for the ILI9341 TFT LCD display controller. Provides enumerated constants for display initialization, configuration, and data transmission commands.

Important dependencies or interactions with other modules. Used by ILI9341 driver for register access and command transmission.

Any special instructions or notes for users of the file. Register values are specific to ILI9341 controller; verify compatibility before use.

Note
All register addresses are 8-bit values as per ILI9341 datasheet specifications.

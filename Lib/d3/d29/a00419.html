Description

TimerMode header file.

This file defines the TimerMode enum class, which specifies the operational modes for timers in the HAL layer. It provides a type-safe way to configure timer behavior, including normal operation, PWM generation, output compare, and encoder modes.

The TimerMode enum is used throughout the HAL core TIM module to ensure consistent and safe timer mode selection, preventing invalid configurations in embedded systems.

Note
This enum is designed for use with STM32 HAL library and FreeRTOS-based applications.
Attention
Ensure that the selected mode is supported by the target hardware and HAL implementation.

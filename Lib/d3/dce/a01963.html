Lib::HAL::GPIO::Outputfinal

Description

Represents a discrete hardware output pin capable of state driving and active reading.

Extends the "Input" abstraction with synchronous writing and toggling operations that map directly to the STM32 GPIO registers.

Reads the instantaneous logical state of the physical input line.

The constructor already asserts a valid port; the runtime check only protects a release build (where "assert" is compiled out) from dereferencing a null port.

Returns
"true" if the input is logical HIGH, "false" if logical LOW or the underlying port handle is invalid.

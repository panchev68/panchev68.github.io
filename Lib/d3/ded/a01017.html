Lib::Canbus

Description

CAN bus client/server service layer built on Lib::HAL::CANPortBase.

Mirrors the HAL Lib::HAL::DriverMode shape but for roles: client and server Service specializations share a non-template ServiceBase owning the CAN port, two RTOS tasks, an RX queue and diagnostics counters.

RTOS::Kernel::CriticalSection

Description

RAII wrapper for critical sections.

This class provides automatic management of FreeRTOS critical sections using the RAII (Resource Acquisition Is Initialization) idiom. Upon construction, it enters a critical section, disabling task switching and interrupts to ensure atomic operations. Upon destruction, it automatically exits the critical section, restoring normal operation. This prevents common errors like forgetting to exit critical sections and ensures exception safety.

Note
Critical sections should be kept as short as possible to minimize system latency.
Attention
Do not use in interrupt service routines; use CriticalSectionISR instead.

RTOS::TickService::ClientBase

TickService Client Implementation Example

This example demonstrates how to create a client that inherits from TickService::ClientBase to receive periodic tick events. The client is automatically registered upon construction and unregistered upon destruction.

Example usage:
#include "Lib/RTOS/TickService.hpp"
class MyTickClient : public RTOS::TickService::ClientBase {
public:
MyTickClient() : ClientBase(10) {} // Update every 10 ticks
void handleTickEvent() override {
// Perform periodic actions on tick event
tickCount++;
}
private:
int tickCount = 0;
};
int main() {
MyTickClient client;
// TickService starts automatically when first client registers.
// In a real RTOS application, the scheduler runs here.
return 0;
}

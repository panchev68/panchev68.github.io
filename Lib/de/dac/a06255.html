Lib::Math::Filter::Kalman

Smooths a noisy measurement such as an ADC reading with Lib::Math::Filter::Kalman.

Smooths a noisy measurement such as an ADC reading with Lib::Math::Filter::Kalman. The filter estimates one value recursively: every call of its call operator takes a new sample and returns the filtered estimate. It keeps its state in double, accepts an integral or a floating-point sample type and is not thread-safe, so call it from one context only.

Configuration

Lib::Math::Filter::Kalman::Config sets three noise terms and the starting value. A larger sensor noise makes the output smoother and slower; a larger process noise makes it follow real changes faster. The terms must be finite and non-negative.

#include <Lib/Math/Filter/Kalman.hpp>
#include <cstdint>
using AdcFilter = Lib::Math::Filter::Kalman<uint16_t>;
AdcFilter makeFilter() noexcept {
AdcFilter::Config config;
config.processNoise = 0.01;
config.sensorNoise = 4.0;
config.estimatedError = 1.0;
config.value = 2048U;
return AdcFilter(config);
}

Filtering ADC samples

Feed every raw sample to the filter and use the returned value. The result is converted to the sample type, so a uint16_t filter returns whole ADC counts.

#include <Lib/Math/Filter/Kalman.hpp>
#include <cstdint>
Lib::Math::Filter::Kalman<uint16_t> filter(Lib::Math::Filter::Kalman<uint16_t>::Config{});
// Called from the task that receives the conversion results.
uint16_t onAdcSample(uint16_t raw) noexcept {
return filter(raw);
}

Floating-point signal

Use a floating-point sample type for a physical quantity. Pass the first measurement as the starting value so the estimate does not have to converge from zero.

#include <Lib/Math/Filter/Kalman.hpp>
Lib::Math::Filter::Kalman<float> makeTemperatureFilter(float firstReading) noexcept {
Lib::Math::Filter::Kalman<float>::Config config;
config.sensorNoise = 0.25;
config.value = firstReading;
return Lib::Math::Filter::Kalman<float>(config);
}

Reset and new parameters

Lib::Math::Filter::Kalman::reset() returns the estimate and the error to their starting values, for example after the input channel was switched. Lib::Math::Filter::Kalman::setParam() loads a new configuration but keeps the running estimate until the next Lib::Math::Filter::Kalman::reset().

#include <Lib/Math/Filter/Kalman.hpp>
#include <cstdint>
void switchChannel(Lib::Math::Filter::Kalman<uint16_t> & filter) noexcept {
Lib::Math::Filter::Kalman<uint16_t>::Config config;
config.sensorNoise = 16.0;
config.value = 0U;
filter.setParam(config);
filter.reset();
}

Description

XCOM service base class and utilities.

Defines the Lib::XCOM::ServiceBase base class for XCOM services, providing utility functions for serialization and value tracking. Includes helper methods for converting values to and from byte vectors, as well as a handle class for tracking changes to 64-bit values with support for binding, status management, and change detection.

Note
The Value64Handle class is designed for tracking external variable changes through binding and is useful for detecting modifications in communication protocols.

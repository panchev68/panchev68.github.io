Description

XCOM/XBEE frame protocol implementation.

Implements framing, escaping and CRC16 checksum calculation to build and parse XCOM frames over a byte stream, working entirely on caller-supplied buffers so a frame can be assembled or decoded from an interrupt-driven receive path.

RTOS::MemoryManager

Shows allocating and releasing heap memory through RTOS::MemoryManager with status reporting.

Shows allocating and releasing heap memory through RTOS::MemoryManager with status reporting.Covers a checked allocation that reports why it failed, a release, and reading the heap usage percentage. Allocation and release are task-context only and must not be called from an ISR.

Warning
Release only pointers returned by RTOS::MemoryManager::allocate(), and release each one exactly once. With 'MEMORY_MANAGER_DIAG' defined, any other pointer corrupts the heap, because its allocation header is read back.

Usage

Checked allocation

RTOS::MemoryManager::allocate() reports the reason for a failure through the optional status argument.

#include <Lib/RTOS/FreeRTOS/MemoryManager.hpp>
#include <cstdint>
#include <span>
void useBuffer() noexcept {
RTOS::MemoryManager::Status status = RTOS::MemoryManager::Status::SUCCESS;
void * block = RTOS::MemoryManager::allocate(256U, &status);
if (status != RTOS::MemoryManager::Status::SUCCESS) {
return; // INVALID_SIZE, SIZE_TOO_LARGE or OUT_OF_MEMORY.
}
const std::span<uint8_t> buffer(static_cast<uint8_t *>(block), 256U);
static_cast<void>(buffer);
RTOS::MemoryManager::deallocate(block);
}

Checking heap usage

RTOS::MemoryManager::getHeapUsagePercent() returns the used share of the heap, from 0 to 100.

#include <Lib/RTOS/FreeRTOS/MemoryManager.hpp>
bool canDoOptionalWork() noexcept {
return RTOS::MemoryManager::getHeapUsagePercent() <= 90U;
}

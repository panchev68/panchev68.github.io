RTOS::PowerManager

Shows enabling tickless low-power idle with RTOS::PowerManager, registering peripheral callbacks around deep sleep and holding a deep-sleep lock while a peripheral is busy.

Shows enabling tickless low-power idle with RTOS::PowerManager, registering peripheral callbacks around deep sleep and holding a deep-sleep lock while a peripheral is busy.The manager puts the MCU into STOP1 deep sleep when the expected idle time is long enough, and into light sleep (plain __WFI()) otherwise. It needs a low-power timer to wake the scheduler, and it is a singleton, so RTOS::PowerManager::instance() is used everywhere.

Important
The class is compiled only when 'FREERTOS_LOW_POWER_SUPPORT', 'HAL_LPTIM_MODULE_ENABLED' and 'LPTIM1' are defined, 'main.h' and 'FreeRTOS.h' are on the include path, and 'USE_HAL_LPTIM_REGISTER_CALLBACKS' is 1. 'configUSE_TICKLESS_IDLE' must be 1 or 2 in 'FreeRTOSConfig.h'. On a target where these are absent the whole class compiles to nothing.
Define 'RTOS_POWER_MANAGER_IMPLEMENTATION' in exactly one '.cpp' file before including the header. That file emits the kernel hook 'vPortSuppressTicksAndSleep()'; without it the port's own weak implementation runs.
Warning
Deep sleep is withheld while a debugger is attached. Stop mode can make SWD and Live Watch lose the connection, so the manager checks RTOS::PowerManager::isDebuggerAttached() first.

Setup and sleep callbacks

RTOS::PowerManager::setup() binds the Lib::HAL::LPTimer that wakes the scheduler; the timer must be opened first. The callbacks run only around each STOP1 entry, not around light sleep, so they should save and restore only the peripheral state that Stop mode loses.

#include <Lib/HAL/TIM/LPTimer.hpp>
#include <Lib/RTOS/FreeRTOS/PowerManager.hpp>
// CubeMX-generated LPTIM handle, declared at global scope so it links to the definition in the CubeMX sources.
extern LPTIM_HandleTypeDef hlptim1;
namespace {
Lib::HAL::LPTimer lowPowerTimer(&hlptim1, LPTIM_CHANNEL_1); // The LPTIM channel the wrapper configures.
void uartPreSleep() {
// Save the UART state and gate its clock.
}
void uartPostSleep() {
// Restore the UART clock and state.
}
} // namespace
bool setupLowPower() {
if (!lowPowerTimer.open()) {
return false;
}
auto & manager = RTOS::PowerManager::instance();
if (!manager.setup(lowPowerTimer)) {
return false;
}
return manager.registerPreSleepCallback(&uartPreSleep) && manager.registerPostSleepCallback(&uartPostSleep);
}

Deep-sleep lock

A RTOS::PowerManager::DeepSleepLock blocks Stop mode for its lifetime. The guard is released at the end of the scope, so the peripheral must finish its transfer inside it.

#include <Lib/RTOS/FreeRTOS/PowerManager.hpp>
void transferWithClock() {
const RTOS::PowerManager::DeepSleepLock lock; // Blocks Stop mode until the end of this scope.
// Run the transfer that needs the peripheral clock.

Checking statistics

RTOS::PowerManager::getStatistics() returns a snapshot of how often each sleep mode was entered. A deep-sleep count that stays at zero usually means a debugger is attached or a lock is held.

#include <Lib/RTOS/FreeRTOS/PowerManager.hpp>
bool deepSleepSeen() {
const RTOS::PowerManager::Statistics stats = RTOS::PowerManager::instance().getStatistics();
return stats.deepSleepCount > 0U;
}

Description

GPIO pin abstractions, including externally-triggered interrupt (EXTI) input pins.

Provides input and output pin wrappers. EXTI-driven input pins share one worker task that runs their callbacks, so the interrupt only sets a bit in the task's notification and the callback never runs in the ISR.

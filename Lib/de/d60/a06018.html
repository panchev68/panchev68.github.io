Lib::Math::Filter::ExponentialSmoothing< T_TYPE >final

Description

template<typename T_TYPE = float>
requires std::is_arithmetic_v<T_TYPE>
class Lib::Math::Filter::ExponentialSmoothing< T_TYPE >

Exponential moving average: every sample moves the output a fixed fraction towards itself.

The output follows y += alpha × (x - y). A small alpha gives a slow, smooth output and a large one a fast, noisy output; alpha = 1 passes the input unchanged. Unlike Lib::Math::Filter::MovingAverage it needs no buffer, only one value, so it suits a heavy smoothing of a slow signal, such as the temperature shown on a display, where a long window would need a lot of memory. It does not reject a single wild sample, which only fades away over many samples. The first sample sets the output directly, so there is no start-up ramp from zero. The state is kept in the floating-point type of the sample, or in float for an integral sample, and the result is rounded to the nearest integer. The filter is not thread-safe: call it from one context only.

Template Parameters
T_TYPESample and result type, integral or floating-point.

Lib::BSP::IS62WV51216

Demonstrates a concrete SRAM class on top of the CRTP base, with a post-write hook, used from a task.

Demonstrates a concrete SRAM class on top of the CRTP base, with a post-write hook, used from a task.The chip sits on FSMC bank 1, chip select NE3, so it appears at 0x68000000. Offsets passed to Lib::BSP::IS62WV51216::read() and Lib::BSP::IS62WV51216::write() are relative to that base. The derived class shadows Lib::BSP::IS62WV51216::onMemoryChanged() to count writes and befriends the base so the hook can stay private.

Important
CubeMX MX_FSMC_Init() must run before the first transfer.
Warning
The hook runs with the mutex held and the mutex is not recursive: calling Lib::BSP::IS62WV51216::read() or Lib::BSP::IS62WV51216::write() from it deadlocks.

Write and read back a record from a task

The derived class passes its Lib::BSP::IS62WV51216::Config to the base constructor. Lib::BSP::IS62WV51216::write() and Lib::BSP::IS62WV51216::read() take a span of bytes; the offset is relative to the base address.

#include <Lib/BSP/RAM/IS62WV51216.hpp>
#include <array>
#include <cstddef>
#include <cstdint>
#include <span>
class FrameStore final : public Lib::BSP::IS62WV51216<FrameStore> {
friend class Lib::BSP::IS62WV51216<FrameStore>; // The base calls onMemoryChanged().
public:
static constexpr Config CONFIG{.baseAddress = 0x68000000U, .sizeBytes = 1024U * 1024U};
FrameStore() noexcept :
IS62WV51216(CONFIG) {
}
[[nodiscard]] uint32_t getWriteCount() const noexcept {
return writeCount;
}
private:
uint32_t writeCount{0U};
void onMemoryChanged([[maybe_unused]] uintptr_t absoluteAddress, [[maybe_unused]] size_t size) noexcept {
++writeCount; // Runs with the mutex held: no read()/write() here.
}
};
FrameStore sram;
void loggerTask() {
if (!sram.open()) {
return; // Out of heap for the mutex.
}
const std::array<std::byte, 4> record{std::byte{0xDE}, std::byte{0xAD}, std::byte{0xBE}, std::byte{0xEF}};
if (!sram.write(0x100U, std::span<const std::byte>{record})) {
return;
}
std::array<std::byte, 4> readBack{};
static_cast<void>(sram.read(0x100U, std::span<std::byte>{readBack}));
}

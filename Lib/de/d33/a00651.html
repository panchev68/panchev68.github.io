enum class Lib::Canbus::Mode : uint8_t
strong

CAN bus operation modes.

This enum class defines the fundamental operation modes for CAN bus services within the library. Each mode represents a distinct communication role that influences how the service interacts with the CAN network, handles messages, and manages connections. The modes are designed to be mutually exclusive and provide type-safe configuration for CAN bus operations.

The enum uses uint8_t as the underlying type for efficient storage and compatibility with embedded systems. Values are explicitly defined to ensure consistent behavior across different platforms.

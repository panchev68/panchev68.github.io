Description

Namespace for error handling classes and functions.

The Lib::Errors namespace contains all abstractions, helpers, and types related to error codes, status enums, and error handling utilities for embedded and real-time systems. All error-related code should reside within this namespace to ensure modularity, consistency, and maintainability.

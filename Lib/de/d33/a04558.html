Lib::BSP::GSM::A7670E::Filefinal

Handle-based access to one file on the modem file system, in the manner of fopen() with fread(), fwrite(), fseek() and fclose(). More...

Description

Handle-based access to one file on the modem file system, in the manner of fopen() with fread(), fwrite(), fseek() and fclose().

Only one File can be open at a time, because the number of modem file handles is not documented. Data lives in the modem flash.

Warning
read() returns 0 both at the end of the file and on an error, because the modem does not document what it returns at the end of the file.
Important
Destroying an open File closes it.

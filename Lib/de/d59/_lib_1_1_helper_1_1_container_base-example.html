Lib::Helper::ContainerBase

Basic usage of ContainerBase for managing a collection of integers.

This example demonstrates how to use the ContainerBase template class to manage a simple collection of integers. It shows adding items, checking for existence, removing items, and iterating over the collection.

Example usage:
#include "Lib/Helper/ContainerBase.hpp"
#include <iostream>
int main() {
Lib::Helper::ContainerBase<int> container;
// Add items to the container
container.add(10);
container.add(20);
container.add(10); // Duplicate, will not be added
// Check size and emptiness
std::cout << "Size: " << container.size() << std::endl; // Output: Size: 2
std::cout << "Is empty: " << (container.isEmpty() ? "Yes" : "No") << std::endl; // Output: Is empty: No
// Access items by index
std::cout << "Item at index 0: " << container[0] << std::endl; // Output: Item at index 0: 10
// Iterate over items
container.each([](int &item) {
std::cout << "Item: " << item << std::endl;
});
// Output:
// Item: 10
// Item: 20
// Remove an item
container.remove(10);
std::cout << "Size after removal: " << container.size() << std::endl; // Output: Size after removal: 1
// Clear the container
container.clear();
std::cout << "Size after clear: " << container.size() << std::endl; // Output: Size after clear: 0
return 0;
}

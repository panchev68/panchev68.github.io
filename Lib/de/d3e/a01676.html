Lib::BSP::EEPROM::I2C::M24C64W

Description

I2C EEPROM driver implementing page-aware read/write with 16-bit addressing.

This implementation provides safe access to a 64-Kbit EEPROM device using 16-bit addressing. It validates addresses and buffer lengths and delegates low-level I2C operations to the underlying DriverBase.

Note
  • Page size: 32 bytes
  • Total capacity: 8192 bytes

Read bytes from EEPROM using 16-bit addressing.

Reads 'size' bytes starting at 'address' into 'buffer'. The implementation ensures reads do not exceed the device capacity and delegates the low-level transfer to the 16-bit addressing helper.

Parameters
addressStarting EEPROM address to read from. Must be less than CHIP_SIZE.
bufferPointer to destination buffer. Must be non-null and able to hold 'size' bytes.
sizeNumber of bytes to read.
Returns
'true' on success, 'false' on failure.
Precondition
  • 'buffer' must be non-null and large enough for 'size' bytes.
  • The address range (address .. address+size-1) must be within the EEPROM capacity.

Writes 'size' bytes from 'buffer' starting at 'address'. Page boundary crossings are handled by the underlying page programming logic to ensure correct EEPROM programming behavior.

Precondition

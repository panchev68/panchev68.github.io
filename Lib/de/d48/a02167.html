Description

Ethernet user protocol class header file.

This file defines the UserProtocol class, which provides functionality for building, parsing, and handling Ethernet user protocol messages. It supports message construction with headers and payloads, parsing of incoming messages, and callback mechanisms for processing commands and updates. The class ensures type safety, bounds checking, and input validation suitable for embedded networking applications. It includes support for custom callbacks, error handling, and integration with HAL for timestamping.

Important dependencies or interactions with other modules: Relies on HAL_GetTick() for timestamps and standard library functions for memory operations. Interacts with network layers for message transmission and reception.

Any special instructions or notes for users of the file: Ensure that callback functions are implemented in derived classes to handle specific protocol behaviors. Validate message data before parsing to avoid errors.

Note
This class is designed for use in real-time embedded systems with FreeRTOS.
Attention
Handle memory carefully in payload processing to avoid buffer overflows.

Lib::Ethernet::UserProtocol

Description

Base class implementing message framing and dispatch for a simple user protocol.

Derive from this class and override the virtual callbacks to handle specific commands and events. Parsing and building use a compact MessageHeader defined below.

Parses the payload as an array of uint64_t values (one per node) and forwards them to callbacks. The 'isInputs' flag selects which callback is used for each entry.

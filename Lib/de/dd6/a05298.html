Lib::Ethernet::Wiznet::W5500final

Register access and basic configuration of the Wiznet W5500 Ethernet controller over SPI. More...

Description

Register access and basic configuration of the Wiznet W5500 Ethernet controller over SPI.

Talks to the chip in variable-length data mode (the NSS pin stays low for a whole frame), with an externally owned SPI port and a chip-select pin. The register map and the frame format follow the W5500 datasheet; no vendor driver is needed.

One chip transaction is a sequence of SPI transfers, so the object must be used by one task at a time (the TCP client in 'ClientBase' is that one task).

Description

Blocking specialization.

Builds directly on SPIPortBase and stores the native handle itself, rather than through 'Device': that class brings an intrusive DeviceManager list link that only an interrupt-driven mode uses, and this mode never registers with the DeviceManager. A blocking transfer completes inside the HAL call itself, so it has no RTOS event group to wait on, no HAL callback to register and nothing to abort once the starting call has returned; that policy lives in SPIPortAsync, shared by the 'IT' and 'DMA' specializations.

Lib::GUI::Displayfinal

Description

One-bit display as the GUI layer sees it: a size and the functions that reach the real driver.

The class is not a template and knows no driver type. It stores the width and height and three optional functions that the application binds once: one that sets a single pixel, one that clears the frame buffer and one that sends it to the panel. The shape drawing in Lib::GUI::Primitives and everything above it works only through Lib::GUI::Display::setPixel(), so any driver that can set a pixel can be used, such as Lib::BSP::Display::SSD1306. A pixel outside the display is dropped before the function is called. Without a clear function the display is cleared pixel by pixel; without a flush function Lib::GUI::Display::flush() does nothing.

Lib::BSP::Ultrasonic::PGA460TPWRQ1< T_MODE >

Description

template<Lib::HAL::DriverMode T_MODE>
class Lib::BSP::Ultrasonic::PGA460TPWRQ1< T_MODE >

Reads the current distance from a PGA460 ultrasonic sensor connected over UART.

A "P1BL" burst-and-listen command triggers a measurement and a subsequent "UMR" request reads back the closest object's time of flight, converted to a distance using the temperature-compensated speed of sound. The UART port is shared by reference, not owned. The listen wait uses "RTOS::delay()" so the calling task yields instead of busy-blocking.

Besides the distance the driver can read and write single registers ("readRegister()", "writeRegister()") and read the transducer frequency and decay period measured during a burst ("readTransducerDiagnostics()"), which shows whether the burst frequency matches the transducer. Registers written this way live in RAM and are lost at power-down; they are reloaded from the EEPROM at the next power-up.

See PGA460TPWRQ1 usage for a usage example and a periodic measurement task.

std::optional< TransducerDiagnostics > Lib::BSP::Ultrasonic::PGA460TPWRQ1< T_MODE >::readTransducerDiagnostics ( )
inlinenodiscardnoexcept

Runs a burst and reads the transducer frequency and decay period measured during it.

Sends "P1BL", waits the configured listen duration and then asks for the system diagnostics (command 8, valid only after a burst). The frequency is not saved if an object was detected before the measurement window ended, so a near object or a threshold set too low gives "std::nullopt".

Returns
The measured values, or "std::nullopt" on a communication error, a checksum mismatch or when no frequency was measured.

template<Lib::HAL::DriverMode T_MODE>
bool Lib::BSP::Ultrasonic::PGA460TPWRQ1< T_MODE >::writeRegister ( uint8_t address,
uint8_t value )
inlinenodiscardnoexcept

Writes one register.

The write is not verified; read the register back to check it. A write to a register that the device reloads from its EEPROM at power-up (0x00..0x2B) lasts only until the next power-down. Writing "PULSE_P1" (0x1E) can switch the device from the UART to the time-command interface (bit 7), so change only the bits you mean to.

addressRegister address.
valueNew register value.
Returns
"true" if the frame was sent.

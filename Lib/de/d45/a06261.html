Lib::Math::Pid

Controls a process variable such as a heater temperature with Lib::Math::Pid.

Controls a process variable such as a heater temperature with Lib::Math::Pid. The controller keeps no timer of its own: call Lib::Math::Pid::compute() once per sample time from a single context, for example a periodic task, and apply the returned output to the actuator. The class is not thread-safe, so guard an instance shared between contexts with a mutex. The snippets use the single-precision alias Lib::Math::PidF.

Automatic mode and output limits

A new controller starts in manual mode, so call Lib::Math::Pid::setMode() with true before the first Lib::Math::Pid::compute(). The output is clamped to Lib::Math::Pid::Parameters::outputMin and Lib::Math::Pid::Parameters::outputMax, and the integral term is held back so that it cannot wind up beyond them.

#include <Lib/Math/Pid.hpp>
Lib::Math::PidF heater(Lib::Math::PidF::Parameters{2.0F, 4.0F, 0.0F, 0.25F, 0.0F, 100.0F});
// Called every 0.25 seconds from a control task.
void controlStep(float setpoint, float measuredTemperature) noexcept {
const float duty = heater.compute(setpoint, measuredTemperature);
// Apply duty (0 to 100 percent) to the heater PWM.
static_cast<void>(duty);
}
void controlStart() noexcept {
heater.setMode(true);
}

Manual mode and bumpless transfer

In manual mode Lib::Math::Pid::compute() returns the last output without calculating. Set the output with Lib::Math::Pid::setManualOutput(), which clamps it to the output limits. Switching back to automatic mode seeds the integral term with the current output, so the output does not jump at the moment of the transfer.

#include <Lib/Math/Pid.hpp>
void manualOverride() noexcept {
Lib::Math::PidF pid(2.0F, 0.5F, 0.0F, 0.1F);
pid.setMode(false);
pid.setManualOutput(40.0F);
const float held = pid.compute(50.0F, 20.0F);
pid.setMode(true);
const float resumed = pid.compute(50.0F, 50.0F);
static_cast<void>(held);
static_cast<void>(resumed);
}

Reverse action

A cooling loop must raise its output when the measurement is above the setpoint. Call Lib::Math::Pid::setDirection() with true to invert the sign of the error; the gains stay positive.

#include <Lib/Math/Pid.hpp>
Lib::Math::PidF cooler(Lib::Math::PidF::Parameters{3.0F, 0.1F, 0.0F, 0.5F, 0.0F, 100.0F});
void coolerInit() noexcept {
cooler.setDirection(true);
cooler.setMode(true);
}
float coolerStep(float setpoint, float temperature) noexcept {
// A temperature above the setpoint gives a positive error and a rising fan speed.
return cooler.compute(setpoint, temperature);
}

Changing gains, sample time and limits at run time

The gains, the sample time and the output limits can be changed while the controller runs. The sample time is already part of the integral and derivative terms, so after a change of the control period only Lib::Math::Pid::setSampleTime() is needed. Lib::Math::Pid::setParameters() replaces every parameter at once.

#include <Lib/Math/Pid.hpp>
void retune(Lib::Math::PidF & pid) noexcept {
pid.setGains(2.5F, 0.8F, 0.05F);
pid.setSampleTime(0.05F);
pid.setOutputLimits(10.0F, 90.0F);
}
void loadProfile(Lib::Math::PidF & pid) noexcept {
const Lib::Math::PidF::Parameters profile{1.0F, 0.2F, 0.0F, 0.1F, 0.0F, 100.0F};
pid.setParameters(profile);
}

Reset and status

Lib::Math::Pid::reset() clears the integral term, the stored input and the output; the parameters, the mode and the direction are kept. Call it when the process restarts, for example after the heater was off for a long time. The getters expose the controller status for logging.

#include <Lib/Math/Pid.hpp>
void restartProcess(Lib::Math::PidF & pid) noexcept {
pid.reset();
}
void logStatus(const Lib::Math::PidF & pid) noexcept {
const float output = pid.getOutput();
const float integral = pid.getIntegralTerm();
const bool automatic = pid.isAutomatic();
const bool reverse = pid.isReverse();
const float proportionalGain = pid.getParameters().kp;
static_cast<void>(output);
static_cast<void>(integral);
static_cast<void>(automatic);
static_cast<void>(reverse);
static_cast<void>(proportionalGain);
}

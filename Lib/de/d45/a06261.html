RTOS::QueueSet

Shows waiting on a queue and a semaphore at the same time with an RTOS::QueueSet.

Shows waiting on a queue and a semaphore at the same time with an RTOS::QueueSet. Covers a set that combines a command queue and a button semaphore, and a task that blocks on the set and dispatches whichever member became ready. Every member must be empty when it is added, and it can belong to only one set at a time. Requires configUSE_QUEUE_SETS set to 1.

Important
The set length must be at least the sum of the member lengths: 4 for the command queue plus 1 for the binary semaphore, so 5 here.

Declaring the members and the set

#include <Lib/RTOS/FreeRTOS/QueueSet.hpp>
#include <Lib/RTOS/FreeRTOS/Queue.hpp>
#include <Lib/RTOS/FreeRTOS/Semaphore.hpp>
#include <cstdint>
namespace {
RTOS::Queue<uint8_t, 4U> commands;
RTOS::Semaphore buttonPressed;
RTOS::QueueSet<2U> events;
}

Opening the set

RTOS::QueueSet::open() with an initializer list creates the set and adds both members in one call. Each member handle comes from RTOS::Queue::getHandle() or RTOS::SemaphoreBase::getHandle() of its own wrapper.

#include <Lib/RTOS/FreeRTOS/QueueSet.hpp>
#include <Lib/RTOS/FreeRTOS/Queue.hpp>
#include <Lib/RTOS/FreeRTOS/Semaphore.hpp>
#include <cstdint>
namespace {
RTOS::Queue<uint8_t, 4U> commands;
RTOS::Semaphore buttonPressed;
RTOS::QueueSet<2U> events;
}
bool openEvents() noexcept {
if (!commands.open() || !buttonPressed.open()) {
return false; // Creation failed: out of heap.
}
return events.open(5U, {commands.getHandle(), buttonPressed.getHandle()});
}

Waiting and dispatching

RTOS::QueueSet::select() returns the member that became ready, or nullptr on timeout. Read each ready member exactly once with a zero timeout, so the set reports only new events.

#include <Lib/RTOS/FreeRTOS/QueueSet.hpp>
#include <Lib/RTOS/FreeRTOS/Queue.hpp>
#include <Lib/RTOS/FreeRTOS/Semaphore.hpp>
#include <chrono>
#include <cstdint>
#include <optional>
using namespace std::chrono_literals;
namespace {
RTOS::Queue<uint8_t, 4U> commands;
RTOS::Semaphore buttonPressed;
RTOS::QueueSet<2U> events;
}
bool openEvents() noexcept {
if (!commands.open() || !buttonPressed.open()) {
return false; // Creation failed: out of heap.
}
return events.open(5U, {commands.getHandle(), buttonPressed.getHandle()});
}
void eventTask(void * parameters) {
static_cast<void>(parameters);
if (!openEvents()) {
return;
}
while (true) {
const RTOS::QueueSet<2U>::Member ready = events.select(100ms);
if (ready == commands.getHandle()) {
if (const std::optional<uint8_t> command = commands.receive(0U); command.has_value()) {
// Handle *command.
}
} else if (ready == buttonPressed.getHandle()) {
static_cast<void>(buttonPressed.take(0U));
}
}
}

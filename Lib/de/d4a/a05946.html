enum RTOS::Task::Priority::Level : UBaseType_t

Priority levels.

Kept as an unscoped enumeration on purpose, so consumers can write Priority::LOW. RTOS::Task::Config::priority takes this type; a numeric kernel priority is passed as 'static_cast<Priority::Level>(n)'.

Enumerator

Lib::USB::SerialPort

Description

Asynchronous serial port facade backed by two UART ports and RTOS tasks.

The receive task accumulates bytes and delivers them via a callback when an inter-byte gap occurs. The transmit task drains a message buffer and writes frames to the TX UART.

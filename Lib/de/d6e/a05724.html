Description

template<std::floating_point T_VALUE, typename T_INPUT = T_VALUE>
class Lib::Math::LinearInterpolation< T_VALUE, T_INPUT >

Linear interpolation between a fixed-size table of (x, y) data points.

Supports up to "MAX_POINTS" data points, stored in a fixed-size array with no heap allocation. A lookup first binary-searches for the enclosing interval, then linearly interpolates between its two endpoints; values outside the table's range clamp to the nearest endpoint.

Template Parameters
T_VALUEFloating-point type of the output (y) values.
T_INPUTFloating-point type of the input (x) coordinates; defaults to "T_VALUE".

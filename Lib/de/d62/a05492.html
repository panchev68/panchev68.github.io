Lib::HAL::OTPfinal

Description

Accessor for the one-time-programmable (OTP) area of the internal flash.

The region is memory mapped, so reads are plain loads; writes go through the flash controller and must be bracketed by unlock() and lock(). The region is written once per bit: a programmed bit can be cleared from one to zero but never restored, and there is no erase operation. The write() method therefore refuses a value that would require setting a bit back to one, instead of silently corrupting the word.

Programs a single word.

The word must be word-aligned and inside the region. Because the area cannot be erased, the new value may only clear bits that are currently set; a value that would need a zero bit to return to one is rejected.

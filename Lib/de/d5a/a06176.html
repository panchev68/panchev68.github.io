Lib::HAL::FlashInterface

Unlocks the flash controller, erases a sector and programs words with Lib::HAL::FlashInterface.

Unlocks the flash controller, erases a sector and programs words with Lib::HAL::FlashInterface.The class is a thin facade over the HAL flash functions and holds no state. Erase and program operations need the controller unlocked, so call Lib::HAL::FlashInterface::unlock() first and Lib::HAL::FlashInterface::lock() afterwards. The HAL calls block until the operation ends, so keep them out of interrupt handlers. Lib::HAL::FlashInterface::writeBuffer() programs in order and stops at the first failure; the words written before that failure stay programmed.

The erase granularity and the programming width are chosen at compile time from the device macros: sectors where FLASH_TYPEERASE_SECTORS is defined, pages where FLASH_TYPEERASE_PAGES is defined, and word or doubleword programming where FLASH_TYPEPROGRAM_WORD or FLASH_TYPEPROGRAM_DOUBLEWORD is defined. On a device without the macro, the method returns false.

Important
The module guard is HAL_FLASH_MODULE_ENABLED, which the project's 'stm32f4xx_hal_conf.h' enables. On the STM32F407xx target the HAL headers define FLASH_TYPEERASE_SECTORS and FLASH_TYPEPROGRAM_WORD, so both methods are compiled in.
Warning
An erase destroys the whole sector, including any code or constants stored in it. Never erase the sector that holds the running firmware, and keep the code that erases and programs in RAM, because the CPU cannot execute from flash while the operation runs. Writes can only clear bits, so a word must be erased before it is programmed to a value that sets bits.

Erase a sector and program a block

Lib::HAL::FlashInterface::eraseSector() takes the sector index and the voltage range that matches the supply voltage; use the HAL constant FLASH_VOLTAGE_RANGE_3 for 2.7 V to 3.6 V on the STM32F407xx. Program the data only after the erase returns true, and check each step.

#include <Lib/HAL/Flash/FlashInterface.hpp>
#include <array>
#include <cstdint>
bool storeSettings() noexcept {
constexpr uint32_t SETTINGS_SECTOR = 11U;
constexpr uint32_t SETTINGS_ADDRESS = 0x080E0000U;
static constexpr std::array<uint32_t, 4> SETTINGS{0x01U, 0x02U, 0x03U, 0x04U};
Lib::HAL::FlashInterface flash;
if (!flash.unlock()) {
return false;
}
bool isStored = flash.eraseSector(SETTINGS_SECTOR, FLASH_VOLTAGE_RANGE_3) &&
flash.writeBuffer(SETTINGS_ADDRESS, SETTINGS.data(), static_cast<uint32_t>(SETTINGS.size()));
isStored = flash.lock() && isStored;
return isStored;
}

Program one word

Lib::HAL::FlashInterface::writeWord() asserts that the address is 4-byte aligned. On a doubleword device the hardware programs 8 bytes at once, so the class reads the neighbouring word and programs the pair; that neighbour must still be erased or hold the value it already has.

#include <Lib/HAL/Flash/FlashInterface.hpp>
#include <cstdint>
bool writeOneWord(uint32_t address, uint32_t value) noexcept {
Lib::HAL::FlashInterface flash;
if (!flash.unlock()) {
return false;
}
const bool isWritten = flash.writeWord(address, value);
return flash.lock() && isWritten;
}

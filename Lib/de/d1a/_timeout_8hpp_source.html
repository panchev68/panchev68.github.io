22 /** Timeout class for managing timeouts in RTOS.
23 * The Timeout class encapsulates timeout management using FreeRTOS ticks. It supports
24 * setting timeouts, checking if they have expired, resetting them, and performing operations
25 * like extension or arithmetic adjustments. It uses TickCounter for tick conversions and
26 * timing checks, ensuring compatibility with FreeRTOS scheduling.

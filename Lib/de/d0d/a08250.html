RTOS::Timeout example

Shows tracking a deadline in a polling loop with RTOS::Timeout.

Covers a timeout created from a duration, polled until it expires, restarted after a successful step, and disabled when no limit is needed. The timeout measures elapsed time with the scheduler tick count.

Usage

Polling until a deadline

#include <Lib/RTOS/FreeRTOS/Kernel.hpp>
#include <Lib/RTOS/FreeRTOS/Timeout.hpp>
#include <chrono>
using namespace std::chrono_literals;
bool waitForReady() noexcept {
RTOS::Timeout deadline(500ms);
while (!deadline.isExpired()) {
// Poll the peripheral here.
RTOS::delay(10ms);
}
return false; // Not ready within 500 ms.
}

Restarting and disabling

RTOS::Timeout::reset() restarts the window from the current tick, and RTOS::Timeout::disable() makes the timeout never expire until RTOS::Timeout::set() is called again.

#include <Lib/RTOS/FreeRTOS/Timeout.hpp>
#include <chrono>
using namespace std::chrono_literals;
void restartWindows() noexcept {
RTOS::Timeout unlimited(1s);
unlimited.disable();
RTOS::Timeout retry(200ms);
retry.reset();
if (retry.getRemainingTicks() > 0U) {
// Still inside the window.
}
}

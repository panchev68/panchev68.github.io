class Lib::System::Parameters< T_DERIVED, T_DATA, T_STORAGE >

CRTP base class managing a parameter structure in persistent storage with CRC16 integrity validation.

The storage image is the raw bytes of T_DATA immediately followed by their CRC16, without padding. The derived class implements restoreByDefault(), which fills the bound data structure with default values; it is called when the stored image fails validation. Declare it public, or befriend this base, so the base can reach it.

template<typename T_DERIVED, typename T_DATA, StorageLike T_STORAGE>
Status Lib::System::Parameters< T_DERIVED, T_DATA, T_STORAGE >::setup ( )
inlinenodiscardnoexcept

Reads the stored parameters, restoring and persisting defaults if the image is invalid.

Opens the storage, reads the image and checks its CRC. On a mismatch, e.g. on first power-up or after corruption, restoreByDefault() fills the bound data with defaults, which are then written back. On success the bound data holds the validated parameters.

Returns
Status::OK on success, Status::ERROR if the storage could not be opened, read or written.

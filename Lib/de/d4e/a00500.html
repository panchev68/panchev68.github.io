Error.hpp

Description

Represents a single trackable error condition with a set/clear/reset lifecycle and optional group tagging.

The lifecycle lives in the CRTP base 'ErrorBase', so a derived error can react to every state change through its own 'handleStateChanged()' without a vtable; 'Error' is the ready-made variant without extra behavior. Every transition is one atomic compare-and-exchange, so tasks and interrupts may call 'set()' / 'clear()' on the same error concurrently and the state change hook runs exactly once per transition.

BSP namespace for board support package.

Board Support Package namespace for hardware abstraction interfaces.

BSP (Board Support Package) Namespace.

This namespace contains board-specific implementations and drivers for hardware components such as displays, peripherals, and interfaces. It abstracts hardware details to provide a consistent API for the application layer.

This namespace contains classes and utilities for board-level hardware abstraction in embedded systems. It provides drivers and interfaces for various peripherals such as encoders, EEPROMs, and other BSP components. The namespace is part of the Lib library, focusing on hardware abstraction and real-time operation support.

Classes in this namespace often inherit from base classes or use HAL (Hardware Abstraction Layer) components. All implementations are designed to be thread-safe and suitable for FreeRTOS-based embedded applications.

This namespace provides abstract interfaces and utilities for board support package components, including hardware abstraction layers for communication interfaces such as I2C ports, enabling platform-independent development and testing of embedded systems.

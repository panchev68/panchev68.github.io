Lib::HAL::Timer::TimOutputCompare example

Generates a timed event with Lib::HAL::Timer::TimOutputCompare.

The timer raises an interrupt when its counter matches the compare value of the channel, which wakes the task blocked in Lib::HAL::Timer::TimOutputCompare::waitCompare(). The task then sets the next compare value with Lib::HAL::Timer::TimOutputCompare::setCompare(). Call Lib::HAL::Timer::TimOutputCompare::start() from the waiting task.

The header defines the HAL callback HAL_TIM_OC_DelayElapsedCallback() itself, so do not define it elsewhere. The ISR path only notifies the task; the compare value is changed in the task.

Usage

Hardware and CubeMX assumptions

  • Timer channel (here 'TIM4', 'TIM_CHANNEL_2') set to Output Compare mode (Timing or Toggle) with its interrupt enabled in the NVIC. The output pin is optional for this use.
  • Timer clock and prescaler are set in CubeMX; the compare value is in timer ticks.
  • One Lib::HAL::Timer::TimOutputCompare per timer handle.

Scheduling a compare event in a task

#include <Lib/HAL/TIM/TimOutputCompare.hpp>
#include <RTOS.hpp>
class DelayedEvent final {
public:
explicit DelayedEvent(TIM_HandleTypeDef * timHandle) noexcept :
compare(timHandle, TIM_CHANNEL_2),
task(RTOS::Task::Config("Delayed", 512, RTOS::Task::Priority::NORMAL), [this]() { run(); }) {
}
private:
Lib::HAL::Timer::TimOutputCompare compare; // Constructed before the task starts using it.
RTOS::Task task; // Must stay the last member.
void run() noexcept {
if (!compare.start()) {
assert(!"DelayedEvent: output compare failed to start");
return;
}
while (true) {
// Fire 1000 ticks after the current counter value.
compare.setCompare(compare.getCounter() + 1000U);
if (compare.waitCompare(std::chrono::milliseconds(500))) {
// The compare event fired; run the delayed action here.
}
}
}
};

Lib::HAL::UartPortBase

Description

Base wrapper around a HAL UART handle providing common functionality.

This class manages registration of HAL callbacks, provides common send/receive/abort operations and exposes utility helpers used by concrete UartPort specializations (blocking, DMA, interrupt-driven).

Lib::BSP::SK6812

Description

SK6812 RGBW single LED driver.

Stores the LED color and encodes it, gamma corrected, into a fixed slice of a shared timer compare buffer using the single wire SK6812 protocol (green-red-blue-white wire order, MSB first). The slice is owned by the caller, typically a SK6812::Ring.

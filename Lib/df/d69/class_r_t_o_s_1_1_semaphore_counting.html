Detailed Description

Counting semaphore class for FreeRTOS.

This class implements a counting semaphore, which allows multiple tasks to access a shared resource up to a maximum count. It provides methods to create the semaphore, check its state, and manage access.

The semaphore can be in various states defined by the Status enum.

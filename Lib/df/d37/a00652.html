Description

Lib::Helper namespace.

This namespace contains various helper utilities and classes for common tasks such as data conversion, hashing, containers, timing, exceptions, and signal processing. It provides reusable components to simplify development in embedded systems.

◆ swapBytes() [2/3]

void Lib::Helper::swapBytes ( const void * source,
void * dest,
size_t size )
inline

Reverse the bytes from source into dest for an arbitrary byte buffer.

If source and dest point to the same buffer the operation reverses the buffer in-place. Otherwise, bytes are copied from source in reverse order into dest. The function does not assume any particular alignment or type for the buffers. Both source and dest must point to valid memory regions of at least 'size' bytes. The function asserts that source and dest are not null. If size is zero, the function does nothing. The function is safe to use with overlapping buffers as long as the regions do not overlap in a way that violates the preconditions.

Parameters
sourcePointer to source buffer (must not be null).
destPointer to destination buffer (must not be null).
sizeNumber of bytes to reverse.
Precondition
source and dest must not be null (asserted).

Reverse the byte order of an integral value.

This function works for any integral type. The implementation converts the value to its unsigned counterpart, performs the byte reversal and converts back to the original type.

Template Parameters

Parameters

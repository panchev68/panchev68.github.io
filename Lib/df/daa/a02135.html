Description

DTH Base Component Header File.

This header file defines the Base class for DTH thermometer components. It provides infrastructure for communicating with DTH sensors using timer-based data reception and GPIO control. Manages RTOS task management and handles low-level protocol details.

The Base class handles data acquisition cycle: initialization, startup impulse, DMA reception, and signal processing. Uses RTOS semaphores for synchronization and timer interrupts for timing control.

Dependencies: HAL GPIO, TIM, RTOS libraries, and Parm.hpp.

Note
This is an abstract base class; derived classes must implement taskEntry().
Attention
Ensure HAL_TIM_REGISTER_CALLBACKS is enabled in HAL configuration.

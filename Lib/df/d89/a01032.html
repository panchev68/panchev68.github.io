Lib::HAL

Description

Hardware abstraction layer for STM32 peripherals.

Contains the mode-templated peripheral drivers (ADC, CAN, DAC, GPIO, I2C, SPI, timers, UART, USB and the watchdogs) built on the Lib::HAL::DriverMode (BLOCKING, IT, DMA) CRTP pattern, the ISR handle-to-instance Lib::HAL::core::DeviceManager lookup, and the shared peripheral lifecycle policy each mode specialization builds on. The OSPI driver and the HASH engine need peripherals the F407 does not have, so they compile to nothing there.

◆ isDmaReachable()

bool Lib::HAL::isDmaReachable ( const void * address,
size_t size )
inlinenodiscardnoexcept

Checks that a buffer does not overlap the core-coupled memory (CCM), which is wired to the CPU only.

The whole range is tested, so a buffer that begins below CCM and runs into it is rejected.

Parameters
addressStart of the buffer.
sizeLength of the buffer in bytes; 0 is always reachable.
Returns
true if the DMA controllers can reach the buffer; always true on a device without CCM.

Lib::HAL::IndependentWatchdog

Starts the hardware Independent Watchdog (IWDG) with Lib::HAL::IndependentWatchdog and keeps it alive from a task.

Starts the hardware Independent Watchdog (IWDG) with Lib::HAL::IndependentWatchdog and keeps it alive from a task.The wrapper does not own the CubeMX-generated handle; pass the hiwdg descriptor, which must outlive the instance. The prescaler and reload value are taken from that handle, so configure them in CubeMX before calling 'open()'. 'refresh()' is a single key-register write and is safe from task and ISR context.

Important
The IWDG is available on every STM32F4xx family, including the STM32F407xx target of this library. The module guard is 'HAL_IWDG_MODULE_ENABLED'; the project's 'stm32f4xx_hal_conf.h' is not in the repository, so that guard is unverified here, although the STM32Cube template enables it.
Warning
Once 'open()' succeeds the watchdog cannot be stopped until the next reset. If 'refresh()' is not called before the configured timeout expires, the MCU resets. Call 'open()' only after the start-up code that must run without a refresh has finished.

Usage

Start the watchdog

'open()' returns false only when the HAL initialization or the lock sequence fails. In that case the watchdog is not running, so the firmware decides whether to continue unprotected or to restart.

#include <Lib/HAL/IWDG/IndependentWatchdog.hpp>
extern IWDG_HandleTypeDef hiwdg; // Generated by CubeMX.
bool startIndependentWatchdog() noexcept {
static Lib::HAL::IndependentWatchdog watchdog(hiwdg);
return watchdog.open();
}

Refresh from a supervisor task

The refresh period must stay well below the timeout that the prescaler and reload value define. A supervisor task that refreshes only after every other task reports healthy keeps the watchdog meaningful; a refresh placed in an unconditional timer ISR would hide a blocked task.

#include <Lib/HAL/IWDG/IndependentWatchdog.hpp>
#include <RTOS.hpp>
extern IWDG_HandleTypeDef hiwdg; // Generated by CubeMX.
void supervisorTask(void *) {
static Lib::HAL::IndependentWatchdog watchdog(hiwdg);
if (!watchdog.open()) {
return;
}
while (true) {
// Refresh only when every monitored task has checked in.
watchdog.refresh();
RTOS::delay(std::chrono::milliseconds(100));
}
}

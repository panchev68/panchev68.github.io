RTOS::TickService Class Referencefinal

Description

TickService.

Manages periodic tick events and notifies registered clients. The TickService class is a singleton that runs an RTOS task managing periodic tick events. Registered clients inherit from ClientBase and receive tick notifications based on their configured update periods. The service is thread-safe and automatically starts/stops based on client registration. Tick events are dispatched at configurable intervals, allowing multiple clients to operate at different periods within a single task.

◆ taskFunction()

void RTOS::TickService::taskFunction ( )
inlineoverridevirtual

Task function for handling tick events.

Executes in the context of the TickService task and iterates over registered clients, decrementing their update period counters and invoking their handleTickEvent() method when the counter reaches zero. Thread-safe access is ensured via mutex.

Implements RTOS::TaskWorker.

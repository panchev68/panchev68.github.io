Lib::Helper::Crc16

Computing CRC16 checksum for a data buffer.

This example demonstrates how to use the Crc16 class to compute a CRC16 checksum for a raw data buffer. The class can be initialized with a buffer and size, and then converted to uint16_t to get the checksum value.

Example usage:
#include "crc16.hpp"
#include <iostream>
int main() {
const uint8_t data[] = {0x01, 0x02, 0x03, 0x04};
Lib::Helper::Crc16 crc(data, sizeof(data));
uint16_t checksum = crc;
std::cout << "CRC16: 0x" << std::hex << checksum << std::endl;
return 0;
}

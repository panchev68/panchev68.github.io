Description

Utility class providing conversions from dBm-like numeric values and discrete indices to percentage values.

The class is a header-only collection of static helpers and is not instantiable.

Convert a discrete index into a percentage using a lookup table.

Expected input range is 0..99, the magnitude of a negative dBm reading as reported by a Digi module. Negative values map to 100 and values >= 100 map to 1. The lookup table provides a non-linear mapping useful for signal-strength UI elements.

Convert a signed dBm-like value to a percentage in range [0, 100].

Values <= -100 map to 0 and values >= 0 map to 100. Intermediate values are linearly offset (result = 100 + value), a fractional part is truncated. A floating-point NaN maps to 0, and an unsigned input, which can never be negative, always maps to 100.

Description

Fixed-offset time zone with a display name and a helper converting local calendar time to UTC minutes.

The conversion is pure calendar arithmetic on the C++20 std::chrono calendar: it does not depend on the C runtime time zone, is reentrant and fully constexpr. Daylight saving time is described by 'TimeChangeRule', which resolves the local wall-clock instant of a transition for any year.

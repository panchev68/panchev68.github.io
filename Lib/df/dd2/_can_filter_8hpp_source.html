27 /** CAN filter configuration wrapper class.
28 *
29 * Provides a type-safe interface for configuring CAN filters by wrapping
30 * the CAN_FilterTypeDef structure. Supports setting filter ID, mask, bank,
31 * mode, scale, activation, and FIFO assignment.
32 *
33 * Role of the type within the module or system: Acts as a configuration helper
34 * for CAN filters in the HAL layer, ensuring proper initialization and management

37 * Important design decisions: Inherits from CAN_FilterTypeDef for direct compatibility
38 * with HAL functions, uses noexcept for real-time safety, and provides constexpr

43 /** Constructs a CAN filter with specified ID and mask.
44 *
45 * Initializes the filter with the given ID and mask, setting default values
46 * for other parameters. The filter is initially disabled.
47 *
48 * @param id The filter ID (default 0).
49 * @param mask The filter mask (default 0xFFFFFFFFU >> 3).
50 *
51 * @pre Both parameters are valid 32-bit unsigned integers.
52 * @post Filter is initialized with provided ID and mask; other fields are set to 0.
53 */
54 explicit CanFilter(uint32_t id = 0, uint32_t mask = 0xFFFFFFFFU >> 3) noexcept {
55 CAN_FilterTypeDef::FilterIdHigh = (id >> 16) & 0xFFFF;
56 CAN_FilterTypeDef::FilterIdLow = id & 0xFFFF;
57 CAN_FilterTypeDef::FilterMaskIdHigh = (mask >> 16) & 0xFFFF;

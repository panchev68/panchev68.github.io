Lib::HAL::ADCPort< DriverMode::DMA >final

Description

Explicit specialized variant driving asynchronous Direct Memory Access (DMA) multi-channel scan paths.

The primary contract of this mode is scanning one or more regular-group channels straight into a caller-owned destination buffer via "start(destination)"; "getValue()" (inherited from the base) remains available for a single-value peek at the most recent conversion. The RTOS event group, the wait wrapper, the HAL callback registration and the DeviceManager wiring all live here, since none of them apply to a blocking conversion.

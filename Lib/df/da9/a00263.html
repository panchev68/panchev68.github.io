Description

CoE (CANopen over EtherCAT) interface header file.

This header file defines the CoE class, which provides an interface for handling CANopen over EtherCAT (CoE) communication in embedded systems using the SOES library. It encapsulates initialization, processing, and access to PDO sizes and SDO objects for EtherCAT slave functionality. The class ensures proper integration with the EtherCAT protocol stack for reliable data exchange.

Important dependencies or interactions with other modules: Relies on the SOES library (native/soes.h) for EtherCAT operations and standard C++ libraries for type definitions. Interacts with EtherCAT master for PDO and SDO communications.

Any special instructions or notes for users of the file: Ensure that the SOES library is properly initialized before instantiating this class. Call initialize() before processing data.

Note
This class is designed for use in real-time EtherCAT slave applications.
Attention
Handle EtherCAT state machines correctly to avoid communication errors.

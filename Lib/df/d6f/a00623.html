Description

USB serial port repeater base class.

This file defines the SerialPortRepeaterBase class which extends Lib::USB::SerialPort to provide USB serial repeater functionality. It manages USB connection detection, enable/disable control, integration with the STM32 USB CDC device stack, and provides callback hooks for connection and data events. The class is designed for use in RTOS-based STM32 embedded systems and depends on HAL GPIO/UART and RTOS components.

Description

Legacy firmware and hardware version containers.

Defines the nested Version::Hardware and Version::Firmware classes that parse "X.Y" version strings, convert them to packed numbers and format them, the firmware one with the build date appended. Kept for the project templates that still derive from them; new code should use FirmwareVersion and HardwareVersion, which build on VersionBase and are fully constexpr.

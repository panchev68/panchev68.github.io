Lib::BSP::SK6812

Demonstrates a ring of 12 SK6812 RGBW LEDs sent out through a PWM timer channel with DMA.

Demonstrates a ring of 12 SK6812 RGBW LEDs sent out through a PWM timer channel with DMA.TIM3 channel 1 is set up in CubeMX as PWM with a word-sized memory-to-peripheral DMA stream. The DMA completion callback stops the PWM, so the line stays low long enough for the LEDs to latch the frame. Colors are linear: the class gamma corrects them while encoding.

Important
The TIM3 ARR must be 219, which the compare values assume.
Start the next frame only after the callback has stopped the PWM.
Warning
A program that also includes Lib/HAL/TIM/TimOnePulse.hpp cannot define this callback, since that header defines it too.
See also
Lib::BSP::SK6812, Lib::BSP::SK6812::Ring
Example usage:
extern "C" {
#include "main.h"
}
#include <Lib/BSP/RGBWLed/SK6812.hpp>
#include <cstdint>
extern "C" TIM_HandleTypeDef htim3; // TIM3 CH1 PWM, ARR = 219, DMA memory-to-peripheral, word size.
Lib::BSP::SK6812::Ring<12> ring;
extern "C" void HAL_TIM_PWM_PulseFinishedCallback(TIM_HandleTypeDef * htim) {
if (htim == &htim3) {
static_cast<void>(HAL_TIM_PWM_Stop_DMA(&htim3, TIM_CHANNEL_1)); // Line stays low: reset gap.
}
}
void showFrame() {
for (size_t index = 0; index < ring.count(); ++index) {
ring[index].setColor(index % 2 == 0 ? ::Color::SALMON : ::Color::INDIANRED);
}
ring[0].setColor(0, 0, 0, 255); // White channel only.
static_cast<void>(HAL_TIM_PWM_Start_DMA(&htim3, TIM_CHANNEL_1, ring.getData(), static_cast<uint16_t>(ring.getSize())));
}

Description

Low-level drivers and helpers for RFID and NFC readers.

Provides the MFRC522 driver with card selection, authentication and Mifare helpers, the ST25R100 NFC controller driver, and the NfcManager, which runs an ISO14443A card discovery state machine on top of the ST25R100.

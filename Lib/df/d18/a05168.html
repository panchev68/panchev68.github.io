Lib::Digi::Core::Frame0x97final

Description

Remote AT Command Response (0x97): result of an AT command executed by a remote node.

Wire layout after the frame type byte: frame ID (1), 64-bit source address (8, big-endian), 16-bit source address (2, big-endian), AT command (2, ASCII big-endian), status (1), parameters. A frame shorter than the fixed fields leaves every member zero and "parameters" empty.

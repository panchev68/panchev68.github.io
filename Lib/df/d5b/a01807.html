Lib::Helper::BufferHandle

Handling buffer data with BufferHandle.

This example demonstrates how to use the BufferHandle class to manage and access byte buffer data in embedded systems. BufferHandle provides a simple wrapper for copying and accessing buffer contents safely.

Example usage:
#include "Lib/Helper/Buffer/BufferHandle.hpp"
int main() {
// Create external data
uint8_t externalData[4] = {0x10, 0x20, 0x30, 0x40};
// Create BufferHandle from data
Lib::Helper::BufferHandle handle(externalData, 4);
// Access data
uint8_t* ptr = handle.data();
size_t size = handle.getSize();
// Modify via pointer
ptr[0] = 0xAA;
// Use as raw pointer
uint8_t* rawPtr = handle;
// Set new data
uint8_t newData[2] = {0xBB, 0xCC};
handle.set(newData, 2);
return 0;
}

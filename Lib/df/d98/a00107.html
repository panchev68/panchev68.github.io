Description

1-Wire driver for the Maxim/Dallas DS18B20 digital temperature sensor.

Bit-bangs the Dallas 1-Wire protocol (reset/presence, bit write/read time slots) directly on a single GPIO pin configured as open-drain, using 'Lib::Helper::Delay::microseconds()' for the sub-millisecond slot timing and 'Lib::Helper::crc8' to validate the scratchpad readback. The pin stays in output-open-drain mode for the whole transaction: driving it low pulls the bus low, and writing it high simply releases it, letting the bus's pull-up bring it back high, without ever switching to input mode – so no per-bit 'HAL_GPIO_Init' call sits inside the timing-critical path. The bus itself is level-shifted (DS18B20 runs at 5V, the MCU pin at 3.3V) through a BSS138 with a 4.7 kOhm pull-up to each rail on its respective side, which preserves open-drain behaviour symmetrically across both sides, so this driver's low/release logic needs no adjustment for it. Assumes a single device on the bus (uses the 'Skip ROM' command), which matches this driver's typical single-sensor wiring; multi-drop ROM search/match is out of scope.

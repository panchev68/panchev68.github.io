Lib::Helper::Exception

Description

Lightweight exception type carrying a string message.

Custom exception class for the library.

The class wraps std::exception and provides constructors from std::string_view and C-string literals. It also exposes helpers to query and set the process terminate handler.

A lightweight wrapper around std::exception that stores a std::string message. Use this type for consistent error reporting across the library. Supports construction from string_view and C-strings; move semantics are provided for efficiency. This class also provides static methods for managing the global terminate handler and, when supported, for retrieving and rethrowing exceptions.

Note
  • Supports construction from string_view and C-strings; move semantics are provided for efficiency.

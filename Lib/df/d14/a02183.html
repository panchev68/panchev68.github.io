Lib::HAL::Timer::TimInputCapturefinal

Description

Controls one hardware timer channel configured under an active Input Capture profile.

Capture interrupts are mapped through the DeviceManager to a task notification, so a task blocked in "waitCapture()" wakes on each captured edge.

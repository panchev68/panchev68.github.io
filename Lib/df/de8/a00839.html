Lib::BSP::Display::Driver< Controller::ILI9341 >

Description

Specialized ILI9341 display driver with SPI interface.

Template specialization of the generic Driver class for ILI9341 controller, managing LCD initialization, pixel transmission via DMA-driven SPI, and configuration of various display parameters including rotation and backlight.

Transmit a pixel buffer block to the display.

Configures the SPI interface for pixel data transmission, sets the address window for the target area, and initiates DMA-based SPI transfer of pixel data to the display RAM.

Parameters

xstarting column coordinate.
ystarting row coordinate.
widthblock width in pixels.
heightblock height in pixels.
Precondition
pixelBuffer must not be null, width and height must not be zero, and width * height must not exceed 65535.

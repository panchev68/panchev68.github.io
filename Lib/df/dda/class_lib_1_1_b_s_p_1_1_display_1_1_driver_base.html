Detailed Description

Abstract base class that defines the interface and shared behavior for hardware-specific display drivers.

Subclasses implement device initialization and pixel transfer logic specific to their hardware platform. The class centralizes transfer-state management and provides helper utilities used by the BSP display layer.

Note
Subclasses must implement the setup() and transmitBlock() pure virtual methods.

Handles a transfer-complete event.

This method is invoked when the underlying DMA or transfer engine signals that the current transfer has finished. The default implementation clears the transfer-active flag. Hardware drivers may override this method to perform additional bookkeeping.

The external C callback DisplayDriver_TransferCompleteCallback() shall call this method when a transfer completes.

Transmits a rectangular pixel block to the display.

Subclass implementations must initiate the transfer of the rectangle described by the provided buffer and coordinates. The transfer may be asynchronous; implementations should set the transfer-active flag when starting an asynchronous transfer and clear it when the transfer completes.

Parameters

yY coordinate of the rectangle origin in display pixels.
widthWidth of the rectangle in pixels.
heightHeight of the rectangle in pixels.
Precondition
The rectangle (x, y, width, height) shall lie within the display bounds and height shall be <= MAX_TRANSFER_HEIGHT.

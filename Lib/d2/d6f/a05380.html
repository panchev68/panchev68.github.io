Lib::HAL::DACPort< DriverMode::IT >final

Description

Interrupt-driven (IT) specialization: enables the channel underrun interrupt.

Values are written through setValue() as in the blocking variant. The DAC raises no interrupt when a value reaches the output; its only channel interrupt is the DMA underrun flag, set when a trigger arrives while DMA requests are enabled and the previous request was not served. This port reports it as Event::UNDERRUN, observed through waitForUnderrun().

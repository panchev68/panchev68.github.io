Lib::Helper::Delayfinal

Description

Busy-wait delay helpers based on the ARM Cortex-M Data Watchpoint and Trace (DWT) cycle counter.

Suitable for short, precise delays where suspending the task or using RTOS timers would be too coarse. Every delay is rounded up to whole CPU cycles, so it is never shorter than requested; interrupts may lengthen it.

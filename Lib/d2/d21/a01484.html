Lib::Digi::API::Service::NetworkDiscoveryfinal

Description

Reads the discovery time "NT" on "open()" and collects the "ND" responses on "start()".

The service holds the local AT command channel from "open()" to "close()", so no other user of that channel may run meanwhile.

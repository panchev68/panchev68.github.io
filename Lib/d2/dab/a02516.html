Description

template<typename T_VALUE, typename T_INPUT = T_VALUE>
class Lib::Math::LinearInterpolation< T_VALUE, T_INPUT >

Linear interpolation table and evaluator.

Stores a fixed-capacity set of (x, y) points and performs linear interpolation between neighboring points. Template parameters select numeric types for inputs and values.

Template Parameters
T_VALUEArithmetic type used for output values.
T_INPUTArithmetic type used for input abscissa values.

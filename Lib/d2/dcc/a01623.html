RTOS::Kernel::CriticalSectionfinal

Description

RAII guard for a kernel critical section, usable from both task and interrupt context.

The construction context is sampled once: in task context the guard uses the nesting taskENTER_CRITICAL() pair, inside an interrupt it saves and restores the interrupt mask instead, because the task-level pair must never be used from an ISR.

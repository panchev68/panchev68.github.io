Lib::System::FirmwareVersionfinal

Description

Firmware version including the build date.

Wraps "VersionBase" for the major/minor/sub-version parsing and formatting, and adds the compilation date, parsed from the "__DATE__" macro at compile time and formatted as YYYY-MM-DD. Uses CRTP instead of virtual dispatch. Convertible to a packed number or to a fixed, NUL-terminated version string. Re-exposes the protected "VersionBase" members as public through using-declarations.

Parses version string in "X.Y" format into 32-bit numeric representation.

Returns an empty optional rather than a zero on failure, so a malformed string is distinguishable from the perfectly valid version "0.0". A field is rejected when it holds a non-digit or exceeds 255.

VersionString Lib::System::VersionBase< FirmwareVersion >::toString ( ) const
inlinenodiscardconstexprnoexcept

Formats the version as a string in "X.YY.ZZ" format.

The major field is unpadded and the minor and sub-version fields are zero-padded to two digits, widening to three when the value needs them. Digits are produced by hand rather than through printf, which would pull in formatting machinery this target has no use for.

Returns
Formatted version string.

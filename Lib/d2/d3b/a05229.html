bool Lib::GSM::A7670E::Power::hardReset ( )
inlinenodiscardnoexcept

Pulses 'RESET' and waits until the modem answers again; for a modem that stopped responding.

Also leaves UART sleep: 'DTR' is driven low, since the module restarts awake.

Returns
true if the modem answered within BOOT_TIMEOUT.

◆ on()

bool Lib::GSM::A7670E::Power::on ( )
inlinenodiscardnoexcept

Powers the modem, starts it with 'PWRKEY' and waits until it answers.

Also turns the command echo off ('ATE0') and enables numeric error codes ('AT+CMEE=1').

Returns
true if the modem answered within BOOT_TIMEOUT; on false the supply is cut again.

◆ sleep()

bool Lib::GSM::A7670E::Power::sleep ( )
inlinenodiscardnoexcept

Puts the modem into UART sleep ('AT+CSCLK=1', then 'DTR' high); it stays registered on the network.

While asleep every command returns Result::NOT_READY until wakeUp().

Returns
true if the modem accepted the sleep mode and 'DTR' was raised; false also without a 'DTR' pin.

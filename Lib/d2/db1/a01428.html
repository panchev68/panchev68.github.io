Lib::HAL::DeviceManagerBase< T_DEVICE, T_HANDLE >

Description

template<typename T_DEVICE, typename T_HANDLE>
class Lib::HAL::DeviceManagerBase< T_DEVICE, T_HANDLE >

Process-global device registry (Meyers singleton).

Provides a simple mapping between HAL handle pointers and their owning device instances. The helper offers basic add/find/remove operations. This class is not thread-safe; callers must synchronize externally when accessing the registry from multiple threads.

Template Parameters
T_DEVICEType of the device object stored in the registry. The device must expose a getHandle() method that returns a T_HANDLE*.
T_HANDLERaw HAL handle pointer type used as the key in the mapping.

template<typename T_DEVICE, typename T_HANDLE>
virtual bool Lib::HAL::DeviceManagerBase< T_DEVICE, T_HANDLE >::addItem ( T_DEVICE * item)
inlinevirtual

Register a device instance with the registry using its HAL handle as the key.

Inserts a mapping from the device's handle to the device pointer. If a mapping for the same handle already exists the insertion is not performed.

Parameters
itemPointer to the device instance to register.
Precondition
item must not be null.
item->getHandle() must return a valid (non-null) T_HANDLE*.
Returns
true if the item was inserted; false if a mapping for the handle already existed.

Lib::BSP::EEPROM::I2C::M24C16final

Description

I2C EEPROM driver implementing page-aware read/write with 8-bit addressing.

Provides safe access to a 16-Kbit EEPROM device using 8-bit addressing. The driver validates transfer parameters and delegates I2C operations to the underlying DriverBase.

Note
  • Page size: 16 bytes
  • Total capacity: 2048 bytes

Read bytes from EEPROM using 8-bit addressing.

Reads 'size' bytes starting at 'address' into 'buffer'. The method validates parameters and delegates the low-level transfer to the 8-bit helper.

Parameters
addressStarting EEPROM address to read from. Must be less than CHIP_SIZE.
bufferPointer to destination buffer. Must be non-null and able to hold 'size' bytes.
sizeNumber of bytes to read.
Returns
'true' on success, 'false' on failure.
Precondition
  • 'buffer' must be non-null and large enough for 'size' bytes.
  • The address range (address .. address+size-1) must be within the EEPROM capacity.

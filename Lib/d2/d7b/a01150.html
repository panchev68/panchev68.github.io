Lib::Digi::Core::ApiFrameBuffer

Description

ApiFrameBuffer class for managing API frame data buffers.

This class encapsulates a fixed-size buffer for API frame data, providing methods to assign, append, and retrieve data safely. It prevents buffer overflows and provides const-correct access to the underlying data.

Role within the module: Serves as a utility for frame data manipulation in the Digi Core communication layer.

Important design decisions: Uses std::array for fixed-size storage, includes size tracking, and provides overloaded methods for flexibility.

Note
Buffer size is limited to 255 bytes as per API specifications.

Lib::Helper::TimePeriod

Measuring Execution Time of a Task

This example demonstrates how to use the TimePeriod class to measure the elapsed time for executing a simple task, such as a loop that performs some computations. The class is useful in embedded systems for profiling code execution without dynamic allocation.

Example usage:
cpp
#include <Lib/Helper/TimePeriod.hpp>
#include <RTOS.hpp> // Assuming RTOS::TickCounter is available
#include <cstdint>
void someTask() {
// Simulate some work
volatile uint32_t sum = 0U;
for (uint32_t i = 0U; i < 1000U; ++i) {
sum += i;
}
}
int main() {
Lib::Helper::TimePeriod timer;
// Start measuring time
timer.start();
// Perform the task
someTask();
// Stop measuring and get elapsed ticks
uint32_t elapsedTicks = 0U;
if (timer.stop(elapsedTicks)) {
// Use elapsedTicks, e.g., log or process
// For demonstration, assume we have a logging function
// log("Task took %u ticks", elapsedTicks);
}
return 0;
}

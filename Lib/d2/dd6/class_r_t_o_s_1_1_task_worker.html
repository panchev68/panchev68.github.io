Detailed Description

TaskWorker base class.

Base class for RTOS task workers that encapsulates task lifecycle management. This class provides a framework for creating RTOS tasks with a virtual task function interface. Derived classes must override the taskFunction() method to implement their specific task logic. The task is initialized with the provided configuration and automatically executes the taskFunction() when scheduled by the RTOS. This base class handles the mapping between the task callback and the virtual interface, allowing subclasses to focus on task implementation without concerning themselves with the underlying FreeRTOS task management details.

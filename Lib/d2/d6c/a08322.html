Description

Quad-SPI (OCTOSPI) driver for the Winbond W25Q128JVSIQ 128 Mbit device.

The 'JVSIQ' ordering option fixes the Quad Enable bit to 1 in hardware, so this driver never touches Status Register-2. See the class description for the operating details and the target restriction.

Lib::Canbus::ServiceBaseabstract

Base class for CAN bus services. More...

Description

Base class for CAN bus services.

Owns an interrupt-driven Lib::HAL::CANPort and two RTOS tasks: the derived service's taskFn() and an RX pump. The pump drains the RX FIFOs and error events into messageReceivedCallback() and errorCallback(), because the HAL port only exposes a wait-then-poll event interface, not a push callback.

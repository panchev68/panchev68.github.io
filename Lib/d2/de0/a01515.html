Lib::Helper::DateTime

Description

Combined date and time representation for embedded systems.

Aggregates Date and Time objects to represent a complete timestamp. Provides validation, string conversion, and efficient 32-bit packing/unpacking for storage and transmission. All operations use fixed-width integers for type safety and hardware compatibility.

Note
Years are relative to Date::FIRST_YEAR (2000) for compact packing.

Converts DateTime to standard POSIX tm structure.

Maps date and time components to corresponding tm structure fields:

  • tm_year: year offset from 1900 (adjust for 1900 baseline)
  • tm_mon: month offset from January (0-11)
  • tm_mday: day of month (1-31)
  • tm_hour: hour (0-23)
  • tm_min: minute (0-59)
  • tm_sec: second (0-59)

◆ pack()

constexpr uint32_t Lib::Helper::DateTime::pack ( const DateTime & dateTime)
inlinestaticconstexpr

Packs DateTime into a compact 32-bit unsigned integer.

Bit layout (32 bits total):

  • Bits 0-5 (6 bits): seconds (0-59)
  • Bits 6-11 (6 bits): minutes (0-59)
  • Bits 12-16 (5 bits): hours (0-23)
  • Bits 17-21 (5 bits): day (1-31)
  • Bits 22-25 (4 bits): month (1-12)
  • Bits 26-31 (6 bits): year offset from FIRST_YEAR (2000-2063)

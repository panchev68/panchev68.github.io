Lib::Helper::Container

Managing a collection of pointers with Container.

This example demonstrates how to use the Container class to manage a collection of pointers to objects. It shows adding items, processing them with a callback, and removing items. This is useful in embedded systems for managing lists of objects without copying.

Example usage:
#include "Lib/Helper/Container.hpp"
struct MyObject {
int value;
MyObject(int v) : value(v) {}
};
void printCallback(MyObject* obj, void* context) {
printf("Object value: %d\n", obj->value);
}
int main() {
Lib::Helper::Container<MyObject> container;
// Create objects
MyObject obj1(10);
MyObject obj2(20);
// Add pointers to container
container.add(&obj1);
container.add(&obj2);
// Process items with callback
container.processItems(printCallback);
// Remove an item
container.remove(&obj1);
// Clear all
container.clear();
return 0;
}

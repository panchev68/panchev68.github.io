Lib::HAL::Reset

Checking System Reset Cause and Performing Reset

This example demonstrates how to use the Reset class to check the cause of the last system reset and perform a software reset if needed. The Reset class is a singleton that reads RCC flags to determine the reset type.

Example usage:
#include "Lib/HAL/core/Reset/Reset.hpp"
int main() {
// Get the reset cause
Lib::HAL::Reset::State resetCause = Lib::HAL::Reset::getResetState();
switch (resetCause) {
case Lib::HAL::Reset::State::SOFTWARE_RESET:
// Handle software reset
break;
case Lib::HAL::Reset::State::POWER_ON_POWER_DOWN_RESET:
// Handle power-on reset
break;
default:
// Handle other reset types
break;
}
// Perform a system reset if needed
if (someCondition) {
Lib::HAL::Reset::resetSystem();
}
return 0;
}

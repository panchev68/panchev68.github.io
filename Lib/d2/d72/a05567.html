Lib::HAL::StreamSerialPortfinal

Description

UART port that receives continuously into a stream buffer and transmits by polling.

'Lib::HAL::UARTPort' receives only into a buffer the caller hands over for one transfer, so bytes arriving between two calls are lost. Devices that send unsolicited data need a receiver that is always armed. This port keeps one byte armed with HAL_UART_Receive_IT() and pushes every received byte into an RTOS::StreamBuffer from the interrupt. One task reads it with read().

close() de-initializes the UART, which returns its pins to the analog state, so a powered-down device is not back-fed through TX. open() brings it back.

Warning
Exactly one task may call read() and discardInput(); the stream buffer allows a single reader.
Examples
Lib::BSP::GSM::A7670E, and Lib::HAL::StreamSerialPort.

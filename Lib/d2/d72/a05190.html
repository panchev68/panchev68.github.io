Lib::Ethercat::SOES::EepromEmulationfinal

Description

EEPROM emulation of an EtherCAT slave controller.

An ESC reads its configuration and the identity of the slave (the SII data) from an I2C EEPROM. Without one, or with the chip set to emulation, the ESC passes every EEPROM command to the PDI and waits for the application to answer it. This class serves those commands: it reads the control and status register, executes the read, write and reload commands against a memory the application provides (flash, RAM) and reports the result to the ESC, so the master can read the SII data with the usual EEPROM commands.

Call process() periodically (or on the EEPROM event of the ESC).

RTOS::TickClient

Shows a periodic task built on RTOS::TickClient, which calls the handleTickEvent() of its derived class on every timer expiry.

Shows a periodic task built on RTOS::TickClient, which calls the handleTickEvent() of its derived class on every timer expiry.Covers a class that inherits RTOS::TickClient with itself as the template argument and implements handleTickEvent(). The callback runs in the FreeRTOS timer service task, so it must not block.

Important
handleTickEvent() must be public or the base must be befriended, because the base calls it.

Derived class

The period is given in scheduler ticks. RTOS::TickClient::Config::autoStart is false, so the timer waits for an explicit RTOS::TickClient::start().

#include <Lib/RTOS/FreeRTOS/TickClient.hpp>
class Sampler final : public RTOS::TickClient<Sampler> {
public:
Sampler() noexcept :
TickClient(Config{.period = 100U, .autoStart = false, .name = "Sampler"}) {
}
void handleTickEvent() noexcept {
// Read the sensor; runs every 100 ticks, in the timer service task.
}
};

Starting and stopping

Check RTOS::TickClient::isValid() after construction, because a failed timer creation leaves the object unusable.

#include <Lib/RTOS/FreeRTOS/TickClient.hpp>
class Sampler final : public RTOS::TickClient<Sampler> {
public:
Sampler() noexcept :
TickClient(Config{.period = 100U, .autoStart = false, .name = "Sampler"}) {
}
void handleTickEvent() noexcept {
// Read the sensor.
}
};
void exampleTask() noexcept {
Sampler sampler;
if (!sampler.isValid()) {
return; // Timer creation failed.
}
static_cast<void>(sampler.start()); // Starts periodic calls to handleTickEvent().
// ...
static_cast<void>(sampler.stop());
}

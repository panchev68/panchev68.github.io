Description

template<Lib::HAL::DriverMode T_MODE>
class Lib::BSP::INA219< T_MODE >

Driver for the INA219 high-side current and power monitor.

The calibration register is never programmed: current is computed on the host from the shunt voltage, then corrected per channel by CurrentCorrection. Every register access is one blocking I2C transaction, so the logic is the same for every transfer mode. Not thread-safe: use each instance from one task.

Opens the I2C port, resets the device and applies the operating configuration.

Configures a 32 V bus range, a +-320 mV shunt range and continuous 128-sample averaged conversions of both channels. Blocks for the reset settle time between the two writes.

Returns
true if the port opened and both configuration writes succeeded.

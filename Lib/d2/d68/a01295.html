Lib::Digi::Core::Frame0x09

Description

Queued local AT command request query (XBee frame type 0x09).

Represents an XBee API frame type 0x09 for queuing AT command parameter changes on the local device for later application. The conversion operator builds the serialized Frame::Data for transmission. Query results are received in response frame type 0x88 (Local AT Command Response) when the queued changes are applied.

Conversion operator to build serialized frame data for transmission.

Constructs a Frame::Data object containing the serialized queued local AT command request in XBee API frame format. Sets the frame type to QUEUE_LOCAL_AT_COMMAND_REQUEST and appends frame ID, AT command, and parameter data in proper byte order.

template<typename Rep, typename Period>
size_t Lib::USB::CDCDevice::write ( std::span< const uint8_t > data,
std::chrono::duration< Rep, Period > timeout )
inlinenodiscardnoexcept

Sends bytes to the host and waits until the host has taken them.

Task context only.

The call fails early when the host has not selected the configuration. The timeout applies to each packet burst, not to the whole call, so a long buffer to a slow host can take longer. Calls from several tasks are serialized.

Template Parameters
RepArithmetic representation type of the timeout.
PeriodRatio type of the timeout.
Parameters
dataBytes to send.
timeoutMaximum time to wait for each burst, rounded up to whole ticks.
Returns
Number of bytes the host took; less than 'data.size()' on a timeout or a bus reset.

Lib::System::Version::Base< Derived >

Description

template<typename Derived>
class Lib::System::Version::Base< Derived >

CRTP base class providing common version functionality.

Implements version string parsing, numeric conversion, conversion operators and formatting. A derived class customizes the sub-version by hiding getSubVersion() with its own, identically named member.

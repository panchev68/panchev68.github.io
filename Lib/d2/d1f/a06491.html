Lib::Math::Filter::MovingAverage

Smooths a noisy measurement such as a digital thermometer or an ADC reading with Lib::Math::Filter::MovingAverage.

Smooths a noisy measurement such as a digital thermometer or an ADC reading with Lib::Math::Filter::MovingAverage. The filter averages the last window of samples kept in a ring buffer: every call of its call operator takes a new sample and returns the average. It owns no heap memory, accepts an integral or a floating-point sample type and is not thread-safe, so call it from one context only.

Filtering a temperature

The window length is a template argument. A longer window smooths more and follows a real change later: a step reaches the output completely after one window of samples. An integral type is averaged exactly and the result is truncated towards zero.

#include <Lib/Math/Filter/MovingAverage.hpp>
#include <cstdint>
// Temperature in 0.1 degC, averaged over the last 8 readings.
Lib::Math::Filter::MovingAverage<int16_t, 8U> temperatureFilter;
// Called from the task that receives the thermometer readings.
int16_t onReading(int16_t reading) noexcept {
return temperatureFilter(reading);
}

Waiting for a full window

Until the window is full the average covers only the samples received so far. Lib::Math::Filter::MovingAverage::isFull() tells when the output has its full smoothing, so a value that must be reliable can wait for it.

#include <Lib/Math/Filter/MovingAverage.hpp>
#include <cstdint>
#include <optional>
Lib::Math::Filter::MovingAverage<int16_t, 8U> filter;
std::optional<int16_t> addReading(int16_t reading) noexcept {
const int16_t average = filter(reading);
if (!filter.isFull()) {
return std::nullopt;
}
return average;
}

Reset

Lib::Math::Filter::MovingAverage::reset() forgets all samples, for example after the link to the sensor was lost, so old readings do not mix with new ones. Lib::Math::Filter::MovingAverage::getAverage() reads the average without adding a sample.

#include <Lib/Math/Filter/MovingAverage.hpp>
#include <cstdint>
void onLinkLost(Lib::Math::Filter::MovingAverage<int16_t, 8U> & filter) noexcept {
filter.reset();
}
int16_t showAverage(const Lib::Math::Filter::MovingAverage<int16_t, 8U> & filter) noexcept {
return filter.getAverage();
}

Removing spikes first

The average does not reject a single wild sample, it spreads it over the whole window. Put a Lib::Math::Filter::Median in front of it to drop the spikes first.

#include <Lib/Math/Filter/Median.hpp>
#include <Lib/Math/Filter/MovingAverage.hpp>
#include <cstdint>
Lib::Math::Filter::Median<int16_t, 5U> spikeFilter;
Lib::Math::Filter::MovingAverage<int16_t, 8U> noiseFilter;
int16_t onReading(int16_t reading) noexcept {
return noiseFilter(spikeFilter(reading));
}

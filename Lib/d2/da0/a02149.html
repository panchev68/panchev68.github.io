Description

ServerBase header file for CAN bus server implementation.

This file defines the ServerBase class, which is a template specialization for server mode in the CAN bus service. It provides functionality for managing CAN bus communication in server mode, including starting and stopping the service, sending messages to client nodes, receiving diagnostics, and handling message callbacks.

The class inherits from ServiceBase and implements server-specific operations such as scanning for active client nodes.

Important dependencies include ServiceBase for base functionality, HAL::CanPort for CAN message handling, and standard library components like std::array for node management.

Note
This is a template specialization for Mode::SERVER.

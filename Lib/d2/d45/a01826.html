Lib::USB::SerialPortRepeaterBase

Description

Base class for USB serial port repeaters.

This class provides a foundation for implementing USB serial port repeaters by inheriting from SerialPort and integrating USB CDC functionality. It handles USB device initialization, data transmission and reception over USB, and provides callbacks for USB events. The class manages USB port enabling/disabling and connection detection, ensuring proper communication between the serial port and USB interface.

Key responsibilities:

  • Initialize and manage USB CDC interface.
  • Handle data flow between serial port and USB.
  • Provide virtual methods for customization in derived classes.
  • Manage USB connection state and signaling.
Note
This class uses a singleton pattern; only one instance should be created.
See also
SerialPort for base serial functionality.

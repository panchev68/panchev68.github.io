RTOS::Task

Task Creation and Management Example.

This example demonstrates how to create, start, and manage a FreeRTOS task using the RTOS::Task class. It shows basic task lifecycle operations including creation with a custom function, starting the task, checking its state, and stopping it. The example uses a simple lambda function that performs a loop with delays to simulate task work.

Example usage:

The code creates a task with a specific name, stack size, and priority. It defines a task function that runs a loop, prints messages, and yields control. The task is started, its state is checked, and then it is stopped. This illustrates safe task management with RAII principles.

#include "Lib/RTOS/Task.hpp"
#include <iostream>
int main() {
// Create a task with custom name, stack size, and priority
RTOS::Task myTask("MyTask", RTOS::Task::DEFAULT_STACK_SIZE, RTOS::Task::DEFAULT_TASK_PRIORITY + 1);
// Define the task function
auto taskFunction = []() {
for (int i = 0; i < 5; ++i) {
std::cout << "Task running, iteration: " << i << std::endl;
RTOS::Task::sleep(100); // Sleep for 100ms
}
std::cout << "Task completed." << std::endl;
};
// Start the task
RTOS::Task::Handle handle = myTask.start(taskFunction);
if (handle) {
std::cout << "Task started successfully." << std::endl;
// Check task state
if (myTask.isRunning()) {
std::cout << "Task is running." << std::endl;
}
// Wait for task to complete (in a real scenario, use notifications or other synchronization)
RTOS::Task::sleep(600); // Wait longer than task duration
// Stop the task
myTask.stop();
std::cout << "Task stopped." << std::endl;
} else {
std::cout << "Failed to start task." << std::endl;
}
return 0;
}

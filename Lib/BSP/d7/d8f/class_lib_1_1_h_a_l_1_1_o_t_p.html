Detailed Description

Driver class for managing STM32 OTP memory.

The OTP class provides singleton access and methods to lock, unlock, read, and write OTP memory. It ensures type safety and robust memory management for STM32 embedded applications, supporting address range validation and type-safe memory access. The class is designed for maintainability and extensibility in embedded system development.

Lib::System::ProduceDate

Reading and Writing Production Date in OTP Memory

This example demonstrates how to use the ProduceDate class to read and write a production date stored in OTP memory. It shows initialization, writing a valid date, and reading it back, including error handling for invalid or empty memory.

Example usage:

The code initializes a ProduceDate instance with an offset, writes a valid date to OTP memory if it's empty, and then reads the date back. It handles potential errors during operations.

#include "Lib/System/ProduceDate.hpp"
#include "Lib/Helper/DateTime.hpp"
int main() {
// Initialize ProduceDate with an offset of 0x100
Lib::System::ProduceDate produceDate(0x100);
// Create a valid date (e.g., 2023-10-01)
Lib::Date dateToWrite(2023, 10, 1);
// Write the date to OTP if memory is empty
Lib::System::ProduceDate::Status writeStatus = produceDate.write(dateToWrite);
if (writeStatus == Lib::System::ProduceDate::Status::OK) {
// Successfully written
} else {
// Handle write error
}
// Read the date from OTP
Lib::Date readDate;
Lib::System::ProduceDate::Status readStatus = produceDate.read(readDate);
if (readStatus == Lib::System::ProduceDate::Status::OK) {
// Use the read date
} else {
// Handle read error or invalid date
}
return 0;
}

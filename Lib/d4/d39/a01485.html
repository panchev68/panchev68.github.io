Lib::Helper::Convert::dBM

Description

dB to percent conversion class.

This class provides static utility functions for converting dB values to percentage representations, including lookup tables for digital percent.

Convert dB value to digital percentage using lookup table.

Converts an 8-bit signed dB value to a percentage using the DBM_TO_PERCENT lookup table. Negative values return 100%, out-of-range values return 1%.

Parameters

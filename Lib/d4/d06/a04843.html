class MulticastDelegate< Ret(Args...), T_CAPACITY >

Non-owning, fixed-capacity collection of FunctionRef subscribers sharing one 'Ret(Args...)' signature.

Holds a fixed-capacity list of FunctionRef subscribers and invokes all of them in registration order, without heap allocation, RTTI or virtual dispatch. Subscribers are stored contiguously in a std::array. Return values of the individual subscribers are discarded, matching event-style usage. A subscriber must not add or remove subscribers of the same instance while it is being invoked, since removal shifts the list and would skip the next entry.

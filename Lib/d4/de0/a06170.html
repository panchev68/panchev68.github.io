Lib::HAL::ADCPort

Reads the regular ADC group through Lib::HAL::ADCPort in the three transfer modes: 'Lib::HAL::DriverMode::BLOCKING' polls the end-of-conversion flag, 'Lib::HAL::DriverMode::IT' waits for a HAL callback, and 'Lib::HAL::DriverMode::DMA' scans the channels into a caller-owned buffer.

Reads the regular ADC group through Lib::HAL::ADCPort in the three transfer modes: 'Lib::HAL::DriverMode::BLOCKING' polls the end-of-conversion flag, 'Lib::HAL::DriverMode::IT' waits for a HAL callback, and 'Lib::HAL::DriverMode::DMA' scans the channels into a caller-owned buffer. The port wraps an ADC_HandleTypeDef created by CubeMX and does not configure the channels itself: the regular sequence (channels, ranks, sample times) must already be set on the handle, and open() then runs HAL_ADC_Init() on it.

The IT and DMA modes need USE_HAL_ADC_REGISTER_CALLBACKS set to 1 in the HAL configuration header, otherwise the header stops the build with a compile-time error. The IT mode's Lib::HAL::ADCPort::read() and Lib::HAL::ADCPort::waitForEvent(), and the DMA mode's Lib::HAL::ADCPort::waitForEvent(), block the calling task and must not run in an ISR.

Hardware assumptions

  • The ADC handle is generated by CubeMX (for example hadc1, declared in 'adc.c'), and its IRQ handler forwards to HAL_ADC_IRQHandler(), so the HAL callbacks registered by the port are invoked.
  • The DMA mode also needs the DMA stream of the ADC configured by CubeMX, with its interrupt forwarding to HAL_DMA_IRQHandler().
  • The sample time of each channel is set by CubeMX; the ports do not expose HAL_ADC_ConfigChannel().

Blocking single conversion

Lib::HAL::ADCPort::start() begins the regular group, Lib::HAL::ADCPort::poll() waits for the conversion and returns the raw value, and Lib::HAL::ADCPort::stop() ends the sequence. A timeout or failure returns 0 and trips an assert in debug builds, so size the timeout for the slowest sample time with margin.

#include <Lib/HAL/ADC/ADCPort-Block.hpp>
#include <chrono>
#include <cstdint>
extern ADC_HandleTypeDef hadc1;
void sampleBlocking() noexcept {
Lib::HAL::ADCPort<Lib::HAL::DriverMode::BLOCKING> adc(&hadc1);
if (!adc.open()) {
return;
}
if (adc.start()) {
const uint32_t raw = adc.poll(std::chrono::milliseconds(10));
// Use raw; its range depends on the resolution set in CubeMX.
static_cast<void>(raw);
static_cast<void>(adc.stop());
}
static_cast<void>(adc.close());
}

Interrupt-driven read from a task

Lib::HAL::ADCPort::read() starts the conversion, waits for Lib::HAL::ADCPort::Event::CONVERSION_COMPLETE or Lib::HAL::ADCPort::Event::ERROR, and returns the value, or 0 on failure or timeout. The timeout is in milliseconds. The port registers itself with the device manager in Lib::HAL::ADCPort::open(), so the ISR path needs no extra wiring.

#include <Lib/HAL/ADC/ADCPort-IT.hpp>
#include <RTOS.hpp>
#include <cassert>
#include <chrono>
#include <cstdint>
extern ADC_HandleTypeDef hadc1;
class AdcTask final {
public:
AdcTask() noexcept :
adc(&hadc1),
task(RTOS::Task::Config("Adc", 256, RTOS::Task::Priority::NORMAL), [this]() { run(); }) {
}
private:
Lib::HAL::ADCPort<Lib::HAL::DriverMode::IT> adc;
RTOS::Task task; // Must stay the last member.
void run() noexcept {
if (!adc.open()) {
assert(!"AdcTask: failed to open ADC");
return;
}
while (true) {
const uint32_t raw = adc.read(std::chrono::milliseconds(20));
if (raw != 0U) {
// Publish raw.
}
RTOS::delay(std::chrono::milliseconds(100));
}
}
};

Waiting for individual events

Use Lib::HAL::ADCPort::start() and Lib::HAL::ADCPort::waitForEvent() directly when the caller must tell a conversion-complete from an error. The timeout of Lib::HAL::ADCPort::waitForEvent() is in RTOS ticks, not milliseconds, so convert with RTOS::TickCounter::msToTicks().

#include <Lib/HAL/ADC/ADCPort-IT.hpp>
#include <RTOS.hpp>
#include <cstdint>
using AdcIt = Lib::HAL::ADCPort<Lib::HAL::DriverMode::IT>;
void convertWithEvents(AdcIt & adc) noexcept {
if (!adc.start()) {
return;
}
const uint32_t events = adc.waitForEvent(AdcIt::Event::CONVERSION_COMPLETE | AdcIt::Event::ERROR, RTOS::TickCounter::msToTicks(20));
if ((events & AdcIt::Event::CONVERSION_COMPLETE) != 0U) {
const uint32_t raw = adc.getValue();
static_cast<void>(raw);
}
static_cast<void>(adc.stop());
}

Scan channels into a buffer

Lib::HAL::ADCPort::start() with a buffer hands it to DMA, which writes one sample per regular rank. The buffer must stay valid until Lib::HAL::ADCPort::stop() is called. The ISR signals Lib::HAL::ADCPort::Event::CONVERSION_COMPLETE once the whole scan has been written, and an empty destination is rejected.

#include <Lib/HAL/ADC/ADCPort-DMA.hpp>
#include <RTOS.hpp>
#include <array>
#include <cstdint>
#include <span>
extern ADC_HandleTypeDef hadc1;
void scanChannels() noexcept {
static std::array<uint32_t, 4> samples{};
Lib::HAL::ADCPort<Lib::HAL::DriverMode::DMA> adc(&hadc1);
if (!adc.open()) {
return;
}
if (adc.start(std::span<uint32_t>(samples))) {
const uint32_t events = adc.waitForEvent(Lib::HAL::ADCPort<Lib::HAL::DriverMode::DMA>::Event::CONVERSION_COMPLETE |
Lib::HAL::ADCPort<Lib::HAL::DriverMode::DMA>::Event::ERROR,
RTOS::TickCounter::msToTicks(50));
if ((events & Lib::HAL::ADCPort<Lib::HAL::DriverMode::DMA>::Event::CONVERSION_COMPLETE) != 0U) {
// Use samples[0] ... samples[3].
}
static_cast<void>(adc.stop());
}
static_cast<void>(adc.close());
}

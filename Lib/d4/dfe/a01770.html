Lib::System::HardwareVersion

Description

Hardware-specific version type derived from VersionBase.

Brief: Provides typed conversions for hardware version values.

The class does not add behavior beyond the base; it exists to provide a semantically clear type for hardware versions and to allow future extensions if hardware-specific formatting or fields are required.

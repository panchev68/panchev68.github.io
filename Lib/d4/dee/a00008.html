Description

Beeper control class for PWM-based audible notification.

Provides beeper functionality for generating tones through PWM-based timer control. Manages configurable beep sequences with durations and pause intervals integrated with RTOS tick events.

Important dependencies or interactions with other modules. Depends on HAL timer module and RTOS tick service for timing and event handling.

Any special instructions or notes for users of the file. Ensure the timer is properly configured and the RTOS tick service is initialized before using the Beep class.

Note
Beep sequences are managed through the RTOS tick service with non-blocking state machine control.

Lib::Ethercat::Dev::Lan9252Base

Description

Lan9252Base class.

Base class for LAN9252 EtherCAT device operations, providing SPI communication, register access, and basic device initialization and control.

Role of the type within the module or system: Serves as a foundation for EtherCAT slave implementations using the LAN9252 chip.

Important design decisions or considerations: Uses a SpiPort class for SPI operations, handles chip reset and ID verification, and provides virtual methods for customization.

Note
This is a base class and should be inherited for specific EtherCAT functionality.
Attention
Ensure proper hardware configuration before instantiation.

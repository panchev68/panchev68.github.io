Lib::Digi::API::Service::Manager

Description

Manager service class for centralized service management.

This singleton class manages a collection of ServiceBase-derived services. It provides methods for adding, removing, and updating services, while preventing duplicates. The manager ensures thread-safe operations and centralized control over service lifecycles. Designed for embedded systems, it integrates with RTOS for efficient resource management.

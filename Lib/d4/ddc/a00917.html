Lib::BSP::Thermometer::DTH::Baseabstract

Description

Base class for DTH thermometer components.

This abstract base class provides the core functionality for DTH sensor communication and data acquisition. It handles hardware initialization, timer configuration, GPIO control, and RTOS task management. Derived classes should implement sensor-specific data processing and protocol handling.

Key features:

  • Timer interrupt-based data reception
  • DMA transfer for high-speed data acquisition
  • RTOS semaphore synchronization
  • Configurable update periods
  • Startup impulse generation

Lib::HAL::Timer::TimEncoder

Reads position and direction from a quadrature encoder with Lib::HAL::Timer::TimEncoder.

Reads position and direction from a quadrature encoder with Lib::HAL::Timer::TimEncoder. The timer counts the encoder edges in hardware, so Lib::HAL::Timer::TimEncoder::read() only returns the counter. It has no interrupt and no task wait; the reads and writes are safe from task context.

The timer must be configured by CubeMX in Encoder mode before the wrapper is opened, because the wrapper only starts the HAL encoder interface and does not set its polarity, filter or prescaler.

Usage

Hardware and CubeMX assumptions

  • Timer (here 'TIM5') in Encoder Mode (TI1 and TI2) with both input pins configured in CubeMX.
  • The counter is 16 or 32 bits wide depending on the timer. The wrapper reads the full 'CNT' register, so wrap-around of a 16-bit timer must be handled by the caller.
  • One Lib::HAL::Timer::TimEncoder per timer handle.

Reading position and direction

#include <Lib/HAL/TIM/TimEncoder.hpp>
class WheelPosition final {
public:
explicit WheelPosition(TIM_HandleTypeDef * timHandle) noexcept :
encoder(timHandle) {
}
[[nodiscard]] bool begin() noexcept {
if (!encoder.open()) {
return false;
}
encoder.write(0U);
return true;
}
[[nodiscard]] uint32_t position() const noexcept {
return encoder.read();
}
[[nodiscard]] bool movingClockwise() const noexcept {
return encoder.isClockwise();
}
private:
Lib::HAL::Timer::TimEncoder encoder;
};

Stopping and closing

Lib::HAL::Timer::TimEncoder::close() stops the counting; the counter value remains until the next Lib::HAL::Timer::TimEncoder::write() call.

void stopWheel(Lib::HAL::Timer::TimEncoder & encoder) noexcept {
if (!encoder.close()) {
return;
}

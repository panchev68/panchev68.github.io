Lib::Helper::Convert

Description

Stateless conversion helpers between signal units and presentation scales.

Contains Lib::Helper::Convert::Ascii (character classification and hex conversion), Lib::Helper::Convert::Bcd (16-bit binary coded decimal), Lib::Helper::Convert::Hex and Lib::Helper::Convert::HexHelper (fixed-width hexadecimal), Lib::Helper::Convert::Percent (a 0 to 100 percentage and an approximate dBm scale) and Lib::Helper::Convert::dBM (dBm-like values or indices as percentages for display).

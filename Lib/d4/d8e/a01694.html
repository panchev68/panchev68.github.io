RTOS::MemoryManager

Description

Memory Manager class for RTOS.

Provides a wrapper around FreeRTOS memory allocation functions with enhanced safety, status reporting, and optional diagnostic capabilities. This class ensures type-safe memory operations and prevents common allocation errors in embedded systems.

The class uses a header-based allocation scheme to track memory blocks and provides methods for allocation, deallocation, and heap monitoring.

Note
All methods are static, making this a utility class without instantiation.
Attention
Memory allocation failures are handled gracefully with status reporting.

enum class RTOS::MemoryManager::Status : uint8_t

Enumeration of possible memory operation status values.

Defines the status codes returned by memory allocation and deallocation operations. These codes indicate the success or failure of memory management functions.

Enumerator
SUCCESS 

Operation completed successfully.

INVALID_SIZE 

Invalid size parameter provided.

OUT_OF_MEMORY 

Insufficient memory available.

NULL_POINTER 

Null pointer passed to function.

SIZE_TOO_LARGE 

Requested size exceeds maximum allowed.

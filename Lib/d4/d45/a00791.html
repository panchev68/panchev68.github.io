Lib::BSP::EncoderPins

Description

Rotary encoder event interface with push button.

Manages rotation and button events from a rotary encoder peripheral. Provides event queue-based handling for rotation (clockwise/counter-clockwise) and button press/release events with configurable pulse divider for rotation filtering.

Reads debounced button state directly from GPIO.

Performs debouncing by reading the button state repeatedly until it stabilizes for the specified debounce period. This is a blocking, synchronous operation suitable for initialization or standalone button state queries.

Parameters
debounceDebounce stability period in milliseconds (0 disables debouncing, default 20 ms).
Returns
true if button is physically pressed (active low), false otherwise.
Note
This is a blocking function that delays during the debounce period.
Suitable for initialization but not recommended for runtime event handling.
Precondition
debounce should be reasonable (typically 10-50 ms for mechanical buttons).

◆ handlePinChangedEvent()

bool Lib::BSP::EncoderPins::handlePinChangedEvent ( uint16_t pinNumber)
inline

Handles GPIO pin change event from interrupt handler.

Processes GPIO pin change events and generates appropriate encoder events (rotation direction or button press/release). This method is called from an ISR and implements quadrature decoding for rotation detection. Button events are generated immediately; rotation events are filtered through the pulse divider.

Parameters
pinNumberGPIO pin number that triggered the interrupt event.
Returns
true if the pin number matches an encoder pin, false if unrecognized.
Precondition
Event queue must be opened before calling this function.
Note
Instance members are used for state tracking to support multiple independent EncoderPins instances and enable testability.
Safe to call from ISR context; uses ISR-safe queue operations.

Lib::HAL::OTP

Reads and programs the one-time-programmable area of the flash with the singleton Lib::HAL::OTP::instance().

Reads and programs the one-time-programmable area of the flash with the singleton .The region is reached through Lib::HAL::OTP::read() and Lib::HAL::OTP::write(). Lib::HAL::OTP::write() is word-aligned, Lib::HAL::OTP::WORD_SIZE bytes at a time, and it can only clear bits: a bit programmed to zero cannot be set back, so the write is rejected when it would require that. Writing the value already stored returns true without touching the flash. Programming must be bracketed by Lib::HAL::OTP::unlock() and Lib::HAL::OTP::lock(), because the flash controller must be unlocked before it accepts a program operation.

Important
The OTP exists only on the STM32F4xx families that define FLASH_OTP_BASE. On the STM32F407xx target the area is 528 bytes from FLASH_OTP_BASE (0x1FFF7800) to FLASH_OTP_END (0x1FFF7A0F). The module guard is HAL_FLASH_MODULE_ENABLED together with FLASH_OTP_BASE; the project's 'stm32f4xx_hal_conf.h' is not in the repository, so the HAL guard is unverified here, although the STM32Cube template enables it.
Warning
Programmed bits cannot be erased, and the OTP is never erased, not even by a mass erase. Every write is permanent. The last 16 bytes of the area hold the lock bytes; programming them locks the corresponding blocks against further writes permanently, so do not write there unless that is the intent.

Program a word once

The write sequence is unlock, program, lock. Lib::HAL::OTP::write() returns false when the address is outside the area or unaligned, when the new value needs a bit set to one that is already programmed to zero, or when the flash controller refuses the program. The first two cases assert in a debug build. In every failure case the flash is left as it was, except for an interrupted program operation, which the hardware may have partly applied.

#include <Lib/HAL/OTP/OTP.hpp>
#include <cstdint>
bool programBoardRevision(uint32_t revision) noexcept {
constexpr uint32_t REVISION_ADDRESS = 0x1FFF7800U;
Lib::HAL::OTP & otp = Lib::HAL::OTP::instance();
if (!otp.unlock()) {
return false;
}
const bool isWritten = otp.write(REVISION_ADDRESS, revision);
const bool isLocked = otp.lock();
return isWritten && isLocked;
}

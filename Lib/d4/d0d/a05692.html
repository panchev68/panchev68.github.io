Lib::Helper::Convert::HexHelperfinal

Description

Helper class that exposes static constexpr conversion utilities.

The class is not instantiable and provides only static methods for converting values to ASCII hex, to packed BCD and back from ASCII hex.

Examples

constexpr uint32_t Lib::Helper::Convert::HexHelper::toBcd ( uint32_t value)
inlinestaticnodiscardconstexprnoexcept

Convert an unsigned decimal value into a packed 32-bit BCD value.

Each decimal digit occupies one nibble, starting from the least significant nibble. Useful for preparing numeric values for protocols or display drivers that expect packed BCD. A 32-bit result holds at most eight digits; a larger value asserts in debug builds and keeps only its eight least significant digits.

Parameters
valueDecimal input value to convert, must not exceed BCD_MAX_VALUE.
Returns
Packed 32-bit BCD representation of the input.

constexpr uint8_t Lib::Helper::Convert::HexHelper::toBcd8 ( uint8_t value)
inlinestaticnodiscardconstexprnoexcept

Convert a 0..99 decimal value into an 8-bit packed BCD byte.

The upper nibble contains the tens digit and the lower nibble the units digit. A value above BCD8_MAX_VALUE asserts in debug builds and keeps only its two least significant digits.

Parameters
valueDecimal value in range 0..99.
Returns
8-bit packed BCD (TTUU) where TT is tens and UU is units.

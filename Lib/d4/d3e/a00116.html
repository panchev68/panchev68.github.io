Description

NetworkDiscovery header file for Digi XBee network device discovery.

This file defines the NetworkDiscovery class, which provides functionality to discover and identify all devices joined to a Digi XBee network. It handles AT command communication, parses node information, and maintains a list of discovered nodes with their addresses and identifiers.

The class integrates with LocalAtCommand for AT command handling and ServiceBase for service management. Designed for embedded Digi modules, it supports robust network scanning, error handling, and diagnostics.

Important dependencies include LocalAtCommand for AT communication, AtCommandString for command formatting, Frame::Helper for data conversion, and ServiceBase for base service functionality.

Note
This service performs blocking operations during discovery; use in appropriate RTOS context.
Attention
Ensure LocalAtCommand is properly initialized before using this service.

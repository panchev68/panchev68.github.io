NodeInfo class for Digi XBee API.

This file defines the NodeInfo class and its nested classes for storing and managing information about Digi XBee nodes, including MAC addresses, network details, discovery data, versions, monitoring values, and diagnostics. The NodeInfo class encapsulates node-specific data structures, supporting robust node identification and monitoring in Digi XBee API applications.

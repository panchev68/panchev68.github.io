Description

Parameters service class.

Provides an interface to read, write, and update static and dynamic parameters of the DIGI XBEE module. Supports both local and remote configuration, and ensures synchronization with the module's state. Designed for embedded Digi modules, enabling robust management of module parameters, error handling, and extensibility for custom configuration logic and diagnostics. Ensures reliable parameter access, event-driven updates, and maintainable, type-safe service development.

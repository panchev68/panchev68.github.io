Lib::HAL::USBDevicePort< DriverMode::DMA >final

Description

DMA specialization.

Only controllers with an internal DMA engine (OTG_HS) can use it; the specialization is compiled only when the device header defines 'USB_OTG_HS'. Transfers start through the same HAL calls as in the IT mode, but the handle must have 'Init.dma_enable' set and every buffer must be 4-byte aligned, since the controller accesses the memory itself.

Receives one transfer on an OUT endpoint and waits for it.

Task context only.

The transfer ends with a short packet or when 'data' is full. On timeout, error or a bus reset it is aborted, so the HAL never writes 'data' after this returns.

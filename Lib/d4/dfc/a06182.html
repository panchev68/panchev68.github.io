Lib::HAL::GPIO::Output

Drives and reads single pins with Lib::HAL::GPIO::Output, Lib::HAL::GPIO::Input and Lib::HAL::GPIO::ExtInterrupt.

Drives and reads single pins with Lib::HAL::GPIO::Output, Lib::HAL::GPIO::Input and Lib::HAL::GPIO::ExtInterrupt. Each wrapper is bound to one Lib::HAL::GPIO::Handle, built from a CubeMX-generated pin pair through the 'PIN()' macro. None of these classes takes a transfer mode, so there is no Lib::HAL::DriverMode parameter.

The wrappers do not configure the pin: the mode, speed and pull are set by the CubeMX-generated MX_GPIO_Init(), which must run before any wrapper is used. Output and input calls are plain register accesses and are safe from an ISR. Lib::HAL::GPIO::ExtInterrupt is the exception, see its own subsection.

Handle and the PIN() macro

'PIN(LED)' expands to a Lib::HAL::GPIO::PinConfig built from LED_GPIO_Port and LED_Pin, the symbols CubeMX emits in 'main.h'. Lib::HAL::GPIO::Handle converts implicitly from that value and must outlive every wrapper that refers to it. A default-constructed handle has no port, and the wrapper constructors assert on it.

#include <Lib/HAL/GPIO.hpp>
namespace {
constexpr Lib::HAL::GPIO::Handle LED_HANDLE = PIN(LED);
constexpr Lib::HAL::GPIO::Handle BUTTON_HANDLE = PIN(BUTTON);
} // namespace

Driving an output

Lib::HAL::GPIO::Output::write() takes the logic level, Lib::HAL::GPIO::Output::setHigh() and Lib::HAL::GPIO::Output::setLow() are shorthands, and Lib::HAL::GPIO::Output::toggle() inverts the current level. The class is non-copyable and non-movable, so keep it as a long-lived object.

#include <Lib/HAL/GPIO.hpp>
namespace {
Lib::HAL::GPIO::Output led(LED_HANDLE);
} // namespace
void blinkOnce() noexcept {
led.setHigh();
led.toggle(); // Now low.
led.write(true); // Now high again.
}

Reading an input

Lib::HAL::GPIO::Input::read() returns true when the pin is high, and Lib::HAL::GPIO::Input::isHigh() and Lib::HAL::GPIO::Input::isLow() are named forms of the same read. The explicit conversion to a boolean also reads the pin.

#include <Lib/HAL/GPIO.hpp>
namespace {
Lib::HAL::GPIO::Input button(BUTTON_HANDLE);
} // namespace
bool isButtonPressed() noexcept {
return button.isLow(); // Active-low button with a pull-up configured by CubeMX.
}

Interrupt on an input pin

Lib::HAL::GPIO::ExtInterrupt derives from Lib::HAL::GPIO::Input and registers its pin with a shared dispatcher in its constructor, which asserts if the pin is already registered. The EXTI line and its edge are set by CubeMX, and the header provides the HAL_GPIO_EXTI_Callback() family, so do not define those in user code.

The bound callback is not run in the interrupt. The HAL callback only signals a shared worker task, which invokes the callback in task context, so the callback may use RTOS calls that are illegal from an ISR. A capturing lambda must be an lvalue that outlives the binding; a capture-less lambda or a function pointer can be passed directly.

Warning
Each EXTI line can be claimed by one Lib::HAL::GPIO::ExtInterrupt at a time; a second one on the same pin asserts in its constructor.
#include <Lib/HAL/GPIO.hpp>
namespace {
void onButtonEdge() noexcept {
// Runs in the EXTI worker task, not in the ISR.
}
Lib::HAL::GPIO::ExtInterrupt button(BUTTON_HANDLE);
} // namespace
void setupButtonInterrupt() noexcept {
button.bindCallback(onButtonEdge);
}
void teardownButtonInterrupt() noexcept {
button.unbindCallback();
}

Whole-port access

Lib::HAL::GPIO::Port wraps one register block (for example GPIOD) rather than a single pin. Lib::HAL::GPIO::Port::setup() passes a native GPIO_InitTypeDef to HAL_GPIO_Init(), and Lib::HAL::GPIO::Port::write() and Lib::HAL::GPIO::Port::read() access the output and input data registers as one word. Use it only when several pins must change in one bus write; the pin wrappers above are the default.

#include <Lib/HAL/GPIO.hpp>
void initPortDLow4() noexcept {
Lib::HAL::GPIO::Port port(GPIOD);
port.setup({
.Pin = GPIO_PIN_0 | GPIO_PIN_1 | GPIO_PIN_2 | GPIO_PIN_3,
.Mode = GPIO_MODE_OUTPUT_PP,
.Pull = GPIO_NOPULL,
.Speed = GPIO_SPEED_FREQ_LOW,
.Alternate = 0,
});
port.write(0x0AU); // Drives PD1 and PD3 high, PD0 and PD2 low.
}

Description

Calendar date and time of day stored as small integral fields.

The type contains nested Date and Time types, helpers to pack the combined value into a 32-bit compact representation, conversion to and from std::chrono::sys_seconds, and conversion to std::tm for interoperability with C runtime functions.

◆ pack()

constexpr uint32_t Lib::Helper::DateTime::pack ( const DateTime & dateTime)
inlinestaticnodiscardconstexprnoexcept

Packs a valid date-time into a compact 32-bit representation.

The packed layout uses exactly 32 bits: seconds (6), minutes (6), hours (5), day (5), month (4) and a year delta (6) relative to Date::FIRST_YEAR. This limits the packable year range to [Date::FIRST_YEAR, 'Date::FIRST_YEAR + 63'].

Parameters
dateTimeDate-time to pack; should be valid and within the packable year range.
Returns
32-bit packed representation.

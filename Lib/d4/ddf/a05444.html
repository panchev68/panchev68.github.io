Lib::GUI::ListMenufinal

Description

Vertical list of text items of which one is selected, scrolled to keep the selection visible.

Holds only a view of the item texts, so the texts must outlive the menu. The selected row is drawn inverted. The selection wraps around at both ends. Moving the selection only changes the state, the list appears on the display with the next Lib::GUI::ListMenu::draw() and a flush.

void Lib::GUI::ListMenu::draw ( )
inlinenoexcept

Draws the visible rows into the frame buffer.

The area of the list is cleared first. The first visible row is moved just far enough to show the selected item.

Draws with the canvas and the primitives of Lib::GUI::Context, so it is clipped to the current drawing area.

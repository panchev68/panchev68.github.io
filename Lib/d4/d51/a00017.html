Description

Digital peripheral base class for SPI-based I/O expansion.

Provides a base class for managing digital inputs and outputs through SPI communication. Supports configurable pin mapping, SPI communication with timeout handling, and dual-port (inputs and outputs) management with independent state tracking and callbacks.

Important dependencies or interactions with other modules. Depends on HAL GPIO and SPI modules, RTOS task and timeout services for timing and concurrency control.

Any special instructions or notes for users of the file. Configure inputs and outputs before calling setup(). Pin mapping fields must be valid and properly aligned.

Note
Supports both sequential (single SPI) and parallel (dual SPI) update modes for optimal throughput.

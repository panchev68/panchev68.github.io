Description

Digital Peripheral Base Class Header.

This header file defines the base classes and structures for digital peripherals in the BSP library. It provides interfaces for handling digital inputs and outputs via SPI communication, supporting both sequential and parallel update modes. The classes manage GPIO pins, SPI ports, and RTOS tasks for efficient peripheral control in embedded systems.

Important dependencies include HAL GPIO and SPI modules, as well as RTOS for task management. This module interacts with hardware peripherals through SPI and GPIO interfaces.

Note
Ensure that SPI and GPIO configurations are properly initialized before using instances of this class.
Attention
This class is designed for embedded systems and may not be suitable for non-real-time applications due to its use of RTOS tasks and hardware-specific code.

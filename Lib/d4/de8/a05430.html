Lib::GUI::Fontfinal

Description

Access to the glyphs and the measures of a font, with an optional character translation table.

Wraps a Lib::GUI::FontData, which must outlive the font, and answers the questions a text drawing needs: the glyph and the width of a character, the height of the font and the width of a text. A character is first translated with the precode table, if one is set, so a source code page (for example a Windows-1251 byte) can be mapped onto the characters of the font. A character that still has no glyph is replaced by '?', or by the first character of the font if even that is missing, so a lookup always succeeds. Characters are compared by their code from 0 to 255, so fonts that reach above 0x7F work.

Lib::System::Configuration

Description

Manage a 31-bit configuration value stored in OTP flash.

Maps a configuration slot at a given flash offset and provides read/write helpers using std::bitset for easy bit-level access.

Status Lib::System::Configuration::write ( const Bitset & value)
inline

Write the provided configuration bitset to flash.

Attempts to unlock the OTP controller, write the 31-bit value and then lock the controller. The stored word uses VALID_MASK bit as a reserved marker and is cleared when writing actual data.

Parameters
valueBitset containing the bits to store.
Returns
Status::OK on success, Status::ERROR on failure.
Precondition
OTP::unlock() returns true (asserted).
Postcondition
OTP controller is locked again (asserted).

Lib::HAL::Timer< TimerMode::ENCODER >

Description

Timer specialised for encoder mode.

This class specialises the generic Timer template for TimerMode::ENCODER and implements the platform-specific open/close operations required to run the timer as a quadrature encoder. It provides a public callback that is invoked when the captured counter value changes.

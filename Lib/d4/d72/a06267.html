RTOS::StreamBuffer

Shows RTOS::StreamBuffer, a byte FIFO that carries a continuous stream of bytes from one writer to one reader.

Shows RTOS::StreamBuffer, a byte FIFO that carries a continuous stream of bytes from one writer to one reader. The writer can be a task or an ISR. Unlike a queue, the buffer keeps no message boundaries: a reader gets whatever bytes are buffered, up to its own buffer size.

  • One writer and one reader. Two tasks blocked in RTOS::StreamBuffer::send(), or two in RTOS::StreamBuffer::receive(), trip a kernel assertion.
  • A blocked reader wakes when at least the trigger level of bytes is buffered, or on timeout.
  • Use RTOS::StreamBuffer::sendFromISR() and RTOS::StreamBuffer::receiveFromISR() inside interrupts; they never block.
  • A buffer created with RTOS::StreamBuffer::createStatic() holds one byte less than its storage.
  • The wrapper is move-only and deletes the native buffer when it is destroyed or closed.

Dynamic creation

RTOS::StreamBuffer::open() allocates the buffer from the FreeRTOS heap, which requires configSUPPORT_DYNAMIC_ALLOCATION set to 1.

#include <Lib/RTOS/FreeRTOS/StreamBuffer.hpp>
#include <cstddef>
RTOS::StreamBuffer stream;
void init() {
// 128 bytes capacity, wake the reader as soon as 1 byte is available.
if (!stream.open(128U, 1U)) {
// FreeRTOS heap exhausted or invalid parameters.
}
}

Static creation

RTOS::StreamBuffer::createStatic() uses caller-provided storage, so no heap is needed. The storage and the control structure must outlive the stream buffer.

#include <Lib/RTOS/FreeRTOS/StreamBuffer.hpp>
#include <array>
#include <cassert>
#include <cstdint>
namespace {
std::array<uint8_t, 257U> storage; // 256 usable bytes
StaticStreamBuffer_t control;
RTOS::StreamBuffer stream;
}
void init() {
// Wake the reader once 16 bytes are buffered.
const bool ok = stream.createStatic(storage, control, 16U);
assert(ok);
}

Task to task

A producer task writes text and a consumer task reads it. Timeouts can be passed as ticks or as std::chrono::duration values.

#include <Lib/RTOS/FreeRTOS/StreamBuffer.hpp>
#include <Lib/RTOS/FreeRTOS/Task.hpp>
#include <array>
#include <chrono>
#include <cstdint>
#include <span>
#include <string_view>
using namespace std::chrono_literals;
void process(std::span<const uint8_t> data);
namespace {
RTOS::StreamBuffer stream;
}
bool openStream() {
// 256 bytes, the consumer wakes on the first byte.
return stream.open(256U, 1U);
}
void producer() {
while (true) {
constexpr std::string_view text = "Hello from producer\r\n";
// Blocks up to 100 ms while the buffer has no free space.
const size_t sent = stream.send(text, pdMS_TO_TICKS(100));
if (sent < text.size()) {
// Timeout: only part of the text was written.
}
RTOS::Task::delay(500ms);
}
}
void consumer() {
std::array<uint8_t, 32U> rx{};
while (true) {
// Blocks until at least the trigger level is buffered or 1 s elapses.
const size_t received = stream.receive(rx.data(), rx.size(), 1s);
if (received == 0U) {
continue; // Timeout, nothing received.
}
process(std::span<const uint8_t>(rx.data(), received));
}
}

ISR to task (UART receive)

A UART interrupt writes each received byte and a task handles the byte stream. The ISR passes higherPriorityTaskWoken and calls portYIELD_FROM_ISR(), so the reader runs right after the ISR.

#include "stm32f4xx_hal.h"
#include <Lib/RTOS/FreeRTOS/StreamBuffer.hpp>
#include <array>
#include <cassert>
#include <cstdint>
#include <span>
extern UART_HandleTypeDef huart2;
void handleBytes(std::span<const uint8_t> data);
namespace {
uint8_t rxByte;
std::array<uint8_t, 129U> rxStorage;
StaticStreamBuffer_t rxControl;
RTOS::StreamBuffer rxStream;
}
extern "C" void HAL_UART_RxCpltCallback(UART_HandleTypeDef * huart) {
if (huart != &huart2) {
return;
}
BaseType_t higherPriorityTaskWoken = pdFALSE;
static_cast<void>(rxStream.sendFromISR(&rxByte, 1U, higherPriorityTaskWoken)); // Byte is dropped if the buffer is full.
static_cast<void>(HAL_UART_Receive_IT(&huart2, &rxByte, 1U));
portYIELD_FROM_ISR(higherPriorityTaskWoken);
}
void uartReaderTask() {
const bool ok = rxStream.createStatic(rxStorage, rxControl, 1U);
assert(ok);
static_cast<void>(HAL_UART_Receive_IT(&huart2, &rxByte, 1U));
std::array<uint8_t, 64U> line{};
while (true) {
const size_t n = rxStream.receive(line.data(), line.size(), portMAX_DELAY);
handleBytes(std::span<const uint8_t>(line.data(), n));
}
}

Several writers

A stream buffer supports only one writer at a time. When several tasks write, serialize them with a RTOS::Mutex and use a zero timeout inside the lock, so no task blocks in RTOS::StreamBuffer::send() while it holds the mutex.

#include <Lib/RTOS/FreeRTOS/Mutex.hpp>
#include <Lib/RTOS/FreeRTOS/MutexGuard.hpp>
#include <Lib/RTOS/FreeRTOS/StreamBuffer.hpp>
#include <string_view>
namespace {
RTOS::Mutex writeMutex; // Opened at startup with open().
RTOS::StreamBuffer logStream; // Opened at startup with open().
}
void log(std::string_view text) {
RTOS::MutexGuard guard(writeMutex);
if (logStream.send(text, 0U) < text.size()) {
// Buffer full: the rest of the text is dropped.
}
}

Monitoring and control

#include <Lib/RTOS/FreeRTOS/StreamBuffer.hpp>
#include <cstddef>
#include <cstdint>
void monitor(RTOS::StreamBuffer & stream) {
if (stream.isOpen()) {
const size_t used = stream.getBytesAvailable(); // Bytes waiting to be read.
const size_t spaces = stream.getSpacesAvailable(); // Bytes that can still be written.
const uint8_t load = stream.getUtilizationPercent();
static_cast<void>(used);
static_cast<void>(spaces);
static_cast<void>(load);
if (stream.isFull()) {
// The producer is faster than the consumer.
}
// Wake the reader only once 32 bytes are collected.
static_cast<void>(stream.setTriggerLevel(32U));
// Discard all content; fails while a task is blocked on the buffer.
static_cast<void>(stream.reset());
}
}

Moving ownership

#include <Lib/RTOS/FreeRTOS/StreamBuffer.hpp>
#include <utility>
RTOS::StreamBuffer makeStream() {
RTOS::StreamBuffer s;
static_cast<void>(s.open(64U, 1U));
return s; // The handle moves out, no copy.
}
void moveExample() {
RTOS::StreamBuffer owner = makeStream();
RTOS::StreamBuffer other = std::move(owner); // 'owner' no longer holds the buffer.
static_cast<void>(other.isOpen());
}

Lib::Math::HammingCode

Protects 16-bit words with Lib::Math::HammingCode, a Hamming(21,16) code that corrects any single flipped bit.

Protects 16-bit words with Lib::Math::HammingCode, a Hamming(21,16) code that corrects any single flipped bit. The class has only static constexpr functions, needs no instance and is safe to call from any context, including an interrupt handler. A codeword uses the low 21 bits of a 32-bit value.

Encoding and decoding

Lib::Math::HammingCode::encode() adds five parity bits to the 16 data bits and Lib::Math::HammingCode::decode() returns the data after correcting a single-bit error.

#include <Lib/Math/HammingCode.hpp>
#include <cstdint>
void storeAndLoad() noexcept {
const uint32_t codeword = Lib::Math::HammingCode::encode(0xA5C3U);
// The codeword travels over a noisy link or sits in memory; bit 6 gets flipped.
const uint32_t received = codeword ^ (1U << 6U);
const uint16_t data = Lib::Math::HammingCode::decode(received);
static_cast<void>(data);
}

Clean, corrected and uncorrectable words

Lib::Math::HammingCode::decode() corrects silently. To learn what happened, compute the syndrome first: 0 means a clean word, a value for which Lib::Math::HammingCode::canCorrect() returns true is the position of the flipped bit, and anything else is uncorrectable. Two flipped bits can also produce a correctable-looking syndrome, which this code cannot tell apart from a single-bit error, so add a checksum on top when that matters.

#include <Lib/Math/HammingCode.hpp>
#include <cstdint>
enum class WordState {
CLEAN,
CORRECTED,
UNCORRECTABLE,
};
WordState check(uint32_t codeword, uint16_t & data) noexcept {
const uint32_t syndrome = Lib::Math::HammingCode::syndrome(codeword);
if (syndrome == 0U) {
data = Lib::Math::HammingCode::decode(codeword);
return WordState::CLEAN;
}
if (Lib::Math::HammingCode::canCorrect(syndrome)) {
data = Lib::Math::HammingCode::decode(codeword);
return WordState::CORRECTED;
}
return WordState::UNCORRECTABLE;
}

Compile-time lookup table

Every function is constexpr, so a table of codewords can be built at compile time and placed in flash. The following code builds the codewords of the values 0 to 15 and checks the table with static_assert.

#include <Lib/Math/HammingCode.hpp>
#include <array>
#include <cstddef>
#include <cstdint>
constexpr std::array<uint32_t, 16U> NIBBLE_CODEWORDS = [] {
std::array<uint32_t, 16U> table{};
for (size_t i = 0U; i < table.size(); ++i) {
table[i] = Lib::Math::HammingCode::encode(static_cast<uint16_t>(i));
}
return table;
}();
static_assert(NIBBLE_CODEWORDS[0] == 0x000000U);
static_assert(NIBBLE_CODEWORDS[1] == 0x000007U);
static_assert(NIBBLE_CODEWORDS[2] == 0x000019U);
static_assert(Lib::Math::HammingCode::decode(NIBBLE_CODEWORDS[11]) == 11U);

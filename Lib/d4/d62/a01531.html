Lib::Helper::Delay Class Reference

Description

Non-instantiable busy-wait delay utilities.

Provides static methods for precise busy-wait delays using the Cortex-M DWT cycle counter. Supports delays in microseconds and nanoseconds with automatic clock frequency detection. The class is designed to be non-instantiable to prevent construction and copying.

This utility is optimized for short blocking delays where interrupt disabling is acceptable. For longer delays or when interrupts must remain enabled, use RTOS delay functions instead.

Note
Uses DWT cycle counter for high-precision timing.
Attention
Performs busy-waiting; interrupts are disabled during delay.

void Lib::Helper::Delay::microseconds ( uint32_t delay)
inlinestatic

Perform busy-wait delay for specified microseconds.

Blocks execution for approximately the specified number of microseconds using the DWT cycle counter for precise timing. The actual delay may vary slightly due to clock frequency accuracy and interrupt overhead.

Parameters
[in]delayDelay duration in microseconds; must be greater than 0.
Precondition
DWT cycle counter must be available and HAL_RCC_GetHCLKFreq() must return valid core clock frequency in Hz.
Postcondition
Execution is blocked for at least the specified delay duration.

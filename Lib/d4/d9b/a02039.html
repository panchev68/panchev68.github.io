Lib::HAL::GPIO::Input

Description

Represents a discrete hardware input pin mapped to a specific microcontroller port.

Non-final base class for "Output" and "ExtInterrupt", which add their own behavior on top of the input state reading.

Examples
Lib::GSM::A7670E.

◆ read()

bool Lib::HAL::GPIO::Input::read ( ) const
inlinenodiscardnoexcept

Reads the instantaneous logical state of the physical input line.

The constructor already asserts a valid port; the runtime check only protects a release build (where "assert" is compiled out) from dereferencing a null port.

Returns
"true" if the input is logical HIGH, "false" if logical LOW or the underlying port handle is invalid.

Lib::Digi::Core::ComDriverabstract

Description

ComDriver class for Digi XBee modules.

This class handles UART communication, frame parsing, hardware reset, and event hooks for Digi XBee modules. It provides methods for opening the driver, sending frames, and virtual callbacks for message events. The implementation supports RTOS integration with mutexes and tasks for thread-safe operations.

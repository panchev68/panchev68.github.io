Lib::BSP::FMEM::OSPI::W25Q128JVSIQ

Quad-SPI (OCTOSPI) device driver for the Winbond W25Q128JVSIQ. More...

Description

Quad-SPI (OCTOSPI) device driver for the Winbond W25Q128JVSIQ.

Read, write and erase run over OCTOSPI in regular command mode: Fast Read Quad I/O for reads and Quad Page Program (1-1-4) for writes. open() runs a power-up, reset and JEDEC ID probe, and the driver is present only when the probe reports the 16 MB capacity code.

Deep power-down: powerDown() and powerUp() wait the datasheet time tDP / tRES1 (3 us), so the next command may follow at once. While powered down the device ignores every command except Release Power-Down, so a caller that uses enterPowerDown() must call releasePowerDown() before the next access.

Program and erase waits sleep the calling task between BUSY polls once the scheduler runs. For the same device on a plain 4-wire SPI bus, see Lib::BSP::W25Q128JVSIQ.

The header compiles to nothing unless the HAL configuration defines HAL_OSPI_MODULE_ENABLED, so it is only usable on an MCU with an OCTOSPI peripheral and that module enabled.

See also
W25Q128JV datasheet, Rev I (Winbond-hosted copy), older revision; the newest found is Rev M (December 2024), not yet confirmed on winbond.com

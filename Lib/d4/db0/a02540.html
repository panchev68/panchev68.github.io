RTOS::Kernel

Description

Kernel wrapper around FreeRTOS primitives.

Encapsulates common RTOS operations and provides RAII helpers for critical sections and scheduler suspension to simplify safe usage across the codebase.

template<typename T_FUNC>
void RTOS::Kernel::withCriticalSection ( T_FUNC && func)
inlinestatic

Execute a function while holding a task-level critical section.

This helper creates a temporary CriticalSection object which disables scheduler/interrupts as appropriate for the task context, executes the provided callable and then restores the previous state when it goes out of scope.

Template Parameters

Parameters

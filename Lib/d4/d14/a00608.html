SerialNumber.hpp - Serial Number Generator.

This file defines the SerialNumber class, which generates a unique serial number for embedded devices using the device's unique identifier (UID) and the CityHash algorithm. The serial number is computed at construction time and cached for efficient access. It provides conversions to uint32_t and formatted string views for various use cases, such as logging, storage, or display.

The class ensures type safety, prevents runtime errors through compile-time checks, and interacts with the device's UID memory region. It depends on the Lib::Helper::CityHash utility for hashing and assumes the presence of a UID_BASE pointer to the device's UID.

Important dependencies include Lib/Helper/CityHash.hpp for hashing functionality, and standard libraries like <array>, <cstdint>, <cstdio>, <cstring>, <string>, and <string_view> for data manipulation and formatting.

Special instructions: Ensure UID_BASE is properly initialized and points to valid UID memory before instantiating SerialNumber. The class is designed for single-threaded embedded environments and uses static buffers for string formatting.

Note
This class is final and cannot be inherited. It performs memory operations on UID_BASE, so verify hardware compatibility and memory layout.
Attention
Do not use in multi-threaded contexts without synchronization, as it uses static buffers.

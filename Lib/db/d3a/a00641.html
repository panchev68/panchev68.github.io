Description

USB serial port interface.

This header defines the SerialPort class which provides an interface for USB serial communication. It uses UART ports for RX/TX and manages asynchronous operation via RTOS tasks. The class supports device reset control and baud-rate configuration.

Note
  • Ensure UART ports and GPIO pins are configured before using this class.

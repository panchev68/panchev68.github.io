Description

CAN receive message wrapper class.

This file defines the CanRxMessage class, which encapsulates a CAN receive message including the header information from CAN_RxHeaderTypeDef and the data payload. It provides a convenient interface for accessing CAN message properties such as identifier, data length, and data buffer.

The class inherits from CAN_RxHeaderTypeDef to include standard CAN header fields and adds a fixed-size data buffer for the message payload.

Important dependencies: Requires STM32 HAL CAN library for CAN_RxHeaderTypeDef.

Note
This class is designed for use in embedded systems with STM32 microcontrollers.
Attention
Ensure that the data buffer size matches the maximum CAN data length (8 bytes).

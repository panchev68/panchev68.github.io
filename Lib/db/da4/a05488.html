Lib::HAL::OSPIPortBase< T_DERIVED >

Description

template<typename T_DERIVED>
class Lib::HAL::OSPIPortBase< T_DERIVED >

CRTP base implementing the open/close/busy policy common to every 'OSPIPort' mode.

Owns no state, not even the native handle: it reaches the handle through 'derived()->getHandle()'. The blocking mode stores the handle itself, while the IT and DMA modes get it from Device through OSPIPortAsync, since only they need the DeviceManager link that Device carries.

Not compile-checked in this repository: the STM32F4 target has no OCTOSPI peripheral and its HAL package ships no OCTOSPI driver.

RTOS::Kernel

Shows the scheduler and critical-section helpers of RTOS::Kernel.

Shows the scheduler and critical-section helpers of RTOS::Kernel.Covers a short critical section that protects a shared counter from other tasks and ISRs, the tick count and the free-standing delay helpers, and the heap statistics. Inside an interrupt handler use RTOS::Kernel::CriticalSectionFromISR, which saves and restores the interrupt mask.

Warning
Keep critical sections as short as possible: while one is active, interrupts of the configured priority are masked and the scheduler cannot switch tasks.

Usage

Protecting shared data

Construction enters the critical section and destruction leaves it, so the scope braces bound its length.

#include <Lib/RTOS/FreeRTOS/Kernel.hpp>
namespace {
volatile uint32_t sharedCounter = 0U;
}
void incrementCounter() noexcept {
const RTOS::Kernel::CriticalSection criticalSection;
++sharedCounter;
}

Tick count and delays

RTOS::getTickCount() is task-context only; use RTOS::getTickCountFromISR() inside an interrupt.

#include <Lib/RTOS/FreeRTOS/Kernel.hpp>
#include <chrono>
using namespace std::chrono_literals;
void measureDelay() noexcept {
const RTOS::Kernel::TickType startTick = RTOS::getTickCount();
RTOS::delay(100ms);
const RTOS::Kernel::TickType elapsedTicks = RTOS::getTickCount() - startTick;
static_cast<void>(elapsedTicks);
}

Heap statistics and yielding

RTOS::Kernel::getMemoryInfo() reports the configured and free heap in bytes.

#include <Lib/RTOS/FreeRTOS/Kernel.hpp>
void checkHeap() noexcept {
const RTOS::Kernel::MemoryInfo heap = RTOS::Kernel::getMemoryInfo();
if (heap.freeHeap < heap.totalHeap / 10U) {
// Less than 10 % of the heap is free.
}
RTOS::Kernel::yield(); // Let other tasks of the same priority run.
}

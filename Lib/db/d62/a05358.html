Lib::HAL::CANPort< DriverMode::IT >final

Description

Interrupt-driven (IT) specialization.

Adds the RTOS task-notification synchronization, HAL callback registration and DeviceManager wiring that only interrupt-driven transfers need. open() registers the instance with the DeviceManager.

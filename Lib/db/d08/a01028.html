Lib::System

Description

System-level facade and configuration storage.

Lib::System::System bundles the firmware and hardware versions, the last reset state, the configuration and the serial number. Lib::System::Configuration manages a 31-bit configuration bitmap stored in one OTP word, and OTP bits cannot be set again once programmed.

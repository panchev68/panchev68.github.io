Lib::System::ProduceDate

Description

ProduceDate class.

Manages production date storage and retrieval from OTP memory.

The ProduceDate class encapsulates operations to read and write production dates stored in OTP memory at a specified offset. It provides validation, error handling, and ensures that writes occur only to empty locations.

Role within the System module: Handles immutable production date information.

Important design decisions: Uses OTP for permanent storage, includes status enumeration for operation results, and validates dates before writing.

Note
Writes are allowed only if the location is empty to prevent overwriting.

1/** One-Time Programmable (OTP) flash memory interface for STM32F4xx microcontrollers.
2 *
3 * This header file provides a C++ wrapper around the STM32F4xx HAL library for OTP flash operations.
4 * It includes the OTP class which offers methods for locking, unlocking, reading, and writing to OTP memory.
5 * The class ensures type-safe operations and validates address ranges to prevent out-of-bounds access.
6 * It supports various data types (uint8_t, uint16_t, uint32_t, uint64_t) for read and write operations.
7 * The OTP memory is used for storing permanent data that can be written once and read multiple times.
8 *
9 * @note This file requires the STM32F4xx HAL library and is only included if FLASH_OTP_BASE is defined.
10 *
11 * @attention Ensure that the flash is unlocked before writing and locked after operations to prevent accidental writes.
12 *
13 * @version 3.04
14 * @date 17 Jan 2026
15 * @file OTP.hpp
16 */

Description

SerialNumber Class - Unique Device Serial Number Generator.

The SerialNumber class generates a unique serial number for embedded devices by hashing the device's unique identifier (UID) using the CityHash algorithm. The serial number is computed once during construction and cached in the 'result' member for efficient access throughout the object's lifetime.

This class serves as a type-safe wrapper for device identification, providing implicit conversions to uint32_t for numerical operations and std::string_view for formatted string representations. It encapsulates the logic for UID access and hashing, ensuring reliable and consistent serial number generation.

Key design decisions include using CityHash for its speed and collision resistance in embedded contexts, caching the result to avoid repeated computations, and providing conversion operators for seamless integration with existing code. The class is marked as final to prevent inheritance and maintain encapsulation.

Note
The class assumes UID_BASE is a valid pointer to the device's UID memory. It performs compile-time assertions and runtime checks to ensure safety.
Attention
Memory operations are performed on UID_BASE; ensure it points to readable memory to avoid undefined behavior.

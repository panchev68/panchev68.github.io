Description

template<Lib::HAL::DriverMode T_MODE>
class Lib::BSP::RFID::NfcManager< T_MODE >

Manages the ISO14443A card discovery state machine of an ST25R100 reader.

Waits for the reader's wake-up (card detect) event, then runs REQA, anticollision and SELECT in a dedicated RTOS task and reports the activated card's UID through a callback. Single-size (4-byte), double-size (7-byte, e.g. NTAG21x) and triple-size (10-byte) UIDs are supported. While the callback runs the card stays selected, so it may read NFC Forum Type 2 memory with readPages() or write one page with writePage(). After every attempt, successful or not, the reader is put back into Wake-up mode.

Owns the task that drives the reader; the reader itself is shared by reference. Not thread-safe: call start() and stop() from one task.

using Reader = Lib::BSP::RFID::ST25R100<Lib::HAL::DriverMode::IT>; using Manager =
Lib::BSP::RFID::NfcManager<Lib::HAL::DriverMode::IT>;
// The UID is 4, 7 or 10 bytes. readPages() and writePage() may be called from here. void onCard(std::span<const uint8_t>
uid) noexcept {
}
Manager manager(reader, {.taskConfig = {"NFC", 512U, RTOS::Task::Priority::NORMAL}, .onCardActivated = onCard});
static_cast<void>(manager.start());

inlinenodiscardnoexcept

Reads the 32-byte originality signature of the selected NTAG21x card with the READ_SIG (0x3C) command.

The signature is NXP's ECDSA (secp128r1) signature over the 7-byte UID of an NTAG21x. Valid only from within the Config::onCardActivated callback, while the card is still selected.

inlinenodiscardnoexcept

Writes one NFC Forum Type 2 page (4 bytes) to the selected card with the WRITE (0xA2) command, then reads it back with readPages() to confirm.

Valid only from within the Config::onCardActivated callback, while the card is still selected.

Untested on real hardware. The card's 4-bit ACK/NAK reply to WRITE is not decoded, so the read-back is the only success signal.

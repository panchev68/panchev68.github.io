Lib::HAL::BackupRamDomain

Keeps small values across resets in the backup registers with Lib::HAL::BackupRamDomain.

Keeps small values across resets in the backup registers with Lib::HAL::BackupRamDomain. Lib::HAL::BackupRamDomain::open() enables the PWR clock, the backup-domain write access and the backup SRAM clock; Lib::HAL::BackupRamDomain::close() reverses them. Access is read-only until 'open()' succeeds, so call it before any Lib::HAL::BackupRamDomain::readRegister() or Lib::HAL::BackupRamDomain::writeRegister(). Those two methods touch the registers directly and do not check the access state themselves. The backup registers survive a system reset but are lost when V_BAT and V_DD are both removed.

Important
The module guard is 'HAL_PWR_MODULE_ENABLED'; the project's 'stm32f4xx_hal_conf.h' is not in the repository, so that guard is unverified here, although the STM32Cube template enables it. On the STM32F407xx target the register count is 'RTC_BKP_NUMBER' (20, indices 0 to 19), and the registers are read from the RTC block because the device has no TAMP block.
Warning
The index is checked only by an assert in debug builds. An index at or above 'RTC_BKP_NUMBER' is undefined behavior in release builds, so pass only the indices defined for the target.

Usage

Store a value across a reset

#include <Lib/HAL/BackupRamDomain/BackupRamDomain.hpp>
namespace {
constexpr uint32_t BOOT_COUNT_REGISTER = 0U;
}
uint32_t incrementBootCount() {
Lib::HAL::BackupRamDomain backup;
if (!backup.open()) {
return 0U;
}
const uint32_t count = backup.readRegister(BOOT_COUNT_REGISTER) + 1U;
backup.writeRegister(BOOT_COUNT_REGISTER, count);
static_cast<void>(backup.close());
return count;
}

Keep the access window short

Backup-domain write access stays open between 'open()' and 'close()', so a stray write from another task or an ISR during that window goes through. Open it, do the accesses, and close it in one task.

#include <Lib/HAL/BackupRamDomain/BackupRamDomain.hpp>
void saveFaultCode(uint32_t faultCode) {
constexpr uint32_t FAULT_REGISTER = 1U;
Lib::HAL::BackupRamDomain backup;
if (backup.open()) {
backup.writeRegister(FAULT_REGISTER, faultCode);
static_cast<void>(backup.close());
}
}

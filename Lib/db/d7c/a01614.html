Lib::Helper::TimePeriod

Description

TimePeriod class for measuring elapsed time.

This class provides methods to measure time intervals using RTOS ticks. It allows starting a timer, stopping it, checking elapsed time, and resetting.

Note
Designed for embedded systems with RTOS.

Lib::HAL::UartPort< T_MODE >

Description

template<DriverMode T_MODE>
class Lib::HAL::UartPort< T_MODE >

Template wrapper for a UART port handle.

T_MODE selects the driver specialization. The base template stores an opaque handle pointer and provides basic utilities (set/get/isValid). Concrete behavior is implemented in specializations.

Template Parameters
T_MODEDriver mode specialization (DriverMode enum).

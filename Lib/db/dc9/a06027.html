Description

Firmware version including the build date.

Wraps 'VersionBase' for the major/minor/sub-version parsing and formatting, and adds the compilation date, parsed from the 'DATE' macro at compile time and formatted as YYYY-MM-DD. Uses CRTP instead of virtual dispatch. Convertible to a packed number or to a fixed, NUL-terminated version string. Re-exposes the protected 'VersionBase' members as public through using-declarations.

Parses version string in 'X.Y' format into 32-bit numeric representation.

Returns an empty optional rather than a zero on failure, so a malformed string is distinguishable from the perfectly valid version '0.0'. A field is rejected when it holds a non-digit or exceeds 255.

Parameters

Returns

Formats the version as a string in 'X.YY.ZZ' format.

The major field is unpadded; minor and sub-version are zero-padded to two digits. Digits are built by hand instead of through printf, which would pull in formatting code the target does not need.

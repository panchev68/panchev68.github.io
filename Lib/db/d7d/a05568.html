Lib::HAL::Timer::TimPwmOutputfinal

Description

Controls one hardware timer channel configured under a Pulse Width Modulation profile.

Provides direct control over the Capture/Compare Registers (CCR) and the Auto-Reload Register (ARR) to modify duty cycle and frequency at runtime. The register setters are single register writes, safe to call from task and ISR context alike.

◆ setPeriod()

void Lib::HAL::Timer::TimPwmOutput::setPeriod ( uint32_t periodValue)
inlinenoexcept

Overrides the timer period in the Auto-Reload Register (ARR); affects every channel of the timer.

Without ARR preload ('AutoReloadPreload'), a value below the running counter lets it overshoot to the counter maximum before wrapping, producing one long period.

Parameters
periodValueNew auto-reload value in timer ticks; the PWM period is 'periodValue' + 1 ticks.

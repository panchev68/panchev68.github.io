Detailed Description

MemoryManager class for FreeRTOS heap allocation and diagnostics.

Provides static APIs for allocation, deallocation, diagnostics, and heap usage. Ensures type safety, error handling, and diagnostic tracking for embedded systems.

void * RTOS::MemoryManager::allocate ( size_t size)
inlinestatic

Allocates memory from FreeRTOS heap.

This overload calls the central implementation and discards the status code.

Parameters
sizeNumber of bytes to allocate.
Returns
Pointer to the user area (not including internal header) on success, or nullptr on failure.
Precondition
size must be a valid allocation size as checked by isValidSize.
Postcondition
On success the returned pointer must be freed with deallocate().
Note
Use the overload taking a Status & if you need the detailed failure reason.

Allocates memory from FreeRTOS heap with status code.

Central entry point for allocations. The returned pointer points to the user area (header is internal).

Parameters
sizeNumber of bytes to allocate.
[out]statusSet to the resulting Status value describing success or failure.
Returns
Pointer to user memory on success, or nullptr on failure. On failure status contains the reason.
Precondition
status may be any Status &; caller may pass a dummy variable if status is not required.
Postcondition
If non-null, returned pointer must be released using deallocate().

Gets heap usage as a percentage (0-100).

Uses the configured configTOTAL_HEAP_SIZE (if defined) and the FreeRTOS free-heap query to compute usage.

Returns
Heap usage percent in whole numbers (0-100). Returns 0 when configTOTAL_HEAP_SIZE is not defined.
Note

constexpr bool RTOS::MemoryManager::isValidSize ( size_t size)
inlinestaticconstexpr

Checks if size is valid for allocation.

Validates requested allocation size against internal header overhead and configured total heap (if available).

Parameters
sizeNumber of bytes requested by the caller.
Returns
true if the requested size is non-zero, does not overflow when adding the internal header, and (if configTOTAL_HEAP_SIZE is defined) does not exceed the configured heap minus header.
Precondition
This function is constexpr and may be evaluated at compile time when possible.

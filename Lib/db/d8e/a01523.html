Lib::Helper::DateTime::Date Class Reference

Description

Date representation with day, month, and year components.

Encapsulates date components with comprehensive validation including leap year calculation and month-specific day range verification. Provides day of week calculation, string conversion (DD.MM.YYYY format), and comparison operators. Years are stored as absolute values starting from FIRST_YEAR (2000) for compatibility with 16-bit representation.

Note
Supports years 2000-2063 in packed format (6-bit year offset).

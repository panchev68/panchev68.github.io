Description

template<typename T, size_t T_SIZE>
requires (std::default_initializable<T> && (T_SIZE > 0U) && (T_SIZE <= std::numeric_limits<size_t>::max() / 2U))
class Lib::Helper::RingBuffer< T, T_SIZE >

Fixed-capacity FIFO container with lock-free single-producer/single-consumer semantics.

Exactly one execution context may call push() and exactly one (possibly different) context may call pop() / front(). clear(), copy and move are not concurrency-safe.

Template Parameters

T_SIZEMaximum number of stored elements; must be greater than 0 and at most half of SIZE_MAX.

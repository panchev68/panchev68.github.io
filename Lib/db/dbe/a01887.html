Lib::System::HardwareVersion

Hardware Version Creation and Usage Example.

This example demonstrates how to create a HardwareVersion object, initialize it with a version string and sub-version, and use its implicit conversion operators for numeric and string representations. This is useful for hardware identification and logging in embedded systems.

Example usage:
#include "HardwareVersion.hpp"
#include <iostream>
int main() {
// Create a hardware version with string "1.2.3" and sub-version 4
Lib::System::HardwareVersion hw("1.2.3", 4);
// Implicit conversion to uint32_t for numeric operations
uint32_t numericVersion = hw;
// Implicit conversion to std::string for display or logging
std::string stringVersion = hw;
// Output the version information
std::cout << "Hardware Version: " << stringVersion << " (Numeric: " << numericVersion << ")" << std::endl;
return 0;
}

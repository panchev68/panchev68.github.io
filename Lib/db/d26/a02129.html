Description

I2C port interface for board support package header file.

This file defines the I2CPort interface for abstracting I2C communication in the board support package. It provides a standardized interface for I2C port operations including initialization, deinitialization, device readiness checks, and data transfer methods for I2C devices.

The interface supports both basic I2C operations and advanced memory-mapped operations with configurable memory addressing. It enables hardware abstraction and allows for different I2C implementations (hardware, software, or mock) to be used interchangeably.

Key features:

  • Port initialization and deinitialization
  • Device readiness verification
  • Basic data transmission and reception
  • Memory-mapped read/write operations
  • Timeout-based operations for reliability

Implementations of this interface should handle the low-level I2C protocol details and provide appropriate error handling and timeout management.

Note
This is an abstract interface; concrete implementations must be provided for specific hardware.
Attention
Ensure proper I2C bus configuration and pull-up resistors for reliable communication.

Description

CRTP base for XBee client applications: answers every received message and supervises the connection.

The client never sends on its own: each message accepted by the derived class is answered with the message the derived class builds. Missing messages are counted as lost cycles and, after "CONNECTION_TIMEOUT", the connection is dropped.

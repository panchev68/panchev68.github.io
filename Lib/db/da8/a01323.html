Lib::Digi::Core::Frame0x81

Description

Parsed Digi XBee API 0x81 (16-bit receive packet) response.

The type extracts the 16-bit source address, RSSI, receive option flags and the RF payload so callers can access parsed frame contents without manual parsing.

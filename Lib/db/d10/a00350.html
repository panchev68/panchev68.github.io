Description

External interrupt handling for GPIO pins with event-driven architecture.

Defines the ExtInterrupt class for managing external interrupts on GPIO pins with event binding, unbinding, and centralized event processing. Provides an EventManager singleton for dispatching interrupt events to registered ExtInterrupt instances and integrates with HAL callbacks.

Key dependencies:

  • Input.hpp: Base GPIO input functionality
  • DeviceManagerBase.hpp: Device management utilities
  • Standard libraries: <cassert>, <cstdint>, <functional>, <unordered_map>

Thread safety: Not thread-safe; should be used within a single task context or with external synchronization in RTOS environments.

Note
This module is enabled only if HAL_EXTI_MODULE_ENABLED is defined.
Attention
Ensure proper initialization and event binding before using interrupts. Always unbind callbacks before destroying ExtInterrupt instances.

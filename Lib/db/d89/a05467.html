Lib::HAL::LPTimerfinal

Description

Manages LPTIM peripheral configuration and interrupt-driven timeout events.

Targets the STM32U5 family and every other part whose HAL ships the modern LPTIM interface, which it relies on for 'LPTIM_OC_ConfigTypeDef', HAL_LPTIM_OC_ConfigChannel() and the per-channel state array. Parts without an LPTIM peripheral, STM32F407 among them, compile this header away, so including it unconditionally is safe.

bool Lib::HAL::LPTimer::startTimeoutInterrupt ( uint32_t timeoutMs)
inlinenodiscardnoexcept

Configures and starts an interrupt-driven timeout.

The slowest prescaler that still fits the timeout into the 16-bit counter is used; a longer timeout is clamped to the longest one the hardware can count.

Parameters
timeoutMsThe desired timeout duration in milliseconds.
Returns
true if successfully armed, false otherwise.

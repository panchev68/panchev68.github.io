Description

Base Voltmeter Header File.

This header file defines the Base class for implementing ADC-based voltmeter functionality in the BSP. It handles ADC voltage reading with integration filtering and linear interpolation for accurate measurements. Designed to integrate with DeviceManager for periodic updates via RTOS tick events.

Important dependencies include HAL ADC port, integration filter, and linear interpolation. Integrates with DeviceManager for tick-based event handling.

Derive from this class to create specific voltmeter implementations. Must be used within DeviceManager context for proper operation.

Note
Requires ADC_HandleTypeDef to be defined; uses conditional compilation.
Attention
Ensure ADC channel and sampling time are compatible with hardware.

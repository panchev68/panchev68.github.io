Detailed Description

Event group wrapper class.

Provides a RAII-compliant wrapper around FreeRTOS event groups for managing event bits. Supports operations like setting, clearing, and waiting for bits with configurable modes and timeouts. Ensures safe usage in both task and ISR contexts.

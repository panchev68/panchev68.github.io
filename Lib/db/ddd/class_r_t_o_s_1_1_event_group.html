Description

template<size_t N_BITS>
class RTOS::EventGroup< N_BITS >

RAII wrapper for FreeRTOS event groups.

Owns a FreeRTOS event group handle and releases it in the destructor. The type is move-only to prevent accidental double-release of the underlying handle. Provides both template-based and bitset-based bit operations for flexibility and type safety in embedded real-time systems.

Template Parameters
N_BITSNumber of event bits supported (1-EventBits_t width).
Note
Move semantics transfer handle ownership to prevent dangling references.
Not copyable; use move semantics for resource management.

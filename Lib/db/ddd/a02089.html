ST7789 Display Driver Header.

This header file defines the Driver class template specialization for the ST7789 display controller. It provides methods for initializing the display and transmitting pixel data blocks via SPI interface.

Important dependencies or interactions with other modules: Inherits from DriverBase, utilizes HAL SPI and GPIO modules for hardware interaction.

Any special instructions or notes for users of the file: Ensure proper configuration of SPI and GPIO pins before instantiation.

Note
This driver is designed for embedded systems using FreeRTOS.

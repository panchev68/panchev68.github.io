Lib::Digi::API::Service::Parameters::Data

Description

Data structure for module parameters.

Holds static and dynamic parameters for the Digi XBee module, including node identifier, serial number, network settings, firmware/hardware versions, and runtime metrics. Provides structured access to module configuration and status information.

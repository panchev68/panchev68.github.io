Lib::Helper::Buffer

Managing dynamic buffers for data storage.

This example demonstrates how to use the Buffer class to manage dynamic byte buffers in embedded systems. The Buffer class provides a safe and convenient way to handle data storage, access, and manipulation, with automatic memory management.

Example usage:
#include "Lib/Helper/Buffer/Buffer.hpp"
int main() {
// Create a buffer with initial size
Lib::Helper::Buffer buffer(16);
// Access and modify elements
buffer[0] = 0xAA;
buffer[1] = 0xBB;
// Get buffer size
size_t size = buffer.getSize();
// Use buffer as raw pointer for external functions
uint8_t* dataPtr = buffer;
// Clear the buffer
buffer.clear();
// Create buffer from existing data
uint8_t externalData[8] = {1, 2, 3, 4, 5, 6, 7, 8};
Lib::Helper::Buffer extBuffer(externalData, 8);
return 0;
}

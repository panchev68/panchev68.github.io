Description

Byte swapping utilities for integral types.

This file provides compile-time and runtime functions for swapping bytes in integral types. It includes generic templates for byte swapping and specializations for common types like uint16_t, int32_t, etc. The functions ensure type safety and compile-time checks for supported sizes.

Important dependencies: Requires C++17 standard library features like std::is_integral, std::make_unsigned.

Any special instructions: Use these functions for endianness conversion in embedded systems.

Note
This header is part of the Lib::Helper namespace.
Attention
Ensure that the type is integral and of supported size to avoid static_assert failures.

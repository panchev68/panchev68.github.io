Lib::GUI::Context

Draws text, shapes and widgets on a 128 x 64 SSD1306 OLED with the Lib::GUI layer.

Draws text, shapes and widgets on a 128 x 64 SSD1306 OLED with the Lib::GUI layer.The GUI classes know no driver. Lib::GUI::Context is the one singleton that holds the whole configuration of the display: its size, the default font, and inside it the Lib::GUI::Display, the Lib::GUI::Primitives for shapes and the Lib::GUI::Canvas for text, already connected. The application describes the display once with Lib::GUI::Context::setup(), binds the driver with Lib::GUI::Context::bind(), and from then on every widget draws with draw() and no argument, taking what it needs from the context. Nothing is shown before Lib::GUI::Context::flush(), which sends the whole frame buffer over I2C and blocks, so call it from a task, never from an ISR. One display is drawn from one task; the classes are not thread-safe.

Important
The font has to be an export of the LCD Vision font editor kept as a constant array. Change the generated flash unsigned char to const uint8_t and keep one of the two data blocks: the one before else for Lib::GUI::FontLayout::HORIZONTAL_ROWS, the one after it for Lib::GUI::FontLayout::VERTICAL_ROWS.

Setting up the display

The configuration is written once. Lib::GUI::LcdVision::parse() reads the font array without copying it, so the array has to outlive the font data. A glyph of an LCD Vision font already contains the space to the next one, so the canvas adds none; use Lib::GUI::Canvas::setGlyphSpacing() on Lib::GUI::Context::getCanvas() to add some.

#include <Lib/BSP/Display/SSD1306.hpp>
#include <Lib/GUI/Context.hpp>
#include <Lib/GUI/LcdVision.hpp>
#include <Lib/HAL/I2C.hpp>
#include "ContinuumMediumBold.hpp" // LCD Vision export of the font 'continuum_medium_bold'.
extern "C" I2C_HandleTypeDef hi2c1; // Generated by CubeMX in main.c.
Lib::HAL::I2CPort<Lib::HAL::DriverMode::IT> i2cPort{&hi2c1};
Lib::BSP::Display::SSD1306<128, 64> oled{{.i2cPort = i2cPort}}; // The driver; SA0 pin low.
const Lib::GUI::FontData font = Lib::GUI::LcdVision::parse(continuum_medium_bold, Lib::GUI::FontLayout::HORIZONTAL_ROWS);
[[nodiscard]] bool openDisplay() noexcept {
if (!oled.open()) {
return false; // Port failed to open or the display did not acknowledge.
}
Lib::GUI::Context & gui = Lib::GUI::Context::instance();
gui.setup({.width = 128, .height = 64, .font = font}); // The whole GUI configuration.
gui.bind(oled); // Binds setPixel(), clear() and flush() of the driver.
return true;
}

Text and shapes

Text and shapes take a Lib::GUI::Position, the top-left corner counted in pixels, and anything outside the drawing area is clipped. Lib::GUI::Primitives::lineByAngle() counts the angle counter-clockwise from the right, as on a drawing.

void drawSplash() noexcept {
Lib::GUI::Context & gui = Lib::GUI::Context::instance();
Lib::GUI::Primitives & primitives = gui.getPrimitives();
Lib::GUI::Canvas & canvas = gui.getCanvas();
gui.clear();
primitives.roundRect({0, 0}, 128, 64, 8);
primitives.line({8, 34}, {119, 34}, true, 2, Lib::GUI::LineStyle::DASHED);
primitives.fillRoundRect({90, 40}, 30, 18, 4);
static_cast<void>(primitives.lineByAngle({20, 56}, 20, 45.0F));
canvas.drawTextAligned(0, 4, 128, "Hello", Lib::GUI::Alignment::CENTER);
static_cast<void>(canvas.drawText({8, 40}, "OLED"));
static_cast<void>(gui.flush());
}

Circles, arcs and curves

All angles are in degrees, counted counter-clockwise from the right: 0 is right, 90 up, 180 left, 270 down. An arc runs from its start to its end angle in that direction. Lib::GUI::PixelMode::INVERT toggles a pixel and needs a driver that can read pixels back, as Lib::BSP::Display::SSD1306 can.

void drawGauge() noexcept {
Lib::GUI::Primitives & primitives = Lib::GUI::Context::instance().getPrimitives();
primitives.circle({32, 32}, 30);
primitives.fillArcRound({32, 32}, 26, 6, 210.0F, 330.0F); // The lower part of the dial.
primitives.pieSlice({96, 32}, 24, 45.0F, 135.0F); // A slice that points up.
primitives.ellipse({96, 32}, 30, 20);
primitives.triangle({90, 56}, {102, 56}, {96, 46}, 30.0F, {96, 52}); // Turned 30 degrees about its base.
primitives.bezierCurve({0, 63}, {64, 20}, {127, 63});
primitives.setPixel({32, 32}, true, Lib::GUI::PixelMode::INVERT);
}

Drawing in a part of the display

Lib::GUI::Context::ViewportScope limits drawing to a rectangle for one block. Inside it the coordinates start at the top-left corner of the rectangle, the text, the shapes and the widgets are clipped to it, and Lib::GUI::Context::clear() clears only that part, so each panel can be redrawn on its own. Scopes can be nested. The frame buffer is still sent whole by Lib::GUI::Context::flush().

void drawPanels() noexcept {
Lib::GUI::Context & gui = Lib::GUI::Context::instance();
gui.clear();
{
const Lib::GUI::Context::ViewportScope left({0, 0}, 64, 64);
gui.getPrimitives().rect({0, 0}, 64, 64);
gui.getCanvas().drawTextAligned(0, 20, 64, "Left", Lib::GUI::Alignment::CENTER);
}
{
const Lib::GUI::Context::ViewportScope right({64, 0}, 64, 64);
gui.getPrimitives().rect({0, 0}, 64, 64);
gui.getCanvas().drawTextAligned(0, 20, 64, "Right", Lib::GUI::Alignment::CENTER);
}
static_cast<void>(gui.flush());
}

Widgets in a periodic task

A Lib::GUI::String keeps its own copy of the text and clears its width before drawing, so a shorter number leaves nothing of a longer one. A widget can have a font of its own, here the one that was parsed above; the others use the font of the context. A Lib::GUI::ListMenu is used the same way with Lib::GUI::ListMenu::selectNext() and Lib::GUI::ListMenu::draw(); give it a font small enough for several rows.

#include <Lib/GUI/ProgressBar.hpp>
#include <Lib/GUI/String.hpp>
#include <RTOS.hpp>
#include <chrono>
void displayTask() noexcept {
if (!openDisplay()) {
return;
}
Lib::GUI::Context & gui = Lib::GUI::Context::instance();
Lib::GUI::String<8> value({.position = {4, 6}, .width = 120, .alignment = Lib::GUI::Alignment::CENTER, .font = &font});
Lib::GUI::ProgressBar bar({.x = 8, .y = 44, .width = 112, .height = 10, .maxValue = 100});
for (int32_t level = 0;; level = (level + 5) % 105) {
gui.clear();
gui.getPrimitives().roundRect({0, 0}, 128, 64, 6);
value.setNumber(level);
value.draw();
bar.setValue(static_cast<uint32_t>(level));
bar.draw();
if (!gui.flush()) {
break; // The bus failed; report it and stop drawing.
}
RTOS::delay(std::chrono::milliseconds(100));
}
}

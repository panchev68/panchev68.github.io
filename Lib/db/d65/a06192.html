Lib::HAL::Reset

Reads the cause of the last reset with Lib::HAL::Reset::getResetState() and requests a system reset with Lib::HAL::Reset::resetSystem().

Reads the cause of the last reset with Lib::HAL::Reset::getResetState() and requests a system reset with .Both members are static; the class has no state and no instance. Lib::HAL::Reset::getResetState() clears the RCC reset flags on every call, so read it once, early in start-up, and keep the result. A later call reports Lib::HAL::Reset::State::UNKNOWN unless a new reset has occurred since.

The class depends only on the CMSIS and RCC definitions, so it has no HAL module guard and needs no module enabled in 'stm32f4xx_hal_conf.h'. The reset flags it maps differ between families; 'RCC_FLAG_PORRST' is used only where the device defines it.

Warning
Lib::HAL::Reset::resetSystem() does not return. Flush logs, close files and stop peripherals that must finish first, because the reset discards everything else.

}
bool wasWatchdogReset(Lib::HAL::Reset::State state) noexcept {
return state == Lib::HAL::Reset::State::INDEPENDENT_WATCHDOG ||
state == Lib::HAL::Reset::State::WINDOW_WATCHDOG;
}

Lib::Crypto::WolfSSLSHA256final

Description

Streaming SHA-256 hasher on wolfCrypt.

Use it where wolfCrypt is linked in anyway, instead of pulling in a second implementation; otherwise 'Lib::Crypto::SHA256' offers a dependency-free software engine and the STM32 HASH peripheral. Every wolfCrypt call can fail, so update() and finish() report failure instead of asserting.

Important
After a failed call or after finish(), the hasher must not be used again.

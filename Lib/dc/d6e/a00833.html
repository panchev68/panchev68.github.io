JaggedArray.hpp

Description

Lightweight non-owning container adapter for jagged data structures.

Provides a collection of pointers to elements or rows with add, remove and indexed access. Designed for embedded use where ownership is managed externally; the pointer list itself lives in a std::vector and therefore on the heap, which is the price of an unbounded row count.

Description

FirmwareVersion class for firmware versioning and build date retrieval.

This file defines the FirmwareVersion class, which extends VersionBase and adds build date extraction using compile-time macros. It ensures type safety, input validation, and robust conversion between version formats for embedded firmware management.

Important dependencies: Inherits from VersionBase for core versioning functionality. Any special instructions: Use compile-time macros DATE for build date extraction.

Note
Build date is extracted at compile time using DATE macro.

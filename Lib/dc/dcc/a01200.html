Description

template<Lib::HAL::DriverMode T_MODE>
class Lib::BSP::Thermometer::TMP102< T_MODE >

Driver for the TMP102 temperature sensor over an I2C port.

Covers initialization, temperature reads, thermostat alert limits and sleep/one-shot control. It caches the configuration register and the device pointer register, so a temperature read right after another one costs a single I2C read instead of a pointer write followed by a read.

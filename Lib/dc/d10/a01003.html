template<Mode T_MODE>
class Lib::Canbus::Service< T_MODE >

Service template class forward declaration.

This template class is forward declared to allow specializations based on the CAN bus mode. Actual implementations are provided in separate files for each mode (e.g., client or server).

Template Parameters
T_MODEThe CAN bus mode enumeration value (e.g., Mode::CLIENT or Mode::SERVER).

Description

Encoder Pins Header File.

This header file defines the EncoderPins class, which provides functionality for handling rotary encoder inputs in the BSP (Board Support Package) layer. The class manages encoder channels, button inputs, and event processing using GPIO and RTOS queue mechanisms. It supports configuration of encoder parameters, event detection, and state management for embedded applications.

Important dependencies include GPIO handling from Lib::HAL and RTOS queue for event queuing.

Note
Ensure proper GPIO pin configuration and RTOS initialization before using this class.
Attention
This class is designed for embedded systems and may have real-time constraints.

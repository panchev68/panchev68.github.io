Lib::BSP::EEPROM::I2C::DriverBaseabstract

Description

Base class for I2C EEPROM drivers.

Provides common functionality for interacting with I2C EEPROM devices over an I2C interface. This class handles device configuration, I2C communication, page-aligned writes, and supports both 8-bit and 16-bit memory addressing schemes for flexible EEPROM compatibility.

Design details. Uses an abstract interface for read/write operations, allowing derived classes to specialize addressing modes based on the EEPROM type (8-bit or 16-bit addressing).

Note
Constructor automatically sets the I2C device address to EEPROM format (0xA0 | lower nibble).
Use open() and close() to manage the I2C connection lifecycle.

Lib::USB::SerialPortRepeaterBase

Description

USB serial port repeater bridging UART and USB CDC communication.

Extends SerialPort with CDC USB device communication: device initialization, connection state tracking, line coding, USB power detection and signalling hooks.

Deprecated
Use Lib::USB::CDCDevice instead.

◆ open()

Status Lib::USB::SerialPortRepeaterBase::open ( )
inlinenodiscardoverridevirtual

Opens the serial port and the USB device interface.

Calls SerialPort::open(), waits USB_PORT_OPEN_DELAY, enables the USB port, installs the CDC callbacks (Init, DeInit, Control, Receive), calls MX_USB_DEVICE_Init() and sets the open flag.

Returns
Status::OK if successful, Status::ERROR if port is already open or SerialPort::open() fails.

Lib::Digi::API::Service::ServiceBase

Description

Lifecycle base class for services registered with Manager.

Derived classes override 'open()'/'close()' to acquire and release resources, and 'beginUpdate()'/'update()'/ 'endUpdate()' to implement periodic behaviour. Manager drives all lifecycle calls through the private 'updateHandler()', so derived classes never need to call it directly. Manager stores heterogeneous ServiceBase-derived instances behind a single pointer type and dispatches to each one's overrides, which is the one place in this hierarchy where runtime polymorphism is actually load-bearing.

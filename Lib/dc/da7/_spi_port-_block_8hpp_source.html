1/** Blocking SPI port implementation for HAL layer.
2 *
3 * This file provides the SpiPort template specialization for blocking (synchronous) SPI operations.
4 * It implements the blocking driver mode, where SPI operations block until completion.
5 * The class inherits from SpiPortBase and overrides virtual methods to provide blocking
6 * transmit, receive, and full-duplex operation support using HAL library functions.
7 *
8 * The blocking mode is suitable for simple SPI operations where tasks can wait for completion
9 * without the need for asynchronous callbacks or event-driven programming. All operations are
10 * synchronous and will block the calling task until the SPI operation completes or times out.

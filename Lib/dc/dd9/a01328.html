Description

Instance.hpp — singleton-like instance management utilities.

This file provides template classes and functions for creating singleton-like instances of objects, ensuring lazy, thread-safe and efficient instantiation in embedded systems. Utilities include default and configuration-based instance creation with optional manual storage management.

Note
  • Uses placement new and aligned storage to avoid heap allocations where required by embedded constraints.
  • Designed for C++11 and later where static local initialization is thread-safe.

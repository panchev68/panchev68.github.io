Lib::BSP::Thermometer::DTH::Driver< Type::DTH22 >

Description

DTH22 driver class template specialization.

This class provides the specific implementation for the DTH22 digital temperature and humidity sensor. It inherits from the Base class and implements the sensor communication protocol, data processing, and validation for the DTH22 sensor type.

The DTH22 sensor uses a single-wire serial interface with timing-based data transmission. This driver handles the initialization, data acquisition, checksum validation, and conversion of raw sensor data to temperature and humidity values.

Key responsibilities:

  • Sensor initialization and startup
  • Periodic data acquisition using RTOS tasks
  • Raw data processing and validation
  • Temperature and humidity value calculation
  • Diagnostic information collection

Lib::Helper::Exception

Description

Custom exception class for embedded systems.

Exception class for custom error handling.

This class provides a custom exception that inherits from std::exception and includes additional functionality for error message handling. It is designed to be lightweight and suitable for embedded environments.

Note
The class uses std::string_view for efficient message handling without memory allocation implications in constrained environments.

Extends std::exception to provide custom error messages and utilities for terminate handlers and exception rethrowing.

Role within the module: Base class for custom exceptions in embedded systems.

Important design decisions: Uses string_view for caption to avoid copying; provides static methods for terminate handling; conditional compilation for advanced features.

Lib::Helper::Convert::dBM

Description

dBM to percentage conversion utilities.

Provides constexpr helper functions to convert dBm values (signed) to a percentage representation suitable for UIs or diagnostics.

constexpr uint8_t Lib::Helper::Convert::dBM::toPercent ( int16_t value)
inlinestaticconstexpr

Convert a signed 16-bit dBm value to percentage.

Values <= -100 map to 0%, values >= 0 map to 100%, values in-between are linearly mapped by adding 100 to the value.

Parameters
valuedBm value (signed 16-bit).
Returns
uint8_t Percentage in range 0..100.

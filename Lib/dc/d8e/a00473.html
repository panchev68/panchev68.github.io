Description

Comprehensive DateTime handling for embedded systems.

Provides Time, Date, and DateTime classes with validation, string conversion, day of week calculation, and 32-bit packing/unpacking capabilities. Uses fixed-width integers for type safety and optimized for C++17 embedded systems.

The file contains strongly-typed date and time components with leap year validation, Zeller's algorithm for day of week calculation, and efficient 32-bit packing for storage and transmission. All operations use fixed-width integers for hardware compatibility.

Important dependencies include standard library headers for string operations, time structures, and array utilities. Designed for embedded systems with limited resources.

Note
Designed for embedded systems; validate dates before use to prevent invalid states.
All date/time components use fixed-width integers for hardware compatibility.

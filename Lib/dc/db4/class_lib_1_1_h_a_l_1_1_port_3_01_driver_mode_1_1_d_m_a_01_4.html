Lib::HAL::Port< DriverMode::DMA > Class Reference

Description

Hardware Abstraction Layer namespace.

Contains classes and functions for hardware abstraction in embedded systems. ADC DMA Port specialization.

Specialization of the Port template for DriverMode::DMA. Provides DMA-based ADC port functionality, implementing the required interface for ADC operations using DMA.

Role of the type within the ADC module as a DMA-based port implementation.

Important design decisions include using DMA for efficient ADC data transfer and inheriting from AdcTransparentPortBase for common ADC functionality.

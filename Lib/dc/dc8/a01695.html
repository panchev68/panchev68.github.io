RTOS::StreamBuffer Class Reference

Description

StreamBuffer class.

This class provides a C++ wrapper around FreeRTOS stream buffers for safe and efficient data streaming.

Note
This class is not thread-safe for multiple writers/readers; use appropriate synchronization.

Description

BSP EEPROM I2C Namespace.

This namespace contains the Board Support Package (BSP) components for EEPROM devices accessed via I2C interface. It includes base classes and utilities for managing I2C EEPROM operations, such as read/write functionality, address handling, and device configuration for various EEPROM chip types with 8-bit or 16-bit addressing.

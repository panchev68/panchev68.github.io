Lib::Digi::Core::Frame0x81final

Description

RX Packet (0x81): RF data received from a node addressed by its 16-bit address.

Wire layout after the frame type byte: source address (2, big-endian), RSSI (1), options (1), RF data. A frame shorter than the fixed fields leaves every member zero and "rfData" empty.

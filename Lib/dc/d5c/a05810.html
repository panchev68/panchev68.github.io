template<std::floating_point T_VALUE, typename T_INPUT = T_VALUE>
class Lib::Math::CubicInterpolation< T_VALUE, T_INPUT >

Fixed-capacity cubic spline interpolator.

Builds a piecewise cubic spline from a set of (x,y) points and provides evaluation and derivative queries. Designed for embedded systems with fixed memory usage and no dynamic allocation: the spline coefficients are computed in place in the segment table, so computing them needs no extra stack. Points may be added in any order; they are sorted and the coefficients are recomputed before the next query.

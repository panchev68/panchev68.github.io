Lib::HAL::CanRxMessage

Description

CAN receive message class.

This class represents a CAN receive message, encapsulating the message header and data payload. It inherits from CAN_RxHeaderTypeDef to provide access to standard CAN header fields and includes a data buffer for the message content.

The class provides methods to retrieve the message identifier, data length, and access to the data buffer. It supports default construction, copy construction, and copy assignment.

Role within the module: Acts as a wrapper for CAN receive messages in the HAL layer, simplifying access to message properties and ensuring type safety.

Important design decisions: Uses std::array for fixed-size data buffer to avoid dynamic memory allocation in embedded systems.

Note
The data buffer is fixed at 8 bytes, matching standard CAN message size.

Description

PID controller implementation (templated).

Small, header-only PID controller that supports proportional, integral and derivative terms. Designed for embedded/real-time use with configurable sample time and output saturation. The template parameter T allows selection of the numeric type (e.g. float or double) used for inputs and outputs. The controller maintains internal state for the integral term and last input to compute the derivative. The compute() method calculates the control output based on the current setpoint and input, applying the PID formula and respecting the configured output limits. The controller can be switched between automatic and manual modes, and supports reversing the control direction. Parameters can be updated at runtime, with care taken to manage state consistency when changing sample time or output limits. The class is designed to be simple and efficient for use in embedded systems, with a focus on clarity and correctness.

Lib::HAL::Timer::TimInputCapture

Measures the time of input edges with Lib::HAL::Timer::TimInputCapture.

Measures the time of input edges with Lib::HAL::Timer::TimInputCapture. The capture interrupt wakes the task blocked in Lib::HAL::Timer::TimInputCapture::waitCapture(), and the task reads the captured counter value with Lib::HAL::Timer::TimInputCapture::getCapture(). Call Lib::HAL::Timer::TimInputCapture::start() from that task, because it binds the task that will wait.

The header defines the HAL callback HAL_TIM_IC_CaptureCallback() itself, so do not define it elsewhere. The ISR path only notifies the task; all reading and processing happen in the task, never in the ISR.

Hardware and CubeMX assumptions

  • Timer channel (here TIM2, TIM_CHANNEL_1) set to Input Capture direct mode, with the capture interrupt enabled in the NVIC.
  • Input filter and edge polarity are set in CubeMX. The wrapper does not change them.
  • One Lib::HAL::Timer::TimInputCapture per timer handle.

Measuring edge timing in a task

#include <Lib/HAL/TIM/TimInputCapture.hpp>
#include <RTOS.hpp>
#include <cassert>
#include <chrono>
#include <cstdint>
class EdgeMeter final {
public:
explicit EdgeMeter(TIM_HandleTypeDef * timHandle) noexcept :
capture(timHandle, TIM_CHANNEL_1),
task(RTOS::Task::Config("EdgeMeter", 512, RTOS::Task::Priority::NORMAL), [this]() { run(); }) {
}
private:
Lib::HAL::Timer::TimInputCapture capture; // Constructed before the task starts using it.
RTOS::Task task; // Must stay the last member.
void run() noexcept {
if (!capture.start()) {
assert(!"EdgeMeter: input capture failed to start");
return;
}
uint32_t previous = 0U;
while (true) {
if (!capture.waitCapture(std::chrono::milliseconds(100))) {
previous = 0U; // No edge within 100 ms; restart the interval.
continue;
}
const uint32_t current = capture.getCapture();
const uint32_t interval = current - previous; // Unsigned subtraction handles counter wrap-around.
previous = current;
// Use interval (in timer ticks).
}
}
};

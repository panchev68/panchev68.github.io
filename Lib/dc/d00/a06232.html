Lib::Helper::Convert::Ascii

Shows the character classification and hexadecimal conversion helpers of Lib::Helper::Convert::Ascii.

Shows the character classification and hexadecimal conversion helpers of Lib::Helper::Convert::Ascii.Every member is 'static constexpr' and does not touch the RTOS, so the helpers are safe from tasks and ISRs. Lib::Helper::Convert::Ascii::toHex() asserts on a non-hex character in debug builds, so check the character with Lib::Helper::Convert::Ascii::isHexDigit() first.

Usage

Character classification

Lib::Helper::Convert::Ascii::isAscii() accepts the full 7-bit range, Lib::Helper::Convert::Ascii::isPrintableAscii() accepts space (32) to tilde (126) only, and Lib::Helper::Convert::Ascii::isDigit() accepts '0' to '9'.

#include <Lib/Helper/Convert/Ascii.hpp>
void classifyCharacter() noexcept {
using Lib::Helper::Convert::Ascii;
const bool isAsciiChar = Ascii::isAscii('A'); // true
const bool isPrintable = Ascii::isPrintableAscii('A'); // true
const bool isDecimal = Ascii::isDigit('7'); // true
if (isAsciiChar && isPrintable && isDecimal) {
// Accept the character.
}
}

Hex digit conversion

Lib::Helper::Convert::Ascii::toHex() maps '0' to '9', 'A' to 'F' and 'a' to 'f' to their numeric value. Lib::Helper::Convert::Ascii::fromHex() maps a nibble back to an uppercase hex character.

  • Compose a byte from two hex characters, high nibble first.
  • Convert the byte back to two uppercase hex characters.
#include <Lib/Helper/Convert/Ascii.hpp>
#include <cstdint>
bool roundTripHexByte() noexcept {
using Lib::Helper::Convert::Ascii;
if (!Ascii::isHexDigit('F') || !Ascii::isHexDigit('a')) {
return false;
}
const uint8_t highNibble = Ascii::toHex('F'); // 15
const uint8_t lowNibble = Ascii::toHex('a'); // 10
const uint8_t byte = static_cast<uint8_t>((highNibble << 4) | lowNibble); // 0xFA
const char outHigh = Ascii::fromHex((byte >> 4) & 0x0FU); // 'F'
const char outLow = Ascii::fromHex(byte & 0x0FU); // 'A'
return (outHigh == 'F') && (outLow == 'A');
}

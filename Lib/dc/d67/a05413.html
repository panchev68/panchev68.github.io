Lib::HAL::OSPIPortAsync< T_DERIVED >

Description

template<typename T_DERIVED>
class Lib::HAL::OSPIPortAsync< T_DERIVED >

CRTP foundation for the interrupt-driven OCTOSPI modes.

Owns everything the two modes share: the RTOS event group, the command phase, the start-then-wait data phases, abort(), HAL callback registration and DeviceManager wiring. A mode specialization only supplies the two HAL calls that start a data phase ('startTransmit() / startReceive()').

A transaction is a command() followed, when the command has a data phase, by one transmit() or receive() of exactly 'cmd.NbData' bytes.

Template Parameters
T_DERIVEDMode specialization providing startTransmit(std::span<const uint8_t>) and startReceive(std::span<uint8_t>), both returning true once the HAL accepted the data phase.

inlinenodiscardnoexcept

Configures and issues a regular command.

Task context only.

A command without a data phase runs over interrupt and is waited for here. A command with a data phase is only configured synchronously, since the HAL raises no interrupt for it; the transfer starts with the following transmit() or receive().

Template Parameters

PeriodRatio type of the timeout.
Parameters

timeoutMaximum time to wait.
Returns
true on success, false on error or timeout.

Lib::Ethercat::Dev::DriverBaseabstract

Description

Abstract base class for EtherCAT hardware drivers.

This class defines the interface that all EtherCAT device drivers must implement. It provides pure virtual methods for common hardware operations including device initialization, reset control, and register access. Concrete implementations should inherit from this class and provide hardware-specific functionality.

Key responsibilities:

  • Device initialization and opening
  • Hardware reset operations
  • Register read/write operations
  • Status register access
Note
All methods are pure virtual and must be implemented by derived classes.

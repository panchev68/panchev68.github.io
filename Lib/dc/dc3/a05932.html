RTOS::Semaphorefinal

Description

Binary semaphore resource manager for task and ISR synchronization.

Created empty (taken): the first take() blocks until a 'give()'. Not a replacement for RTOS::Mutex, since a binary semaphore has no owner and no priority inheritance.

Examples
RTOS::QueueSet, and RTOS::Semaphore.

◆ getCountFromISR()

UBaseType_t RTOS::SemaphoreBase< Semaphore >::getCountFromISR ( ) const
inlinenodiscardnoexceptinherited

Gets the current count from an ISR context.

FreeRTOS V10 has no 'uxSemaphoreGetCountFromISR()', but a semaphore is a queue of zero-sized items whose count is its number of waiting items, so the ISR-safe queue query gives the same value.

Returns
Current count (0 or 1 for a binary semaphore), or 0 if not open.

Convenient when the overwrite is the last RTOS call of the ISR; batch several FromISR calls through the 'overwriteFromISR(BaseType_t &)' overload instead, so that only one context switch is requested.

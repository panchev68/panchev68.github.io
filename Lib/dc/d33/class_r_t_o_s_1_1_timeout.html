RTOS::Timeout Class Referencefinal

Description

Timeout utility for FreeRTOS tick-based timing.

Provides methods to set, check, reset, disable, and manipulate timeouts using FreeRTOS tick counters. Designed for deterministic embedded systems with type safety, clear ownership, and predictable behavior.

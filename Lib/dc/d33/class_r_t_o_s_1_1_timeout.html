Detailed Description

Timeout class for managing timeouts in RTOS.

The Timeout class encapsulates timeout management using FreeRTOS ticks. It supports setting timeouts, checking if they have expired, resetting them, and performing operations like extension or arithmetic adjustments. It uses TickCounter for tick conversions and timing checks, ensuring compatibility with FreeRTOS scheduling.

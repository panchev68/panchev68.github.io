Lib::Digi::Core::Frame::Helper::Convert

Description

Big-endian to host-byte-order conversion for unsigned integers.

Single-byte values pass through unchanged; wider values are byte-swapped via 'SwapBytes::swap()'. Overloaded to convert either an in-register value or a value read from an unaligned memory pointer.

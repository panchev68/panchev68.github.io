Lib::Digi::Core::Frame::Helper

Description

Helper class for Digi Core Frame operations.

Contains nested classes for type conversion and vector manipulation, enabling efficient and type-safe handling of Digi XBee API frame data. This class serves as a utility hub for frame processing tasks, including endianness conversion and data serialization, optimized for embedded systems and RTOS usage.

The Helper class promotes code reusability and type safety by providing templated methods for common operations, reducing the risk of errors in frame construction and parsing.

Lib::Helper::Convert::Bcd

Shows converting packed BCD values to a string, a single ASCII digit and a numeric decimal value with Lib::Helper::Convert::Bcd.

Shows converting packed BCD values to a string, a single ASCII digit and a numeric decimal value with Lib::Helper::Convert::Bcd.The helpers are 'static constexpr' and do not touch the RTOS, so they are safe from tasks and ISRs. In debug builds Lib::Helper::Convert::Bcd::toHex() and Lib::Helper::Convert::Bcd::toString() assert on a nibble outside 0 to 9. Release builds return Lib::Helper::Convert::Bcd::INVALID_VALUE from toHex(), Lib::Helper::Convert::Bcd::INVALID_CHARACTER from toAsc() and an all-NUL buffer from toString(). Check untrusted input with Lib::Helper::Convert::Bcd::isValid() first.

Digits to string

Lib::Helper::Convert::Bcd::toString() returns a fixed, NUL-terminated buffer of Lib::Helper::Convert::Bcd::Digits, so the result is printed through 'data()'.

#include <Lib/Helper/Convert/Bcd.hpp>
#include <cstdint>
#include <iostream>
void printBcdDigits() {
using Lib::Helper::Convert::Bcd;
const uint16_t bcdValue = 0x1234;
const Bcd::Digits digits = Bcd::toString(bcdValue);
std::cout << "toString(0x1234) = " << digits.data() << '\n';
}

Rejecting malformed input

The nibble 0xA is not a decimal digit, so 0x12A4 is malformed. Lib::Helper::Convert::Bcd::isValid() reports it without side effects, and Lib::Helper::Convert::Bcd::toHex() should only be called after it returns true.

#include <Lib/Helper/Convert/Bcd.hpp>
#include <cstdint>
bool acceptBcd(uint16_t raw, uint16_t & decimal) noexcept {
using Lib::Helper::Convert::Bcd;
if (!Bcd::isValid(raw)) {
return false; // Bcd::isValid(0x12A4) is false.
}
decimal = Bcd::toHex(raw);
return true;
}

Description

Lightweight wrapper for GPIO pin configuration providing typed access.

Encapsulates GPIO port and pin information in a lightweight, constexpr-compatible wrapper. Supports compile-time and runtime pin comparisons and queries. All methods are constexpr-compatible, allowing use in constant expressions.

Examples
Lib::HAL::GPIO::Output.

Lib::Helper::Convert::Percent

Shows converting between a percentage and a dBm value with Lib::Helper::Convert::Percent.

Shows converting between a percentage and a dBm value with Lib::Helper::Convert::Percent. The mapping is linear between -100 dBm (0%) and -50 dBm (100%), and both directions clamp their input to that range.

The helpers are 'static constexpr' and do not touch the RTOS, so they are safe from tasks and ISRs.

Percentage to dBm

Lib::Helper::Convert::Percent::toDBm() clamps the percentage to 100 first, so 150% yields -50 dBm.

#include <Lib/Helper/Convert/Percent.hpp>
#include <cstdint>
#include <iostream>
void printPercentAsDbm() {
using Lib::Helper::Convert::Percent;
const int8_t dbm = Percent::toDBm(80U);
std::cout << "80% -> " << static_cast<int>(dbm) << " dBm\n";
const int8_t clampedDbm = Percent::toDBm(150U);
std::cout << "150% -> " << static_cast<int>(clampedDbm) << " dBm\n";
}

dBm to percentage

Lib::Helper::Convert::Percent::fromDBm() clamps the dBm value to the -100 to -50 range, so -100 dBm yields 0%.

#include <Lib/Helper/Convert/Percent.hpp>
#include <cstdint>
#include <iostream>
void printDbmAsPercent() {
using Lib::Helper::Convert::Percent;
const uint8_t percentage = Percent::fromDBm(-100);
std::cout << "-100 dBm -> " << static_cast<int>(percentage) << "%\n";
}

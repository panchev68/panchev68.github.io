Lib::HAL::ADCPort

Reads the regular ADC group through 'Lib::HAL::ADCPort' in the three transfer modes: Lib::HAL::DriverMode::BLOCKING polls the end-of-conversion flag, Lib::HAL::DriverMode::IT waits for a HAL callback, and Lib::HAL::DriverMode::DMA scans the channels into a caller-owned buffer.

Reads the regular ADC group through 'Lib::HAL::ADCPort' in the three transfer modes: Lib::HAL::DriverMode::BLOCKING polls the end-of-conversion flag, Lib::HAL::DriverMode::IT waits for a HAL callback, and Lib::HAL::DriverMode::DMA scans the channels into a caller-owned buffer. The port wraps an ADC_HandleTypeDef created by CubeMX and does not configure the channels itself: the regular sequence (channels, ranks, sample times) must already be set on the handle, and 'open()' then runs HAL_ADC_Init() on it.

The IT and DMA modes need USE_HAL_ADC_REGISTER_CALLBACKS set to 1 in the HAL configuration header, otherwise the header stops the build with a compile-time error. Their 'waitForEvent()' and 'read()' block the calling task and must not run in an ISR. The ports are not thread-safe: use one instance from a single task.

Hardware assumptions

  • The ADC handle is generated by CubeMX (for example 'hadc1' in 'adc.c') and its IRQ handler forwards to the HAL, so the HAL callbacks registered by the port are invoked: ADC_IRQHandler() calls HAL_ADC_IRQHandler() in the CubeMX-generated code.
  • The DMA mode additionally needs the DMA stream of the ADC configured by CubeMX, with its IRQ forwarding to HAL_DMA_IRQHandler().
  • The sample time of each channel is set by CubeMX; the ports do not expose HAL_ADC_ConfigChannel().

Blocking single conversion

'Lib::HAL::ADCPort::start()' begins the regular group, 'Lib::HAL::ADCPort::poll()' spins until the conversion completes and returns the raw value, and 'Lib::HAL::ADCPort::stop()' ends the sequence. A timeout returns 0 and trips an assert in debug builds, so size the timeout for the slowest sample time with margin.

#include <Lib/HAL/ADC/ADCPort-Block.hpp>
#include <chrono>
extern ADC_HandleTypeDef hadc1;
void sampleBlocking() noexcept {
Lib::HAL::ADCPort<Lib::HAL::DriverMode::BLOCKING> adc(&hadc1);
if (!adc.open()) {
return;
}
if (adc.start()) {
const uint32_t raw = adc.poll(std::chrono::milliseconds(10));
// Use raw (0-4095 for 12-bit alignment).
static_cast<void>(raw);
static_cast<void>(adc.stop());
}
static_cast<void>(adc.close());
}

Interrupt-driven read from a task

'Lib::HAL::ADCPort::read()' starts the conversion, waits for 'Lib::HAL::ADCPort::Event::CONVERSION_COMPLETE' or 'Lib::HAL::ADCPort::Event::ERROR', and returns the value, or 0 on failure or timeout. The timeout is in milliseconds. The port registers itself with the device manager in 'open()', so the ISR path needs no extra wiring.

#include <Lib/HAL/ADC/ADCPort-IT.hpp>
#include <RTOS.hpp>
#include <chrono>
extern ADC_HandleTypeDef hadc1;
class AdcTask final {
public:
AdcTask() noexcept :
adc(&hadc1),
task(RTOS::Task::Config("Adc", 256, RTOS::Task::Priority::NORMAL), [this]() { run(); }) {
}
private:
Lib::HAL::ADCPort<Lib::HAL::DriverMode::IT> adc;
RTOS::Task task; // Must stay the last member.
void run() noexcept {
if (!adc.open()) {
assert(!"AdcTask: failed to open ADC");
return;
}
while (true) {
const uint32_t raw = adc.read(std::chrono::milliseconds(20));
if (raw != 0U) {
// Publish raw.
}
RTOS::delay(std::chrono::milliseconds(100));
}
}
};

Waiting for individual events

Use 'Lib::HAL::ADCPort::start()' and 'Lib::HAL::ADCPort::waitForEvent()' directly when the caller needs to tell a conversion-complete from an error. Note the timeout here is in RTOS ticks, not milliseconds.

if (adc.start()) {
const uint32_t events = adc.waitForEvent(Lib::HAL::ADCPort<Lib::HAL::DriverMode::IT>::Event::CONVERSION_COMPLETE |
Lib::HAL::ADCPort<Lib::HAL::DriverMode::IT>::Event::ERROR,
RTOS::TickCounter::msToTicks(20));
if ((events & Lib::HAL::ADCPort<Lib::HAL::DriverMode::IT>::Event::CONVERSION_COMPLETE) != 0U) {
const uint32_t raw = adc.getValue();
static_cast<void>(raw);
}
static_cast<void>(adc.stop());
}

Continuous scan into a buffer

'Lib::HAL::ADCPort::start(std::span<uint32_t>)' hands the buffer to DMA, which writes one sample per regular rank. The buffer must stay valid until 'Lib::HAL::ADCPort::stop()' is called. The ISR delivers 'Lib::HAL::ADCPort::Event::CONVERSION_COMPLETE' once the whole scan has been written, and an empty destination is rejected.

#include <Lib/HAL/ADC/ADCPort-DMA.hpp>
#include <RTOS.hpp>
#include <array>
#include <span>
extern ADC_HandleTypeDef hadc1;
void scanChannels() noexcept {
static std::array<uint32_t, 4> samples{};
Lib::HAL::ADCPort<Lib::HAL::DriverMode::DMA> adc(&hadc1);
if (!adc.open()) {
return;
}
if (adc.start(std::span<uint32_t>(samples))) {
const uint32_t events = adc.waitForEvent(Lib::HAL::ADCPort<Lib::HAL::DriverMode::DMA>::Event::CONVERSION_COMPLETE |
Lib::HAL::ADCPort<Lib::HAL::DriverMode::DMA>::Event::ERROR,
RTOS::TickCounter::msToTicks(50));
if ((events & Lib::HAL::ADCPort<Lib::HAL::DriverMode::DMA>::Event::CONVERSION_COMPLETE) != 0U) {
// Use samples[0] ... samples[3].
}
static_cast<void>(adc.stop());
}
static_cast<void>(adc.close());
}

Lib::Math::Filter::Median

Rejects isolated wild samples with Lib::Math::Filter::Median.

Rejects isolated wild samples with Lib::Math::Filter::Median. The filter returns the middle value of the sorted window of the last samples, so a spike from a bus error or a missed pulse never reaches the output, and a real step passes without being smeared. Each call sorts a copy of the window, which suits windows of 3 to 15 samples. It owns no heap memory and is not thread-safe, so call it from one context only.

Rejecting a spike

An odd window gives the middle sample. A spike is dropped as long as fewer samples than half the window are wrong.

#include <Lib/Math/Filter/Median.hpp>
#include <cstdint>
Lib::Math::Filter::Median<int16_t, 3U> filter;
// Called from the task that receives the readings.
int16_t onReading(int16_t reading) noexcept {
return filter(reading);
}

Window not yet full

Until the window is full, or with an even window, the result is the mean of the two middle samples, truncated towards zero for an integral type. Lib::Math::Filter::Median::isFull() tells when the window holds all its samples.

#include <Lib/Math/Filter/Median.hpp>
#include <cstdint>
Lib::Math::Filter::Median<int16_t, 5U> filter;
bool isReliable(int16_t reading, int16_t & median) noexcept {
median = filter(reading);
return filter.isFull();
}

Spikes first, then noise

The median does not smooth small random noise well. Chain it with a Lib::Math::Filter::MovingAverage: the median removes the spikes, the average removes the noise.

#include <Lib/Math/Filter/Median.hpp>
#include <Lib/Math/Filter/MovingAverage.hpp>
#include <cstdint>
Lib::Math::Filter::Median<int16_t, 5U> spikeFilter;
Lib::Math::Filter::MovingAverage<int16_t, 8U> noiseFilter;
int16_t onReading(int16_t reading) noexcept {
return noiseFilter(spikeFilter(reading));
}

Reset

Lib::Math::Filter::Median::reset() forgets all samples, for example after the sensor was switched. Lib::Math::Filter::Median::getMedian() reads the median without adding a sample.

#include <Lib/Math/Filter/Median.hpp>
#include <cstdint>
void onSensorSwitched(Lib::Math::Filter::Median<int16_t, 5U> & filter) noexcept {
filter.reset();
}

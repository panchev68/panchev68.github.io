Lib::Digi::Core::Diagnostic

Description

Diagnostic counter collection for Digi Core communication statistics.

This class maintains counters for various communication events occurring in the Digi Core module, providing insights into communication health and facilitating debugging. It provides a singleton interface for global access to diagnostic counters across the application.

Note
This class implements a singleton pattern; access the instance via instance().
Warning
Counters are not thread-safe; synchronize access if concurrent reads/writes occur.

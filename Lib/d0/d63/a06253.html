Lib::Math::CubicInterpolation

Fits a smooth curve through measured points with Lib::Math::CubicInterpolation, a cubic spline stored in fixed-size arrays without heap allocation.

Fits a smooth curve through measured points with Lib::Math::CubicInterpolation, a cubic spline stored in fixed-size arrays without heap allocation. The spline is recomputed lazily before the first query after the points or the boundary conditions change. A query updates cached data, so the object is neither const nor thread-safe: use it from one context or guard it with a mutex. At least two points are needed, and their x coordinates must be strictly increasing once sorted.

Natural spline

The default boundary condition is Lib::Math::CubicInterpolation::BoundaryType::NATURAL, which makes the second derivative zero at both ends. Build the table from a std::array of points in any order; the constructor sorts it and computes the spline.

#include <Lib/Math/Interpolation/CubicInterpolation.hpp>
#include <array>
using Spline = Lib::Math::CubicInterpolationF;
Spline flowCurve(std::array<Spline::Point, 5U>{{
{0.0F, 0.0F},
{1.0F, 2.0F},
{2.0F, 3.5F},
{3.0F, 4.0F},
{4.0F, 4.2F},
}});
float flowAt(float pressure) noexcept {
return flowCurve.interpolate(pressure);
}

Clamped spline

Lib::Math::CubicInterpolation::BoundaryType::CLAMPED fixes the slope at both ends. Pass the end slopes to the constructor or to Lib::Math::CubicInterpolation::setBoundaryConditions(); the spline is recomputed on the next query.

#include <Lib/Math/Interpolation/CubicInterpolation.hpp>
#include <array>
using Spline = Lib::Math::CubicInterpolationF;
Spline rampCurve(std::array<Spline::Point, 3U>{{
{0.0F, 0.0F},
{5.0F, 10.0F},
{10.0F, 10.0F},
}}, Spline::BoundaryType::CLAMPED, 0.0F, 0.0F);
void changeEndSlopes() noexcept {
rampCurve.setBoundaryConditions(Spline::BoundaryType::CLAMPED, 1.0F, 0.0F);
}
void useNaturalBoundary() noexcept {
rampCurve.setBoundaryConditions(Spline::BoundaryType::NATURAL);
}

Slope of the curve

Lib::Math::CubicInterpolation::getDerivative() returns the first derivative of the spline, for example the sensitivity of a sensor at the current operating point.

#include <Lib/Math/Interpolation/CubicInterpolation.hpp>
float relativeSlope(Lib::Math::CubicInterpolationF & spline, float x) noexcept {
const float value = spline.interpolate(x);
const float slope = spline.getDerivative(x);
return (value != 0.0F) ? (slope / value) : slope;
}

Point limits and run-time changes

The table holds up to Lib::Math::CubicInterpolation::MAX_POINTS points. Lib::Math::CubicInterpolation::addPoint() returns false when the table is full, so check the result. Points may be added in any order, and Lib::Math::CubicInterpolation::clear() empties the table.

#include <Lib/Math/Interpolation/CubicInterpolation.hpp>
Lib::Math::CubicInterpolationD profile;
bool record(double x, double y) noexcept {
return profile.addPoint(x, y);
}
double evaluate(double x) noexcept {
if (profile.getPointCount() < 2U) {
return 0.0;
}
return profile.interpolate(x);
}
void startNewProfile() noexcept {
profile.clear();
}

◆ writeFile()

bool Lib::GSM::A7670E::Files::writeFile ( std::string_view path,
std::span< const uint8_t > data )
inlinenodiscardnoexcept

Replaces a file without a window in which both copies are lost.

The data is first written to 'path' with '.tmp' appended, then the old file is deleted and the temporary file is renamed to 'path'. A power loss at any step leaves either the old file or the temporary file with the new data. After a power loss between the delete and the rename, read the temporary file with 'path' plus '.tmp'.

Important
Each write erases and rewrites the file, so it wears the modem flash. Write only when the content changes.
Parameters
pathFull path such as 'C:/config.bin'; at most 111 bytes and no comma.
dataBytes to store; 1 byte or more.
Returns
'true' if the new content is in place under 'path'.

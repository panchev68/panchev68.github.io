Lib::Helper

Description

Utility helpers shared by the library modules.

Contains the following helpers:

  • BitSet, a 32-bit event bitmask for FreeRTOS task notifications.
  • Lib::Helper::CityHash, a non-cryptographic 32-bit hash for small and medium buffers.
  • crc8 and crc16, CRCs over a byte sequence. The crc8 variant is the Dallas/Maxim CRC used by 1-Wire devices.
  • FindPeaks, rising and falling peak detection in a sliding window.
  • Integrator, a moving-average integrator over a fixed-size window.
  • JaggedArray, a non-owning container adapter for rows of elements.
  • Lib::Helper::StringHelper, simple string operations.
  • Lib::Helper::Delay, busy-wait delays on the Cortex-M DWT cycle counter.
  • RingBuffer, a lock-free single-producer, single-consumer ring buffer.
  • Lib::Helper::SwapBytes, constexpr byte swapping and unaligned read-and-swap.
  • Calendar helpers: Lib::Helper::Sunset (sunrise, sunset and solar position), Lib::Helper::MoonPhase, Lib::Helper::DateTime, Lib::Helper::TimePeriod (a stopwatch on the tick counter) and Lib::Helper::TimeZone (a fixed-offset time zone).
  • Lib::Helper::Exception, a freestanding exception type and terminate-handler helpers.
  • The Lib::Helper::Convert sub-namespace of conversion helpers.

RTOS::Taskfinal

Description

Encapsulates a FreeRTOS task handle and exposes a safe C++ interface for task creation, lifecycle management and querying runtime state.

Use Task::Config to configure stack size, name and priority. Tasks are started by providing a std::function callback that will be executed in the RTOS task context.

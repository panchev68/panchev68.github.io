Lib::SolarControl::MPPT::ReferenceParameters

Description

Configuration values used to initialise MPPT coefficients.

Values represent physical references such as nominal maximum power, MPP voltage/current and reference irradiance. All fields have reasonable defaults and may be overridden by the caller.

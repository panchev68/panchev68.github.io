Lib::Helper::FindPeaks

Detecting rising and falling peaks in a signal.

Detecting rising and falling peaks in a signalThis example demonstrates how to use Lib::Helper::FindPeaks to process a sequence of integer samples, detect rising and falling peaks, and retrieve their positions. The example uses a small sample buffer to illustrate the behaviour of the sliding-window algorithm implemented by FindPeaks.

#include "FindPeaks.hpp"
#include <iostream>
int main() {
Lib::Helper::FindPeaks finder;
// Example signal samples
int samples[] = {10, 20, 15, 5, 25, 30, 20};
for (int s : samples) finder.addSample(s);
size_t risingPos = finder.getRisingPeakPosition();
size_t fallingPos = finder.getFallingPeakPosition();
std::cout << "Rising peak position: " << risingPos << "\n";
std::cout << "Falling peak position: " << fallingPos << "\n";
return 0;
}

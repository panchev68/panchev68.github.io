Detailed Description

TickService for periodic tick event notification.

The TickService class manages a periodic tick event using an RTOS task and notifies registered clients by calling their handleTickEvent() method. Clients must inherit from ClientBase and are automatically registered/unregistered. The service supports configurable tick intervals, client management, and thread-safe operations.

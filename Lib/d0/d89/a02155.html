Description

ServiceBase header file for CAN bus service base class.

This file defines the ServiceBase class, which serves as a base class for CAN bus services in the Lib::Canbus namespace. It provides common functionality for initializing CAN communication, sending and receiving messages, managing diagnostics, handling errors, and running tasks in an embedded RTOS environment using FreeRTOS and IAR Embedded Workbench.

The class encapsulates HAL::CanPort for low-level CAN operations, RTOS::Task for task management, and RTOS::Queue for message queuing.

Important dependencies include HAL/CAN.hpp for CAN hardware abstraction, RTOS.hpp for RTOS primitives, and standard library headers for types and assertions.

Note
This class is designed for embedded systems and uses C++17 features.
Attention
Ensure proper CAN handle initialization before using this class.

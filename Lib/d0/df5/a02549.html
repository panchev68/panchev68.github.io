Lib::Math::HammingCode

Description

Hamming(21,16) error-correcting code implementation.

Encodes 16-bit data into a 21-bit codeword with 5 parity bits and decodes codewords back to data, correcting any single-bit error. Codeword positions are numbered from 1: the parity bits sit at the power-of-two positions 1, 2, 4, 8 and 16, the data bits fill the other positions in order, and the parity bit at position 2^k covers every position whose number has bit k set. All operations are constexpr, so they can also build lookup tables at compile time.

Checks whether a syndrome value indicates a correctable error position.

A syndrome of 0 indicates no error; a non-zero syndrome in the range [1, CODE_BITS] indicates a correctable single-bit error at that position. Syndromes outside this range are uncorrectable.

Parameters
syndromeError syndrome computed from parity checks.
Returns
true if 'syndrome' is in the correctable range [1, 21], false otherwise.

Decodes and corrects a Hamming(21,16) codeword.

Computes the syndrome from the parity checks, which is the position of a single flipped bit, corrects that bit and extracts the original 16 data bits. A codeword with two or more flipped bits is not detected and decodes to wrong data.

Parameters
value21-bit Hamming codeword, possibly with a single-bit error.

Encodes a 16-bit value into a Hamming(21,16) codeword.

Moves the 16 data bits to the non-parity positions of the codeword, then sets each of the 5 parity bits so that the positions it covers hold an even number of ones.

Parameters
value16-bit unsigned data to encode.
Returns
21-bit Hamming codeword with error correction capability.

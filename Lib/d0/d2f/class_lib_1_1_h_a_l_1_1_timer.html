Detailed Description

template<TimerMode T_MODE>
class Lib::HAL::Timer< T_MODE >

Timer class template for encapsulating timer functionality in a specific mode.

This class provides exclusive ownership of a timer handle, validity checks, and mode retrieval for a given timer mode.

Template Parameters
T_MODETimer mode defining operational characteristics.

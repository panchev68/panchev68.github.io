Description

Declaration of the ParametersBase class for managing system parameters with storage and CRC validation.

This file declares the ParametersBase class, which provides a foundation for managing system parameters stored in persistent storage. Data integrity is ensured by a CRC16 value appended to the stored blob. It includes an abstract StorageBase interface for storage backends and supports reading, writing, and validating parameter data.

Important dependencies include crc16.hpp for CRC calculations and standard libraries for memory management.

Note
This class is designed for embedded systems requiring reliable parameter persistence.

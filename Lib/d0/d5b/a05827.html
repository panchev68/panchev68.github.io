Description

template<typename T = float>
class Lib::Math::Pid< T >

Configurable Proportional-Integral-Derivative (PID) controller.

Supports configurable gains (Kp, Ki, Kd), output limits, sample time adjustment and both automatic and manual operation modes, with any user-defined numeric type (e.g. 'float', 'double', a fixed-point type). Implements anti-windup for the integral term and derivative filtering based on input measurements, to prevent derivative kick.

Template Parameters
TNumeric type used for calculations; any floating-point or fixed-point type.

inlinenodiscardnoexcept

Computes the controller output for the given setpoint and input.

Applies anti-windup to the integral accumulator, clamps the output to the configured bounds, and updates the internal state. In manual mode returns the last output without computation. The derivative term uses the change in input (backward difference), not the change in error, to avoid a derivative kick from setpoint changes.

Parameters
setpointDesired target value.
inputCurrent measured value.
Returns
Computed controller output, clamped within the configured output limits.

Switches the controller between automatic and manual operation modes.

When transitioning from manual to automatic mode, initializes the integral accumulator with the current output value and marks the first automatic cycle for proper derivative handling. When in manual mode, the controller returns the previously set output without computation.

Parameters
automatictrue to enable automatic mode, false to switch to manual mode.

Sets the output limits and applies anti-windup constraints in automatic mode.

Defines the minimum and maximum bounds for the controller output. In automatic mode the integral accumulator and the last output are clamped to the new limits immediately; the next compute() narrows the integral bounds again around the proportional term.

Parameters
minOutputNew minimum output limit; must not exceed 'maxOutput'.

Updates the sampling period and automatically adjusts the integral and derivative gains.

Modifies the sample time and recalculates Ki and Kd to maintain the same closed-loop behavior. Specifically, Ki is scaled proportionally to the time change, and Kd is scaled inversely.

Lib::HAL::BackupRamDomainfinal

Stateless facade over the backup domain write gate and the backup data registers. More...

Description

Stateless facade over the backup domain write gate and the backup data registers.

The registers are accessed directly, so neither an RTC handle nor the RTC HAL module is needed. Writes take effect only between open() and close(); reads are always allowed. The backup data registers belong to the TAMP block, or to the RTC block on families without TAMP. They keep their content across low-power modes and, with a backup supply, across a power loss.

Lib::BSP::DeviceManager::DeviceBase

Description

Base class for a device managed by the DeviceManager, dispatched through CRTP instead of virtual calls.

A derived device is added to the registry on construction and removed from it on destruction, so it never has to manage its own registration. Dispatch to the concrete device is resolved once, at construction, into two FunctionRef callbacks bound to the derived type's own setup() and handleTickEvent(); this keeps the registry's std::vector<DeviceBase *> homogeneous without a vtable. The derived type must grant DeviceBase friendship when either method is not public.

Lib::BSP::Display::Driver< Controller::ST7789 >

Description

Driver class template specialization for ST7789 display controller.

This class provides the implementation for controlling the ST7789 TFT display controller. It handles initialization, pixel data transmission, and low-level SPI communication with the display.

The driver manages hardware reset, configuration registers, and efficient block transfers using DMA-capable SPI communication for optimal performance.

◆ setup()

bool Lib::BSP::Display::Driver< Controller::ST7789 >::setup ( )
inlineoverridevirtual

Initializes the ST7789 display hardware.

Performs complete display initialization sequence including hardware reset, register configuration, and display enable. Configures memory access control, pixel format, power control, and gamma settings.

The initialization sequence includes:

  • Opening SPI communication interface
  • Hardware reset using NRST pin
  • Sending initialization command sequence
  • Enabling display output and backlight
Returns
true if initialization is successful, false otherwise.
Precondition
SPI and GPIO pins must be properly configured.
Postcondition
Display is ready for pixel data transmission.

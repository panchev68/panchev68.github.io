Description

Manager for a 31-bit configuration bitmap stored in one OTP word.

Bits 0 to 30 hold the configuration, bit 31 is the validity flag: an erased word reads as all ones, so a cleared flag marks a word that has been programmed. OTP bits can only be cleared, never set again, so a later write may only turn configuration bits off.

Lib::HAL::UARTPort< DriverMode::DMA >final

Description

DMA specialization.

The event group, start-then-wait transfers, abort(), HAL callbacks and DeviceManager wiring come from UARTPortAsync, shared with the IT mode. This class supplies only the two HAL calls that start a DMA transfer.

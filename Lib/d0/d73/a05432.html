Lib::GUI::FontData

Bitmap font data, fixed or proportional width, in any of the layouts of Lib::GUI::FontLayout. More...

Description

Bitmap font data, fixed or proportional width, in any of the layouts of Lib::GUI::FontLayout.

Every glyph has a slot of width columns in data, the slot of a character starts after the slots of the characters before it. A fixed-width font uses every column of a slot. A proportional font lists the real width of every glyph in widths: with isPacked cleared the glyph still sits in a full slot and uses only that many columns; with isPacked set the glyphs follow each other without padding, as the LCD Vision generator stores them. The pixels inside a glyph are ordered as layout says. The glyph spacing is not part of the data; the Lib::GUI::Canvas adds it. A plain aggregate that is normally a constant in flash; read it through Lib::GUI::Font. Data exported by the LCD Vision font editor is turned into one by Lib::GUI::LcdVision::parse().

Description

DTH22 driver specialization header file.

This file contains the template specialization of the Driver class for the DTH22 sensor type. It provides the implementation for reading temperature and humidity data from the DTH22 sensor, including data processing, validation, and diagnostic information.

The driver inherits from the Base class and implements the sensor-specific logic for the DTH22, which is a digital temperature and humidity sensor. It handles the timing-based communication protocol, data extraction, checksum validation, and conversion to human-readable values.

Key features include:

  • Temperature and humidity measurement
  • Raw data access for advanced users
  • Data validity checking
  • Diagnostic counters for troubleshooting
  • RTOS task-based data acquisition

Dependencies:

  • Base.hpp: Base class for DTH drivers
  • FreeRTOS: For task management and delays
  • HAL libraries: For timer and GPIO operations
Note
This specialization is specifically for Type::DTH22 and should not be used for other sensor types.
Attention
Ensure proper hardware connections and timing constraints for reliable operation.

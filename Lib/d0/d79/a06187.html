Lib::Crypto::WolfSSL

Demonstrates sealing a telemetry record with AES-GCM and an ECDHE handshake with ECDSA signing on wolfCrypt.

Demonstrates sealing a telemetry record with AES-GCM and an ECDHE handshake with ECDSA signing on wolfCrypt.Every class needs the I-CUBE-wolfSSL pack generated by CubeMX, with RNG, AES GCM and ECC Support enabled for these examples. 'sealTelemetry()' derives a 32-byte AES-256 key by hashing a passphrase, draws a fresh nonce from the random generator for every message and authenticates a clear-text header alongside the encrypted reading. 'handshake()' creates two key pairs, checks that both sides derive the same ECDHE secret, and signs and verifies its hash. A hashed passphrase is only for illustration; a real device uses a provisioned key or the ECDHE secret. The examples run in task context: the wolfCrypt calls block for a while on a Cortex-M4.

Important
The 'WolfSSLRandom' must outlive every ECC or RSA key generated from it: the keys keep a pointer to it for blinding and timing-resistant operations.
Warning
Never reuse an AES-GCM nonce with the same key: it reveals the plaintext and lets an attacker forge tags.

Usage

Sealing a telemetry record

The nonce is random for every call, and the header travels in clear but is covered by the tag.

#include <Lib/Crypto/WolfSSL.hpp>
#include <array>
#include <cstdint>
#include <span>
#include <string_view>
using namespace Lib::Crypto;
bool sealTelemetry(std::span<const uint8_t> reading, WolfSSLRandom & rng, std::span<uint8_t> sealed) {
constexpr std::string_view PASSPHRASE = "device-42";
const auto key = WolfSSLSHA256::hash({reinterpret_cast<const uint8_t *>(PASSPHRASE.data()), PASSPHRASE.size()});
if (!key) {
return false;
}
WolfSSLAesGcm aes;
if (!aes.open(*key)) { // 32 bytes: AES-256.
return false;
}
std::array<uint8_t, WolfSSLAesGcm::NONCE_SIZE> nonce{};
if (!rng.generate(nonce)) { // Fresh nonce per message.
return false;
}
constexpr std::array<uint8_t, 2> HEADER{0x01, 0x10}; // Authenticated, sent in clear.
WolfSSLAesGcm::Tag tag{};
return aes.encrypt(nonce, HEADER, reading, sealed, tag);
}
void sealOnce(WolfSSLRandom & rng) {
constexpr std::array<uint8_t, 4> READING{0x00, 0x2A, 0x01, 0xF4};
std::array<uint8_t, READING.size()> sealed{};
static_cast<void>(sealTelemetry(READING, rng, sealed));
}

ECDHE agreement and ECDSA signature

Both keys come from the same 'WolfSSLRandom', which outlives them because it is a local of the calling function.

#include <Lib/Crypto/WolfSSL.hpp>
#include <array>
#include <cstddef>
#include <cstdint>
#include <span>
using namespace Lib::Crypto;
bool handshake(WolfSSLRandom & rng) {
WolfSSLEcc device;
WolfSSLEcc server;
if (!device.generateKey(rng) || !server.generateKey(rng)) {
return false;
}
WolfSSLEcc::SharedSecret deviceSecret{};
WolfSSLEcc::SharedSecret serverSecret{};
if (!device.sharedSecret(server, deviceSecret) || !server.sharedSecret(device, serverSecret)) {
return false;
}
const auto digest = WolfSSLSHA256::hash(deviceSecret);
std::array<uint8_t, WolfSSLEcc::MAX_SIGNATURE_SIZE> signature{};
size_t signatureLength = 0;
bool isValid = false;
return digest && device.sign(*digest, rng, signature, signatureLength) &&
device.verify(std::span{signature.data(), signatureLength}, *digest, isValid) && isValid && (deviceSecret == serverSecret);
}
void cryptoTask() {
WolfSSLRandom rng; // Outlives every key generated from it.
static_cast<void>(handshake(rng));
}

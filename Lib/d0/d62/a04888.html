Lib::Crypto::WolfSSLAesGcmfinal

Description

AES-GCM authenticated encryption on wolfCrypt (CubeMX: AES GCM Support).

One instance holds one key, set with open(); encrypt() and decrypt() can then run any number of times, each with its own nonce and optional associated data.

Warning
Never reuse a nonce with the same key: it reveals the plaintext and lets an attacker forge tags.
Important
Not thread-safe: give each task its own instance, or guard a shared one with an RTOS::Mutex.
Examples
Lib::Crypto::WolfSSL.

Description

template<HttpTransport T_RAW_TRANSPORT>
class Lib::HTTP::WolfSSLTransport< T_RAW_TRANSPORT >

TLS client session on wolfSSL over any connected raw HttpTransport, itself an HttpTransport.

open() runs the handshake over the raw link and checks the server certificate against the given CA and server name; close() ends the TLS session but leaves the raw link connected, so the caller still owns connecting and disconnecting it. The class knows nothing about the link, so a new modem or socket type needs no change here.

Important
The wolfSSL configuration generated by CubeMX needs 'WOLFSSL_IAR_ARM' and 'WOLFSSL_NO_SOCK' to build on IAR without POSIX sockets, and 'HAVE_SNI' so the server can pick the right certificate by name.
The certificate validity window is checked against wolfSSL's configured time source, on STM32 usually the RTC: set the clock before open(), or the handshake fails.
Not thread-safe: one instance serves one connection from one task.

Runs the TLS handshake over an already connected raw transport.

Closes any previous session first. The server certificate must chain to 'caCertificate' and name 'serverName'; anything else fails the handshake.

Parameters
rawTransportConnected transport the session runs over; must outlive the session.
serverNameDNS name of the server, sent via SNI and checked against its certificate.
caCertificatePEM certificate(s) of the CA trusted to sign the server certificate.
Returns
true once the session is ready for send() and receive(), false on any failure or after 10 s.

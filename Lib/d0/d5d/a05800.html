Lib::Math::Filter::Kalman< T_TYPE >

Description

template<typename T_TYPE = double>
requires std::is_arithmetic_v<T_TYPE>
class Lib::Math::Filter::Kalman< T_TYPE >

Discrete 1-dimensional Kalman filter for signal filtering and state estimation.

Recursively estimates the true value of a noisy signal: configurable process noise, sensor noise and initial error terms trade off noise rejection against responsiveness to real signal changes. The estimate is kept in 'double' and converted to 'T_TYPE' on output.

Template Parameters
T_TYPEInput/output value type, integral or floating-point.

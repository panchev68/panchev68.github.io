RTOS::EventGroup

Demonstrates opening an RTOS::EventGroup, setting bits from a task and from an ISR, and waiting for both.

Demonstrates opening an RTOS::EventGroup, setting bits from a task and from an ISR, and waiting for both.One bit is set by the task itself, the other by an interrupt through 'setBitsFromISR()'. That call is deferred to the timer daemon task, so it needs 'configUSE_TIMERS' and 'INCLUDE_xTimerPendFunctionCall'. 'Bits' is a 'std::bitset' covering only the bits FreeRTOS leaves usable; its 'operator|' is not 'constexpr' here, so a combined mask is a plain 'const'. The returned bits hold the state when the wait ended, before the clear on exit.

See also
RTOS::EventGroup, RTOS::EventGroup::wait()
Example usage:
#include <Lib/RTOS/FreeRTOS/EventGroup.hpp>
#include <chrono>
using namespace std::chrono_literals;
RTOS::EventGroup events;
constexpr RTOS::EventGroup::Bits TASK_READY{1U << 0U};
constexpr RTOS::EventGroup::Bits DATA_READY{1U << 3U};
const RTOS::EventGroup::Bits ALL_READY = TASK_READY | DATA_READY;
extern "C" void EXTI0_IRQHandler() {
static_cast<void>(events.setBitsFromISR(DATA_READY)); // Deferred to the timer daemon task.
}
void exampleTask() {
if (!events.open()) {
return; // Creation failed: out of heap.
}
static_cast<void>(events.setBits(TASK_READY));
// Wait up to 1 s for both bits; they are cleared on exit only if both were set.
const RTOS::EventGroup::Bits result = events.wait(ALL_READY, true, true, 1s);
if ((result & ALL_READY) == ALL_READY) {
// Both bits set.
} else {
// Timeout: at most one of the bits was set.
}
events.close();
}

Description

USB serial port adapter that provides buffered receive and transmit tasks.

The SerialPort class wraps platform UART objects and an RTOS message buffer to implement a simple USB serial transport. Clients may override handlePostReceivedEvent and handlePostTransmitEvent to react to completed receive and transmit operations.

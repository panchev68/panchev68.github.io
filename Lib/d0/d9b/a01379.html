Lib::HAL::AdcPortBaseabstract

Description

ADC port base class.

Abstract base class for ADC port operations, providing a unified interface for configuration, control, resource management, and raw ADC value reading. Inherits from AdcHandle for handle management and AdcChannel for channel configuration.

Role of the type within the module or system: Acts as the foundation for concrete ADC port implementations, defining the common interface and delegating specific operations to derived classes.

Important design decisions: Uses multiple inheritance from AdcHandle and AdcChannel for composition, provides pure virtual methods for start/stop/release to allow different implementations, and includes default implementations for common operations.

Lib::Helper::BufferHandle

Description

Small owning wrapper around a byte sequence.

BufferHandle manages an internal vector of bytes that can be set from an external buffer. It provides accessors to the internal data and allows for implicit conversion to pointer types for ease of use. The class ensures that the provided buffer is valid and non-empty when setting or accessing data, and it supports copy construction and assignment for flexible use. This handle is useful when a stable, owned buffer representation is required, allowing for easy updates and access to the underlying byte data.

Description

template<IssuerKey T_ISSUER>
class Lib::BSP::RFID::NTAG21x::CardRecord< T_ISSUER >

Parser and verifier of the signed card record, keyed by the 'T_ISSUER' policy.

The record is 76 bytes starting at page 'FIRST_PAGE': a 3-byte magic (from 'T_ISSUER::MAGIC'), a format version byte (1), the 4-byte big-endian card number, a 1-byte issuer key id (from 'T_ISSUER::KEY_ID'), 3 reserved zero bytes, and the 64-byte ECDSA P-256 signature r || s. The signature covers SHA-256 of the first 12 header bytes followed by the card UID, so a record copied onto another card fails verification. The product holds only the issuer public key and cannot create valid records itself.

'T_ISSUER' supplies the magic, the key id and the issuer's uncompressed secp256r1 public key X || Y, big-endian (micro-ecc format). The matching private key signs records with a separate signing tool and must never reach this header or the device.

Important
micro-ecc must be configured for 'secp256r1' and included as 'ThirdParty/micro-ecc/uECC_config.h'.

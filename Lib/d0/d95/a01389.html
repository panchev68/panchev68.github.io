Lib::HAL::AdcPortBaseabstract

Description

Base class for ADC port implementations.

This class provides a standardized interface for managing ADC operations in embedded systems. It combines handle management from AdcHandle and channel configuration from AdcChannel.

The class implements the PIMPL (Pointer to Implementation) pattern through inheritance and provides a virtual interface for ADC operations. It ensures type safety and resource management for ADC peripherals.

Key features:

  • Virtual setup method for channel initialization
  • Pure virtual start/stop methods for ADC control
  • Pure virtual release method for resource cleanup
  • Read method for retrieving ADC conversion values
  • Exception-safe operations with RAII principles

Design considerations:

  • Uses protected inheritance for AdcChannel to hide implementation details
  • Public inheritance from AdcHandle for handle access
  • Virtual destructor for proper polymorphic destruction
  • Const-correctness for read operations
Note
Derived classes should implement platform-specific ADC operations.
Thread-safety depends on the underlying HAL implementation.

Reads the ADC conversion value.

Retrieves the latest ADC conversion result. This method provides a thread-safe way to access the most recent conversion value. The value represents the digital equivalent of the analog input voltage.

Returns
The 16-bit ADC conversion value (0-65535 for 16-bit resolution). Returns 0 if no valid conversion is available.
Precondition
ADC conversion should have been started and completed.
Note
This method is const and thread-safe for reading.
Value range depends on ADC resolution configuration.

virtual bool Lib::HAL::AdcPortBase::start ( )
pure virtual

Starts ADC conversion.

Initiates the ADC conversion process. The implementation depends on the specific ADC hardware and requirements (single conversion, continuous, DMA-based, etc.). This is a pure virtual method that must be implemented by derived classes.

Returns
true if the ADC conversion was started successfully, false otherwise. Failure may occur due to hardware errors, invalid configuration, or busy state.
Precondition
ADC must be properly configured via setup().
Postcondition
ADC conversion is initiated if successful.
Note
Blocking vs non-blocking behavior depends on implementation.
Thread-safety depends on the underlying HAL implementation.

◆ stop()

virtual bool Lib::HAL::AdcPortBase::stop ( )
pure virtual

Stops ADC conversion.

Stops the ongoing ADC conversion process. This method should gracefully halt any active conversions and prepare the ADC for reconfiguration or shutdown.

Returns
true if the ADC conversion was stopped successfully, false otherwise. Failure may occur if no conversion was active or due to hardware errors.
Precondition
ADC conversion should be active (started).
Postcondition
ADC conversion is stopped and ADC is in idle state.
Note

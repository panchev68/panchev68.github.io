Lib::Helper::InstanceWithArg< T, T_CONFIG >

Description

template<typename T, typename T_CONFIG>
class Lib::Helper::InstanceWithArg< T, T_CONFIG >

InstanceWithArg template class for singleton-like objects with configuration.

Manages a static instance of type T initialized with a configuration object, using placement new for manual memory management in embedded environments where heap allocation may be undesirable.

Role within the module: Configurable singleton pattern with manual construction and destruction.

Note
  • Uses aligned storage and placement new to avoid heap allocation.
  • A volatile initialization flag is used to ensure visibility across threads on platforms where that is sufficient.
Template Parameters
TThe type of the instance to manage.
T_CONFIGThe type of the configuration object.

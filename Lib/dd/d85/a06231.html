Lib::Helper::Convert::dBM

Shows converting dBm-like values and discrete indices to percentage values with Lib::Helper::Convert::dBM.

Shows converting dBm-like values and discrete indices to percentage values with Lib::Helper::Convert::dBM. Both helpers return a UI-ready percentage: Lib::Helper::Convert::dBM::toPercent() yields 0 to 100, and Lib::Helper::Convert::dBM::toDigiPercent() yields 1 to 100.

The helpers are 'static constexpr' and do not touch the RTOS, so they are safe from tasks and ISRs.

Usage

Floating dBm-like value to percentage

Lib::Helper::Convert::dBM::toPercent() maps values at or below -100 to 0, values at or above 0 to 100, and every value in between to 100 plus the value.

#include <Lib/Helper/Convert/dBM.hpp>
#include <cstdint>
#include <iostream>
void printDbmAsPercent() {
using Lib::Helper::Convert::dBM;
const double dbmValue = -45.0;
const uint8_t percent = dBM::toPercent(dbmValue);
std::cout << "dBm " << dbmValue << " -> " << static_cast<int>(percent) << "%\n"; // 55
std::cout << "dBm -120 -> " << static_cast<int>(dBM::toPercent(-120.0)) << "%\n"; // 0
std::cout << "dBm 0 -> " << static_cast<int>(dBM::toPercent(0.0)) << "%\n"; // 100
}

Discrete index to percentage

Lib::Helper::Convert::dBM::toDigiPercent() reads a lookup table of 100 entries. A negative index yields 100, and an index of 100 or more yields 1. Any integer type other than 'bool' and 'char' is accepted.

#include <Lib/Helper/Convert/dBM.hpp>
#include <cstdint>
#include <iostream>
void printIndexAsPercent() {
using Lib::Helper::Convert::dBM;
const uint8_t index = 40;
const uint8_t lookupPercent = dBM::toDigiPercent(index);
std::cout << "index " << static_cast<int>(index) << " -> " << static_cast<int>(lookupPercent) << "%\n"; // 88
std::cout << "index -1 -> " << static_cast<int>(dBM::toDigiPercent(-1)) << "%\n"; // 100
std::cout << "index 100 -> " << static_cast<int>(dBM::toDigiPercent(100)) << "%\n"; // 1
std::cout << "index 200 -> " << static_cast<int>(dBM::toDigiPercent(static_cast<uint8_t>(200))) << "%\n"; // 1
}

Lib::Helper::Exception

Description

Custom exception class for the library.

Exception class for custom error handling.

The Exception class extends std::exception to provide custom error messages and additional functionality for exception handling. It supports construction from string views, C-strings, copy and move operations, and provides methods to retrieve the error message. Additionally, it offers static methods for managing the global terminate handler.

Role of the type within the module or system: Used throughout the library for consistent error reporting and exception propagation.

Important design decisions or considerations: Supports move semantics for efficiency, provides thread-safe static methods for terminate handler management, and ensures null-safety in constructors.

Note
This class is not intended for use in real-time critical sections due to exception overhead.
See also
std::exception

Extends std::exception to provide custom error messages and utilities for terminate handlers and exception rethrowing.

Role within the module: Base class for custom exceptions in embedded systems.

Note
  • Uses std::string_view for the caption to avoid unnecessary copies.
  • Exposes static helpers to manage the process terminate handler.
  • Uses conditional compilation to expose additional helpers only when the C++ library supports them.

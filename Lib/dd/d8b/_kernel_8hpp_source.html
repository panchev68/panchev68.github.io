46 /** Kernel abstraction for FreeRTOS management.

48 * This class provides a comprehensive set of static methods for managing FreeRTOS kernel operations,
49 * including task scheduling, timing, critical sections, memory diagnostics, and system state queries.

97 /** RAII wrapper for critical sections.
98 *
99 * This class provides automatic management of FreeRTOS critical sections using the RAII (Resource Acquisition Is Initialization) idiom.
100 * Upon construction, it enters a critical section, disabling task switching and interrupts to ensure atomic operations.
101 * Upon destruction, it automatically exits the critical section, restoring normal operation.
102 * This prevents common errors like forgetting to exit critical sections and ensures exception safety.
103 *
104 * @note Critical sections should be kept as short as possible to minimize system latency.
105 * @attention Do not use in interrupt service routines; use CriticalSectionISR instead.
106 */
107 class CriticalSection {
108 public:
109 /** Construct and enter critical section.
110 *
111 * Disables interrupts and task switching to create a critical section.
112 * This ensures that the following code block executes atomically.
113 */
114 CriticalSection() { Kernel::enterCritical(); }
115
116 /** Destructor that exits the critical section.
117 *
118 * Automatically restores interrupts and task switching when the object goes out of scope.
119 * Ensures that critical sections are always properly exited, even in case of exceptions.
120 */
121 ~CriticalSection() { Kernel::exitCritical(); }
122
123 private:
124 CriticalSection(const CriticalSection &) = delete;
125 CriticalSection & operator=(const CriticalSection &) = delete;
126 CriticalSection(CriticalSection &&) = delete;
127 CriticalSection & operator=(CriticalSection &&) = delete;
128 };

134 * This allows safe manipulation of shared resources from ISRs while preserving the interrupt state.

166 * Upon construction, it suspends the scheduler, preventing task switching.

589 /** Calculate percentage safely.

592 * Uses 64-bit arithmetic to prevent overflow when calculating percentages.
593 * Caps the result at 100% to handle edge cases.
594 *
595 * @param used The amount used (numerator).
596 * @param total The total amount (denominator).
597 * @return The calculated percentage as a value from 0 to 100.

601 const uint64_t percent = (used * 100ULL) / total;
602 return static_cast<uint8_t>(percent > 100ULL ? 100ULL : percent);

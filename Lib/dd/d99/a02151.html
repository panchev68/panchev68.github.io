Description

DTH thermometer base component header.

This file defines the base class for DTH (Digital Temperature and Humidity) thermometer components. It provides the fundamental infrastructure for communicating with DTH sensors, including timer-based data reception, GPIO pin control, and RTOS task management. The base class handles low-level protocol details and provides virtual methods for sensor-specific implementations.

The Base class manages the complete data acquisition cycle: initialization, startup impulse generation, DMA-based data reception, and signal processing. It uses RTOS semaphores for synchronization and timer interrupts for precise timing control.

Dependencies: Requires HAL GPIO, TIM, RTOS libraries, and Parm.hpp for parameters.

Note
This is an abstract base class; derived classes must implement taskEntry().
Attention
Ensure HAL_TIM_REGISTER_CALLBACKS is enabled in HAL configuration.

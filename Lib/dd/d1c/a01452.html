Lib::HAL::Timer< T_MODE >

Description

template<TimerMode T_MODE>
class Lib::HAL::Timer< T_MODE >

A thin wrapper that associates a TimerHandle with a compile-time TimerMode.

The class stores a single TimerHandle instance and exposes simple operations to set and retrieve the handle, check validity and obtain the compile-time configured timer mode.

Template Parameters
T_MODECompile-time timer mode that configures behaviour or interpretation of the stored handle.

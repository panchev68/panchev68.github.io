Lib::GUI::Display

Draws text, shapes and widgets on a 128 x 64 SSD1306 OLED with the Lib::GUI layer.

Draws text, shapes and widgets on a 128 x 64 SSD1306 OLED with the Lib::GUI layer.The GUI classes know no driver. The application creates the driver, then a Lib::GUI::Display with the size and binds the driver's pixel, clear and flush functions to it with Lib::GUI::Display::bind(). A Lib::GUI::Primitives takes the display once, and everything above it, the Lib::GUI::Canvas for text and the widgets, draws through that one instance. Nothing is shown before Lib::GUI::Canvas::flush(), which sends the whole frame buffer over I2C and blocks, so call it from a task, never from an ISR. One display is drawn from one task; the classes are not thread-safe.

Important
The font has to be an export of the LCD Vision font editor kept as a constant array. Change the generated flash unsigned char to const uint8_t and keep one of the two data blocks: the one before else for Lib::GUI::FontLayout::HORIZONTAL_ROWS, the one after it for Lib::GUI::FontLayout::VERTICAL_ROWS.

Setting up the display

The order is fixed: driver, display with its functions, primitives, canvas. Lib::GUI::LcdVision::parse() reads the font array without copying it, so the array has to outlive the font data. A glyph of an LCD Vision font already contains the space to the next one, so the canvas adds none; use Lib::GUI::Canvas::setGlyphSpacing() to add some.

#include <Lib/BSP/Display/SSD1306.hpp>
#include <Lib/GUI/Canvas.hpp>
#include <Lib/GUI/Display.hpp>
#include <Lib/GUI/LcdVision.hpp>
#include <Lib/GUI/Primitives.hpp>
#include <Lib/HAL/I2C.hpp>
#include "ContinuumMediumBold.hpp" // LCD Vision export of the font 'continuum_medium_bold'.
extern "C" I2C_HandleTypeDef hi2c1; // Generated by CubeMX in main.c.
Lib::HAL::I2CPort<Lib::HAL::DriverMode::IT> i2cPort{&hi2c1};
Lib::BSP::Display::SSD1306<128, 64> oled{{.i2cPort = i2cPort}}; // 1. The driver; SA0 pin low.
Lib::GUI::Display display{{.width = 128, .height = 64}}; // 2. The size; functions are bound in open().
Lib::GUI::Primitives primitives{{.display = display}}; // 3. One instance for all the layers above.
const Lib::GUI::FontData font = Lib::GUI::LcdVision::parse(continuum_medium_bold, Lib::GUI::FontLayout::HORIZONTAL_ROWS);
Lib::GUI::Canvas canvas{primitives, font}; // 4. Text and widgets draw on the canvas.
[[nodiscard]] bool openDisplay() noexcept {
if (!oled.open()) {
return false; // Port failed to open or the display did not acknowledge.
}
display.bind(oled); // Binds setPixel(), clear() and flush() of the driver.
return true;
}

Text and shapes

Text and shapes take a Lib::GUI::Position, the top-left corner counted in pixels, and anything outside the display is clipped. Lib::GUI::Primitives::lineByAngle() counts the angle counter-clockwise from the right, as on a drawing.

void drawSplash() noexcept {
canvas.clear();
primitives.roundRect({0, 0}, 128, 64, 8);
primitives.line({8, 34}, {119, 34}, true, 2, Lib::GUI::LineStyle::DASHED);
primitives.fillRoundRect({90, 40}, 30, 18, 4);
static_cast<void>(primitives.lineByAngle({20, 56}, 20, 45.0F));
canvas.drawTextAligned(0, 4, 128, "Hello", Lib::GUI::Alignment::CENTER);
static_cast<void>(canvas.drawText({8, 40}, "OLED"));
static_cast<void>(canvas.flush());
}

Widgets in a periodic task

A Lib::GUI::String keeps its own copy of the text and clears its width before drawing, so a shorter number leaves nothing of a longer one. A Lib::GUI::ProgressBar draws through the Lib::GUI::Primitives alone. A widget can have a font of its own, here the one that was parsed above; the others use the font of the canvas. A Lib::GUI::ListMenu is used the same way with Lib::GUI::ListMenu::selectNext() and Lib::GUI::ListMenu::draw(); give it a font that is small enough for several rows.

#include <Lib/GUI/ProgressBar.hpp>
#include <Lib/GUI/String.hpp>
#include <RTOS.hpp>
#include <chrono>
void displayTask() noexcept {
if (!openDisplay()) {
return;
}
Lib::GUI::String<8> value({.position = {4, 6}, .width = 120, .alignment = Lib::GUI::Alignment::CENTER, .font = &font});
Lib::GUI::ProgressBar bar({.x = 8, .y = 44, .width = 112, .height = 10, .maxValue = 100});
for (int32_t level = 0;; level = (level + 5) % 105) {
canvas.clear();
primitives.roundRect({0, 0}, 128, 64, 6);
value.setNumber(level);
value.draw(canvas);
bar.setValue(static_cast<uint32_t>(level));
bar.draw(primitives);
if (!canvas.flush()) {
break; // The bus failed; report it and stop drawing.
}
RTOS::delay(std::chrono::milliseconds(100));
}
}

Lib::HAL::AdcPortBaseabstract

Description

Abstract base type for ADC port implementations.

Provides a common interface and shared functionality for concrete ADC ports. Implementations must provide start/stop/release semantics while benefiting from the protected AdcChannel helper and the AdcHandle ownership.

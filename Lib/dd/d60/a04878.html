Lib::Crypto::SHA256< SHA256Engine::HARDWARE >final

Description

Streaming SHA-256 hasher driving the STM32 HASH peripheral in SHA-256 mode.

Every call is a blocking HAL transaction (HAL_HASHEx_SHA256_Accmlt() and HAL_HASHEx_SHA256_Accmlt_End()), so call only from a task, never from an ISR. Not thread-safe and not reentrant with any other user of the same HASH_HandleTypeDef: use one instance, from one task, for the lifetime of a digest. The peripheral only accepts whole 32-bit words mid-stream, so up to 3 trailing bytes of each update() are buffered internally and prepended to the next call, or to finish(), which accepts any remainder length.

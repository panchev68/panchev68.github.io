Description

template<typename T_DERIVED, typename T_HANDLE, typename T_BASE, typename T_PORT>
class Lib::HAL::AsyncPortCore< T_DERIVED, T_HANDLE, T_BASE, T_PORT >

CRTP foundation of the interrupt-driven ports (UART, SPI, I2C, OCTOSPI, USB device and host).

Lifecycle: the RTOS event group, the peripheral, the DeviceManager slot and the HAL callbacks are opened in that order and undone in reverse when a step fails. A port supplies only what is specific to its peripheral: the callbacks it wires ('registerCallbacks()' / 'unregisterCallbacks()') and its transfers. Holds no HAL type of its own and needs no 'main.h': the handle type and the peripheral base class are parameters.

Template Parameters
T_DERIVEDConcrete mode specialization; it owns the native handle through Device and is the type the DeviceManager registers.
T_HANDLENative HAL handle type.
T_BASEPeripheral base class (for example UARTPortBase), providing open() and close() for the peripheral itself.
T_PORTThe port class deriving from this one. It must declare this class a friend and provide the static functions 'registerCallbacks(T_HANDLE *)' and 'unregisterCallbacks(T_HANDLE *)'; the first returns true if the HAL accepted every callback.

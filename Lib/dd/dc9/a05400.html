Description

The one GUI of the program: the size of the display, its driver functions, the shape drawing, the text, the default font and the current drawing area, kept in one singleton that every other GUI class reads from.

Reached through Lib::GUI::Context::instance(), created on first use. The application describes the display once with Lib::GUI::Context::setup() and binds the driver with Lib::GUI::Context::bind(). The widgets take no GUI argument: their draw() uses the display, the primitives, the canvas and the font of this instance. It owns the Lib::GUI::Display, the Lib::GUI::Primitives built on it and the Lib::GUI::Canvas built on those. Lib::GUI::Context::ViewportScope limits drawing to a part of the display for a block. One display is drawn from one task; the classes below are not thread-safe.

Warning
There is one display. A program with a second screen needs its own Lib::GUI::Display and Lib::GUI::Primitives, which the widgets of this singleton do not use.

Lib::Digi::API::Service::PairServicefinal

Description

Holds the local and remote AT command channels for the pairing procedure described in PairService.md.

Only the lifecycle exists: "initialize()" opens both channels and "tearDown()" closes them. The service is not owned or driven by the application base, so an owner must call "update()" itself. The local channel is shared with the other services, so none of them may run at the same time.

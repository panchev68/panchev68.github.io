Description

Error class definition and implementation.

This file defines the Error class, which represents error states in the system. The Error class provides methods to manage error states, associate errors with groups, and handle error lifecycle including setting, clearing, resetting, enabling, and disabling. It supports virtual operators for boolean conversion and assignment, allowing flexible error handling. The class uses a static common ID counter for unique error identification and maintains state transitions.

Important dependencies include standard libraries for integers, strings, and string views, as well as the Group class for error categorization.

Note
This class is designed for embedded systems and follows MISRA C++ guidelines.
Attention
Ensure proper initialization and state management to avoid undefined behavior.

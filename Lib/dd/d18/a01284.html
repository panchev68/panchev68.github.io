Lib::Digi::API::ServerBase< Derived >

Description

template<typename Derived>
class Lib::Digi::API::ServerBase< Derived >

Transaction state machine and connection supervision of an XBee server.

"Derived" must provide "handleIncomingMessage(const std::vector<uint8_t> &)" returning "bool", "handleOutgoingMessage(std::vector<uint8_t> &)", "outputsUpdatedSuccessfulCallback()" and "handleTaskTickEvent()"; if they are private it must befriend "ApplicationBase<Derived>" and "ServerBase<Derived>". The outgoing buffer keeps its previous content when handed to "handleOutgoingMessage()".

using Lib::BSP::Thermometer::DTH::DTH22 = Driver<Type::DTH22>

Type alias for DTH22 digital temperature and humidity sensor driver.

This alias simplifies the usage of the DTH22 sensor by providing a direct type reference to the specialized driver. The DTH22 is a low-cost digital sensor that provides calibrated digital output for temperature and humidity measurements.

Key features:

  • Temperature measurement range: -40°C to 80°C with ±0.5°C accuracy
  • Humidity measurement range: 0% to 100% RH with ±2% accuracy
  • Single-wire communication protocol
  • Low power consumption suitable for battery-operated devices

Usage example:

DTH22 sensor(config);
float temperature, humidity;
if (sensor.read(temperature, humidity)) {
// Process temperature and humidity data
}

Supported DTH sensor types enumeration.

This enumeration defines the available sensor types within the DTHxx family that are supported by the driver framework. Each type corresponds to a specific sensor model with its own communication protocol and data format characteristics.

The enumeration enables template specialization and compile-time type checking to ensure correct sensor handling and prevent runtime errors.

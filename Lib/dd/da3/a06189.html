Lib::HAL::LPTimer

Arms a low-power timeout with Lib::HAL::LPTimer and waits for it from a task.

Arms a low-power timeout with Lib::HAL::LPTimer and waits for it from a task. Lib::HAL::LPTimer::startTimeoutInterrupt() converts a millisecond timeout into a prescaled LPTIM period, and the autoreload match callback sets an event bit that Lib::HAL::LPTimer::waitForEvent() waits on. Lib::HAL::LPTimer::getElapsedRtosTicks() reports how much of the timeout has passed, in RTOS ticks.

The LPTIM interrupt path is handled by the class: its callback is registered with the HAL in Lib::HAL::LPTimer::open(). The CubeMX-generated LPTIM1_IRQHandler() must still call HAL_LPTIM_IRQHandler() for that callback to run.

Important
The class is written for the STM32U5 LPTIM: its instance limit and clock-source table follow that series. It requires the LPTIM peripheral and USE_HAL_LPTIM_REGISTER_CALLBACKS set to 1. The header is guarded by HAL_LPTIM_MODULE_ENABLED and LPTIM1; on the STM32F407 target, LPTIM1 does not exist, so the header compiles to nothing. RTOS::PowerManager uses this class for tickless sleep under the same guard.

Hardware and CubeMX assumptions

  • LPTIM1 enabled in CubeMX with its clock source (LSE, LSI or MSIK) set; the frequency table inside the class must match the CubeMX clock tree.
  • USE_HAL_LPTIM_REGISTER_CALLBACKS set to 1 in the HAL configuration header.
  • Up to two instances (one per LPTIM handle). A third one asserts.

Waiting for a timeout in a task

#include <Lib/HAL/TIM/LPTimer.hpp>
#include <RTOS.hpp>
#include <cstdint>
bool waitForTimeout(Lib::HAL::LPTimer & timer, uint32_t timeoutMs) noexcept {
if (!timer.startTimeoutInterrupt(timeoutMs)) {
return false;
}
const uint32_t bits = timer.waitForEvent(HAL_LPTIM_AUTORELOAD_MATCH_CB_ID, portMAX_DELAY);
timer.stopInterrupt();
return bits != 0U;
}
void setup(LPTIM_HandleTypeDef * lptimHandle) noexcept {
Lib::HAL::LPTimer timer(lptimHandle, LPTIM_CHANNEL_1);
if (!timer.open()) {
return;
}
static_cast<void>(waitForTimeout(timer, 500U));
}

Converting elapsed time to RTOS ticks

Lib::HAL::LPTimer::getElapsedRtosTicks() returns the full armed timeout once the match fired, and the current counter scaled to RTOS ticks otherwise. Pass the same timeout (in milliseconds) that was armed.

#include <Lib/HAL/TIM/LPTimer.hpp>
#include <cstdint>
uint32_t elapsedTicks(const Lib::HAL::LPTimer & timer, uint32_t armedTimeoutMs) noexcept {
return timer.getElapsedRtosTicks(armedTimeoutMs);
}

Closing

Lib::HAL::LPTimer::close() de-initializes the LPTIM; the destructor calls it as well.

#include <Lib/HAL/TIM/LPTimer.hpp>
void shutdown(Lib::HAL::LPTimer & timer) noexcept {
static_cast<void>(timer.close());
}

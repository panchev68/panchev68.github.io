Lib::HAL::Timer::TimOutputComparefinal

Controls one hardware timer channel configured under an active Output Compare profile. More...

Description

Controls one hardware timer channel configured under an active Output Compare profile.

Compare-match interrupts are mapped through the DeviceManager to a task notification, so a task blocked in waitCompare() wakes on each match, enabling hardware-timed pin switching.

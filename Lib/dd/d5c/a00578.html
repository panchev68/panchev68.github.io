Description

Proportional-Integral-Derivative (PID) controller implementation.

This file provides a generic, template-based PID controller class for various control applications. The controller supports configurable gains (Kp, Ki, Kd), output limits, sample time adjustment, and both automatic and manual operation modes. It implements anti-windup for the integral term and derivative filtering based on input measurements to prevent derivative kick.

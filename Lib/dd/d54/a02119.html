Description

Timer template class for HAL operations.

This file defines a template class for managing timers in the HAL layer, providing a type-safe interface for different timer modes. It encapsulates timer handles and modes, ensuring safe and efficient timer operations within the embedded system.

Important dependencies include TimerHandle and TimerMode classes for handle management and mode specification.

Note
This template is designed for compile-time mode selection to optimize performance in real-time systems.
Attention
Ensure TimerMode is correctly defined and compatible with the underlying hardware.

Lib::HAL::IndependentWatchdogfinal

Description

Controls the hardware Independent Watchdog; once started it cannot be stopped until the next reset.

Wraps the HAL watchdog start and counter reload to protect the firmware against lockups and unhandled faults. Keeps no state of its own beyond a reference to the native handle.

◆ refresh()

void Lib::HAL::IndependentWatchdog::refresh ( )
inlinenoexcept

Reloads the independent hardware counter to prevent a system reset.

A single key-register write, so it is safe to call from task and ISR context alike. Returns no status: HAL_IWDG_Refresh() always reports 'HAL_OK', so a status flag would carry no information.

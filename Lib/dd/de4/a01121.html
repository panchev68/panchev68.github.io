Lib::Digi::API::UserProtocol

Description

Abstract base class for handling user-defined communication protocols.

This class provides a framework for parsing and building protocol messages, including command handling for inputs, outputs, and parameters. Derived classes must implement the virtual methods to define specific protocol behaviors.

The class supports thread-safe operations if implemented in derived classes, and includes assertions for debugging invalid states.

inlineprotectedvirtual

Parses incoming protocol buffer and dispatches to appropriate handler.

This method extracts the command from the buffer and calls the corresponding virtual handler method based on the command type. It performs basic validation on the buffer length and command validity.

Parameters
bufferThe incoming data buffer containing the protocol message.
Returns
true if the message was successfully parsed and handled, false otherwise.
Precondition
buffer must not be empty.
Postcondition
Appropriate handler method is called if command is valid.

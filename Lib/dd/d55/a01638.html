template<typename T_VALUE, typename T_INPUT = T_VALUE>
class Lib::Math::CubicInterpolation< T_VALUE, T_INPUT >

Cubic spline interpolation class for embedded applications.

The CubicInterpolation class template provides smooth cubic interpolation between data points using natural or clamped boundary conditions. It uses a tridiagonal matrix solution for efficient spline coefficient calculation and supports up to MAX_POINTS data points. All internal state variables are initialized and updated according to standard cubic spline equations.

Constructor of CubicInterpolation class.

Initializes a new instance of the CubicInterpolation class with a provided array of points and boundary conditions. The points are copied into the internal storage, sorted if necessary, and spline coefficients are computed immediately. This constructor is useful for static initialization with known data points.

Add a data point to the interpolation table.

Adds a single data point to the interpolation table. If the maximum number of points is reached, the operation fails. Adding a point invalidates the sorted state and computed coefficients, requiring re-sorting and re-computation on next interpolation.

Parameters
pointThe data point to add, containing x and y values.
Returns
Status::OK if the point was added successfully, Status::ERROR if the table is full.
Precondition
The interpolation table must not be full (pointCount < MAX_POINTS).
Postcondition
The point is added, sorted state is false, computed state is false.

Set boundary conditions for spline interpolation.

Configures the boundary conditions for the cubic spline. For natural boundaries, second derivatives at endpoints are zero. For clamped boundaries, first derivatives at endpoints are specified. Changing boundary conditions invalidates computed coefficients, requiring re-computation.

Parameters
boundaryThe type of boundary condition (natural or clamped).
leftDerivThe first derivative at the left endpoint, used for clamped boundaries.
rightDerivThe first derivative at the right endpoint, used for clamped boundaries.
Postcondition
Boundary conditions are updated, computed state is false.

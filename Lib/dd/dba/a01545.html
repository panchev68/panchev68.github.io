Lib::Helper::FindPeaks

Description

FindPeaks class for detecting peaks in signal data.

Implements a sliding window algorithm to detect rising and falling peaks in a sequence of integer samples, with smoothing for noise reduction.

Role within the module: Signal processing utility for peak detection.

Important design decisions: Uses fixed window size; maintains peak info for rising and falling peaks; applies smoothing to reduce false positives.

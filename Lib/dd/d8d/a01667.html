RTOS::Task::Notifyfinal

Description

Encapsulates FreeRTOS task notification mechanics.

Sending methods target the owning task. Receiving methods (wait(), waitForBits(), take()) always act on the calling task, as FreeRTOS does, so they must be called from the owning task itself.

◆ waitForBits() [2/2]

bool RTOS::Task::Notify::waitForBits ( Bits bitsToWaitFor,
TickType timeout = portMAX_DELAY ) const
inlinenodiscardnoexcept

Blocks the calling task until any of the given bits is set or the timeout expires.

Notifications carrying only unrelated bits do not end the wait early; those bits are left set in the notification value, and only the awaited bits are cleared on a match.

Parameters
bitsToWaitForBits to wait for; any one of them ends the wait.
timeoutMaximum total wait in ticks; portMAX_DELAY waits forever.
Returns
true if one of the bits was received, false on timeout.

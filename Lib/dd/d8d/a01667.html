RTOS::MessageBuffer Class Reference

Description

MessageBuffer class for FreeRTOS message buffer management.

This class provides a complete C++ abstraction for FreeRTOS message buffers, enabling safe and efficient inter-task communication with variable-length messages. It uses RAII principles for automatic resource management and provides separate methods for task and ISR contexts to ensure proper operation in all scenarios.

The class supports:

  • Creation and destruction of message buffers with specified sizes
  • Blocking and non-blocking message transmission
  • Message reception with timeout capabilities
  • Buffer state inspection (empty, full, available space)
  • Reset functionality for clearing buffer contents
  • Move semantics for efficient resource transfer
Note
Message buffers allow variable-length messages unlike fixed-size queues.
Attention
Buffer size should be chosen carefully to balance memory usage and performance.

Receives a message from the buffer in task context.

Copies data from the message buffer into the destination buffer. If the buffer is empty, the operation will block until data is available or timeout occurs. This method is safe to call from task context but not from ISRs.

Parameters

Returns

Note

Resets the message buffer.

Clears all data from the message buffer, resetting it to an empty state. Any unread messages are discarded. The buffer remains open and can continue to be used. This operation is atomic and thread-safe.

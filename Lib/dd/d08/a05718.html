Lib::Helper::Exception

Lightweight exception that stores a C-string message without allocating. More...

Description

Lightweight exception that stores a C-string message without allocating.

The message pointer is stored as is, so it must reference storage that outlives the exception, typically a string literal. Copying is cheap and always succeeds, as required for an object that is thrown. The project builds with '–no_exceptions', so in practice only the terminate-handler helpers are exercised; the exception-pointer helpers are compiled only when exceptions are enabled.

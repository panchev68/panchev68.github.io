RAII-based wrapper for FreeRTOS kernel control primitives.

Also owns the duration-to-tick conversion shared by every wrapper, so this header depends on nothing else in the wrapper layer.

◆ RTOS_HEAP_HAS_STATS

#define RTOS_HEAP_HAS_STATS   0

Opt-in switch telling RTOS::Kernel::getMemoryInfo() that the linked heap scheme provides 'vPortGetHeapStats()'.

Only heap_4 and heap_5 implement that function, and FreeRTOS exposes no macro naming the linked heap file. The default therefore follows the 'USE_FreeRTOS_HEAP_n' macro that STM32CubeMX writes into 'FreeRTOSConfig.h'; define it to 1 or 0 before including this header (or on the command line) when the heap is selected another way.

Description

Frame type constants for XBee protocol communication.

Defines enumerated constants for all frame types used in XBee protocol communication. Includes request frame types (transmission, AT commands, data relay) and response frame types (receive packets, status indicators, command responses). Each constant represents a specific API frame identifier used in the XBee communication protocol.

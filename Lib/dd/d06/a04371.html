Description

template<typename T_DERIVED>
class Lib::BSP::DigitalPeripheralBase::PortBase< T_DERIVED >

Common interface of the input and the output port, dispatched through CRTP instead of virtual calls.

serve() takes this type so it can drive either port without runtime polymorphism; every method just forwards to the same-named method of 'T_DERIVED', which hides it in the derived class's own scope.

Template Parameters
T_DERIVEDConcrete port providing setup(), preUpdateCallback(), update(), postUpdateCallback() and getSpiHandle().

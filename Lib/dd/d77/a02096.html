Lib::Digi::Core::Frame0x17

Description

Frame representing a remote AT command request (0x17).

Contains destination addressing, command identifier, options and optional parameters required to execute an AT command on a remote node.

Lib::Digi::Core::Frame0x17::operator Frame::Data ( )
inlineoverridevirtual

Serialize this query into a Frame::Data payload.

The returned Frame::Data will contain, in order: frameId, destination address (64-bit), a reserved 16-bit address placeholder, remote command option, AT command identifier and any parameters.

Returns
A populated Frame::Data ready for transmission.
Postcondition
The returned Frame::Data::type is set to Frame::Type::REMOTE_AT_COMMAND_REQUEST.

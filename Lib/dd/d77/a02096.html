Description

Abstract base class for display drivers.

This header declares the DriverBase class which provides the interface and common functionality for all display driver implementations. The class supports driver initialization, pixel-block transmission, and transfer state management used by BSP display drivers.

Important dependencies or interactions with other modules. Used by specific display driver implementations (e.g., ILI9341) for common interface.

Any special instructions or notes for users of the file. Subclasses must implement pure virtual methods setup() and transmitBlock().

Note
Provides singleton-like access via global instance pointer for C callbacks.

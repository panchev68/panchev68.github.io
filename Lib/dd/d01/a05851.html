Lib::Pneumatics::Cylinder

Drives a pneumatic cylinder output from off/on position sensor feedback. More...

Description

Drives a pneumatic cylinder output from off/on position sensor feedback.

Either or both sensors may be physically absent, configured via Config::offSensor / Config::onSensor; an absent sensor's transitions are then confirmed by timeout instead, and its uncommanded-move detection is disabled. With both sensors absent, the cylinder behaves as a purely time-based actuator: Status::UNKNOWN only clears once command() is called, and Status::IS_ERROR can never be raised.

◆ update()

Status Lib::Pneumatics::Cylinder::update ( )
inlinenoexcept

Advances the internal state machine from the current sensor readings and applies the resulting output level.

Must be polled periodically. Raises Status::IS_ERROR on an uncommanded position loss or a switch-timeout; the output then holds its last level until command() or clearError() leaves the error state.

Returns
Current cylinder status.

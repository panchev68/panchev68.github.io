Lib::Helper::JaggedArrayBase

Managing a Collection of Integer Pointers

This example demonstrates how to use JaggedArrayBase to manage a dynamic collection of integer pointers. It shows adding items, accessing elements by index, and removing specific items, with bounds checking and duplicate prevention.

Example usage:
#include "JaggedArray.hpp"
#include <iostream>
int main() {
Lib::Helper::JaggedArrayBase<int> jaggedArray;
int value1 = 10;
int value2 = 20;
int value3 = 30;
// Add items to the jagged array
jaggedArray.addItem(&value1);
jaggedArray.addItem(&value2);
jaggedArray.addItem(&value3);
// Access and print elements
std::cout << "Elements: ";
for (size_t i = 0; i < jaggedArray.getSize(); ++i) {
std::cout << *jaggedArray[i] << " ";
}
std::cout << std::endl;
// Remove an item
jaggedArray.removeItem(&value2);
// Print after removal
std::cout << "After removal: ";
for (size_t i = 0; i < jaggedArray.getSize(); ++i) {
std::cout << *jaggedArray[i] << " ";
}
std::cout << std::endl;
return 0;
}

Lib::Helper::swapBytes

Byte-Order Swapping Example

This example demonstrates the usage of the swapBytes utilities for converting byte order of integral values and raw memory buffers in the context of embedded and networking code. It showcases template-based value swapping for different integer types and the buffer overload for reversing byte arrays, which is useful for endianness conversion in data serialization and communication protocols.

Example usage:
#include <iostream>
#include <iomanip>
#include "Lib/Helper/SwapBytes.hpp"
int main() {
using Lib::Helper::swapBytes;
std::cout << std::hex << std::showbase;
uint16_t u16 = 0x1234U;
uint32_t u32 = 0x12345678U;
uint64_t u64 = 0x0123456789ABCDEFULL;
std::cout << "u16: " << u16 << " -> " << swapBytes(u16) << "\n";
std::cout << "u32: " << u32 << " -> " << swapBytes(u32) << "\n";
std::cout << "u64: " << u64 << " -> " << swapBytes(u64) << "\n";
uint8_t src[4] = {0x11, 0x22, 0x33, 0x44};
uint8_t dst[4] = {};
swapBytes(src, dst, 4);
std::cout << "buffer src: ";
for (auto b : src) std::cout << "0x" << static_cast<int>(b) << " ";
std::cout << "\nbuffer dst: ";
for (auto b : dst) std::cout << "0x" << static_cast<int>(b) << " ";
std::cout << std::endl;
return 0;
}

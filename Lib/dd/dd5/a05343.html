Lib::HAL::ADCPortBase< Derived >

Description

template<typename Derived>
class Lib::HAL::ADCPortBase< Derived >

CRTP foundation for the lifecycle and single-conversion read policy shared by every ADC transfer mode.

Owns no state of its own, not even the native handle: it reaches the handle through 'derived()->getHandle()'. Each mode owns its handle storage. Device adds an intrusive DeviceManager list link that only the interrupt-driven and DMA modes use, so the blocking specialization stores the handle directly.

Template Parameters
DerivedHigh-level concrete driver class owning the native handle.

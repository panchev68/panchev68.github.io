Lib::Helper::TimeZone

Constructs a Lib::Helper::TimeZone and converts local calendar time to UTC minutes since the epoch.

Constructs a Lib::Helper::TimeZone and converts local calendar time to UTC minutes since the epoch.The conversion shifts the local time by the zone offset and does not use the C runtime time zone, so it runs in task or main context and is also usable at compile time. Lib::Helper::TimeZone::convertLocalToUtcMinutes() returns std::nullopt for invalid input, such as a bad date or time of day. Daylight saving time is resolved separately through Lib::Helper::TimeZone::TimeChangeRule.

Usage

Local time to UTC minutes

'offsetSeconds' is the number of seconds that the caller's epoch lies after 1970-01-01 00:00 UTC; 0 counts from the Unix epoch itself.

#include <Lib/Helper/TimeZone.hpp>
#include <cstdint>
#include <ctime>
#include <optional>
void convertCetToUtc() {
// Central European Time, UTC+60 minutes.
constexpr Lib::Helper::TimeZone tz("CET", 60);
// Local 2026-05-11 12:00 CET is 11:00 UTC.
constexpr std::time_t epochOffsetSeconds = 0;
const std::optional<int32_t> utcMinutes = tz.convertLocalToUtcMinutes(2026, 5, 11, 12, 0, epochOffsetSeconds);
if (!utcMinutes.has_value()) {
return; // Invalid date or time of day.
}
// *utcMinutes holds the UTC minutes since the epoch.
}

Switching to summer time

Summer time begins on the last Sunday of March at 02:00 local time and adds 120 minutes to UTC from then on. The Lib::Helper::TimeZone::TimeChangeRule resolves the local transition instant for a year, and Lib::Helper::TimeZone::setName() and Lib::Helper::TimeZone::setOffset() switch a copy of the zone to that offset.

#include <Lib/Helper/TimeZone.hpp>
#include <chrono>
#include <cstdint>
#include <ctime>
#include <optional>
void convertCestToUtc() {
using Rule = Lib::Helper::TimeZone::TimeChangeRule;
constexpr Lib::Helper::TimeZone tz("CET", 60);
constexpr Rule summerTime{"CEST", Rule::LAST_WEEK, 0, 3, 2, 120};
// 2026-03-29 02:00 local time, the last Sunday of March.
[[maybe_unused]] const std::chrono::local_seconds summerStart = summerTime.getLocalTransition(std::chrono::year{2026});
Lib::Helper::TimeZone summerZone = tz;
summerZone.setName(summerTime.ruleName);
summerZone.setOffset(summerTime.getOffset());
constexpr std::time_t epochOffsetSeconds = 0;
const std::optional<int32_t> summerUtcMinutes = summerZone.convertLocalToUtcMinutes(2026, 5, 11, 12, 0, epochOffsetSeconds);
if (summerUtcMinutes.has_value()) {
// *summerUtcMinutes is 10:00 UTC, expressed in minutes since the epoch.
}
}

Description

MessageBuffer class for FreeRTOS message buffer management.

This file provides a comprehensive C++17 wrapper for FreeRTOS message buffer operations. The MessageBuffer class offers type-safe, RAII-compliant management of message buffers, supporting both task and ISR contexts for sending and receiving variable-length messages. It includes status tracking, timeout handling, and buffer state queries for robust inter-task communication in embedded systems.

Key features:

  • RAII-based buffer lifecycle management
  • Type-safe message sending and receiving
  • ISR-compatible operations with proper context switching
  • Buffer state monitoring (empty/full/space available)
  • Timeout support for blocking operations
  • Comprehensive error handling and status reporting
Note
Requires FreeRTOS message buffer functionality to be enabled.
Attention
Message buffers are more flexible than queues but have higher overhead.

Description

ADC handle type alias header.

This header file defines the AdcHandle type alias for managing ADC peripheral handles in the HAL layer. It provides a type-safe wrapper around the STM32 HAL ADC handle structure, ensuring proper resource management and type safety for ADC operations.

Important dependencies include the Handle template for resource management.

Note
This file is part of the HAL core ADC module.

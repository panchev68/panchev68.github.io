Lib::Digi::API::Pauseabstract

Description

Interface for pausing and resuming dynamic operations in services.

Services that support pausing (e.g., to temporarily halt periodic reads or writes) can implement this interface. The ApplicationBase class uses this interface to control service behavior during certain operations.

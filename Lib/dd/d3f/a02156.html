Lib::Errors::Dispatcherfinal

Description

Dispatcher monitors Error objects and raises high-level status events.

The dispatcher is a singleton that subscribes to the RTOS tick service and inspects the global error vector on a periodic basis. Applications may register a handler to be notified when the status changes.

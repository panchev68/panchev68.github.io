RTOS::EventGroupfinal

Owning wrapper of a FreeRTOS event group, letting tasks wait on several flags at once. More...

Description

Owning wrapper of a FreeRTOS event group, letting tasks wait on several flags at once.

FreeRTOS keeps the top 8 bits of EventBits_t for itself, so Bits holds only the usable width and a reserved bit can never be passed in. The ISR set and clear calls are deferred to the timer daemon task: they exist only with configUSE_TIMERS and INCLUDE_xTimerPendFunctionCall, and fail when its command queue is full.

Bits RTOS::EventGroup::sync ( Bits bitsToSet,
Bits bitsToWaitFor,
TickType timeout )
inlinenodiscardnoexcept

Synchronizes several tasks at a common rendezvous point.

Task context only. Each participant sets its own bit and waits for the bits of all participants as one atomic step; the last one to arrive releases every waiter, and the awaited bits are cleared once the condition is met.

Parameters
bitsToSetBits the calling task sets on arrival, usually its own bit.
bitsToWaitForBits that must all be set to pass; must not be empty.
timeoutMaximum wait time, in ticks.
Returns
Bits when the wait ended, before the automatic clear; the rendezvous succeeded if every bit of bitsToWaitFor is set in it.

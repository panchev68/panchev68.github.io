Little-endian conversion helpers for LAN9252 register payloads. More...

Description

Little-endian conversion helpers for LAN9252 register payloads.

The shifts are explicit instead of a union or std::bit_cast, so the wire format does not depend on the host byte order and the helpers work in constant expressions. Reading a union member other than the last one written is undefined behaviour in C++, which is why the driver never relies on it.

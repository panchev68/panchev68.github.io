Description

Byte-swapping utilities for integral types and raw memory.

Provides constexpr functions to reverse byte order for signed and unsigned integral types and a runtime helper to reverse arbitrary byte buffers. These utilities are useful when converting between endianness representations. The implementation uses an internal helper for unsigned types and explicit specializations for common widths. The byte buffer reversal function can operate in-place or copy from source to destination.

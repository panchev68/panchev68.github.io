Description

template<typename T_DERIVED>
class Lib::HAL::UARTPortBase< T_DERIVED >

Compile-time polymorphic foundation implementing the handle-lifecycle policy shared by every transfer mode.

Owns no state of its own, not even the native handle: it reaches the handle through 'derived()->getHandle()' instead of inheriting Device. Device brings an intrusive DeviceManager list link ('nextDevice') that only an interrupt-driven mode uses, so the blocking specialization stores its handle directly. 'IT' and 'DMA' get their handle storage from Device through UARTPortAsync.

template<typename T_DERIVED>
bool Lib::HAL::UARTPortBase< T_DERIVED >::setBaudRate ( uint32_t baudRate)
inlinenodiscardnoexcept

Reconfigures the baud rate at runtime.

The HAL exposes no dedicated runtime setter, so the handle's init structure is updated and re-applied through HAL_UART_Init(). Registered HAL callbacks survive the re-initialization. Available in every transfer mode.

Parameters
baudRateNew baud rate to apply, in bits per second.
Returns
true if the reconfiguration succeeded; false while a transfer is in flight.

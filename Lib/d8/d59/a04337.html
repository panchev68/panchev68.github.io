Lib::BSP::EEPROM::I2C::Driver< T_Device >

Description

template<typename T_Device>
class Lib::BSP::EEPROM::I2C::Driver< T_Device >

CRTP base driver class for I2C EEPROM devices.

Provides transfer validation, page-aligned write handling with timing delays, and the 8-bit and 16-bit addressed transfer primitives. Concrete drivers derive from 'Driver<T_Device>' and implement readImpl() and writeImpl() to select the addressing width for their chip, without virtual dispatch overhead.

Chips with an 8-bit word address and more than 256 bytes (M24C04 ... M24C16) carry the upper address bits in the slave address, which the 8-bit primitives handle.

Reads data from EEPROM with 8-bit addressing.

For chips with a single-byte word address. Address bits 8..10 of larger chips (M24C04 ... M24C16) are sent in the slave address, where they replace the E2/E1/E0 strap bits, so the configured strap address must be 0 for those chips.

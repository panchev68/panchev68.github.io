Lib::BSP::Backlight

Description

Backlight control class.

Provides comprehensive backlight control with PWM-based brightness adjustment, smooth fading effects, and automatic dimming features for embedded display systems. This class integrates with RTOS tick services for precise timing of fade transitions and sleep management, and utilizes STM32 HAL for PWM output generation on specified timer channels. It supports configurable brightness ranges, fade step durations, and sleep timeouts to optimize power consumption and user experience in battery-powered or energy-conscious applications.

Key features include:

  • PWM-driven brightness control for smooth dimming.
  • Fade-in/out effects with configurable step timing.
  • Automatic sleep mode after inactivity timeout.
  • Integration with RTOS for event-driven operation.
  • Type-safe configuration and runtime assertions for reliability.
Note
This class inherits from RTOS::TickService::ClientBase to receive periodic tick events for fading logic.
Attention
Ensure the STM32 timer is properly configured and not shared with other peripherals.

Lib::BSP::Backlight::Backlight ( const Config & config)
inlineexplicit

Constructor for Backlight.

Initializes the backlight instance with the provided configuration, resolves the timer CCR register for PWM control, and starts PWM output on the specified timer channel. Validates all configuration parameters to ensure safe operation. The dimmer is initialized and ready for operation.

Parameters
configConfiguration structure containing timer settings, fade parameters, and brightness limits.
Precondition
config must contain valid timer handle, positive fade step, and valid min/max brightness range.
Postcondition
PWM is started, CCR register resolved, dimmer initialized, target brightness set to 0.

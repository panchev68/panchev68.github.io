Lib::BSP::RFID::MFRC522Config

Description

Hardware configuration parameters used to initialize the MFRC522 driver.

Kept standalone so the transport and helper layers (Interface, Chipset, Card, Mifare) can depend on it directly instead of on the enclosing MFRC522 class, which lets MFRC522 hold them as plain value members.

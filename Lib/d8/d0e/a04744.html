Lib::Crypto::WolfSSLRandomfinal

Description

Cryptographically secure random generator on wolfCrypt's configured entropy source (CubeMX: RNG Support).

Besides producing random bytes, it seeds the key generation, signing and key exchange of the other 'WolfSSL*' classes through native().

Important
Not thread-safe: give each task its own instance, or guard a shared one with an 'RTOS::Mutex'.
Examples
Lib::Crypto::WolfSSL.

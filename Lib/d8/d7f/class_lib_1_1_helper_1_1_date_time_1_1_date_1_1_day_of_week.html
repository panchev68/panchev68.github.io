Detailed Description

Day of week calculation and string representation utilities.

Provides Zeller's congruence algorithm for day of week calculation, along with helper functions for short and long day name lookups. All operations are constexpr for compile-time evaluation.

Note
Uses ISO week convention (Monday=0, Sunday=6).

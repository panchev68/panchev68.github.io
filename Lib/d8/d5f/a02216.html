Lib::Ethernet::MacAddress

Description

Represents a 6-byte MAC address.

The class stores the address in a fixed-size array and provides helpers to convert to/from the human-readable colon-separated hex form ("AA:BB:CC:DD:EE:FF"), as well as validation and deterministic generation using the system serial.

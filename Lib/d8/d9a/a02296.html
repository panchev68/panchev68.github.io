Lib::HAL::Handle< T_HANDLE >

Description

template<typename T_HANDLE>
class Lib::HAL::Handle< T_HANDLE >

Handle template for HAL handle management.

Wraps a pointer to a HAL handle type and offers safe access, comparison operators and implicit conversion to the raw pointer. The template asserts the provided pointer is valid on construction.

Template Parameters
T_HANDLEThe type of the HAL handle being wrapped.

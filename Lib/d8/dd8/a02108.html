Description

ILI9341 display controller driver implementation.

This header provides a specialized driver for the ILI9341 TFT LCD display controller, enabling communication and control via SPI interface with DMA support for efficient pixel data transmission. Supports initialization, pixel block transfers, rotation control, and backlight management in embedded systems.

Important dependencies or interactions with other modules. Depends on HAL SPI and GPIO modules, RTOS for timing, and Backlight module for brightness control.

Any special instructions or notes for users of the file. Ensure SPI and GPIO peripherals are properly configured before driver initialization.

Note
Optimized for STM32 HAL and FreeRTOS environments with DMA-based pixel transfers.

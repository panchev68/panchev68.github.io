Lib::Digi::Core::QueueMessage

Description

A small fixed-capacity message container used when enqueuing/dequeuing messages between components.

The class exposes a fixed-size storage buffer and an explicit size field indicating how many bytes of the buffer are valid. It intentionally provides a conversion operator to std::vector<uint8_t> for convenience when exporting the payload.

Lib::HAL::USBHostPortAsync< T_DERIVED >

Description

template<typename T_DERIVED>
class Lib::HAL::USBHostPortAsync< T_DERIVED >

CRTP foundation for the interrupt-driven USB host modes.

Owns the RTOS event group, the start-then-wait channel transfers, HAL callback registration, DeviceManager wiring and the event handler hook. A mode specialization only supplies the HAL call that starts a transfer ("startTransfer()"), as in "UARTPortAsync". The last URB state of every channel is kept, so "transfer()" can tell a completed transfer from NAK, STALL and an error. Every HAL callback, and therefore the event handler, runs in interrupt context.

Template Parameters
T_DERIVEDMode specialization providing "startTransfer(uint8_t, USBDirection, USBEndpointType, bool, std::span<uint8_t>)", returning "true" once the HAL accepted the transfer.

inlinenodiscardnoexcept

Runs one transfer on a channel and waits for its end.

Task context only.

For an OUT transfer the buffer is only read. A transfer that ends with NAK is reported as "NOT_READY" and is not repeated here, so the caller chooses its own retry policy. On timeout the channel is halted, so the HAL never uses "data" after this returns.

Template Parameters
RepArithmetic representation type of the timeout.
PeriodRatio type of the timeout.
Parameters
channelChannel number, opened with "openChannel()".
directionData direction of the transfer.
typeTransfer type of the endpoint.
isSetup"true" for the setup stage of a control transfer, "false" for data and status stages.
dataSource (OUT) or destination (IN) buffer, up to 65535 bytes; empty for a zero-length packet.
timeoutMaximum time to wait, rounded up to whole ticks.
Returns
How the transfer ended; "getTransferCount()" tells how many bytes moved.

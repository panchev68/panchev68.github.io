Lib::BSP::I2CPortabstract

Description

Minimal I2C transport interface used by board support drivers.

Implementations must provide open/close semantics and basic send/receive operations. Methods return 'true' on success and 'false' on failure.

This helper provides a default no-op implementation; platform-specific drivers may override to support devices that require an internal memory/register address prior to reading.

Lib::Digi::Core::Frame0x17

Description

Remote AT command request query (XBee frame type 0x17).

Represents an XBee API frame type 0x17 for querying or setting AT command parameters on a remote device identified by its 64-bit IEEE address. The conversion operator builds the serialized Frame::Data for transmission. Query results are received in response frame type 0x97 (Remote AT Command Response).

Lib::Digi::Core::Frame0x17::operator Frame::Data ( ) const
inlinenodiscard

Conversion operator to build serialized frame data for transmission.

Constructs a Frame::Data object containing the serialized remote AT command request in XBee API frame format. Sets the frame type to REMOTE_AT_COMMAND_REQUEST and appends frame ID, destination address, reserved address, remote command option, AT command, and parameter data in proper byte order.

Returns
Frame::Data object ready for transmission.

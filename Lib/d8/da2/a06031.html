Description

template<typename T_TYPE, size_t T_SIZE>
requires (std::is_arithmetic_v<T_TYPE> && (T_SIZE > 0U))
class Lib::Math::Filter::MovingAverage< T_TYPE, T_SIZE >

Average of the last T_SIZE samples, kept in a ring buffer.

Every sample has the same weight and a sample leaves the window after exactly T_SIZE newer ones, so noise is reduced by about the square root of T_SIZE, and a real step reaches the output completely after T_SIZE samples. Use it for noise that is random from sample to sample, such as the jitter of a digital thermometer or an ADC reading; it does not reject a single wild sample, which Lib::Math::Filter::Median does. Until the window is full the average covers only the samples received so far, and Lib::Math::Filter::MovingAverage::isFull() tells when the output has the full smoothing. An integral type is averaged exactly and the result is truncated towards zero. The filter owns no heap memory and is not thread-safe: call it from one context only.

Template Parameters
T_TYPESample and result type, integral or floating-point.
T_SIZEWindow length in samples, at least 1.

Lib::Helper::Convert::Bcd

Converting BCD values using the Bcd class.

This example demonstrates how to use the Bcd class to convert Binary Coded Decimal (BCD) values to strings, ASCII characters, and decimal numbers. BCD represents each decimal digit with four bits, allowing easy conversion between binary and decimal representations.

Example usage:
#include "Lib/Helper/Convert/Bcd.hpp"
#include <iostream>
int main() {
// BCD value for 1234 (0x1234 in hex)
uint16_t bcdValue = 0x1234;
// Convert BCD to string
std::string str = Lib::Helper::Convert::Bcd::toString(bcdValue);
std::cout << "BCD to string: " << str << std::endl; // Output: 1234
// Convert BCD to decimal number
uint16_t decimal = Lib::Helper::Convert::Bcd::toHex(bcdValue);
std::cout << "BCD to decimal: " << decimal << std::endl; // Output: 1234
// Convert single BCD digit to ASCII
char asc = Lib::Helper::Convert::Bcd::toAsc(0x05);
std::cout << "BCD digit to ASCII: " << asc << std::endl; // Output: 5
return 0;
}

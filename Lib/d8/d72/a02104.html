Lib::HAL::USBHostPort< DriverMode::DMA >final

Description

Explicit specialized variant driving DMA transfers.

Only controllers with an internal DMA engine (OTG_HS) can use it; the specialization is compiled only when the device header defines "USB_OTG_HS". The transfers start through the same HAL call as in the IT mode, but the handle must have "Init.dma_enable" set and every buffer must be aligned to 4 bytes, because the controller reads and writes the memory itself.

Runs one transfer on a channel and waits for its end.

Task context only.

For an OUT transfer the buffer is only read. A transfer that ends with NAK is reported as "NOT_READY" and is not repeated here, so the caller chooses its own retry policy. On timeout the channel is halted, so the HAL never uses "data" after this returns.

PeriodRatio type of the timeout.

Lib::BSP::Display::TouchGFX_BW< T_DISPLAY >final

Description

template<PagedDisplay T_DISPLAY>
class Lib::BSP::Display::TouchGFX_BW< T_DISPLAY >

Shows the black and white frame buffer of TouchGFX on a display that keeps its pixels in pages, such as Lib::BSP::Display::SSD1306.

TouchGFX renders a 1-bit-per-pixel frame buffer row by row, eight pixels per byte with the leftmost pixel in the most significant bit. The display wants pages: a byte is a column of eight pixels with the top one in bit 0. Every 8 x 8 block of pixels is therefore turned by 90 degrees; the class does it with three masked shifts on one 64-bit word instead of moving single bits. Lib::GUI is not involved, the two are alternatives. The class holds no TouchGFX type and needs no TouchGFX header, so its three connections to the framework are plain arguments:

  • the frame buffer and the changed rectangle are passed to Lib::BSP::Display::TouchGFX_BW::update(), called from TouchGFXHAL::flushFrameBuffer(); - the vertical-sync tick is the onVSync callback, normally touchgfx::OSWrappers::signalVSync, run by a software timer started with Lib::BSP::Display::TouchGFX_BW::start(); - the display driver is a Lib::BSP::Display::PagedDisplay.

Only the 8 x 8 blocks that touch the changed rectangle are converted, then the whole panel is flushed. The sync period should not be shorter than one panel transfer (about 25 ms on I2C at 400 kHz), otherwise TouchGFX renders frames that are never shown.

Important
Lib::BSP::Display::TouchGFX_BW::update() blocks on the panel transfer, so it runs in the TouchGFX task, never in an interrupt. The frame buffer has to be the 1-bit one that the generated HAL owns, WIDTH / 8 bytes per row.

Converts a rectangle of a TouchGFX frame buffer into the pages of a display frame buffer.

Works on whole 8 x 8 blocks: every block that contains a pixel of the rectangle is converted, so a few more pixels than asked may be refreshed, always with their current content. Pure function, it touches no display.

Parameters
frameBufferThe 1-bit TouchGFX frame buffer, Lib::BSP::Display::TouchGFX_BW::FRAME_SIZE bytes.
pagesThe page-organized frame buffer to write into, WIDTH * HEIGHT / 8 bytes.
leftColumn of the first changed pixel, inside the display.
topRow of the first changed pixel, inside the display.
rightColumn of the last changed pixel, inside the display.
bottomRow of the last changed pixel, inside the display.

Converts the 8 x 8 blocks that touch a changed rectangle and shows the frame on the panel.

The rectangle is cut to the display. An empty rectangle changes nothing and sends nothing, which saves the panel transfer when TouchGFX reports a frame without changes.

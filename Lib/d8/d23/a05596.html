Lib::HAL::UARTPortAsync< T_DERIVED >

Description

template<typename T_DERIVED>
class Lib::HAL::UARTPortAsync< T_DERIVED >

CRTP foundation for the interrupt-driven UART modes.

Owns the logic both modes would otherwise duplicate: the start-then-wait transfer sequence, abort() and the HAL callbacks. The open/close sequence comes from AsyncPortCore. A mode specialization only supplies the two HAL calls that start a transfer ('startTransmit()' / 'startReceive()'). Transmit and receive use separate event bits, so one task may send while another receives on the same port.

Template Parameters
T_DERIVEDMode specialization providing 'startTransmit(std::span<const uint8_t>)' and 'startReceive(std::span<uint8_t>)', both returning true once the HAL accepted the transfer.

Reconfigures the baud rate at runtime.

The HAL exposes no dedicated runtime setter, so the handle's init structure is updated and re-applied through HAL_UART_Init(). Registered HAL callbacks survive the re-initialization. Available in every transfer mode.

Description

UART port template for HAL UART management.

Provides a template base class for UART port implementations with mode-specific operations. Encapsulates UART handle management, validity checks, and ensures exclusive ownership through deleted copy and move operations. Supports different driver modes via template specialization for flexible UART communication patterns.

The template provides core functionality for UART port management including handle storage, validation, and mode-specific behavior. Designed for embedded systems requiring reliable UART communication with type-safe mode handling.

Important dependencies include DriverMode enumeration and standard library headers for assertions and integer types. Interacts with HAL UART drivers and communication protocols.

Note
Template parameter T_MODE defines the operational characteristics of the UART port.
Exclusive ownership prevents accidental handle sharing between instances.

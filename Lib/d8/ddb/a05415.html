Description

Discrete hardware port controller wrapping peripheral register blocks.

Encapsulates direct memory-mapped register access and native STM32 HAL initialization sequences to manipulate entire register blocks at once.

Examples
Lib::HAL::GPIO::Output.

void Lib::HAL::GPIO::Port::write ( uint32_t value)
inlinenoexcept

Writes a bitmask to all output lines of the port in a single store.

The store is not read-modify-write, but it overwrites every pin of the port; use Output to change one pin.

Parameters

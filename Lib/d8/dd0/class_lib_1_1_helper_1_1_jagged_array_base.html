Lib::Helper::JaggedArrayBase< T > Class Template Reference

Description

template<class T>
class Lib::Helper::JaggedArrayBase< T >

Jagged array base template class.

Manages a collection of pointers to elements of type T. Provides array-like access with dynamic addition and removal of elements. Ensures no duplicates and null pointers.

Template Parameters
TThe type of elements stored in the array.

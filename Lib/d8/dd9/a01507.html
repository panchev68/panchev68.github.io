Lib::Helper::Crc16

Description

Class for computing CRC16 checksums.

This class calculates CRC16 checksums using the CCITT polynomial (0x1021). It can be initialized with raw data buffers or std::vector<uint8_t> and provides implicit conversion to uint16_t for the computed checksum.

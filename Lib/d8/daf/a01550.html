Lib::Helper::DateTime

Description

DateTime class for combined date and time representation.

Combines Date and Time classes to represent a full timestamp. Provides string conversion, validation, and packing/unpacking for storage.

Role within the module: Core utility for timestamp handling in embedded systems.

Important design decisions: Uses nested classes for Date and Time; supports packing into 32-bit integer for efficient storage.

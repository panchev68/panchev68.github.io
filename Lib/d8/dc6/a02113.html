Lib::HAL::SPIPortBase< T_DERIVED >

Description

template<typename T_DERIVED>
class Lib::HAL::SPIPortBase< T_DERIVED >

CRTP foundation implementing the handle-lifecycle and transfer-dispatch policy shared by every SPI transfer mode.

Owns no state beyond the begin/end-transaction hooks, not even the native handle: it reaches the handle through "derived()->getHandle()" instead of inheriting "Device<>". "Device<>" brings an intrusive DeviceManager list link ("nextDevice") that only an interrupt-driven mode uses, and a blocking specialization never registers with the DeviceManager. Each mode therefore owns its own handle storage: "IT" and "DMA" get it from "Device<>" through "SPIPortAsync", while the blocking specialization stores it directly. The begin/end-transaction hooks live here rather than per mode, since every mode's send, receive and sendReceive bracket the transfer the same way.

A mode specialization provides "sendHandler()", "receiveHandler()" and "sendReceiveHandler()", each taking the validated buffer(s) and a "Timeout", and returning only once the hardware no longer touches the buffers.

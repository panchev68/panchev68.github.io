Description

DriverDataDirection enumeration for specifying data direction in HAL driver interfaces.

Defines an enumeration for specifying data direction in HAL driver interfaces. Supports receive (RX), transmit (TX), and bidirectional (RX_TX) data flow modes. Used in driver interfaces to specify communication direction.

Note
Values are bit-flags for flexible combination.

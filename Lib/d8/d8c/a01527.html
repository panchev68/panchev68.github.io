Lib::Helper::StringHelperfinal

Description

Collection of lightweight string utility helpers.

All APIs are static, non-allocating and non-throwing, and operate on std::string_view and std::span so they bind to literals, arrays and strings alike.

Split input by delimiter and invoke callback once for each token.

Every token, including empty ones between adjacent delimiters and the one after the last delimiter, is passed as a std::string_view referencing the original input.

Lib::BSP::RFID::Mifare

Helper for Mifare Classic card operations on the MFRC522 chipset. More...

Description

Helper for Mifare Classic card operations on the MFRC522 chipset.

Implements block read/write, authentication handling, and value manipulation helpers. Talks to the card over RF through Chipset::transceive(), which drives the MFRC522's FIFO/COMMAND-register sequence.

Authenticate a specific sector block using Key A or Key B.

Authentication must be performed before any read or write on the target block. The key and UID are taken as fixed-extent spans, so a caller cannot pass a buffer of the wrong length.

inline

Format a 16-byte buffer as a Mifare Value Block.

Layout: the value (4 bytes, little-endian), its bitwise inverse, the value again, then the block address, its inverse, the address again and its inverse.

Parameters
bufferOutput buffer that will receive 16 bytes; must be non-null and at least 16 bytes.
valueInitial integer value to store in the value block.
blockAddrAddress of the block where this value block will be stored.

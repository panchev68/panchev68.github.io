crc16.hpp

Description

Calculate a 16-bit CRC over a sequence of bytes.

The helper provides a lightweight view-based interface that computes the CRC on demand when the instance is converted to 'uint16_t'. The algorithm divides the message by polynomial 0x1021 MSB-first, with a zero initial value and no final XOR, matching CRC-16/XMODEM (CRC-16/CCITT, zero init): the check value over the ASCII string '123456789' is '0x31C3'. The CRC is computed byte-wise from a 256-entry table generated at compile time and placed in flash.

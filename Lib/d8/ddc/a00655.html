enum class Lib::Digi::Core::ApiMode
strong

ApiMode enum class for Digi XBee API operating modes.

This enumeration defines the available operating modes for Digi XBee modules, providing options for transparent communication or API-based operations. It ensures type safety and prevents invalid mode selections.

Role within the module: Provides a standardized way to specify API modes in the Digi Core library.

Important design decisions: Uses enum class for scoping and type safety, with clear member names and descriptions.

Enumerator
TRANSPARENT 

API modes are disabled; the module operates in transparent mode.

API1 

API mode without escaped characters.

API2 

API escaped operating mode (API 2).

Lib::GUI::Displayfinal

Description

One-bit display as the GUI layer sees it: a size, a drawing area and the functions that reach the real driver.

The class is not a template and knows no driver type. It stores the width and height and three optional functions that the application binds once: one that sets a single pixel, one that clears the frame buffer and one that sends it to the panel. The shape drawing in Lib::GUI::Primitives and everything above it works only through Lib::GUI::Display::setPixel(), so any driver that can set a pixel can be used, such as Lib::BSP::Display::SSD1306. A pixel outside the drawing area is dropped before the function is called. Without a clear function the display is cleared pixel by pixel; without a flush function Lib::GUI::Display::flush() does nothing.

The drawing area is the whole display until Lib::GUI::Display::setViewport() narrows it to a rectangle. Inside the area the coordinates start at its top-left corner, Lib::GUI::Display::getWidth() and Lib::GUI::Display::getHeight() give its size, and Lib::GUI::Display::clear() clears only the area, so one part of the screen can be drawn and redrawn without touching the rest. The frame buffer is still sent whole by Lib::GUI::Display::flush().

Viewport Lib::GUI::Display::setViewport ( const int32_t x,
const int32_t y,
const int32_t newWidth,
const int32_t newHeight )
inlinenoexcept

Limits drawing to a rectangle inside the current drawing area.

The rectangle is given in the coordinates of the current area and is cut to it, so an area can only shrink. Later drawing uses coordinates from the top-left corner of the new area.

Parameters
xColumn of the left edge, counted in the current area.
yRow of the top edge, counted in the current area.
newWidthWidth in pixels; at least 1 after the cut, otherwise nothing can be drawn.
newHeightHeight in pixels; at least 1 after the cut, otherwise nothing can be drawn.
Returns
The previous area, to give back to Lib::GUI::Display::restoreViewport().

template<typename T_ELEMENT_TYPE, size_t N_QUEUE_LENGTH = 1U>

class RTOS::Queue< T_ELEMENT_TYPE, N_QUEUE_LENGTH >

Fixed-capacity FreeRTOS queue carrying items of one trivially copyable type.

The kernel copies every item with 'memcpy()' on send and receive, which is why the element type must be trivially copyable: anything owning a resource (a std::vector, a std::string, a smart pointer) would be shallow-copied and double-released. Task-context methods may block; the 'FromISR' variants never block and report through 'higherPriorityTaskWoken' whether the caller must request a context switch with 'portYIELD_FROM_ISR()' before leaving the interrupt. A queue that has been added to a 'RTOS::QueueSet' must only be read after the set selected it, and then with a zero timeout.

Template Parameters
T_ELEMENT_TYPEData type held by the queue; must be trivially copyable and default-initializable.
N_QUEUE_LENGTHMaximum number of items the queue can hold; must be greater than zero.
Examples
RTOS::Queue, and RTOS::QueueSet.

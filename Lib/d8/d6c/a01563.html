Lib::Helper::RingBuffer< T, T_SIZE > Class Template Reference

Description

template<typename T, size_t T_SIZE>
class Lib::Helper::RingBuffer< T, T_SIZE >

Ring buffer template class.

Implements a fixed-size circular buffer for FIFO operations. Elements are stored in a contiguous array, and indices wrap around when reaching the end. Push operations fail if the buffer is full, and pop operations fail if empty.

Template Parameters
TThe type of elements stored in the buffer.
T_SIZEThe fixed capacity of the buffer (must be greater than 0).

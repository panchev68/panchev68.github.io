RTOS::Queue

Shows passing typed messages between a producer task and a consumer with an RTOS::Queue.

Shows passing typed messages between a producer task and a consumer with an RTOS::Queue.Covers a queue of eight 32-bit samples with a blocking send and receive that take a timeout, and a latest-value queue of length one that uses RTOS::Queue::overwrite(). Each element is copied into the queue, so the sender may reuse its variable immediately. Use the FromISR variants for sends and receives inside an interrupt handler.

Important
Open the queues from task context before any ISR uses them.

Usage

Declaring the queues

The second template argument is the length; it defaults to 1.

#include <Lib/RTOS/FreeRTOS/Queue.hpp>
#include <cstdint>
namespace {
RTOS::Queue<uint32_t, 8U> samples;
RTOS::Queue<uint32_t> latestSetpoint; // Length 1 by default.
}

Producer task

RTOS::Queue::send() drops the item when the queue stays full for the whole timeout; RTOS::Queue::overwrite() always succeeds and replaces the single stored value.

#include <Lib/RTOS/FreeRTOS/Queue.hpp>
#include <chrono>
#include <cstdint>
using namespace std::chrono_literals;
namespace {
RTOS::Queue<uint32_t, 8U> samples;
RTOS::Queue<uint32_t> latestSetpoint;
}
void producerTask(void * parameters) {
static_cast<void>(parameters);
if (!samples.open() || !latestSetpoint.open()) {
return; // Creation failed: out of heap.
}
uint32_t value = 0U;
while (true) {
static_cast<void>(samples.send(value++, 10ms));
static_cast<void>(latestSetpoint.overwrite(value));
}
}

Consumer task

RTOS::Queue::receive() returns an empty std::optional when no item arrives within the timeout.

#include <Lib/RTOS/FreeRTOS/Queue.hpp>
#include <chrono>
#include <cstdint>
#include <optional>
using namespace std::chrono_literals;
namespace {
RTOS::Queue<uint32_t, 8U> samples;
}
void consumerTask(void * parameters) {
static_cast<void>(parameters);
while (true) {
if (const std::optional<uint32_t> sample = samples.receive(100ms); sample.has_value()) {
// Process *sample.
}
}
}

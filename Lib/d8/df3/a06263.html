RTOS::EventGroup

Shows opening an RTOS::EventGroup, setting one bit from a task and one from an interrupt, and waiting for both.

Shows opening an RTOS::EventGroup, setting one bit from a task and one from an interrupt, and waiting for both.RTOS::EventGroup::setBitsFromISR() is deferred by FreeRTOS to the timer daemon task, so it needs 'configUSE_TIMERS' and 'INCLUDE_xTimerPendFunctionCall' enabled. RTOS::EventGroup::Bits is an std::bitset limited to the bits FreeRTOS leaves usable. Only the '...FromISR()' calls may run in an interrupt; RTOS::EventGroup::wait() and RTOS::EventGroup::setBits() must run in a task. The value returned by RTOS::EventGroup::wait() is the state when the wait ended, before the clear on exit.

Usage

Set and wait for bits

  • 'TASK_READY' is set by the task itself.
  • 'DATA_READY' is set by an interrupt through RTOS::EventGroup::setBitsFromISR().
  • The wait clears both bits on exit only when both were set.
#include <Lib/RTOS/FreeRTOS/EventGroup.hpp>
#include <chrono>
using namespace std::chrono_literals;
RTOS::EventGroup events;
constexpr RTOS::EventGroup::Bits TASK_READY{1U << 0U};
constexpr RTOS::EventGroup::Bits DATA_READY{1U << 3U};
const RTOS::EventGroup::Bits ALL_READY = TASK_READY | DATA_READY;
extern "C" void EXTI0_IRQHandler() {
static_cast<void>(events.setBitsFromISR(DATA_READY)); // Deferred to the timer daemon task.
}
void exampleTask() {
if (!events.open()) {
return; // Creation failed: out of heap.
}
static_cast<void>(events.setBits(TASK_READY));
// Wait up to 1 s for both bits.
const RTOS::EventGroup::Bits result = events.wait(ALL_READY, true, true, 1s);
if ((result & ALL_READY) == ALL_READY) {
// Both bits set.
} else {
// Timeout: at most one of the bits was set.
}
events.close();
}

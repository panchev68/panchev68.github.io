Lib::HAL::SPIPort< DriverMode::DMA >final

Description

DMA specialization: transfers are started through the HAL DMA calls and completed from interrupt callbacks.

Handle lifecycle and the begin/end-transaction hooks come from SPIPortBase; the event group, start-then-wait transfers, SPIPortAsync::abort(), HAL callback registration and DeviceManager wiring come from SPIPortAsync, shared with the IT mode. This specialization only supplies the three HAL calls that start a DMA transfer.

Important
Transfer buffers must lie in DMA-reachable memory; the core-coupled memory (CCM) is not accessible to the DMA controller, which a debug build checks with an assert.

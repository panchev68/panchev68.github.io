Description

DriverMode header file.

This file defines the DriverMode enum, which specifies the operational modes for drivers in the HAL layer. It provides options for blocking, interrupt-driven, and DMA-based operations, allowing configuration of driver behavior for different performance and responsiveness requirements in embedded systems.

The DriverMode enum is used to set the mode of HAL drivers, ensuring appropriate handling of data transfer operations.

Note
This enum is designed for use with STM32 HAL library and FreeRTOS-based applications.
Attention
Ensure that the selected mode is compatible with the hardware capabilities and RTOS configuration.

Description

Frame header structure with start delimiter and length field.

Defines the binary layout of a frame header containing a start delimiter byte and a 16-bit length field (split into MSB and LSB). The struct is packed to ensure compact memory layout without padding, suitable for direct serialization and deserialization of frame data.

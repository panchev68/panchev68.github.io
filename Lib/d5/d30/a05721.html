Description

template<HttpTransport T_TRANSPORT>
class Lib::HTTP::Client< T_TRANSPORT >

HTTP/1.1 client over any connected HttpTransport, without heap or exceptions.

Builds the request line and headers itself, sends them and the optional body, then reads the response into a caller-provided buffer. For plain HTTP the transport is the project's own socket or modem stream; for HTTPS it is a WolfSSLTransport wrapping that stream. Every request sends 'Connection: close', so the caller reconnects the transport between requests.

Important
Only Content-Length delimited responses are understood: a chunked response is reported as Status::MALFORMED_RESPONSE. Fine for typical cloud REST/JSON APIs, not for arbitrary servers.
Requests block the calling task, polling the transport every tick, for at most 10 s while sending and 10 s while receiving.

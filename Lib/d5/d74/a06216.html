Lib::HAL::WindowWatchdog

Starts the hardware Window Watchdog (WWDG) with Lib::HAL::WindowWatchdog and refreshes it from a periodic task.

Starts the hardware Window Watchdog (WWDG) with Lib::HAL::WindowWatchdog and refreshes it from a periodic task.The wrapper does not own the CubeMX-generated handle; it stores the pointer passed to the constructor, which must stay valid for the lifetime of the instance. The counter, prescaler and window are read from the handle when Lib::HAL::WindowWatchdog::open() runs, so configure them in CubeMX before calling it.

Important
The class compiles only when HAL_WWDG_MODULE_ENABLED is defined. The project's HAL configuration header ('EWARM/Core/Inc/stm32f4xx_hal_conf.h') defines it, so the module is enabled for this target.
Warning
Once Lib::HAL::WindowWatchdog::open() succeeds the watchdog cannot be stopped until the next reset. A refresh issued before the window opens, or after the counter reaches zero, resets the MCU. Lib::HAL::WindowWatchdog::refresh() reports only that the reload register accepted the refresh, so true does not by itself prove that the refresh fell inside the window.

Start and refresh

#include <Lib/HAL/WWDG/WindowWatchdog.hpp>
#include <RTOS.hpp>
#include <chrono>
extern WWDG_HandleTypeDef hwwdg; // Generated by CubeMX.
void windowWatchdogTask(void *) {
static Lib::HAL::WindowWatchdog watchdog(&hwwdg);
if (!watchdog.open()) {
return;
}
while (true) {
// The refresh must fall inside the window configured in CubeMX.
if (!watchdog.refresh()) {
// The HAL refused the refresh; a refresh outside the window resets the MCU.
}
RTOS::delay(std::chrono::milliseconds(20));
}
}

Narrow the refresh window at run time

Lib::HAL::WindowWatchdog::setWindow() writes the window value into the handle and re-applies the configuration through HAL_WWDG_Init(). Call it before the refresh task starts, so that the first refresh falls inside the new window.

#include <Lib/HAL/WWDG/WindowWatchdog.hpp>
#include <cstdint>
bool configureWindow(Lib::HAL::WindowWatchdog & watchdog) noexcept {
constexpr uint32_t WINDOW_VALUE = 0x50U; // Window upper limit as a counter value.
return watchdog.setWindow(WINDOW_VALUE);
}

Lib::BSP::EncoderPins

Demonstrates a rotary encoder with a push button driving a menu position from a task.

Demonstrates a rotary encoder with a push button driving a menu position from a task.All three pins are EXTI inputs on both edges with a pull-up, named ENC_CLK, ENC_DT and ENC_BTN in CubeMX, so the 'PIN()' macro can build their handles. The EXTI callback forwards every pin to the encoder, which ignores pins that are not its own. With 'divider = 2' two rotation steps make one CW or CCW event. A button release longer than one second resets the position.

Warning
The callback must be the application's own: don't include Lib/HAL/GPIO/ExtInterrupt.hpp or the umbrella Lib/HAL/GPIO.hpp in the same program, since they define it too.
See also
Lib::BSP::EncoderPins, Lib::BSP::EncoderPins::Config, Lib::BSP::EncoderPins::kbdhit()
Example usage:
#include <Lib/BSP/Encoder/EncoderPins.hpp>
#include <Lib/HAL/GPIO/Handle.hpp>
#include <chrono>
#include <cstdint>
using namespace std::chrono_literals;
Lib::BSP::EncoderPins encoder{{
.channel1 = PIN(ENC_CLK),
.channel2 = PIN(ENC_DT),
.button = PIN(ENC_BTN),
.divider = 2,
}};
extern "C" void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin) {
static_cast<void>(encoder.handlePinChangedEvent(GPIO_Pin));
}
void menuTask() {
if (!encoder.open()) {
return;
}
int32_t position = 0;
while (true) {
switch (encoder.kbdhit(100ms)) {
case Lib::BSP::EncoderPins::EventState::CW:
++position;
break;
case Lib::BSP::EncoderPins::EventState::CCW:
--position;
break;
case Lib::BSP::EncoderPins::EventState::BUT_PULL:
if (encoder.getButtonHoldPeriod() >= 1s) {
position = 0; // Long press: reset.
}
break;
default:
break; // Timeout or BUT_PUSH.
}
}
}

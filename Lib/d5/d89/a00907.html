Lib::Ethercat::SOES

Description

Simple Open EtherCAT Slave (SOES) stack integration.

Provides the "Mailbox" class and related high-level abstractions for EtherCAT mailbox operations, asynchronous communication and protocol handling on top of the vendored SOES stack.

template<EscAccess T_ESC>
bool Lib::Ethercat::SOES::setSyncManagerEnabled ( T_ESC & esc,
uint8_t index,
bool isEnabled )
inlinenodiscardnoexcept

Enables or disables a sync manager from the PDI side.

Writes bit 0 of the PDI control register of the sync manager (0 enables, 1 deactivates) and reads it back until the chip shows the change, giving up after a bounded number of reads.

Template Parameters
T_ESCRegister access of the slave controller.
Parameters
escThe slave controller.
indexSync manager number, 0 to 7.
isEnabledtrue to enable the sync manager, false to deactivate it.
Returns
true if the chip showed the change.

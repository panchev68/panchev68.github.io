Lib::Digi::Core::Frame0x00

Description

Transmit request query for 64-bit destination addressing (XBee frame type 0x00).

Represents an XBee API frame type 0x00 that sends data to a remote device using a 64-bit IEEE destination address. The query encapsulates the frame ID for response tracking, destination address, transmission options, and the RF data payload to transmit. The conversion operator builds the serialized Frame::Data for transmission.

Constructs a Frame::Data object containing the serialized transmit request in XBee API frame format. Sets the frame type to TX_REQUEST_64BIT_ADDR and appends frame ID, destination address, options, and RF data in proper byte order.

Lib::Helper::Delay

Description

Helper class offering delay functions based on cycle counts.

All members are static; the class cannot be instantiated, copied, or assigned. It uses the Cortex‑M Data Watchpoint and Trace unit (DWT) to provide fine-grained blocking delays.

void Lib::Helper::Delay::microseconds ( uint32_t duration)
inlinestatic

Busy-wait for the specified number of microseconds.

The function computes how many CPU ticks correspond to duration microseconds at the current HCLK frequency obtained from HAL_RCC_GetHCLKFreq(), then spins until the DWT cycle counter has advanced by that many ticks.

Parameters
durationNumber of microseconds to delay; must be greater than zero.
Precondition
HAL_RCC_GetHCLKFreq() returns a valid (non‑zero) frequency.

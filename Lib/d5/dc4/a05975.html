RTOS::Timeoutfinal

Helper for tracking time-based event timeouts. More...

Description

Helper for tracking time-based event timeouts.

The elapsed time is computed with wrap-safe unsigned arithmetic, so a timeout stays correct across the tick counter overflow as long as it is polled at least once every 2^32 ticks.

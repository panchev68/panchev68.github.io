Description

Interrupt-driven (IT) specialization.

Lifecycle, command phase, abort() and callback wiring come from OSPIPortAsync, shared with the DMA mode. This class supplies only the two HAL calls that start an interrupt-driven data phase.

inlinenodiscardnoexceptinherited

Configures and issues a regular command.

Task context only.

A command without a data phase runs over interrupt and is waited for here. A command with a data phase is only configured synchronously, since the HAL raises no interrupt for it; the transfer starts with the following transmit() or receive().

Template Parameters
RepArithmetic representation type of the timeout.
PeriodRatio type of the timeout.
Parameters
cmdFully populated command descriptor; 'cmd.NbData' is the byte count of the following data phase.
timeoutMaximum time to wait.
Returns
true on success, false on error or timeout.

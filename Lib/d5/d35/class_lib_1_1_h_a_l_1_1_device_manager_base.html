Detailed Description

template<typename T_DEVICE, typename T_HANDLE>
class Lib::HAL::DeviceManagerBase< T_DEVICE, T_HANDLE >

Base Device Manager Template This template class provides a singleton base for managing devices of type T_DEVICE using handles of type T_HANDLE.

It maintains a map of handles to devices for efficient lookup and management in the HAL layer.

Template Parameters
T_DEVICEThe type of device being managed.
T_HANDLEThe type of handle used for device identification.

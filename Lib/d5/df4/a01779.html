Lib::USB::SerialPortRepeaterBase

Description

USB serial port repeater bridging UART and USB CDC communication.

Extends SerialPort to provide bidirectional USB device communication through the CDC (Communications Device Class) protocol. Manages USB device initialization, connection state tracking, line coding parameters, USB power detection, and event signaling for connection state changes. Uses FreeRTOS tasks and STM32 USB device middleware for reliable USB serial communication.

Opens the serial port and initializes USB device interface.

Calls the base SerialPort::open(), waits for USB initialization delay, enables the USB port, configures CDC callbacks (Init, DeInit, Control, Receive), and initializes the USB device via MX_USB_DEVICE_Init(). Sets the internal open flag to track state.

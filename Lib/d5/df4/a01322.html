Lib::Ethercat::CoE

Description

CoE class for CANopen over EtherCAT communication.

The CoE class provides methods to initialize and process CoE data, access Process Data Object (PDO) sizes, and retrieve Service Data Object (SDO) objects for EtherCAT communication in embedded systems. It serves as a wrapper around the SOES library functions for easier integration and type safety.

Role of the type within the module or system: Central interface for CoE protocol handling in EtherCAT slaves, enabling configuration and data exchange with EtherCAT masters.

Important design decisions or considerations: Uses extern "C" includes for SOES library integration, provides const access methods for data retrieval, and encapsulates EtherCAT-specific types.

Note
Call initialize() and process() in the appropriate EtherCAT state machine contexts.

Lib::GUI::Glyph

Description

View of the stored pixels of one character, read through Lib::GUI::Glyph::isSet() whatever the font layout is.

Does not own the bytes, which belong to the font data. It is created by Lib::GUI::Font::getGlyph() and is only valid while the font data is.

Lib::BSP::EncoderPins

Demonstrates a rotary encoder with a push button driving a menu position from a task.

Demonstrates a rotary encoder with a push button driving a menu position from a task.The example assumes all three pins are EXTI inputs on both edges, named ENC_CLK, ENC_DT and ENC_BTN in CubeMX, so the PIN() macro can build their handles. The EXTI callback forwards every pin to the encoder through Lib::BSP::EncoderPins::handlePinChangedEvent(), which ignores pins that are not its own. With a divider of 2 two rotation steps make one CW or CCW event. The example resets the position on a button release after more than one second.

Warning
The callback must be the application's own: don't include 'Lib/HAL/GPIO/ExtInterrupt.hpp' or the umbrella 'Lib/HAL/GPIO.hpp' in the same program, since they define HAL_GPIO_EXTI_Callback() too.

Menu position from encoder events

Lib::BSP::EncoderPins::kbdhit() waits for the next event from the task; Lib::BSP::EncoderPins::handlePinChangedEvent() is called from the EXTI callback for every pin. A Lib::BSP::EncoderPins::EventState::BUT_PULL event carries the hold time in Lib::BSP::EncoderPins::getButtonHoldPeriod().

#include <Lib/BSP/Encoder/EncoderPins.hpp>
#include <Lib/HAL/GPIO/Handle.hpp>
#include <chrono>
#include <cstdint>
using namespace std::chrono_literals;
Lib::BSP::EncoderPins encoder{{
.channel1 = PIN(ENC_CLK),
.channel2 = PIN(ENC_DT),
.button = PIN(ENC_BTN),
.divider = 2,
}};
extern "C" void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin) {
static_cast<void>(encoder.handlePinChangedEvent(GPIO_Pin));
}
void menuTask() {
if (!encoder.open()) {
return;
}
int32_t position = 0;
while (true) {
switch (encoder.kbdhit(100ms)) {
case Lib::BSP::EncoderPins::EventState::CW:
++position;
break;
case Lib::BSP::EncoderPins::EventState::CCW:
--position;
break;
case Lib::BSP::EncoderPins::EventState::BUT_PULL:
if (encoder.getButtonHoldPeriod() >= 1s) {
position = 0; // Long press: reset.
}
break;
default:
break; // Timeout or BUT_PUSH.
}
}
}

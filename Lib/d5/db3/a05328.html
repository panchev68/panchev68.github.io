Lib::HAL::HASHPort< DriverMode::IT >final

Description

HASH port that waits for the SHA-256 digest on the HASH interrupt instead of polling.

'sha256()' starts 'HAL_HASHEx_SHA256_Start_IT()' and blocks the calling task until the digest complete or error callback, registered with 'HAL_HASH_RegisterCallback()', reports from the HASH IRQ. When the project uses 'RTOS::PowerManager', STOP mode is withheld while waiting, since the peripheral clock stops there.

Thread safety: callers of one port are serialized by an internal mutex; task context only.

Important
The NVIC priority of the HASH IRQ must allow FreeRTOS 'FromISR' calls.

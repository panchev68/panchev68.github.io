RTOS::SemaphoreBaseabstract

Description

Base class for RTOS semaphores.

This abstract base class provides the common interface and implementation for various types of semaphores in the RTOS library. It manages the FreeRTOS semaphore handle and offers methods for taking and giving semaphores, both in normal and ISR contexts.

The class uses RAII for resource management, ensuring proper cleanup of semaphore handles. Move semantics are supported for efficient ownership transfer.

Derived classes must implement the open() method to create the specific semaphore type.

Note
This class is not intended for direct instantiation; use derived classes instead.

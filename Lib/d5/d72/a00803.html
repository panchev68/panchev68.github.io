Lib::BSP::DigitalPeripheralBase

Description

SPI-driven digital input and output block, updated periodically by its own RTOS task.

Owns one input port and one output port. Call setup() once to start the task; derived classes may override handlePreUpdateEvent() and handlePostUpdateEvent() to run code around every update cycle.

enum class Lib::BSP::DigitalPeripheralBase::UpdateMode : uint8_t
strong

How the update task serves the two ports.

Enumerator
SEQUENTIAL 

Ports share one SPI bus; each is reconfigured, served and released in turn.

PARALLEL 

Ports have separate SPI buses; each is configured once and then served every cycle.

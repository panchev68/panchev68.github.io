Description

Hex conversion utilities for the fixed-width unsigned integer types.

Provides conversions of 'uint8_t', 'uint16_t', 'uint32_t' and 'uint64_t' values to fixed-width uppercase hexadecimal strings, to packed BCD values and to decimal ASCII strings. All results are returned in fixed, NUL-terminated std::array buffers sized from the worst case of the type, so nothing allocates and everything is usable in a constant expression. Depends on 'HexHelper' (and through it on 'Ascii') for the low-level nibble and BCD operations.

One constrained class template replaces the former per-width specializations; every width shares the same code and only the digit counts are derived from the type.

Lib::Crypto::SHA256< SHA256Engine::SOFTWARE >final

Description

Streaming SHA-256 hasher with a portable C++ compression function.

Owns no tables beyond the 64 round constants and never allocates: the state is the eight hash words, one pending 64-byte block and two counters. Whole blocks of the input are compressed straight from the caller's buffer, and the message schedule keeps only 16 words, so the compression needs little stack.

Description

AdcPort header file.

This file provides type aliases for ADC port specializations based on driver modes. It includes the necessary headers for blocking, interrupt-driven, and DMA-based ADC operations, allowing users to select the appropriate port type for their application requirements in embedded systems.

The aliases simplify the usage of ADC ports by providing clear names for different operational modes, ensuring type safety and ease of integration with HAL components.

Include this file to access ADC port types; ensure the corresponding implementation files are linked.

Description

Ethernet over EtherCAT (EoE): the Ethernet frame tunnel of an EtherCAT slave.

Carries Ethernet frames between the master and a network stack on the slave over the mailbox. A frame is cut into fragments that fit a mailbox message; this class puts the fragments of a received frame together and hands the frame to the application, and cuts a frame the application queues into fragments and sends them. It also answers the requests that set and get the IP parameters of the slave. It does not contain a network stack: the application passes received frames to its stack and queues the frames the stack wants to send.

Use it from the mailbox handler of a Slave: pass every message to handle() and call service() in the idle hook, which sends the fragments.

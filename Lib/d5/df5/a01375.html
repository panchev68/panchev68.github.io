Lib::Ethernet::MacAddress

Description

MacAddress class for embedded networking applications.

The MacAddress class represents a MAC address, providing construction, conversion, and validation functionalities. It supports creation from byte arrays, automatic generation using device serial number, string conversions, and access to individual bytes. Designed for type safety and efficiency in embedded systems.

Role of the type within the module or system: Core component for network address management in Ethernet communications, ensuring proper device identification and configuration.

Important design decisions or considerations: Uses std::array for fixed-size storage, provides const access methods, and includes static utility functions for conversions.

Note
Generated MAC addresses use a predefined OUI for consistency.

Lib::BSP::Display::Driver< Controller::ILI9341 >

Description

Specialized ILI9341 display driver implementation.

Provides full control over the ILI9341 TFT display controller with support for initialization, pixel transmission, rotation control, and backlight management. Uses SPI communication with DMA for efficient pixel block transfers.

See also
DriverBase
Controller::ILI9341
Note
This driver is optimized for STM32 HAL and FreeRTOS environments.

Transmits a block of pixel data to the display.

Sends pixel data from the provided buffer to the specified rectangular area on the display using DMA for efficient transfer. The pixel data is expected to be in RGB565 format.

Parameters
pixelBufferPointer to the pixel data buffer.
xX-coordinate of the top-left corner of the target area.
yY-coordinate of the top-left corner of the target area.
widthWidth of the target area in pixels.
heightHeight of the target area in pixels.
Precondition
pixelBuffer must not be null, width and height must be positive, and the total pixels must fit in uint16_t.
Postcondition
The specified area on the display is updated with the pixel data.

Implements Lib::BSP::Display::DriverBase.

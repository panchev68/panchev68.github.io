Lib::XCOM::ServiceBase::Value64Handle

Description

Handle for tracking changes to 64-bit values.

The Value64Handle class provides change tracking for 64-bit values through binding to external variables. It maintains status (NO_INIT, CHANGED, IN_PROGRESS, COMPLETED) and tracks the previous value to detect modifications. Useful for detecting when bound values change and managing operation state transitions.

Bind the handle to an external value.

Associates this handle with an external 64-bit variable, enabling change tracking and value management. After binding, the handle can detect when the external variable is modified and manage its lifecycle.

Parameters

Mark the handle as completed.

Updates the previous value to the current bound value and sets status to COMPLETED. This is called after processing the change to reset the change tracking state.

Postcondition
Previous value synchronized with current bound value; status is COMPLETED.

◆ update()

Status Lib::XCOM::ServiceBase::Value64Handle::update ( )
inline

Update the status of the handle.

Checks the current state of the bound value (if any) and updates the handle status accordingly. If the handle is not bound, returns NO_INIT. If in-progress, maintains IN_PROGRESS. Otherwise, compares the current value with the previous value to determine CHANGED or COMPLETED status.

Returns
Updated status after checking bound value state.
Postcondition
Status reflects current state: NO_INIT (unbound), IN_PROGRESS (unchanged), CHANGED (value differs from previous), or COMPLETED (value unchanged).

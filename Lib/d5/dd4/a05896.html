Lib::SolarControl::MPPT::ReferenceParameters

Configuration values used to initialise the MPPT coefficients. More...

Description

Configuration values used to initialise the MPPT coefficients.

The values are physical references such as nominal maximum power, MPP voltage and current, and reference irradiance. Every field has a default and may be overridden by the caller.

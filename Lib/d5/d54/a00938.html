Lib::BSP::UARTPortabstract

Description

Interface for UART port abstraction.

This abstract class defines the interface for UART communication ports in the board support package. It provides methods for initializing the UART port, performing data transfers, and managing the communication lifecycle with timeout-based operations.

The interface supports both transmission and reception of data with preconditions for parameter validation. All methods are pure virtual, requiring concrete implementations for specific hardware platforms.

Implementations should handle UART bus management, error conditions, flow control, and ensure proper synchronization with the underlying hardware peripherals.

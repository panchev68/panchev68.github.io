RTOS::EventGroup

Comprehensive example demonstrating EventGroup usage in embedded applications.

Comprehensive example demonstrating EventGroup usage in embedded applications.This example shows initialization, ISR signaling, and task-side waiting patterns for real-time event synchronization using FreeRTOS event groups.

Example usage:
#include "EventGroup.hpp"
#include <bitset>
// Define application event bit roles for readability
enum Event : size_t { EVT_INIT = 0, EVT_FRAME = 1, EVT_BUTTON = 2, EVT_ERROR = 3 };
// EventGroup instance (RAII wrapper) - supports up to 8 event bits
static RTOS::EventGroup<8> systemEvents;
// Initialize the event group during system startup
void initializeSystemEvents() {
if (!systemEvents.open()) {
// Handle allocation failure (log, retry, safe-fail)
// In embedded systems, this might trigger system reset
}
}
// Example ISR: signal frame synchronization event from display interrupt
extern "C" void onDisplayVSyncISR() {
// Use template variant for compile-time type safety
systemEvents.setBitsFromISR<EVT_FRAME>();
}
// Example ISR: signal button press event from GPIO interrupt
extern "C" void onButtonPressISR() {
// Use template variant for single bit signaling
systemEvents.setBitsFromISR<EVT_BUTTON>();
}
// Task that waits for frame events with timeout handling
void frameProcessingTask(uint32_t timeoutTicks) {
if (!systemEvents.isOpen()) return; // Ensure created
// Template variant: wait for EVT_FRAME only
auto result = systemEvents.waitForBits<EVT_FRAME>(timeoutTicks);
if (result[EVT_FRAME]) {
// Handle frame event (render, process, update display)
processNextFrame();
} else {
// Timeout occurred; handle accordingly
handleFrameTimeout();
}
}
// Task that waits for multiple conditions using bitset
void userInterfaceTask(uint32_t timeoutTicks) {
if (!systemEvents.isOpen()) return;
std::bitset<8> waitMask;
waitMask[EVT_BUTTON] = 1; // Wait for button press
waitMask[EVT_INIT] = 1; // Or initialization complete
auto result = systemEvents.waitForBits(waitMask, timeoutTicks);
if (result.any()) {
if (result[EVT_BUTTON]) {
// Handle button interaction
processButtonEvent();
}
if (result[EVT_INIT]) {
// Handle initialization completion
finalizeSystemSetup();
}
} else {
// Timeout - no events occurred
handleUIIdleState();
}
}
// Error handling task using bitset for multiple error conditions
void errorMonitoringTask() {
if (!systemEvents.isOpen()) return;
std::bitset<8> errorMask;
errorMask[EVT_ERROR] = 1; // Monitor error events
while (true) {
auto result = systemEvents.waitForBits(errorMask, portMAX_DELAY);
if (result[EVT_ERROR]) {
// Handle system error (log, reset, recovery)
performErrorRecovery();
}
}
}
// Clean-up when shutting down (optional in embedded systems)
void shutdownSystemEvents() {
if (systemEvents.isOpen()) {
systemEvents.close();
}
}

Notes:
  • The setBitsFromISR helpers are safe to call from ISR context and will perform context switching if a higher priority task is woken.
  • Template variants provide compile-time type safety and avoid runtime errors.
  • Bitset variants offer flexibility for dynamic event combinations.
  • Always check isOpen() before using the event group.
  • Use appropriate timeouts to prevent task blocking in real-time systems.

Lib::HAL::CanRxMessage

Description

Wrapper for a received CAN message containing header and data buffer.

Inherits from CAN_RxHeaderTypeDef and provides a fixed 8-byte data buffer owned by the object. Accessors return the standard ID, the data length code (DLC) and pointers to the payload buffer.

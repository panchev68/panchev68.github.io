Lib::BSP::EncoderPins

Description

EncoderPins class for handling rotary encoder inputs.

Manages two quadrature input channels and a push button. Decodes rotation direction, supports optional pulse division to reduce event rate and records button hold time.

bool Lib::BSP::EncoderPins::handlePinChangedEvent ( uint16_t pinNumber)
inline

Handle a GPIO pin-change event delivered by ISR or dispatcher.

Decodes button changes and quadrature transitions; when a complete rotation step is detected an EventState (CW/CCW) is queued.

Parameters
pinNumberGPIO pin number that changed.
Returns
true if the pin belongs to this encoder, false otherwise.
Note
This function is intended to be called from an interrupt context.

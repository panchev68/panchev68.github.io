Lib::BSP::SK6812::Ring< T_COUNT >

Description

template<size_t T_COUNT>
class Lib::BSP::SK6812::Ring< T_COUNT >

Fixed number of SK6812 LEDs sharing one contiguous compare buffer for a single DMA transfer.

The buffer is a member, so no heap is used and every LED slice stays valid for the ring's lifetime. Pass getData() and getSize() to the PWM DMA start call.

Template Parameters
T_COUNTNumber of LEDs; must be greater than 0.

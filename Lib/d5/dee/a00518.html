Description

RingBuffer.hpp file.

This file provides a template class for implementing a fixed-size ring buffer (circular buffer). The RingBuffer class supports efficient insertion and removal of elements with O(1) complexity for most operations. It uses a fixed-size array for storage and manages read/write positions to achieve circular behavior. Suitable for embedded systems requiring bounded memory usage.

Important dependencies: Uses std::array for storage, std::utility for move operations, and standard assertions for bounds checking.

Special instructions: The buffer size must be known at compile time; no dynamic resizing.

Note
This implementation does not handle thread safety; synchronization is required for concurrent access.
Attention
Overwriting full buffer is not supported; push operations fail if full.

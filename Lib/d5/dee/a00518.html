Description

Standard library helpers: minimal conversions and utility functions.

Provides lightweight implementations of C-style string to number conversions and a small integer formatting helper suitable for constrained or freestanding environments where full libc is not available.

Note
  • Implementations avoid dynamic allocation and locale dependence.

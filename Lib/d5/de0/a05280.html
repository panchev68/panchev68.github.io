Lib::Ethernet::UserProtocol< T_DERIVED >

Description

template<typename T_DERIVED>
class Lib::Ethernet::UserProtocol< T_DERIVED >

Builds and parses user protocol messages.

The derived class may provide handleIncomingMessageHeader(), echoCallback(), updateNodeActivityCallback(), inputsUpdateCallback() and handleOutputsUpdate(); each replaces the empty default of this class. If it declares them private, it must make 'UserProtocol<T_DERIVED>' its friend.

template<typename T_DERIVED>
Error Lib::Ethernet::UserProtocol< T_DERIVED >::parse ( std::span< const uint8_t > data,
Command & command,
uint8_t & option )
inlinenodiscard

Parses the incoming messages.

Handles every message in the buffer in turn: reads the header, reports it, checks the payload length and runs the command, which calls the callbacks. Stops at the first error.

Parameters
dataReceived bytes: one or more whole messages.
[out]commandCommand of the last message read.
[out]optionOption of the last message read.
Returns
Error::OK if every message was valid, otherwise the first error.

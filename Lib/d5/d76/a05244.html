template<EscAccess T_ESC, size_t T_MAX_SIZE = 256U>
class Lib::Ethercat::SOES::Mailbox< T_ESC, T_MAX_SIZE >

EtherCAT slave mailbox transport, written directly on the ESC registers.

The mailbox is the asynchronous channel between master and slave (CoE, FoE, EoE, AoE, SoE and VoE ride on it). It is two sync managers of the EtherCAT slave controller: SM0 carries messages from the master to the slave, SM1 from the slave to the master. This class enables both through the PDI control registers, reads the configuration the master wrote, receives one message at a time, sends messages and mailbox errors, and answers the master's repeat requests by writing the last message the master read again. It does not interpret the protocols themselves: it hands the protocol type and payload to the caller.

The chip is reached through a type that provides 'readReg()' and 'writeReg()' (the LAN9252 driver does), so no vendor stack is needed. One task at a time may use a mailbox.

Template Parameters
T_ESCRegister access of the slave controller, see 'EscAccess'.
T_MAX_SIZELargest mailbox, in bytes, that the object can handle; the master's sync manager configuration must fit it.

bool Lib::Ethercat::SOES::Mailbox< T_ESC, T_MAX_SIZE >::start ( )
inlinenodiscardnoexcept

Enables SM0 and SM1, reads the configuration the master wrote and starts the mailbox.

Call it when the slave leaves INIT, once the master has configured SM0 and SM1. Any earlier message state is dropped. On a bad configuration both sync managers are deactivated again.

Returns
true if both sync managers are enabled by the master and their sizes fit the mailbox.

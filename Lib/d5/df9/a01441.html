Lib::HAL::TimerHandle

Description

TimerHandle struct for managing timer resources.

This struct encapsulates a pointer to a TIM_HandleTypeDef and a channel number, providing a unified interface for timer operations in the HAL layer. It ensures type safety and validity checks for timer handles, preventing common errors in embedded timer management.

The TimerHandle supports equality and inequality comparisons, as well as validity checks, making it suitable for use in collections and conditional logic.

FunctionRef

Binds a FunctionRef to a lambda, to a functor and to a free function, then calls it.

Binds a FunctionRef to a lambda, to a functor and to a free function, then calls it.FunctionRef owns nothing. It stores a capture-less lambda or a free function by value, and also any other callable that is trivially copyable and exactly as wide as a pointer, such as a functor holding one 'int' on this 32-bit target or a lambda capturing only 'this'. Any other callable is referenced, so an lvalue of it must outlive the reference, and a larger temporary is rejected at compile time.

Bind and rebind

Assigning a new callable to a FunctionRef rebinds it to that callable.

#include <Lib/Core/FunctionRef.hpp>
#include <iostream>
struct Adder {
int base;
Adder(int b) :
base(b) {
}
int operator()(int x) const {
return base + x;
}
};
void functionRefExample() {
// A capture-less lambda is stored by value, so the temporary is fine.
FunctionRef<int(int)> callable = [](int x) { return x * 2; };
std::cout << callable(5) << "\n";
// A functor as wide as a pointer is stored by value too, so the temporary is fine.
callable = Adder{3};
std::cout << callable(5) << "\n";
// A captureless lambda held in an lvalue is also stored by value.
auto square = [](int v) { return v * v; };
callable = square;
std::cout << callable(4) << "\n";
}

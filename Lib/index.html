IAR EWARM Library

📖 Overview

The IAR EWARM Library is a header-only C++20 library for embedded systems development on STM32F4xx microcontrollers using IAR Embedded Workbench 10.10.2. It provides a type-safe interface to hardware peripherals, FreeRTOS abstractions, communication protocols, and board-support drivers. The library abstracts low-level HAL details while maintaining direct access to hardware capabilities through multiple transfer modes (blocking, interrupt-driven, DMA) and supports CAN bus communication, EtherCAT slave operation, Modbus, the Digi/XBEE and XCOM protocol stacks, and an HTTP/1.1 client with optional TLS.

The project base directory is X:\Lib\IAR. It is almost entirely header-only; the library source is inc/Lib/**/*.hpp under that base. The library is not built standalone. The IAR project under EWARM/ is generated by STM32CubeMX and contains only test code that consumes the library from X:\Lib\IAR\inc.

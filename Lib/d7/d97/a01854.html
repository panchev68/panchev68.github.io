Using Timer Encoder for Quadrature Encoder Input

This example demonstrates how to initialize and use the Timer encoder specialization to handle quadrature encoder inputs in an embedded system. It shows setting up the timer handle, configuring a callback for value changes, and starting the encoder.

Example usage:
#include "Lib/HAL/core/TIM/Timer-Encoder.hpp"
#include "stm32f4xx_hal.h" // Assuming STM32F4
// Assume TIM_HandleTypeDef htim3 is initialized elsewhere
extern TIM_HandleTypeDef htim3;
int main() {
// Create encoder timer instance
Lib::HAL::Timer<Lib::HAL::TimerMode::ENCODER> encoderTimer(&htim3);
// Set callback for value changes
encoderTimer.onValueChanged = [](uint32_t newValue) {
// Handle encoder value change, e.g., update position
printf("Encoder value: %u\n", newValue);
};
// Open the encoder timer
if (encoderTimer.open()) {
// Timer is now active and will call the callback on value changes
while (true) {
// Main loop, encoder interrupts will handle value updates
}
} else {
// Handle error
}
// Close when done
encoderTimer.close();
return 0;
}

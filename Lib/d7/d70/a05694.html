Description

Helper type that computes a 16-bit CRC for provided data views.

Create an instance with a character view, a byte span or a byte vector and obtain the CRC by converting the instance to uint16_t. The type is a trivially copyable, non-owning view; the viewed bytes must outlive it. It declares no destructor on purpose: a user-declared one, even defaulted, makes the class non-literal on this toolchain and would prevent constant evaluation.

Compute and return the 16-bit CRC value for the provided data view on demand.

The incoming byte is XORed with the byte leaving the high end of the register to select the table entry, which is the byte-wise equivalent of the direct bit-by-bit division.

Returns
Computed 16-bit CRC value; 0 for an empty view.

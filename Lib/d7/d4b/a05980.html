RTOS::TickCounterfinal

Description

Static utility class for reading the system tick count and converting between ticks and time units.

Every conversion to ticks rounds up, so a wait is never shorter than requested, and saturates at 'portMAX_DELAY', which FreeRTOS treats as waiting forever. Every method that reads the tick count is task-context only and has an explicit 'FromISR' twin for interrupt context.

◆ toTicks()

template<typename Rep, typename Period>
constexpr TickType RTOS::TickCounter::toTicks ( std::chrono::duration< Rep, Period > duration)
inlinestaticnodiscardconstexprnoexcept

Converts a std::chrono duration to scheduler ticks, rounding up.

Negative durations convert to 0 ticks. The duration must be representable as a 64-bit tick count. Forwards to RTOS::durationToTicks(), the one conversion shared by every wrapper.

Template Parameters
RepArithmetic representation type of the input duration.
PeriodRatio type of the input duration.
Parameters
durationDuration to convert.
Returns
Equivalent number of ticks, saturated at 'portMAX_DELAY'.

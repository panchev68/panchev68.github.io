Lib::HAL::Timer< T_MODE >

Description

template<TimerMode T_MODE>
class Lib::HAL::Timer< T_MODE >

Timer template class for managing HAL timers.

This class provides a type-safe wrapper around timer operations, parameterized by timer mode. It manages timer handles and provides methods for configuration and validation.

Role within the module: Acts as an abstraction layer for timer peripherals in the HAL.

Important design decisions: Uses template metaprogramming for compile-time mode selection, deleted copy and move operations to prevent resource duplication.

Template Parameters
T_MODEThe timer mode, must be a valid TimerMode enum value.

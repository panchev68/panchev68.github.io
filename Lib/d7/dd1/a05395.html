Lib::GUI::Canvasfinal

Description

Text and layout helper over the shared Lib::GUI::Primitives, which draws the shapes and pixels.

Holds a reference to the primitives of the display and the current font, so it is cheap to create and to pass to widgets. Text is drawn from the top-left corner of the first glyph, in whole-pixel scale steps, with the extra space of Lib::GUI::Canvas::setGlyphSpacing() and Lib::GUI::Canvas::setLineSpacing(), none by default. A newline character starts a new line at the same left position. A character without a glyph is drawn as its replacement, see Lib::GUI::Font::resolve(). Several fonts can be used: select one with Lib::GUI::Canvas::setFont(), or let a widget use its own through Lib::GUI::Canvas::FontScope. Nothing is sent to the panel until Lib::GUI::Canvas::flush() is called.

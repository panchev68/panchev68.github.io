Description

template<typename T_DEVICE, typename T_HANDLE>
class Lib::HAL::DeviceManagerBase< T_DEVICE, T_HANDLE >

DeviceManagerBase template class for device management.

This template class provides a base implementation for managing devices using handles. It implements a singleton pattern and uses an unordered map for efficient device storage and retrieval. The class is designed to be inherited by specific device managers.

Template Parameters
T_DEVICEThe type of the device being managed.
T_HANDLEThe type of the handle used to identify devices.

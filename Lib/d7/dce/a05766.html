Lib::Helper::TimePeriodfinal

Stopwatch based on the RTOS tick counter. More...

Description

Stopwatch based on the RTOS tick counter.

Records a start tick and computes elapsed ticks. The unsigned tick subtraction stays correct across a single wraparound of the tick counter. Callers in an interrupt must use the FromISR method variants.

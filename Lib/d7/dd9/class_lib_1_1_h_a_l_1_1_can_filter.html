Detailed Description

CAN filter configuration wrapper class.

Provides a type-safe interface for configuring CAN filters by wrapping the CAN_FilterTypeDef structure. Supports setting filter ID, mask, bank, mode, scale, activation, and FIFO assignment.

Role of the type within the module or system: Acts as a configuration helper for CAN filters in the HAL layer, ensuring proper initialization and management of filter settings for CAN communication.

Important design decisions: Inherits from CAN_FilterTypeDef for direct compatibility with HAL functions, uses noexcept for real-time safety, and provides constexpr accessors where possible for compile-time evaluation.

Lib::HAL::AdcChannel::Config

Description

Convenience configuration type derived from HAL's ADC_ChannelConfTypeDef.

The constructor initializes the channel, rank and sampling time and clears the offset field. The type can be implicitly converted to a pointer to ADC_ChannelConfTypeDef when required by HAL APIs.

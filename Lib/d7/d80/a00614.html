Description

Configuration storage helper for persistent device settings.

Provides read/write access to a 31-bit configuration stored in OTP flash memory. This class wraps low-level OTP operations and exposes a simple bitset-based API for reading and writing configuration values.

Note
  • The class uses Lib::HAL::OTP singleton for flash access.
  • Writes are attempted twice before reporting failure to mitigate transient write errors.

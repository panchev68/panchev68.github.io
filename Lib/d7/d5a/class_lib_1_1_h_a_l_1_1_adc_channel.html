Detailed Description

ADC channel configuration and management class.

Encapsulates configuration and management of ADC channels using the STM32 HAL library. Provides a type-safe interface for ADC channel setup, utilizing a nested Config class for parameter storage and initialization.

Role of the type within the module or system: Acts as a wrapper for ADC channel configuration, providing structured parameter initialization and delegating the actual configuration to the HAL layer.

Important design decisions: Uses a nested Config class that inherits from ADC_ChannelConfTypeDef for direct HAL compatibility, provides explicit constructor for initialization, and delegates hardware configuration to HAL functions.

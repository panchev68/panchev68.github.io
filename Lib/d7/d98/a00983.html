Lib::Canbus::Service< Mode::CLIENT >abstract

Description

CAN bus client service implementation.

Template specialization for the Service class operating in CLIENT mode. Provides methods for sending CAN messages in various formats (raw data, values) and retrieving diagnostic information. The client service extends ServiceBase with virtual methods that can be overridden in derived classes for handling task execution, message reception callbacks, and error conditions.

Lib::BSP::DeviceManager::DeviceBaseabstract

Description

Base class for devices managed by DeviceManager.

Instances automatically register themselves with the manager on construction and unregister on destruction. Derived classes should override setup() to perform initialization and handleTickEvent() to implement periodic work.

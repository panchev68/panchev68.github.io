Detailed Description

One-Time Programmable (OTP) flash memory management class.

This class provides an interface for interacting with the OTP flash memory on STM32F4xx devices. It supports reading and writing data of various types, locking and unlocking the flash, and provides utility methods for address calculations and range validation.

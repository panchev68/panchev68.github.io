RTOS::Timer

Shows a software timer that runs a callback from the FreeRTOS timer daemon task.

Shows a software timer that runs a callback from the FreeRTOS timer daemon task.Covers an auto-reload timer that toggles an LED every 500 ms and a one-shot timer that is started on demand. Callbacks run in the timer daemon task context, not in an ISR, so they must not block for long. The timer objects must outlive their callbacks, so they are kept in namespace scope here; destroying a timer stops it.

Warning
The callback is stored as a non-owning 'FunctionRef': the function it points to must outlive the timer.

Auto-reload timer

RTOS::Timer::make() returns an empty optional when the native timer cannot be created.

#include <Lib/RTOS/FreeRTOS/Timer.hpp>
#include <optional>
namespace {
void toggleLed() {
// Toggle the LED from the timer daemon task.
}
std::optional<RTOS::Timer> blink;
}
void startBlink() {
blink = RTOS::Timer::make(RTOS::Timer::Config::fromMs("Blink", &toggleLed, 500U));
if (blink.has_value() && blink->start() == RTOS::Timer::Status::SUCCESS) {
// Blinking until blink is stopped or destroyed.
}
}

One-shot timer

A one-shot timer runs its callback once after each RTOS::Timer::start(). The period is given in seconds here.

#include <Lib/RTOS/FreeRTOS/Timer.hpp>
#include <optional>
namespace {
void timeoutHandler() {
// Runs once, 3 s after the timer is started.
}
std::optional<RTOS::Timer> timeout;
}
void startTimeout() {
timeout = RTOS::Timer::make(
RTOS::Timer::Config::fromSeconds("Timeout", &timeoutHandler, 3U, RTOS::Timer::Mode::ONE_SHOT));
if (timeout.has_value()) {
static_cast<void>(timeout->start());
}
}

Changing the period at run time

RTOS::Timer::setPeriodMs() changes the period of the timer. FreeRTOS also starts a stopped timer as a side effect, so call RTOS::Timer::stop() afterwards if the timer must stay stopped.

#include <Lib/RTOS/FreeRTOS/Timer.hpp>
void blinkFaster(RTOS::Timer & blink) {
static_cast<void>(blink.setPeriodMs(250U));
}

Lib::HAL::DeviceManager< T_DEVICE, T_HANDLE >

Description

template<typename T_DEVICE, typename T_HANDLE>
class Lib::HAL::DeviceManager< T_DEVICE, T_HANDLE >

Forward declaration of the registry that owns the Device list links.

Process-wide registry that maps native HAL handles to their concrete CRTP drivers.

Template Parameters
T_DEVICEThe concrete derived driver class implementation tracking this framework.
T_HANDLENative micro-controller hardware handle descriptor structure type.

Registration and removal run under RTOS::Kernel::CriticalSection, so an interrupt cannot observe a half-updated list. Lookups do not take the critical section.

Template Parameters
T_DEVICEConcrete driver class derived from Device.
T_HANDLENative STM32 HAL handle descriptor structure type.

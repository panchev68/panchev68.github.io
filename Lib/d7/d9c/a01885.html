RTOS::Timer

Timer Usage Example

This example demonstrates how to create, configure, and manage FreeRTOS software timers using the RTOS::Timer abstraction. It shows one-shot and auto-reload timers, setting periods, starting/stopping, and handling timer callbacks.

Example usage:
#include "Lib/RTOS/Timer.hpp"
void heartbeatCallback() {
// Heartbeat logic executed when timer expires
}
void someTaskFunction(void *pvParameters) {
// Create a one-shot timer with 1000 ms period
auto oneShotTimer = RTOS::Timer::makeMs("OneShotTimer", heartbeatCallback, 1000);
if (oneShotTimer && oneShotTimer->start()) {
// One-shot timer started successfully
}
// Create an auto-reload timer with 2000 ms period
auto autoReloadTimer = RTOS::Timer::makeMs("AutoReloadTimer", heartbeatCallback, 2000, RTOS::Timer::Mode::AUTO_RELOAD);
if (autoReloadTimer && autoReloadTimer->start()) {
// Auto-reload timer started successfully
}
// Check timer state
if (autoReloadTimer->isActive()) {
uint32_t remaining = autoReloadTimer->getRemainingTimeMs();
// Use remaining time information
}
// Change timer period
autoReloadTimer->setPeriodMs(3000);
// Stop timer
autoReloadTimer->stop();
// Reset timer from task context
autoReloadTimer->reset();
}
Timer.hpp
FreeRTOS Timer Abstraction Header.
Output:
The timers execute their callbacks at the specified periods. One-shot timer fires once, while auto-reload timer fires repeatedly until stopped. All operations are thread-safe and integrated with FreeRTOS timer daemon task.

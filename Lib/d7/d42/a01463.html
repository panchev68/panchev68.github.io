Lib::Helper::ContainerBase< T >

Description

template<typename T>
class Lib::Helper::ContainerBase< T >

ContainerBase - Base template class for managing collections of items.

This class provides virtual methods for adding, removing, and accessing items in a container backed by std::vector. It allows derived classes to customize behavior while providing default implementations.

Template Parameters
TThe type of elements stored in the container.

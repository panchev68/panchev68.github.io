Lib::Errors::Observer< Derived, T_ERROR >

Description

template<typename Derived, ErrorKind T_ERROR = SimpleError>
class Lib::Errors::Observer< Derived, T_ERROR >

CRTP foundation reading active errors from the Lib::Errors::Dispatcher, optionally restricted to a single Lib::Errors::Group.

The logic lives here, so a derived observer narrows the filter by providing its own matches() without a vtable; Lib::Errors::GroupObserver is the ready-made group-filtered variant.

Constructing from an existing Lib::Errors::Group filters by that external, caller-owned group. Constructing from a caption instead creates and owns a new Lib::Errors::Group for the lifetime of this observer. With neither, every active error in the Lib::Errors::Dispatcher is observed. A derived class replaces the filter by defining its own "matches(const T_ERROR &) const", which hides the default one; it can still call Lib::Errors::Observer::matches() for the group filter.

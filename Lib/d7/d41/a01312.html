Lib::Digi::API::Service::Parametersfinal

Description

Module parameter service: a blocking full read, periodic polling of the runtime values and change writing.

The service hooks run in the application task. "setChannel()", "setPanId()", "writeChanges()" and "pauseReadDynamicParameters()" only post requests through atomics, so any task may call them; the application task applies them in "process()". While connected, a channel change is written to the remote module first and then locally, together with a PAN ID change, and a change without a new channel is dropped; while disconnected, channel and PAN ID are written locally only.

◆ writeChanges()

void Lib::Digi::API::Service::Parameters::writeChanges ( )
inlinenoexcept

Requests the pending channel and PAN ID changes to be written while the service runs.

The request is taken by "process()" in the application task, so it never races a running write; a request made during a write follows that write.

const ObjectList & Lib::Ethercat::CoE::getSDOObjects ( ) const
inline

Access the SOES-provided SDO object list.

The returned reference refers to an externally defined array (SDOobjects) provided by the native SOES layer. The caller must not attempt to free or modify the array unless explicitly allowed by the SOES implementation.

Returns
Reference to the external object list describing SDO entries.

◆ process()

void Lib::Ethercat::CoE::process ( )
inline

Run CoE processing step.

This forwards to the SOES stack's ESC_coeprocess() routine which handles CoE state machines and SDO processing. Callers should invoke this periodically from the main EtherCAT processing loop.

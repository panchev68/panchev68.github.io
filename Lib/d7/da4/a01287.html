Lib::Digi::Core::Frame0x01

Description

Transmit request query for 16-bit destination addressing (XBee frame type 0x01).

Represents an XBee API frame type 0x01 that sends data to a remote device using a 16-bit destination address. The query encapsulates the frame ID for response tracking, destination address, transmission options, and the RF data payload to transmit. The conversion operator builds the serialized Frame::Data for transmission.

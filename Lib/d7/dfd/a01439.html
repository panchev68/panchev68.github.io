Lib::Helper::Convert::Asciifinal

Description

ASCII utility class for character validation and conversion.

Provides static methods and constants for validating and converting ASCII characters. Designed for compile-time evaluation and safe use in embedded systems.

The class is non-instantiable and functions solely as a container for related utilities.

constexpr uint8_t Lib::Helper::Convert::Ascii::toHex ( char character)
inlinestaticnodiscardconstexprnoexcept

Convert a hexadecimal character to its numeric value.

Converts a hexadecimal character into its 4-bit numeric value (0..15). A character that is not a hex digit yields INVALID_NIBBLE rather than an unspecified value, so a parser can reject bad input on the result alone; debug builds additionally assert.

Parameters
characterHexadecimal character to convert.
Returns
Numeric value of the hex digit in the range 0..15, or INVALID_NIBBLE if it is no hex digit.

Lib::Canbus::Service< Mode::SERVER >abstract

Description

Template specialization of Service for server mode.

This class provides server-side CAN bus communication functionality. It manages client nodes, sends messages, receives responses, and performs diagnostic operations. The class is designed for embedded systems using FreeRTOS and IAR Embedded Workbench.

Template Parameters
Mode::SERVERSpecialization for server mode operation.

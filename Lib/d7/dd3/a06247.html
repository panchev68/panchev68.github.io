Lib::Helper::TimePeriod

Measures elapsed RTOS ticks in a task with Lib::Helper::TimePeriod.

Measures elapsed RTOS ticks in a task with Lib::Helper::TimePeriod. Results have tick granularity.

The example starts the stopwatch, delays for a known interval, reads the elapsed ticks and the elapsed time without stopping, then stops it to read the final ticks and resets it. It runs in task context and relies on the FreeRTOS scheduler. Inside an interrupt handler use Lib::Helper::TimePeriod::startFromISR(), Lib::Helper::TimePeriod::stopFromISR(), Lib::Helper::TimePeriod::elapsedFromISR() and Lib::Helper::TimePeriod::elapsedTimeFromISR() instead.

Measuring a delay

Lib::Helper::TimePeriod::stop writes the elapsed ticks only when the stopwatch was running, so check its return value before using the result.

#include <Lib/Helper/TimePeriod.hpp>
#include <Lib/RTOS/FreeRTOS/Task.hpp>
#include <Lib/RTOS/FreeRTOS/TickCounter.hpp>
#include <chrono>
#include <cstdint>
void timingExampleTask() {
using namespace std::chrono_literals;
Lib::Helper::TimePeriod timer;
timer.start();
// Simulate work or wait for 200 ms.
RTOS::Task::delay(RTOS::TickCounter::toTicks(200ms));
// Query the elapsed ticks and time without stopping.
[[maybe_unused]] const uint32_t elapsedTicks = timer.elapsed();
[[maybe_unused]] const std::chrono::milliseconds elapsedTime = timer.elapsedTime();
// Stop and read the elapsed ticks.
uint32_t measured = 0U;
if (timer.stop(measured)) {
// 'measured' holds the ticks elapsed since start.
}
// Reset the timer for reuse.
timer.reset();
}

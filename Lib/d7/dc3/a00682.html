Description

Lib::HAL namespace.

The Lib::HAL namespace encapsulates all Hardware Abstraction Layer functionality for the STM32-based embedded system library. It includes abstractions for GPIO pins, ADC ports, CAN communication, timers, backup RAM, and other peripherals.

Components within this namespace are designed to work seamlessly with FreeRTOS for multitasking and TouchGFX for user interface management.

◆ DriverDataDirection

enum class Lib::HAL::DriverDataDirection : uint8_t
strong

Driver data direction flags.

Represents the allowed directions of data flow for a driver. Use RX for receive-only behaviour, TX for transmit-only, and RX_TX for both.

Note
  • Values are defined as bitflags stored in an 8-bit unsigned integer.
  • RX_TX is the bitwise combination of RX and TX.
Enumerator
RX 

Receive-only direction.

TX 

Transmit-only direction.

RX_TX 

Both receive and transmit (RX | TX).

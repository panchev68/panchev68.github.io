Lib::BSP::EncoderPinsfinal

Description

Rotary encoder with a push button, reporting rotation and button changes as queued events.

The GPIO interrupt callback forwards every pin change to handlePinChangedEvent(); a task then takes the events with kbdhit(). Rotation steps are divided by the pulse divider before an event is queued, and the button is active low. The button hold time of the last press is kept for getButtonHoldPeriod().

Warning
Cannot share a program with Lib::HAL::GPIO::ExtInterrupt or Lib::BSP::EncoderTimer: the application defines HAL_GPIO_EXTI_Callback() for this class, and ExtInterrupt defines it too.

inlinenodiscardnoexcept

Reads the debounced button state by polling the pin.

Task context only: sleeps 1 ms between samples. The scan stops after four times 'stableSamples' attempts, so a bouncing or floating line cannot block the caller forever; the last sampled level is returned then.

Parameters

inlinenoexcept

Turns a GPIO pin change into an encoder event.

Call from the GPIO EXTI callback only, for every pin; pins that don't belong to this encoder are ignored, so several encoders can share one callback. The direction is decided when both channels have changed once.

Parameters

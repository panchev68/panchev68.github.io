class Lib::Helper::BitSet< N_BITS >

Wrapper for event bits used in FreeRTOS task notifications.

Provides a type-safe interface for managing event bits as a 32-bit mask, with helper methods for setting and clearing individual bits. Bits at or above N_BITS are always kept cleared. The type is trivially copyable and declares no destructor on purpose: a user-declared one, even defaulted, makes the class non-literal on this toolchain and would prevent a constexpr instance.

Description

template<ErrorKind T_ERROR>
class Lib::Errors::BasicDispatcher< T_ERROR >

Owns every constructed error and periodically scans it for state changes through an RTOS::TickClient.

One dispatcher exists per error type; Dispatcher is the one for the plain 'Error'. A custom error type derives from 'ErrorBase', makes its constructors private and befriends BasicDispatcher, which constructs it with a caption and a group.

'statusChangedHook' is invoked from the tick client's callback, in the timer service task, whenever an error becomes active, or when an error has been cleared and no error is active any more. Create the errors before start(): the registry is not guarded against being extended while a scan runs.

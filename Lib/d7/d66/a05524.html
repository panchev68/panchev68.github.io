Lib::HAL::SPIPort< DriverMode::IT >final

Description

Interrupt-driven (IT) specialization.

Handle lifecycle and the begin/end-transaction hooks come from SPIPortBase; the event group, start-then-wait transfers, abort(), HAL callback registration and DeviceManager wiring come from SPIPortAsync, shared with the DMA mode. This specialization only supplies the three HAL calls that start an interrupt-driven transfer.

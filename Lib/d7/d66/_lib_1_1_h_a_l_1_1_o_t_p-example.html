Lib::HAL::OTP

Program OTP memory: unlock, write, read, lock.

Demonstrates basic usage of Lib::HAL::OTP to access STM32 OTP memory: unlocking FLASH, writing a value, locking back, and validating by reading. Use with caution: OTP cells are one-time programmable and cannot be erased.

Example usage:
#include "Lib/HAL/OTP.hpp"
int main() {
auto &otp = Lib::HAL::OTP::instance();
const Lib::HAL::OTP::AddressType addr = Lib::HAL::OTP::beginAddr();
const uint32_t value = 0x12345678;
if (!otp.unlock()) { return -1; }
const bool ok = otp.write<uint32_t>(addr, value);
(void)otp.lock();
const uint32_t readBack = otp.read<uint32_t>(addr);
return (ok && readBack == value) ? 0 : -1;
}

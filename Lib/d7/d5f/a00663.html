Description

RTOS namespace.

Contains classes and utilities for Real-Time Operating System abstractions. This namespace provides C++ wrappers and utilities for FreeRTOS primitives, enabling type-safe and RAII-based resource management in embedded applications.

The RTOS namespace includes abstractions for:

  • Task management and scheduling
  • Synchronization primitives (mutexes, semaphores)
  • Inter-task communication (queues, message buffers)
  • Memory management utilities
  • Timing and delay functions

void RTOS::delay ( uint32_t duration)
inline

Delay execution for a specified number of milliseconds.

Pauses the current task for the specified duration in milliseconds, allowing the scheduler to switch to other ready tasks. The actual delay may be slightly longer due to task scheduling granularity.

Parameters
durationNumber of milliseconds to delay. A value of 0 performs a yield.
Note
Safe to call from task context only, not from ISR.
Other tasks with higher priority may prevent exact timing.

◆ yield()

void RTOS::yield ( )
inline

Yield the processor to another task.

Allows the FreeRTOS scheduler to immediately switch to another ready task with equal or higher priority. The current task enters the ready state and can be scheduled again when its priority warrants execution.

Note
Useful for cooperative multitasking and load balancing.
Safe to call from task context only, not from ISR.

28 /** TaskWorker base class.
29 *
30 * Base class for RTOS task workers that encapsulates task lifecycle management.
31 * This class provides a framework for creating RTOS tasks with a virtual task function interface.
32 * Derived classes must override the taskFunction() method to implement their specific task logic.
33 * The task is initialized with the provided configuration and automatically executes the taskFunction()
34 * when scheduled by the RTOS. This base class handles the mapping between the task callback and
35 * the virtual interface, allowing subclasses to focus on task implementation without concerning
36 * themselves with the underlying FreeRTOS task management details.
37 */
38 class TaskWorker {
39 public:
40 /** Configuration type alias for task configuration.

43 */
44 using Config = Task::Config;

47 *
48 * Initializes the TaskWorker with the specified task configuration.
49 * Creates the underlying Task object and binds the virtual taskFunction() method

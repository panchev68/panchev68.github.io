Lib::Helper::Convert::HexHelper

Converting values using HexHelper.

This example demonstrates how to use the HexHelper class for basic hexadecimal conversions, such as converting numeric values to ASCII hex characters and vice versa. It shows the usage of toAscii and fromAscii methods.

Example usage:
#include "HexHelper.hpp"
#include <iostream>
int main() {
// Convert a 4-bit value to ASCII hex
uint8_t value = 10;
char ascii = Lib::Helper::Convert::HexHelper::toAscii(value);
std::cout << "Hex ASCII for 10: " << ascii << std::endl; // Output: A
// Convert ASCII hex back to numeric value
uint8_t num = Lib::Helper::Convert::HexHelper::fromAscii('A');
std::cout << "Numeric value for 'A': " << static_cast<int>(num) << std::endl; // Output: 10
return 0;
}

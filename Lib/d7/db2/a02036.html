Lib::Digi::Core::Frame::Data

Description

Container for binary frame data and its type.

Holds a byte vector representing frame payload and a type field. Provides methods to assign raw memory and append integral values in big-endian byte order.

Note
Methods perform simple null/length checks for input pointers.

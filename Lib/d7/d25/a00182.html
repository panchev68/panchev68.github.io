Description

Frame0x09 class definition for Digi Core Queries.

This file defines the Frame0x09 class, which represents a frame for queue local AT command requests in the Digi Core library. The class encapsulates the frame ID, AT command, and parameters for constructing a data frame used in communication protocols.

It inherits from QueryBase and provides an operator to convert to Frame::Data for serialization.

Important dependencies include Frame::Data for data handling and QueryBase for base query functionality.

Note
Ensure parameters vector is populated correctly before conversion to avoid invalid frames.
Attention
This class is part of the Digi Core module and should be used in contexts requiring AT command queuing.

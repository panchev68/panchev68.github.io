Description

template<size_t T_COUNT>
class Lib::BSP::SK6812::Ring< T_COUNT >

The buffer is sized at compile time, so no heap allocation takes place and every LED slice stays valid for the ring's lifetime. Pass getData()/getSize() to the timer DMA transfer.

Template Parameters
T_COUNTnumber of LEDs in the ring.

Lib::Math::HammingCode Class Reference

Description

Encodes 16-bit data into a 21-bit codeword with 5 parity bits and decodes (with single-bit error correction) codewords back to data. All operations are compile-time evaluable (constexpr) for zero runtime overhead in constant expressions and lookup table generation.

constexpr bool Lib::Math::HammingCode::canCorrect ( uint32_t syndrome)
inlinestaticconstexpr

A syndrome of 0 indicates no error; a non-zero syndrome in the range [1, CODE_BITS] indicates a correctable single-bit error at that position. Syndromes outside this range are uncorrectable.

constexpr uint32_t Lib::Math::HammingCode::encode ( uint16_t value)
inlinestaticconstexpr

Maps 16 data bits into positions defined by DATA_POSITIONS and appends 5 parity bits at positions 1, 2, 4, 8, 16 to form a 21-bit codeword. Each parity bit covers a subset of bit positions in the codeword.

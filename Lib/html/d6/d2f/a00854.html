Lib::BSP::Display::Driver< Controller::ILI9341 > Class Reference

Description

Template specialization of the generic Driver class for the ILI9341 controller, managing LCD initialization, pixel transmission via DMA-driven SPI, and configuration of display parameters including rotation and backlight.

SerialPortRepeaterBase.hpp File Reference

USB serial port repeater with bidirectional USB device interface. More...

Description

This header defines the SerialPortRepeaterBase class which extends SerialPort to provide bidirectional communication bridging between UART and USB CDC (Communications Device Class). The class manages USB device initialization, line coding control, USB power detection, and provides virtual hook methods for customizing connection state signaling. It integrates with STM32 USB device middleware and FreeRTOS for robust USB serial communication.

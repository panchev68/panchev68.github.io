Lib::Digi::Core::ApiFrameBuffer Class Reference

Description

Manages a fixed-size buffer of 255 bytes with automatic bounds checking for data operations. Provides convenient methods for assigning data from vectors or raw pointers, appending data, clearing the buffer, and retrieving buffer contents. The buffer size is tracked automatically, and all operations validate buffer capacity before modifying data.

See also
Lib::Digi::Core for related buffer management utilities

Lib::Communication::Modbus::Slave Class Referencefinal

Description

Singleton that encapsulates the serial transport and provides methods to open, close, receive messages, and send responses using callback semantics for asynchronous message reception and processing.

Use init(SerialPortBase&) once to initialize the singleton with a serial port, then access via instance().

See also
https://docs.arduino.cc/learn/communication/modbus/#function-code

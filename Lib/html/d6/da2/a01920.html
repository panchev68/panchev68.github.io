Description

template<std::floating_point T_VALUE, typename T_INPUT = T_VALUE>
class Lib::Math::LinearInterpolation< T_VALUE, T_INPUT >

Template class for performing linear interpolation between data points with support for different input and output types. Supports up to 256 data points with fixed-size arrays for embedded system compatibility. Provides both fast lookup and smooth interpolation with compile-time type safety.

Template Parameters
T_VALUEfloating-point type for output values.
T_INPUTfloating-point type for input coordinates; defaults to T_VALUE.

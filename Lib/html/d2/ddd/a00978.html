Lib::BSP::EEPROM::I2C::M24C64W Class Referencefinal

Description

Concrete M24C64W EEPROM driver implementation.

The M24C64W is an 8192-byte (64K-bit) EEPROM with a 32-byte page size, addressed with 16-bit word addresses.

Derives from "Driver<M24C64W>" (CRTP), which provides all transfer validation, page-aligned writing and dispatch.

Lib::Digi::Core::Frame0x17::DstAddress Union Reference

Description

Provides dual access to the 64-bit destination address: either as a complete 64-bit value or as two 32-bit parts (MSB and LSB). Enables efficient storage and manipulation of remote device IEEE addresses with flexible access methods.

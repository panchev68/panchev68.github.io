Lib::Digi::Core::Module Class Reference

Description

This class FunctionRefs communication to ComDriver while simplifying the public interface for protocol-based queries and aggregating lifecycle/response events through callbacks. Module is the sole driver implementation, so ComDriver dispatches its notification hooks to it via CRTP rather than virtual functions.

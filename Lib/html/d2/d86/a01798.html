Description

template<typename T, size_t T_SIZE>
requires (std::default_initializable<T> && (T_SIZE > 0U))
class Lib::Helper::RingBuffer< T, T_SIZE >

Template parameter 'T' is the stored element type. 'T_SIZE' defines the maximum number of elements that can be held in the buffer and must be > 0.

Template Parameters
TElement type stored in the buffer; must be default-constructible.
T_SIZEMaximum capacity of the buffer; must be greater than 0.

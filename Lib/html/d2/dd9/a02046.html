Description

template<StorageLike T_STORAGE>
class Lib::System::Parameters< T_STORAGE >

This class provides a framework for storing and retrieving parameter data from persistent storage with automatic CRC16-based data integrity verification. It handles the life cycle of parameter operations including setup, reading, writing, and validation. When data corruption is detected, the class automatically restores parameters to their default state. Derived classes must implement the restoreByDefault() method; the storage backend is selected at compile time through 'T_STORAGE'.

This class is optimized for embedded systems with stack allocation of small buffers and efficient memory management.

◆ setup()

template<StorageLike T_STORAGE>
Status Lib::System::Parameters< T_STORAGE >::setup ( )
inline

Performs the initial setup operation by opening the storage device, reading the stored parameters, and validating data integrity using the CRC16 checksum. If validation fails (indicating data corruption or initialization), the parameters are automatically restored to their default values, then written back to storage. Finally, the validated data is copied into the user's data buffer.

Returns
Status::OK if setup succeeded, Status::ERROR if any operation failed.

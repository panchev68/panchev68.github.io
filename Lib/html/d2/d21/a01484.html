Lib::Ethernet::Port Class Reference

Description

The Port class encapsulates a 16-bit unsigned integer representing an Ethernet port number. It provides constructors, accessors, mutators, string conversion methods, and validation.

Role within the Ethernet module: Handles port configurations and communications.

Important design decisions: Uses RAII, provides implicit conversion to uint16_t for compatibility.

Note
Port values should be validated before use.

Lib::HAL::OSPIPortAsync< T_DERIVED > Class Template Reference

Description

template<typename T_DERIVED>
class Lib::HAL::OSPIPortAsync< T_DERIVED >

A transaction is a command() followed, when the command has a data phase, by one transmit() or receive() of exactly cmd.NbData bytes.

Template Parameters
T_DERIVEDMode specialization providing startTransmit(std::span<const uint8_t>) and startReceive(std::span<uint8_t>), both returning true once the HAL accepted the data phase.

template<typename Rep, typename Period>
bool Lib::HAL::OSPIPortAsync< T_DERIVED >::command ( OSPI_RegularCmdTypeDef & cmd,
std::chrono::duration< Rep, Period > timeout )
inlinenodiscardnoexcept

Task context only.

A command without a data phase runs over interrupt and is waited for here. A command with a data phase only configures the peripheral; the transfer starts with the following transmit() / receive().

FIX: The command used to be issued over interrupt unconditionally, but the HAL raises no interrupt for a command with a data phase (it only configures the registers), so such a command always ran into its timeout and failed. It is now configured synchronously, as the ST examples do before a DMA data phase.

Template Parameters

PeriodRatio type of the timeout.
Parameters

timeoutMaximum time to wait.
Returns
true on success, false on error or timeout.

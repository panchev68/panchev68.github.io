Lib::BSP::SK6812::TimerBuffer Class Reference

Description

Owns the contiguous array of timer compare words sent out by DMA, growing it as each LED binds its own slice while preserving the data already written.

◆ bind()

size_t Lib::BSP::SK6812::TimerBuffer::bind ( TimerData & timerData)
inline

Grows the array in place with 'realloc()' instead of allocating a new array and copying the old one over, so the buffer never needs twice its final size in RAM at once and previously written words are moved only when the allocator cannot extend the current block.

Returns the slice's word offset rather than a pointer, since this call may relocate the shared array: a pointer returned to an earlier caller would go dangling as soon as another LED binds afterward, while the offset of an already reserved slice stays valid for the buffer's lifetime.

Lib::BSP::FMEM::SPI::DriverBase< Derived > Class Template Reference

Description

template<typename Derived>
class Lib::BSP::FMEM::SPI::DriverBase< Derived >

'Derived' must implement 'readImpl()', 'writeImpl()', 'eraseChipImpl()' and 'eraseSectorImpl()' with the same signatures as the forwarding methods below; DriverBase dispatches to them through a static cast instead of a vtable. The base class references an externally owned SPI port wrapper, shared by every device on the same bus, and owns the NSS pin handle but does not manage device-specific protocol details.

RTOS::MessageBuffer

Minimal example demonstrating typical usage of the RTOS::MessageBuffer wrapper.

Minimal example demonstrating typical usage of the RTOS::MessageBuffer wrapper.Shows creating a message buffer, sending and receiving a small message from a task context. This example assumes FreeRTOS is running and that the wrapper is used from application tasks or ISRs. The example focuses on API usage and does not include full task setup boilerplate.

Note
The wrapper dispatches to ISR-safe FreeRTOS APIs automatically when called from an interrupt context.
Example usage:
#include "MessageBuffer.hpp"
#include <cstring>
using namespace RTOS;
void task_send_receive_example()
{
MessageBuffer mb;
// Create a 256-byte underlying message buffer.
if (!mb.open(256)) {
// handle error
return;
}
const char payload[] = "hello";
// Send from a task (blocks up to 100 ticks if necessary).
size_t sent = mb.send(payload, sizeof(payload), static_cast<MessageBuffer::TickType>(100));
// Prepare receive buffer and receive the message (blocks up to 100 ticks).
char recv[32] = {};
size_t received = mb.receive(recv, sizeof(recv), static_cast<MessageBuffer::TickType>(100));
// Use received data (note: 'received' contains the number of bytes copied).
if (received > 0) {
// null-terminate if expected to be a string
if (received < sizeof(recv)) recv[received] = '\0';
}
mb.close();
}

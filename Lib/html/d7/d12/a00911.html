Lib::BSP::Ethercat::PDI::LAN9252::Interface Class Referencefinal

Description

Encapsulates SPI and NSS pin operations with mutex protection for thread-safe communication. Composes (rather than inherits) the SPI port: 'Lib::HAL::SPIPort<DriverMode::IT>' is 'final' - matching the house convention shared by every mode specialization, since none of them are meant to be extended further - so it cannot serve as a base class here. Composition still keeps the raw port private, and callers can only reach the framed operations declared below, never a raw transfer that would bypass chip select and the bus mutex.

Lib::BSP::RFID::MFRC522< T_DERIVED > Class Template Reference

Description

template<typename T_DERIVED = void>
class Lib::BSP::RFID::MFRC522< T_DERIVED >

Manages hardware initialization, antenna control and a background polling task that detects cards and reports their UID. Every detected UID is routed through handleCardDetected(); its default implementation forwards to the callback bound via bindCardDetectionCallback(). A class deriving from MFRC522<T_DERIVED> passes itself as T_DERIVED and overrides handleCardDetected() to react without going through the callback; the override hides the base version in the derived class's own scope, so no explicit dispatch is needed at the call site.

Template Parameters
T_DERIVEDConcrete driver overriding handleCardDetected(), or void to use MFRC522 directly without an override.

Lib::Digi::API::Connection::Quality Class Referencefinal

Description

Every request/response cycle is one bit in a sliding window of the last WINDOW_SIZE cycles; the PDR over that window is the primary score. The filtered RSSI, mapped linearly from RSSI_STRONG (100 %) to RSSI_SENSITIVITY (0 %), scales the PDR score down by up to RSSI_WEIGHT percent, so a weakening signal lowers the result before packets get lost. The state follows the percent with hysteresis: down at once, up only after the better grade has held for STATE_UPGRADE_DELAY.

In scanner mode every reset starts a SCANNER_SETTLE_TIME period whose samples are ignored, and onUpdate fires once, when the window is filled with fresh samples.

Thread safety: onExchange() and update() run in the application task, onRssi() in the receiver task; clear(), the mode setters and the getters are safe from any task. Cross-task data goes only through atomics and is applied inside update().

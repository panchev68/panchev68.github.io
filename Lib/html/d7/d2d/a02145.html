Lib::Helper::TimeZone

Demonstrates constructing a Lib::Helper::TimeZone, updating its properties and converting a local calendar date/time to UTC minutes since epoch using convertLocalToUtcMinutes.

Demonstrates constructing a Lib::Helper::TimeZone, updating its properties and converting a local calendar date/time to UTC minutes since epoch using convertLocalToUtcMinutes. The example shows basic error handling for invalid input.

The example runs in task or main context; it does not require the RTOS. Use the returned value of -1 to detect conversion errors (invalid date or mktime failure).

#include "Lib/Helper/TimeZone.hpp"
#include <cstdint>
void timezoneExample() {

const time_t epochOffsetSeconds = 0;
const int32_t utcMinutes = tz.convertLocalToUtcMinutes(2026, 5, 11, 12, 0, epochOffsetSeconds);
if (utcMinutes == -1) {
// handle conversion error (invalid date or mktime failure)
} else {
// utcMinutes now contains minutes since epoch in UTC
(void)utcMinutes; // example: use for logging or further calculations
}
// Mutate the zone display name and offset if needed
Lib::Helper::TimeZone mutableTz = tz; // copy for demonstration
mutableTz.setName("Central Europe");
mutableTz.setOffsetMinutes(120); // adjust offset to +120 minutes as an example
// Re-run conversion with modified offset if application logic requires it

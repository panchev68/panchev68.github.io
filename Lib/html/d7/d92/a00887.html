Lib::BSP::SPIPort Class Referenceabstract

Description

Defines the contract for SPI implementations, providing methods to manage port lifecycle, perform full-duplex and half-duplex data transfers, control chip select signals, and access the underlying SPI hardware handle.

Performs a full-duplex or half-duplex bidirectional transfer where data is transmitted on the MOSI line while simultaneously receiving data on the MISO line. The source and destination buffers may have different sizes; when the smaller buffer is exhausted, the transfer continues with dummy data.

destinationSizenumber of bytes to receive.

Returns

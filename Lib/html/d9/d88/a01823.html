Lib::Helper::crc8 Class Referencefinal

Description

Create an instance with a byte span and obtain the CRC by converting the instance to uint8_t. The type is a trivially copyable, non-owning view; the viewed bytes must outlive it. It declares no destructor on purpose: a user-declared one, even defaulted, makes the class non-literal on this toolchain.

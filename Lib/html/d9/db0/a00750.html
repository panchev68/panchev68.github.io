◆ isElapsed()

bool Lib::Digi::Core::isElapsed ( const RTOS::Timeout & timeout)
inlinenodiscardnoexcept

The Digi stack was written against a timeout whose check treated a disabled or never-set timeout as elapsed, e.g. to start polling at once or to skip a settle period. RTOS::Timeout::isExpired() is false for a disabled timeout, so this restores that meaning in one place.

Parameters
timeoutTimeout to test.
Returns
true if timeout is disabled or its duration has elapsed.

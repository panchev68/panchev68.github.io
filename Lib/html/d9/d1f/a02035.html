Lib::System::HardwareVersion Class Reference

Description

This class extends VersionBase to provide hardware-specific version handling. It supports version representation as both numeric values (via uint32_t) and human-readable strings (via a fixed, NUL-terminated buffer), with transparent type conversion allowing the object to be used directly in contexts requiring either format. Derives from VersionBase via CRTP, re-exposing the protected base members as public through using-declarations.

VersionString Lib::System::VersionBase< HardwareVersion >::toString ( ) const
inlinenodiscardconstexprnoexcept

The major field is unpadded and the minor and sub-version fields are zero-padded to two digits, widening to three when the value needs them. Digits are produced by hand rather than through printf, which would pull in formatting machinery this target has no use for.

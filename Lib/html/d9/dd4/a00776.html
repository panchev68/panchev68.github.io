Lib::BSP::INA219< T_MODE > Class Template Referencefinal

Description

template<Lib::HAL::DriverMode T_MODE>
class Lib::BSP::INA219< T_MODE >

Provides synchronous helpers to read bus voltage, shunt voltage and current. Binds to an I2C port in any 'Lib::HAL::DriverMode' - every mode's 'masterTransmit'/'masterReceive' blocks the caller until completion or timeout, so the driver logic itself stays mode-agnostic.

Template Parameters
T_MODETransfer mode of the bound 'Lib::HAL::I2CPort' instance.

FunctionRef.hpp File Reference

Non-owning delegate modelled on C++26 std::function_ref, without heap, RTTI or virtual dispatch. More...

Description

Binds a free function, an object method or any callable object through a type-erased trampoline selected at bind time. Supports the const and noexcept signature qualifiers of std::function_ref. Unlike the standard type it can be empty (default constructor, isBound(), reset()) and is equality comparable, which optional callbacks and MulticastDelegate rely on. An instance is two pointers wide.

Lib::SolarControl::MPPT Class Reference

Description

Maintains reference parameters, computes coefficients from those parameters and updates a voltage setpoint based on new measurements. The type stays a literal type - no destructor is declared and the estimator is a non-owning 'FunctionRef' rather than a heap-allocating 'std::function' - so an instance can be built in a constant expression.

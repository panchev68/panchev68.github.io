constexpr PortString Lib::Ethernet::Port::toString ( uint16_t value)
inlinestaticnodiscardconstexprnoexcept

Converts a port value to its decimal digits.

The digits are returned by value in a fixed, NUL-terminated buffer. A "std::string_view" would dangle: the only thing it could point at is a temporary that dies with the return expression.

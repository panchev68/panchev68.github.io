◆ resetChip()

bool Lib::BSP::Ethercat::PDI::LAN9252::Base::resetChip ( )
inlinenodiscard

Drives the reset pin low for a short period and polls the device until the expected chip identifier is returned or a timeout expires. The poll yields between attempts so lower priority tasks keep running while the chip boots.

Returns
'true' if reset and verification succeeded, 'false' otherwise.
Postcondition
chipState is set to READY on success or ERROR on failure.

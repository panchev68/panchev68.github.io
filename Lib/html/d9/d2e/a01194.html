Lib::Digi::API::Service::ChannelScanner Class Reference

Description

ChannelScanner advances through a predefined channel list at a fixed interval and writes the selected channel value using the provided Parameters instance. Scanning is suspended on every update while an active Connection is established, to avoid overriding an explicit channel choice.

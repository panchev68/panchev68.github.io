Lib::BSP::Thermometer::OneWire::DS18B20 Class Reference

Description

1-Wire device driver for the Maxim/Dallas DS18B20 temperature sensor.

The Dallas 1-Wire protocol (reset/presence, bit write and read time slots) is bit-banged directly on one GPIO pin configured as open-drain for the whole transaction: driving the pin low pulls the bus low, and releasing it lets the external pull-up bring the line high. The pin never switches to input mode, so no "HAL_GPIO_Init" call sits inside the timing-critical path. Slot timing uses "Lib::Helper::Delay::microseconds()" and the scratchpad readback is validated with "Lib::Helper::crc8". The bus is level-shifted to the 5 V sensor side; the open-drain logic is the same either way.

Only one device per bus is supported: every command is addressed with Skip ROM, and ROM search/match is not implemented.

The conversion resolution is selectable through "Config::resolution", default 12 bit. A lower resolution shortens the conversion from 750 ms (12 bit, 0.0625 C steps) down to 94 ms (9 bit, 0.5 C steps), and with it the time the sensor draws its conversion current. "open()" writes the resolution to the configuration register in the scratchpad and keeps TH and TL. It is not copied to EEPROM, so it survives only while the sensor stays powered. Every resolution, 12 bit included, is written and read back, so the sensor's power-on value is never assumed.

◆ readTemperatureCelsius()

std::optional< float > Lib::BSP::Thermometer::OneWire::DS18B20::readTemperatureCelsius ( )
inlinenodiscard

Trigger a temperature conversion and read back the result.

Issues a bus reset, a Skip ROM, a Convert T, waits out the worst-case conversion time of the configured resolution, then reads back and CRC-validates the scratchpad. The undefined low bits of a reduced-resolution result are masked off.

Returns
Measured temperature in degrees Celsius, or "std::nullopt" on a missing device or a failed CRC.

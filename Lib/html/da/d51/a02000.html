bool RTOS::Mutex::lock ( TickType timeout = WAIT_FOREVER)
inlinenodiscardnoexcept

The mutex must already be open via open(); calling this while closed returns 'false' without attempting to create the underlying handle, since lazily creating a synchronization primitive from within itself is not thread-safe.

Lib::SolarControl::PerturbAndObserve Class Reference

Description

The controller perturbs the voltage setpoint by a configurable step size and observes power changes to track the maximum power point. Designed for use on MCUs with float arithmetic, and kept a literal type so a controller can be built in a constant expression.

Note
Small power changes below 'powerThreshold' are ignored as noise.

Description

This header defines version classes for managing firmware and hardware version information, including parsing version strings, converting to numeric representations, and formatting version output with optional date/time information. The Version class provides a base class for common version functionality and specialized Firmware and Hardware subclasses for specific versioning needs in the embedded system.

Lib::Errors::Observer Class Reference

Description

Constructing from an existing 'Group' filters by that external, caller-owned group. Constructing from a caption instead creates and owns a new 'Group' for the lifetime of this observer. With neither, every active error in the 'Dispatcher' is observed.

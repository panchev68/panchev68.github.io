Lib::Helper::Convert::Bcd Class Referencefinal

Description

Contains static utilities for converting BCD values to decimal strings, single ASCII digits and numeric (decimal) values. Every conversion rejects a malformed nibble with a defined sentinel rather than producing a silently wrong result; debug builds additionally assert.

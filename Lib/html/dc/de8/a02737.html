XCOM frame protocol implementation used by Lib::XCOM. More...

Description

Implements framing, escaping and CRC16 checksum calculation used to build and parse XCOM frames transported over a byte stream. Both directions work on caller-supplied buffers and never allocate, so a frame can be assembled or decoded from an interrupt-driven receive path.

Lib::BSP::Thermometer::OneWire::DS18B20 Class Reference

Description

1-Wire device driver for the Maxim/Dallas DS18B20 temperature sensor.

Bit-banged on one open-drain GPIO pin, addressed with Skip ROM only (single device per bus, no ROM search). "Config::resolution" (default 12 bit) is written to the scratchpad by "open()" and read back, never assumed; TH/TL are kept, but the setting is not copied to EEPROM so it is lost on power-down.

◆ readRom()

std::optional< std::array< uint8_t, ROM_SIZE > > Lib::BSP::Thermometer::OneWire::DS18B20::readRom ( )
inlinenodiscard

Read the 8-byte ROM code (family code, serial number, CRC) with Read ROM.

Only valid with a single device on the bus, same assumption as the rest of this class: with more than one device, every one answers at once and the bytes collide. Useful to check write/read bit-level communication independently of the scratchpad path (the family code of a genuine DS18B20 is "GENUINE_FAMILY_CODE").

Returns
ROM bytes, family code first and CRC last, or "std::nullopt" on a missing device or a failed CRC.

◆ readTemperatureCelsius()

std::optional< float > Lib::BSP::Thermometer::OneWire::DS18B20::readTemperatureCelsius ( )
inlinenodiscard

Trigger a temperature conversion and read back the result.

Issues a bus reset, a Skip ROM, a Convert T, waits out the worst-case conversion time of the configured resolution, then reads back and CRC-validates the scratchpad. The undefined low bits of a reduced-resolution result are masked off.

Returns
Measured temperature in degrees Celsius, or "std::nullopt" on a missing device or a failed CRC.

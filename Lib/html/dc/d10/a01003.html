Lib::BSP::RFID::Interface Class Reference

Description

Provides a small transport abstraction around a platform SPI port and exposes open/close/send/receive operations used by higher-level code.

See also
https://www.nxp.com/docs/en/data-sheet/MFRC522.pdf

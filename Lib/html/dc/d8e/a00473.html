TimTimebase.hpp File Reference

Configures an event-driven, hardware periodic Timebase interface using STM32 Timers. More...

Description

Eliminates CPU polling overhead by mapping the hardware Update Interrupt (UIF) through the central DeviceManager to unblock application threads via Task Notifications.

Unlike the other timer wrappers this header does not define the HAL callback: CubeMX already generates HAL_TIM_PeriodElapsedCallback() in main.c whenever a timer is the HAL timebase, which is always the case with FreeRTOS. Forward to this driver from that function's user-code section instead:

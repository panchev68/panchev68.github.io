RTOS::Task Class Referencefinal

Description

An owning instance creates the native task in start() and deletes it in stop() or on destruction. A non-owning instance, obtained from current() or the Handle constructor, only references a task created elsewhere and never deletes it. The entry callable is copied into a small in-place buffer, so it must be trivially copyable and fit ENTRY_CAPACITY bytes, which covers capturing lambdas such as [this] and FunctionRef bindings.

RTOS::MutexGuard

Demonstrates scope-based mutex locking with RTOS::MutexGuard to ensure automatic unlock.

Demonstrates scope-based mutex locking with RTOS::MutexGuard to ensure automatic unlock.Shows creating and opening a Mutex, using MutexGuard to protect a critical section, and checking the guard state after construction. The example uses real project APIs and expects the underlying FreeRTOS kernel to be initialized before use.

Note
This example runs in a task context and blocks when Mutex::WAIT_FOREVER is used.
Example usage:
#include "Lib/RTOS/Mutex.hpp"
#include "Lib/RTOS/MutexGuard.hpp"
void exampleTask(void * /*unused*/) {
RTOS::Mutex m(RTOS::Mutex::Type::NORMAL);
if (!m.open()) {
// handle creation failure
return;
}
{
RTOS::MutexGuard guard(m); // locks mutex on construction
if (!guard.isLocked()) {
// lock failed - handle accordingly
} else {
// Critical section protected by 'm'
// perform shared resource access here
}
} // guard destroyed here; mutex unlocked if it was locked
m.close();
}

Lib::HAL::ADCPort< DriverMode::DMA > Class Referencefinal

Description

The primary contract of this mode is scanning one or more regular-group channels straight into a caller-owned destination buffer via 'start(destination)'; 'getValue()' (inherited from the base) remains available for a single-value peek at the most recent conversion.

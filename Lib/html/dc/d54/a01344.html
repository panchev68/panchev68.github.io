Lib::Digi::Core::Frame::Header Struct Reference

Description

A packed structure representing the frame header format with a single-byte start delimiter for frame synchronization and a two-byte length field stored in big-endian byte order. The structure is memory-packed to maintain a fixed 3-byte layout without padding.

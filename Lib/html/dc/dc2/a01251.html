Lib::Digi::Core::Frame::Data Class Reference

Description

Provides methods for data assignment and appending, supporting both raw byte sequences and typed values (8-bit through 64-bit integers); multi-byte values are converted to network byte order (big-endian).

The payload is stored inline rather than heap-allocated: XBee API1 frames are capped at 'MAX_SIZE' bytes by the protocol's 16-bit length field as enforced by 'ComDriver::MAX_FRAME_SIZE', so no frame ever needs more.

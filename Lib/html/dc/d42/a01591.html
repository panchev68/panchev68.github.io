Lib::HAL::DACPort< DriverMode::DMA > Class Referencefinal

Description

Owns the callback registration and event-group synchronization infrastructure needed to observe DAC DMA completion, half-completion, error, and underrun notifications, since only DMA transfers actually raise these HAL callbacks.

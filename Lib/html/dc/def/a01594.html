Lib::HAL::OTP Class Referencefinal

Description

The region is memory mapped, so reads are plain loads; writes go through the flash controller and must be bracketed by unlock() and lock().

◆ write()

bool Lib::HAL::OTP::write ( uint32_t address,
uint32_t value )
inlinenodiscardnoexcept

The word must be word-aligned and inside the region. Because the area cannot be erased, the new value may only clear bits that are currently set; a value that would need a zero bit to return to one is rejected.

Parameters

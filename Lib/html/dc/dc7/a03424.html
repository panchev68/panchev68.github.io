TickCounter example

Demonstrates reading the tick count, measuring elapsed ticks, and converting between ticks and time units.

Conversions to ticks round up, so a wait is never shorter than requested, and saturate at portMAX_DELAY. RTOS::TickCounter::get() is safe from both task and ISR context.

Note
All APIs are static; RTOS::TickCounter is non-instantiable.
See also
RTOS::TickCounter, RTOS::Task::delay
Example usage:
#include <Lib/RTOS/FreeRTOS/Task.hpp>
#include <Lib/RTOS/FreeRTOS/TickCounter.hpp>
#include <chrono>
using namespace std::chrono_literals;
void timingTask() noexcept {
const RTOS::TickCounter::TickType start = RTOS::TickCounter::get();
RTOS::Task::delay(150ms);
const RTOS::TickCounter::TickType elapsed = RTOS::TickCounter::getElapsedTicksSince(start);
const std::chrono::milliseconds elapsedTime = RTOS::TickCounter::toDuration(elapsed);
const RTOS::TickCounter::TickType timeoutTicks = RTOS::TickCounter::toTicks(2s);
static_cast<void>(elapsedTime);
static_cast<void>(timeoutTicks);
}

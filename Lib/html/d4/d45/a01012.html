Color Class Reference

Description

Every constant packs an 8 bit red, green, blue and white channel into a single 32 bit value, laid out as white shifted 24 bits, blue shifted 16 bits, green shifted 8 bits, red in the low byte.

See also
[HTML Color Codes] https://htmlcolorcodes.com/

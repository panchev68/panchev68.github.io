RTOS::MutexGuard

Demonstrates scope-based mutex locking with RTOS::MutexGuard to ensure automatic unlock.

Demonstrates scope-based mutex locking with RTOS::MutexGuard to ensure automatic unlock.Shows creating and opening a Mutex, using MutexGuard to protect a critical section, both with an infinite and with a std::chrono timeout, and checking the guard state after construction. The example runs in a task context and expects the FreeRTOS scheduler to be running; a mutex must never be locked or unlocked from an ISR.

Note
The first guard blocks indefinitely, since it uses the default Mutex::WAIT_FOREVER timeout.
Example usage:
#include <Lib/RTOS/FreeRTOS/Mutex.hpp>
#include <Lib/RTOS/FreeRTOS/MutexGuard.hpp>
#include <chrono>
using namespace std::chrono_literals;
void exampleTask(void * parameters) {
static_cast<void>(parameters);
RTOS::Mutex mutex(RTOS::Mutex::Type::NORMAL);
if (!mutex.open()) {
return; // Creation failed: out of heap.
}
{
const RTOS::MutexGuard guard(mutex); // Locks on construction, waits forever.
if (guard.isLocked()) {
// Critical section protected by 'mutex'.
}
} // Guard destroyed here; the mutex is unlocked only if it was locked.
if (const RTOS::MutexGuard guard(mutex, 10ms); guard) {
// Lock acquired within 10 ms.
} else {
// Timed out: the critical section is not protected and nothing is unlocked.
}
mutex.close();
}

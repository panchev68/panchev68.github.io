W25Q128JVSIQ.hpp File Reference

Quad-SPI (OCTOSPI) driver for the Winbond W25Q128JVSIQ 128 Mbit device. More...

Description

The '...SIQ' ordering option ties the Quad Enable bit permanently to 1 in hardware (IO2/IO3 always enabled, '/HOLD' disabled), so unlike the generic Winbond quad-capable parts this driver never reads or writes Status Register-2 to turn Quad mode on. Provides read/write/erase operations with page programming and sector/block erasure over the OCTOSPI peripheral in regular (1-1-4 program, 1-4-4 read) command mode; device discovery via JEDEC ID occurs during initialization. See also 'Lib::BSP::W25Q128JVSIQ' (FlashMemory/SPI/) for the same device driven over a plain 4-wire SPI bus instead.

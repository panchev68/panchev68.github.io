◆ command()

bool Lib::HAL::OSPIPort< DriverMode::BLOCKING >::command ( OSPI_RegularCmdTypeDef & cmd,
std::chrono::milliseconds timeout )
inlinenodiscardnoexcept

Sets up the instruction/address/data phases for the transaction that follows; a command with a data phase ('cmd.DataMode' not HAL_OSPI_DATA_NONE) must be followed by a matching 'transmit()' or 'receive()' call.

Parameters
cmdFully populated command descriptor; 'cmd.NbData' drives the byte count of the following 'transmit()'/'receive()' call.
timeoutDuration to wait for the command phase to complete.
Returns
true on success, false on error, timeout, or a null handle.

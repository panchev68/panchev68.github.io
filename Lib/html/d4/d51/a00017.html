DigitalPeripheralBase.hpp File Reference

Base support for digital peripheral I/O interfacing over SPI-backed port expanders. More...

Description

DigitalPeripheralBase provides input and output port abstractions that communicate with external GPIO expanders via SPI. It implements a small task-driven update loop that can operate in sequential or parallel update modes and exposes hooks for pre/post update processing.

Lib::HAL::ADCPort< DriverMode::BLOCKING > Class Referencefinal

Description

A full blocking single-shot read is 'start(); const uint32_t value = poll(timeout); stop();' - this mirrors how a blocking regular-group conversion genuinely works on this hardware: 'HAL_ADC_PollForConversion()' spins on the end-of-conversion flag itself rather than waiting on an interrupt.

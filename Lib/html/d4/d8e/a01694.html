Lib::Helper::BitSet< N_BITS > Class Template Referencefinal

Description

template<size_t N_BITS = 32U>
class Lib::Helper::BitSet< N_BITS >

This class provides a type-safe interface for managing event bits as a 32-bit mask, with helper methods for setting and clearing individual bits. It is designed to be used with FreeRTOS task notification APIs.

Template Parameters
N_BITSMaximum number of bits managed by the type (1..32).

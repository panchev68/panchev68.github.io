Lib::Helper::JaggedArrayBase< T_ELEMENT > Class Template Reference

Description

template<typename T_ELEMENT>
class Lib::Helper::JaggedArrayBase< T_ELEMENT >

The container never takes ownership of the pointees; clients are responsible for their lifetime. Copying and moving only duplicate or transfer the pointer list, never the pointees. The destructor is not virtual (no vtable pointer per instance), so a derived class must not be destroyed through a JaggedArrayBase pointer.

Lib::BSP::Display::DriverBase Class Reference

Description

Every concrete driver is used through its own compile-time type (e.g. Lib::BSP::Display::ILI9341), never through a DriverBase pointer, so this base declares no virtual functions. Derived drivers inherit it privately and are free to define their own handleTransferCompleteEvent() and canTransferBlock(), calling the base implementation explicitly when they need it, since dispatch here is static, not virtual.

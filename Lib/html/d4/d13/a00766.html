RTOS Namespace Reference

C++20 RAII wrappers over FreeRTOS primitives. More...

Description

Provides type-safe, non-copyable classes for tasks, queues, semaphores, mutexes, timers, event groups and tick helpers, so application code reaches for these wrappers instead of raw FreeRTOS calls.

Lib::Digi::Core::Frame0x17 Class Reference

Description

Represents an XBee API frame type 0x17 for querying or setting AT command parameters on a remote device identified by its 64-bit IEEE address. The conversion operator builds the serialized Frame::Data for transmission. Query results are received in response frame type 0x97 (Remote AT Command Response).

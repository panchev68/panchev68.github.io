PowerManager.hpp File Reference

Power management component providing low-power mode transitions for FreeRTOS tickless idle. More...

Description

Coordinates system entry into low-power modes and provides mechanisms to register callbacks that prepare peripherals for sleep and restore their state upon waking up.

Stop mode needs a clock that keeps running while the core is stopped, so the manager drives an LPTIM through 'Lib::HAL::LPTimer'. It therefore targets the STM32U5 family and every other part that carries an LPTIM peripheral. On a device without one - STM32F407 among them - the guard below compiles the whole component away, and the application simply runs without tickless idle.

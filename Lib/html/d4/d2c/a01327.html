Lib::Digi::API::UserProtocol< Derived > Class Template Reference

Description

template<typename Derived>
class Lib::Digi::API::UserProtocol< Derived >

The derived class may hide any of handleInputsUpdate(), handleGetParameters(), handleSetParameters() and handleOutputsUpdate() with the same signature; if it declares them private it must befriend UserProtocol<Derived>.

◆ startTimeoutInterrupt()

bool Lib::HAL::LPTimer::startTimeoutInterrupt ( uint32_t timeoutMs)
inlinenodiscard
Parameters
timeoutMsThe desired timeout duration in milliseconds.
Returns
'true' if successfully armed, 'false' otherwise.

< Prescaler divider values corresponding to HAL macros.

The prescaler macros are used to configure the LPTIM peripheral's clock division. The order of these macros corresponds to the order of the prescaler divider values in PRESCALER_DIVIDERS. This mapping ensures that the correct prescaler setting is applied based on the calculated divider needed to achieve the desired timeout duration within the hardware's tick range.

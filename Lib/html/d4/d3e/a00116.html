Voltmeter.hpp File Reference

Voltmeter sensor base class and types for ADC-based voltage measurement. More...

Description

Provides the Voltmeter class, a base abstraction for voltage measurement through an ADC peripheral with hardware DMA support. It integrates raw ADC values, applies linear interpolation, and dispatches notifications when the voltage changes. Derive from it for a specific voltmeter implementation.

Lib::Errors::ObserverBase< Derived, T_ERROR > Class Template Reference

Description

template<typename Derived, ErrorKind T_ERROR = Error>
class Lib::Errors::ObserverBase< Derived, T_ERROR >

CRTP foundation reading active errors from the "Dispatcher", optionally restricted to a single "Group".

Constructing from an existing "Group" filters by that external, caller-owned group. Constructing from a caption instead creates and owns a new "Group" for the lifetime of this observer. With neither, every active error in the "Dispatcher" is observed. A derived class replaces the filter by defining its own "bool matches(const Error &) const", which hides the default one; it can still call "ObserverBase::matches()" for the group filter.

Lib::Helper::DateTime Class Referencefinal

Description

The type contains nested Date and Time types and helpers to pack the combined value into a 32-bit compact representation and to convert to tm for interoperability with C runtime functions.

◆ pack()

constexpr uint32_t Lib::Helper::DateTime::pack ( const DateTime & dateTime)
inlinestaticnodiscardconstexprnoexcept

The packed layout uses exactly 32 bits: seconds (6), minutes (6), hours (5), day (5), month (4) and a year delta (6) relative to 'Date::FIRST_YEAR'. This limits the packable year range to ['Date::FIRST_YEAR', 'Date::FIRST_YEAR' + 63].

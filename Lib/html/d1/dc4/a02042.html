Lib::System::Storage< T_DERIVED > Class Template Reference

Description

template<typename T_DERIVED>
class Lib::System::Storage< T_DERIVED >

This class defines the compile-time contract for storage implementations that handle reading and writing parameter data to persistent storage media. A concrete backend derives from 'Storage<T_DERIVED>' and implements 'openImpl()', 'closeImpl()', 'readImpl()' and 'writeImpl()' as public members; dispatch happens through 'static_cast' to 'T_DERIVED' rather than through a virtual table, so specific storage backends such as flash memory or EEPROM cost no runtime indirection.

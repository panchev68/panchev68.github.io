Lib::Digi::API::ClientBase< Derived > Class Template Reference

Description

template<typename Derived>
class Lib::Digi::API::ClientBase< Derived >

Derived must provide handleIncomingMessage(const std::vector<uint8_t> &) returning bool, handleOutgoingMessage(std::vector<uint8_t> &) and handleTaskTickEvent(); if they are private it must befriend ApplicationBase<Derived> and ClientBase<Derived>. Replies carry no frame ID, so the module sends no transmit status for them.

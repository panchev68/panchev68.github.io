Description

template<typename T_DERIVED>
class Lib::Digi::API::Service::ServiceBase< T_DERIVED >

open() and close() only request a transition; update(), called from the application task, performs it and calls the hooks initialize(), process() and tearDown(). The base supplies empty hooks, so a service only declares the ones it needs; a private hook requires the service to befriend its base. Services are always used through their concrete type, which resolves every call at compile time instead of through a vtable.

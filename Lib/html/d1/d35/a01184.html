FunctionRef< Ret(Args...)> Class Template Reference

Description

template<typename Ret, typename... Args>
class FunctionRef< Ret(Args...)>

Stores an opaque context pointer together with a static trampoline function selected at bind time, so calling through the reference never requires heap allocation or virtual dispatch. A default-constructed 'FunctionRef' is unbound; calling 'invoke()' or 'operator()' on it is undefined behavior.

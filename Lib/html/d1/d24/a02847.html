W25Q128JVSIQ.hpp File Reference

Quad-SPI (OCTOSPI) driver for the Winbond W25Q128JVSIQ 128 Mbit device. More...

Description

The ...SIQ ordering option ties the Quad Enable bit permanently to 1 in hardware (IO2/IO3 always enabled, /HOLD disabled), so unlike the generic Winbond quad-capable parts this driver never touches Status Register-2 to enable Quad mode. Provides read/write/erase with page programming and sector/block erasure over OCTOSPI in regular command mode (1-1-4 program, 1-4-4 read); device discovery via JEDEC ID happens during initialization. See also Lib::BSP::W25Q128JVSIQ (FlashMemory/SPI/) for the same device driven over a plain 4-wire SPI bus instead.

HAL_OSPI_MODULE_ENABLED is not defined anywhere in this project's EWARM/Core/Inc/stm32f4xx_hal_conf.h (which only carries a commented-out HAL_QSPI_MODULE_ENABLED), and the target part, STM32F407xx, has no OCTOSPI peripheral at all - that HAL module belongs to the F7/H7/L4+ family. This header is currently dead code on this target; it compiles only when built against a HAL package/MCU that actually defines the macro.

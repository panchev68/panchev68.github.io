Hex.hpp File Reference

Hex conversion utilities for various integer types. More...

Description

This file provides template specializations for converting unsigned integer types ('uint8_t', 'uint16_t', 'uint32_t', 'uint64_t') to hexadecimal strings and decimal ASCII representations. It includes methods for converting numbers to hex strings, packed BCD values, and formatted decimal strings, optimized for minimal RAM usage. Depends on 'HexHelper.hpp' for low-level hex operations and ASCII conversion.

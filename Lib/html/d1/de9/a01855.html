Description

template<typename T = float>
class Lib::Math::Pid< T >

This template class implements a PID control algorithm suitable for various control applications with user-defined numeric types (e.g., float, double, fixed-point types). The controller provides anti-windup protection for the integral term, adjustable sample time, configurable output limits, and selectable control direction.

Template Parameters
TThe numeric type used for calculations (default: float). Can be any floating-point or fixed-point numeric type.

◆ compute()

template<typename T = float>
T Lib::Math::Pid< T >::compute ( T setpoint,
T input )
inline

Calculates the proportional, integral, and derivative terms based on the current error, applies anti-windup to the integral accumulator, limits the output to configured bounds, and updates the internal state. In manual mode, returns the current output without modification. The derivative term uses the change in input (backward difference) to prevent derivative kick from setpoint changes.

Parameters
setpointThe desired target value.
inputThe current measured value.
Returns
The computed controller output value, clamped within the configured output limits.
Precondition
autoMode must be set to true for automatic operation; otherwise the function returns the previous output without computation.

◆ setMode()

template<typename T = float>
void Lib::Math::Pid< T >::setMode ( bool automatic)
inline

When transitioning from manual to automatic mode, initializes the integral accumulator with the current output value and marks the first automatic cycle for proper derivative handling. When in manual mode, the controller returns the previously set output without computation.

Parameters
automatictrue to enable automatic mode, false to switch to manual mode.

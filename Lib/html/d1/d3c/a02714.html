StreamBuffer examples

RTOS::StreamBuffer wraps a FreeRTOS stream buffer: a byte FIFO that carries a continuous stream of bytes from one writer to one reader.

The writer can be a task or an ISR. Unlike a queue, the buffer does not keep message boundaries: a reader gets whatever bytes are buffered, up to its own buffer size.

Rule Detail
Single writer/reader Two tasks blocked in send(), or two in receive(), trip a kernel assertion.
Trigger level A blocked reader wakes when at least trigger level bytes are buffered, or on timeout.
ISR variants Use sendFromISR() / receiveFromISR() inside interrupts; they never block.
Static capacity A buffer created with createStatic() holds one byte less than its storage.
Ownership The wrapper is move-only and deletes the native buffer in its destructor or close().

Dynamic creation

open() allocates the buffer from the FreeRTOS heap (configSUPPORT_DYNAMIC_ALLOCATION == 1).

#include <RTOS.hpp>
RTOS::StreamBuffer stream;
void init() {
// 128 bytes capacity, wake the reader as soon as 1 byte is available.
if (!stream.open(128U, 1U)) {
// FreeRTOS heap exhausted or invalid parameters.
}
}

Static creation

createStatic() uses caller-provided storage, so no heap is needed. The storage and the control structure must outlive the stream buffer.

#include <RTOS.hpp>
#include <array>
namespace {
std::array<uint8_t, 257U> storage; // 256 usable bytes
StaticStreamBuffer_t control;
RTOS::StreamBuffer stream;
}
void init() {
// Wake the reader once 16 bytes are buffered.
const bool ok = stream.createStatic(storage, control, 16U);
assert(ok);
}

Task to task

A producer task writes text and a consumer task reads it. Timeouts can be passed as ticks or as std::chrono durations.

#include <RTOS.hpp>
#include <array>
#include <chrono>
#include <string_view>
using namespace std::chrono_literals;
RTOS::StreamBuffer stream;
void producer() {
while (true) {
constexpr std::string_view text = "Hello from producer\r\n";
// Blocks up to 100 ms while the buffer has no free space.
const size_t sent = stream.send(text, pdMS_TO_TICKS(100));
if (sent < text.size()) {
// Timeout: only part of the text was written.
}
vTaskDelay(pdMS_TO_TICKS(500));
}
}
void consumer() {
std::array<uint8_t, 32U> rx{};
while (true) {
// Blocks until at least the trigger level is buffered or 1 s elapses.
const size_t received = stream.receive(rx.data(), rx.size(), 1s);
if (received == 0U) {
continue; // timeout, nothing received
}
process(std::span(rx.data(), received));
}
}

ISR to task (UART receive)

The typical use case: a UART interrupt writes each received byte and a task handles the byte stream. Pass higherPriorityTaskWoken and call portYIELD_FROM_ISR() so the reader runs immediately after the ISR.

#include <RTOS.hpp>
#include <array>
extern UART_HandleTypeDef huart2;
namespace {
uint8_t rxByte;
std::array<uint8_t, 129U> rxStorage;
StaticStreamBuffer_t rxControl;
RTOS::StreamBuffer rxStream;
}
extern "C" void HAL_UART_RxCpltCallback(UART_HandleTypeDef * huart) {
if (huart != &huart2) {
return;
}
BaseType_t higherPriorityTaskWoken = pdFALSE;
(void) rxStream.sendFromISR(&rxByte, 1U, higherPriorityTaskWoken); // byte is dropped if the buffer is full
(void) HAL_UART_Receive_IT(&huart2, &rxByte, 1U);
portYIELD_FROM_ISR(higherPriorityTaskWoken);
}
void uartReaderTask() {
const bool ok = rxStream.createStatic(rxStorage, rxControl, 1U);
assert(ok);
(void) HAL_UART_Receive_IT(&huart2, &rxByte, 1U);
std::array<uint8_t, 64U> line{};
while (true) {
const size_t n = rxStream.receive(line.data(), line.size(), portMAX_DELAY);
handleBytes(std::span(line.data(), n));
}
}

Several writers

A stream buffer supports only one writer at a time. When several tasks write, serialize them with a mutex and use a zero timeout inside the lock, so no task blocks in send() while it holds the mutex.

RTOS::Mutex writeMutex; // opened at startup
RTOS::StreamBuffer logStream;
void log(std::string_view text) {
RTOS::MutexGuard guard(writeMutex);
if (logStream.send(text) < text.size()) {
// Buffer full: the rest of the text is dropped.
}
}

Moving ownership

RTOS::StreamBuffer makeStream() {
RTOS::StreamBuffer s;
(void) s.open(64U, 1U);
return s; // handle moves out, no copy
}
RTOS::StreamBuffer owner = makeStream();
RTOS::StreamBuffer other = std::move(owner); // owner is closed afterwards

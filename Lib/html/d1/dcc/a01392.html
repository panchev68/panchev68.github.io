Lib::Digi::Core::Frame0x08 Class Reference

Description

Represents an XBee API frame type 0x08 for querying or setting AT command parameters on the local device. Parameter changes apply immediately. The conversion operator builds the serialized Frame::Data for transmission. Query results are received in response frame type 0x88 (Local AT Command Response).

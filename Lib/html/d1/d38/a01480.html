Lib::Ethernet::Node Class Reference

Description

The Node class encapsulates an IP address and a port number, representing a network endpoint. It provides constructors for initialization and a method to set the address and port.

Role of the type within the module or system: This class is fundamental to network communication in the Ethernet library, used for defining destinations or sources in network operations.

Important design decisions or considerations: Members are mutable to allow modifications even in const contexts, which is useful for caching or lazy initialization in embedded systems.

Note
Use this class to represent any network node in the system.

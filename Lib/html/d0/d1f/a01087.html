Lib::BSP::Voltmeter< T_DERIVED > Class Template Reference

Description

template<typename T_DERIVED = void>
class Lib::BSP::Voltmeter< T_DERIVED >

Reads raw ADC values periodically from a configured regular ADC channel via a single-slot DMA scan, applies moving-average filtering through integration, converts the integrated value to voltage using linear interpolation, and calls handleValueChanged() when the voltage changes. Registered with the DeviceManager through DeviceManager::DeviceBase, which drives handleTickEvent() from the shared tick timer.

The measurement cycle is controlled by a configurable update period, and the filtering is performed with a fixed window size of five samples. A class deriving from Voltmeter<T_DERIVED> passes itself as T_DERIVED and overrides handleValueChanged() to perform custom actions when the voltage changes; the override hides the base version in the derived class's own scope, so no explicit dispatch is needed at the call site.

◆ handleValueChanged()

template<typename T_DERIVED = void>
void Lib::BSP::Voltmeter< T_DERIVED >::handleValueChanged ( float value)
inlinenoexcept

Called from handleTickEvent() when a new voltage value, after integration and interpolation, differs from the previous measurement. This default implementation does nothing; T_DERIVED overrides it to perform custom actions such as updating a display or logging the change. Not meant to be called directly.

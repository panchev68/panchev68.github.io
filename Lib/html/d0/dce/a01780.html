Lib::Helper::CityHash Class Referencefinal

Description

Provides constant evaluation for text input and a convenient implicit conversion to uint32_t for use as a compact fingerprint of binary data. The class declares no destructor on purpose: a user-declared one, even defaulted, makes it non-literal on this toolchain and would prevent a constexpr instance.

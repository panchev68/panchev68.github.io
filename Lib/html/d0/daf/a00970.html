Lib::BSP::Thermometer::DTH::Base Class Referenceabstract

Description

Provides core functionality for reading temperature and humidity data from DHT sensors. Inherits from RTOS::TaskWorker to integrate with the real-time operating system. Manages hardware timer capture for precise timing of the one-wire communication protocol and handles interrupt-driven data reception.

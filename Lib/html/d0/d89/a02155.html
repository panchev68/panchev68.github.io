RTOS::TickCounter

Example demonstrating common TickCounter utilities: reading the tick count, computing elapsed ticks, and converting between milliseconds and ticks.

Example demonstrating common TickCounter utilities: reading the tick count, computing elapsed ticks, and converting between milliseconds and ticks. The example shows a simple timing measurement performed inside a task context using RTOS::Task::delay for portability.

The example assumes the FreeRTOS scheduler is running. Use the provided conversion helpers to avoid manual arithmetic errors when working with timeouts and delays.

Note
All APIs are static; TickCounter is non-instantiable.
See also
RTOS::TickCounter, RTOS::Task::delay
Example usage:
#include "Lib/RTOS/TickCounter.hpp"
#include "Lib/RTOS/Task.hpp"
void timingTask() {
// Record start tick
const RTOS::TickCounter::TickType start = RTOS::TickCounter::get();
// Do some work and delay 150 ms
RTOS::Task::delay(RTOS::TickCounter::msToTicks(150U));
// Compute elapsed ticks since start and convert to milliseconds
const auto elapsedTicks = RTOS::TickCounter::getElapsedTicksSince(start);
const uint32_t elapsedMs = RTOS::TickCounter::ticksToMs(elapsedTicks);
// Use elapsedMs for logging, checks or timeout adjustments
(void)elapsedMs; // suppress unused-variable warnings in example
}

Description

Transport-agnostic HTTP/1.1 client.

"Client<T_TRANSPORT>" builds requests and parses responses over any caller-supplied byte-stream transport (Ethernet, a GSM data-mode link, ...) satisfying the "HttpTransport" concept; "WolfSSLTransport" wraps a raw transport in a wolfSSL TLS session to request HTTPS.

Lib::BSP::IS62WV51216< Derived > Class Template Reference

Description

template<typename Derived>
class Lib::BSP::IS62WV51216< Derived >

Implements thread-safe read/write over a contiguous memory-mapped SRAM region. The post-write hook onMemoryChanged() is dispatched at compile time via CRTP — Derived may shadow it to react to writes without any virtual-dispatch overhead.

Derived must inherit publicly, because the base converts itself to Derived to reach the hook. A shadowing onMemoryChanged() must be public as well, or Derived must declare 'friend class IS62WV51216<Derived>;' so the base may call it.

Call open() before the first transfer: the mutex has no handle until then and every read()/write() reports failure rather than touching the region unprotected.

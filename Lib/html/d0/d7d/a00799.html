Lib::BSP::EncoderPins Class Reference

Description

Manages a rotary encoder with two channels (CLK and DT) and a push button, providing event-based updates for rotation and button press/release. Features include pulse division (debouncing), reverse polarity, and button hold period measurement. All pin change events are handled via GPIO interrupt callbacks.

This enumeration defines the available communication modes that can be used to configure the Digi device for different types of data transmission and reception protocols.

Enumerator
TRANSPARENT 

Transparent serial mode for direct data pass-through communication.

API1 

API mode 1 for structured frame-based communication.

API2 

API mode 2 for enhanced structured frame-based communication.

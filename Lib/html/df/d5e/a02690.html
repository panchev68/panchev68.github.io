# StreamBuffer Class Documentation
## Overview
`RTOS::StreamBuffer` (`StreamBuffer.hpp`) is a move-only RAII wrapper over a FreeRTOS stream buffer: a byte stream from
**exactly one writer to exactly one reader**, either of which may be a task or an interrupt.
## Rules inherited from FreeRTOS
- **Single writer, single reader.** Two tasks blocked in `send()` (or two in `receive()`) trip a kernel assertion.
Several writers or readers must serialize their calls themselves (e.g. with `RTOS::Mutex`) and use a zero timeout.
- **Trigger level.** A reader blocked in `receive()` wakes once at least the trigger level is buffered, or when its
timeout expires, and then returns whatever is available. The level must be in `1 .. getCapacity()`.
- **Static storage.** A static buffer holds `size - 1` bytes (one byte distinguishes full from empty), and `size` must
exceed 4 bytes. Supply one byte more than the payload you need to buffer.
- **ISR variants** never block and report through `higherPriorityTaskWoken`; initialize it to `pdFALSE` and pass it to
`portYIELD_FROM_ISR()` before leaving the interrupt.
## Public API
### Lifecycle
- `bool open(size_t bufferSize, size_t triggerLevel)` — heap allocation (`configSUPPORT_DYNAMIC_ALLOCATION`).
- `bool createStatic(uint8_t * storage, size_t size, StaticStreamBuffer_t & buffer, size_t trigger)` — static allocation.
- `bool createStatic(std::span<uint8_t> storage, StaticStreamBuffer_t & buffer, size_t trigger)` — same, sized by the span.
- `void close()`, `bool isOpen() const`, `bool reset()`.
### Send (task context)
- `size_t send(const void * source, size_t length, TickType blockTime)`
- `size_t send(const void * source, size_t length, std::chrono::duration timeout)`
- `size_t send(std::string_view sv, TickType blockTime)` — sends the characters without the terminating NUL.
- `size_t send(const Range & range, TickType blockTime)` — any contiguous, sized range of trivially copyable
elements (`std::array`, `std::span`, `std::vector`, ...); sends `size() * sizeof(element)` bytes.
### Send (ISR context)
- `size_t sendFromISR(const void * source, size_t length, BaseType_t & higherPriorityTaskWoken)`
- `size_t sendFromISR(const Range & range, BaseType_t & higherPriorityTaskWoken)`
### Receive
- `size_t receive(void * dest, size_t maxLen, TickType blockTime)`
- `size_t receive(void * dest, size_t maxLen, std::chrono::duration timeout)`
- `size_t receive(T_RANGE && dest, TickType blockTime)` / `receive(T_RANGE && dest, std::chrono::duration timeout)` — any writable contiguous range (`std::span`, `std::array`, typed spans)
- `size_t receiveFromISR(void * dest, size_t maxLen, BaseType_t & higherPriorityTaskWoken)`
### State queries and management
- `size_t getBytesAvailable() const`, `size_t getSpacesAvailable() const`
- `bool isEmpty() const` (also `true` when closed), `bool isFull() const` (`false` when closed)
- `size_t getCapacity() const`, `uint8_t getUtilizationPercent() const`
- `bool setTriggerLevel(size_t level)`
- `Handle getHandle() const`, `operator Handle() const`
`std::chrono` timeouts are rounded up to whole ticks; durations that do not fit the tick range wait indefinitely.
## Usage Example
### Task context
```cpp
RTOS::StreamBuffer buffer;
if (!buffer.open(256, 4)) { // 256-byte buffer, reader wakes at 4 bytes
return;
}
(void) buffer.send("Hello", 0U); // 5 bytes, no NUL
uint8_t rxBuffer[32];
using namespace std::chrono_literals;
const size_t received = buffer.receive(rxBuffer, sizeof(rxBuffer), 100ms);
```
### ISR context
```cpp
void SomeISR() {
BaseType_t higherPriorityTaskWoken = pdFALSE;
(void) buffer.sendFromISR(data, length, higherPriorityTaskWoken);
portYIELD_FROM_ISR(higherPriorityTaskWoken);
}
```
### Static allocation
```cpp
static std::array<uint8_t, 257> storage; // holds 256 bytes
static StaticStreamBuffer_t control;
RTOS::StreamBuffer buffer;
(void) buffer.createStatic(storage, control, 4);
```

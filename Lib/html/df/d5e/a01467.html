Lib::Errors::Error Class Reference

Description

Instances are created and owned exclusively by 'Dispatcher::createError()'; the constructors are private and 'Dispatcher' is a friend. A raised error moves 'DISABLE' -> 'NO_ERROR' -> 'ACTIVE' -> 'CLEARED' -> 'NO_ERROR' as 'enable()'/'set()'/'clear()'/'reset()' are called.

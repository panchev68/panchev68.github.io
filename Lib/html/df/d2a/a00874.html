Lib::BSP::EEPROM::I2C::Driver< T_Device > Class Template Reference

Description

template<typename T_Device>
class Lib::BSP::EEPROM::I2C::Driver< T_Device >

Provides shared functionality for reading from and writing to I2C-based EEPROM chips: transfer validation, page-aligned write handling with timing delays, and 8-bit/16-bit addressed transfer primitives. Concrete drivers derive from Driver<T_Device> and implement readImpl()/writeImpl() to select the addressing width appropriate for their chip, without incurring virtual dispatch overhead.

Lib::Digi::Core::Frame0x8b Class Referencefinal

Description

Wire layout after the frame type byte: frame ID (1), 16-bit destination address or reserved (2), transmit retry count (1), delivery status (1), discovery status (1). A truncated frame leaves every member zero.

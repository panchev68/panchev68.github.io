Lib::BSP::Thermometer::DTH::Driver< Type::DTH22 > Class Reference

Description

Specializes the Base template for DHT22, implementing the one-wire protocol timing and data frame processing specific to DHT22 sensors. Provides temperature and humidity readings with diagnostic counters for monitoring data reception and validation health.

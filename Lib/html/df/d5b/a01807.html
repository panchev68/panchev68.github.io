Description

Provides constexpr byte swapping for integral types, reading swapped values from unaligned memory and in-place buffer reversal.

template<std::integral T>
constexpr T Lib::Helper::SwapBytes::swap ( T value)
inlinestaticnodiscardconstexprnoexcept

Supported sizes are 1, 2, 4 and 8 bytes. For 1-byte types, the original value is returned.

Delegates to 'std::byteswap()' (C++23 '<bit>') when the standard library ships it; falls back to a manual, constexpr-friendly bit-twiddling implementation otherwise, since this project targets C++20.

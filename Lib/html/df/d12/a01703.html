Lib::HAL::Rtc Class Referencefinal

Description

The tick service needs the RTC_Alarm_IRQn interrupt enabled in the NVIC (CubeMX); HAL_RTC_SetAlarm_IT() configures the EXTI line itself.

◆ stopTickService()

void Lib::HAL::Rtc::stopTickService ( )
inlinenoexcept

Task context only.

Called from another task, it wakes the worker and waits until it has left its loop on its own, so the worker is never deleted in the middle of a HAL call or of the callback. Called from inside the callback, it only requests the stop; the worker exits once the callback returns. The callback must therefore not block on the task calling this.

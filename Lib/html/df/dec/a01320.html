Lib::Digi::Core::ComDriver< Derived > Class Template Reference

Description

template<typename Derived>
class Lib::Digi::Core::ComDriver< Derived >

Manages UART transmit and receive ports, a reset pin and a background task that accumulates incoming bytes into framed messages processed by the project's Protocol implementation. 'Derived' supplies the emitXxx() notification hooks; dispatch to them is resolved at compile time via CRTP instead of a vtable.

Lib::HAL::USBDevicePort< DriverMode::IT > Class Referencefinal

Description

Explicit specialized variant driving interrupt (IT) transfers.

Everything interrupt-driven comes from "USBDevicePortAsync", shared with the DMA mode. This specialization only supplies the two HAL calls that start a transfer. The FIFO of the controller is filled by the interrupt handler.

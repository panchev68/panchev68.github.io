◆ toBcd()

constexpr uint32_t Lib::Helper::Convert::Hex< uint32_t >::toBcd ( uint32_t number)
inlinestaticconstexpr

Each decimal digit of the input occupies a nibble in the returned value. A 32-bit result can only hold 8 packed decimal digits; the input is limited to 'BCD_MAX_VALUE' accordingly.

Parameters
number32-bit value to convert, must not exceed 'BCD_MAX_VALUE'.
Returns
BCD encoded 32-bit value.

LPTimer.hpp File Reference

Low-power timer peripheral driver for STM32 architectures. More...

Description

This class provides a hardware abstraction layer for the LPTIM peripheral, managing initialization, timeout interrupts, and event synchronization using RTOS primitives.

The driver targets the STM32U5 family and every other part whose HAL ships the modern LPTIM interface, which it relies on for 'LPTIM_OC_ConfigTypeDef', 'HAL_LPTIM_OC_ConfigChannel()' and the per-channel state array. Parts without an LPTIM peripheral - STM32F407 among them, where the whole F4 line except F410/F413/F423 lacks it - compile this header away, so including it unconditionally is safe.

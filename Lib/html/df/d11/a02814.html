CRC-protected parameter block persisted through a compile-time selected storage backend. More...

Description

Provides a generic framework for keeping a parameter structure in persistent storage with CRC16 integrity checking and automatic restoration of defaults when the stored image is corrupted or missing. Both the storage backend and the default-value policy are bound through CRTP, so neither costs a virtual table, and the storage image lives inside the object instead of on the heap.

RTOS::Task

Demonstrates creating an RTOS::Task, using notifications for event synchronization, and clean shutdown.

Demonstrates creating an RTOS::Task, using notifications for event synchronization, and clean shutdown. The example shows a worker task waiting for an event bit and a controller that signals the worker.

The example assumes the FreeRTOS scheduler is running and that task notifications are enabled in the FreeRTOS configuration. It uses real project APIs and follows the library patterns for setup, start, notification and stop.

Note
This example runs in a task context. Use portENTER_CRITICAL/portEXIT_CRITICAL only when interacting with non-thread-safe resources; notifications shown here are ISR-safe and scheduler-safe.
See also
RTOS::Task::Notify, RTOS::Task::Config
Example usage:
#include "Lib/RTOS/Task.hpp"
// Worker bit used for synchronization
constexpr RTOS::Task::EventBits WORKER_BIT = RTOS::Task::EventBits(0x01);
// Controller task or main thread signals the worker via notification bits
void controllerThread(RTOS::Task & worker) {
// Ensure the worker has been created
if (!worker.isCreated()) {
// start the worker with default configuration if necessary
RTOS::Task::Config cfg("worker");
worker.setup(cfg);
worker.start([&worker]() {
// Worker entry: wait for event and perform work
const auto awaited = RTOS::Task::EventBits(0x01);
if (worker.waitForEvent(awaited, /*timeout=*/portMAX_DELAY)) {
// perform protected work here
}
});
}
// Signal the worker to proceed
worker.fireEvent(WORKER_BIT);
// Optionally change priority
worker.priority.set(RTOS::Task::Priority::Level::NORMAL);
// Later, stop the worker cleanly
worker.stop();
}

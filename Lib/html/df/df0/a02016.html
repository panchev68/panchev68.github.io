RTOS::SemaphoreBase< Derived > Class Template Reference

Description

template<typename Derived>
class RTOS::SemaphoreBase< Derived >

The derived class creates the native handle in its own open() and stores it in semaphoreHandle; this base owns it from then on and deletes it on close() or destruction. Construction, destruction and moves are protected, so the base can only exist as a subobject of a derived semaphore.

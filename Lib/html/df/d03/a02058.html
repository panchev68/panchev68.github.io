Lib::System::System Class Referencefinal

Description

This class aggregates all system-level information and functionality including:

  • Tracking of last reset state and reason
  • Persistent configuration parameters (production date, sale date, runtime config)
  • Device identification (serial number, firmware version, hardware version)
  • System reset and restart functionality

The System class is instantiated with firmware and hardware version information at startup and provides unified access to system state throughout the application lifetime. All members are public to allow direct access from application code.

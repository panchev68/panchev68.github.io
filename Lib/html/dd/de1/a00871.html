Lib::BSP::EEPROM::I2C::M24C64W Class Referencefinal

Description

Extends Driver<M24C64W> with M24C64W-specific geometry, selecting 16-bit addressing for its larger address space. All transfer validation, page-aligned writing and dispatch is provided by the base class.

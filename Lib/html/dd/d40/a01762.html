Lib::Helper::Delay Class Referencefinal

Description

The implementation uses the Data Watchpoint and Trace (DWT) cycle counter to perform cycle-accurate delays. These functions are suitable for short delays where sleeping the CPU or using RTOS tasks/timers is not efficient.

MulticastDelegate< Ret(Args...), T_CAPACITY > Class Template Reference

Description

template<typename Ret, typename... Args, size_t T_CAPACITY>
requires (T_CAPACITY > 0U)
class MulticastDelegate< Ret(Args...), T_CAPACITY >

Subscribers are stored contiguously in a std::array and invoked in registration order. Return values of the individual subscribers are discarded, matching event-style usage. A subscriber must not add or remove subscribers of the same instance while it is being invoked, since removal shifts the list and would skip the next entry.

Lib::BSP::EncoderTimer Class Reference

Description

Detects bidirectional rotation from the timer encoder interface and handles an associated push-button with push/release/hold semantics. Rotation is derived from the counter register and the hardware direction bit, so it stays correct across a counter wraparound; button events are delivered through a FreeRTOS queue to allow safe consumption from task context.

bool Lib::BSP::EncoderTimer::open ( )
inlinenodiscard

Configures the timer in encoder mode, opens the internal button queue, and binds the button external interrupt callback. The current counter value is latched so the first read() cannot report a spurious rotation.

Returns
'true' on successful initialization, 'false' on failure.
Precondition

◆ read()

EventCode Lib::BSP::EncoderTimer::read ( )
inlinenodiscard

Drains a pending button transition first, then samples the timer counter, and finally reports a hold once the button has stayed down past the hold threshold. If nothing happened the function returns 'EventCode::NONE'.

Returns
EventCode representing the detected event, or 'EventCode::NONE' if none.
Precondition

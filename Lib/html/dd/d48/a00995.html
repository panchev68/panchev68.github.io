Lib::BSP::RFID::Chipset Class Reference

Description

Implements register operations and command execution. Provides helper routines used by higher-level MFRC522 interfaces and holds a reference to the parent IO interface. Stores the initial receiver gain used for RF configuration.

◆ readUID()

bool Lib::BSP::RFID::Chipset::readUID ( std::array< uint8_t, UID_LENGTH > & uid)
inline

The PICC's cascade level 1 anticollision response is 5 bytes: 4 UID bytes followed by a BCC checksum byte (the XOR of those 4 bytes). The BCC is verified but not written to 'uid'.

Parameters
[out]uidDestination for the 4 UID bytes; only written when the read succeeds.
Returns
'true' on success with 'uid' populated; 'false' on failure or a BCC checksum mismatch, in which case 'uid' is left unmodified.

◆ transceive()

bool Lib::BSP::RFID::Chipset::transceive ( const uint8_t * txData,
uint8_t txLength,
uint8_t * rxData,
uint8_t rxCapacity,
uint8_t & rxLength,
uint8_t txLastBits = 0U,
std::chrono::milliseconds timeout = std::chrono::milliseconds{30} )
inline

Flushes the FIFO, writes txData, triggers a Transceive command, waits 'timeout' for the exchange to complete, then reads back whatever the PICC returned. This is the correct path for talking to a card: it goes through the chip's FIFO_DATA/COMMAND-register sequence, unlike a raw SPI transaction with 'Interface::sendReceive()' (which only accesses the MFRC522's own register interface).

Parameters
txDataCommand bytes to transmit; may be 'nullptr' only when txLength is 0.
txLengthNumber of bytes to transmit (clamped to MAX_MULTI_BYTE_COUNT).
rxDataBuffer to receive the response; may be 'nullptr' only when rxCapacity is 0.
rxCapacityCapacity of rxData in bytes.
[out]rxLengthNumber of bytes actually written into rxData.
txLastBitsNumber of valid bits in the last transmitted byte (0 means all 8); use 7 for a REQA/WUPA short frame.
timeoutTime to wait for the PICC's response before reading back the FIFO.
Returns
'true' if the exchange completed without a protocol, parity or collision error.

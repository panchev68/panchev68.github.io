Lib::BSP::Thermometer::DTH::Base< T_DERIVED > Class Template Reference

Description

template<typename T_DERIVED>
class Lib::BSP::Thermometer::DTH::Base< T_DERIVED >

Provides timer/GPIO-driven one-wire communication and task scheduling for reading DHT sensor data. The background task launched by start() dispatches each cycle to T_DERIVED::taskEntry() at compile time, with no vtable involved.

Template Parameters
T_DERIVEDConcrete driver implementing taskEntry(). Must publicly inherit from Base<T_DERIVED>.

Lib::Canbus::Service< Mode::SERVER > Class Referenceabstract

Description

Template specialization for the Service class operating in SERVER mode. Provides methods for receiving client requests, sending responses to specific nodes, and discovering available clients through the scanning mechanism. The server extends ServiceBase with virtual callback methods that derive classes can override for custom request processing and client discovery notifications.

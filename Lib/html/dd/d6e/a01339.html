Lib::Digi::Core::ComDriver< T_DERIVED > Class Template Reference

Description

template<typename T_DERIVED>
class Lib::Digi::Core::ComDriver< T_DERIVED >

Sends are serialized by a mutex; a receiver task assembles incoming bytes into frames and dispatches them. T_DERIVED supplies the message boundary hooks signalBeginMessageSend(), signalEndMessageSend(), signalBeginMessageReceive() and signalEndMessageReceived(), resolved at compile time.

Template Parameters
T_DERIVEDConcrete driver implementing the message boundary hooks.

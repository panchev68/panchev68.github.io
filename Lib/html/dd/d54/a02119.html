Lib::System::Storage< T_DERIVED > Class Template Reference

Description

template<typename T_DERIVED>
class Lib::System::Storage< T_DERIVED >

A concrete backend derives from Storage<T_DERIVED> and implements openImpl(), closeImpl(), readImpl() and writeImpl() as public members. Dispatch happens through a static_cast to T_DERIVED rather than through a virtual table, so backends such as flash memory or EEPROM cost no runtime indirection.

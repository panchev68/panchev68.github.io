RTOS::MessageBuffer

Minimal example demonstrating typical usage of the RTOS::MessageBuffer wrapper.

Minimal example demonstrating typical usage of the RTOS::MessageBuffer wrapper.Shows creating a message buffer, sending and receiving a small message from a task context. This example assumes FreeRTOS is running and focuses on API usage, without full task setup boilerplate.

Note
Message buffers support a single writer and a single reader. Every message costs its payload plus a 4-byte length header, so a 256-byte buffer carries messages of up to getMaxMessageSize() bytes (252). From an interrupt use the sendFromISR() and receiveFromISR() variants; the overloads taking a higherPriorityTaskWoken flag leave the portYIELD_FROM_ISR() call to the caller.
Example usage:
#include <Lib/RTOS/FreeRTOS/MessageBuffer.hpp>
using namespace std::chrono_literals;
void taskSendReceiveExample()
{
RTOS::MessageBuffer mb;
// Create a 256-byte underlying message buffer.
if (!mb.open(256)) {
// handle error
return;
}
const char payload[] = "hello";
// Send from a task (blocks up to 100 ticks if necessary).
const size_t sent = mb.send(payload, sizeof(payload), static_cast<RTOS::MessageBuffer::TickType>(100));
// Prepare receive buffer and receive the message (blocks up to 100 ms).
char recv[32] = {};
const size_t received = mb.receive(recv, sizeof(recv), 100ms);
// 'received' is the payload size, or 0 on timeout or if 'recv' was too small for the message.
if (received > 0 && received < sizeof(recv)) {
recv[received] = '\0';
}
mb.close();
}

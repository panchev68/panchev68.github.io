RTOS::EventGroup Class Referencefinal

Description

The usable width is 24 bits with 32-bit ticks and 8 bits with configUSE_16_BIT_TICKS, because FreeRTOS keeps the top 8 bits of EventBits_t for its own control flags. The FromISR set and clear operations are deferred to the timer daemon task, so they need configUSE_TIMERS and INCLUDE_xTimerPendFunctionCall, and they can fail when the timer command queue is full.

Lib::Canbus Namespace Reference

CAN bus client/server service layer built on 'Lib::HAL::CAN'. More...

Description

Mirrors the HAL 'DriverMode' shape but for roles: client and server 'Service' specializations share a non-template 'ServiceBase' owning the CAN port, an RTOS task, an RX queue and diagnostics counters.

enum class Lib::Canbus::Mode : uint8_t
strong

Defines two distinct modes of operation for CAN bus services: CLIENT mode for initiating communication and SERVER mode for responding to requests. This enumeration is used as a template parameter to specialize the Service class for different communication patterns.

Enumerator
CLIENT 

Client mode: initiates requests and processes responses from the server.

SERVER 

Server mode: processes requests from clients and sends responses.

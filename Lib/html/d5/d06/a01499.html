Lib::Ethernet::UserProtocol Class Reference

Description

The UserProtocol class provides methods for building and parsing Ethernet user protocol messages, handling commands, options, and payloads. It supports callback mechanisms for message processing and activity updates. The class is designed for embedded systems, ensuring efficient memory usage and real-time performance.

Role of the type within the module or system: This class is central to the Ethernet communication module, facilitating protocol-level interactions between devices.

Important design decisions or considerations: Uses virtual callbacks for extensibility, packed structures for efficient serialization, and error enums for robust error handling.

Note
Derived classes should implement the virtual callback methods to handle specific protocol events.

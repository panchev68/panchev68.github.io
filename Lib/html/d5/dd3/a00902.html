Description

template<Lib::HAL::DriverMode T_MODE>
class Lib::BSP::INA219< T_MODE >

Driver for the INA219 high-side current and power monitor.

Implements the big-endian 16-bit register layout over I2C, with a per-channel offset and polarity correction applied to the measured current. Every register access is a single I2C transaction (pointer write plus repeated-start read), so no device pointer state is kept on the host. Each access blocks the caller until completion or timeout, so the driver logic is mode-agnostic. Not thread-safe: use each instance from one task.

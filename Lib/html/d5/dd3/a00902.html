Lib::BSP::Ethercat::PDI::LAN9252::Interface Class Referencefinal

Description

Composes rather than inherits the SPI port, since Lib::HAL::SPIPort<DriverMode::IT> is final; keeping it private also means callers can only reach the framed operations below, never a raw transfer that bypasses chip select and the bus mutex.

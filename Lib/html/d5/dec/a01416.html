Lib::Digi::Core::ResponseEvents Class Reference

Description

Manages event callbacks for all supported XBee response frame types using a singleton pattern. Allows decoupled event handling across the application. Client code subscribes to events by assigning callback functions to the public member variables. Thread-safe access to the singleton instance via the instance() method.

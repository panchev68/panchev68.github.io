MulticastDelegate< Ret(Args...), Capacity > Class Template Reference

Description

template<typename Ret, typename... Args, size_t Capacity>
class MulticastDelegate< Ret(Args...), Capacity >

Subscribers are stored in a 'std::array' sized by 'Capacity' and invoked in registration order. Return values from individual subscribers are discarded, matching typical event-style usage; the signature's return type is still validated at compile time through the 'FunctionRef' it is built on.

Template Parameters
RetReturn type of each bound subscriber.
ArgsParameter types of each bound subscriber.
CapacityMaximum number of subscriber delegates (defaults to 4).

Lib::HAL::SPIPortAsync< T_DERIVED > Class Template Reference

Description

template<typename T_DERIVED>
class Lib::HAL::SPIPortAsync< T_DERIVED >

CRTP foundation for the interrupt-driven SPI modes.

Owns everything the two modes would otherwise duplicate: the RTOS event group, the start-then-wait transfer sequence, abort(), HAL callback registration and DeviceManager wiring. A mode specialization only supplies the three HAL calls that start a transfer ("startTransmit()", "startReceive()" and "startTransmitReceive()").

Template Parameters
T_DERIVEDMode specialization providing "startTransmit(std::span<const uint8_t>)", "startReceive(std::span<uint8_t>)" and "startTransmitReceive(std::span<const uint8_t>, std::span<uint8_t>)", each returning "true" once the HAL accepted the transfer.

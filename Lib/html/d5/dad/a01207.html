Lib::Digi::API::ApplicationBase< Derived > Class Template Reference

Description

template<typename Derived>
class Lib::Digi::API::ApplicationBase< Derived >

Derived must provide initialize(), update() and handleTaskTickEvent() (all void, no parameters); if they are private it must befriend ApplicationBase<Derived>. The public API is Pausable. The XBee receiver task feeds received payloads and delivery statuses through two single-slot queues, so the application task always sees the newest one.

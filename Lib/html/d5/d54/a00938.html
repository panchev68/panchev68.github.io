Lib::BSP::FMEM::SPI::DriverBase< T_DERIVED > Class Template Reference

Description

template<typename T_DERIVED>
class Lib::BSP::FMEM::SPI::DriverBase< T_DERIVED >

T_DERIVED must implement readImpl(), writeImpl(), eraseChipImpl() and eraseSectorImpl() with the same signatures as the forwarding methods below; DriverBase dispatches to them through a static cast instead of a vtable. The base class references an externally owned SPI port wrapper, shared by every device on the same bus, and owns the NSS pin handle but does not manage device-specific protocol details.

Lib::Crypto::WolfSSH Class Referencefinal

Description

RAII guard for wolfSSH's global library state.

Exactly one instance must exist, constructed before any other 'WolfSSH*' class is used and outliving all of them; construct it once at startup, e.g. alongside "Lib::System::System".

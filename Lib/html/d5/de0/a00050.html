EncoderTimer.hpp File Reference

Hardware encoder driver using a timer peripheral in encoder mode. More...

Description

Implements rotary encoder handling on STM32 timers configured in encoder mode and integrates an external push-button with hold detection. The timer counter is sampled on every read() call, while button transitions arrive through an external interrupt and are buffered in a FreeRTOS queue for safe processing from application tasks.

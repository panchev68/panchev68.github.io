Lib::XCOM::Protocol Class Referencefinal

Description

A frame on the wire is a start delimiter, a payload length, a command byte, the payload and a little-endian CRC16, with every occurrence of the delimiter or the escape marker inside the body replaced by a two-byte escape sequence. All methods are static; the type is never instantiated.

◆ MAX_FRAME_SIZE

size_t Lib::XCOM::Protocol::MAX_FRAME_SIZE = 1U + (2U * (MAX_RAW_FRAME_SIZE - 1U))
staticconstexpr

Escaping can double every byte after the leading delimiter, so the wire form of a maximal frame is almost twice its raw size. Sizing a buffer by the raw length instead would reject perfectly valid frames whose payload happens to contain many delimiter or escape bytes.

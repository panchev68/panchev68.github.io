Description

template<HttpTransport T_RAW_TRANSPORT>
class Lib::HTTP::WolfSSLTransport< T_RAW_TRANSPORT >

wolfSSL-backed TLS "HttpTransport", wrapping any raw byte-stream transport for HTTPS connections to a cloud service.

"T_RAW_TRANSPORT" is the already-connected link the TLS handshake and session run over - a Wiznet "Socket", a GSM module's data-mode stream, or anything else satisfying "HttpTransport"; this class has no knowledge of what that link actually is, so a new transport (e.g. a different GSM module or chip) needs no change here. "open()" runs the TLS handshake; "close()" (or the destructor) tears the TLS session down without touching the raw transport, so the caller still owns and closes it. Not thread-safe: one instance serves one connection from one task.

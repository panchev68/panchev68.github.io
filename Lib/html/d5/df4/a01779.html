Lib::Helper::JaggedArrayBase< T_ELEMENT > Class Template Reference

Description

template<typename T_ELEMENT>
class Lib::Helper::JaggedArrayBase< T_ELEMENT >

The class stores raw pointers and does not take ownership of the pointed objects. It guarantees simple indexed access and basic modification routines. Clients are responsible for the lifetime of stored pointers. Copying and moving are both supported (and cheap): they only duplicate/transfer the pointer list, never the pointees.

Template Parameters
T_ELEMENTType of the stored element or row object.

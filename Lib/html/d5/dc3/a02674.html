Helper.hpp File Reference

Byte-order conversion helpers for the LAN9252 EtherCAT slave controller. More...

Description

Converts between unsigned integers and their little-endian byte representation, which is the order the LAN9252 expects for register payloads. The conversion is written with explicit shifts instead of a union or a 'std::bit_cast', so it produces the same wire format on any host byte order and stays usable in constant expressions. Reading a union member other than the one last written is undefined behaviour in C++; these helpers exist so the driver never has to rely on it.

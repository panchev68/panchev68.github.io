Lib::HAL::I2C::HandleRegistry Class Referencefinal

Description

'DeviceManager<T_DEVICE, T_HANDLE>' is a singleton keyed on the concrete C++ type, so 'Port<IT>' and 'Port<DMA>' each get their own independent registry and would never notice if both were constructed on the same physical handle. This plain, non-template registry is shared across every 'DriverMode', so claiming one physical peripheral twice is caught instead of letting two drivers silently manage the same hardware.

Lib::BSP::DeviceManager Class Reference

Description

Implements a singleton pattern to manage a collection of registered devices and orchestrate their initialization and periodic tick event handling. Devices register themselves automatically through the DeviceBase constructor and are organized in a dynamic list. The manager controls the creation and lifecycle of a periodic timer driven by FreeRTOS, ensuring all registered devices receive tick events at regular intervals.

bool Lib::BSP::DeviceManager::setup ( )
inlinestatic

Calls the setup method on all registered devices and creates a FreeRTOS timer for periodic tick event distribution. Once the timer is successfully started, all registered devices will receive periodic handleTickEvent calls at regular intervals.

Returns
true if all devices were initialized and the tick timer was successfully created and started; false otherwise.

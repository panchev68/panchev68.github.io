Lib::Digi::Core::AtCommandChannel Class Reference

Description

Used via composition, not inheritance: each command type owns an AtCommandChannel member and forwards its open()/close()/isOpenState()/receive() to it, while keeping its own send() and response-frame event handler, since those differ by AT command frame type.

Lib::Pneumatics::Cylinder Class Reference

Description

Either or both sensors may be physically absent, configured via Config::offSensor / Config::onSensor; an absent sensor's transitions are then confirmed by timeout instead, and its uncommanded-move detection is disabled. With both sensors absent, the cylinder behaves as a purely time-based actuator: Status::UNKNOWN only clears once command() is called, and Status::IS_ERROR can never be raised.

Lib::Ethernet::Wiznet::ClientBase Class Referenceabstract

Description

TCP client base class for Wiznet Ethernet communication.

This abstract class provides a framework for TCP client operations, managing connection state transitions, message handling, and task-based communication loops. It integrates with FreeRTOS for non-blocking asynchronous network operations and provides hooks for LED feedback and application-specific logic.

Provides connection state management, message handling, and diagnostic tracking.

Initializes connection state to IDLE, disables activity LEDs, and creates a FreeRTOS task that runs the main message processing loop. The task has a stack size of 256 bytes and priority level 1.

Postcondition
Connection state is set to IDLE, and a TCP_CLIENT task is running.

Lib::HAL::Timer::TimTimebase Class Referencefinal

Description

Controls hardware timer blocks configured under active periodic Timebase profiles.

Eliminates CPU polling overhead by mapping the hardware Update Interrupt (UIF) through the DeviceManager to a task notification, so a task blocked in "waitPeriod()" wakes once per period.

Unlike the other timer wrappers this header does not define the HAL callback: CubeMX already generates "HAL_TIM_PeriodElapsedCallback()" in "main.c" whenever a timer is the HAL timebase, which the project relies on with FreeRTOS. Forward to this driver from that function's user-code section instead:

void Lib_HAL_TimTimebase_PeriodElapsed(TIM_HandleTypeDef * htim); // USER CODE BEGIN PFP
...
Lib_HAL_TimTimebase_PeriodElapsed(htim); // USER CODE BEGIN Callback 1

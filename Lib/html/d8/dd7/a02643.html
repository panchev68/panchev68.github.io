I2C EEPROM driver base class. More...

Description

Provides a base implementation for I2C EEPROM drivers supporting variable address sizes and page-based write operations. Manages I2C communication, device addressing, memory access, and page-aligned write handling with appropriate timing delays for EEPROM write cycles. Uses CRTP so concrete drivers only need to supply the address-width-specific read/write implementation, while shared transfer validation and dispatch live here.

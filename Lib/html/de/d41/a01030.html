Lib::BSP::Voltmeter::Base Class Reference

Description

Voltmeter::Base reads raw ADC values periodically from a configured ADC channel, applies median-based filtering through integration, converts the integrated value to voltage using linear interpolation, and notifies observers when the voltage changes. The class inherits from DeviceManager::DeviceBase for integration into the device management framework.

The measurement cycle is controlled by a configurable update period, and the filtering is performed with a fixed window size of five samples. Derived classes can override handleValueChanged to perform custom actions when voltage values are updated.

◆ start()

virtual bool Lib::Digi::API::ApplicationBase::start ( bool pauseAfterStart)
inlinevirtual

Registers the module's response event handlers, resets the hardware and waits for it to report readiness, then reads the initial parameter set and starts the RTOS task that drives update().

Parameters
pauseAfterStartIf 'true', the application starts in the PAUSE state instead of RUNNING.
Returns
'true' on success; 'false' if the module failed to open or did not respond to the hardware reset.

Lib::System::FirmwareVersion Class Reference

Description

This class extends VersionBase to provide firmware version handling with additional build date tracking. It automatically formats the compilation date in YYYY-MM-DD format and provides methods for accessing the version in various formats (numeric, string). The class supports implicit type conversion to both uint32_t and the fixed version-string buffer for convenient version representation. Derives from VersionBase via CRTP, re-exposing the protected base members as public through using-declarations.

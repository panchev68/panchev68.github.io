Discrete Kalman filter for signal filtering and state estimation. More...

Description

Implements a template-based 1-dimensional Kalman filter supporting arithmetic types (integral and floating-point). The filter uses recursive estimation to reduce noise while maintaining responsiveness to signal changes. It features configurable process noise, sensor noise and initial error terms and is optimized for real-time embedded systems.

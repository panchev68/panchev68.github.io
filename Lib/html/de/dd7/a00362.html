I2CPortBase.hpp File Reference

Configures the minimal I2C lifecycle policy shared by every transfer mode, including blocking. More...

Description

Owns no state of its own - not even the native handle: it reaches the handle through 'derived()->getHandle()' instead of inheriting 'Device<>'. 'Device<>' brings an intrusive DeviceManager list link ('nextDevice') that only an interrupt-driven mode ever uses; a blocking specialization has no business carrying it, since it never registers with the DeviceManager. Each mode therefore owns its own handle storage: 'IT'/'DMA' get it from 'Device<>' (which DeviceManager also needs), while the blocking specialization stores it directly.

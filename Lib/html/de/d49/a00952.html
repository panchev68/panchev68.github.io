Lib::BSP::W25Q128JVSIQ Class Reference

Description

Implements I/O operations for Winbond W25Q128JVSIQ serial flash device. In-memory caching of device parameters is performed on first access. Derives from 'FMEM::SPI::DriverBase' via CRTP: 'readImpl()'/'writeImpl()'/ 'eraseChipImpl()'/'eraseSectorImpl()' below are dispatched to by the base's 'read()'/'write()'/'eraseChip()'/ 'eraseSector()' without a vtable, and the SPI port/chip-select members are inherited from the base rather than duplicated here. 'open()'/'close()'/'getInfo()' are overridden outright since this device needs a power-up/reset/ JEDEC-probe sequence and a richer, device-specific 'Info' the generic base does not model.

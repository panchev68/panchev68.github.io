Lib::Crypto::WolfSSHServerContext Class Referencefinal

Description

Server-side SSH context: host key, banner and password authentication, shared by every session created from it (CubeMX: wolfSSH Core).

One context normally serves every session of a single derived "WolfSSHServer" type (sequential or concurrent); it must outlive every session created from it. Registering a session of a different derived type against the same context overwrites its I/O dispatch, so one context should serve one "WolfSSHServer" specialization. Not thread-safe: configure it (host key, banner, auth handler) before any session starts accepting, then treat it as read-only.

◆ command()

template<typename T_DEVICE>
bool Lib::HAL::OSPI::Base< T_DEVICE >::command ( OSPI_RegularCmdTypeDef & cmd,
uint32_t timeoutMs )
inlinenodiscard

Sets up the instruction/address/data phases for the transaction that follows; a command with a data phase ('cmd.DataMode' not 'HAL_OSPI_DATA_NONE') must be followed by a matching 'transmit()' or 'receive()' call. How the command actually executes, and whether the calling task blocks, is entirely up to the concrete 'Port<DriverMode>'.

Parameters
cmdFully populated command descriptor; 'cmd.NbData' drives the byte count of the following 'transmit()'/'receive()' call.
timeoutMsTimeout in milliseconds to wait for the command phase to complete.
Returns
'true' on success; 'false' on error or timeout.

Description

Concrete M24C16 EEPROM driver implementation.

The M24C16 is a 2048-byte (16K-bit) EEPROM with a 16-byte page size, addressed with 8-bit word addresses. Address bits 8..10 travel in the slave address, so the chip ignores its E2/E1/E0 pins and the configured strap address must be 0.

Derives from "Driver<M24C16>" (CRTP), which provides all transfer validation, page-aligned writing and dispatch.

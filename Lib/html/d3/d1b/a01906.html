Lib::HAL::GPIO::ExtInterrupt Class Referencefinal

Description

Handles hardware external line interrupts with centralized notification-driven dispatching.

A single shared worker task services every registered pin instance; the interrupt path only ORs a bitmask task notification, keeping ISR execution time minimal. The private nested "DeviceManager" maps each pin number to its instance through a direct index lookup, so dispatch never sweeps the full registry inside the interrupt path.

void Lib::HAL::GPIO::ExtInterrupt::bindCallback ( FunctionRef< void()> callback)
inlinenoexcept

Binds the callback invoked from the shared worker task when this pin's interrupt fires.

Replaces any previously bound callback. The callback runs in the worker task, never in the ISR. It is only referenced, not copied: a capturing lambda must be an lvalue that outlives the binding, while a capture-less lambda or a function pointer may be passed directly.

Parameters
callbackCallable invoked with no arguments on each interrupt; must be bound.

Lib::Digi::API::Service::ChannelScanner Class Referencefinal

Description

One scan starts on every open() and runs in the application task, in the same task as Parameters, so the channel changes need no locking. A channel is left after the connection quality reports a full scanner-mode window or after SCAN_CHANNEL_PERIOD. The channel values are written to CH unchanged, so they must be valid for the module's band. When the scan ends the service stays running, idle, until close().

FIX: The scan used to run in its own task, which called Parameters::setChannel() and Parameters::writeChanges() concurrently with Parameters::process() in the application task; it also cost a task stack and a queue.

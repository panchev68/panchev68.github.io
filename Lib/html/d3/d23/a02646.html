LAN9252 EtherCAT slave controller low-level driver interface. More...

Description

Provides the Base class which encapsulates SPI and GPIO management, chip initialization, reset sequencing, and register access for the LAN9252 EtherCAT slave controller. The implementation supports CSR and PRAM register operations, burst transfers, and basic chip state management required for EtherCAT communication.

Every operation that touches the bus reports success, and every hardware handshake is bounded by a timeout, so a device that stops responding surfaces as a failed call instead of a task that never returns.

Depends on HAL SPI and GPIO modules, Helper and Registers modules. Ensure SPI and GPIO peripherals are configured before calling open().

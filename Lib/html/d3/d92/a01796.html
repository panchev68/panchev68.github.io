◆ toBcd()

template<std::unsigned_integral T>
constexpr uint32_t Lib::Helper::Convert::Hex< T >::toBcd ( T number)
inlinestaticnodiscardconstexprnoexcept

Each decimal digit of the input occupies a nibble in the returned value. A 32-bit result can only hold eight packed decimal digits, so the input is limited to BCD_MAX_VALUE; the member is not available for types wider than 32 bits.

Parameters
numberValue to convert, must not exceed BCD_MAX_VALUE.
Returns
BCD encoded 32-bit value.

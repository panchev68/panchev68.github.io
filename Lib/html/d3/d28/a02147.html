RTOS::EventGroup

Example demonstrating opening an EventGroup, setting bits from task and ISR-safe context, waiting for bits, and clearing them on exit.

Example demonstrating opening an EventGroup, setting bits from task and ISR-safe context, waiting for bits, and clearing them on exit.The example shows a typical usage pattern: create wrapper, open underlying FreeRTOS event group, set and wait for bits, then close. It uses pdMS_TO_TICKS to convert milliseconds.

Example usage:
#include "EventGroup.hpp"
#include "FreeRTOS.h"
void example_task()
{
RTOS::EventGroup eg;
if (!eg.open()) {
// handle error
return;
}
RTOS::EventGroup::EventBitset bits;
bits.set(0); // event bit 0
bits.set(3); // event bit 3
// Set bits from task context
eg.setBits(bits);
// Wait up to 1000 ms for both bits to be set and clear them on exit
auto result = eg.waitForBits(bits, pdMS_TO_TICKS(1000), true, true);
if (result.test(0) && result.test(3)) {
// both bits set
} else {
// timeout or partial
}
eg.close();
}

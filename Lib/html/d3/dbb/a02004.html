RTOS::MutexGuard Class Referencefinal

Description

The guarded mutex must already be open via 'Mutex::open()'; if it is not, or if the lock times out, construction still succeeds but the critical section is left unprotected. Callers relying on the lock must check isLocked().

Class-level 'nodiscard': a guard constructed as an unnamed temporary (e.g. 'MutexGuard(m);') is destroyed at the end of that statement instead of holding the lock for the following code, silently defeating the RAII protection; the attribute turns that mistake into a compiler warning.

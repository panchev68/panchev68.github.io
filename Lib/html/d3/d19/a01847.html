Description

template<size_t T_WINDOW_SIZE = 3U, typename T = int>
requires ((T_WINDOW_SIZE > 0U) && std::is_arithmetic_v<T> && std::is_signed_v<T>)
class Lib::Helper::FindPeaks< T_WINDOW_SIZE, T >

The sample type must be signed, since deltas between samples may be negative. The caller must keep the sample range such that twice the largest delta fits into T. The instance is a literal type.

Template Parameters
T_WINDOW_SIZEDistance, in samples, between the two samples compared per step; must be greater than 0.

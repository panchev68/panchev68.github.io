◆ reserveSlice()

void Lib::BSP::SK6812::TimerData::reserveSlice ( )
inline

Stores the slice as a stable word offset rather than a raw pointer, since the shared buffer is reallocated by 'TimerBuffer::bind()' every time another LED joins the ring; a cached pointer would go dangling as soon as a later LED is constructed, while the offset of an already reserved slice never changes. Must be called exactly once, after the owning SK6812 instance has finished constructing all of its members (its 'timerBuffer' reference must already be bound).

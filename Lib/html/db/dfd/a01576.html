Lib::HAL::DACPort< DriverMode::BLOCKING > Class Referencefinal

Description

The underlying STM32 HAL DAC driver raises no interrupt for a direct register write becoming active. With no hardware trigger configured, the written value reaches the output synchronously as part of the write call itself; with a hardware trigger configured, the value is latched on the next trigger edge, which must be observed through the trigger source's own interrupt (e.g. a timer update IRQ) rather than through the DAC peripheral.

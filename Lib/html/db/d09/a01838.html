Description

template<std::floating_point T_VALUE, typename T_INPUT = T_VALUE>
class Lib::Math::CubicInterpolation< T_VALUE, T_INPUT >

Builds a piecewise cubic spline from a set of (x,y) points and provides evaluation and derivative queries. Designed for embedded systems with fixed memory usage and no dynamic allocation.

Template Parameters
T_VALUEFloating-point type used for coefficients and outputs.
T_INPUTInput type for x-coordinates (defaults to T_VALUE).

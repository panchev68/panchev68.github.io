Socket class for Wiznet Ethernet communication. More...

Description

Provides TCP/UDP socket operations, error handling, and protocol/flag wrappers for embedded systems. Integrates with native Wiznet W5500 driver and supports connection, transmission, and reception. Designed for use with FreeRTOS and custom Node/DataHandle types. Ensures type safety, resource management, and extensibility for socket operations.

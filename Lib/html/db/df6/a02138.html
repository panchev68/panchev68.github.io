Lib::HAL::USBHostPortBase< T_DERIVED > Class Template Reference

Description

template<typename T_DERIVED>
class Lib::HAL::USBHostPortBase< T_DERIVED >

Compile-time polymorphic foundation implementing the lifecycle and channel policy of the USB host port.

Owns no state: the native "HCD_HandleTypeDef" is reached through "derived()->getHandle()", as in "UARTPortBase". The class is a thin typed layer over the ST HAL HCD calls; the clock, pins, VBUS switch and the interrupt ("HAL_HCD_MspInit()" and the "OTG_FS_IRQHandler()" calling "HAL_HCD_IRQHandler()") stay in the CubeMX code. Enumeration and device classes are not part of this layer.

T_DERIVEDConcrete driver class owning the native handle and the transfer mechanism.

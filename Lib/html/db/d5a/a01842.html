Lib::HAL::CANPort< DriverMode::IT > Class Referencefinal

Description

Explicit specialized variant driving asynchronous Interrupt (IT) business logic paths.

Adds the RTOS task-notification synchronization, HAL callback registration and DeviceManager wiring that only interrupt-driven transfers need. Registers automatically with the central DeviceManager.

Lib::Helper::TimePeriod

Simple example showing how to use Lib::Helper::TimePeriod to measure elapsed RTOS ticks in a task context.

Simple example showing how to use Lib::Helper::TimePeriod to measure elapsed RTOS ticks in a task context. The example starts the stopwatch, delays for a known interval, reads elapsed ticks, and demonstrates stopping and resetting the stopwatch.

Note
This example runs in a task context and relies on the FreeRTOS scheduler. Use the conversion helpers in RTOS::TickCounter when converting ticks to milliseconds for logging or checks.
See also
Lib::Helper::TimePeriod, RTOS::Task::delay, RTOS::TickCounter
Example usage:
#include "Lib/Helper/TimePeriod.hpp"
#include "Lib/RTOS/Task.hpp"
void timingExampleTask() {
Lib::Helper::TimePeriod timer;
// Start measurement
timer.start();
// Simulate work or wait for 200 ms
RTOS::Task::delay(RTOS::TickCounter::msToTicks(200U));
// Query elapsed ticks without stopping
const uint32_t elapsedTicks = timer.elapsed();
// Stop and retrieve elapsed ticks
uint32_t measured = 0U;
if (timer.stop(measured)) {
// measured contains the ticks elapsed since start
}
// Reset the timer for reuse
timer.reset();
}

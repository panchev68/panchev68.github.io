Lib::Helper::TimePeriod

Measures elapsed RTOS ticks in a task with Lib::Helper::TimePeriod.

Measures elapsed RTOS ticks in a task with Lib::Helper::TimePeriod.The example starts the stopwatch, delays for a known interval, reads the elapsed ticks and the elapsed time without stopping, then stops and resets the stopwatch.

Note
This example runs in task context and relies on the FreeRTOS scheduler. Use the FromISR variants inside an interrupt handler.
See also
Lib::Helper::TimePeriod, RTOS::Task::delay, RTOS::TickCounter
Example usage:
#include <Lib/Helper/TimePeriod.hpp>
#include <Lib/RTOS/FreeRTOS/Task.hpp>
#include <chrono>
void timingExampleTask() {
using namespace std::chrono_literals;
Lib::Helper::TimePeriod timer;
// Start measurement
timer.start();
// Simulate work or wait for 200 ms
RTOS::Task::delay(RTOS::TickCounter::toTicks(200ms));
// Query elapsed ticks and elapsed time without stopping
const uint32_t elapsedTicks = timer.elapsed();
const std::chrono::milliseconds elapsedTime = timer.elapsedTime();
// Stop and retrieve elapsed ticks
uint32_t measured = 0U;
if (timer.stop(measured)) {
// measured contains the ticks elapsed since start
}
// Reset the timer for reuse
timer.reset();
}

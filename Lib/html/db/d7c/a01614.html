Description

template<typename T_DEVICE>
class Lib::HAL::SPI::Base< T_DEVICE >

Provides common management of HAL SPI handle, transfer initiation helpers, event bit handling for completion and error conditions, and wiring of HAL callbacks to the corresponding class instance. Unlike the other port bases, the transfer handlers are 'virtual' rather than CRTP calls, so a concrete port can be swapped behind a 'Base *' at run time; the CRTP parameter stays for DeviceManager routing only.

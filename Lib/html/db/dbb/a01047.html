Lib::Communication::Modbus::Master Class Referencefinal

Description

Singleton that encapsulates the serial transport and provides methods to open, close, send messages, and handle incoming responses using callback semantics for asynchronous message reception.

Use init(SerialPort&) once to initialize the singleton with a serial port, then access via instance().

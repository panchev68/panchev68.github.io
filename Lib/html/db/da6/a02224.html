RTOS::EventGroup

Demonstrates opening an RTOS::EventGroup, setting bits from a task and from an ISR, waiting for them, and clearing them on exit.

Demonstrates opening an RTOS::EventGroup, setting bits from a task and from an ISR, waiting for them, and clearing them on exit.The task waits for two event bits with a std::chrono timeout; one bit is set by the task itself and the other by an interrupt through setBitsFromISR(), which is deferred to the timer daemon task and therefore needs configUSE_TIMERS and INCLUDE_xTimerPendFunctionCall. Only the low 24 bits are usable (8 bits with configUSE_16_BIT_TICKS); FreeRTOS reserves the rest.

RTOS::EventGroup
Example usage:
#include <Lib/RTOS/FreeRTOS/EventGroup.hpp>
#include <chrono>
using namespace std::chrono_literals;
RTOS::EventGroup events;
constexpr RTOS::EventGroup::Bits TASK_READY{1U << 0U};
constexpr RTOS::EventGroup::Bits DATA_READY{1U << 3U};
extern "C" void EXTI0_IRQHandler() {
static_cast<void>(events.setBitsFromISR(DATA_READY)); // Yields to the daemon task if needed.
}
void exampleTask() {
if (!events.open()) {
return; // Creation failed: out of heap.
}
static_cast<void>(events.setBits(TASK_READY));
// Wait up to 1 s for both bits; they are cleared on exit only if both were set.
const auto result = events.waitForBits(TASK_READY | DATA_READY, 1s, true, true);
if ((result & (TASK_READY | DATA_READY)) == (TASK_READY | DATA_READY)) {
// Both bits set.
} else {
// Timeout or only one bit set.
}
events.close();
}

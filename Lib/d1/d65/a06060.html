Lib::System::Versionfinal

Description

Container of the legacy version classes.

Groups the CRTP 'Base' with the common parsing and formatting, and the Hardware and Firmware specializations, that parse 'X.Y' version strings, convert them to packed numbers and format them, the firmware one with the build date appended. Kept for the project templates that still derive from them; new code should use 'FirmwareVersion' and 'HardwareVersion', which build on 'VersionBase' and are fully constexpr.

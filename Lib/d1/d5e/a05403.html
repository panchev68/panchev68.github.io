Lib::HAL::FlashInterfacefinal

Description

Stateless facade over the internal Flash controller.

Erasing and programming need the controller unlocked, see unlock(). The HAL calls block until the operation ends. Programming granularity follows the family: a 32-bit word where the HAL offers 'FLASH_TYPEPROGRAM_WORD', a 64-bit doubleword where it offers 'FLASH_TYPEPROGRAM_DOUBLEWORD'. Families with other granularities (for example quad-word) are not supported yet and every programming call returns false there.

Programs a buffer of 32-bit words into consecutive flash addresses.

On doubleword families the words are paired into full doublewords. An unaligned start or an odd trailing word goes through writeWord(), which preserves the neighbouring half.

Parameters
startAddressFlash address of the first word, 4-byte aligned.
dataPointerSource words.
wordLengthNumber of 32-bit words to program.
Returns
true if every word was programmed. Always false if the family's program granularity is unsupported.

bool Lib::HAL::FlashInterface::writeWord ( uint32_t address,
uint32_t data )
inlinenodiscardnoexcept

Programs one 32-bit word.

On doubleword families the hardware programs 8 bytes at once, so the other half of the doubleword is read back and written unchanged. It must still be erased (all ones) or hold the value already there.

Parameters
addressFlash address, 4-byte aligned.
dataValue to program.
Returns
true if the word was programmed. Always false if the family's program granularity is unsupported.

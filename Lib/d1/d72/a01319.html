Lib::Digi::Core::Frame0x80

Description

Parsed Digi XBee API 0x80 (64-bit receive packet) response.

The class extracts the 64-bit source address, RSSI, receive option flags and the RF payload so callers can easily access frame contents without handling raw byte parsing.

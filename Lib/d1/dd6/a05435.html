Description

Blocking master specialization.

Builds directly on I2CPortBase and stores the native handle itself, rather than through 'Device': that class brings an intrusive DeviceManager list link that only an interrupt-driven mode uses, and this mode never registers with the DeviceManager. A blocking transfer completes inside the HAL call itself, so it has no RTOS event group to wait on, no HAL callback to register and nothing to abort once the starting call has returned; that policy lives in I2CPortAsync, shared by the 'IT' and 'DMA' specializations.

Every timeout is rounded up to whole milliseconds and saturates at 'HAL_MAX_DELAY' (wait forever).

Probes whether a slave device acknowledges its address on the bus.

HAL_I2C_IsDeviceReady() is always a blocking poll in the HAL, regardless of the transfer mode this port otherwise uses for 'masterTransmit()' and 'masterReceive()', so this lives once in the shared base.

Template Parameters
RepArithmetic representation type of the timeout.
PeriodRatio type of the timeout.
Parameters
devAddressTarget 8-bit slave device address to probe.
trialsNumber of probe attempts before giving up.
timeoutDuration to wait for each probe attempt, rounded up to whole milliseconds.
Returns
true if the device acknowledged within the given trials.

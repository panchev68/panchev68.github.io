RTOS::SemaphoreCounting

Description

Counting semaphore implementation built on top of FreeRTOS counting semaphores.

The semaphore manages a handle created with xSemaphoreCreateCounting. It offers helpers to inspect the current count, capacity and to open the underlying handle when needed.

Lib::USB::SerialPort Class Reference

Description

SerialPort class for managing USB serial communication.

This class handles USB serial port operations including data transmission and reception using UART ports and RTOS tasks. It provides methods for opening/closing the port, sending/receiving data, and setting configuration parameters. Role of the type within the module or system: Provides a high-level interface for USB serial communication in embedded systems. Important design decisions or considerations: Uses RTOS tasks for asynchronous operation, message buffers for data handling.

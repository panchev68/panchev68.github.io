Lib::System::VersionBase< Derived >

Description

template<typename Derived>
class Lib::System::VersionBase< Derived >

Base class providing common version parsing, formatting, and conversion functionality.

Implements core version string parsing for "X.Y" format strings, numeric representation with separate major and minor components, and formatted string output in "X.YY.ZZ" format that includes an optional sub-version component. Customization points - getValue(), getSubVersion() and toString() - are resolved through the CRTP pattern instead of virtual dispatch: a derived class overrides them by hiding the base members with its own, identically named ones.

Parses version string in "X.Y" format into 32-bit numeric representation.

Returns an empty optional rather than a zero on failure, so a malformed string is distinguishable from the perfectly valid version "0.0". A field is rejected when it holds a non-digit or exceeds 255.

template<typename Derived>
VersionString Lib::System::VersionBase< Derived >::toString ( ) const
inlinenodiscardconstexprprotectednoexcept

Formats the version as a string in "X.YY.ZZ" format.

The major field is unpadded and the minor and sub-version fields are zero-padded to two digits, widening to three when the value needs them. Digits are produced by hand rather than through printf, which would pull in formatting machinery this target has no use for.

Returns
Formatted version string.

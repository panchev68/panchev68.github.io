Lib::Digi::Core::Frame0x88final

Description

Local AT Command Response (0x88): result of an AT command executed by the attached module.

Wire layout after the frame type byte: frame ID (1), AT command (2, ASCII big-endian), status (1), data. A frame shorter than the fixed fields leaves every member zero and "data" empty.

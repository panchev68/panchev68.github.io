Lib::BSP::EEPROM::FlashEmulation

Keeps a boot counter and a calibration structure in the two flash pages reserved for the emulated EEPROM.

Keeps a boot counter and a calibration structure in the two flash pages reserved for the emulated EEPROM.Each value has its own 16-bit key and its own length, so the counter and the calibration are stored side by side. A missing key reads as 0 bytes, which lets the first boot start from defaults. Every write() of a changed value appends a record, and the emulation compacts the pages when the active one is full.

Important
Call open() once, before the first read() or write(), and only from a task, never from an ISR.
Warning
Each boot writes the counter once, so frequent resets wear the flash. Store the counter less often when the device restarts many times.
See also
Lib::BSP::EEPROM::FlashEmulation, Lib::BSP::EEPROM::FlashEmulation::open(), Lib::BSP::EEPROM::FlashEmulation::read(), Lib::BSP::EEPROM::FlashEmulation::write()
Example usage:
#include <Lib/BSP/EEPROM/Internal/FlashEmulation.hpp>
#include <array>
#include <cstddef>
#include <cstdint>
#include <cstring>
namespace {
constexpr uint16_t KEY_BOOT_COUNT = 1U; // Number of boots, 4 bytes.
constexpr uint16_t KEY_CALIBRATION = 2U; // Calibration structure.
struct Calibration {
int16_t offset; // Sensor offset in millimetres.
uint16_t gain; // Gain in 1/1000 units.
};
// The two pages must be reserved in the linker script: the last sector pair of bank 2.
Lib::BSP::EEPROM::FlashEmulation eeprom{0x081FC000U};
} // namespace
void startup() {
if (!eeprom.open()) {
return; // The area could not be prepared; run with the default settings.
}
// Boot counter: a missing key reads as 0 bytes, so the first boot starts from 0.
uint32_t bootCount = 0U;
std::array<uint8_t, sizeof(bootCount)> rawCount{};
if (eeprom.read(KEY_BOOT_COUNT, rawCount) == rawCount.size()) {
std::memcpy(&bootCount, rawCount.data(), sizeof(bootCount));
}
++bootCount;
std::memcpy(rawCount.data(), &bootCount, sizeof(bootCount));
static_cast<void>(eeprom.write(KEY_BOOT_COUNT, rawCount));
// Calibration: read it, or keep the defaults when it is missing or of another size.
Calibration calibration{0, 1000U};
std::array<uint8_t, sizeof(Calibration)> rawCalibration{};
if (eeprom.read(KEY_CALIBRATION, rawCalibration) == rawCalibration.size()) {
std::memcpy(&calibration, rawCalibration.data(), sizeof(calibration));
}
// Store a new calibration after the user changes it.
calibration.offset = 12;
std::memcpy(rawCalibration.data(), &calibration, sizeof(calibration));
if (!eeprom.write(KEY_CALIBRATION, rawCalibration)) {
// The flash refused the record; keep the value in RAM and report the fault.
}
}

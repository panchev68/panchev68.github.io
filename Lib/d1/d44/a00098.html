Description

XPT2046 resistive touchscreen controller driver with SPI interface.

This file defines the XPT2046 class for interfacing with XPT2046 resistive touch panel controllers. Provides GPIO-based SPI communication, automatic debouncing, calibration support, and coordinate transformation with rotation capability for display orientation adjustment.

Key Features

  • 12-bit ADC resolution for touch position detection
  • Configurable calibration ranges with automatic coordinate scaling
  • Moving average integration for noise reduction and stability
  • Debounce filtering to eliminate transient touch noise

  • Support for multiple display orientations via rotation settings

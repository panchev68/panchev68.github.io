Lib::HAL::Timer::TimEventBase< T_DERIVED >

Description

template<typename T_DERIVED>
class Lib::HAL::Timer::TimEventBase< T_DERIVED >

CRTP foundation registering a timer wrapper with the DeviceManager and signalling its hardware events to a task.

Owns the DeviceManager registration that routes a raw HAL handle back to its C++ instance, and the task notification that hands a hardware event from the ISR to the waiting task. Each derived class only adds the HAL start and stop calls and the registers it drives. The DeviceManager keys on the native handle, so each derived type supports one instance per timer.

Template Parameters
T_DERIVEDConcrete timer wrapper; each type gets its own DeviceManager registry.

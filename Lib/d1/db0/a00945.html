Lib::BSP::XPT2046

Description

XPT2046 touchscreen controller driver with SPI interface and debouncing.

Provides direct SPI communication with the XPT2046 capacitive touch controller using GPIO pins for all signals (MOSI, MISO, SCK, NSS). Includes automatic debouncing, calibration support, and coordinate transformation with rotation capability. Runs touch detection on a dedicated FreeRTOS task for non-blocking operation.

Features:

  • 12-bit ADC resolution touch position detection.
  • Configurable calibration ranges for X and Y axes.
  • Moving average integration for noise reduction.
  • Support for multiple display orientations with rotation.
  • Debounce filtering to eliminate touch noise.
  • Event-driven interrupt handling with RTOS queue signaling.
Note
Uses bit-banged SPI communication instead of hardware SPI module.
Touch coordinates are clamped to calibration bounds and scaled to display dimensions.
Interrupt pin (NIRQ) must be active-low to trigger touch detection.

Lib::GUI::ProgressBarfinal

Description

Horizontal bar that shows how far a value has come between zero and a maximum.

An outline with a fill from the left; the fill never covers the outline. Changing the value only stores it, the bar appears on the display with the next Lib::GUI::ProgressBar::draw() and a flush.

The area of the bar is cleared first, so the bar can be redrawn over its previous state.

Draws with the primitives of Lib::GUI::Context, so it is clipped to the current drawing area.

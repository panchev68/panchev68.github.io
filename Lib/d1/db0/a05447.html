Description

template<typename T_DERIVED>
class Lib::HAL::I2CPortAsync< T_DERIVED >

CRTP foundation for the interrupt-driven I2C master modes.

Owns everything the two modes would otherwise duplicate: the RTOS event group, the start-then-wait master transfers, abort(), HAL callback registration and DeviceManager wiring. A mode specialization only supplies the four HAL calls that start a master transfer ('startMasterTransmit()', 'startMasterReceive()', 'startMemWrite()' and 'startMemRead()').

Template Parameters
T_DERIVEDMode specialization providing 'startMasterTransmit()', 'startMasterReceive()', 'startMemWrite()' and 'startMemRead()', each returning true once the HAL accepted the transfer.

Probes whether a slave device acknowledges its address on the bus.

HAL_I2C_IsDeviceReady() is always a blocking poll in the HAL, regardless of the transfer mode this port otherwise uses for 'masterTransmit()' and 'masterReceive()', so this lives once in the shared base.

Template Parameters
RepArithmetic representation type of the timeout.
PeriodRatio type of the timeout.
Parameters
devAddressTarget 8-bit slave device address to probe.
trialsNumber of probe attempts before giving up.
timeoutDuration to wait for each probe attempt, rounded up to whole milliseconds.
Returns
true if the device acknowledged within the given trials.

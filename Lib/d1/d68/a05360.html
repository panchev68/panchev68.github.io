Lib::HAL::I2CPortBase< T_DERIVED >

Description

template<typename T_DERIVED>
class Lib::HAL::I2CPortBase< T_DERIVED >

CRTP foundation implementing the handle-lifecycle policy shared by every I2C transfer mode, blocking included.

Owns no state of its own, not even the native handle: it reaches the handle through 'derived()->getHandle()' instead of inheriting "Device<>". "Device<>" brings an intrusive DeviceManager list link ("nextDevice") that only an interrupt-driven mode uses, and a blocking specialization never registers with the DeviceManager. Each mode therefore owns its own handle storage: "IT" and "DMA" get it from "Device<>", which the DeviceManager also needs, while the blocking specialization stores it directly.

Probes whether a slave device acknowledges its address on the bus.

"HAL_I2C_IsDeviceReady()" is always a blocking poll in the HAL, regardless of the transfer mode this port otherwise uses for "masterTransmit()" and "masterReceive()", so this lives once in the shared base.

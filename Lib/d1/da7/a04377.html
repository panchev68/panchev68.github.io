Lib::BSP::EncoderTimerfinal

Description

Rotary encoder on a timer in encoder mode, with a push button, polled for events from one task.

Rotation, button changes and the hold time are evaluated only inside read(), so call it periodically. The direction comes from the timer's direction bit, so it stays correct when the counter wraps. The button is active low, served through Lib::HAL::GPIO::ExtInterrupt in its worker task.

Important
Several steps between two read() calls make one event: poll faster than one detent can be turned.
Warning
Cannot share a program with Lib::BSP::EncoderPins, which needs its own HAL_GPIO_EXTI_Callback().

bool Lib::BSP::EncoderTimer::open ( )
inlinenodiscardnoexcept

Starts the timer, opens the button queue and binds the button callback.

Latches the current counter, so the first read() reports no spurious rotation. A failed step rolls back the ones before it. Does nothing if already open.

Returns

◆ read()

EventCode Lib::BSP::EncoderTimer::read ( )
inlinenodiscardnoexcept

Returns the next pending event without blocking.

Checks in priority order: a button change, then rotation, then an expired hold time, and returns at most one event per call. Bounce repeating the same level is filtered out, so every push gets exactly one release.

Returns
Detected event, or EventCode::NONE if nothing happened or the driver is not open.

RTOS::TaskWorkerabstract

Description

Base class for worker objects that execute a single task function inside a managed RTOS task.

Derive from TaskWorker and implement taskFunction() with the work to be performed. The default implementations of start/stop/suspend/resume forward to the contained Task helper.

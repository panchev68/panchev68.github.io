Lib::BSP::FMEM::OSPI::W25Q128JVSIQ

Reads, writes and erases a Winbond W25Q128JV serial flash on the OCTOSPI bus.

Reads, writes and erases a Winbond W25Q128JV serial flash on the OCTOSPI bus.The driver takes a shared Lib::HAL::OSPIPort<Lib::HAL::DriverMode::IT> by reference and does not own it. Addresses are byte addresses within the 16 MB chip, and Lib::BSP::FMEM::OSPI::W25Q128JVSIQ::eraseSector() works on 4 KB sectors, so a write must be preceded by an erase of the sector it touches.

Important
Target: a part with OCTOSPI, such as STM32U5. The class is compiled only when HAL_OSPI_MODULE_ENABLED is defined; on STM32F407 the whole class compiles to nothing.
Warning
Erasing and writing block the calling task while the chip is busy, which can take milliseconds. Do not call them from an ISR.

Open and identify

Lib::BSP::FMEM::OSPI::W25Q128JVSIQ::open() powers the chip up, resets it and reads the JEDEC ID; the driver is present only for the 16 MB part. Lib::BSP::FMEM::OSPI::W25Q128JVSIQ::isPresent() reports the cached result without touching the bus.

#include <Lib/BSP/FlashMemory/OSPI/W25Q128JVSIQ.hpp>
#include <Lib/HAL/OSPI.hpp>
// OCTOSPI port configured in the application (CubeMX) and shared with other consumers; defined outside this file.
extern Lib::HAL::OSPIPort<Lib::HAL::DriverMode::IT> ospiPort;
namespace {
Lib::BSP::FMEM::OSPI::W25Q128JVSIQ flash({.ospi = ospiPort});
} // namespace
bool openFlash() {
if (!flash.open()) {
return false; // Chip did not answer or the JEDEC ID is unexpected.
}
return flash.isPresent();
}

Read and write

Lib::BSP::FMEM::OSPI::W25Q128JVSIQ::write() programs pages of 256 bytes. The sector must be erased first, because programming can only clear bits.

#include <Lib/BSP/FlashMemory/OSPI/W25Q128JVSIQ.hpp>
#include <array>
#include <cstdint>
bool storeRecord(Lib::BSP::FMEM::OSPI::W25Q128JVSIQ & flash) {
constexpr uint32_t RECORD_ADDRESS = 0x000000U;
const std::array<uint8_t, 4U> record{0x12U, 0x34U, 0x56U, 0x78U};
if (!flash.eraseSector(RECORD_ADDRESS)) {
return false;
}
if (!flash.write(RECORD_ADDRESS, record.data(), record.size())) {
return false;
}
std::array<uint8_t, 4U> readBack{};
return flash.read(RECORD_ADDRESS, readBack.data(), readBack.size()) && readBack == record;
}

Power down

Lib::BSP::FMEM::OSPI::W25Q128JVSIQ::enterPowerDown() lowers the standby current between accesses. Call Lib::BSP::FMEM::OSPI::W25Q128JVSIQ::releasePowerDown() before the next access.

#include <Lib/BSP/FlashMemory/OSPI/W25Q128JVSIQ.hpp>
void idleFlash(Lib::BSP::FMEM::OSPI::W25Q128JVSIQ & flash) {
static_cast<void>(flash.enterPowerDown());
// ... long idle period ...
static_cast<void>(flash.releasePowerDown());
}

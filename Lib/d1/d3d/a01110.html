Lib::Digi::API::Service::NetworkDiscovery::Node

Description

Node class representing a discovered network node.

This class parses raw node data from AT command responses and provides structured access to the node's 16-bit network address, 64-bit MAC address, and string identifier. It ensures safe and efficient parsing of binary data.

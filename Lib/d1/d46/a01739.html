Lib::System::ParametersBase Class Referenceabstract

Description

Provides a foundation for managing system parameters with persistent storage and integrity checks.

The ParametersBase class encapsulates functionality to read, write, and validate a contiguous parameter blob stored in a Storage implementation. A CRC16 is appended to the data to allow integrity checks. It uses an internal buffer for data and CRC storage, and provides methods for setup, writing, and validation.

Role within the System module: Base class for parameter management in embedded systems.

Important design decisions: Uses abstract StorageBase for backend flexibility, includes CRC for data integrity, and requires derived classes to implement default value restoration.

Note
Derived classes must implement restoreByDefault() to set default values.

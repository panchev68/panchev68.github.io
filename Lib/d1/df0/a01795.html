Lib::XCOM::ServiceBase

Description

Base class for XCOM services.

The ServiceBase class provides a foundation for implementing XCOM services, offering utility functions for serialization and value tracking. It includes template methods for converting values to and from byte vectors, as well as the Value64Handle class for tracking changes to 64-bit values with binding and status management capabilities.

Extract value from byte vector.

Extracts a value of type T from a vector of bytes at the specified offset. If insufficient bytes are available, the remaining bytes are zero-filled. Uses bounds checking with assertion to ensure valid offset.

Template Parameters
TType of the value to extract (must be trivially copyable).
Parameters
bytesSource vector of bytes.
offsetOffset in the vector to start extraction (defaults to 0).
Returns
Extracted value, with zero-fill for missing bytes.
Precondition
offset <= bytes.size(); asserts if violated.
Postcondition
Result is a valid value of type T constructed from bytes at offset.

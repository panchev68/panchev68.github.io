Description

Specialized ST7789 display driver with SPI interface.

Template specialization of the generic Driver class for the ST7789 controller, managing LCD initialization and pixel transmission via DMA-driven SPI.

See also
ST7789V controller datasheet (Crystalfontz copy), third-party; check Sitronix for the official revision

Transmits a pixel buffer block to the display.

Configures the SPI interface for pixel data transmission, sets the address window for the target area, and initiates a DMA-based SPI transfer of pixel data to the display RAM.

A zero 'width' or 'height' is rejected: nothing is sent and the call returns without touching the bus.

Parameters
pixelBufferPointer to the pixel data buffer (16-bit color values).
xStarting column coordinate.
yStarting row coordinate.
widthBlock width in pixels.
heightBlock height in pixels.
Precondition
pixelBuffer != nullptr
width > 0
height > 0
width * height <= 0xffff

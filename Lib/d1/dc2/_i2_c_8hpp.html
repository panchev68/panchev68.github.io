Detailed Description

I2C HAL interface header.

This file provides the interface and configuration checks for integrating the I2C HAL layer. It ensures that the required callback registration macro is enabled and includes the I2CPort abstraction for STM32 HAL-based I2C communication. The file is intended to be used as a central include for I2C HAL features and enforces correct configuration for callback support.

Note
This file requires HAL_I2C_MODULE_ENABLED to be defined.
Attention
Ensure USE_HAL_I2C_REGISTER_CALLBACKS is set to 1 for callback functionality.

Detailed Description

Base class for handling version information.

VersionBase encapsulates the common functionality required to represent a version composed of a major and minor component and an additional subversion value. The class is designed to be used as a protected base for concrete version types (for example, hardware or firmware versions).

Construct from a textual version and optional subversion.

The constructor parses versionString and stores a compact numeric representation internally. The subVersion parameter may be used to provide a runtime-determined extension to the base version.

inlinestaticprotected

Parse a textual version into compact numeric form.

The function accepts a C-string in the form "X.Y" where X and Y are decimal integers. Non-numeric characters (other than the separator '.') result in a return value of 0 to indicate an invalid input.

Parameters
versionStringNull-terminated textual version ("X.Y").
Returns
A 32-bit value encoding major and minor parts (major<<8 | minor), or 0 on parse error.
Precondition
versionString should follow the "X.Y" format; the function is defensive and will return 0 on malformed input.

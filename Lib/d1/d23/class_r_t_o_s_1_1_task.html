Detailed Description

Task management class providing object-oriented FreeRTOS interface.

Encapsulates task handles and configurations for safe task management in embedded systems, including creation, lifecycle management, state queries, and priority control. Uses RAII for automatic task cleanup, provides static methods for common operations, and includes ISR-safe variants where applicable. Tasks are automatically deleted in the destructor if still running.

Note
Ensure FreeRTOS is initialized before using Task objects.

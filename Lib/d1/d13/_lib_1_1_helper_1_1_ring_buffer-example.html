Lib::Helper::RingBuffer

usage example.

RingBuffer template class usage.

This example demonstrates basic usage of the RingBuffer class, including pushing and popping elements, and checking buffer state.

Example usage:
#include "Lib/Helper/RingBuffer.hpp"
#include <iostream>
int main() {
Lib::Helper::RingBuffer<int, 3> ringBuffer;
ringBuffer.push(1);
ringBuffer.push(2);
ringBuffer.push(3);
std::cout << "Front: " << ringBuffer.front() << "\n"; // Outputs 1
std::cout << "Back: " << ringBuffer.back() << "\n"; // Outputs 3
int value;
while (ringBuffer.pop(value)) {
std::cout << "Popped: " << value << "\n";
}
return 0;
}

Lib::Ethernet::Wiznet::ClientBase< T_DERIVED >

Description

template<typename T_DERIVED>
class Lib::Ethernet::Wiznet::ClientBase< T_DERIVED >

TCP client base class for Wiznet Ethernet communication.

Connection state, message handling and diagnostic counters for an embedded TCP client. Messages are passed as std::span and received into a fixed buffer, so the client allocates nothing.

CRTP base: the derived class supplies the message handling, without virtual calls. It must provide 'handleIncomingMessage()', 'handleOutgoingMessage()', 'handleConnectionStateChangedEvent()' and 'initCallback()'; it may provide updateRxLedCallback(), updateTxLedCallback(), handleApplicationProcess() and readLinkState(), which replace the defaults of this class. If it declares them private, it must make 'ClientBase<T_DERIVED>' its friend. This class runs the connect / receive / send state machine in its own task.

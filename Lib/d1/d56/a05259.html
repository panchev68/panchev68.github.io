Lib::Errors::Error< Derived >

Description

template<typename Derived>
class Lib::Errors::Error< Derived >

CRTP foundation tracking a single error condition through an explicit lifecycle.

Instances are created and owned exclusively by Lib::Errors::Dispatcher::createError(); the derived class makes its constructors private and befriends Lib::Errors::Dispatcher. A raised error moves from Error::State::DISABLE to Error::State::NO_ERROR, then to Error::State::ACTIVE and Error::State::CLEARED, and back to Error::State::NO_ERROR, as enable(), set(), clear() and reset() are called; disable() returns it to Error::State::DISABLE from any state.

Every transition is one atomic compare-and-exchange, so tasks and interrupts may call set() or clear() on the same error concurrently, and the state-change hook runs exactly once per transition. After each move the base calls handleStateChanged() if the derived class defines it (publicly, or by befriending Error), passing the previous and the current state; without it the call is compiled out. A derived class also writes "using Error::operator=;" to keep the assignment from bool, which its own implicit assignment would hide.

Lifecycle state of an error.

Enumerator

Error reporting is disabled; set() has no effect.

NO_INIT 

Marker of the scan's last latched state before its first scan; an error never holds it.

NO_ERROR 

Enabled and currently not raised.

ACTIVE 

Currently raised.

CLEARED

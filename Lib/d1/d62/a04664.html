Description

template<typename T_DERIVED>
class Lib::BSP::Thermometer::DTH::Base< T_DERIVED >

CRTP base for DHT sensor driver implementations.

Manages low-level one-wire communication timing using a hardware timer and a GPIO pin. The background polling task launched by start() dispatches each cycle to 'T_DERIVED::taskEntry()' at compile time, with no vtable involved.

Template Parameters
T_DERIVEDConcrete driver implementing 'taskEntry()'. Must publicly inherit from 'Base<T_DERIVED>'.

Lib::BSP::SK6812

Description

One SK6812 RGBW LED, encoded as PWM compare values for a timer driven by DMA.

Keeps the linear color and writes it, gamma corrected, into its 32-word slice of a shared compare buffer: one word per bit, green-red-blue-white, MSB first. The class only fills the buffer; starting the PWM DMA transfer is up to the caller.

Important
The timer ARR must be 219: the compare values assume 220 ticks per bit, 1.25 us at a 176 MHz timer.
Warning
The buffer holds no reset gap: keep the line low for at least 80 us between frames, for example by stopping the PWM after the transfer, or the LEDs never latch the new colors.
Not tested on hardware.
See also
https://github.com/hubmartin/WS2812B_STM32F4
SK6812RGBW specification (DigiKey, Adafruit copy), third-party; check the LED vendor for the newest revision

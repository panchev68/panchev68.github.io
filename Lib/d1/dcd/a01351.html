Lib::Errors::Dispatcherfinal

Description

Owns every constructed 'Error' and periodically scans it for state changes via an 'RTOS::TickClient'.

'statusChangedHook' is invoked from the tick client's callback whenever an error becomes active, or when the count of newly cleared errors changes while none are currently active.

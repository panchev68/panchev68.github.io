Detailed Description

Specialized ILI9341 display driver implementation.

Provides full control over the ILI9341 TFT display controller with support for initialization, pixel transmission, rotation control, and backlight management. Uses SPI communication with DMA for efficient pixel block transfers.

See also
DriverBase
Controller::ILI9341
Note
This driver is optimized for STM32 HAL and FreeRTOS environments.

Transmits a block of pixel data to the display at specified coordinates.

Configures the display address window to the specified region and transfers pixel data via SPI DMA. Pixel data is expected in RGB565 format.

Parameters

xHorizontal position (column) of the block.
yVertical position (row) of the block.
widthBlock width in pixels.
heightBlock height in pixels.
Precondition
pixelBuffer must be non-null and valid.
width and height must be non-zero.
width * height must not exceed 65535 (16-bit limit).
Note
This method initiates DMA transfer; completion is notified via callback.

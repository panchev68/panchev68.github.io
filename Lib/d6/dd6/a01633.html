Lib::Crypto::WolfSSLChaCha20Poly1305final

Description

ChaCha20-Poly1305 authenticated encryption on wolfCrypt (CubeMX: ChaCha20 / Poly1305 Support).

Stateless: every call takes the key, since wolfCrypt offers this cipher only as one-shot functions. Faster than AES-GCM in software on a core without an AES accelerator.

Warning
Never reuse a nonce with the same key: it reveals the plaintext and lets an attacker forge tags.

Description

Timer template for hardware abstraction layer timer management.

This file defines the Timer template class, which encapsulates timer functionality for a specific mode in the hardware abstraction layer (HAL). The class provides exclusive ownership of a timer handle, validity checks, and mode retrieval for a given timer mode.

Purpose and functionality:

  • Encapsulates timer handle and mode for type-safe timer management in HAL.
  • Provides exclusive ownership semantics (non-copyable, non-movable).
  • Supports handle assignment, access, validity check, and mode retrieval.

Important dependencies:

  • TimerHandle.hpp for timer handle abstraction.
  • TimerMode.hpp for timer mode enumeration.
Note
This template is intended for use in the HAL layer to manage timers with specific operational modes.

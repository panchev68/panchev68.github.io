Lib::HAL::WindowWatchdog

Starts the hardware Window Watchdog (WWDG) with Lib::HAL::WindowWatchdog and refreshes it from a periodic task.

Starts the hardware Window Watchdog (WWDG) with Lib::HAL::WindowWatchdog and refreshes it from a periodic task.The wrapper does not own the CubeMX-generated handle; the pointer passed to the constructor must stay valid for the lifetime of the instance. Counter, prescaler and the initial window come from the handle, so configure them in CubeMX before calling 'open()'. Unlike the IWDG, the WWDG counts down only while its clock runs, and a refresh is accepted only inside the window.

Important
The WWDG is available on every STM32F4xx family, including the STM32F407xx target of this library. The module guard is 'HAL_WWDG_MODULE_ENABLED'; the project's 'stm32f4xx_hal_conf.h' is not in the repository, so that guard is unverified here, although the STM32Cube template enables it.
Warning
Once 'open()' succeeds the watchdog cannot be stopped until the next reset. A refresh issued before the window opens, or after the counter reaches zero, resets the MCU. 'refresh()' returns the status of the HAL call only; the HAL does not report an early refresh, so true does not prove the refresh was inside the window.

Usage

Start and refresh

#include <Lib/HAL/WWDG/WindowWatchdog.hpp>
#include <RTOS.hpp>
extern WWDG_HandleTypeDef hwwdg; // Generated by CubeMX.
void windowWatchdogTask(void *) {
static Lib::HAL::WindowWatchdog watchdog(&hwwdg);
if (!watchdog.open()) {
return;
}
while (true) {
// Period must fall inside the window configured in CubeMX.
if (!watchdog.refresh()) {
// The HAL refused the refresh; the watchdog will reset the MCU if the window is missed.
}
RTOS::delay(std::chrono::milliseconds(20));
}
}

Narrow the refresh window at run time

'setWindow()' writes the window value into the handle and re-runs HAL_WWDG_Init(), which restarts the counter. Call it once, before the refresh task starts, so that the first refresh does not fall outside the new window.

#include <Lib/HAL/WWDG/WindowWatchdog.hpp>
extern WWDG_HandleTypeDef hwwdg; // Generated by CubeMX.
bool configureWindow(Lib::HAL::WindowWatchdog & watchdog) noexcept {
return watchdog.setWindow(0x50U); // Window upper limit as a counter value.
}

Description

MAC Address class header file.

This file defines the MacAddress class for representing and manipulating MAC addresses in embedded networking applications. It provides construction from arrays, automatic generation based on device serial number, conversion to and from string representations, validation, and access methods. The class ensures type safety, bounds checking, and input validation for reliable network operations.

Important dependencies or interactions with other modules: Relies on HexHelper for hexadecimal conversions and SerialNumber for device-specific MAC generation. Interacts with network interfaces for address assignment.

Any special instructions or notes for users of the file: Use the static methods for string conversions and validation. Ensure MAC addresses are validated before use in network configurations.

Note
This class uses STMicroelectronics SRL Manufacturer OUI for generated addresses.
Attention
Validate string inputs to prevent invalid MAC address assignments.

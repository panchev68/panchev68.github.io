AdcPort.hpp - ADC Port Type Aliases.

This file defines type aliases for ADC ports operating in different driver modes, including blocking, interrupt-driven, and DMA-based modes. It provides convenient access to ADC port specializations for various use cases in embedded systems, enabling developers to select the appropriate mode based on performance and interrupt requirements. The aliases simplify code by abstracting the underlying template instantiations and promote consistent usage across the HAL layer.

The file supports synchronous operations in blocking mode, asynchronous operations in interrupt mode, and high-throughput operations in DMA mode, catering to different application needs in resource-constrained environments.

Important dependencies include the core ADC port implementations (AdcPortBlock.hpp, AdcPortIT.hpp, AdcPortDMA.hpp) and the driver mode enumeration (DriverMode.hpp). These provide the foundational classes and types for ADC functionality.

Special instructions: Choose the mode based on your application's latency and CPU usage requirements. Blocking mode is simplest but blocks execution; interrupt mode allows concurrent processing; DMA mode offers highest performance for continuous sampling.

Note
These are type aliases for template specializations; ensure the underlying implementations are included and configured properly.
Attention
Incorrect mode selection can lead to performance issues or deadlocks; verify hardware and driver compatibility.

Lib::HAL::Timer

STM32 hardware timer abstractions for encoder, input-capture, one-pulse, output-compare, PWM and timebase modes. More...

Description

STM32 hardware timer abstractions for encoder, input-capture, one-pulse, output-compare, PWM and timebase modes.

The encoder mode reads the position count and the rotation direction in hardware, so the CPU does not have to track them.

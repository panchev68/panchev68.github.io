Lib::Digi::API::Service::ServiceBase

Description

Base class for Digi API services.

Derived services implement the small lifecycle API exposed here (open/close/beginUpdate/update/endUpdate). The Manager invokes updateHandler() to drive the lifecycle and ensure proper sequencing of begin/end hooks.

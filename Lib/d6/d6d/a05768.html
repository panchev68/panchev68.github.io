Lib::Helper::SwapBytesfinal

Description

Helpers for byte-order manipulation.

Provides constexpr byte swapping for integral types, reading swapped values from unaligned memory and in-place buffer reversal.

T Lib::Helper::SwapBytes::fromPointer ( const void * source)
inlinestaticnodiscardnoexcept

Read an integral value from a possibly unaligned pointer and return its byte-swapped representation.

The bytes are copied with std::memcpy() into a byte array that is then reinterpreted with std::bit_cast(), which is well defined for unaligned or packed data.

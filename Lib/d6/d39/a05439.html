Description

template<typename Derived>
class Lib::HAL::HASHPortBase< Derived >

Shared lifecycle of the HASH port specializations.

Important
The handle must be configured for 8-bit data ('HASH_DATATYPE_8B', byte swapping): with 'HASH_DATATYPE_32B' a byte stream on a little-endian core does not hash as in FIPS 180-4. open() asserts this.
Template Parameters
DerivedConcrete mode specialization, providing 'getHandle()'.

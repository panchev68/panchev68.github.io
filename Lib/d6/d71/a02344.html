Description

template<size_t T_SIZE>
class Lib::Helper::BufferStatic< T_SIZE >

Fixed-size static buffer.

Inherits from Buffer and provides a statically allocated byte array of size T_SIZE.

Template Parameters
T_SIZENumber of bytes in the static buffer.

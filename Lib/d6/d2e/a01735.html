Lib::System::HardwareVersion

Description

Represents a hardware version with implicit conversions to numeric and string types.

The HardwareVersion class encapsulates a hardware version value, providing implicit conversion operators to uint32_t and std::string for convenient use in comparisons, logging, and serialization. It inherits from VersionBase to utilize its parsing and storage mechanisms.

Role within the System module: Manages hardware versioning for embedded devices.

Important design decisions: Inheritance from VersionBase ensures consistency with other version types and reuses proven parsing logic.

uint32_t Lib::System::VersionBase::stringToU32 ( std::string_view versionString)
inlinestaticprotectedinherited

Parse a textual version into compact numeric form.

The function accepts a string view in the form "X.Y" where X and Y are decimal integers. Non-numeric characters (other than the separator '.') result in a return value of 0 to indicate an invalid input.

Parameters
versionStringTextual version ("X.Y").
Returns
A 32-bit value encoding major and minor parts (major<<8 | minor), or 0 on parse error.
Precondition
versionString should follow the "X.Y" format; the function is defensive and will return 0 on malformed input.

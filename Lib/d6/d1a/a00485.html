Description

Singleton instance helpers for thread-safe lazy initialization.

This file provides template classes and functions for creating singleton instances of types, ensuring thread-safe lazy initialization and access. It includes basic instance management and configuration-based initialization. These utilities are designed for embedded systems where resource management is critical.

Important dependencies: Relies on standard library for placement new and alignment. Any special instructions: Use with caution in multi-threaded environments.

Note
These classes use static storage for thread-safety in single-threaded contexts.

template<MqttTransport T_TRANSPORT, size_t T_TX_SIZE = 512U, size_t T_RX_SIZE = 512U>
class Lib::MQTT::Client< T_TRANSPORT, T_TX_SIZE, T_RX_SIZE >

MQTT 3.1.1 client over any MqttTransport, built on wolfMQTT, without heap or exceptions.

Owns the wolfMQTT client state and the transmit and receive buffers; the transport is bound by reference. Operations block the calling task until the broker answers or the timeout expires. Incoming messages are delivered to the handler from inside process(). A payload larger than the receive buffer arrives in several fragments (see Message::isFirst and Message::isLast).

Every method may be called from any task: a mutex serializes the access to the wolfMQTT state. process() waits in short slices and releases the mutex between them, so a publish() from another task is delayed by at most one slice plus its own network exchange.

TLS is the wolfMQTT built-in one: set Config::useTls and, when needed, a Config::tlsCallback that configures the wolfSSL context. A transport that already encrypts (for example one built on the project's wolfSSL transport) leaves Config::useTls cleared.

Important
The message handler runs while the client lock is held, so it must not call back into the client; hand the message to another task instead. None of the methods may be called from an interrupt.
Template Parameters
T_TRANSPORTConnected-stream transport satisfying MqttTransport.
T_TX_SIZETransmit buffer size in bytes; limits the largest packet the client sends.
T_RX_SIZEReceive buffer size in bytes; limits the payload fragment handed to the handler.

Status Lib::MQTT::Client< T_TRANSPORT, T_TX_SIZE, T_RX_SIZE >::process ( std::chrono::milliseconds timeout)
inlinenodiscardnoexcept

Waits for incoming packets and hands published messages to the handler.

The wait is split into slices of PROCESS_SLICE and the client lock is released between them, so other tasks can use the client while this one waits. The wait may overshoot timeout by up to one slice.

Parameters
timeoutLongest time to wait for a packet.
Returns
Status::SUCCESS if a packet was processed; Status::TIMEOUT if nothing arrived (not a failure).

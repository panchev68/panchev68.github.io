Lib::Helper::Crc16

Description

Crc16 class for computing CRC-16 checksums.

Provides constructors for initializing with data buffers or vectors, and methods for calculating CRC-16-CCITT checksums. The class supports conversion to uint16_t for easy access to the computed checksum.

Role within the module: Utility for data integrity verification.

Important design decisions: Implements CRC-16-CCITT algorithm; stores data pointers for lazy evaluation; provides static size information.

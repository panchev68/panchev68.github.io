Description

Base driver class for SPI flash memory devices.

This file defines the base class for SPI flash memory drivers, providing a common interface for initializing, reading, writing, and erasing SPI flash memory chips. It includes configuration structures, status enumeration, and virtual methods that derived classes must implement.

The class manages SPI communication and chip select pin control, offering a standardized way to interact with various SPI flash memory devices.

Note
This is an abstract base class; concrete implementations must inherit and implement the pure virtual methods.
Attention
Ensure proper SPI configuration and pin setup before using derived drivers.

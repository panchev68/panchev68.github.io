Description

template<typename Derived>
class Lib::Digi::Core::QueryBase< Derived >

CRTP base class for XBee query frame handling.

Defines the common interface for all query frame classes, enabling uniform serialization and transmission of different frame types without a vtable. 'Derived' must implement its own 'operator Frame::Data() const'.

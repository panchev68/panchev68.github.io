Lib::BSP::Display::Driver< Controller::ILI9341 >::Config

Description

Configuration Structure for ILI9341 Driver.

Holds the necessary handles and pins for initializing the ILI9341 display driver.

Includes SPI handle, data/command pin, slave select pin, and reset pin configurations.

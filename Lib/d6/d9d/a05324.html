Lib::HAL::ADCPort< DriverMode::IT >final

Description

Interrupt-driven (IT) specialization for single regular-group conversions.

Holds the RTOS event group, the wait wrapper, the HAL callback registration and the DeviceManager wiring, none of which a blocking conversion needs.

Lib::HAL::HASHPort< DriverMode::BLOCKING >final

HASH port polling the peripheral until the digest is ready ('HAL_HASHEx_SHA256_Start()'). More...

Description

HASH port polling the peripheral until the digest is ready ('HAL_HASHEx_SHA256_Start()').

Not thread-safe: the caller serializes users of the same handle.

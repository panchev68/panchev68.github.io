Lib::BSP::Beep

Buzzer driven by toggling a timer output-compare channel for a set duration and repeat count. More...

Description

Buzzer driven by toggling a timer output-compare channel for a set duration and repeat count.

play() only arms a sequence; a periodic tick plays it out in the RTOS timer service task as beep, pause, repeat, so the call never blocks. A play() call made while a sequence is still running is ignored, also when several tasks call it at once.

Important
The timer is set up by CubeMX (prescaler and period give the tone); the driver only reconfigures the channel as output compare in toggle mode on every beep.

Lib::HAL::USBDevicePortAsync< T_DERIVED >

Description

template<typename T_DERIVED>
class Lib::HAL::USBDevicePortAsync< T_DERIVED >

CRTP foundation for the interrupt-driven USB device modes.

Owns the RTOS event group, the start-then-wait transfers, HAL callback registration, DeviceManager wiring and the event handler hook. A mode specialization only supplies the two HAL calls that start a transfer (startTransmit() / 'startReceive()'), as in UARTPortAsync.

Every HAL callback arrives in interrupt context. The registered event handler runs there too, so it must be short and may only call interrupt-safe functions; this is how a class layer such as a CDC device answers a setup packet inside the same interrupt, without a task switch.

Template Parameters
T_DERIVEDMode specialization providing 'startTransmit(uint8_t, std::span<const uint8_t>)' and 'startReceive(uint8_t, std::span<uint8_t>)', both returning true once the HAL accepted the transfer.

Receives one transfer on an OUT endpoint and waits for it.

Task context only.

The transfer ends with a short packet or when 'data' is full. On timeout, error or a bus reset it is aborted, so the HAL never writes 'data' after this returns.

Template Parameters

PeriodRatio type of the timeout.

dataDestination buffer; empty for the status stage of a control transfer.
timeoutMaximum time to wait, rounded up to whole ticks.
Returns
Number of bytes received, or nothing on initiation failure, reset or timeout.

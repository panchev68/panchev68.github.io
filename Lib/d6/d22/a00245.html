Description

Error Dispatcher for managing error instances and their states.

This file defines the Dispatcher class, which provides a singleton mechanism for managing error instances, tracking their states, and notifying observers on status changes. The Dispatcher integrates with RTOS tick services to periodically check and update error states, ensuring timely notification and management of error conditions in embedded systems. It supports error grouping, observer notification, and efficient state tracking for robust error handling.

Important dependencies include Error, Group, RTOS tick services, and container utilities.

Any special instructions or notes for users of the file: Register errors via createError and set statusChangedHook for notifications.

Note
Designed as a singleton for global error management.
Attention
Ensure RTOS is initialized before starting the dispatcher.

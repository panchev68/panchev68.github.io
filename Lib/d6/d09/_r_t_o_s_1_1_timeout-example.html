RTOS::Timeout

Timeout Usage Example

This example demonstrates how to use the Timeout class to manage timing operations in a FreeRTOS task. It shows setting timeouts, checking expiration, resetting timeouts, and performing arithmetic operations.

Example usage:
#include "Lib/RTOS/Timeout.hpp"
#include "Lib/RTOS/TickCounter.hpp"
void someTaskFunction(void *pvParameters) {
// Create a timeout for 1000 ticks (approximately 1 second at 1000Hz tick rate)
RTOS::Timeout timeout(1000);
// Main task loop
while (true) {
// Check if timeout has expired
if (timeout.isExpired()) {
// Perform periodic action
// ... (e.g., toggle LED, send heartbeat, etc.)
// Reset timeout to start counting again
timeout.reset();
}
// Alternative: Check remaining time
uint32_t remaining = timeout.getRemainingTicks();
if (remaining < 100) {
// Timeout is about to expire, prepare for action
}
// Extend timeout by 500 ticks
timeout += 500;
// Shorten timeout by 200 ticks
timeout -= 200;
// Disable timeout temporarily
timeout.disable();
// Re-enable with new duration
timeout.set(2000);
// Delay task for 100 ticks
RTOS::Task::delay(100);
}
}

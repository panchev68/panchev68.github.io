Lib::Helper::Container< T >

Description

template<typename T>
class Lib::Helper::Container< T >

Container template class for managing pointer collections.

Provides methods to add, remove, and process items in a collection without allowing duplicates. It uses a vector internally for storage.

Role within the module: Utility for managing lists of objects.

Important design decisions: Stores raw pointers; does not manage ownership. Prevents duplicate additions.

Template Parameters
TThe type of objects pointed to by the pointers.

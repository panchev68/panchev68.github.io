Description

SHA-256 message digest (FIPS 180-4), selectable between two implementations through SHA256Engine.

SOFTWARE is the portable compression in plain C++: no hardware dependency, available in every project. HARDWARE drives the STM32 HASH peripheral in SHA-256 mode and needs HAL_HASH_MODULE_ENABLED plus a caller-owned HASH_HandleTypeDef. There is no reliable way to tell, from this header, whether a project that happens to enable the HASH module actually wants it used for this digest (the module may be enabled for an unrelated feature, or the peripheral may be shared with other code), so the engine is always an explicit template argument, never auto-selected from HAL_HASH_MODULE_ENABLED. Lib::Crypto::SHA256<> (empty angle brackets) keeps meaning SOFTWARE; this is a breaking change from the previous non-template Lib::Crypto::SHA256 class, so every existing caller needs the explicit <> added at its declaration (C++ only substitutes a template's default argument where an argument list, even an empty one, is actually written).

Streaming interface for both engines: construct, feed data with update() any number of times, then call finish(). The SOFTWARE engine owns no tables beyond the 64 round constants; the whole state is 104 bytes, no heap.

const Lib::Crypto::SHA256<>::Digest digest = Lib::Crypto::SHA256<>::hash(message); // SOFTWARE, as before
Lib::Crypto::SHA256<Lib::Crypto::SHA256Engine::HARDWARE> hasher(&hhash); if (hasher.update(message)) { const
std::optional<Lib::Crypto::SHA256<Lib::Crypto::SHA256Engine::HARDWARE>::Digest> digest = hasher.finish();
}

Lib::BSP::Backlight

Description

PWM controlled backlight with auto-dimming support.

Backlight encapsulates a TIM peripheral PWM channel and provides a configurable software dimmer that smoothly fades between values and can reduce brightness after a period of inactivity. The class uses the RTOS TickService::ClientBase interface to receive periodic tick events for timing fades and sleep timeout handling.

Responsibilities:

  • Controlling PWM brightness via a TIM peripheral.
  • Smoothly fading brightness over a configured time interval.
  • Implementing inactivity-based automatic dimming.
  • Coordinating with the RTOS tick service for timing events.

Lib::Digi::API::ServerBaseabstract

Description

Base class for Digi XBee API server implementations.

Provides a foundational implementation for Digi XBee API server components, extending ApplicationBase to handle server-specific operations such as message transmission, reception, and state management for embedded RTOS-based systems. Derived classes implement application-specific logic for processing incoming messages, preparing outgoing messages, and handling periodic task events. The class manages a transaction state machine to coordinate message exchanges and connection state. Designed for use in Digi XBee API server applications, it emphasizes modularity, extensibility and integration with the broader Digi XBee API infrastructure.

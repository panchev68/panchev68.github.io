WolfSSL.hpp

Description

Declares the C++ wrappers over the wolfCrypt primitives of the I-CUBE-wolfSSL pack.

The whole file compiles to nothing without the wolfSSL middleware, and each class beyond SHA-256 and the random generator compiles only when its algorithm is enabled in the wolfSSL configuration generated by CubeMX.

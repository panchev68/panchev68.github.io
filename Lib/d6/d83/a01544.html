Description

Namespace for Ethernet device classes and functions.

The Lib::Ethernet namespace contains all abstractions, helpers, and types related to Ethernet device configuration, status enums, and communication utilities for embedded and real-time systems. All Ethernet-related code should reside within this namespace to ensure modularity, consistency, and maintainability.

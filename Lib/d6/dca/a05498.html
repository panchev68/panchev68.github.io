Description

Controls the microcontroller Real-Time Clock calendar structures with event notifications.

Eliminates CPU polling loops: a hardware Alarm interrupt, routed through the central DeviceManager, unblocks the background worker task instantly via task notifications. The tick service needs the 'RTC_Alarm_IRQn' interrupt enabled in the NVIC (CubeMX); HAL_RTC_SetAlarm_IT() configures the EXTI line itself.

Starts the tick worker, which calls the observer once per second, and arms the seconds alarm.

Task context only.

The observer is referenced, not copied: an lvalue must outlive the service, and only a capture-less lambda or a pointer-sized capture such as '[this]' may be passed as a temporary.

Parameters
callbackObserver executed in the worker task, outside ISR context, once per second; must be bound.
stackSizeWorker task stack size in words; size it for what 'callback' does.
priorityWorker task priority.
Returns
true if the worker runs and Alarm A is armed; false if already running, if a previous worker is still finishing after a stop from inside its own callback, or on failure.

◆ stopTickService()

void Lib::HAL::RTCDevice::stopTickService ( )
inlinenoexcept

Stops the tick service.

Task context only. Called from another task, it wakes the worker and waits until it has left its loop on its own, so the worker is never deleted in the middle of a HAL call or of the callback. Called from inside the callback, it only requests the stop; the worker exits once the callback returns. The callback must therefore not block on the task calling this.

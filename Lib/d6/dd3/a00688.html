Description

Lib::HAL namespace.

The Lib::HAL namespace encapsulates all Hardware Abstraction Layer functionality for the STM32-based embedded system library. It includes abstractions for GPIO pins, ADC ports, CAN communication, timers, backup RAM, and other peripherals.

Components within this namespace are designed to work seamlessly with FreeRTOS for multitasking and TouchGFX for user interface management.

◆ AdcHandle

using Lib::HAL::AdcHandle = Handle<ADC_HandleTypeDef>

ADC handle type alias.

Type alias for ADC handle management. This alias provides a convenient and type-safe way to work with ADC peripheral handles in the HAL layer. It wraps the standard STM32 ADC_HandleTypeDef structure with additional safety and resource management features.

The AdcHandle is used throughout the ADC subsystem to ensure consistent handle management and prevent common errors like null pointer dereferences or improper handle initialization.

Usage:

  • Pass to ADC port classes for peripheral access
  • Ensure proper initialization before ADC operations
  • Automatic resource cleanup through RAII

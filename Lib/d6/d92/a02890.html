Lib::BSP::EEPROM::I2C::Driver

Demonstrates a ready-made chip driver and a new chip driver built on the CRTP base, both on one I2C bus.

Demonstrates a ready-made chip driver and a new chip driver built on the CRTP base, both on one I2C bus.A chip driver derives from Lib::BSP::EEPROM::I2C::Driver, passes its page and chip size to the base, and picks the word address width in readImpl() and writeImpl() via the protected Lib::BSP::EEPROM::I2C::Driver::read8() or Lib::BSP::EEPROM::I2C::Driver::read16() primitives, keeping both private and befriending the base. Lib::BSP::EEPROM::I2C::Driver::read() and Lib::BSP::EEPROM::I2C::Driver::write() take any object by address and size, and Lib::BSP::EEPROM::I2C::Driver::write() splits the request into page-aligned chunks with the 5 ms write cycle after each. Each chip needs its own E2/E1/E0 strap value. A failed Lib::BSP::EEPROM::I2C::Driver::open() leaves the shared port open, so a missing chip does not cut off the other devices on the bus.

Important
Lib::BSP::EEPROM::I2C::Driver::write() sleeps through the write cycle, so call it from a task, never from an ISR.
Warning
An 8-bit chip larger than 256 bytes (M24C04 ... M24C16) needs strap 0: its upper address bits use those slave-address bits, so any other strap value addresses the wrong block.

Usage

New chip driver and storage on a shared bus

'M24C02' is a new chip built on the base; Lib::BSP::EEPROM::I2C::M24C64W is the ready-made driver. Both use the same 'Lib::HAL::I2CPort', each with its own address strap. Lib::BSP::EEPROM::I2C::Driver::read() and Lib::BSP::EEPROM::I2C::Driver::write() take the address in bytes, not in pages.

#include <Lib/BSP/EEPROM/I2C/Driver.hpp>
#include <Lib/BSP/EEPROM/I2C/M24C64W.hpp>
#include <Lib/HAL/I2C.hpp>
#include <array>
#include <cstddef>
#include <cstdint>
extern "C" I2C_HandleTypeDef hi2c1; // Generated by CubeMX in main.c.
namespace EEPROM = Lib::BSP::EEPROM::I2C;
// New chip on top of the base: M24C02, 256 bytes, 16-byte pages, 8-bit word address.
class M24C02 final : public EEPROM::Driver<M24C02> {
friend class EEPROM::Driver<M24C02>; // The base calls readImpl()/writeImpl().
public:
explicit M24C02(const Config & config) noexcept :
Driver<M24C02>(config, PAGE_SIZE, CHIP_SIZE) {
}
private:
static constexpr uint8_t PAGE_SIZE = 16U;
static constexpr size_t CHIP_SIZE = 256U;
[[nodiscard]] bool readImpl(const uint32_t addr, void * const buffer, const size_t size) noexcept {
return read8(addr, buffer, size);
}
[[nodiscard]] bool writeImpl(const uint32_t addr, const void * const buffer, const size_t size) noexcept {
return write8(addr, buffer, size);
}
};
struct Settings {
uint32_t serialNumber;
uint16_t brightness;
uint16_t crc;
};
Lib::HAL::I2CPort<Lib::HAL::DriverMode::IT> i2cPort{&hi2c1};
EEPROM::M24C64W eeprom{{.i2cPort = i2cPort, .addr = 0x00}}; // E2/E1/E0 tied low.
M24C02 calibration{{.i2cPort = i2cPort, .addr = 0x01}}; // E0 tied high.
constexpr uint32_t SETTINGS_ADDRESS = 0x0100U;
void storageTask() {
if (!eeprom.open()) {
return; // Port failed to open or the chip did not acknowledge.
}
Settings settings{};
if (eeprom.read(SETTINGS_ADDRESS, &settings, sizeof(settings))) {
settings.brightness = 80U;
// Split into page-aligned writes, each followed by the write-cycle delay.
static_cast<void>(eeprom.write(SETTINGS_ADDRESS, &settings, sizeof(settings)));
}
if (calibration.open()) {
std::array<uint8_t, 32> table{};
static_cast<void>(calibration.read(0x00, table.data(), table.size()));
}
}

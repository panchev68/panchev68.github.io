RTOS::TickService::ClientBase Class Referenceabstract

Description

Base class for tick event clients.

Clients must inherit from ClientBase and implement handleTickEvent(). Registration and unregistration are performed automatically via constructor and destructor. Each client maintains its own update period counter for independent tick event scheduling.

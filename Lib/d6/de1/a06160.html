Lib::Crypto::SHA256

Demonstrates hashing a message in one call and in pieces with the software engine, and with the STM32 HASH peripheral.

Demonstrates hashing a message in one call and in pieces with the software engine, and with the STM32 HASH peripheral.The software engine needs no hardware and is available in every project, so Lib::Crypto::SHA256 with empty angle brackets selects it. The hardware engine, 'SHA256<SHA256Engine::HARDWARE>', needs a device with the HASH peripheral, the module enabled in 'stm32f4xx_hal_conf.h' ('HAL_HASH_MODULE_ENABLED') and a caller-owned HASH_HandleTypeDef such as hhash. The STM32F407xx has no HASH peripheral (its CMSIS device header defines no HASH registers), and this project's 'stm32f4xx_hal_conf.h' has the module commented out, so on this target the hardware engine is compiled out and the hardware example below does not build. The engine is never selected automatically, so every declaration names it explicitly. Both engines feed data through Lib::Crypto::SHA256::update() and end with Lib::Crypto::SHA256::finish().

Warning
Call the hardware engine only from a task, never from an ISR, and use one instance for the lifetime of one digest: every call is a blocking HAL transaction on a shared peripheral.

Hashing with the software engine

A one-shot call fits a message that is already in one buffer; the streaming form fits a message that arrives in pieces. Do not update a hasher after Lib::Crypto::SHA256::finish().

#include <Lib/Crypto/SHA256.hpp>
#include <cstdint>
#include <span>
using namespace Lib::Crypto;
SHA256<>::Digest hashMessage(std::span<const uint8_t> message) noexcept {
return SHA256<>::hash(message);
}
SHA256<>::Digest hashPieces(std::span<const uint8_t> header, std::span<const uint8_t> body) noexcept {
SHA256<> hasher;
hasher.update(header);
hasher.update(body);
return hasher.finish();
}

Hashing with the HASH peripheral

This subsection applies only to a device with the HASH peripheral, see the lead. The peripheral accepts whole 32-bit words mid-stream, so the hasher buffers up to 3 trailing bytes of each update internally; any piece length works. A HAL failure in Lib::Crypto::SHA256::update() means the hasher must not be used again. Lib::Crypto::SHA256::finish() returns no value on a HAL failure. The class also offers a one-shot static 'hash(handle, data)' for a message held in one buffer.

#include <Lib/Crypto/SHA256.hpp>
#include <cstdint>
#include <span>
using namespace Lib::Crypto;
bool hashWithPeripheral(HASH_HandleTypeDef * handle, std::span<const uint8_t> message, SHA256<SHA256Engine::HARDWARE>::Digest & digest) {
SHA256<SHA256Engine::HARDWARE> hasher(handle);
if (!hasher.update(message)) {
return false;
}
const auto result = hasher.finish();
if (!result) {
return false;
}
digest = *result;
return true;
}

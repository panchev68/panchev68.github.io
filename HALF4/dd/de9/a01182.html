USART Interrupts Definition
STM32F4xx_HAL_Driver » USART » USART Exported Constants

Description

Elements values convention: 0xY000XXXX.

  • XXXX : Interrupt mask in the XX register
  • Y : Interrupt source register (2bits)
    • 01: CR1 register
    • 10: CR2 register
    • 11: CR3 register

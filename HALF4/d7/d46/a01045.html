SMARTCARD Interrupts Definition
STM32F4xx_HAL_Driver » SMARTCARD » SMARTCARD Exported constants

Description

Elements values convention: 0xY000XXXX.

  • XXXX : Interrupt mask in the Y register
  • Y : Interrupt source register (2bits)
    • 01: CR1 register
    • 11: CR3 register
